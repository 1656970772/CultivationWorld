# 剩余世界观参考模板 · 优化分析 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 产出一份《剩余模板优化分析报告》，对 27 个待修模板逐个给出速评卡、列出需新增的模板、并给出讨论顺序——只分析、不改模板内容。

**Architecture:** 先从 10 个已修好模板提炼评审 rubric，再建"项目代码 ↔ 模板"对照表找缺口，然后按主题分 6 组逐个产出速评卡，最后汇总新增清单与优先排序，全部写入单一报告文件，分任务提交。

**Tech Stack:** Markdown 文档；读取用 Read / Grep（模板均为 UTF-8）；原文小说如需核对按 `rg --encoding gb18030` 与 StoryGraph 规则（本计划基本不涉及原文核对）。

## 关键约定（所有任务通用）

- **交付文件（唯一产出物）：** `docs/superpowers/plans/2026-06-14-剩余模板优化分析报告.md`
- **本次不动、仅作基准的 10 个模板：** 丹药分析、法宝分析、材料分析、武器分析、炼丹师、炼器师、符师、阵法师、功法术法神通、秘境遗迹与机缘。**不对它们提修改意见。**
- **模板读取：** 用 Read 工具读 `docs/世界观参考/模板/<名>.md`（UTF-8）。**不要**用默认 UTF-8 去读原文 `.txt`；本计划无需读原文。
- **不替用户敲定"每个模板涵盖哪些点"：** 速评卡的"建议涵盖方面"只写**草案/起点清单**，供用户后续逐项确认。
- **提交信息：** 中文 `docs:` 前缀；按 CLAUDE.md，文档头部含"最后更新"日期。
- **速评卡统一格式（六字段，缺一不可）：**
  ```markdown
  #### <模板名>
  - **当前状态：** <一句话现状>
  - **主要问题：** <乱在哪：结构 / 字段 / 与代码脱节 / 缺来源标注 等，至少 2 条>
  - **对接的项目代码：** <关联的 apps/game/data/<目录> 或系统；无则写"暂无直接对接"并说明>
  - **建议涵盖方面（草案）：** <3-7 条要点，作为后续讨论起点，逐条以动词/名词短语列出>
  - **优先级：** 高 / 中 / 低 —— <一句理由>
  ```
