# 世界模拟架构目录

> 最后更新：2026-06-09

## 目标

本目录定义 `CultivationWorld` 正式运行期的世界时间、NPC 行为、近处实时模拟、远处月压缩模拟、NPC 遇见玩家剧情对话和重要 NPC 保真度架构。

其中 `01-鬼谷八荒参考模型.md` 是参考来源总结；`02` 到 `08` 是本项目的正式架构与落地接口。

核心结论：

- 玩家附近使用高保真实时域，按帧推进位置、碰撞、交互、即时战斗和剧情触发。
- 远离玩家的世界不逐帧跑全量 NPC，而按月执行一次压缩模拟，结算关系、背包、修为、境界、路线、事件、日志、死亡和门派状态。
- 近处实时与远处月压缩写入同一套实体状态、关系账本、物品交易、修为服务、事件日志和剧情状态，不建立两份世界真相源。
- NPC 遇见玩家的剧情对话使用配置化 DSL、条件解释器、权重选择、选项成本和副作用命令，不在代码中按境界、时间或地点硬编码分支。
- 重要 NPC 即使远离玩家，也使用更高保真的月内 episode 模拟，保留行动轨迹、关系义务、剧情包绑定和可追溯日志。

## 文档顺序

1. `00-架构契约与证据.md`：范围、证据等级、参考来源和当前项目事实。
2. `01-鬼谷八荒参考模型.md`：鬼谷八荒参考总结，只作为架构取法来源。
3. `02-分层时间域总架构.md`：近处实时、暖区日模拟、远处月压缩的总架构。
4. `03-远处月压缩模拟.md`：远处一个月一次算完的主流程。
5. `04-近处实时模拟.md`：玩家附近逐帧运行与既有 Job/Toil、Tick、移动、事件系统的衔接。
6. `05-NPC遇见玩家剧情对话.md`：相遇检测、对话候选、条件、选项、副作用、剧情包状态机。
7. `06-重要NPC保真度.md`：重要 NPC 分层、月内 episode、日志和性能预算。
8. `07-月压缩关键状态结算细节.md`：修为、背包、关系、任务、战斗、死亡、地点和剧情包在一个月内如何结算。
9. `08-项目落地接口与改造路线.md`：当前项目需要新增或修改的模块、关键接口和接入顺序。

## 审查结论

| 检查项 | 结论 |
|---|---|
| 通用架构 | 使用时间域、阶段处理器、StateDelta、Ledger、FidelityPolicy、DialogueResolver 等通用抽象，不为单个需求写死。 |
| 设计模式适配 | 沿用模板方法、策略、命令、注册表、观察者、仓储/账本、解释器模式。 |
| 配置化覆盖范围 | 时间域半径、保真等级、压缩阶段、月度 agenda、地点偏好、对话条件、选项、权重、副作用、重要 NPC 规则全部配置化。 |
