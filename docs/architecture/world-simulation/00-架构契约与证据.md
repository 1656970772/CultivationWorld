## 架构缺口

| 缺口 | 当前表现 | 需要补齐的架构抽象 |
|---|---|---|
| 时间粒度 | 日 Tick 与多 Tick 循环，没有近处逐帧和远处月压缩的统一调度。 | `TimeDomainScheduler`、`SimulationZoneResolver`、`PhasePipeline`。 |
| 月压缩 | 门派、道侣、生育等有月间隔，但 NPC 仍逐日循环。 | `MonthlyCompressionEngine`、`MonthlyAgendaResolver`、`StateDeltaLedger`。 |
| 位置轨迹 | 远处 NPC 状态可能只剩最终坐标。 | `TravelItinerary`、`VisitedPlaceLedger`、`EncounterOpportunityResolver`。 |
| 玩家相遇剧情 | 当前没有完整 NPC 对话 DSL 和剧情包状态。 | `EncounterDetector`、`DialogueResolver`、`DramaPackageRuntime`、`DialogueCommandEngine`。 |
| 重要 NPC | 当前 role 可区分掌门、长老、核心弟子等，但没有保真度调度策略。 | `NpcFidelityPolicy`、`ImportantNpcProfile`、`EpisodeSampler`。 |
