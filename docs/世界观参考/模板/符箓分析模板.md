# 符箓分析模板

## 适用范围

本模板用于整理玄幻、修仙作品中由原文明确出现或明确支撑的符箓、灵符、法符、符篆、符宝、玉符、符牌、令符、传讯符、遁符、攻击符、防御符、封印符、血符、魂符，以及可预制、可携带、可激活或可消耗的其他术式载体。

本模板重点分析符箓本体由什么载体和材料制成、如何注入或封存力量、成符后处于何种状态、如何保存携带与激活、激活后如何运行并产生效果、如何与目标及环境互动、能够使用几次，以及它的品阶、限制、代价、风险、状态变化、失效方式和流通价值。符师的传承、职业成长、制符委托和产业分工放入 `符师模板.md`；阵法中的阵纹与符文放入 `阵法分析模板.md`，器物铭文和法宝禁制放入对应的法宝或炼器模板。

符纸、符墨、符笔、符书和符方通常只是材料、工具或知识载体，不因带有“符”字便单独建立符箓卡。普通文字、符号比喻、族纹印记、血脉印记、阵法纹路、器物铭文和一般术法，也不因外形或功能近似而自动视为符箓；只有其明确构成独立术式载体，或以“制成、封存、携带、激活、消耗”的方式运作时，才纳入本模板。

## 整理原则

1. 准入判定：收录能够独立承载、封存、激活、运行或消耗术式的符箓及边界载体；仅是材料、工具、知识载体、容器、作用对象、身份信物、阵纹、铭文或普通文字的，不单独建卡。玉符、玉简、卷轴、玉珠、玉瓶等按实际运行方式判定，不按名称直接排除。
2. 一符一卡：同一符箓的别名、实例、品阶、载体、制作方法、使用者、效果和状态变化统一归入同一张卡；核心术式、载体或作用实质不同的，分别建卡并写明区分项。
3. 字段对应：每个字段只写本字段相关内容，不重复、不跨字段补充；不引入无关的具体事件、剧情过程或人物信息。除确有必要说明形成、激活、失效或流转事实外，不展开事件经过。
4. 原文优先：只记录原文明确说明或能够直接支撑的内容，区分旁白、人物判断、实际表现和上下文推断；没有依据时写“原文未说明”，不得用常识或同类设定补齐未知环节。
5. 生命周期完整：按来源、形成、封存、状态、激活、运行、表现、效果、消耗、交互、失效和流通等字段分别记录；每张卡保留模板列出的全部字段，不因信息不足而省略。
6. 状态与边界分开：区分激发后表现与实际效果，区分限制、代价与风险，区分正常失效、被动破解与极端崩溃；没有使用记录字段，不罗列每次使用，只填写“使用次数与持续”的结论。
7. 简洁输出：只保留判断符箓成立、运行和结果所需的信息，不展开无关剧情；流通信息只写简短持有变化链，格式为“xxx手中 -> xxx时间到xxx手中 -> xx地方被xxx所得”。

## 字段说明

- 类型与形态：类型写攻击、防御、遁逃、飞行、传讯、定神、封印、召唤、破幻、控魂、契约、储能或辅助等；形态写纸符、玉符、符牌、令符、符宝、血符、魂符、身体符箓、虚空符印或其他载体。
- 准入理由：简要说明该对象为何属于符箓或独立符法载体，如可预制携带、封存术式、贴附或捏碎激活、使用后消耗，或以临战成符的方式独立生效。
- 信息依据与确定性：写信息来自旁白直接陈述、人物判断、实际表现、上下文直接推断或尚未说明，必要时附章节、段落或情节锚点；不同结论依据不同时分别标注，不得以整张卡一个“原文明确”覆盖所有字段。
- 制作者/使用者：写制符者、炼制者、绘制者、封存者、持有者、激活者及所属势力；身份不明时写“原文未说明”。
- 品阶与稀有度：按作品自身的品级、等阶、品质、常见程度或传承限制填写；没有说明时写“原文未说明”。
- 载体与材料：写符纸、玉片、符牌、法宝胚体、金墨、银粉、丹砂、精血、魂力、身体、虚空痕迹及其他实际材料。
- 能量与封存：写法力、灵力、神识、精血、魂力、元真灵气或其他力量如何注入、保存并等待激活；没有预先封存时写明临战形成。
- 制作/形成方式：写选材、调墨、依图绘制、书写符纹、注入力量、封存、检验，以及血符凝结、虚空画符或身体绘符等形成过程。
- 状态与演变：写成符后的完整度、品质、充能程度和当前损耗，成符的保存携带方式与适宜环境，以及温养、强化、升级、退化、老化、残缺、污染、修复、补充能量和使用后残留等变化；普通符箓没有成长或状态变化时不强行补写。
- 激活方式：写念咒、注入法力、神识触发、贴附、拍击、捏碎、燃烧、抛出、展开、以血引动或自动触发等方式。
- 运行机制：写激活后符纹、封存力量、载体和外界灵气如何作用，力量如何传导、转化、锁定、释放或维持；只记录原文明确说明或上下文能够直接确认的机制，不得根据常见设定补写符纹回路、自动吸收灵气等内容。
- 激发后表现：写激活后可感知的光影、颜色、声响、气息、温度、风压、雷火、空间波动、符纹变化、虚影，以及符纸燃烧、碎裂、化灰或留下的痕迹；不重复填写实际功能效果。
- 作用对象与范围：写自身、单体、多人、区域、灵魂、阵法、幻境、传讯目标或其他对象，以及距离、覆盖范围和敌我限制。
- 效果：写攻击、防御、移动、传讯、定神、封印、召唤、破幻、控魂、储存或释放力量等实际结果。
- 使用次数与持续：写一次性、多次使用、可重复充能、持续时间、触发次数、冷却或效果被冲破前的维持状态；不明时写“原文未说明”。
- 限制/代价/风险：限制写生效前提，代价写必然支付的消耗，风险写可能但并非必然发生的负面结果；可包括境界、法力、神识、血脉、材料、口诀、目标条件、精血损耗、制作或激活失败、反噬、误触和失控。
- 交互/克制/失效：写符箓与目标、其他术法及环境的相互影响，分别说明它能克制什么、什么能克制它，以及目标抵抗、环境增益或削弱、载体损毁、力量耗尽、符路断裂、被强力冲破、封印解除等正常失效、被动破解或极端崩溃方式。
- 来源/获取/流通：写符方或传承来源、首创者、师承制作、宗门发放、坊市购买、拍卖、任务奖励、遗迹所得、抢夺、价格、转赠及持有或转移关系；流通只作简短记录，不展开交易或剧情过程。符箓本体的消耗、残留和损毁归入“状态与演变”或“交互/克制/失效”。
