# 符箓分析模板

## 适用范围

本模板用于整理玄幻、修仙作品中由原文明确出现或明确支撑的符箓、灵符、法符、符篆、符宝、玉符、符牌、令符、传讯符、遁符、攻击符、防御符、封印符、血符、魂符，以及可预制、可携带、可激活或可消耗的其他术式载体。

本模板重点分析符箓本体由什么载体和材料制成、如何注入或封存力量、成符后处于何种状态、如何保存携带与激活、激活后如何运行并产生效果、如何与目标及环境互动、能够使用几次，以及它的品阶、限制、代价、风险、状态变化、失效方式和流通价值。符师的传承、职业成长、制符委托和产业分工放入 `符师模板.md`；阵法中的阵纹与符文放入 `阵法分析模板.md`，器物铭文和法宝禁制放入对应的法宝或炼器模板。

符纸、符墨、符笔、符书和符方通常只是材料、工具或知识载体，不因带有“符”字便单独建立符箓卡。普通文字、符号比喻、族纹印记、血脉印记、阵法纹路、器物铭文和一般术法，也不因外形或功能近似而自动视为符箓；只有其明确构成独立术式载体，或以“制成、封存、携带、激活、消耗”的方式运作时，才纳入本模板。

## 整理原则

1. 先做准入判定  
   可收录预先制成的纸符、玉符、符牌、符宝和令符，也可收录临战凝成的血符、魂符、虚空符印、身体符箓及其他明确称为“符”且能独立执行术式的载体。定神符、金刚符、飞天符、通音符、剑符或小剑符箓、破魇之符、元符和金阙符箓均属于可判定对象。只有符纸、符笔或符文图样而没有成符结果时，记录在相关符箓卡的制作字段中，不单独建卡。

2. 排除相邻体系的误收内容  
   聚气散、墨叶莲、蛇涎果、聚灵草、水属性二级魔核、材料价格及四品炼药师炼制流程属于丹药或炼药体系，不建立符箓卡。阵眼阵纹、器物铭文、功法运行纹路、族纹、血脉印记、契约文字和普通符号也应先排除；只有它们形成可独立激活的符箓、符印或符法载体时，才重新进行准入判定。

3. 区分符箓本体、制符工具与符师职业  
   空白符纸、黄纸、银粉、金墨、丹砂符笔、毛笔、契纸、符囊、金纹符书和《符囊书》等，分别作为材料、工具、容器或传承记录，不自动建立符箓卡。广源派擅长符书咒文、制符不易、长老能够炼制元符等内容主要归入 `符师模板.md`；具体制成的元符、金阙符箓、持门符和斗门符则可在本模板中分别建卡。法契只有在明确呈现独立符法效果时才纳入，契纸与丹砂符笔只写入其构成或制作字段。

4. 明确内容与推断分开  
   符箓名称、材料、制作者、品阶、制作方法、运行机制、效果和代价分别判断依据与确定性，不得用常见设定补齐未知环节。人物判断、实际表现、旁白说明和上下文直接推断应加以区分；必要时记录章节、段落或情节锚点，不能用整张卡的一个“原文明确”覆盖所有字段。韩立曾用黄纸、毛笔和银粉依图绘制定神符但催动失败，只能说明该次仿制材料或方法不足；不能据此虚构正确符纸、符墨、制符口诀、成功率、运行机制或完整效果。

5. 边界符法按实际形态处理  
   没有完整符师职业体系，不妨碍明确的临战符法建立符箓卡。凤清儿“以血为契、以契为符”唤醒祖魂，可作为血契符式判定；萧炎以精血形成破魇之符并破开梦魇幻境，可作为临战血符收录；侵入火奴脑海并只能暂时维持控制的灵魂符文，可作为非预制的控魂符文候选。此类卡应写明其不是普通预制纸符，并按原文记录载体、形成方式与持续限制。

6. 一符一卡，变体归并  
   同一符箓后续出现新的品阶、品质、制作材料、激活方法、使用者、效果、限制、失败原因或交易信息时，补入同一张符箓卡。若同名符箓的核心术式、载体形态或作用实质不同，则分别建卡，并在名称中写明品阶、载体或传承等区分项；不得以“补充”“后期版本”等名义重复建卡。

7. 按符箓生命周期整理
   优先写清符箓的来源与参与角色、载体和材料如何形成符箓、力量如何注入与封存、成符如何检验并处于何种状态、如何保存携带、使用时如何激活、激活后如何运行、产生何种外在表现和实际效果、如何与目标及环境互动，以及符箓何时消耗、衰减、修复、充能、升级或失效。普通符箓没有自行成长过程时，不得强行补写；只记录原文出现的充能、温养、强化、损耗、老化、残缺、修复和升级。定神符应合并记录事先预备的法符与韩立仿制失败的信息；金刚符应记录黄色符纸、念咒、贴身激活、符内灵气消耗和形成金色光罩；元符应记录长老炼制、纳入元真灵气和争斗中取用的关系。

8. 区分激发后表现与实际效果  
   “激发后表现”只写可直接感知的外在现象，如符纸燃烧或碎裂、符纹亮起、颜色与光影变化、声响、气息、温度、风压、雷火、空间波动、虚影显现和残留痕迹；“效果”写防御、杀伤、传讯、移动、封印或破幻等实际作用。金刚符的金色漆字亮起、金光大放和金罩显现属于激发表现，抵挡攻击属于实际效果。原文没有描写外在表现时写“原文未说明”，不得按符箓名称自行设计特效。

9. 使用条件、消耗、互动和风险不可省略
   符箓不得写成无条件生效的能力。品阶与修为要求、法力或神识消耗、精血损耗、载体品质、保存期限、激活时间、作用距离、使用次数、目标抗性、环境增益或削弱、绘制失败、符路中断、反噬、误触、效果被冲破和载体损毁等均应按原文填写；同时区分符箓能够克制什么、什么能够克制符箓，以及正常失效、被动破解和极端崩溃。没有说明时写“原文未说明”。

10. 保持类型、品阶与场景覆盖  
   长篇作品应兼顾攻击、防御、遁逃、飞行、传讯、定神、封印、召唤、破幻、控魂、契约和储能等类型，并覆盖低阶日用符、高阶符箓、符宝、纸符、玉符、身体符箓、血符和临战符法。太南小会中的空白符纸、灵符价格和金刚符阶位，飞天符、通音符、剑符，广源派金纹符书与金阙符箓，《符囊书》中的元符、持门符和斗门符等内容应按各自符箓关系整理，不因某一类战斗符更显眼而忽略交易、传讯、储能或传承型符箓。

11. 缺失处理与输出自检  
    只填写原文明确说明或能由上下文直接确认的信息；输入材料缺失时写“数据缺失，不补写”，已经检查但没有相关内容时写“未检出”，尚未检查时写“未覆盖”。完成后检查：是否误收丹药、炼药材料、阵纹、器物铭文、族纹或普通文字，是否把工具和传承直接当成符箓，是否把推断写成确定事实，是否遗漏载体、材料、能量、制作、状态、激活、运行机制、激发后表现、对象范围、环境互动、次数、限制和失效，同一符箓是否被重复拆卡。每张卡只保留符箓成立与使用所需信息，不长篇复述剧情。

## 字段说明

- 类型与形态：类型写攻击、防御、遁逃、飞行、传讯、定神、封印、召唤、破幻、控魂、契约、储能或辅助等；形态写纸符、玉符、符牌、令符、符宝、血符、魂符、身体符箓、虚空符印或其他载体。
- 准入理由：简要说明该对象为何属于符箓或独立符法载体，如可预制携带、封存术式、贴附或捏碎激活、使用后消耗，或以临战成符的方式独立生效。
- 信息依据与确定性：写信息来自旁白直接陈述、人物判断、实际表现、上下文直接推断或尚未说明，必要时附章节、段落或情节锚点；不同结论依据不同时分别标注，不得以整张卡一个“原文明确”覆盖所有字段。
- 制作者/使用者：写制符者、炼制者、绘制者、封存者、持有者、激活者及所属势力；身份不明时写“原文未说明”。
- 品阶与稀有度：按作品自身的品级、等阶、品质、常见程度或传承限制填写；没有说明时写“原文未说明”。
- 载体与材料：写符纸、玉片、符牌、法宝胚体、金墨、银粉、丹砂、精血、魂力、身体、虚空痕迹及其他实际材料。
- 能量与封存：写法力、灵力、神识、精血、魂力、元真灵气或其他力量如何注入、保存并等待激活；没有预先封存时写明临战形成。
- 制作/形成方式：写选材、调墨、依图绘制、书写符纹、注入力量、封存、检验，以及血符凝结、虚空画符或身体绘符等形成过程。
- 状态与演变：写成符后的完整度、品质、充能程度和当前损耗，成符的保存携带方式与适宜环境，以及温养、强化、升级、退化、老化、残缺、污染、修复、补充能量和使用后残留等变化；普通符箓没有成长或状态变化时不强行补写。
- 激活方式：写念咒、注入法力、神识触发、贴附、拍击、捏碎、燃烧、抛出、展开、以血引动或自动触发等方式。
- 运行机制：写激活后符纹、封存力量、载体和外界灵气如何作用，力量如何传导、转化、锁定、释放或维持；只记录原文明确说明或上下文能够直接确认的机制，不得根据常见设定补写符纹回路、自动吸收灵气等内容。
- 激发后表现：写激活后可感知的光影、颜色、声响、气息、温度、风压、雷火、空间波动、符纹变化、虚影，以及符纸燃烧、碎裂、化灰或留下的痕迹；不重复填写实际功能效果。
- 作用对象与范围：写自身、单体、多人、区域、灵魂、阵法、幻境、传讯目标或其他对象，以及距离、覆盖范围和敌我限制。
- 效果：写攻击、防御、移动、传讯、定神、封印、召唤、破幻、控魂、储存或释放力量等实际结果。
- 使用次数与持续：写一次性、多次使用、可重复充能、持续时间、触发次数、冷却或效果被冲破前的维持状态；不明时写“原文未说明”。
- 限制/代价/风险：限制写生效前提，代价写必然支付的消耗，风险写可能但并非必然发生的负面结果；可包括境界、法力、神识、血脉、材料、口诀、目标条件、精血损耗、制作或激活失败、反噬、误触和失控。
- 交互/克制/失效：写符箓与目标、其他术法及环境的相互影响，分别说明它能克制什么、什么能克制它，以及目标抵抗、环境增益或削弱、载体损毁、力量耗尽、符路断裂、被强力冲破、封印解除等正常失效、被动破解或极端崩溃方式。
- 来源/获取/流通/影响：写符方或传承来源、首创者、师承制作、宗门发放、坊市购买、拍卖、任务奖励、遗迹所得、抢夺、价格、转赠及其对归属和后续行动的影响；符箓本体的消耗、残留和损毁归入“状态与演变”或“交互/克制/失效”。
