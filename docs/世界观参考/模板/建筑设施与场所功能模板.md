# 建筑设施与场所功能模板

# 规范

用于整理不宜归入势力内部结构、秘境遗迹、交易流程或宗门任务制度的中立场所、公共设施、特殊功能建筑与独立功能地标。

- 尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角、单一境界、少数名场面或少数成功案例。
- 只写原文能支撑的内容。缺失字段写“原文未说明”；不得为补齐结构而虚构。
- 本文不写总览、支撑材料段、项目字段映射或游戏化抽象；只整理值得独立收录的场所功能与事件链。
- 普通宗门内部设施放入 `势力设定模板.md`；秘境、遗迹、洞府、试炼地、禁地放入 `秘境遗迹与机缘模板.md`；拍卖、坊市、黑市等交易流程放入 `拍卖坊市与交易模板.md`；任务发布、贡献兑换和晋升考核放入 `宗门任务体系模板.md`。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 收录范围：优先收录具备中立、公共、特殊、跨势力或事件触发价值的场所；只写名称和外观不够，要写清它如何被使用、由谁维护、产生什么收益或风险。
- 中立交通设施：写传送阵、飞舟港、渡口、驿站、空间通道、界门等的通行条件、路线记录、封锁、偏差、偷渡和埋伏风险。
- 公共服务设施：写客栈、医馆、寄存处、租赁洞府、避难所、临时营地等的禁斗规则、费用、疗伤、藏身、寄存、保密和泄密风险。
- 检测与登记设施：写测灵台、血脉照验台、身份登记处、通缉照影壁、鉴定台等的检测流程、公开性、复核、身份暴露和资格结果。
- 封印与镇压设施：写镇魔塔、镇魂碑、封印井、镇压阵台、灾害隔离阵等的维护方式、失控条件、公共安全、破封和灾害外泄后果。
- 独立功能地标：写无主灵泉、雷池、地火口、寒潭、风穴、灵眼、空间裂缝观测点等的使用条件、自然周期、修炼或采集产出、争夺和反噬。
- 公共事件场所：写斗法台、论道台、法会场、公开裁决场、临时征召点等的公开规则、见证、名声传播、群体任务和冲突升级。
- 设施名称和类型：写具体名称，并归入中立交通设施、公共服务设施、检测与登记设施、封印与镇压设施、独立功能地标或公共事件场所；类型不清时按原文功能描述。
- 所属地点或控制者：写所在区域、城池、商路、边境或看守者；若声称中立，要写中立依据。
- 中立性或开放性：写是否多方可用、是否只看费用、令牌或规矩、是否被某势力暗中控制。
- 空间与布局：写入口、核心区域、等候、登记、守卫位置、逃生路线、危险区和与流程相关的布局。
- 主要功能：写通行、疗伤、住宿、检测、登记、镇压、避难、裁决、集结、短期修炼等普通功能。
- 特殊用处：写跨域传送、识破伪装、验证血脉、封锁灾害、镇压邪物、隔绝神识、触发公共事件等特殊用途；没有则写“原文未说明”。
- 使用者：写散修、宗门弟子、商队、凡人、妖族、逃亡者、追杀者、管理者、围观者等。
- 进入条件：写费用、令牌、身份、介绍人、开放时间、境界限制、许可、血脉、紧急状态等。
- 使用流程：写抵达、登记、缴费或验令、等待、使用、记录、复核、离开或异常处置；如果只出现片段，按原文片段写并标出缺口。
- 消耗：写灵石、材料、时间、名额、人情、隐私暴露、登记身份、伤势或失败代价。
- 产出：写位移、通行资格、恢复、藏身、检测结果、身份记录、材料、感悟、情报或公共消息。
- 限制与周期：写距离、次数、冷却、开放时段、自然周期、名额、身体承受上限、战时封锁等。
- 维护与管理：写阵法师、掌柜、医修、守卫、裁判、城卫、记录者、巡逻队、供能和违规惩罚。
- 风险：写身份暴露、追杀堵门、传送偏差、设施被攻破、封印松动、反噬、管理者偏袒等。
- 相关事件：写逃亡、追杀、疗伤、检测争议、封印破裂、地标争夺、公开裁决、临时征召等。
- 后续影响：写换地图、被追踪、获得资格、结识关系、名声传播、秩序变化、灾害爆发或新任务链。

```md
### 城中传送阵

- 设施名称和类型：城中传送阵；中立交通设施
- 所属地点或控制者：设在城池核心阵台区，由城卫、阵法师或城中管理者维护，按作品设定填写
- 中立性或开放性：多方可用，通常按费用、令牌、身份核验或战时封锁规则开放
- 空间与布局：入口、缴费或验令处、候阵区、核心阵台、守卫位置和异常隔离区，按作品设定填写
- 主要功能：跨城、跨域或短距离位移
- 特殊用处：紧急撤离、追踪拦截、封锁商路或触发跨地域事件，原文未说明时写“原文未说明”
- 使用者：散修、宗门弟子、商队、逃亡者、追杀者、守卫和阵法师
- 进入条件：灵石、通行令、身份登记、开放时段、境界承受上限或战时许可
- 使用流程：抵达阵台、登记或验令、缴费、等待阵法开启、传送、记录结果、异常时复核或隔离
- 消耗：灵石、阵法能量、等待时间、身份登记和传送失败代价
- 产出：位移、通行记录、换地图机会、追踪线索或公共消息
- 限制与周期：距离、次数、冷却、名额、阵法负荷、维护时段和战时封锁
- 维护与管理：阵法师供能检修，城卫守卫秩序，记录者登记通行，违规者受罚
- 风险：身份暴露、追杀堵门、传送偏差、阵法被破坏、管理者偏袒或封锁路线
- 相关事件：逃亡、追杀、商队通行、战时封城、传送事故或跨域任务开启
- 后续影响：角色换地图、被追踪、获得通行资格、消息扩散或区域秩序变化

### 城中医馆

- 设施名称和类型：城中医馆；公共服务设施
- 所属地点或控制者：设在城内安全街区，由医修、掌柜或城中势力维护，按作品设定填写
- 中立性或开放性：通常按费用和规矩接诊，可能受城规、身份、仇怨或暗中控制影响
- 空间与布局：门厅、问诊区、疗伤室、药房、休养房、守卫位置和后门路线，按作品设定填写
- 主要功能：疗伤、解毒、续命、休养、购买药材或请求医修诊断
- 特殊用处：藏身、隔绝追踪、延缓伤势、判断中毒或引出诊疗争议，原文未说明时写“原文未说明”
- 使用者：伤者、同伴、医修、掌柜、追杀者、看守者和消息打探者
- 进入条件：诊金、药材、介绍人、医修许可、急症优先规则或城中禁斗规则
- 使用流程：入馆求诊、说明伤势、缴费或抵押、诊断、疗伤或配药、休养、结算离开
- 消耗：灵石、药材、人情、时间、隐私暴露和治疗失败代价
- 产出：伤势恢复、毒性缓解、诊断结果、藏身机会、药材情报或新关系
- 限制与周期：医修境界、药材储备、治疗时长、每日接诊名额、禁斗时段和伤势承受上限
- 维护与管理：医修诊治，掌柜收费，护卫维持禁斗，药童取药，违规者被驱逐或交给城卫
- 风险：泄密、追杀堵门、误诊、药材不足、医修偏袒、诊疗争执或伤势反噬
- 相关事件：疗伤、逃亡藏身、解毒争议、医修交易、追杀冲突或城卫介入
- 后续影响：角色恢复行动能力、欠下人情、暴露行踪、获得情报或牵出后续任务
```
