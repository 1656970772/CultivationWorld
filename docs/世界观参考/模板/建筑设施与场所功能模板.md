# 建筑设施与场所功能模板

## 适用范围

本模板用于整理具有独立功能链的建筑、设施、固定场所和特殊功能地标，包括中立或公共设施、势力控制设施、天然功能地标，以及能够稳定提供修炼、悟道、淬体、疗伤、资源汇聚、检测、镇压、交通或公共事件功能的具体地点。

特殊修炼与资源场所包括但不限于：血池、灵液池、洗髓池、养魂池、剑池、固定雷池、灵泉、寒潭、血河、雷海、悟道山、悟道峰、剑意崖、重力山、剑林、浮空岛、悟道古树、悟道石、法则碑、道痕壁、传承祭坛、炼心塔、修炼台、寒冰洞和万火窟，以及其他具有稳定特殊功能的池、泉、潭、井、河、海、山、峰、崖、谷、林、岛、树、石、碑、壁、台、坛、塔、洞、窟。实际整理不仅限于这些名称；只要对象固定存在，并能写出进入、触发、使用、消耗、产出、恢复或风险机制，即可纳入。

本模板不要求场所必须中立或公共。宗门、家族、城池或个人控制的场所，只要其独立功能、使用流程、资源规则或事件价值足以单独分析，也可以建立场所卡。只写名称、外观、组织整体、普通自然地点、私人住所和纯剧情会面地点，不足以单独进入本模板。

普通宗门或家族内部堂口与制度优先放入 `势力设定模板.md`；秘境、遗迹、洞府、试炼地和禁地的探索链优先放入 `秘境遗迹与机缘模板.md`；拍卖、坊市、黑市等交易流程优先放入 `拍卖坊市与交易模板.md`；任务发布、贡献兑换和晋升考核优先放入 `宗门任务体系模板.md`。同一地点兼具特殊设施功能时，本模板保留其固定功能、使用流程和风险，其他模板只保留对应制度、探索或交易内容。

## 整理原则

1. 一设施一卡  
   同一设施的标准名、别名、版本异写、入口、附属区、流程节点、管理者变化和后续影响，优先归并到同一张卡。  
   同一大场所的入口、药园、厨房、等候区、登记处、核心区等，写入“子区域/流程节点”；只有具备独立开放规则、独立功能或独立事件链时，才拆成新卡。

2. 类型固定  
   “模板类型”必须从以下七类中选择：中立交通设施、公共服务设施、检测与登记设施、封印与镇压设施、特殊修炼与资源场所、独立功能地标、公共事件场所。  
   原文称谓较特殊时，在“原文功能类型”中按原文概括，不要把自由标签写进“模板类型”。

3. 字段完整  
   每张卡必须包含：设施名称、别名/版本异写、模板类型、原文功能类型、所属地点或控制者、中立性或开放性、场所外观描述、空间与布局、子区域/流程节点、核心媒介/功能来源、运行/触发机制、环境与规则影响、储量/恢复/枯竭、主要功能、特殊用处、使用者、进入条件、使用流程、消耗、产出、限制与周期、维护与管理、风险、相关事件、后续影响、纳入依据。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

4. 收录门槛清楚  
   进入本模板的对象必须是具体场所、设施或固定功能载体，并且能写出基本功能链：谁能使用、如何进入或接触、如何触发和运行、消耗什么、产生什么结果或风险。  
   悟道山、悟道石、血池、灵液池等不因名称特殊就自动收录；只有具备稳定功能、使用流程、资源规则、开放限制、周期变化或事件链时才建立场所卡。书籍、功法、组织名、宗门整体、普通山崖树林、私人住所内部布局和纯剧情独处地点，不因出现过人物活动就写成设施卡。

5. 转出规则明确  
   拍卖场、坊市、黑市的买卖机制转入交易模板；洞府、试炼地、禁地、灵穴洞天的进入与探索链转入秘境遗迹模板；普通宗门堂口和制度职责转入势力结构或宗门任务体系。固定场所具有独立修炼、悟道、淬体、资源产出、检测、镇压或运行机制时，可在本模板单独建卡。  
   血池、灵液池中的精血、灵液等内容物归入 `材料分析模板.md`，池体在本模板记录布局、运行、使用与恢复机制；可移动、收取、封印、认主或具有灵智的完整池体转入材料模板的“天地奇物与有灵异质”。固定悟道石、法则碑和道痕壁作为场所核心媒介时归本模板；可携带的石材原料归材料模板，被炼成完整器物时归法宝模板。

6. 特殊场所按功能链整理  
   血池、灵液池、悟道山、悟道石等特殊场所按“核心媒介—触发方式—使用过程—消耗—产出—恢复或枯竭—风险”整理。天然场所没有人工维护者时，在“维护与管理”中记录自然维持、阵法稳定、守护者或“无人维护”。

7. 摘要粒度统一  
   “相关事件”最多写 3-5 条要点，每条只写事件类型、设施作用和结果。禁止把对白、战斗过程、人物心理或长段剧情复述塞入该字段。  
   其他字段也应写规则、功能和后果，不展开无关背景。

8. 不虚构设定  
   场所外观、维护者、费用、限制、风险、开放规则、隐藏控制者和后续影响，必须按原文可支撑的信息填写。  
   常识推测不能写成事实；不确定时写“原文未说明”，或在“纳入依据”中说明不确定性。

## 字段说明

- 设施名称：写具体建筑、场所、阵台、地标或公共功能设施名称。
- 别名/版本异写：写别名、简称、错写、前后文不同译名或版本异写；没有写“原文未说明”。
- 模板类型：只能填写中立交通设施、公共服务设施、检测与登记设施、封印与镇压设施、特殊修炼与资源场所、独立功能地标、公共事件场所之一。
- 原文功能类型：按原文概括实际称谓或用途，如传送阵、飞舟港、医馆、测灵台、镇魔塔、血池、灵液池、悟道山、悟道石、灵泉、斗法台、法会场等。
- 所属地点或控制者：写所在区域、城池、商路、边境、宗门、家族、管理者或看守者；若声称中立，要写中立依据。
- 中立性或开放性：写是否多方可用、是否只看费用、令牌或规矩、是否被某势力明面或暗中控制。
- 场所外观描述：写场所可直接观察或感知到的建筑风格、地貌轮廓、尺度、色彩、材质、光照、陈设、植被、天气、气息、声响、破损痕迹及标志性景观；没有明确描写时写“原文未说明”，不得根据场所名称或功能自行补写。简单场所可用一段概括；复杂场所按需分为“整体风貌”“外部与入口”“内部与分区”“关键区域/标志物”2-4 块，不适用的分块可省略。此字段描述场所看起来或感知起来如何，“空间与布局”则描述区域之间的位置、连接和通行关系，二者不要重复。
- 空间与布局：写入口、核心区域、等候区、登记处、守卫位置、逃生路线、危险区和与流程相关的布局。
- 子区域/流程节点：写同一大场所下的入口、药园、厨房、候阵区、鉴定处、裁决台、休养房等；没有写“原文未说明”。
- 核心媒介/功能来源：写场所发挥作用所依赖的池液、泉眼、悟道石、道痕、法则碑、阵法、地火、雷霆、灵脉、封印物或其他核心载体；内容物需要独立分析时关联材料卡。
- 运行/触发机制：写自然开启、阵法启动、注入灵力、血脉响应、令牌激活、特定时辰、雷劫触发、静坐参悟或其他运行方式。
- 环境与规则影响：写灵气浓度、时间流速、重力、神识压制、法则显化、悟性增幅、淬体压力、污染、禁斗和其他区域规则。
- 储量/恢复/枯竭：写池液容量、灵气储量、感悟次数、资源恢复周期、补充方式、过度使用、失效和永久枯竭。
- 主要功能：写通行、疗伤、住宿、检测、登记、镇压、避难、裁决、集结、悟道、淬体、养魂、资源汇聚和短期修炼等功能。
- 特殊用处：写跨域传送、识破伪装、验证血脉、封锁灾害、镇压邪物、隔绝神识、触发公共事件等特殊用途；没有写“原文未说明”。
- 使用者：写散修、宗门弟子、商队、凡人、妖族、逃亡者、追杀者、管理者、围观者等。
- 进入条件：写费用、令牌、身份、介绍人、开放时间、境界限制、许可、血脉、紧急状态等。
- 使用流程：写抵达、登记、缴费或验令、等待、使用、记录、复核、离开或异常处置；如果只出现片段，按已出现内容填写。
- 消耗：写灵石、材料、时间、名额、人情、隐私暴露、登记身份、伤势或失败代价。
- 产出：写位移、通行资格、恢复、藏身、检测结果、身份记录、材料、感悟、情报或公共消息。
- 限制与周期：写距离、次数、冷却、开放时段、自然周期、名额、身体承受上限、战时封锁等。
- 维护与管理：写阵法师、掌柜、医修、守卫、裁判、城卫、记录者、巡逻队、自然维持、阵法稳定、资源补充、供能和违规惩罚。
- 风险：写身份暴露、追杀堵门、传送偏差、设施被攻破、封印松动、反噬、管理者偏袒等。
- 相关事件：最多写 3-5 条要点，每条概括事件类型、设施作用和结果。
- 后续影响：写换地图、被追踪、获得资格、结识关系、名声传播、秩序变化、灾害爆发或新任务链。
- 纳入依据：写为什么进入本模板，如具备公共开放、势力内部独立功能、特殊修炼或资源机制、跨势力使用、独立流程、公共事件或明确设施作用；边界不清时说明不确定性。
