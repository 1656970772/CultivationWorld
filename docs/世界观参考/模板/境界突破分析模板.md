# 境界突破分析模板

## 适用范围

本模板用于整理小说中各个关键境界的状态跃迁规则和实际突破案例，重点记录角色从何种积累与瓶颈出发，因何触发突破，内部发生什么核心转化，如何与环境及外力互动，最终达到何种完成度，并产生什么代价、恢复需求和长期影响。

本模板以关键境界为卡片。同一个境界下，不同角色可能有不同积累状态、突破路线、核心机制、准备、互动、结果和代价；原文描写较完整的代表性正常突破可作为基线收录，异常、极端、失败、被打断和特殊路线继续重点收录，并分别记录为“突破方式一 / 突破方式二 / 突破方式 N”。

只因为突破后基础属性增加、修为变强、寿元增加或境界名称变化，而没有突破前状态、实际过程或结果依据的，不单独收录。每个关键境界可选一至两个原文描写较完整的正常突破作为参照；重复且没有新增规则信息的普通案例不再收录。普通修炼升级、单纯战斗胜负、公开测验、成人仪式、门派考核、功法学习、资源交易和人物病情，不直接写成突破方式；只有它们直接参与突破过程或改变突破结果时，才写入对应字段。

## 整理原则

1. 一境界一卡：每张卡只对应一个规范的起点→终点境界关系。同一境界下的角色、路线、正常或异常结果统一写在同一张卡内，不按角色、资源、斗技、剧情或抽取批次重复建卡。
2. 先判定是否准入：只有发生真实境界跃迁，或失败、被打断、暂时进入、伪境、跌落等能够揭示突破规则的案例才建立突破方式。纯准备、资源炼制、功法学习、战斗试手、战力旁证、突破后巩固和普通恢复不单独建卡，必要时写入对应案例字段。
3. 总述与案例分开：先写境界与小境界一般描述，再写境界说明、突破本质与判定标准、一般突破方式和规则依据；一般规则必须有原文通用说明或多个案例共同支持，不得由单一特殊案例上推。
4. 字段对应与事件边界：每个字段只写本字段相关内容，不重复、不跨字段补充；不引入无关的具体事件、剧情过程或人物信息。突破过程只保留说明状态跃迁所需的关键节点，不设置单独的使用记录或事件记录字段。
5. 一种方式一组字段：每个保留案例使用完整的“突破方式 N”字段，编号连续且唯一；准备、契机、方式、核心机制、过程、结果、代价和稳固分别填写，不用完整剧情代替字段内容。案例起点与终点必须和境界卡片关系一致，未完成或暂时状态要明确标注。
6. 结果与证据分开：区分完整成功、部分完成、半步、伪境、暂时进入、跌落、失败、被打断和异变路线；分别标注实际代价、明确风险、失败结果和可逆性证据。没有依据时写“原文未说明”，不得把“不会跌落”等经验判断写成规则。
7. 术语和边界优先：境界、功法、资源、异象和结果使用作品原文说法；功法、丹药、法宝、阵法和战斗细节只写其对突破的直接作用，完整设定移交对应模板。
8. 字段完整与简洁输出：每张卡和每个突破方式都必须保留模板列出的字段；使用“原文未说明”“未检出”“未覆盖”或“不适用”处理缺失。只保留稳定规则和必要证据，不堆叠逐次事件、批次日志或重复案例；同一路线通常保留一至两个基线，其余仅在带来新规则时收录。

## 字段说明

- 境界卡片名称：只写规范的起点境界 → 终点境界关系，不写具体角色、资源、功法或剧情结果；同一关系的正常、异常和特殊路线统一归入该卡。
- 境界与小境界一般描述：写小说中各个境界和小境界的一般描述，包括大境界、小境界、层数、段位、圆满、半步、伪境、化形、妖兽阶位等；某些小境界没有一般特殊描述时，写“原文未说明”。
- 境界说明：简要说明这个境界在作品中的位置、前后层级和为什么属于关键突破。
- 突破本质与判定标准：写从原境界进入目标境界时，修为、能量性质、肉身、神魂、法则理解、丹田、经脉、血脉或其他核心结构发生什么质变，以及作品以什么标准判定突破真正完成；原文只说境界名称变化而没有解释内部机制时，写“原文未说明”。
- 境界一般突破方式：写该境界在小说中通常如何突破，包括一般前置条件、常见路线、资源、环境、风险、完成标准和稳固方式；原文没有一般说明时写“原文未说明”，不得由单一特殊案例推断通用规则。
- 境界规则依据与确定性：写通用规则来自旁白直接说明、修炼典籍、师长讲解、多个案例共同验证、单一案例推断或人物评价，必要时附章节、段落或原文位置；存在矛盾、适用对象限制或尚未验证时分别说明，不能用单一案例替代通用依据。
- 突破方式一 / 二 / N：只收录具有独立规则增量的正常、异常、失败或特殊路线；同一连续突破事件不拆成多个方式。
- 角色名字：写发生该次真实状态跃迁或规则性失败的角色。
- 简要介绍：写该角色当时的身份、突破类型和作为代表案例的理由；不展开角色支线或剧情背景，突破前修为、资源和瓶颈写入“突破前状态与瓶颈”。
- 案例依据与确定性：写该案例信息来自旁白、角色自述、功法或系统信息、实际突破表现、旁人判断、事后结果或上下文推断，必要时附章节、段落或原文位置；尚未确认、相互矛盾和缺失的部分分别标注。
- 所习功法：写突破时修炼、依赖或影响突破的功法、法门、斗技、秘术；没有写“原文未说明”。
- 突破前状态与瓶颈：写原境界具体层次、积累程度、身体、神魂、心境、寿元、伤势、资源余量、此前失败次数、瓶颈表现、是否满足一般资格，以及与普通突破者相比的差异。
- 突破地点与环境：写突破发生的位置，以及灵气、天气、地形、阵法、安全程度、封闭或公开状态、资源环境和界面规则等静态条件；动态帮助、攻击和规则压制写入“突破中的外部互动与干扰”。
- 突破前准备：写丹药、材料、功法运转、法宝、阵法、护法、疗伤、闭关资源、心境调整等。
- 突破契机：写为什么在此时突破，如资源齐备、药力积累、战斗压迫、功法圆满、心境变化、血脉觉醒、机缘触发、被迫冲关等。
- 突破方式：写具体路线，如丹药辅助、强行冲关、自然积累、天劫突破、心境突破、神识突破、肉身突破、血脉觉醒、外力灌顶、夺舍重修、转世恢复、妖兽化形等。
- 核心转化机制：写本次突破中真正促成境界跃迁的内部变化，如能量压缩或质变、凝丹、开脉、神魂蜕变、法则领悟、血脉觉醒、肉身重塑、吸收外力或天地认可，以及这些变化之间的因果关系；没有机制说明时不得根据境界名称补写。
- 突破过程：只按先后顺序写能够说明状态跃迁、成败或代价的关键步骤；“突破方式”写路线分类，“核心转化机制”写为何能够跃迁，本字段不逐步复述剧情。
- 突破中的外部互动与干扰：只写直接改变突破成败、风险或结果的护法、救援、规则压制、天劫、资源争夺、攻击、打断和应对，不罗列无关战斗过程。
- 突破异象/外部反应：写雷劫、灵气波动、天地异象、法宝反应、血脉变化、妖气变化、旁人察觉、护法反应或势力震动等。
- 突破结果与完成度：写完整成功、部分完成、半步、伪境、成功但未稳固、暂时进入后跌落、失败回退、被打断、异变转入其他路线、死亡或继续卡住，并判断是否达到作品给出的真正完成标准。
- 突破代价/风险/可逆性：分别写实际已经支付的资源、寿元、伤势和其他代价，当时存在但未发生的风险，以及损伤能否恢复、境界是否可能跌落、失败后能否重试、恢复所需时间和资源、是否永久失去突破资格。
- 突破后稳固/效果/长期影响：写境界是否稳定、是否存在虚弱期或适应期、如何巩固力量，以及本次突破对修为、战力、寿元、神魂、体质、能力、资源、伤势、后遗症和下一境界瓶颈的直接影响；社会或势力影响只有在原文明确改变角色后续突破条件时才记录。
