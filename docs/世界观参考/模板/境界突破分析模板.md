# 境界突破分析模板

## 适用范围

本模板用于整理小说中各个关键境界的状态跃迁规则和实际突破案例，重点记录角色从何种积累与瓶颈出发，因何触发突破，内部发生什么核心转化，如何与环境及外力互动，最终达到何种完成度，并产生什么代价、恢复需求和长期影响。

本模板以关键境界为卡片。同一个境界下，不同角色可能有不同积累状态、突破路线、核心机制、准备、互动、结果和代价；原文描写较完整的代表性正常突破可作为基线收录，异常、极端、失败、被打断和特殊路线继续重点收录，并分别记录为“突破方式一 / 突破方式二 / 突破方式 N”。

只因为突破后基础属性增加、修为变强、寿元增加或境界名称变化，而没有突破前状态、实际过程或结果依据的，不单独收录。每个关键境界可选一至两个原文描写较完整的正常突破作为参照；重复且没有新增规则信息的普通案例不再收录。普通修炼升级、单纯战斗胜负、公开测验、成人仪式、门派考核、功法学习、资源交易和人物病情，不直接写成突破方式；只有它们直接参与突破过程或改变突破结果时，才写入对应字段。

## 整理原则

1. 一境界一卡  
   每张卡对应一个关键境界突破关系，例如“炼气期 → 筑基期”“筑基期 → 结丹期”“斗之气十段 → 斗者”“筑元 → 开脉”“妖兽进阶 / 化形”。  
   同一境界下多个角色、多个路线、多个成败结果，都写在同一张卡里，不要拆成重复境界卡。

2. 先写境界总述  
   在所有境界突破卡片之前，先写“境界与小境界一般描述”。  
   该部分按小说原文整理各个境界、小境界、层数、段位、圆满、半步、伪境、化形等一般描述；某些小境界没有一般特殊描述时，写“原文未说明”。

3. 每卡先写一般突破方式  
   每张境界卡片在具体角色突破方式之前，必须先写“境界一般突破方式”。  
   该字段只写小说中对该境界突破的通用描述、常见路径、常用资源、常见风险和常见结果；如果原文没有一般说明，写“原文未说明”。不得由单个角色的特殊突破直接推断所有人都必须如此。

4. 一种方式一组字段  
   每出现一个有特点的突破方式，就写成“突破方式一 / 突破方式二 / 突破方式 N”。  
   每个境界卡片必须写境界说明、突破本质与判定标准、境界一般突破方式、境界规则依据与确定性。每个具体突破方式必须写角色名字、简要介绍、案例依据与确定性、所习功法、突破前状态与瓶颈、突破地点与环境、突破前准备、突破契机、突破方式、核心转化机制、突破过程、突破中的外部互动与干扰、突破异象/外部反应、突破结果与完成度、突破代价/风险/可逆性、突破后稳固/效果/长期影响。

5. 收录看特点  
   每个关键境界优先保留原文描写较完整的正常突破基线，再重点收录主角、重要配角、反派、妖兽进阶、失败突破、异常突破、强行突破、被打断突破、借外力突破、特殊功法路线、特殊资源路线和特殊体质路线。
   普通突破如果能够说明通用条件、内部机制、完成标准或稳固过程，可以作为代表案例；只重复“成功突破、属性增强”而没有新增信息的，不收录。

6. 成败都可收录  
   完整成功、半步突破、伪境、成功后未稳固、暂时进入后跌落、突破失败、跌境重修、被外力打断、反噬重伤、异变转入其他路线、永久失去突破资格或死亡，都可以收录。
   失败案例只有突破方式新颖、代价特殊、影响后续修炼或揭示境界规则时才收录。

7. 作品术语优先  
   境界名称、功法名称、丹药材料、突破资源、异象名称和突破结果，必须使用作品原文自己的说法。  
   不得把其他体系词汇套入当前作品；不确定时写“原文未说明”。

8. 不展开功法卡  
   “所习功法”只写角色突破时修炼或依赖的功法、法门、斗技、秘术名称，以及它在突破中的作用。  
   功法效果、品阶、来源、传承和完整层数，放入 `功法术法神通模板.md`，不要在本模板展开。

9. 不虚构设定  
   突破前状态、本质、完成标准、地点环境、准备、契机、方式、机制、过程、外部互动、异象、结果、代价、可逆性、稳固和长期影响应分别判断依据与确定性；原文没有说明时不得用常见修仙设定补齐。
   应区分旁白直接说明、修炼典籍、师长讲解、角色自述、实际突破表现、旁人判断、事后结果、多个案例共同验证和上下文直接推断；必要时附章节、段落或情节锚点。统一使用“原文未说明”“未检出”“未覆盖”或“不适用”，不要为了补齐结构自行创造丹药、护法、雷劫、心魔、攻击者、特殊效果、恢复方式或失败后果。

## 字段说明

- 境界卡片名称：写关键突破关系，如炼气期 → 筑基期、斗之气十段 → 斗者、筑元 → 开脉、妖兽某阶 → 更高阶 / 化形。
- 境界与小境界一般描述：写小说中各个境界和小境界的一般描述，包括大境界、小境界、层数、段位、圆满、半步、伪境、化形、妖兽阶位等；某些小境界没有一般特殊描述时，写“原文未说明”。
- 境界说明：简要说明这个境界在作品中的位置、前后层级和为什么属于关键突破。
- 突破本质与判定标准：写从原境界进入目标境界时，修为、能量性质、肉身、神魂、法则理解、丹田、经脉、血脉或其他核心结构发生什么质变，以及作品以什么标准判定突破真正完成；原文只说境界名称变化而没有解释内部机制时，写“原文未说明”。
- 境界一般突破方式：写该境界在小说中通常如何突破，包括一般前置条件、常见路线、资源、环境、风险、完成标准和稳固方式；原文没有一般说明时写“原文未说明”，不得由单一特殊案例推断通用规则。
- 境界规则依据与确定性：写通用规则来自旁白直接说明、修炼典籍、师长讲解、多个案例共同验证、单一案例推断或人物评价，必要时附章节、段落或情节锚点；存在矛盾、适用对象限制或尚未验证时分别说明。
- 突破方式一 / 二 / N：同一境界下的不同角色、不同路线、不同结果分别展开。
- 角色名字：写发生该次突破的角色。
- 简要介绍：写该角色当时的身份和处境，本次属于正常、异常还是极端突破，以及为什么值得作为该境界的代表案例；突破前修为、资源和瓶颈写入“突破前状态与瓶颈”。
- 案例依据与确定性：写该案例信息来自旁白、角色自述、功法或系统信息、实际突破表现、旁人判断、事后结果或上下文推断，必要时附章节、段落或情节锚点；尚未确认、相互矛盾和缺失的部分分别标注。
- 所习功法：写突破时修炼、依赖或影响突破的功法、法门、斗技、秘术；没有写“原文未说明”。
- 突破前状态与瓶颈：写原境界具体层次、积累程度、身体、神魂、心境、寿元、伤势、资源余量、此前失败次数、瓶颈表现、是否满足一般资格，以及与普通突破者相比的差异。
- 突破地点与环境：写突破发生的位置，以及灵气、天气、地形、阵法、安全程度、封闭或公开状态、资源环境和界面规则等静态条件；动态帮助、攻击和规则压制写入“突破中的外部互动与干扰”。
- 突破前准备：写丹药、材料、功法运转、法宝、阵法、护法、疗伤、闭关资源、心境调整等。
- 突破契机：写为什么在此时突破，如资源齐备、药力积累、战斗压迫、功法圆满、心境变化、血脉觉醒、机缘触发、被迫冲关等。
- 突破方式：写具体路线，如丹药辅助、强行冲关、自然积累、天劫突破、心境突破、神识突破、肉身突破、血脉觉醒、外力灌顶、夺舍重修、转世恢复、妖兽化形等。
- 核心转化机制：写本次突破中真正促成境界跃迁的内部变化，如能量压缩或质变、凝丹、开脉、神魂蜕变、法则领悟、血脉觉醒、肉身重塑、吸收外力或天地认可，以及这些变化之间的因果关系；没有机制说明时不得根据境界名称补写。
- 突破过程：按先后顺序写关键步骤、持续时间、痛苦反应、力量变化、瓶颈松动、核心结构凝聚或蜕变、失败回退和强行压制；“突破方式”写路线分类，“核心转化机制”写为何能够跃迁，本字段只写过程顺序。
- 突破中的外部互动与干扰：写护法、救援、灌顶、阵法支持、天地规则、天劫或界面压制、资源争夺、敌人攻击、偷袭、围杀、追踪、破阵、夺取机缘和强行打断，以及角色的应对和互动结果。
- 突破异象/外部反应：写雷劫、灵气波动、天地异象、法宝反应、血脉变化、妖气变化、旁人察觉、护法反应或势力震动等。
- 突破结果与完成度：写完整成功、部分完成、半步、伪境、成功但未稳固、暂时进入后跌落、失败回退、被打断、异变转入其他路线、死亡或继续卡住，并判断是否达到作品给出的真正完成标准。
- 突破代价/风险/可逆性：分别写实际已经支付的资源、寿元、伤势和其他代价，当时存在但未发生的风险，以及损伤能否恢复、境界是否可能跌落、失败后能否重试、恢复所需时间和资源、是否永久失去突破资格。
- 突破后稳固/效果/长期影响：写境界是否立即稳定，是否存在虚弱期或适应期，如何巩固和重新控制力量，以及修为、战力、寿元、神魂、体质、能力、资源、伤势、后遗症、身份、地位、行动范围、下一境界瓶颈和对宗门、敌人、地区或社会关系的长期影响。
