# 境界突破分析模板

## 适用范围

本模板用于整理小说中各个关键境界的突破方式，重点记录“谁以什么方式突破、过程有什么特点、突破后产生什么特殊效果或代价”。

本模板以关键境界为卡片。同一个境界下，不同角色可能有不同突破方式、不同准备、不同干扰、不同结果和不同代价；只要原文写出了有辨识度的突破方式或特殊突破效果，就应分别记录为“突破方式一 / 突破方式二 / 突破方式 N”。

只因为突破后基础属性增加、修为变强、寿元增加、境界名称变化，而没有特殊突破方式、特殊过程、特殊风险、特殊代价或特殊效果的，不单独收录。普通修炼升级、单纯战斗胜负、公开测验、成人仪式、门派考核、功法学习、资源交易和人物病情，不直接写成突破方式；只有它们直接参与突破过程或造成特殊结果时，才写入对应字段。

## 整理原则

1. 一境界一卡  
   每张卡对应一个关键境界突破关系，例如“炼气期 → 筑基期”“筑基期 → 结丹期”“斗之气十段 → 斗者”“筑元 → 开脉”“妖兽进阶 / 化形”。  
   同一境界下多个角色、多个路线、多个成败结果，都写在同一张卡里，不要拆成重复境界卡。

2. 先写境界总述  
   在所有境界突破卡片之前，先写“境界与小境界一般描述”。  
   该部分按小说原文整理各个境界、小境界、层数、段位、圆满、半步、伪境、化形等一般描述；某些小境界没有一般特殊描述时，写“文章未提及”。

3. 每卡先写一般突破方式  
   每张境界卡片在具体角色突破方式之前，必须先写“境界一般突破方式”。  
   该字段只写小说中对该境界突破的通用描述、常见路径、常用资源、常见风险和常见结果；如果文章没有一般说明，写“文章未提及”。

4. 一种方式一组字段  
   每出现一个有特点的突破方式，就写成“突破方式一 / 突破方式二 / 突破方式 N”。  
   每个突破方式必须写角色名字、简要介绍、所习功法、突破地点、突破环境、突破前准备、突破契机、突破方式、突破过程、突破中干扰/攻击、突破异象/外部反应、突破结果、突破代价/风险、突破后状态/效果。

5. 收录看特点  
   优先收录主角突破、重要配角突破、反派突破、妖兽进阶、失败突破、异常突破、强行突破、被打断突破、借外力突破、特殊功法路线、特殊资源路线、特殊体质路线。  
   如果某次突破只是普通属性提升，没有特殊方式或特殊效果，不收录。

6. 成败都可收录  
   突破成功、突破失败、半步突破、跌境重修、强行突破后根基不稳、被攻击中断、反噬重伤、以特殊代价换取突破，都可以收录。  
   失败案例只有突破方式新颖、代价特殊、影响后续修炼或揭示境界规则时才收录。

7. 作品术语优先  
   境界名称、功法名称、丹药材料、突破资源、异象名称和突破结果，必须使用作品原文自己的说法。  
   不得把其他体系词汇套入当前作品；不确定时写“原文未说明”。

8. 不展开功法卡  
   “所习功法”只写角色突破时修炼或依赖的功法、法门、斗技、秘术名称，以及它在突破中的作用。  
   功法效果、品阶、来源、传承和完整层数，放入 `功法术法神通模板.md`，不要在本模板展开。

9. 不虚构设定  
   突破地点、环境、准备、契机、过程、干扰、异象、结果、代价和后续状态，原文没有说明就写“原文未说明”。  
   不要为了补齐结构而自行创造丹药、护法、雷劫、心魔、攻击者、特殊效果或失败后果。

## 字段说明

- 境界卡片名称：写关键突破关系，如炼气期 → 筑基期、斗之气十段 → 斗者、筑元 → 开脉、妖兽某阶 → 更高阶 / 化形。
- 境界与小境界一般描述：写小说中各个境界和小境界的一般描述，包括大境界、小境界、层数、段位、圆满、半步、伪境、化形、妖兽阶位等；某些小境界没有一般特殊描述时，写“文章未提及”。
- 境界说明：简要说明这个境界在作品中的位置、前后层级和为什么属于关键突破。
- 境界一般突破方式：写该境界在小说中通常如何突破，包括一般条件、常见资源、常见环境、常见风险和常见结果；文章没有一般说明时写“文章未提及”。
- 收录标准：说明本卡只记录该境界下有特点的突破方式，普通属性增加或普通升级不收录。
- 突破方式一 / 二 / N：同一境界下的不同角色、不同路线、不同结果分别展开。
- 角色名字：写发生该次突破的角色。
- 简要介绍：写该角色当时身份、境界起点、处境和这次突破为什么值得记录。
- 所习功法：写突破时修炼、依赖或影响突破的功法、法门、斗技、秘术；没有写“原文未说明”。
- 突破地点：写洞府、闭关室、战场、秘境、灵脉、宗门禁地、荒野、法阵内、天劫场地等。
- 突破环境：写灵气、天气、阵法、护法、安全程度、敌情、资源环境、特殊地形或界面条件。
- 突破前准备：写丹药、材料、功法运转、法宝、阵法、护法、疗伤、闭关资源、心境调整等。
- 突破契机：写为什么在此时突破，如资源齐备、药力积累、战斗压迫、功法圆满、心境变化、血脉觉醒、机缘触发、被迫冲关等。
- 突破方式：写具体路线，如丹药辅助、强行冲关、自然积累、天劫突破、心境突破、神识突破、肉身突破、血脉觉醒、外力灌顶、夺舍重修、转世恢复、妖兽化形等。
- 突破过程：写关键步骤、持续时间、痛苦反应、灵力/斗气/法力变化、瓶颈松动、凝聚、开脉、承劫、失败回退或强行压制。
- 突破中干扰/攻击：写突破过程中是否被敌人攻击、偷袭、围杀、追踪、破阵、夺取机缘或强行打断；包括攻击者、攻击方式、护法/防护、应对方式和结果。
- 突破异象/外部反应：写雷劫、灵气波动、天地异象、法宝反应、血脉变化、妖气变化、旁人察觉、护法反应或势力震动等。
- 突破结果：写突破成功、突破失败、半步突破、境界稳固、境界虚浮、跌境、重伤、反噬、死亡或继续卡瓶颈。
- 突破代价/风险：写丹药损耗、材料耗尽、寿元消耗、伤势加重、心魔、根基不稳、身份暴露、敌人追杀、法宝损毁、后续瓶颈等。
- 突破后状态/效果：写突破后的修为、战力、特殊能力、根基状态、伤势、资源余量、身份变化、行动范围、后续修炼需求或特殊后遗症。

### 炼气期 → 筑基期

- 境界一般突破方式：一般需要炼气圆满或接近圆满，并借助筑基丹、闭关环境、灵气资源、护法或其他特殊资源冲击筑基；如果作品没有一般说明，写“文章未提及”。
- 收录标准：只记录筑基方式、突破资源、突破风险或筑基后效果有特点的案例；单纯“成功筑基、属性增强”不单独收录。

#### 突破方式一：丹药辅助筑基

- 所习功法：突破时修炼的主功法、心法或辅助法门；没有写“原文未说明”
- 突破地点：洞府、闭关室、宗门修炼地、灵脉或临时藏身处；按原文填写
- 突破环境：灵气浓度、阵法、防护、护法、安全程度和外部威胁按原文填写
- 突破前准备：筑基丹、灵石、闭关资源、疗伤准备、护法安排、心境调整等
- 突破契机：筑基丹到手、境界圆满、寿元压力、门派安排、追杀压力或机缘触发
- 突破方式：服用筑基丹或同类资源辅助冲关
- 突破过程：服丹、炼化药力、冲击瓶颈、稳定筑基境界；具体过程按原文填写
- 突破中干扰/攻击：写是否被偷袭、围杀、破阵、资源争夺或打断；没有写“原文未说明”
- 突破异象/外部反应：灵气波动、护法察觉、同门反应、势力评价等；没有写“原文未说明”
- 突破结果：筑基成功、筑基失败、半步筑基、重伤或继续卡瓶颈；按原文填写
- 突破代价/风险：筑基丹消耗、失败伤势、资源耗尽、根基不稳、身份暴露或后续瓶颈
- 突破后状态/效果：筑基后的法力质量、战力、寿元、身份地位、行动范围和后续修炼需求

#### 突破方式二：无丹药或资源不足强行筑基

- 角色名字：按原文填写
- 简要介绍：角色缺少常规筑基资源，却因寿元、追杀、门派压力或其他原因强行冲关
- 所习功法：原文未说明时写“原文未说明”
- 突破地点：临时闭关地、逃亡藏身处、普通洞府或其他地点；按原文填写
- 突破环境：资源不足、安全性不足、无人护法、敌人逼近或环境不稳定等
- 突破前准备：有限丹药、灵石、临时阵法、保命物、疗伤资源等；按原文填写
- 突破契机：资源不足但时间不等人，或被逼到不得不突破
- 突破方式：缺少关键资源时强行冲关，或用替代资源冒险突破
- 突破过程：强行运转功法、冲击瓶颈、承受反噬或中途失败；按原文填写
- 突破中干扰/攻击：写是否被追杀、偷袭、打断、破阵或夺取资源；没有写“原文未说明”
- 突破异象/外部反应：按原文填写；没有写“原文未说明”
- 突破结果：成功、失败、重伤、跌境、死亡或留下隐患
- 突破代价/风险：失败率更高、伤势更重、根基不稳、资源耗尽或后续瓶颈加重
- 突破后状态/效果：如果成功，写是否根基不稳、战力异常或后遗症明显；失败则写后续影响

### 筑基期 → 结丹期 / 更高境界

- 境界说明：中高阶大境界突破，通常涉及更高强度的修为积累、心境、神识、资源、环境和风险。
- 境界一般突破方式：一般需要当前境界圆满、资源齐备、功法或心境达到要求，并通过闭关、炼化特殊资源、承受天劫或其他方式突破；如果作品没有一般说明，写“文章未提及”。
- 收录标准：只记录结丹或更高境界突破方式有特点、资源路线特殊、失败代价明显或突破后效果特殊的案例。

#### 突破方式一：常规积累突破

- 角色名字：按原文填写
- 简要介绍：角色完成当前境界积累，以较常规方式冲击下一境界
- 所习功法：突破时主修功法或辅助法门；按原文填写
- 突破地点：闭关洞府、宗门修炼地、秘境或其他突破场所
- 突破环境：灵气、阵法、护法、安全程度、闭关条件和外部威胁按原文填写
- 突破前准备：丹药、灵石、天材地宝、功法圆满、心境准备、护法安排等
- 突破契机：修为圆满、资源齐备、寿元压力、师门安排或关键机缘
- 突破方式：常规积累后闭关冲关
- 突破过程：闭关、炼化、凝结、开关、稳定境界等过程按原文填写
- 突破中干扰/攻击：写是否被敌袭、战乱、破阵、资源争夺或中断；没有写“原文未说明”
- 突破异象/外部反应：天地异象、灵气变化、雷劫、护法反应、势力震动等
- 突破结果：突破成功、失败、半步突破、境界虚浮或重伤
- 突破代价/风险：资源消耗、反噬、心魔、根基不稳、寿元损耗或后续瓶颈
- 突破后状态/效果：寿元、战力、法力质量、神识、身份地位、可参与事件和地图层级变化

#### 突破方式二：特殊资源或外力突破

- 角色名字：按原文填写
- 简要介绍：角色依靠特殊丹药、天材地宝、秘境机缘、传承、灌顶或特殊体质冲击境界
- 所习功法：相关功法、传承法门或辅助秘术；按原文填写
- 突破地点：秘境、传承地、闭关地、灌顶场所、特殊灵地等
- 突破环境：特殊资源环境、传承限制、外力干预、护法或危险条件
- 突破前准备：特殊丹药、天材地宝、传承资格、外力支持、身体承受准备
- 突破契机：特殊资源到手、传承开启、机缘触发或外力介入
- 突破方式：借特殊资源、传承或外力冲破瓶颈
- 突破过程：炼化资源、接受灌顶、承受传承、冲击瓶颈或遭遇反噬
- 突破中干扰/攻击：写是否有人争夺资源、破坏传承、偷袭闭关或中断外力
- 突破异象/外部反应：特殊资源异象、传承反应、天地异动、旁人察觉等
- 突破结果：成功、失败、半步突破、获得额外能力、根基强化或留下后遗症
- 突破代价/风险：资源反噬、传承失败、外力中断、身体承受不住、身份暴露或后续限制
- 突破后状态/效果：是否比常规突破更快、更稳，是否获得额外能力、特殊根基或特殊后遗症

### 妖兽阶位 → 更高阶位 / 化形

- 境界说明：妖兽、灵兽、妖修或血脉生物的阶位提升、血脉进阶或化形突破。
- 境界一般突破方式：一般通过血脉成长、吞食灵药、吸收天地灵气、凝练妖丹、承受天劫、族群护持或外部压力进阶；如果作品没有一般说明，写“文章未提及”。
- 收录标准：只记录血脉、天劫、吞噬、灵药、族群护持、围猎干扰或化形效果有特点的进阶案例。
