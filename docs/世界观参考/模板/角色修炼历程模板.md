# 角色修炼历程模板

## 适用范围

用于整理作品中角色成长、突破、资源消耗与关键转折构成的修炼行动链。

## 前置声明

- 覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角或成功案例。
- 只写原文、资料来源或可靠依据能支撑的修炼行动链。缺失字段写“原文未说明”，不得补造收益、消耗、时间或突破结果。
- 案例只是最低写法示范，不是数量上限；有价值的长期链条、阶段链和关键片段都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充来源，成熟后转为 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

本文只整理角色修炼行动链。不写总览、证据段、节奏抽象表，也不单独拆“角色类型、起点状态、阶段目标、风险、结果”等字段。

每个案例按原文先后顺序写角色做了什么：去了哪里、花了多久、兑换/炼制/购买/学习/闭关了什么，参加了什么事件，获得什么奖励，消耗什么资源，得到什么材料/法宝/功法/关系/修为提升，是否突破境界。

主角修炼经历必须尽量完整，并按境界分段写；每个境界段都尽量写完整行动链，不只挑精彩片段。配角、NPC、反派、宗门天才、散修、妖修等角色用于补足不同成长路径；有完整链就写完整链，只有典型片段时才只写片段。

每个小事件优先写清“时间 / 获得 / 消耗 / 提升”。原文写了多少就写多少；没有明确时间、收益、消耗或提升时，可以只写事件本身。

## 案例

### 案例

#### 案例 1：境界段行动链

**行动链：**

1. 写角色起点境界、状态和阶段目标。
2. 按顺序写兑换、购买、炼制、拜师、任务、比试、闭关、游历、秘境、交易等行动。
3. 每步尽量写时间、地点、消耗资源、获得资源、功法/法宝变化和关系变化。
4. 遭遇事件时写消耗、战果、伤势、情报、追杀或后续任务。
5. 闭关或炼化后写修为变化、功法层数、法宝状态和是否突破。
6. 阶段结束时写该境界段结果，并说明如何衔接下一段行动链。

#### 案例 2：散修瓶颈与资源链

**行动链：**

1. 角色开始时卡在某境界瓶颈，缺少突破丹药或关键材料。
2. 前往坊市、任务点或秘境打探资源，写情报来源和消耗。
3. 接取任务、组队或独行搜集资源，写获得与消耗。
4. 因资源暴露、争夺或追杀产生冲突，写战斗、逃亡和损失。
5. 出售、交换或炼化所得资源，写丹药、洞府、灵石、功法或法宝变化。
6. 闭关或突破后，按原文写突破成功、失败、重伤恢复或继续卡瓶颈。

#### 案例 3：配角修炼行动链

**行动链：**

1. 先判断原文是否给出该配角的完整修炼行动链。
2. 有完整链时，按境界或阶段写当前状态、出门/闭关、资源获得与消耗、功法提升、突破或失败。
3. 只有关键片段时，写片段开始状态、机会来源、资源消耗、修炼过程、持续时间和结果。
4. 结果可包括修为提升、学会功法、伤势恢复、突破成功、突破失败、资源耗尽、心魔加重或引发后续事件。
5. 原文未说明的境界、时长、资源或结果，写“原文未说明”。

### 待定案例

按如下格式记录，暂不补齐正式案例字段：

1. 对象名称：关键摘要（来源）；新增摘要（来源）。
