# 角色修炼历程模板

## 适用范围

本模板用于整理主角完整修炼历程，并补充少量修炼经历足够详细、对世界观或成长路径有参考价值的重要配角修炼历程。

本模板以主角为主。主角只建一张“某某修炼历程”卡片，先用“角色总览”记录初始基础、长期目标、主修路线、整体覆盖范围和最终状态，再按作品原文实际写到的修炼进度和跨度分段整理，不按“炼气期、筑基期”这类大境界粗分。分段标题应尽量写成“炼气一层到炼气二层”“炼气五层到炼气八层”“斗之气三段到斗之气七段”“某功法第四层到第六层”这类具体进度段。

每个进度段都要重点写完整行动链：角色以何种身份和状态开始，本阶段追求什么、为何选择当前路线，去了哪里、花了多长时间，如何获取并消耗资源，怎样学习、闭关、战斗、疗伤或调整路线，身心和能力如何变化，受到哪些人物、势力和环境影响，是否突破、失败、衰退或恢复，最终以何种状态进入下一阶段。突破只是修炼历程的一种条件分支，不能替代正常积累、停滞、疗伤、转修和衰退过程。

其他角色只有在原文给出比较详细、连续、能体现修炼路径差异的修炼历程时，才单独成立“某某修炼历程”卡片。普通身份介绍、单次战斗、社交对话、旁观评价、外貌描写、组织结构和零散背景，不单独写入本模板。

## 整理原则

1. 主角一人一卡  
   主角卡片命名为“角色名修炼历程”，例如“韩立修炼历程”“萧炎修炼历程”。  
   卡片先填写一份角色总览，再按书中实际修炼进度和跨度设小标题，每个小标题下填写同一套阶段字段。不要把主角拆成多张零散阶段卡。
   角色标题下、首个进度段标题前的四个总览字段属于角色全局信息，每个角色只填写一次；此后的每个四级标题代表一个独立修炼进度段，并重复使用同一套阶段字段。

2. 进度跨度分段优先  
   主角修炼经历必须尽量完整，并按作品原文写到的境界层数、等级段位、功法层数、修为跨度或重大修炼推进排序。  
   分段不要只写“炼气期”“筑基期”这种大境界；应优先写清本段从哪里到哪里，如“炼气一层到炼气二层”“炼气五层到炼气八层”。每个进度段都要写清阶段起点、目标选择、行动链、获得与消耗、身心能力变化、外部互动、突破或非突破变化、风险恢复、阶段终点和后续影响。

3. 配角从严收录  
   配角、NPC、反派、宗门天才、散修、妖修、异族、失败者和被牵连者，只有修炼历程较详细时才单独成立卡片。  
   如果原文只给出一句境界、一次出场或零散背景，不建卡；如果只给出一段典型修炼片段，可以在该角色卡中只写对应阶段。

4. 行动链最重要  
   “行动链”是每个进度段的核心字段，必须按原文先后顺序逐步写清角色做了什么。  
   每个小事件优先写清时间、地点、目标或原因、行动、获得、消耗、变化和结果；行动链应同时覆盖获取资源、学习修炼、实战验证、受伤受阻、疗伤恢复、路线调整和阶段结果，原文没有说明的部分不要补。

5. 字段完整  
   角色总览必须包含：初始基础与先天约束、长期目标与主修路线、历程覆盖范围与总体完整度、最终状态与传承遗产。每个进度段必须包含：阶段身份与处境、阶段起点状态、阶段目标与路线选择、阶段完整度、信息依据与不确定性、行动链、获得/消耗/阶段净变化、身心与能力系统变化、外部互动与环境约束、突破详情、风险/失败/恢复、阶段终点状态、后续影响。
   禁止空字段。原文没有说明、检查范围内没有发现、材料尚未覆盖或该阶段客观上不涉及某一环节时，应分别写“原文未说明”“未检出”“未覆盖”或“不适用”。无明显变化时写“原文未说明明显变化”。

6. 术语必须贴合作品  
   境界名称、等级名称、段位名称、功法层数、资源名称、丹药名称、法宝名称和称谓写法，必须使用作品原文已经出现的说法。  
   不得把其他修炼体系的通用境界套到本书角色身上。

7. 去重与合并  
   同一人物同一进度段内的重复闭关、重复突破准备和相近修炼事件，优先合并到同一进度段的行动链中。  
   只有进入新层数、新等级、新段位、新功法阶段，或原文明确出现较大修炼跨度和重大修炼转折时，才另起进度段。“阶段起点状态”和“阶段终点状态”写完整快照，“身心与能力系统变化”只写两者之间的变化量；行动链写逐事件明细，“获得/消耗/阶段净变化”只做汇总。

8. 不写无效占位  
   不要为了凑年份、测验、阶段或数量，生成大量“原文未说明”的占位节点。  
   只有模板字段必须存在且原文缺失时，才写“原文未说明”；行动链里没有修炼价值的空节点应省略。本阶段没有突破时，“突破详情”只写“不涉及突破”，不展开全部突破子项。

9. 不虚构设定  
   不得为了补齐时间、数量、境界、功法层数、丹药名、材料名、法宝状态、灵石/贡献消耗、修炼动机、路线选择、外部互动、恢复过程、突破地点、突破过程、突破中干扰、突破异象、突破结果、最终状态或师承关系而自行虚构。
   应区分旁白直接说明、角色自述、功法或系统信息、实际修炼表现、他人评价、时间推算和上下文直接推断；推测内容不能写进确定行动链，只能放入“信息依据与不确定性”。

## 字段说明

### 角色总览字段

- 初始基础与先天约束：写角色正式修炼前或故事起点时已经存在的出身、种族、年龄、灵根、资质、体质、血脉、初始修为、寿元、伤病、缺陷、先天传承、诅咒、家庭和资源条件；后天获得的能力不得倒填为先天基础。
- 长期目标与主修路线：写角色求生、复仇、长生、救人或其他长期修炼动因，主修功法、修炼体系和核心能力路线，炼体、神识、剑道、血脉等辅助路线，以及曾经放弃、替换或被迫选择的路线；区分角色当时目标和后来结果。
- 历程覆盖范围与总体完整度：写已经检查的章节、时间和修炼阶段范围，是否从正式修炼开始记录，中间是否存在时间跳跃、缺卷或叙事留白，以及整张卡属于完整修炼史、主要阶段整理还是典型片段集合。
- 最终状态与传承遗产：写当前已知终点或作品结局时的修为、身体、神魂、寿元、伤势、战力、核心功法和资源，以及飞升、死亡、失踪、退隐、废功、转世、收徒、遗留传承、体系创建、未完成目标和开放结局；连载作品应写明只是当前节点。

### 进度段字段

- 阶段身份与处境：写该进度段角色的身份、所属势力、社会地位、活动地域，以及被追杀、受庇护、囚禁、流亡、闭关等处境；修为、功法、资源和伤势写入阶段起点状态。
- 阶段起点状态：写该进度段开始时的修为、功法与术法层次、体质、血脉、神魂、心境、寿元、伤势、异常状态、法宝、资源、债务、已知瓶颈和当前需求，形成阶段开始时的完整快照。
- 阶段目标与路线选择：写角色本阶段主动追求或被迫完成的修炼目标，选择的功法、资源、师承、闭关、历练、战斗或疗伤路线，放弃的替代方案及选择原因；区分角色计划和实际结果。
- 阶段完整度：写完整阶段、典型片段、残缺链条、只见准备、只见结果或中间存在时间跳跃；这里只判断材料覆盖形态，不代替具体信息的确定性判断。
- 信息依据与不确定性：分别标注信息来自旁白直接说明、角色自述、功法或系统信息、实际修炼表现、他人评价、时间推算、上下文直接推断或尚未说明，必要时附章节、段落或情节锚点；同时记录矛盾记载、阶段边界不清和缺失细节。
- 行动链：最重要字段。按先后顺序逐条写时间、地点、目标或原因、行动、获得、消耗、身心或能力变化和结果；覆盖获取信息与资源、学习修炼、闭关积累、实战验证、受伤受阻、疗伤恢复、路线调整和阶段结果，缺失部分只写已说明内容。
- 获得/消耗/阶段净变化：汇总该进度段获得、消耗、剩余、损毁、遗失、暂时占用后归还的材料、丹药、灵石、贡献、功法、法宝、情报和时间，以及形成或偿还的人情、债务和承诺；行动链写逐事件明细，本字段只做分类汇总和净结果。
- 身心与能力系统变化：只写阶段起点到终点之间的变化量，包括修为、境界、战力、功法、术法及熟练度，身体、体质、血脉、神识、魂魄、意志、心境、寿元、伤势、毒素、诅咒、异常状态、法宝、契约对象、知识和控制能力的提升、停滞、衰退、损毁或恢复。
- 外部互动与环境约束：写师父、同伴、宗门、家族、敌人、契约对象、资源提供者和旁观者如何帮助、控制、误导或阻碍角色，以及地域灵气、秘境规则、战争、法律、宗门制度、天道规则等环境因素如何改变修炼路线和结果。
- 突破详情：本阶段没有突破时只写“不涉及突破”，不展开子项；发生突破时按以下子项记录：
  - 突破地点与环境：写突破地点，以及周围灵气、阵法、天气、地势、安全程度、封闭或公开状态等静态条件。
  - 突破前准备：写丹药、功法、材料、法宝、阵法、护法、疗伤、闭关资源和心境调整等准备。
  - 突破契机：写为什么在此时突破，如药力积累、战斗压迫、功法圆满、资源齐备、心境变化、机缘触发或被迫冲关。
  - 突破方式：写闭关冲关、服丹炼化、功法运转、吸收灵气、吞噬异火、血脉觉醒、战中突破、借阵突破或传承灌顶等方式。
  - 突破过程：写关键步骤、持续时间、痛苦反应、力量运转、瓶颈松动、失败回退或强行压制等内部过程。
  - 突破中的外部互动与干扰：写护法、救助、规则压制、敌人攻击、偷袭、围杀、追踪、破阵、夺取机缘或强行打断，以及角色的应对和互动结果。
  - 突破异象及外部反应：写灵气波动、雷劫、天地异象、法宝反应、他人察觉、围观者判断和势力反应等外在表现。
  - 突破结果与即时状态：写突破成功、失败、半步突破或继续卡住，以及突破结束当刻的境界稳固程度、战力、伤势、反噬、资源余量和后续需求；整个进度段结束时的完整状态另写入“阶段终点状态”。
  - 突破代价与风险：只写本次突破直接造成的丹药和材料损耗、伤势、寿元消耗、心魔、根基不稳、身份暴露、追杀或法宝损毁；阶段长期风险和恢复过程写入“风险/失败/恢复”。
- 风险/失败/恢复：分别写正常瓶颈和暂时停滞，资源不足、路线错误、功法冲突、突破失败、走火入魔、反噬、境界跌落、根基受损、能力封印、废功、夺舍、失控或死亡等异常及极端结果，以及疗伤、重修、转修、封印、外力救治、重新筑基等恢复方式和完全恢复、留下后遗症、暂时压制或不可逆等恢复结果。
- 阶段终点状态：写整个进度段结束时的修为、功法与术法层次、体质、血脉、神魂、心境、寿元、战力、伤势、异常状态、法宝、资源、债务、身份和处境，形成阶段终点的完整快照；不要把突破结束当刻的状态自动等同于阶段终点。
- 后续影响：写该进度段如何引出下一段修炼、任务、目标或路线变化，以及对关系、势力、声誉、敌对状态、资源需求和最终命运的后续影响。
