# 角色修炼历程模板

## 适用范围

用于整理作品中角色成长、突破、资源消耗与关键转折构成的修炼行动链。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

本文只整理小说中出现过，或能由小说内容明确支撑的角色修炼行动链，不写总览，不写证据段，不写节奏抽象表，不单独拆“角色类型、起点状态、阶段目标、风险、结果”等字段。

每个案例只写行动链。行动链要按原文先后顺序逐步写清角色做了什么：去了哪里、花了多长时间、兑换了什么、炼制了什么、闭关多久、学会了什么、参加了什么事件、获得什么名次或奖励、消耗了什么资源、得到什么材料/法宝/功法/关系/修为提升、是否突破境界。

主角的行动链必须尽量完整，并按境界分段写；例如炼气期一条、筑基期一条、结丹期一条、元婴期一条。每个境界段都要尽量写出该境界内的完整行动链，而不是只挑精彩片段。配角、NPC、反派、宗门天才、散修、妖修等角色的行动链作为补充样本，用于补足不同成长路径。

行动链里的每个小事件都尽量写清“时间 / 获得 / 消耗 / 提升”，并尽可能具体到材料名称、数量、时长、修为变化、境界变化、功法名称、功法层数、法宝状态、丹药名称、灵石或贡献消耗等。原文写了多少就写多少；没有写的不要补。没有明确获得、消耗、提升或时间时，可以只写事件本身；不得为了补齐收益、消耗、时间或突破结果而自行虚构。

主角必须写完整修炼经历，并按境界分段。配角、NPC、反派、宗门天才、散修、妖修等角色如果原文有完整修炼行动链，也应写完整链；如果原文没有完整长期修炼链，只出现精彩、典型或有参考价值的一段经历，才只写该精彩片段。

## 案例

### 案例

#### 案例 1：某宗门弟子从筑基初期到筑基中期

**行动链：**

1. 角色开始时为筑基初期。
2. 去宗门库房兑换炼器材料，消耗宗门贡献，获得炼制法宝所需的主材和辅材。
3. 请炼器师或自行炼制法宝，消耗材料和灵石，获得法宝。
4. 进入普通闭关室闭关修炼三个月，消耗丹药和灵石，学会某功法第三层。
5. 宗门大比开始，角色参加筑基弟子比试。
6. 角色在宗门大比中获得第几名，获得宗门奖励，包括丹药、灵石、贡献、法器或进入高阶修炼场所的资格。
7. 角色与师兄一起拜访某宗门，途中或访问期间参与切磋、交易、护送或外交事件。
8. 返回路上遇到某事件，例如妖兽袭击、散修截杀、秘境入口、同门求援或资源线索；消耗符箓、丹药或法力，获得材料、情报、关系提升或战斗经验。
9. 回到宗门后，使用奖励进入高等级闭关室修炼数月，消耗丹药、灵石或贡献。
10. 修炼结束后修为提升，突破到筑基中期。
11. 去某坊市参加拍卖，消耗灵石，拍得某材料、丹药、功法残篇或法宝。
12. 将拍卖所得用于后续炼器、炼丹、突破准备或任务交换，形成下一段修炼行动链。

#### 案例 2：散修靠坊市与秘境资源冲击瓶颈

**行动链：**

1. 角色开始时卡在某境界瓶颈，缺少突破丹药或关键材料。
2. 前往坊市打探材料价格和秘境消息，消耗灵石购买情报。
3. 接取护送、猎妖或采药任务，获得进入危险区域的理由。
4. 在任务途中遭遇妖兽或修士冲突，消耗符箓、丹药或法力，获得妖兽材料、战利品或新的秘境线索。
5. 进入秘境或危险地点搜集资源，获得突破材料、法宝碎片、功法线索或灵药。
6. 因资源暴露被追杀或截杀，消耗逃遁符、疗伤丹或法宝耐久，成功逃脱或击败敌人。
7. 回到坊市出售部分材料，获得灵石。
8. 用灵石购买丹药、租赁洞府或兑换闭关资源。
9. 闭关修炼若干月，消耗丹药和灵石。
10. 突破成功、突破失败、重伤恢复或继续卡瓶颈的结果按原文填写。

#### 案例 3：配角修炼行动链

**行动链：**

1. 先判断原文是否给出该配角的完整修炼行动链。
2. 如果原文给出完整链，按境界或阶段顺序完整写出：当前境界、每次出门或闭关、每次资源获得与消耗、每次功法提升、每次突破或失败。
3. 如果原文没有完整链，只出现一段关键修炼片段，才只写该片段。
4. 片段开始时写清角色当前境界或状态；如果原文未说明，写“原文未说明”。
5. 角色因某个原因获得机会，例如宗门奖励、师傅赠药、秘境所得、拍卖所得、杀敌战利品或亲友相助。
6. 角色消耗该资源进行闭关、炼化、疗伤、转修、突破或学习功法。
7. 写清闭关或修炼持续时间；如果原文未说明，写“原文未说明”。
8. 写清结果：修为提升、学会功法、伤势恢复、突破成功、突破失败、资源耗尽、心魔加重或引发后续事件。
