# 角色修炼历程模板

## 适用范围

本模板用于整理主角完整修炼历程，并补充少量修炼经历足够详细、对世界观或成长路径有参考价值的重要配角修炼历程。

本模板以主角为主。主角只建一张“某某修炼历程”卡片，卡片下面按作品原文实际写到的修炼进度和跨度分段整理，不按“炼气期、筑基期”这类大境界粗分。分段标题应尽量写成“炼气一层到炼气二层”“炼气五层到炼气八层”“斗之气三段到斗之气七段”“某功法第四层到第六层”这类具体进度段。每个进度段都要重点写行动链：角色去了哪里，花了多长时间，兑换、购买、炼制、服用、学习、闭关或参战了什么，获得什么资源，消耗什么资源，功法、法宝、伤势、关系和修为发生什么变化，是否突破或失败。

其他角色只有在原文给出比较详细、连续、能体现修炼路径差异的修炼历程时，才单独成立“某某修炼历程”卡片。普通身份介绍、单次战斗、社交对话、旁观评价、外貌描写、组织结构和零散背景，不单独写入本模板。

## 整理原则

1. 主角一人一卡  
   主角卡片命名为“角色名修炼历程”，例如“韩立修炼历程”“萧炎修炼历程”。  
   卡片下面按书中实际修炼进度和跨度设小标题，每个小标题下填写同一套字段。不要把主角拆成多张零散阶段卡。

2. 进度跨度分段优先  
   主角修炼经历必须尽量完整，并按作品原文写到的境界层数、等级段位、功法层数、修为跨度或重大修炼推进排序。  
   分段不要只写“炼气期”“筑基期”这种大境界；应优先写清本段从哪里到哪里，如“炼气一层到炼气二层”“炼气五层到炼气八层”。每个进度段都要写清阶段起点、阶段终点、行动链、获得与消耗、突破细节、风险失败和后续影响。

3. 配角从严收录  
   配角、NPC、反派、宗门天才、散修、妖修、异族、失败者和被牵连者，只有修炼历程较详细时才单独成立卡片。  
   如果原文只给出一句境界、一次出场或零散背景，不建卡；如果只给出一段典型修炼片段，可以在该角色卡中只写对应阶段。

4. 行动链最重要  
   “行动链”是每个进度段的核心字段，必须按原文先后顺序逐步写清角色做了什么。  
   每个小事件优先写清时间、地点、行动、获得、消耗、提升和结果；原文没有说明的部分不要补。

5. 字段完整  
   每个进度段必须包含：角色身份、阶段起点、阶段终点、阶段完整度、行动链、获得与消耗、修为/功法/法宝变化、突破详情、风险与失败、后续影响、不确定项。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

6. 术语必须贴合作品  
   境界名称、等级名称、段位名称、功法层数、资源名称、丹药名称、法宝名称和称谓写法，必须使用作品原文已经出现的说法。  
   不得把其他修炼体系的通用境界套到本书角色身上。

7. 去重与合并  
   同一人物同一进度段内的重复闭关、重复突破准备和相近修炼事件，优先合并到同一进度段的行动链中。  
   只有进入新层数、新等级、新段位、新功法阶段，或原文明确出现较大修炼跨度和重大修炼转折时，才另起进度段。

8. 不写无效占位  
   不要为了凑年份、测验、阶段或数量，生成大量“原文未说明”的占位节点。  
   只有模板字段必须存在且原文缺失时，才写“原文未说明”；行动链里没有修炼价值的空节点应省略。

9. 不虚构设定  
   不得为了补齐时间、数量、境界、功法层数、丹药名、材料名、法宝状态、灵石/贡献消耗、突破地点、突破过程、突破中干扰/攻击、突破异象、突破结果或师承关系而自行虚构。  
   推测内容不能写进确定行动链，只能放入“不确定项”。

## 字段说明

- 角色身份：写该进度段角色身份，如凡人、散修、宗门弟子、长老、家族子弟、反派、妖修、异族、势力成员等。
- 阶段起点：写该进度段开始时的修为、功法层数、伤势、资源、身份和处境。
- 阶段终点：写该进度段结束时的修为、功法层数、突破结果、资源变化、伤势变化和处境变化。
- 阶段完整度：写完整阶段、典型片段、残缺链条或只见结果；不要把残缺片段伪装成完整阶段。
- 行动链：最重要字段。按先后顺序逐条写时间、地点、行动、获得、消耗、提升和结果；缺失部分只写已说明内容。
- 获得与消耗：汇总该进度段获得的材料、丹药、灵石、贡献、功法、法宝、师承、关系和情报，以及消耗的资源、时间、伤势、代价和人情。
- 修为/功法/法宝变化：写修为提升、境界突破、功法层数变化、法宝炼成/损毁/强化、丹药炼化、伤势恢复或失败后果。
- 突破详情：把突破相关内容集中到一个字段下展开；没有突破时写“不涉及突破”。展开项包括：
  - 突破地点：写突破发生在哪里，如洞府、闭关室、秘境、战场、灵脉、宗门禁地、荒野、法阵内等。
  - 突破环境：写突破时周围灵气、阵法、天气、地势、安全程度、同伴护法、封闭/公开状态等。
  - 突破前准备：写突破前准备了哪些丹药、功法、材料、法宝、阵法、护法、疗伤、闭关资源或心境调整。
  - 突破契机：写为什么在此时突破，如药力积累、战斗压迫、功法圆满、资源齐备、心境变化、机缘触发或被迫冲关。
  - 突破方式：写闭关冲关、服丹炼化、功法运转、吸收灵气、吞噬异火、血脉觉醒、战中突破、借阵突破、传承灌顶等。
  - 突破过程：写突破过程中的关键步骤、持续时间、痛苦反应、灵力运转、瓶颈松动、失败回退或强行压制。
  - 突破中干扰/攻击：写突破过程中是否被敌人攻击、偷袭、围杀、追踪、破阵、夺取机缘或强行打断；包括攻击者、攻击方式、护法/防护、应对方式和结果。
  - 突破异象/外部反应：写灵气波动、雷劫、天地异象、法宝反应、他人察觉、护法反应等。
  - 突破结果：写突破成功、突破失败、半步突破、境界稳固、境界虚浮、重伤、反噬或继续卡瓶颈。
  - 突破代价/风险：写丹药损耗、材料耗尽、伤势加重、寿元消耗、心魔、根基不稳、身份暴露、敌人追杀、法宝损毁等。
  - 突破后状态：写突破后的修为、战力、功法层数、法宝状态、伤势、资源余量、身份变化和后续需求。
- 风险与失败：写卡瓶颈、走火入魔、资源暴露、追杀、失败重修、药力反噬、师承控制、寿元压力等；没有写“原文未说明”。
- 后续影响：写该进度段如何引出下一段修炼、任务、关系变化、势力变化、敌对关系或新的资源需求。
- 不确定项：写推测但未确认、原文未说明、阶段边界不清、突破细节缺失等内容。

## 重要配角修炼历程卡片

### 某重要配角修炼历程

#### 关键修炼进度段

- 角色身份：重要配角、反派、宗门天才、散修、妖修或异族；按原文填写
- 阶段起点：该阶段开始时的境界、状态、资源和处境；不明时写“原文未说明”
- 阶段终点：该阶段结束时的修为、伤势、资源、关系或处境变化；不明时写“原文未说明”
- 阶段完整度：完整阶段、典型片段、残缺链条或只见结果
- 行动链：
  - 先判断原文是否给出该配角较详细的修炼历程。
  - 如果原文给出完整链，按修炼进度和跨度顺序完整写出每次出门、闭关、资源获得与消耗、功法提升、突破或失败。
  - 如果原文只出现一段关键修炼片段，只写该片段，不强行补成完整修炼史。
  - 片段开始时写清角色当前境界或状态；如果原文未说明，写“原文未说明”。
  - 角色因宗门奖励、师傅赠药、秘境所得、拍卖所得、杀敌战利品或亲友相助获得修炼机会。
  - 角色消耗资源进行闭关、炼化、疗伤、转修、突破或学习功法。
  - 写清修为提升、学会功法、伤势恢复、突破成功、突破失败、资源耗尽、心魔加重或引发后续事件等变化。
- 获得与消耗：按原文填写该配角获得的资源、功法、丹药、法宝、师承和关系，以及消耗的时间、资源、伤势和代价
- 修为/功法/法宝变化：按原文填写提升、停滞、失败、转修、恢复、损毁或强化
- 突破详情：
  - 突破地点：按原文填写；没有突破时写“不涉及突破”
  - 突破环境：按原文填写周围灵气、阵法、护法、安全程度等；无说明写“原文未说明”
  - 突破前准备：按原文填写丹药、材料、功法、法宝、阵法、护法和闭关资源
  - 突破契机：按原文填写药力积累、战斗压迫、功法圆满、资源齐备、心境变化或机缘触发
  - 突破方式：按原文填写闭关冲关、服丹炼化、吸收灵气、战中突破、借阵突破等
  - 突破过程：按原文填写持续时间、痛苦反应、灵力运转、瓶颈变化和失败回退
  - 突破中干扰/攻击：按原文填写是否被敌人攻击、偷袭、围杀、追踪、破阵、夺取机缘或强行打断，以及护法、防护、反击、撤离和突破结果
  - 突破异象/外部反应：按原文填写灵气波动、雷劫、他人察觉、护法反应、敌人干扰等
  - 突破结果：突破成功、突破失败、半步突破、境界稳固、境界虚浮、重伤或继续卡瓶颈
  - 突破代价/风险：写资源耗尽、伤势加重、根基不稳、心魔、身份暴露、敌人追杀或法宝损毁
  - 突破后状态：写突破后的修为、战力、资源余量、伤势、法宝状态和后续需求
- 风险与失败：写资源不足、路线错误、强敌干扰、心魔、反噬、师承控制或寿元压力；没有写“原文未说明”
- 后续影响：写该阶段如何影响角色后续修炼、地位、敌友关系、任务或命运
- 不确定项：凡是推测身份、推测功法、推测资源来源或推测突破结果的内容，都写在这里，不写进确定行动链
