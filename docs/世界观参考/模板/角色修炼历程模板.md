# 角色修炼历程模板

## 适用范围

本模板用于整理主角完整修炼历程，并补充少量修炼经历足够详细、对世界观或成长路径有参考价值的重要配角修炼历程。

本模板以主角为主。主角只建一张“某某修炼历程”卡片，先用“角色总览”记录初始基础、长期目标、主修路线、整体覆盖范围和最终状态，再按作品原文实际写到的修炼进度和跨度分段整理，不按“炼气期、筑基期”这类大境界粗分。分段标题应尽量写成“炼气一层到炼气二层”“炼气五层到炼气八层”“斗之气三段到斗之气七段”“某功法第四层到第六层”这类具体进度段。

每个进度段围绕修炼因果链整理：起点状态 -> 目标与路线 -> 资源与行动 -> 能力变化 -> 受阻、突破或恢复 -> 终点状态。只保留直接影响修炼推进的必要事实，不逐章罗列地点、时间、人物行动或战斗过程。突破只是修炼历程的一种条件分支，不能替代正常积累、停滞、疗伤、转修和衰退过程。

其他角色只有在原文给出比较详细、连续、能体现修炼路径差异的修炼历程时，才单独成立“某某修炼历程”卡片。普通身份介绍、单次战斗、社交对话、旁观评价、外貌描写、组织结构和零散背景，不单独写入本模板。

## 整理原则

1. 一人一卡：每个角色只建立一张修炼历程卡，先写角色总览，再按实际修炼推进建立进度段；不按抽取批次、章节窗口或单次事件拆卡。
2. 进度分段：按故事时间、境界或等级变化、功法阶段、长期停滞、重大突破、路线转折和恢复过程分段；每段写清起点、目标、关键修炼变化和终点，不用单一大境界或固定章节数代替进度。
3. 配角从严：只有原文提供连续且足以体现修炼路径的材料时才单独建卡；一句境界、一次战斗、普通身份介绍或零散背景不单独成卡。配角和势力内容只有直接改变该角色修炼目标、资源、能力、风险或路线时才写入。
4. 字段对应与事件边界：每个字段只写本字段相关内容，不重复、不跨字段补充；不引入无关的具体事件、剧情过程或人物信息。行动链只保留影响修炼推进的关键因果节点，不逐章复述，也不设置单独的使用记录或事件记录字段。
5. 快照与变化分开：阶段起点状态和阶段终点状态写完整快照；身心与能力系统变化只写两者之间的变化量；获得/消耗/阶段净变化只做分类汇总；突破只是阶段变化的一种分支，不能替代积累、停滞、转修、疗伤和恢复。
6. 字段完整与原文优先：角色总览和进度段必须保留模板列出的全部字段。术语、境界、功法、资源和称谓按原文填写；原文没有说明、未检出、未覆盖或客观不适用时，分别写“原文未说明”“未检出”“未覆盖”或“不适用”，不得用常识、时间推算或个案表现补齐。
7. 生命周期与简洁输出：按目标与路线、资源与修炼、能力变化、外部约束、突破或非突破结果、风险恢复和后续影响整理；区分自有能力、借用能力、契约对象和外部援助。只保留稳定规则和必要证据，不堆叠批次日志、逐次修炼经过或无关群体剧情。

## 字段说明

### 角色总览字段

- 初始基础与先天约束：写角色正式修炼前或故事起点时已经存在的出身、种族、年龄、灵根、资质、体质、血脉、初始修为、寿元、伤病、缺陷、先天传承、诅咒、家庭和资源条件；后天获得的能力不得倒填为先天基础。
- 长期目标与主修路线：写角色求生、复仇、长生、救人或其他长期修炼动因，主修功法、修炼体系和核心能力路线，炼体、神识、剑道、血脉等辅助路线，以及曾经放弃、替换或被迫选择的路线；区分角色当时目标和后来结果。
- 历程覆盖范围与总体完整度：写已检查的章节、时间和修炼阶段范围，是否存在时间跳跃、缺卷或叙事留白，以及整张卡属于完整修炼史、主要阶段整理还是典型片段集合；不在本字段堆叠批次日志或事件清单。
- 最终状态与传承遗产：写当前已知终点或作品结局时的修为、身体、神魂、寿元、伤势、核心功法、资源和传承结果；连载作品应明确这是当前节点，不展开此前阶段的剧情过程。

### 进度段字段

- 阶段身份与处境：写该进度段角色的身份、所属势力、社会地位、活动地域，以及被追杀、受庇护、囚禁、流亡、闭关等处境；修为、功法、资源和伤势写入阶段起点状态。
- 阶段起点状态：写该进度段开始时的修为、功法与术法层次、体质、血脉、神魂、心境、寿元、伤势、异常状态、法宝、资源、债务、已知瓶颈和当前需求，形成阶段开始时的完整快照。
- 阶段目标与路线选择：写角色本阶段主动追求或被迫完成的修炼目标，选择的功法、资源、师承、闭关、历练、战斗或疗伤路线，放弃的替代方案及选择原因；区分角色计划和实际结果。
- 阶段完整度：写完整阶段、典型片段、残缺链条、只见准备、只见结果或中间存在时间跳跃；这里只判断材料覆盖形态，不代替具体信息的确定性判断。
- 信息依据与不确定性：分别标注信息来自旁白直接说明、角色自述、功法或系统信息、实际修炼表现、他人评价、时间推算、上下文直接推断或尚未说明，必要时附章节、段落或原文位置；同时记录矛盾记载、阶段边界不清和缺失细节，不用整段剧情代替证据说明。
- 行动链：只按先后顺序保留影响修炼推进的关键因果节点，采用“目标或瓶颈 -> 路线与行动 -> 资源得失 -> 修炼或验证 -> 受阻与恢复 -> 阶段结果”的简要结构；不逐章罗列时间、地点、人物对话或无关战斗，缺失部分不补写。
- 获得/消耗/阶段净变化：只汇总该进度段新增、消耗、剩余、损毁、遗失、归还或状态转移的资源、功法、法宝、情报、时间、人情和债务；不重复行动链，不展开具体获取或使用经过。
- 身心与能力系统变化：只写阶段起点到终点之间的变化量，包括修为、境界、战力、功法、术法及熟练度，身体、体质、血脉、神识、魂魄、意志、心境、寿元、伤势、毒素、诅咒、异常状态、法宝、契约对象、知识和控制能力的提升、停滞、衰退、损毁或恢复。
- 外部互动与环境约束：只写直接改变角色修炼目标、资源、能力、风险或路线的师父、同伴、宗门、家族、敌人、契约对象和环境因素；无关的配角剧情、势力排名和群体行动不写入本字段。
- 突破详情：本阶段没有突破时只写“不涉及突破”，不展开子项；发生突破时按以下子项记录：
  - 突破地点与环境：写突破地点，以及周围灵气、阵法、天气、地势、安全程度、封闭或公开状态等静态条件。
  - 突破前准备：写丹药、功法、材料、法宝、阵法、护法、疗伤、闭关资源和心境调整等准备。
  - 突破契机：写为什么在此时突破，如药力积累、战斗压迫、功法圆满、资源齐备、心境变化、机缘触发或被迫冲关。
  - 突破方式：写闭关冲关、服丹炼化、功法运转、吸收灵气、吞噬异火、血脉觉醒、战中突破、借阵突破或传承灌顶等方式。
  - 突破过程：只写有原文依据且能说明突破成败或代价的关键过程，不逐步复述剧情。
  - 突破中的外部互动与干扰：只写直接改变突破成败、风险或结果的外部干扰、救助和应对，不罗列无关战斗过程。
  - 突破异象及外部反应：写灵气波动、雷劫、天地异象、法宝反应、他人察觉、围观者判断和势力反应等外在表现。
  - 突破结果与即时状态：写突破成功、失败、半步突破或继续卡住，以及突破结束当刻的境界稳固程度、战力、伤势、反噬、资源余量和后续需求；整个进度段结束时的完整状态另写入“阶段终点状态”。
  - 突破代价与风险：只写本次突破直接造成的丹药和材料损耗、伤势、寿元消耗、心魔、根基不稳、身份暴露、追杀或法宝损毁；阶段长期风险和恢复过程写入“风险/失败/恢复”。
- 风险/失败/恢复：分别写正常瓶颈和暂时停滞，资源不足、路线错误、功法冲突、突破失败、走火入魔、反噬、境界跌落、根基受损、能力封印、废功、夺舍、失控或死亡等异常及极端结果，以及疗伤、重修、转修、封印、外力救治、重新筑基等恢复方式和完全恢复、留下后遗症、暂时压制或不可逆等恢复结果。
- 阶段终点状态：写整个进度段结束时的修为、功法与术法层次、体质、血脉、神魂、心境、寿元、战力、伤势、异常状态、法宝、资源、债务、身份和处境，形成阶段终点的完整快照；不要把突破结束当刻的状态自动等同于阶段终点。
- 后续影响：只写该进度段对下一段修炼目标、路线、资源、能力、风险或关键关系的直接影响；不扩展无关势力剧情或逐次事件。
