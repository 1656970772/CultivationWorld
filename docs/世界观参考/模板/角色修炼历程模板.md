# 角色修炼历程模板

# 规范

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的角色修炼行动链，不写总览，不写节奏抽象表，不单独拆“角色类型、起点状态、阶段目标、风险、结果”等字段。

每个案例只写行动链。行动链要按原文先后顺序逐步写清角色做了什么：去了哪里、花了多长时间、兑换了什么、炼制了什么、闭关多久、学会了什么、参加了什么事件、获得什么名次或奖励、消耗了什么资源、得到什么材料/法宝/功法/关系/修为提升、是否突破境界。

主角的行动链必须尽量完整，并按境界分段写；例如炼气期一条、筑基期一条、结丹期一条、元婴期一条。每个境界段都要尽量写出该境界内的完整行动链，而不是只挑精彩片段。配角、NPC、反派、宗门天才、散修、妖修等角色的行动链作为补充样本，用于补足不同成长路径。

行动链里的每个小事件都尽量写清“时间 / 获得 / 消耗 / 提升”，并尽可能具体到材料名称、数量、时长、修为变化、境界变化、功法名称、功法层数、法宝状态、丹药名称、灵石或贡献消耗等。原文写了多少就写多少；没有写的不要补。没有明确获得、消耗、提升或时间时，可以只写事件本身；不得为了补齐收益、消耗、时间或突破结果而自行虚构。

主角必须写完整修炼经历，并按境界分段。配角、NPC、反派、宗门天才、散修、妖修等角色如果原文有完整修炼行动链，也应写完整链；如果原文没有完整长期修炼链，只出现精彩、典型或有参考价值的一段经历，才只写该精彩片段。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 整理对象：只整理角色修炼行动链；不写总览、节奏抽象表，也不单独拆“角色类型、起点状态、阶段目标、风险、结果”等字段。
- 行动顺序：按原文先后写角色去了哪里、花了多久、兑换/炼制/购买/学习/闭关了什么、参加了什么事件、获得什么奖励、消耗什么资源、得到什么材料/法宝/功法/关系/修为提升、是否突破境界。
- 主角分段：主角修炼经历必须尽量完整，并按境界分段写；每个境界段都尽量写完整行动链，不只挑精彩片段。
- 配角样本：配角、NPC、反派、宗门天才、散修、妖修等角色用于补足不同成长路径；有完整链就写完整链，只有典型片段时才只写片段。
- 事件细节：每个小事件优先写清“时间 / 获得 / 消耗 / 提升”，尽可能具体到材料名称、数量、时长、修为变化、境界变化、功法名称、功法层数、法宝状态、丹药名称、灵石或贡献消耗等。
- 未说明处理：原文写了多少就写多少；没有明确时间、收益、消耗或提升时，可以只写事件本身；原文未说明的信息统一写“原文未说明”，不得自行虚构。

## 案例

### 案例

```md
# 《作品名》角色修炼历程

## 角色修炼历程卡片

### 某宗门弟子从筑基初期到筑基中期

- 整理对象：某宗门弟子的筑基期修炼行动链。
- 行动链：
  - 角色开始时为筑基初期。
  - 去宗门库房兑换炼器材料，消耗宗门贡献，获得炼制法宝所需的主材和辅材。
  - 请炼器师或自行炼制法宝，消耗材料和灵石，获得法宝。
  - 进入普通闭关室闭关修炼三个月，消耗丹药和灵石，学会某功法第三层。
  - 宗门大比开始，角色参加筑基弟子比试。
  - 角色在宗门大比中获得第几名，获得宗门奖励，包括丹药、灵石、贡献、法器或进入高阶修炼场所的资格。
  - 角色与师兄一起拜访某宗门，途中或访问期间参与切磋、交易、护送或外交事件。
  - 返回路上遇到某事件，例如妖兽袭击、散修截杀、秘境入口、同门求援或资源线索；消耗符箓、丹药或法力，获得材料、情报、关系提升或战斗经验。
  - 回到宗门后，使用奖励进入高等级闭关室修炼数月，消耗丹药、灵石或贡献。
  - 修炼结束后修为提升，突破到筑基中期。
  - 去某坊市参加拍卖，消耗灵石，拍得某材料、丹药、功法残篇或法宝。
  - 将拍卖所得用于后续炼器、炼丹、突破准备或任务交换，形成下一段修炼行动链。

### 散修靠坊市与秘境资源冲击瓶颈

- 整理对象：散修冲击某境界瓶颈的修炼行动链。
- 行动链：
  - 角色开始时卡在某境界瓶颈，缺少突破丹药或关键材料。
  - 前往坊市打探材料价格和秘境消息，消耗灵石购买情报。
  - 接取护送、猎妖或采药任务，获得进入危险区域的理由。
  - 在任务途中遭遇妖兽或修士冲突，消耗符箓、丹药或法力，获得妖兽材料、战利品或新的秘境线索。
  - 进入秘境或危险地点搜集资源，获得突破材料、法宝碎片、功法线索或灵药。
  - 因资源暴露被追杀或截杀，消耗逃遁符、疗伤丹或法宝耐久，成功逃脱或击败敌人。
  - 回到坊市出售部分材料，获得灵石。
  - 用灵石购买丹药、租赁洞府或兑换闭关资源。
  - 闭关修炼若干月，消耗丹药和灵石。
  - 突破成功、突破失败、重伤恢复或继续卡瓶颈的结果按原文填写。

### 配角修炼行动链

- 整理对象：配角、NPC、反派、宗门天才、散修、妖修等角色的完整链或典型片段。
- 行动链：
  - 先判断原文是否给出该配角的完整修炼行动链。
  - 如果原文给出完整链，按境界或阶段顺序完整写出当前境界、每次出门或闭关、每次资源获得与消耗、每次功法提升、每次突破或失败。
  - 如果原文没有完整链，只出现一段关键修炼片段，才只写该片段。
  - 片段开始时写清角色当前境界或状态；如果原文未说明，写“原文未说明”。
  - 角色因某个原因获得机会，例如宗门奖励、师傅赠药、秘境所得、拍卖所得、杀敌战利品或亲友相助。
  - 角色消耗该资源进行闭关、炼化、疗伤、转修、突破或学习功法。
  - 写清闭关或修炼持续时间；如果原文未说明，写“原文未说明”。
  - 写清修为提升、学会功法、伤势恢复、突破成功、突破失败、资源耗尽、心魔加重或引发后续事件等后续变化。
```

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
