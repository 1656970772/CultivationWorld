# 散修生存方式模板

## 适用范围

本文用于整理散修、游侠、小家族修士、临时队伍、底层修士如何获取资源、承担成本、规避风险、建立关系、加入或离开势力。

本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。

## 前置声明

- 本文要求尽量覆盖不同境界、不同资源状态、不同年龄阶段、不同职业路线和不同结局的散修样本；不要只写主角同境界或少数成功者。
- 炼气、筑基、金丹、元婴等不同境界散修，只要原文有对应内容，都应尽量分别记录。不同境界的资源来源、生存成本、风险来源、社交策略、上升路径、散修优势和失败路径往往不同，不能混成一种散修规则。
- 文档长度不是问题，样本范围要尽量大；低阶散修、老散修、临时队伍、游商、猎妖人、情报贩、客卿、隐居高人、失败者、负债者、投靠者、退隐者、堕为邪修者都可以写。
- 不把散修写成“自由职业者”美化版，必须写清生存压力、资源短缺、缺少靠山、信息不对称和被强者夺取资源的风险。
- 除了生存压力，也必须写清散修的优势；例如行动自由、少受宗门规矩限制、可随时迁移、可隐匿身份、可跨区域交易、可灵活选择机缘、可避免宗门内斗、可临时结盟或投靠、可独占战利品、可走偏门路线。
- 散修优势不能泛泛写“自由”，要结合具体案例说明这种优势如何带来资源、保命、逃亡、交易、突破、隐藏身份或避祸机会。
- 不只写主角成功路线；底层散修、老散修、失败者、投靠者、负债者、重伤退隐者、被迫效忠者、堕为邪修者也要写。
- 不把所有散修都写成孤狼；临时合作、依附商会、加入队伍、投靠宗门、成为客卿、加入散修联盟也要记录。
- 原文没有说明境界阶段、收入来源、生存成本、风险来源、风险规避、散修优势、上升路径或失败路径时，不要补，可以写“原文未说明”。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

整理时应覆盖以下内容，不局限于以下类别：

- **散修类型**：低阶散修、老散修、隐居高人、游商、炼丹/炼器散修、情报贩、猎妖人、赏金猎人、临时队伍、散修联盟成员、客卿、投靠者、失败者。
- **境界阶段**：炼气、筑基、金丹、元婴，或作品自己的境界说法；同一类型在不同境界差异明显时要拆开写。
- **资源状态**：贫困、勉强维持、短期暴富、负债、资源稳定、资源断供、怀璧其罪、被迫变卖法宝。
- **收入来源**：采药、挖矿、猎妖、护送、悬赏、代工炼丹炼器、坊市倒卖、拍卖套利、秘境探险、杀人夺宝、投靠宗门。
- **生存成本**：丹药、符箓、法宝维修、洞府租金、传送费、情报费、疗伤费、保护费、贡奉、队伍分成、人情债。
- **风险来源**：劫杀、黑市坑人、强者夺宝、队友背叛、伤病、无护法突破、信息不对称、财富暴露、无靠山、被势力利用。
- **风险规避**：伪装身份、改名换地、抱团、依附、结盟、交易人情、隐藏财富、分散出售、拜入宗门、加入商会/悬赏组织、远走避祸。
- **散修优势**：行动自由、身份灵活、路线选择自由、战利品分配自由、不受宗门任务束缚、可跨区域交易、可避开派系斗争、可独占机缘、可走偏门。
- **上升路径**：得到传承、拜师、积累财富、参加试炼、进入大势力、成为客卿、创立小势力、获得强者庇护。
- **失败路径**：死亡、被夺舍、堕为邪修、负债、重伤退隐、被迫效忠、投敌、转为凡俗、沦为炮灰。

## 案例

### 案例

#### 案例 1：低阶散修日常谋生

人物/群体名和类型：写具体人物、群体或散修类型，例如“低阶散修”“坊市底层散修”“无靠山炼气散修”。

境界阶段：写清炼气、筑基、金丹、元婴，或作品自己的境界说法；如果同一类散修在不同境界生存方式明显不同，要拆成多个案例。

资源状态：写清贫困、勉强维持、刚获得小机缘、负债、缺丹药、缺法器、无洞府、收入不稳定等。

收入来源：写清采药、挖矿、打杂、低阶悬赏、跑腿、看守、坊市小买卖、替人传信、临时护送等来源。

收入流程：非常详细写。写清如何发现机会，去哪里接活，谁发布需求，怎么谈报酬，行动过程怎么做，如何交付成果，如何拿到灵石/丹药/贡献/材料，是否会被压价、拖欠或克扣。

生存成本：非常详细写。写清丹药、符箓、法器维修、洞府租金、坊市摊位费、传送费、疗伤费、情报费、保护费、队伍分成和日常修炼消耗。

风险来源：非常详细写。写清低阶散修会遇到什么风险，例如被强者欺压、被黑店坑、任务死亡、材料被抢、无护法突破、受伤无钱医治、被同伴抛弃、信息不对称。

风险规避方式：非常详细写。写清如何隐藏修为、伪装贫穷、少带财物、结伴而行、选低风险任务、避开强者、租安全住处、分散出售材料、远走避祸。

散修优势：非常详细写。写清当前案例中散修优势如何发挥作用，例如不受宗门杂役安排、可自由换坊市、可避开派系斗争、可挑选低风险活计、可隐匿身份、可独占小机缘。原文未说明则写“原文未说明”。

社交策略：写清是否靠熟人介绍、结交掌柜、投靠强者、和同阶散修互助、加入临时队伍、交易人情或保持低调。

临时合作：写清是否会组队采药、共同护送、分摊情报费、合租洞府、共同抵御劫修或事后分账。

依附或投靠：写清是否依附坊市、商会、小家族、宗门外围、强者或散修联盟，以及代价是什么。

上升机会：写清积攒灵石、买丹药、买法器、参加试炼、拜师、进入宗门、获得传承或遇到贵人的机会。

失败路径：非常详细写。写清贫困、受伤、负债、任务失败、被抢、无法突破、被迫卖身、沦为炮灰、死亡或退回凡俗的过程。

财富暴露后果：写清获得小机缘、卖出材料、购买法器、拍卖得宝后是否被盯上、跟踪、截杀、勒索或强买。

典型事件：写清原文中低阶散修谋生、被坑、抱团、捡漏、负债、突破失败、被救或被杀的事件。

结局或后续影响：写清此类散修最后是成长、投靠、退隐、死亡、转行、堕落还是进入更高层级生存方式。

#### 案例 2：猎妖 / 采药 / 挖矿型散修

人物/群体名和类型：写具体猎妖人、采药散修、矿区散修、资源采集队伍或相关人物。

境界阶段：写清对应境界；不同境界采集地点、妖兽风险和收益明显不同，应拆开写。

资源状态：写清是否缺修炼资源、为突破攒钱、被迫冒险、临时暴富、材料压仓或需要还债。

收入来源：写清妖兽材料、灵药、矿石、妖丹、毒囊、兽皮、灵草、秘境外围资源、宗门或商会收购。

收入流程：非常详细写。写清如何打听资源点，如何购买地图或情报，如何准备工具，如何进入山脉/矿区/药谷，如何采集或猎杀，如何保存材料，如何出售或上交。

生存成本：非常详细写。写清地图费、情报费、丹药、解毒药、修补法器、队伍分成、储物工具、进山路费、矿区保护费、疗伤费。

风险来源：非常详细写。写清妖兽袭击、毒瘴、矿洞坍塌、采药被抢、队友背叛、守护妖兽、资源未成熟、归途截杀、商会压价。

风险规避方式：非常详细写。写清结伴、雇向导、避开高阶妖兽、只采外围资源、预留逃遁符、隐瞒收获、分批出售、绕路回城。

散修优势：非常详细写。写清不受宗门采集配额限制、可自由选择资源点、可独占发现的灵药、可绕开官方收购、可跨坊市寻找高价买家、可临时改变路线。原文未说明则写“原文未说明”。

社交策略：写清与采药队、猎妖队、商会收购人、坊市掌柜、情报贩、矿区管事的关系。

临时合作：写清如何组队、如何分工、如何分账、谁负责探路、谁负责战斗、谁负责采集，如何防止背叛。

依附或投靠：写清是否长期给商会、宗门外围、小家族或矿区势力供货，以及获得保护还是被压价。

上升机会：写清发现稀有灵药、猎得高阶妖兽、找到矿脉、结识买家、获得功法或赚够突破资源的机会。

失败路径：非常详细写。写清被妖兽杀死、矿难、材料被抢、受伤无钱医治、队伍内斗、资源点被势力夺走、被迫加入黑市或邪修。

财富暴露后果：写清高价值材料出售后被商会、劫修、同伴、宗门或妖兽族群盯上的后续。

典型事件：写清原文中进山采药、猎妖、矿区争夺、守药妖兽、归途截杀、材料交易等事件。

结局或后续影响：写清散修积累资源、升级装备、拜入势力、死亡、负债、转行或成为老练猎妖人的后续。

#### 案例 3：坊市交易 / 倒卖 / 情报型散修

人物/群体名和类型：写游商、倒卖散修、情报贩、拍卖捡漏者、黑市中间人、坊市熟客等。

境界阶段：写清境界；低阶和高阶交易圈层、风险和本钱不同，应拆开写。

资源状态：写清本钱多少、是否负债、是否短期暴富、是否手握稀缺情报、是否缺周转灵石。

收入来源：写清低买高卖、坊市倒卖、拍卖套利、情报贩卖、代购、寄售、鉴定差价、黑市中介费。

收入流程：非常详细写。写清如何获得货源或情报，如何判断价格，如何寻找买家，如何谈价，如何规避假货，如何交割，如何保密，如何处理尾随风险。

生存成本：非常详细写。写清摊位费、入场费、情报费、鉴定费、保密费、黑市介绍费、传送费、押金、库存占用、被骗成本。

风险来源：非常详细写。写清假货、压价、托价、身份暴露、财富暴露、黑吃黑、商会打压、情报过期、买卖违约、被执法盯上。

风险规避方式：非常详细写。写清换身份交易、分散出售、找中间人、验货、签契约、只做熟客、保留退路、隐藏真实身家、跨坊市倒货。

散修优势：非常详细写。写清散修可自由跨坊市、无宗门身份包袱、可快速换身份、可做灰色交易、可利用信息差、可不受宗门价格规则限制。原文未说明则写“原文未说明”。

社交策略：写清与掌柜、商会、拍卖行、黑市、情报贩、炼丹师、猎妖人、买家和托的关系。

临时合作：写清是否合伙倒卖、共同凑本钱、共享情报、联手压价、共同护送货物。

依附或投靠：写清是否依附商会、黑市、坊市管理者、强者客户或情报组织，获得渠道还是失去自由。

上升机会：写清通过倒卖暴富、获得稀缺情报、结识强者、进入商会、成为客卿或掌握稳定渠道。

失败路径：非常详细写。写清被骗破产、假货追责、黑市灭口、商会封杀、情报错误、货物被抢、债务缠身。

财富暴露后果：写清交易获利、拍卖得宝、倒卖成功后被盯梢、勒索、截杀、套话或纳入商会控制。

典型事件：写清原文中坊市倒卖、拍卖套利、情报交易、黑市交割、买卖纠纷、被追踪等事件。

结局或后续影响：写清散修变富、被吞并、加入商会、转做黑市、破产逃亡或因情报卷入大事件。

#### 案例 4：临时队伍 / 秘境探险散修

人物/群体名和类型：写临时探险队、秘境队伍、遗迹队伍、散修联盟小队、临时合作修士等。

境界阶段：写清队伍成员境界构成；不同境界队伍进入的秘境和分配规则不同，要分开记录。

资源状态：写清是为了缺资源临时组队，还是为高价值机缘冒险，是否本钱不足、保命物不足或短期暴富。

收入来源：写清秘境资源、古修洞府、遗迹材料、妖兽尸骸、宝箱、传承线索、队伍分成、雇佣报酬。

收入流程：非常详细写。写清如何得到秘境/遗迹消息，如何招募队友，如何约定分成，如何进入，如何探索，如何分配机缘，如何退出和销赃。

生存成本：非常详细写。写清门票、地图、情报、保命符、丹药、队伍押金、分成成本、交通费、疗伤费和背叛代价。

风险来源：非常详细写。写清队友背叛、杀人夺宝、秘境危险、分赃不均、信息假、出口关闭、受伤无人护法、强者截胡。

风险规避方式：非常详细写。写清签约、立誓、找熟人、保留底牌、隐藏收获、提前约定分成、准备逃生路线、分散行动或快速撤离。

散修优势：非常详细写。写清散修可临时拼队、自由选择队友、不受宗门名额限制、可独占偶然机缘、可随时退出、可绕开宗门规则进入灰色秘境。原文未说明则写“原文未说明”。

社交策略：写清如何判断队友、交换情报、建立临时信任、选择带队者、处理分赃和冲突。

临时合作：写清队伍组成、分工、分账、战斗职责、探路职责、破阵职责、撤退规则和背叛预防。

依附或投靠：写清是否需要依附强者队伍、商会队伍、宗门外围队伍或散修联盟才能进入高价值区域。

上升机会：写清得到传承、法宝、材料、认识强者、被宗门招揽、积累名声或掌握新地图。

失败路径：非常详细写。写清死亡、被困、队友背叛、机缘被抢、欠债、重伤、被灭口、被迫投靠强者。

财富暴露后果：写清出秘境后被追踪、被队友出卖、被强者搜身、被坊市盯上或引发杀人夺宝。

典型事件：写清临时组队、探索、分赃、背叛、救援、机缘争夺、逃出秘境等原文事件。

结局或后续影响：写清队伍解散、结盟延续、仇怨形成、角色暴富、重伤退隐、进入大势力或堕为邪修。

#### 案例 5：客卿 / 依附商会或宗门的散修

人物/群体名和类型：写客卿散修、供奉、商会护卫、宗门外围修士、附属势力修士等。

境界阶段：写清境界；高阶散修成为客卿与低阶散修求庇护的逻辑不同，应拆开写。

资源状态：写清是资源稳定但受制于人，还是缺靠山才投靠，是否有一技之长或战力优势。

收入来源：写清供奉、月俸、护送报酬、炼丹炼器报酬、商会雇佣、宗门任务、庇护换服务。

收入流程：非常详细写。写清如何被招揽或主动投靠，如何谈待遇，承担什么职责，如何领取供奉，如何处理额外任务和退出。

生存成本：非常详细写。写清失去部分自由、承担护卫任务、战斗风险、被派遣、受规矩限制、人情债、违约代价和身份绑定。

风险来源：非常详细写。写清被当炮灰、被卷入势力斗争、合同不公、强敌报复、供奉断供、被怀疑忠诚、难以脱身。

风险规避方式：非常详细写。写清保留退路、谈清契约、保持中立、分散人脉、隐藏底牌、只接有限任务、避免深度派系站队。

散修优势：非常详细写。写清散修可按利益选择依附对象、可换靠山、可谈待遇、可利用独立身份做中间人、可在多个势力间周旋。原文未说明则写“原文未说明”。

社交策略：写清与商会、宗门长老、雇主、同为客卿者、附属家族和敌对势力的关系。

临时合作：写清是否和其他客卿组队、共同护送、共同炼制、共同抵御外敌或私下交换资源。

依附或投靠：写清投靠条件、待遇、义务、退出方式、违约后果、是否会被视为自家人。

上升机会：写清成为正式长老、供奉、商会核心、宗门客卿、获得洞府、功法、庇护和稳定资源。

失败路径：非常详细写。写清被雇主牺牲、卷入派系斗争、违约追杀、失去自由、债务绑定、被迫效忠。

财富暴露后果：写清作为客卿获得资源后是否被同僚嫉妒、被雇主控制、被敌人盯上或被迫承担更危险任务。

典型事件：写清受聘、护卫、议价、背叛、被派战斗、获得供奉、退出或被追杀事件。

结局或后续影响：写清散修稳定发展、成为势力成员、保持独立、被吞并、被牺牲或转投他处。

#### 案例 6：隐居高人 / 老散修

人物/群体名和类型：写隐居散修、老散修、无门派高阶修士、避世修士、退隐炼丹师/炼器师等。

境界阶段：写清境界和寿元状态；老散修、隐居高人和落魄高阶散修要分开写。

资源状态：写清是否有积蓄、洞府、传承、弟子、旧伤、寿元压力、资源断供或长期隐居所得。

收入来源：写清出售丹药法器、偶尔接客卿、收徒、交换情报、守洞府、开小店、靠旧资源、靠传承或不再谋生。

收入流程：非常详细写。写清如何维持隐居生活，如何与外界交易，如何选择交易对象，如何避免暴露，如何收徒或传承。

生存成本：非常详细写。写清洞府维护、阵法维护、疗伤、延寿丹药、隐藏身份成本、弟子培养、旧仇规避。

风险来源：非常详细写。写清寿元将尽、旧仇追来、传承被觊觎、弟子背叛、洞府暴露、资源断供、强者逼迫出山。

风险规避方式：非常详细写。写清布阵、改名、远遁、隐藏境界、只见熟人、设置考验、分散传承、伪装普通修士。

散修优势：非常详细写。写清隐居散修不受宗门事务牵连、可自由选择传人、可避开派系斗争、可隐藏旧身份、可按自己节奏修炼或传承。原文未说明则写“原文未说明”。

社交策略：写清是否保持少量可靠人脉、收徒、与商会暗中交易、与宗门保持距离、和旧友互助。

临时合作：写清是否偶尔出山、护送、炼制、解围、与主角合作或参与大战。

依附或投靠：写清是否拒绝势力招揽，是否成为客卿，是否晚年投靠宗门换取资源。

上升机会：写清突破晚期、获得传人、传承延续、旧伤治愈、重回修仙界或建立小势力。

失败路径：非常详细写。写清坐化、被夺传承、弟子背叛、旧仇寻来、寿元耗尽、洞府被破、被迫效忠。

财富暴露后果：写清传承、洞府、丹方、法宝、积蓄被发现后引来争夺、围攻或拜师潮。

典型事件：写清隐居、收徒、传承、旧仇、坐化洞府、被强者逼迫、主角获机缘等事件。

结局或后续影响：写清传承流出、角色得益、老散修坐化、势力争夺、隐居地暴露或新门派萌芽。

#### 案例 7：失败散修

人物/群体名和类型：写负债散修、重伤散修、堕为邪修者、投敌者、退隐凡俗者、沦为炮灰者等。

境界阶段：写清失败发生在什么境界，不同境界失败代价不同，要分开记录。

资源状态：写清负债、无丹药、法宝损毁、伤病缠身、被通缉、失去队友、被夺机缘或无法突破。

收入来源：写清失败前靠什么谋生，失败后是否靠乞求、卖法宝、投靠、邪修手段、低价打工或凡俗生活。

收入流程：非常详细写。写清失败者如何继续获取最低资源，是否被压价、被剥削、被迫接危险活、卖掉积蓄或投靠强者。

生存成本：非常详细写。写清疗伤费、债务、追杀成本、躲藏成本、丹药断供、身份伪装、赎身、赔偿和精神压力。

风险来源：非常详细写。写清债主、仇家、黑市、旧队友、宗门追责、邪修诱惑、伤势恶化、寿元不足、凡俗牵连。

风险规避方式：非常详细写。写清逃亡、改名、躲入凡俗、投靠强者、出卖情报、加入邪修、求宗门庇护、隐姓埋名。

散修优势：非常详细写。即使失败，也要写清散修是否还能利用身份灵活、迁移自由、无宗门连坐、可重新换地方、可隐姓埋名、可低成本断尾求生。原文未说明则写“原文未说明”。

社交策略：写清失败者是否求助旧友、投靠仇敌、加入黑市、卖人情、欺骗新人或远离修仙圈。

临时合作：写清是否和其他失败者结伴、组成低端队伍、抱团取暖、互相出卖或共同逃亡。

依附或投靠：写清是否被迫效忠、卖身、投敌、做炮灰、成为邪修爪牙或成为凡俗供奉。

上升机会：写清是否还有翻身机会，例如奇遇、强者救助、拜入宗门、得到传承、治愈旧伤或重新积累资源。

失败路径：非常详细写。写清从资源不足到任务失败、受伤、负债、被追杀、堕落、死亡、退隐凡俗的链条。

财富暴露后果：写清失败者如果仍握有宝物、传承、地图或秘密，会如何被追杀、逼供、夺舍、控制或利用。

典型事件：写清负债、重伤退隐、堕为邪修、被迫效忠、投敌、被杀、被凡俗吞没等事件。

结局或后续影响：写清死亡、退隐、堕落、被利用、重新崛起、成为反派、成为警示样本或影响他人选择。
