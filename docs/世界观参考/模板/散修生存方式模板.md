# 散修生存方式模板

# 规范

## 参考和要求

- 整理范围：本文用于整理散修、游侠、小家族修士、临时队伍、底层修士如何获取资源、承担成本、规避风险、建立关系、加入或离开势力。
- 样本覆盖：样本要覆盖不同境界、资源状态、年龄阶段、职业路线和结局；不要只写主角同境界或少数成功者。
- 风格限制：不把散修写成“自由职业者”美化版。要写清资源短缺、缺少靠山、信息不对称、被夺资源和生死风险。
- 优势记录：也要写清散修优势，例如行动自由、身份灵活、可迁移、可隐匿、可跨区域交易、可避开宗门内斗、可临时结盟或投靠。
- 优势落点：散修优势不能泛泛写“自由”，要结合具体案例说明这种优势如何带来资源、保命、逃亡、交易、突破、隐藏身份或避祸机会。
- 关系形态：不把所有散修都写成孤狼；临时合作、依附商会、加入队伍、投靠宗门、成为客卿、加入散修联盟也要记录。
- 文本依据：只写小说内容能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 待定处理：信息不足但符合主题的内容，先写入 `### 待定案例`；信息足够后再转为正式案例。
- 参考范围：本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。
- 低阶谋生型：坊市底层散修、无靠山炼气散修、跑腿修士等；重点写收入小、成本高、风险密集的日常活路和失败代价。
- 采集猎妖型：采药散修、猎妖人、矿区散修、资源采集队等；重点写资源点、准备成本、队伍分账、妖兽或矿区风险。
- 交易情报型：游商、倒卖散修、情报贩、拍卖捡漏者、黑市中间人等；重点写货源、价格判断、保密、假货、黑吃黑和财富暴露。
- 临时队伍型：秘境队伍、遗迹队伍、散修联盟小队、临时护送队等；重点写组队、分工、分账、背叛预防、退出和事后追杀。
- 依附客卿型：客卿散修、供奉、商会护卫、宗门外围修士等；重点写待遇、义务、自由损失、退出方式和被卷入势力斗争的风险。
- 隐居老散修：隐居高人、老散修、退隐炼丹师或炼器师等；重点写寿元、旧伤、传承、洞府暴露、收徒和旧仇。
- 失败散修：负债者、重伤退隐者、堕为邪修者、被迫效忠者、炮灰等；重点写从资源不足到失败、逃亡、堕落、死亡或退隐的链条。
- 要素覆盖：整理时可覆盖以下要素。

- 散修类型：低阶散修、老散修、隐居高人、游商、炼丹/炼器散修、情报贩、猎妖人、赏金猎人、临时队伍、散修联盟成员、客卿、投靠者、失败者。
- 境界阶段：炼气、筑基、金丹、元婴，或作品自己的境界说法；同一类型在不同境界差异明显时拆开写。
- 资源状态：贫困、勉强维持、短期暴富、负债、资源稳定、资源断供、怀璧其罪、被迫变卖法宝。
- 收入渠道与流程：采药、挖矿、猎妖、护送、悬赏、代工炼丹炼器、坊市倒卖、拍卖套利、秘境探险、杀人夺宝、投靠宗门；写清机会获得方式、报酬谈判、行动交付和被压价或克扣的过程。
- 生存成本：丹药、符箓、法宝维修、洞府租金、传送费、情报费、疗伤费、保护费、贡奉、队伍分成、人情债。
- 风险类型与规避：劫杀、假货、强者夺宝、队友背叛、无护法突破、信息不对称、财富暴露、无靠山、被势力利用；对应写伪装、抱团、依附、结盟、隐藏财富、分散出售、换地、拜入宗门、加入商会或远走避祸。
- 社交与依附：熟人介绍、掌柜、商会、强者、同阶互助、临时队伍、客卿、散修联盟。
- 上升机会与失败路径：得到传承、拜师、积累财富、参加试炼、进入大势力、成为客卿、创立小势力、获得强者庇护；或死亡、被夺舍、堕为邪修、负债、重伤退隐、被迫效忠、投敌、转为凡俗、沦为炮灰。
- 财富暴露后果、典型事件、结局或后续影响：按原文写清，不明则写“原文未说明”。

类型示例：

- 低阶谋生型：重点写日常活路、收入结算、修炼成本、被坑被骗和失败代价。
- 采集猎妖型：重点写资源点、准备成本、队伍分账、材料出售、妖兽或矿区风险。
- 交易情报型：重点写货源、价格判断、保密方式、假货、黑吃黑和财富暴露。
- 临时队伍型：重点写组队、分工、分账、背叛预防、退出方式和事后追杀。
- 依附客卿型：重点写待遇、义务、自由损失、退出方式和被卷入势力斗争的风险。
- 隐居老散修：重点写寿元、旧伤、传承、洞府暴露、收徒和旧仇。
- 失败散修：重点写从资源不足到失败、逃亡、堕落、死亡或退隐的链条。

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。
