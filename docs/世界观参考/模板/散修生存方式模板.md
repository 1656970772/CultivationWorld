# 散修生存方式模板

## 适用范围

用于整理散修、游侠、小家族修士、临时队伍、底层修士如何获取资源、承担成本、规避风险、建立关系、加入或离开势力。

## 前置声明

- 样本要覆盖不同境界、资源状态、年龄阶段、职业路线和结局；不要只写主角同境界或少数成功者。
- 不把散修写成“自由职业者”美化版。要写清资源短缺、缺少靠山、信息不对称、被夺资源和生死风险。
- 也要写清散修优势，例如行动自由、身份灵活、可迁移、可隐匿、可跨区域交易、可避开宗门内斗、可临时结盟或投靠。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 信息不足但符合主题的内容，先写入 `### 待定案例`。后续获得新信息时，在同一待定项追加摘要和来源；信息足够后，复核来源并转为正式案例。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 低阶谋生型 | 坊市底层散修、无靠山炼气散修、跑腿修士 | 收入小、成本高、风险密集，重点写日常活路和失败代价。 |
| 采集猎妖型 | 采药散修、猎妖人、矿区散修、资源采集队 | 重点写资源点、准备成本、队伍分账、妖兽或矿区风险。 |
| 交易情报型 | 游商、倒卖散修、情报贩、拍卖捡漏者、黑市中间人 | 重点写货源、价格判断、保密、假货、黑吃黑和财富暴露。 |
| 临时队伍型 | 秘境队伍、遗迹队伍、散修联盟小队、临时护送队 | 重点写组队、分工、分账、背叛预防、退出和事后追杀。 |
| 依附客卿型 | 客卿散修、供奉、商会护卫、宗门外围修士 | 重点写待遇、义务、自由损失、退出方式和被卷入势力斗争的风险。 |
| 隐居老散修 | 隐居高人、老散修、退隐炼丹师/炼器师 | 重点写寿元、旧伤、传承、洞府暴露、收徒和旧仇。 |
| 失败散修 | 负债者、重伤退隐者、堕为邪修者、被迫效忠者、炮灰 | 重点写从资源不足到失败、逃亡、堕落、死亡或退隐的链条。 |

通用卡片字段：

- 人物/群体名和类型：写具体人物、群体或散修类型。
- 境界阶段：写清境界；同一类型在不同境界差异明显时拆开写。
- 资源状态：贫困、勉强维持、短期暴富、负债、资源稳定、资源断供、怀璧其罪等。
- 收入来源与流程：写清机会从哪里来、谁发布需求、如何谈报酬、如何行动、如何交付、如何被压价或克扣。
- 生存成本：丹药、符箓、法宝维修、洞府租金、传送费、情报费、疗伤费、保护费、贡奉、队伍分成、人情债。
- 风险来源与规避：劫杀、假货、强者夺宝、队友背叛、无护法突破、信息不对称、财富暴露；对应写伪装、抱团、依附、隐藏财富、换地、拜入宗门等。
- 散修优势：必须结合案例说明优势如何带来资源、保命、逃亡、交易、突破、隐藏身份或避祸机会。
- 社交与依附：熟人介绍、掌柜、商会、强者、同阶互助、临时队伍、客卿、散修联盟。
- 上升机会与失败路径：传承、拜师、财富积累、进入大势力、创立小势力；或死亡、夺舍、堕为邪修、负债、重伤、被迫效忠、退回凡俗。
- 财富暴露后果、典型事件、结局或后续影响：按原文写清，不明则写“原文未说明”。

## 案例

### 案例

#### 案例 1：低阶散修日常谋生

人物/群体名和类型：写具体人物、群体或散修类型，例如“低阶散修”“坊市底层散修”“无靠山炼气散修”。

境界阶段：写清炼气、筑基、金丹、元婴，或作品自己的境界说法。

资源状态：写清贫困、负债、缺丹药、缺法器、无洞府、收入不稳定等。

收入来源与流程：写清采药、挖矿、跑腿、低阶悬赏、坊市小买卖等来源，以及接活、议价、行动、交付和报酬结算过程。

生存成本：写清修炼、居住、疗伤、情报、保护、交通和人情成本。

风险来源与规避：写清被抢、被坑、任务死亡、无护法突破、信息不对称，以及隐藏身份、结伴、避开强者、分散出售、远走避祸等方法。

散修优势：写清当前案例中散修优势如何发挥作用；原文未说明则写“原文未说明”。

社交、依附与合作：写清是否靠熟人、队伍、商会、小家族、宗门外围或强者庇护。

上升机会、失败路径与后续：写清能否攒资源、买丹药、入宗门、获得传承；也写清贫困、受伤、负债、被抢、死亡或退回凡俗的过程。
