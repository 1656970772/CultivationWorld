# 拍卖坊市与交易模板

## 适用范围

本模板用于整理作品中明确出现的拍卖、坊市、店铺、商会、临时交易会、高阶交换会、黑市、宗门兑换、资源分配、寄卖委托、结算交割、服务换报酬，以及由交易引发的信息传播、势力反应、尾随截杀等事件。

本模板重点分析交易如何运转，包括交易场景、主办或控制者、参与者、场所、准入条件、交易准备、物品或服务、定价与交换机制、交易流程、价格台账、结算交割、信息传播、风险代价和后续影响，不只记录人物买到或卖出了什么。

本模板不展开商品本体、材料属性、丹药功效、法宝能力、功法内容或完整经济体系。相关对象只保留与交易机制直接相关的信息，完整内容分别放入对应的材料、丹药、武器、法宝、功法或其他专题模板。

## 整理原则

1. 先做准入判定  
   具有明确交易对象或服务、付出与回报、交换或分配规则、定价议价、竞价、寄卖、结算、交割、准入资格或交易后果的事件可以收录。单纯获得赠礼、捡到物品、一般人情往来或没有交换关系的资源变化，不作为交易主案例。

2. 区分主交易与关联事件  
   直接交易、资源兑换或分配、服务换报酬通常可以独立成例。筹资借贷、寄卖鉴定、验资入场、结算交割、贵宾礼遇、消息外泄、势力拉拢、结仇追杀等通常挂接到对应主交易；只有具备独立物品、价格、交割、准入或后果机制时才另开案例。

3. 同一交易链合并整理  
   同一拍卖、坊市购买、寄卖结算或服务委托的准备、成交、交割和后续影响统一写入一张卡。流程相同且没有新增机制的重复交易可选取代表案例，不把每一次出价、付款或领取拆成微型案例。

4. 保持字段完整  
   每张卡包含：事件类型、场景类型、主办或控制者、参与者、交易场所、场所外观描述、准入条件、交易准备、交易物品/服务、定价或交换机制、交易流程、价格台账、结算交割、信息传播、风险代价、关联事件、后续影响、适用身份/阶段。没有可靠内容时写“原文未说明”；仅因本次整理范围尚未覆盖时写“本次未覆盖到明确内容”；确实不适用的字段写“不适用”。

5. 不混用不同交易规则  
   拍卖、坊市、店铺、黑市、高阶交换会、宗门兑换和服务交易分别按各自的准入、定价、交割与风险机制填写，不把它们概括成同一套通用规则。不同地域、境界、身份和势力造成的规则差异分别记录。

6. 价格与资源流转可核对  
   有明确价格时，价格台账填写物品或服务、货币或资源单位、数量、要价或起拍价、加价过程、成交价或兑换成本、税率或手续费、税费、净额、付出方、获得方、价格性质和回算结果。总价、净额、税后收入、批次合计和平均价应能与分项相互核对；信息不足时写“不足以回算”，不把估算写成确定数值。

7. 保留风险与交易后果  
   假货、托价、压价、财富暴露、竞价结仇、尾随截杀、黑吃黑、身份暴露、执法介入、通缉、家族欺压、同门竞争和信誉受损等，是交易机制的一部分，应与成交结果一并整理。没有明确风险时写“原文未说明”，不默认写成无风险或可自由进出。

8. 区分信息缺失状态  
   “原文未说明”表示作品没有明确给出相关内容；“本次未覆盖到明确内容”表示当前整理范围不足；“报告缺失/未生成/需重新生成”表示输入报告不可用。报告缺失时不根据零散线索补写正式交易案例。

9. 保持代表性与输出密度  
   样本兼顾多境界、多身份、多地域、多势力、多场景和不同结局，不只记录主角交易。场所外观应简明保留，复杂场所按层次分块；人物外貌、气氛和叙事铺陈只保留与交易流程、身份差异、隐私保护或风险有关的部分。作品未说明的建筑风格、装饰等级、色彩、材质和空间规模不得根据拍卖会、黑市等场景类型自行补写。

10. 输出前自检  
    检查交易是否满足准入条件、主案例与关联事件是否正确合并、场景规则是否混用、字段是否齐全、价格与批次金额是否可回算、风险与后续影响是否遗漏、候选事件是否具有代表性、具体案例是否保留，以及案例区是否只包含实际输出字段和示例内容。

## 字段说明

- 事件名称：使用作品中的拍卖、坊市、店铺、交换会、兑换事件或服务交易名称；无正式名称时使用简洁、可辨识的描述性名称。
- 事件类型：填写直接交易、资源兑换或分配、交易准备、寄卖/委托、结算交割、交易后果、服务换报酬或边界事件。准备、结算和后果作为关联事件时，在主卡中标明。
- 场景类型：填写普通拍卖会、特色拍卖会、高阶修士交换会、固定坊市、临时交易会、店铺、黑市、商会、宗门兑换殿、资源分配场所或服务委托等。
- 主办或控制者：填写商会、拍卖行、坊市管理者、家族、宗门、黑市势力、店铺掌柜、主持修士或服务提供者，以及其组织、鉴定、护卫和交割职责。
- 参与者：填写买方、卖方、寄卖方、竞拍者、散修、宗门弟子、家族子弟、摊贩、拍卖师、鉴定师、托、劫修、执法者和隐藏身份的高阶修士等。
- 交易场所：填写入场口、大厅、普通席、贵宾席、包厢、拍卖台、鉴宝室、后台库房、交割室、坊市街道、店铺柜台、黑市入口、宗门兑换柜台和离场风险点等。
- 场所外观描述：填写交易场所可直接观察到的建筑形制、规模、风格、色彩、材质、光照、招牌、装饰、陈设、摊位、座席、展台、隐私设施、防护设施、破损痕迹及标志物。简单店铺、柜台或临时会面处可用一段概括；大型拍卖场、坊市、黑市等复杂场所按需分为“整体外观”“外部与入口”“内部与分区”“关键交易区域/标志物”2-4 块，不适用的分块可省略。此字段描述场所看起来如何，“交易场所”只记录交易发生地点及功能区域，二者不要重复。没有明确描写时写“原文未说明”；非固定场所或无需场所的交易可写“不适用”。
- 准入条件：填写请柬、验资、保证金、会员或贵宾资格、宗门身份、黑市暗号、介绍人、境界、信誉担保、成人仪式资格、贡献或战功权限等。
- 交易准备：填写消息预告、筹资借贷、准备货物、寄卖鉴定、身份伪装、验资、获取名额或贵宾资格等。
- 交易物品/服务：填写货币、丹药、法宝、功法、材料、妖兽资源、符箓、阵盘、情报、地图、秘境钥匙、传承残篇，以及讲解、鉴定、带路、护送等服务。
- 定价或交换机制：填写固定价、讨价还价、起拍与加价、拍卖溢价、黑市折价或高价、以物易物、高阶资源互换、贡献兑换、战功兑换、服务换报酬、急需溢价和压价等。
- 交易流程：填写预告、入场、验资、落座、鉴定、展示、问价、议价、竞价、成交、付款、兑换、寄售、扣费、交割、结算和离场等实际环节。
- 价格台账：有明确数值时逐项填写物品或服务、货币或资源单位、数量、要价或起拍价、加价过程、成交价或兑换成本、税率或手续费、税费、净额、付出方、获得方、价格性质与回算结果。价格性质使用“原文明示”“计算结果”“估算”或“原文未说明”。
- 结算交割：填写付款、扣税、手续费、后台结算、实物移交、令牌或资格发放、贵宾权益变化和离场安排等。
- 信息传播：填写交易预告、压轴品消息、坊市传闻、商会放风、黑市情报、买家或卖家身份泄露、贵宾待遇暴露、交易结果外传等。
- 风险代价：填写假货、托价、压价、财富暴露、竞价结仇、尾随截杀、黑吃黑、身份暴露、执法介入、通缉、欺压和信誉受损等。
- 关联事件：填写与主交易相连的交易准备、寄卖委托、结算交割、贵宾礼遇、势力反应、消息外泄、尾随截杀和后续追责等。
- 后续影响：填写资源与货币变化、人脉建立、商会关系、势力拉拢、结仇追杀、任务链延续、市场认知和经营机会等。
- 适用身份/阶段：填写参与交易所需的身份、权限、境界、财富层级或职业能力。
- 缺失/不确定项：汇总报告缺失、候选事件召回不足、价格无法回算、事件边界不清、交易场所、准入条件、交割方式或离场风险未说明等状态。

### 候选事件参考范围

以下分类用于候选事件召回与边界判断，实际整理不仅限于这些参考范围。作品中出现其他具有明确交换、定价、准入、分配、结算或交易后果的机制时，也应按相同原则纳入或挂接到相关主案例。

- 世俗与低阶日常交易：银两、铜钱、米谷、猎物、药材、基础兵器、客栈补给和普通店铺买卖；可参考厨房换野兔、药材购买等小额实物交易。规模较小但具备明确物品、付款和交割时仍可保留。
- 临时交易会与散修交换：交易盛会、临时摊位、修士集会、散修抱团、灵石支付、以物换物、低声问价和离场自保；可参考太南小会式交易场景。
- 固定坊市与店铺经营：家族坊市、宗门坊市、城镇商区、丹阁、器阁、材料铺、摊贩街和大型活动场内临时市场；关注摊位费、佣金、入城费、店铺位置、护卫规则、明码标价、议价搭售、货源、口碑和同行竞争，可参考萧家坊市、药材购买与魔晶议价。
- 拍卖、寄卖与批次结算：拍卖预告、拍品画册、请柬、验资、鉴定、寄卖、保证金、起拍、加价、分批竞拍、税费抽成、后台交割、贵宾费率和流拍处理；可参考筑基灵液寄卖、七瓶筑基灵液拍卖及其结算链。
- 拍后交易与高阶交换会：拍卖结束后的私下交易、指定资源交换、混合货币、以物易物、传音议价、熟人引荐和会后追踪；与主拍卖共享参与者和风险时作为关联阶段，形成独立准入与交换规则时可单独成例。
- 宗门、家族与战时资源兑换：贡献、战功、功勋、身份资格、成人仪式、任务记录、审批权限、配额和限次领取；可参考斗气阁功法领取、贡献殿、战备殿和军需资源兑换。战争、灾变或资源紧张造成的兑换价格变化也属于参考范围。
- 代炼、修复、鉴定与知识服务：委托炼丹、炼器修复、宝物鉴定、解读古文或道书、情报咨询、带路和护送；关注材料由谁提供、成功率、抽成或成品分配、验收、赔偿、信誉和重复经营，可参考讲解蚀文道书换报酬等服务交易。
- 商会网络、会员与贵客体系：商铺分会、人物识别、贵宾卡、会员等级、专人接待、内部消息、拍品宣传、跨城调货和商会关系；重点整理优惠、准入、隐私、情报传播和势力拉拢，而不是只写礼遇场面。
- 黑市、销赃与灰色交易：暗号、介绍人、身份伪装、赃物、禁物、走私、中间人、匿名交割和黑吃黑；同时记录坊市保护边界、执法介入、城内安全与离场后追杀等差异。
- 赌石、盲选与高风险鉴宝交易：源石、矿料、封存物、未知残片或来历不明物品的估值、切解、竞价和全损风险；关注鉴定能力、信息差、围观抬价、造假、开出稀有物后的财富暴露与争夺。
- 借贷、赊欠与担保：私人借钱、商会垫资、赊账、抵押、保证金、信誉担保、利息或人情债、逾期追偿和债务引发的控制关系；仅作为交易准备时挂接主案例，形成独立借贷规则时单独成例。
- 商队、商船与跨地域流通：凡俗商队、修士商队、远程运输、跨城商路、商船、空间通道、护送费用、路税、损耗、劫掠、封锁和地域价差；交易重点在运输、补给与风险分摊时，可作为流通型交易案例。
- 垄断、限额与稀缺市场：宗门或世家垄断丹方、宝地、高阶材料和进入资格，实行限购、配额、内部优先、禁售或关系供货；关注垄断如何改变价格、准入、替代品、走私和势力冲突。
- 交易后的信息与冲突：贵宾礼遇、商铺情报传播、身份与财富暴露、势力拉拢、同行打压、竞价结仇、尾随截杀、交易纠纷和执法追责；可参考拍卖后礼遇与势力反应，通常挂接到对应主交易。
- 边界事件：赠礼、战利品分配、任务奖励、宗门月俸、人情往来和单纯取得物品，只有出现明确对价、资格、配额、交换、结算或违约机制时才纳入本模板；否则转入物资、任务、势力或人物关系类模板。
