# 拍卖坊市与交易模板

# 规范

本文重点整理交易流程和交易场所，不只记录买卖结果。

本文不写总览，不写考据段，不写项目字段映射，不写游戏化抽象；案例区类型提示只用于提示类型差异。

- 只整理原文出现过，或能由文本内容明确支撑的交易流程、交易场所和交易后果。
- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角买到什么。
- 不写无文本依据的固定价目表；价格只写原文明示内容，没有就写相对贵贱、稀缺程度或“原文未说明”。
- 拍卖、坊市、黑市、商会、交换会、宗门兑换不要混成一种规则；流程相同的场景写代表案例即可。
- 原文没有说明交易场所、准入条件、竞价方式、交割方式、价格或离场风险时，写“原文未说明”，不要补设定。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 交易场景：普通拍卖会、特色拍卖会、高阶修士交换会、固定坊市、临时交易会、黑市、商会、宗门兑换殿、悬赏阁、情报楼、丹阁、器阁。
- 交易场所：入场口、大厅、普通席、贵宾席、包厢、拍卖台、展示台、鉴宝室、后台库房、交割室、护卫位置、离场通道、坊市街道、店铺柜台、黑市入口、宗门兑换柜台、截杀地点。
- 准入条件：请柬、验资、保证金、会员等级、贵宾资格、宗门身份、黑市暗号、介绍人、境界要求、信誉担保。
- 交易物品：灵石、丹药、法宝、功法、材料、妖兽资源、符箓、阵盘、灵兽、情报、地图、秘境钥匙、传承残篇。
- 参与者：散修、宗门弟子、商会、拍卖师、鉴定师、托、劫修、情报贩、执法者、隐藏身份的高阶修士。
- 交易流程：预告、入场、验资、落座、鉴定、展示、竞价、加价、压轴品、成交、付款、交割、离场、尾随截杀。
- 价格机制：固定价、讨价还价、起拍价、加价、拍卖溢价、黑市折价或高价、以物易物、高阶资源交换、急需溢价、压价。
- 信息传播：拍卖预告、压轴品消息、坊市传闻、商会放风、黑市情报、买家身份泄露、宝物消息外传。
- 风险后果：假货、托价、压价、财富暴露、尾随截杀、黑吃黑、身份暴露、执法介入、通缉、交易后被盯上。
- 写作重点：重点写交易前信息、交易过程、交易后风险和后续影响。
- 场所描写：围绕入场、验资、落座、展示、竞价、成交、交割、离场和风险点展开。
- 布置取舍：室内布置只写与流程、身份差异、隐私保护和风险有关的部分。
- 独立成例：有特殊流程、特殊准入、特殊商品、特殊风险或后续事件时，可单独写成案例。

### 案例

```md
# 《作品名》拍卖坊市与交易

## 交易案例

### 普通拍卖会

- 类型示例：商会拍卖、坊市拍卖。
- 重点：预告、验资、席位、展示、竞价、成交、交割、离场风险。
- 交易场景类型：普通拍卖会、特色拍卖会、交换会、坊市店铺、黑市、宗门兑换等。
- 主办或控制者：商会、拍卖行、坊市管理者、宗门、黑市势力、主持修士等；写清组织、鉴定、护卫和交割责任。
- 交易场所：入场口、验资处、大厅、普通席、贵宾席、包厢、展示台、鉴宝室、后台库房、交割室、护卫位置、离场通道、店铺柜台、黑市暗门、宗门兑换柜台等。
- 准入流程：请柬、验资、保证金、会员、贵宾资格、宗门身份、暗号、介绍人、境界要求、信誉担保、权限等级。
- 交易流程：预告、入场、验资、落座、展示、问价、竞价、议价、成交、付款、交割、寄售、兑换、离场、尾随截杀。
- 交易物品：灵石、丹药、法宝、功法、材料、妖兽资源、符箓、阵盘、灵兽、情报、地图、秘境钥匙、传承残篇。
- 定价或竞价方式：固定价、讨价还价、起拍价、加价、拍卖溢价、黑市高价或折价、以物易物、贡献兑换、战功兑换、高阶资源交换。
- 信息传播：拍卖预告、压轴品消息、坊市传闻、商会放风、黑市情报、买家身份泄露、交易结果外传。
- 风险代价：假货、托价、压价、财富暴露、竞价结仇、尾随截杀、黑吃黑、身份暴露、执法介入、通缉、交易后被盯上。
- 后续影响：获得资源、消耗灵石或贡献、结仇、被追杀、消息扩散、势力介入、宝物转手、任务链延续。

### 特色拍卖会

- 类型示例：大型高阶拍卖、特殊规则拍卖。
- 重点：特殊准入、隔绝神识、暗标、以物换物、秘密交割、强者镇守。

### 高阶修士交换会

- 类型示例：私下交换会、临时交易会。
- 重点：熟人介绍、轮流展示、指定交换、传音议价、会后追踪。

### 坊市与店铺

- 类型示例：丹阁、器阁、材料铺、情报楼。
- 重点：入城、问价、验货、讨价还价、寄售、出售战利品、出城截杀。

### 黑市交易

- 类型示例：地下拍卖、赃物交易、禁物交易。
- 重点：暗号、伪装、销赃、禁物、黑吃黑、执法和身份暴露风险。

### 宗门兑换

- 类型示例：贡献殿、任务堂、内部交易会。
- 重点：身份权限、贡献/战功、兑换目录、长老审批、同门竞争。
```
