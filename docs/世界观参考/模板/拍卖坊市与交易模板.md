> 类型：拍卖会、坊市、黑市、商会、交换会与交易流程调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文重点整理交易流程和交易场所，不只记录买卖结果。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不写无来源固定价目表；价格只写原文明确出现的内容，没有就写相对贵贱、稀缺程度或“原文未说明”。
- 拍卖会、坊市、黑市、商会、交换会、宗门兑换等场景，要重点写清交易流程和交易场所，包括入场、验资、落座、展示、竞价、成交、交割、离场和后续风险。
- 拍卖会场所描写要围绕交易流程展开，例如入场在哪里、普通修士坐在哪里、贵宾在哪里、拍品在哪里展示、在哪里付款交割、护卫在哪里维持秩序、离场从哪里走；室内布置只写与流程、身份差异、隐私保护和风险有关的部分。
- 相同流程和风格的拍卖会只写一个代表案例即可，不需要重复堆样本。
- 如果某个交易场景有特殊交易流程、特殊交易场所、特殊准入条件、特殊商品、特殊风险或特殊后续事件，可以单独写成案例。
- 拍卖和坊市不要混成一种规则；黑市、宗门兑换、商会交易、高阶修士交换会也要分别写清差异。
- 不只写“买到了什么”，必须写交易前信息、交易过程、交易后风险和后续影响。
- 原文没有说明交易场所、准入条件、竞价方式、交割方式、价格或离场风险时，不要补，可以写“原文未说明”。

## 参考范围（不局限于以下类别）

- **交易场景**：普通拍卖会、特色拍卖会、高阶修士交换会、固定坊市、临时交易会、黑市、商会、宗门兑换殿、悬赏阁、情报楼、丹阁、器阁。
- **交易场所**：入场口、大厅、普通席、贵宾席、包厢、拍卖台、展示台、鉴宝室、后台库房、交割室、护卫位置、离场通道、坊市街道、店铺柜台、黑市入口、宗门兑换柜台、截杀地点。
- **准入条件**：请柬、验资、保证金、会员等级、贵宾资格、宗门身份、黑市暗号、介绍人、境界要求、信誉担保。
- **交易物品**：灵石、丹药、法宝、功法、材料、妖兽资源、符箓、阵盘、灵兽、情报、地图、秘境钥匙、传承残篇。
- **参与者**：散修、宗门弟子、商会、拍卖师、鉴定师、托、劫修、情报贩、执法者、隐藏身份的高阶修士。
- **交易流程**：预告、入场、验资、落座、鉴定、展示、竞价、加价、压轴品、成交、付款、交割、离场、尾随截杀。
- **价格机制**：固定价、讨价还价、起拍价、加价、拍卖溢价、黑市折价或高价、以物易物、高阶资源交换、急需溢价、压价。
- **信息传播**：拍卖预告、压轴品消息、坊市传闻、商会放风、黑市情报、买家身份泄露、宝物消息外传。
- **风险后果**：假货、托价、压价、财富暴露、尾随截杀、黑吃黑、身份暴露、执法介入、通缉、交易后被盯上。

## 完整交易场景案例

### 案例 1：普通拍卖会

交易场景类型：普通拍卖会 / 商会拍卖 / 坊市拍卖；按原文填写。

主办或控制者：商会、拍卖行、坊市管理者、宗门附属商号或地方势力；写清谁负责组织、鉴定、护卫和交割。

交易场所：写清拍卖楼位置，以及交易流程会经过的地点：入场口、验资处、普通席、贵宾席或包厢、拍卖台、拍品展示处、后台库房、鉴宝室、交割室、护卫位置、离场通道等；室内细节只写与竞价、交割、隐私保护和离场风险有关的内容。

准入流程：写清是否需要请柬、验资、保证金、贵宾身份、宗门身份、商会会员或介绍人；如果普通修士也能入场，要写清入场门槛。

交易流程：写清拍卖预告、入场、验资、落座、拍卖师开场、拍品展示、起拍价、加价规则、竞价过程、压轴品、成交确认、付款、交割、离场。

交易物品：写清丹药、法宝、材料、功法、秘境钥匙、情报、地图、灵兽、阵盘、符箓、传承残篇等；如果有压轴品，要单独写。

定价或竞价方式：起拍价、固定加价、自由加价、灵石竞价、以物抵价、临时加价、商会鉴定估价；原文没有价格就写相对贵贱和稀缺程度。

信息传播：写清拍卖预告如何传出，哪些人知道压轴品，买家身份是否隐藏，宝物消息是否在拍卖后外传。

风险代价：托价、假货、压价、财富暴露、竞价结仇、身份暴露、离场被跟踪、城外截杀、商会泄露消息等。

后续影响：获得资源、消耗灵石、结仇、被追杀、消息扩散、势力介入、宝物再次转手、引发夺宝或通缉事件。

### 案例 2：特色拍卖会

交易场景类型：特殊城市拍卖会 / 大型高阶拍卖会 / 有特殊规则的拍卖会；例如韩立在田阗城参加的拍卖会这类有特色的场景。

主办或控制者：写清主办势力、控制城市或场馆的组织、负责秩序的强者，以及拍卖会背后的商会或势力关系。

交易场所：重点写清和普通拍卖会不同的交易地点与动线，例如分流入场口、特殊验资处、隐蔽贵宾室、隔绝神识禁制、特殊展示台、单独交割室、秘密离场通道、强者镇守位置。

准入流程：写清特殊准入条件，例如高额灵石门槛、特殊请柬、贵宾令牌、身份保密、强者推荐、特定境界或势力资格。

交易流程：写清是否有预展、鉴宝、公开竞价、暗标、压轴拍品、临时加拍、以物换物、场后私下交易、单独交割等特殊流程。

交易物品：重点写清特色拍品，例如高阶丹药、稀缺材料、古宝、法宝残片、功法残篇、秘境钥匙、异族物品、特殊情报。

定价或竞价方式：写清高阶资源是否不能用普通灵石购买，是否允许以物易物，是否出现溢价、争抢、恶意抬价或临时换价。

信息传播：写清拍卖会名声、压轴品消息、特殊物品消息、参会者身份和成交结果如何传播。

风险代价：高阶修士窥探、身份暴露、离场埋伏、商会暗中记名、强者争夺、特殊物品引发长期追杀。

后续影响：特色拍卖会往往会引出后续夺宝、截杀、结盟、换地图、身份伪装、资源消化或新的冲突事件。

### 案例 3：高阶修士交换会

交易场景类型：私下交换会 / 高阶修士交换会 / 临时交易会。

主办或控制者：高阶修士、商会、宗门长老、散修圈子、临时主持者；写清主持者是否负责秩序和鉴定。

交易场所：写清交换会所在密室、洞府、包厢或禁制房间，以及隐蔽入口、主持位置、展示位置、参与者落座位置、出入口和护卫情况；重点写这些场所如何影响展示、传音议价、保密和离场。

准入流程：写清是否需要熟人介绍、境界门槛、身份保密、保证金、交换物资格、邀请令牌或临时担保。

交易流程：写清参与者轮流展示物品、说明需求、提出交换条件、他人报价、私下传音谈判、成交、未成交收回、会后私下联系。

交易物品：高阶材料、法宝、古宝、丹方、功法残篇、秘境线索、妖丹、稀缺灵草、特殊情报等。

定价或竞价方式：以物易物、指定材料交换、灵石补差、私下加价、传音议价、高阶资源不接受低阶货币。

信息传播：写清交换会是否保密，谁知道参会者身份，交易物品消息是否外泄，未成交物是否会引来追踪。

风险代价：暴露需求、暴露身家、被强者盯上、假货、交换失败、会后截杀、熟人关系破裂。

后续影响：获得关键材料、凑齐炼丹炼器资源、引出秘境线索、结识高阶修士、被尾随或卷入夺宝事件。

### 案例 4：坊市与普通店铺交易

交易场景类型：固定坊市 / 丹阁 / 器阁 / 材料铺 / 情报楼。

主办或控制者：宗门附属坊市、商会、地方势力、坊市管理者或大型店铺。

交易场所：写清坊市入口、街道、摊位区、店铺区、丹阁器阁、鉴定柜台、后院仓库、执法巡逻范围、城门和离场路线；重点写角色在哪里问价、验货、付款、出售材料和被人盯上。

准入流程：写清是否需要入城费、身份检查、坊市令牌、摊位费、商铺资格、宗门身份或缴纳税费。

交易流程：写清进坊市、找店铺或摊位、问价、验货、讨价还价、付款、收货、出售材料、寄售、鉴定、离开。

交易物品：日常丹药、低中阶材料、符箓、法器、法宝、情报、地图、功法基础本、妖兽材料等。

定价或竞价方式：固定价、讨价还价、店铺压价、批量出售、寄售抽成、地域差价、急需涨价。

信息传播：写清坊市传闻、店铺掌柜消息、摊贩口风、情报贩、出售稀缺材料后是否暴露身份。

风险代价：假货、压价、被盯梢、露财、黑店、执法势力介入、出城后截杀。

后续影响：角色获得修炼物资、处理战利品、获取情报、暴露财富、被商会记住或引发后续追踪。

### 案例 5：黑市交易

交易场景类型：黑市 / 地下拍卖 / 私下赃物交易。

主办或控制者：黑市势力、邪修组织、商会暗线、地下坊市、情报组织。

交易场所：写清黑市入口、暗号验证点、隐蔽街区、地下大厅、私人交易室、黑市拍卖台、护卫位置、暗门、逃生通道、遮掩身份的阵法或面具；重点写这些地点如何服务验证身份、交易、销赃、逃离和黑吃黑。

准入流程：写清暗号、介绍人、保证金、身份伪装、面具、令牌、黑市时间、进入地点变化等。

交易流程：写清进入、验证身份、展示或询价、鉴定、议价、付款、交割、快速离场、销赃或购买禁物。

交易物品：赃物、禁药、邪道材料、通缉物、情报、奴仆、灵兽、秘境地图、来历不明的法宝或功法。

定价或竞价方式：黑市高价、急需高价、赃物折价、以物易物、情报换物、私下议价。

信息传播：写清交易是否保密，黑市是否会泄露客户，禁物消息是否引来执法势力或仇家。

风险代价：黑吃黑、假货、被钓鱼执法、身份暴露、被邪修盯上、赃物原主追查、离场截杀。

后续影响：角色获得禁物或情报，也可能引发通缉、追杀、身份暴露、赃物溯源或黑市势力牵连。

### 案例 6：宗门兑换与内部交易

交易场景类型：宗门兑换 / 贡献兑换 / 内部交易会。

主办或控制者：宗门、任务堂、贡献殿、丹堂、器堂、藏经阁、长老或执事。

交易场所：写清任务堂、贡献殿、兑换柜台、功法架、丹药库、法宝库、长老值守位置、排队区域、禁制和身份验证方式；重点写弟子在哪里登记、审核、扣贡献、领取资源和被同门看见。

准入流程：写清弟子身份、贡献点、战功、任务凭证、境界要求、权限等级、长老批准或名额限制。

交易流程：写清上交任务物、登记贡献、查看兑换目录、申请兑换、审核权限、扣除贡献、领取资源、借阅功法或进入修炼设施。

交易物品：丹药、材料、法器、法宝、功法、闭关室资格、秘境名额、师长指点、护法资源、任务情报。

定价或竞价方式：贡献兑换、战功兑换、内部固定规则、名额竞争、长老审批、任务优先级。

信息传播：写清兑换稀缺资源是否会被同门知道，任务奖励是否公开，名额争夺是否引发派系关注。

风险代价：贡献不足、权限不够、被同门抢名额、长老压制、宗门克扣、兑换记录暴露身家。

后续影响：获得修炼资源、突破准备、功法提升、同门竞争、派系站队、任务链延续或宗门内部矛盾。
