# 生灵与妖兽材料分析模板

## 适用范围

本模板用于整理作品中明确出现、能够从妖兽、生灵或特殊血脉个体中独立取得或明确脱离的妖丹、魔核、血液、精血、血液精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶及其他生灵来源原料。

本模板只分析离体材料本身，不展开来源生灵的完整物种设定、人物设定、坐骑关系、血脉身份、战斗能力或能力本体。完整生灵、异火兽火、灵植、矿物、灵能资源、天然灵液、丹药、法宝、符箓、功法、武器、傀儡和阵法分别放入对应专题；下游成品只在“用途/下游去向”中简要说明。

## 整理原则

1. 先做准入判定：对象必须是已经独立取得、明确可脱离或作品明确作为原料处理的生灵来源材料；只有“可能取材”“具有潜在价值”“仅观察到身体部位”“仍在来源体内”或“完整生灵本身”不得建卡。
2. 按对象形态划清边界：妖丹、魔核、精血、骨骼、鳞甲等归本模板；固定池体、非血液液体、异火兽火、矿物、灵植、能力状态和成品转入对应专题。来源生灵只作为来源关联，不在本卡展开。
3. 一物一卡：同名、别名、同物异名、不同来源境界、血脉、完整度、鲜度和品质归入同一卡，在对应字段中分项记录差异；只有形成独立名称、独立性质和独立用途的派生材料才另建卡，并写清原材料关系。
4. 字段只写字段相关内容：不跨字段重复堆叠，不引入无关人物、地点、战斗招式、对白、交易过程或剧情流水账；不设置或展开使用记录、事件记录和逐条过程日志。
5. 按关键材料链整理：只保留“来源与形成 -> 独立取得 -> 初始状态 -> 处理净化 -> 保存储运 -> 使用条件 -> 作用结果 -> 残留、消耗或派生物”的必要节点，不把每次取得、使用或加工拆成多张卡。
6. 分开记录来源、状态、规格与属性：来源物种和境界不等于材料品质；当前状态不等于持有剧情；五行药性、本征属性、寒热偏性、毒性、血脉特征和外观分别记录，不互相推断或替代。
7. 风险覆盖材料全流程：除使用风险外，还应记录取得风险、来源损伤或死亡、处理失败、保存失败、权属争议、族群禁忌、强制取材、尸体或灵魂利用及作品内可确认的追责后果；不进行脱离文本的价值评判。
8. 信息不足时如实标注并保持简洁：使用“原文明确”“实际表现”“人物评价或传闻”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不得根据名称、颜色、来源境界、现实常识或同类设定补齐属性、用途和分数。

## 信息与输出规则

1. 事实与推断分开：来源、形成、产出、适配、价值和属性等结论只写已确认内容；传闻、人物判断和上下文推断放入“信息依据与判断边界”，并说明判断理由、替代解释和不确定处。
2. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留结论内容和确定性类型。
3. 关键案例不写具体事件清单：只写材料链的最短状态变化，不记录人物逐步行动、战斗过程、对白、完整炼制过程或逐条使用过程。
4. 输出前自检：检查是否存在独立离体材料、来源部位和实际取得方式；检查完整生灵、潜在材料、能力状态、成品和跨专题对象是否误收；检查重复卡、派生关系、属性边界、风险范围、字段完整性和未知项是否规范。

## 字段说明

- 子类：填写妖丹、魔核、血液、精血、血液精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶或其他生灵来源材料。
- 别名/同物异名：填写同一材料的俗称、异称和不同来源称呼；已经形成独立性质的派生材料另行记录，不与同物异名混淆。
- 准入理由：说明对象为何是已经独立取得、明确脱离或明确作为原料处理的生灵来源材料；仅有潜在取材价值或仍在来源体内时应写排除理由。
- 来源物种/个体：填写产生或承载材料的妖兽、灵兽、魔兽、真灵、修士或其他生灵；来源生灵本体设定放入对应专题。
- 来源部位/存在形态：填写体内核心、血液、池中汇聚的血液精华、骨、鳞、皮、角、筋、囊、结晶或魂体残留，并注明是否已独立离体。
- 来源境界/血脉：填写来源对象的境界、阶位、血脉、变异和成熟阶段；不直接把来源层级当作材料品质或药力。
- 形成机制/生成条件：填写材料在来源生灵体内或相关环境中形成、成熟、分泌、蜕落、凝聚、结晶或富集的条件；无法证明形成机制时写“原文未说明”。
- 取得方式/产出规律：填写猎杀、自然脱落、蜕皮、取血、抽取、交易、遗骸发现或其他实际取得方式，以及取得时机、单次产量、产出周期、能否重复取得、对来源个体的损伤或死亡影响和脱离时的初始状态；遇见、乘坐、战斗、守护或召唤不等于取得材料。
- 外观描述：填写材料离体后可直接观察到的颜色、形状、大小、质地、气味、纹理和灵光，不重复记录完整度、鲜度或品质等级。
- 内部结构/关键组分/基础物性：填写组织层次、核心、髓质、纤维、囊壁、晶体、杂质、活性集中部位、内部灵纹或能量结构，以及硬度、韧性、弹性、黏度、浓度、相态、导能和承载等基础性质；只填写有内容的项目。
- 当前状态：填写观察时的完整、破损、鲜活、凝固、干枯、失活、污染、纯净、封存或其他状态，以及状态对可用性的已确认影响；不写当前持有者的剧情行动。
- 规格/计量/品质判据：填写枚、滴、瓶、斤、块、部位等计量方式，单体或批次数量、纯度、品级、可用比例和品质判定理由；不重复来源境界、血脉和当前完整度。
- 残余能量/意志：填写材料中残留的妖力、血脉力量、残魂、怨念、狂暴能量、灵性和排异倾向，以及这些内容对材料状态和使用的直接影响。
- 五行药性/本征属性：作为药材时填写金、木、水、火、土药性；作为炼器、制符、布阵或修炼材料时填写五行、雷、冰、阴阳等本征属性；药性、属性和血脉特征分别说明。
- 寒热偏性：填写材料本体及接触、吞服、炼化、移植或处理时呈现的大寒、寒、凉、平、温、热、大热或作品自定义偏性；不得由五行、名称或颜色反推。
- 外界响应与状态演变：填写材料随时间、温度、湿度、灵气、光照、容器、污染、阵法或相邻材料发生的吸收、释放、共鸣、凝固、干枯、腐坏、失活、异变或极端变化，以及变化条件、顺序、速度、阈值、可逆性和产物。
- 处理/净化与状态转化：填写放血、分割、清洗、去毒、提纯、浓缩、炼化、封魂或其他主动处理方式，以及处理前后形态、属性、活性、品质、损耗、副产物和失败结果；不展开完整炼丹、炼器或战斗过程。
- 保存/储运与稳定性：填写保存容器、温度、灵气、封禁、包装、运输和交接要求，以及保存期限、灵性流失、挥发、污染、破损、失活和储运失败后的处置；仍在来源体内不属于保存方式。
- 适用对象/境界/阶段：填写明确适用或不适用的物种、体质、血脉、修炼境界、加工者能力和工艺阶段；仅凭强者身份或名称推定时写“上下文推断”或“原文未说明”。
- 直接使用方式/条件/用量：填写吞服、炼化、移植、沐浴、外敷或其他直接使用途径，以及剂量、浓度、前置处理、使用环境、配合手段和禁忌；没有实际使用或明确用途时不要写成可用方案。
- 作用过程/核心效果/后续变化：填写材料如何被激活、吸收、转化、承载或释放力量，作用对象和部位、起效与持续过程、补充能量、淬体、强化血脉或其他直接效果，以及效果衰退、永久或临时改变、反弹和残留；下游成品效果只写在对应专题。
- 用途/下游去向：填写已经发生或原文明示的炼丹、炼器、制符、布阵、血祭、修炼、交易和任务用途，以及独立派生材料、下游成品、正常副产物、使用后残留和最终消耗方式；“可作为”但未被确认的用途应标为推断或不写。
- 限制、风险与异常处置：按取得、处理、保存和使用阶段填写血脉冲突、残魂反噬、污染、爆裂、失控、保存失败、使用失败、势力追责及其他风险；同时记录来源损伤或死亡、是否自愿或强制、族群禁忌、尸体或灵魂利用、权属争议、黑市或宗门态度以及作品内可确认的追责后果。
- 关键案例与变化链：只填写能够验证材料形成、独立取得、处理、保存、使用、失效或派生关系的最短链条，按“初始状态 -> 关键变化 -> 结果状态 -> 后续去向”记录；没有连续材料链时写“原文未说明”，不展开具体事件或来源生灵设定。
- 稀有度/供给稳定性：按来源物种、单次产量、产出周期、可重复取得性、地域或势力限制及作品评价填写，区分来源罕见、产量稀少、难以取得和供应不稳定；不因价格或强者境界直接推定稀有。
