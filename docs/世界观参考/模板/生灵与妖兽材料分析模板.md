# 生灵与妖兽材料分析模板

## 适用范围

本模板用于整理作品中明确出现的妖丹、魔核、血液、精血、血池内可独立取用的血液精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶及其他来自生灵的原料。

本模板只分析从妖兽、生灵或特殊血脉个体取得的材料，不展开来源生灵的完整物种设定、人物设定或战斗能力。灵植、矿物、灵能资源、天然灵液和天地奇物分别放入对应材料模板；下游成品只在“用途/下游去向”中出现。

## 整理原则

1. 先做准入判定
   对象应当是从妖兽、生灵或特殊血脉个体取得的可用原料。完整妖兽、人物或具备稳定物种、生理结构和完整生物行为的对象不得建立本模板卡片。

2. 按对象形态划清边界
   妖丹、精血、骨骼、鳞甲等归本模板。血池中的可独立取用血液或血液精华归本模板；固定池体、可移动池体和非血液性质的液体按其自身存在形态放入其他对应模板。来源生灵与下游丹药、法宝、符箓和阵法只作关联，不在本卡中展开完整设定。

3. 统一名称并实行一物一卡
   同名、别名、同物异名以及不同来源境界、血脉、完整度、鲜度和品质的同一材料归入同一卡，在对应字段中分项记录差异。加工、凝聚或异变后形成具有独立名称、性质和用途的新资源时，可另建派生物卡，并与原材料相互关联。

4. 按完整材料链整理
   依次记录对象身份、来源与形成、取得与脱离、静态构成、当前状态与本征属性、外界响应与状态演变、处理与保存、使用与作用、异常与极端状态、后续变化和下游去向。对不会离体生长的骨、鳞、角等材料，以其在来源生灵体内的形成和成熟代替“成长”；对精血、毒液、魂晶、血池精华等材料，重点记录富集、凝聚、活性维持和衰变。

5. 区分来源、状态与品质
   来源物种、境界和血脉记录材料的来源条件；当前状态记录观察时的完整度、鲜度、活性和污染；规格与品质记录材料自身的计量、纯度、等级和判定结果。不得在多个字段重复抄写同一信息。不同状态会改变属性、用途、作用效果或风险时，在相应字段中分项说明。

6. 分开记录药性、本征属性与寒热偏性
   可入药、吞服、浸泡或移植的材料记录五行药性与寒热偏性；用于炼器、布阵、制符或血脉承载的材料同时记录五行、雷、冰、阴阳等本征属性。寒性不自动等于水属性，血液也不自动判为火属性或温热。

7. 按阶段记录异常与处置
   材料自身在时间或环境中的异常写入“外界响应与状态演变”；处理失败、损耗和副产物写入“处理/净化与状态转化”；保存和运输失败写入“保存/储运与稳定性”；取得、使用、势力追责及未被前述字段涵盖的异常统一写入“限制、风险与异常处置”。极端状态应记录触发条件、变化过程、结果、可逆性和已知处置方式，避免只写笼统的“危险”。

8. 保留材料流转和实际变化链
   记录取得、分割、净化、去毒、封魂、保存、直接使用、交易、消耗、派生物、残留物和加工去向。关键案例只概括实际发生的状态变化和结果，用于串联材料链，不展开来源生灵或下游成品的完整设定。

9. 保持字段完整并在输出前自检
    每张卡必须使用本模板的全部字段。没有可靠内容时写“原文未说明”；本次整理范围不足时写“本次未覆盖到明确内容”；确实不适用时写“不适用”。输出前检查四个章节是否齐全，准入和对象分层是否正确，同物是否重复建卡，来源、形成、状态和品质是否混淆，五行药性与寒热偏性是否混淆，作用过程与风险是否重复或矛盾，以及案例区是否只保留实际输出字段和示例内容。

## 字段说明

- 子类：填写妖丹、魔核、血液、精血、血池精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶或其他生灵材料。
- 别名/同物异名：填写妖丹/内丹、魔核/魔晶等同物异名，区分同物异名与已经形成独立性质的派生材料。
- 准入理由：说明对象为何是从妖兽、生灵或特殊血脉个体取得的可用原料。
- 来源物种/个体：填写来源妖兽、灵兽、魔兽、真灵、修士或其他生灵。
- 来源部位/存在形态：填写体内核心、血液、池中汇聚的血液精华、骨、鳞、皮、角、筋、囊、结晶或魂体残留。
- 来源境界/血脉：填写来源对象的境界、阶位、血脉、变异和成熟阶段。
- 形成机制/生成条件：填写材料在来源生灵体内或相关环境中如何形成、成熟、分泌、蜕落、凝聚、结晶或富集，以及所需境界、血脉、时间、生命阶段、死亡条件或环境条件。
- 取得方式/产出规律：填写猎杀、自然脱落、蜕皮、取血、抽取、交易或遗骸发现等取得方式，以及取得时机、单次产量、产出周期、能否重复取得、对来源个体的损伤或死亡影响和脱离时的初始状态。
- 外观描述：填写可直接观察到的颜色、形状、大小、质地、气味、纹理和灵光，不重复记录完整度、鲜度或品质等级。
- 内部结构/关键组分/基础物性：填写组织层次、核心、髓质、纤维、囊壁、晶体、杂质、活性集中部位、内部灵纹或能量结构，以及硬度、韧性、弹性、黏度、浓度、相态、导能和承载等基础性质；不同材料只填写适用项目。
- 当前状态：填写观察时的完整、破损、鲜活、凝固、干枯、失活、污染、纯净、封存或其他状态，并注明不同状态对可用性的已知影响。
- 规格/计量/品质判据：填写枚、滴、瓶、斤、块、部位等计量方式，单体或批次数量、纯度、品级、可用比例和品质判定依据；来源境界、血脉和当前完整度只在对应字段记录。
- 残余能量/意志：填写妖力、血脉力量、残魂、怨念、狂暴能量、灵性与排异倾向的来源和表现。
- 五行药性/本征属性：填写材料作为药材时的金、木、水、火、土药性，以及作为炼器、制符、布阵或修炼材料时的五行、雷、冰、阴阳等本征属性；药性与其他用途的属性不同则分别说明。
- 寒热偏性：填写材料本体及其在接触、吞服、炼化、移植或处理时呈现的大寒、寒、凉、平、温、热、大热或作品自定义偏性；不得由五行属性反推。
- 外界响应与状态演变：填写材料随时间、温度、湿度、灵气、光照、容器、污染、阵法或相邻材料发生的吸收、释放、共鸣、凝固、干枯、腐坏、失活、异变或极端变化，以及变化的触发条件、顺序、速度、阈值、可逆性和产物。
- 处理/净化与状态转化：填写放血、分割、清洗、去毒、提纯、浓缩、炼化、封魂或其他主动处理方式，以及处理前后形态、属性、活性、品质、损耗、副产物和失败结果的变化。
- 保存/储运与稳定性：填写保存容器、温度、灵气、封禁、包装、运输和交接要求，以及保存期限、灵性流失、挥发、污染、破损、失活和储运失败后的处置。
- 适用对象/境界/阶段：填写明确适用或不适用的物种、体质、血脉、修炼境界、加工者能力和工艺阶段。
- 直接使用方式/条件/用量：填写吞服、炼化、移植、沐浴、外敷或其他直接使用途径，以及剂量、浓度、前置处理、使用环境、配合手段和禁忌。
- 作用过程/核心效果/后续变化：填写材料如何被激活、吸收、转化、承载或释放力量，作用对象和部位、起效与持续过程、补充能量、淬体、强化血脉或其他正常效果，以及效果衰退、永久或临时改变、反弹和残留。
- 用途/下游去向：填写炼丹、炼器、制符、布阵、血祭、修炼、交易和任务用途，以及加工后形成的独立派生材料、下游成品、正常副产物、使用后残留和最终消耗方式。
- 限制、风险与异常处置：按取得、处理、保存和使用阶段填写血脉冲突、残魂反噬、污染、爆裂、失控、保存失败、使用失败、势力追责及其他风险，并记录异常或极端状态的征兆、结果、可逆性和已知处置方式。
- 关键案例与变化链：简要填写能够验证材料链的一次实际形成、取得、处理、保存、使用、失效或派生事件，按初始状态、关键变化、结果和后续影响串联；没有连续事件时写“原文未说明”。
- 稀有度/供给稳定性：按来源物种、单次产量、产出周期、可重复取得性、地域或势力限制及作品评价填写，区分来源罕见、产量稀少和供应不稳定。
