# 符师模板

## 适用范围

用于整理作品中的符师职业，以及与制符流程高度相关的制符师、符箓师、符宝炼制者、符文传承、符纸符墨制作、传讯符、遁符、防御符、攻击符、封印符、血符、魂符、符阵结合、一次性术式载体等内容。

本模板关注“符师职业如何运转”：传承获取、材料准备、制符环境、绘制注灵、封存携带、激活使用、失败反噬、售卖交换和职业成长闭环。具体符箓名称、一次性效果、价格和适用境界，可在物品或战斗机制文档中细化。

本模板不展开炼丹、炼器、阵法流程中的符文/阵纹/禁制底层应用：丹药上的丹纹和封药符纹放入 `炼丹师模板.md`，器物上的铭文、阵纹和认主禁制放入 `炼器师模板.md`，阵法结构中的符文节点、阵眼阵基和破阵解纹放入 `阵法师模板.md`。本模板侧重独立符箓、符宝、符牌、符纸等可携带、可预制、可消耗的术式载体。

## 前置声明

- 覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角或成功案例。
- 只写原文、资料来源或可靠依据能支撑的内容。缺失字段写“原文未说明”，不得为补齐体系而虚构。
- 案例只是最低写法示范，不是数量上限；有价值的职业分支、流程细节和失败样本都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充来源，成熟后转为 `### 案例`。
- 与炼丹、炼器、阵法重叠时，只记录独立符箓和制符职业相关内容，其余转入对应模板。

## 案例

### 案例

#### 特殊手段案例：符箓 / 符宝 / 符阵结合

- **案例名称和类型**：如虚空画符、血符、符宝、遁符保命、符阵结合。
- **使用者**：人物、身份、境界、符师水平、所属势力。
- **使用场景**：战斗、逃亡、传讯、封印、宗门任务、秘境探索、交易或救援。
- **前置条件**：符方、材料、工具、精血、魂魄、灵石、神识、法力、传承或预制时间。
- **具体过程**：写绘制、封存、携带、激活、命中或维持效果；不要只写“符箓发动”。
- **产出或效果**：写实际效果，以及与普通符箓的差异。
- **代价与风险**：写符毁、反噬、误触、耗尽、污染、保存失败、被识破或失控。
- **限制**：写是否限本人、符方、血脉、神识、境界、载体、口诀或距离范围。
- **可参考点**：写低阶保命、一次性消耗经济、传讯网络、战斗准备、越级反制或任务奖励价值。
