# 符师模板

## 适用范围

本模板用于整理作品中明确存在的符师职业、制符师、符箓师、符宝炼制者、符纸符墨制作者，以及具备可学习知识、重复生产流程、人员角色、组织分工或稳定传承的制符体系与职业分支。

本模板重点不是单独收集符箓条目，也不是把所有带“符文、符号、纹路、印记”的描写都归为符师职业。本模板重点分析“玩家如果选择符师职业，这个职业在小说世界里如何运转”：从职业起源、知识传承、入行培养、组织分工、资源供应、工具环境、接受需求、设计制符、注灵封存、质量检验、保存交付、产能和成功率、成本收益、职业互动、异常风险，到成长、衰退、退出、继承及最终影响的完整闭环。

炼丹、炼器、阵法流程中的符文、阵纹、禁制、铭文、丹纹、器纹和法阵节点，不放入本模板。丹药、药方、药材和炼药流程不写成符师卡；器物铭文、认主禁制和炼器流程不写成符师卡；阵眼、阵基和破阵解纹不写成符师卡。只有原文明确存在制符职业、人员身份、可复用知识、符箓传承或重复生产闭环时，才进入本模板；单张可携带、可预制、可消耗或可激活的术式载体，本身不足以证明符师职业成立。

若作品没有明确符师职业，只出现血符、魂符、符印、封印符文、灵魂符文、临战画符或单件符宝，应转入 `符箓分析模板.md`。只有这些特殊符法进一步证明存在可学习技艺、稳定制作者角色、重复生产过程或持续传承时，才可作为符师职业的特殊分支或个人样本；不得用炼药师、炼器师、阵法师或普通修炼体系硬填符师字段。

## 整理原则

1. 一对象一卡
   先明确卡片分析的是整体职业体系、职业分支、制符组织还是个人样本；同一分析对象的别名、阶段变化和后续补充必须归并到同一张卡，不得把某位符师的个人经历直接写成整个职业体系的共性。
   禁止另建“某某（补充）”“某某后期”“某某别名”等重复卡；阶段变化写入同卡的“职业生命周期与变化”。

2. 字段完整  
   每张卡必须包含：分析层级与职业定位、纳入依据、信息依据与确定性、体系起源与历史、知识与技能体系、入行条件与培养认证、组织结构与职业互动、产品与服务范围、资源投入与供应、工具/设施/作业环境、生产/服务流程与质量控制、产品分层与质量差异、产能/成功率/结果、成本/收益/流通、异常/损失/极端风险、职业生命周期与变化、职业影响与最终结果、边界说明。
   禁止空字段。原文没有说明、检查范围内没有发现、材料尚未覆盖或该对象客观上不具有某一环节时，应分别填写“原文未说明”“未检出”“未覆盖”或“不适用”。

3. 先做主题门控  
   只有符师、制符、符纸符墨制作、符方与符文传承、符宝炼制等内容能够证明存在职业身份、知识体系、重复生产、培养传承或组织分工时，才写成符师卡。
   只出现单张符箓、一次临战画符、炼药、药材、丹药、炼器、阵法、纹路、族纹、印记、文字或符号比喻时，不写成符师职业卡；单张符箓和特殊符法按实际形态转入对应模板。

4. 边界分层清楚  
   必须区分符师职业、制符流程、符箓物品、符宝炼制、临战符法、封印符文、族纹印记、阵法纹路、器物铭文和普通文字。  
   具体符箓的载体、激活、运行机制、效果和失效方式主要写入 `符箓分析模板.md`；本模板只概述职业能够提供的产品与服务、生产能力和质量结果。边界不清时，在“边界说明”中写明不确定性，不要把相邻职业内容套进符师字段。

5. 职业生命周期闭环优先
   优先写清职业如何产生、知识如何构成和传承、人员如何入行和晋升、组织如何分工、资源如何供应、需求如何进入生产流程、成品如何检验和交付、产能与成功率如何、如何定价流通并与外界互动，以及事故、强行制符、衰退、退出、继承和职业影响。
   单张符箓的战斗效果不能替代职业体系分析；没有上升成长、衰退或最终影响时，不得根据常见职业模型补写。

6. 样本覆盖均衡  
   样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界、少数名场面或少数成功案例。  
   低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都可纳入样本。

7. 不虚构设定  
   不得为了补齐职业等级、境界梯度、制符流程、材料体系、价格体系、收益方式或失败后果而自行虚构。  
   职业起源、知识结构、组织分工、产能、成功率、价格、关系、事故、衰退和影响应分别判断依据与确定性。应区分旁白直接说明、符书或符方文本、符师讲解、实际制符表现、交易记录、他人评价和上下文直接推断；必要时附章节、段落或情节锚点，不能用整张卡的一个“原文明确”覆盖所有字段。

8. 输出简化  
   保留职业判断所需的起源、知识、培养、组织、产品、资源、流程、质量、产能、流通、风险、生命周期和影响，不展开无关剧情背景。
   不把炼药材料价格、丹药炼制流程、器物铭文、阵法符文等相邻体系写成符师案例，也不长篇复述单张符箓的战斗过程。

## 字段说明

- 分析层级与职业定位：先写本卡分析的是整体符师职业体系、职业分支、制符组织还是个人样本，再写符师、制符师、符箓师、符宝炼制者、符纸符墨制作者等具体身份、职责边界和彼此关系；个人表现不得直接写成职业共性。
- 纳入依据：写为什么进入符师模板，如原文明确存在符师身份、可复用制符知识、人员培养、重复生产流程、组织分工或稳定传承；只有单张符箓或一次临战符法时不满足职业准入。
- 信息依据与确定性：分别标注信息来自旁白直接说明、符书或符方文本、符师讲解、实际制符表现、交易记录、他人评价、上下文直接推断或尚未说明，必要时附章节、段落或情节锚点；不同结论依据不同时分别说明。
- 体系起源与历史：写符师职业或该制符体系由谁、何时、因何需求产生，早期用途、知识源头、重要改革、分支形成、兴盛衰落及相关宗门、家族、地域或族群；原文只说明传承归属而没有创始过程时，不补写历史。
- 知识与技能体系：写符文理论、符方、材料辨识、绘制、注灵、封存、检验、修复等知识和技能，以及它们通过师承、宗门藏书、残篇、交易、抢夺、自创或逆向研究等方式获得和传承；同时说明知识是否完整、保密、分级或存在缺失。
- 入行条件与培养认证：写境界、灵根、神识、血脉、稳定性、材料辨识、符文理解、传承资格等准入条件，以及学徒培养、临摹练习、考核认证、晋升标准、失败淘汰和独立制符标志；不同阶段条件不同时分别说明。
- 组织结构与职业互动：写符师以散修、宗门弟子、供奉、符房成员、商铺经营者或军队后勤等何种方式活动，以及内部师徒、等级、分工、管理、保密和利益关系；同时记录作业场景，以及与客户、宗门、同行、材料商、相邻职业、执法机构和符箓使用者之间的合作、依赖、竞争、冲突、监管与声誉变化。
- 产品与服务范围：写该职业能够制作、修复、鉴定或定制的纸符、玉符、符牌、符宝、令符、血符、魂符等产品，以及符方抄录、封印、传讯网络、战场补给或其他明确服务；单张符箓的详细机制和效果写入 `符箓分析模板.md`。
- 资源投入与供应：写符纸、符墨、灵石、精血、魂力、法力、神识、特殊载体和时间等会被消耗或占用的资源，以及来源、供应稳定性、稀缺程度、替代方案和断供影响；符笔、符桌等可重复使用对象写入“工具/设施/作业环境”。
- 工具/设施/作业环境：写符笔、符刀、符桌、制符台、符房、静室、阵法辅助、禁制保护、保存容器，以及灵气、温度、湿度、场地安全或临战环境等作业条件；区分必需条件、辅助条件和便携替代方案。
- 生产/服务流程与质量控制：按需求或委托、符方选择或设计、材料准备、载体处理、绘制、注灵、封存、检验、品级判定、废品处置、保存包装、交付或自用、使用反馈和返修等环节整理；激活和命中目标只在符师同时负责现场施用时填写。
- 产品分层与质量差异：写不同载体、品阶、品质、完整品、残次品、废符、标准品、定制品、新品、残旧品、修复品、一次性、多次使用或可充能产品在成本、保存、可靠性、激活条件、威力、可携带性和目标客户上的差别。
- 产能/成功率/结果：写单位时间产量、单次或批量生产能力、成功率、成品率、质量稳定性、能够制作的最高品阶、交付结果及失败品比例；产品功能只做攻击、防御、传讯、封印等类型概述，不重复展开单张符箓效果。
- 成本/收益/流通：写材料、时间、人工和设施成本，售价、委托费、宗门贡献、任务奖励、利润或亏损，以及坊市、宗门、拍卖、军需等流通渠道、市场需求、价格波动、稀缺溢价和回本情况。
- 异常/损失/极端风险：分别写生产异常、产品异常、人身损失、经营风险和极端事故，如断笔、符路错误、注灵或封存失败、误触、失效、反噬、法力耗尽、精血损耗、魂魄污染、材料断供、泄密、假符、声誉受损、强行炼制越阶符箓、符房爆毁、禁术失控或死亡；正常资源成本不在此重复填写。
- 职业生命周期与变化：写入行、学徒、独立制符、晋升、转职、创新、自创符方、形成分支、能力衰退、伤病、失去资格、退出、退休、死亡、知识残缺或失传、收徒继承、组织分裂及职业分支消亡等全过程；无明显变化时写“原文未说明明显变化”。
- 职业影响与最终结果：写符师职业对个人身份、财富、修为和生存造成的长期结果，以及对宗门后勤、战争、通信、贸易、封印体系、地方经济、资源消耗、权力结构、环境和社会安全产生的实际影响；区分已经发生、人物评价和合理推断。
- 边界说明：写为什么属于符师职业或制符体系，而不是单张符箓、炼丹、炼器、阵法、族纹、器物铭文、普通文字或单纯战斗招式；边界不清时写明不确定性和建议归入的其他模板。
