# 符师模板

# 规范

用于整理作品中的符师职业，以及与制符流程高度相关的制符师、符箓师、符宝炼制者、符文传承、符纸符墨制作、传讯符、遁符、防御符、攻击符、封印符、血符、魂符、符阵结合、一次性术式载体等内容。

本模板重点不是单独收集符箓条目；具体符箓名称、一次性效果、价格和适用境界可以在物品或战斗机制文档中继续细化。本模板重点分析“玩家如果选择符师职业，这个职业在小说世界里如何运转”：从获取符方或符文传承、准备符纸符墨、选择环境、使用符笔、绘制符文、注入法力或神识、封存符力、保存携带、激活使用、失败反噬、售卖交换到职业成长的完整闭环。

本模板不负责分析炼丹、炼器、阵法流程中的符文/阵纹/禁制底层应用：丹药上的丹纹和封药符纹放入 `炼丹师模板.md`，器物上的铭文、阵纹和认主禁制放入 `炼器师模板.md`，阵法结构中的符文节点、阵眼阵基和破阵解纹放入 `阵法师模板.md`。本模板侧重独立符箓、符宝、符牌、符纸等“可携带、可预制、可消耗的术式载体”的制作、保存、交易和使用。

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的符师职业、制符流程、职业分支、符文传承、工具设施、制符环境、操作手法、特殊手段、收益方式和失败后果，不编造小说中不存在的职业体系。

整理时应按职业分支、制符环节、符箓用途和适用境界尽可能覆盖完整：每一种职业分工、每一类符箓用途、每一个境界阶段，只要小说中有对应内容，都应尽量写入对应段落。文档长度不设上限，宁可写长，也不要为了压缩篇幅遗漏有参考价值的职业样本、流程细节和失败案例。

如果某类职业分支、某个境界阶段，或输入资源、符方获取途径、工具设施、制符环境、操作手法、特殊手段、成符结果、限制/失败后果等字段在小说中没有可靠依据，可以写“原文未说明”；不得为了补齐职业等级、境界梯度、制符流程或数值体系而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 职业定位与分支：写符师、制符师、符箓师、符宝炼制者、符纸符墨制作者等身份差异、职责边界和适用境界。
- 处理对象：写符箓、符宝、符牌、符纸、血符、魂符、传讯符、遁符、防御符、攻击符、封印符等可携带或可预制的术式载体。
- 输入资源：写符纸、符墨、符笔、灵石、精血、魂魄、法力、神识、特殊载体和预制时间等制符消耗。
- 获取途径：写符方、符文传承、师承、宗门藏书、坊市购买、遗迹收获、任务奖励、交易或抢夺等获得方式。
- 工具与环境：写制符台、静室、阵法辅助、灵气环境、禁制保护、保存容器等工具设施和环境要求。
- 操作者门槛：写境界、神识、灵根、血脉、手法、经验、职业等级或资格限制。
- 制符流程：写准备、绘制、注灵、封存、检验、保存、携带、激活和异常处置。
- 载体差异：写普通符、符宝、玉符、符牌、符阵结合、临时虚空画符等载体差异和限制。
- 产出与效果：写攻击、防御、遁逃、传讯、封印、召唤、治疗、定位、隐匿等结果。
- 代价与风险：写符毁、反噬、误触、保存失败、法力耗尽、污染、失控、被识破等后果。
- 收益方式：写售卖、交换、任务奖励、宗门供给、战斗保命、越级反制和传讯网络价值。
- 出现场景：写宗门符房、坊市符铺、拍卖会、战场补给、秘境准备、逃亡保命、洞府闭关、传讯系统、封印现场、散修交易等场景。
- 适用境界：按作品自己的境界体系写符师入门、独立制符、高阶符箓、符宝或特殊制符手段对应的阶段。

- 输入资源：精血、魂魄、符方、符纸、符墨、符笔、灵石、神识、法力、特殊传承、提前预制时间或符宝载体。
- 获取途径：师承、家族传承、宗门传承、古符残片、秘境机缘、拍卖交易、抢夺、自创或残符补全。
- 工具与环境：符笔、符刀、符桌、静室、封存盒、传讯阵台、灵气稳定处、战场临时环境或符阵节点。
