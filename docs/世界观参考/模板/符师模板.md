# 符师模板

## 适用范围

本模板用于整理作品中的符师职业，以及与制符流程高度相关的制符师、符箓师、符宝炼制者、符文传承、符纸符墨制作、传讯符、遁符、防御符、攻击符、封印符、血符、魂符、符阵结合、一次性术式载体等内容。

本模板重点不是单独收集符箓条目，也不是把所有带“符文、符号、纹路、印记”的描写都归为符师职业。本模板重点分析“玩家如果选择符师职业，这个职业在小说世界里如何运转”：从获取符方或符文传承、准备符纸符墨、选择环境、使用符笔、绘制符文、注入法力或神识、封存符力、保存携带、激活使用、失败反噬、售卖交换到职业成长的完整闭环。

炼丹、炼器、阵法流程中的符文、阵纹、禁制、铭文、丹纹、器纹和法阵节点，不放入本模板。丹药、药方、药材和炼药流程不写成符师卡；器物铭文、认主禁制和炼器流程不写成符师卡；阵眼、阵基和破阵解纹不写成符师卡。只有当原文明确表现为可携带、可预制、可消耗、可激活的术式载体，或明确存在制符职业、符箓传承、符纸符墨、符笔、符宝炼制等职业闭环时，才进入本模板。

若作品没有明确符师职业，但出现血符、魂符、符印、封印符文、灵魂符文、临战画符等特殊符法，可以作为“特殊符箓/符宝案例”整理；必须写清其不是完整职业体系，不得用炼药师、炼器师、阵法师或普通修炼体系硬填符师字段。

## 整理原则

1. 一体系一卡  
   同一符师体系、同一职业分支、同一符法传承、同一类特殊符箓或符宝，应归并到同一张卡。  
   禁止另建“某某（补充）”“某某后期”“某某别名”等重复卡；阶段变化写入同卡的“职业成长与变化”。

2. 字段完整  
   每张卡必须包含：职业定位与分支、纳入依据、处理对象、输入资源、获取途径、工具与环境、操作者门槛、制符流程、载体差异、产出与效果、代价与风险、收益方式、出现场景、适用境界、职业成长与变化、边界说明。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

3. 先做主题门控  
   只有符师、制符、符箓、符纸、符墨、符笔、符方、符文传承、符宝、灵符、法符、符书、符法、血符、魂符、玉符、符牌、符印等内容与独立术式载体或制符流程有关时，才写成符师卡。  
   只出现“炼药、药材、丹药、炼器、阵法、纹路、族纹、印记、文字、符号比喻”等内容时，不写成符师卡。

4. 边界分层清楚  
   必须区分符师职业、制符流程、符箓物品、符宝炼制、临战符法、封印符文、族纹印记、阵法纹路、器物铭文和普通文字。  
   边界不清时，在“边界说明”中写明不确定性，不要把相邻职业内容套进符师字段。

5. 流程闭环优先  
   优先整理可复用的职业闭环：传承来源、材料准备、工具环境、制符手法、注灵封存、保存携带、激活方式、失败后果、交易收益和成长门槛。  
   单张符箓的战斗效果可以写，但不能替代职业流程分析。

6. 样本覆盖均衡  
   样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界、少数名场面或少数成功案例。  
   低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都可纳入样本。

7. 不虚构设定  
   不得为了补齐职业等级、境界梯度、制符流程、材料体系、价格体系、收益方式或失败后果而自行虚构。  
   原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”。

8. 输出简化  
   保留职业判断所需的流程、资源、门槛、风险和收益，不展开无关剧情背景。  
   不把炼药材料价格、丹药炼制流程、器物铭文、阵法符文等相邻体系写成符师案例。

## 字段说明

- 职业定位与分支：写符师、制符师、符箓师、符宝炼制者、符纸符墨制作者、血符师、魂符师、临战画符者等身份差异、职责边界和适用阶段。
- 纳入依据：写为什么进入符师模板，如存在制符流程、符箓传承、符纸符墨、符笔、符宝炼制、可携带术式载体、临战画符或血符魂符等。
- 处理对象：写符箓、符宝、符牌、符纸、血符、魂符、传讯符、遁符、防御符、攻击符、封印符等可携带或可预制的术式载体。
- 输入资源：写符纸、符墨、符笔、灵石、精血、魂魄、法力、神识、特殊载体和预制时间等制符消耗。
- 获取途径：写符方、符文传承、师承、宗门藏书、坊市购买、遗迹收获、任务奖励、交易、抢夺或自创等获得方式。
- 工具与环境：写制符台、静室、阵法辅助、灵气环境、禁制保护、保存容器、符笔、符刀、符桌等工具设施和环境要求。
- 操作者门槛：写境界、神识、灵根、血脉、手法、经验、职业等级、资格限制、传承限制或临战稳定性。
- 制符流程：写准备、绘制、注灵、封存、检验、保存、携带、激活和异常处置；不要只写“符箓发动”。
- 载体差异：写普通纸符、玉符、符牌、符宝、令符、符阵节点、虚空画符等在成本、保存时间、激活条件、威力、可携带性和使用次数上的差别。
- 产出与效果：写攻击、防御、遁逃、传讯、封印、召唤、治疗、定位、隐匿、破幻、控魂等结果。
- 代价与风险：写符毁、反噬、误触、保存失败、法力耗尽、精血损耗、魂魄污染、效果失控、被识破等后果。
- 收益方式：写售卖、交换、任务奖励、宗门供给、战斗保命、越级反制、传讯网络价值、封印委托等收益。
- 出现场景：写宗门符房、坊市符铺、拍卖会、战场补给、秘境准备、逃亡保命、洞府闭关、传讯系统、封印现场、散修交易等场景。
- 适用境界：按作品自己的境界体系写符师入门、独立制符、高阶符箓、符宝或特殊制符手段对应的阶段。
- 职业成长与变化：写从学徒到独立制符、高阶符师、符宝炼制者、符法传承者的成长路径；无明显变化时写“原文未说明明显变化”。
- 边界说明：写为什么不是炼丹、炼器、阵法、族纹、器物铭文、普通文字或单纯战斗招式；边界不清时写明不确定性。

## 案例

```md
# 《作品名》符师

## 符师职业卡片

### 符师/制符体系名称

- 职业定位与分支：
- 纳入依据：
- 处理对象：
- 输入资源：
- 获取途径：
- 工具与环境：
- 操作者门槛：
- 制符流程：
- 载体差异：
- 产出与效果：
- 代价与风险：
- 收益方式：
- 出现场景：
- 适用境界：
- 职业成长与变化：
- 边界说明：

### 宗门符房制符师

- 职业定位与分支：宗门符房供奉、制符弟子或制符学徒，负责稳定产出宗门任务、战斗补给和日常消耗所需符箓。
- 纳入依据：存在符房、制符人员、符纸符墨、符笔、符方或稳定符箓产出流程，属于明确的制符职业分支。
- 处理对象：符纸、符墨、符笔、传讯符、防御符、攻击符、遁符、封印符等，按作品实际出现的对象填写。
- 输入资源：符纸、符墨、符笔、法力、神识、灵石、妖兽材料、灵砂、保存容器和预制时间；没有可靠依据时写“原文未说明”。
- 获取途径：宗门藏书、师承传授、任务奖励、坊市购买、遗迹收获、交易或抢夺等，按原文填写。
- 工具与环境：宗门符房、静室、制符台、封存盒、禁制保护、稳定灵气环境等；高阶符箓若需要特殊环境，应单独写明。
- 操作者门槛：修为境界、法力精细控制、神识强度、符文理解、笔力稳定、材料辨识、传承资格和制符经验。
- 制符流程：选符纸、调符墨、处理材料、净手静心、起笔绘符、注入法力或神识、封存符力、检验、保存、携带、出售或自用。
- 载体差异：纸符、玉符、符牌、符宝、令符、符阵节点等在成本、保存时间、激活条件、威力、可携带性和使用次数上不同；不明时写“原文未说明”。
- 产出与效果：攻击、防御、遁逃、传讯、封印、召唤、治疗、定位、隐匿等，具体效果按原文填写。
- 代价与风险：符纸损毁、符墨报废、符路断裂、符力反噬、误触、保存失败、法力耗尽、效果失控或被人识破。
- 收益方式：售卖符箓、宗门贡献、代制委托、战场后勤、任务奖励、保命符溢价、传讯网络收益、交换符方或换取材料。
- 出现场景：宗门符房、坊市符铺、拍卖会、战场补给、秘境准备、逃亡保命、洞府闭关、传讯系统、封印现场或散修交易。
- 适用境界：按作品境界体系填写入门、独立制符、高阶符箓、符宝和特殊制符手段对应的阶段。
- 职业成长与变化：写制符学徒、独立制符师、高阶符师、符宝炼制者或符文传承者的阶段变化；无明显变化时写“原文未说明明显变化”。
- 边界说明：只整理独立符箓制作与使用闭环；炼丹药方、器物铭文、阵法符文和普通材料价格不写入本卡。

### 特殊符箓/符宝案例

- 职业定位与分支：血符师、魂符师、符宝炼制者、封印符师、符阵结合者、临战画符者等特殊制符或用符身份；若不是完整职业体系，应写明只是特殊符法样本。
- 纳入依据：存在血符、魂符、符宝、古符拓印、符箓叠加、符箓封印、传讯符、遁符、一次性保命符或符阵结合载体等可被激活的术式载体。
- 处理对象：血符、魂符、符宝、古符拓印、符箓叠加、符箓封印、传讯符、遁符、一次性保命符或符阵结合载体。
- 输入资源：精血、魂魄、符方、符纸、符墨、符笔、灵石、神识、法力、特殊传承、提前预制时间或符宝载体。
- 获取途径：师承、家族传承、宗门传承、古符残片、秘境机缘、拍卖交易、抢夺、自创或残符补全。
- 工具与环境：符笔、符刀、符桌、静室、封存盒、传讯阵台、灵气稳定处、战场临时环境或符阵节点。
- 操作者门槛：特定境界、血脉、神识、符文理解、特殊口诀、符宝掌控能力、临战稳定性或长期制符经验。
- 制符流程：写清谁在什么场景下，用什么条件，如何绘制、封存、携带、激活、命中目标或维持效果，不要只写“符箓发动”。
- 载体差异：说明普通纸符、玉符、符牌、符宝、虚空画符、符阵节点在成本、威力、保存、激活和使用次数上的差别。
- 产出与效果：写清攻击、防御、遁逃、传讯、封印、召唤、治疗、定位、隐匿、破幻、控魂等效果，以及与普通符箓的差异。
- 代价与风险：符毁、反噬、误触、法力耗尽、精血损耗、魂魄污染、保存失败、效果失控或被人识破。
- 收益方式：低阶保命、一次性消耗经济、战斗准备、越级反制、传讯网络、封印委托、任务奖励或宗门供给。
- 出现场景：战斗、逃亡、传讯、封印、宗门任务、秘境探索、拍卖交易、救援、临战激发或提前预制。
- 适用境界：按原文境界体系填写；原文没有说明的步骤、材料、条件、失败后果或长期影响，写“原文未说明”。
- 职业成长与变化：写特殊符法是否从单次用符发展为稳定职业、传承、符宝炼制路线或符法分支；无明显变化时写“原文未说明明显变化”。
- 边界说明：若只是血契、符印、灵魂符文、封印符文或临时符法，应写清其不是完整符师职业；炼药、炼器、阵法或普通纹路内容不写入本卡。
```
