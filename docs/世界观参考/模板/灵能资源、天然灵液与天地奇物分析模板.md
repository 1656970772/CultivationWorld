# 灵能资源、天然灵液与天地奇物分析模板

## 适用范围

本模板用于整理作品中明确出现的三类对象：

1. 灵能资源与产出源：灵石、灵晶、灵髓、灵贝等可携带资源，以及灵脉、灵眼、矿脉、贝场和能够持续产出或汇聚资源的固定灵池、血池、灵液池等资源节点。
2. 天然灵液与精华：作为原料或天然资源存在的灵液、真露、灵泉原液、灵液池内可独立取用的原液、玉液、毒液、分泌物和天地凝露。
3. 天地奇物与有灵异质：独立存在且不是场景本体的异火、神雷、可收取或封印的雷池、血池、灵液池、邪祟之物、有灵异质和其他可捕获、炼化、控制或利用的天地奇物。

本模板不分析灵植与药材、矿物与炼器材料、生灵与妖兽材料，也不分析丹药成品、法宝成品、符箓成品、功法秘籍、装备、饰品、容器、检测工具、普通建筑、组织、身份、资质、技能和秘术。下游成品只在用途字段中出现，完整内容放入对应专题模板。

## 整理原则

1. 先分类，再建卡
   每个对象先判断是否符合灵能资源与产出源、天然灵液与精华或天地奇物与有灵异质的准入条件，再从三类卡片中选择一类。不得用同一对象重复建立多类卡片；跨领域用途写入主卡的用途或关联字段。

2. 按存在形态确定主类
   灵石属于可携带灵能资源，灵脉属于产出源；作为原料采集的天然灵液归天然灵液与精华；可脱离地点独立存在并能移动、收取、封印、认主、寄生、炼化或控制的异火、神雷、雷池或邪祟异质，归天地奇物与有灵异质。

3. 区分原料、成品和产出源
   原料可被采集、消耗、加工或作为下游投入；成品已经具备完整用途和使用结构；产出源可持续或周期性地产出资源。产出源与产出物均有独立名称和机制时可以分别建卡，并通过产出关系关联。

4. 池体与内容物分层整理
   血池、灵液池、雷池等对象先区分“池中内容物”和“池本体”。池中血液或血液精华归入 `生灵与妖兽材料分析模板.md`；池中天然灵液或原液归天然灵液与精华。固定池体若持续产出或汇聚资源，归灵能资源与产出源；若重点是地点、建筑、阵法或修炼环境，转入秘境、场所、建筑或阵法模板；若整个池体可移动、收取、封印、认主、寄生或具有灵智，归天地奇物与有灵异质。内容物与池本体均有独立名称和机制时可以分别建卡，并通过产出、储存或寄生关系关联。

5. 一物一卡
   同名、别名、同物异名、不同品阶、纯度、属性、能量浓度、规格和灵性阶段归入同一卡。若加工、凝聚或分裂后形成有独立名称、性质和用途的新资源，可另建派生物卡，并在来源、产出或成长字段中连接原对象。

6. 字段完整
   每张卡只使用所属类别的字段，并保持字段完整。灵能资源记录五行或本征属性、寒热偏性、能量强度、危害性和温和度；天然灵液记录本征属性、药性与寒热偏性、效力或活性强度、毒性和温和度；天地奇物记录五行与寒热偏性、效力或威能、毒性或污染性和温和度。没有可靠内容时写“原文未说明”；本次整理范围不足时写“本次未覆盖到明确内容”；确实不适用时写“不适用”。不得用同类小说常识或使用者当前境界补齐资源设定。

7. 差异在卡内展开
   品阶、纯度、大小、属性、能量浓度、储量、产出阶段和灵性阶段等差异写入同一张卡的相应字段。差异会改变寒热偏性、药力或效力、毒性或污染性、温和度、效果、用途、取得条件或风险时，在相关字段中分别描述。

8. 明确灵液与丹药边界
   天然形成、作为原料采集或尚未成为命名药物的灵液归本模板。经过炼制、配伍或加工，能够直接服用、外用并作为完整药物产生疗伤、突破、解毒或毒杀效果的药液、真露和灵液，归入 `丹药分析模板.md`。

9. 明确奇物与场景、生灵、法宝边界
   固定存在并以地形、环境或区域规则为核心的火域、雷域、天然雷池和邪地，归入秘境、场所或世界环境类模板。可脱离地点独立存在、能够移动、收取、封印、认主、寄生、炼化或控制的异火、神雷、雷池和邪祟异质，归入天地奇物与有灵异质。具备稳定物种、生理结构和完整生物行为的对象归妖兽或人物；被人为炼成完整器物的对象归法宝。

10. 保留完整资源生命周期
    按“形成—分布与发现—自然运行—开采、采集或捕获—加工与储运—权属与争夺—利用与转化—环境反馈—再生、成长或衰退—枯竭、变质、失控或消亡—处置与最终去向”的链条记录。下游丹药、武器、法宝和阵法只作为用途或产出去向，不在本卡中展开完整效果；作品只展示部分环节时，只填写有证据的部分。

11. 区分正常、异常和极端状态
    正常产出、稳定保存和受控利用，与枯竭、泄漏、污染、变质、暴走、逃逸、容器损坏和环境崩溃分别记录。异常内容应说明触发条件、可感知征兆、扩散范围、处置方式、恢复可能和最终后果，不只罗列风险名称。

12. 输出前自检
    检查三类归属是否唯一、成品是否误收、产出源与产出物是否混为一物、池中内容物与池本体是否正确分层、同名对象是否重复建卡、形成与产地分布是否分开、发现与取得是否分开、灵液是否与丹药重叠、奇物是否满足非场景判定，五行属性与寒热偏性是否混淆，效力、毒性或污染性、温和度是否有证据及评分依据，权属与争夺是否交代、衰退终局是否记录、事实与推断是否区分，以及案例区是否只包含实际输出字段和示例内容。

## 属性记录与量化规则

1. 按类别解释同一维度
   天然灵液的“效力/活性强度”表示单位剂量产生的已确认药效、腐蚀、催化、淬炼、供能或其他天然作用强度；灵能资源的“能量强度”表示单位资源可提供、储存或输出的能量；天地奇物的“效力/威能强度”表示其核心规则或主要作用的强度。不得把储量、影响范围、稀有度或价格直接当作强度。

2. 五行与寒热分开
   五行填写金、木、水、火、土中的单一、复合或偏向，天然灵液可进一步记录药性；寒热填写大寒、寒、凉、平、温、热、大热或作品自定义偏性。冰寒不自动等于水属性，炽热不自动等于火属性，异火也可能具有其他复合属性。

3. 强度使用 1~100
   效力/活性强度、能量强度和效力/威能强度统一使用 1~100。仅在原文给出数值，或同一作品内存在足够明确的品阶、对比和实际表现时评分，同时写明“数值 + 评分对象 + 依据 + 原文明示/相对折算”。相对折算可使用 1~20 极弱、21~40 较弱、41~60 中等、61~80 较强、81~100 极强五档；证据不足时写“原文未说明（不评分）”。不同作品的折算分数默认不可直接比较。

4. 毒性、污染与反噬分开
   毒性记录物质或能量对肉身、经脉、神魂的毒害，可在证据充分时附 0~100；0 只用于原文明示或实际验证无毒。污染性记录对目标、环境或其他材料的持续异化，反噬记录捕获、炼化或控制失败后返回使用者的伤害。三者存在因果联系时可以互相引用，但不得合并成一个模糊风险等级。

5. 温和度使用 1~100
   温和度越高表示能量、药性或规则越平稳、越容易吸收、炼化、引导、封存或与其他材料协同；越低表示越狂暴、刺激、排斥或难以控制。温和度不等于无毒、低强度或高稳定寿命。不同纯度、浓度、品阶、稀释状态、灵性阶段和控制状态应分项评分，不取平均值掩盖差异。

6. 证据优先
   将关键结论区分为“原文明确”“由连续产出、实际使用或事故直接确认”“合理推断”“角色或旁人推测”“原文未说明”和“本次未覆盖到明确内容”。合理推断必须写明依据、替代解释和不确定之处；不得根据名称、颜色、现实药理或同类修仙设定补齐属性和分数。量化值只用于索引与同作品内比较，不能替代原文描述、适用条件和实际结果。

## 字段说明

### 灵能资源与产出源卡片字段

- 子类/资源形态：填写可携带能源货币、修炼资源、矿脉、灵脉、灵眼、贝场、固定灵池、固定血池、固定灵液池或其他汇聚与产出节点。
- 准入理由：说明对象为何是可消耗灵能资源、货币，或能持续产出资源的源头。
- 信息依据与判断边界：标明关键结论属于原文明确、由连续产出或实际使用直接确认、合理推断、角色或旁人推测、原文未说明或本次未覆盖；合理推断需给出依据、替代解释和不确定之处，量化评分同时记录评分对象与依据。
- 形态/外观：填写晶石、贝珠、灵髓、矿层、脉络、泉眼或能量节点等形态。
- 五行/本征属性/纯度：填写金、木、水、火、土及灵气、魔气、雷力、星力、阴阳、空间等属性，以及纯度、杂质、吸收、传导、储存或排斥关系。
- 寒热偏性：填写资源本体及释放、吸收、开采或汇聚时呈现的大寒、寒、凉、平、温、热、大热或其他温度倾向，不得由五行属性反推。
- 能量强度（1~100）：填写单位资源的能量含量、输出或供能强度，并注明评分对象、依据和证据性质；不同品阶、纯度或形态差异明显时分项评分，证据不足时写“原文未说明（不评分）”。
- 危害性/毒性：填写接触、吸收、开采、污染或过量使用造成的毒害、侵蚀、爆裂、冻伤、灼伤和环境破坏；有充分依据时可附毒性 0~100，未知不得写成无毒或 0。
- 温和度（1~100）：填写能量是否平稳、是否容易吸收、引导、储存和驱动，以及杂质、冲突与失控倾向；越高越温和，注明评分依据，证据不足时写“原文未说明（不评分）”。
- 单位/品阶/规格：填写上中下品、块、枚、斤、储量等级、矿脉规模和其他计量。
- 形成机制与原生条件：填写天地凝聚、矿脉生成、生灵产出、宗门培育等真正形成资源或产出源的机制，以及所需地质、灵气、时间和其他原生条件；当前所在地点统一放入下一字段。
- 分布、发现与可达性：填写地域、深度、数量、聚集规律、移动或隐藏情况，以及通过异象、灵气波动、勘探法器、地图或感知发现的方法；同时记录进入、勘探和开采所需的境界、路线、时机、权限、禁制破解或环境承受条件。
- 储量/规模：填写单体含量、矿藏储量、灵脉覆盖范围和可支持人数。
- 自然运行、产出、再生、衰退与枯竭后续：填写能量流动、汇聚、泄漏和稳定规律，产出物、产出周期、恢复条件、开采速度，以及品阶下降、衰退、枯竭、重新恢复或彻底失效后的地质、生态、修炼与势力后果；产出源与产出物分别建卡时在此关联。
- 开采、加工、储运与损耗：填写挖掘、抽取、切割、布阵引流、提纯、分级、封装、储存、运输和交接方式，以及加工损耗、泄漏、挥发、破损、抢夺和运输途中失效；直接吸收和下游使用统一放入“用途/下游去向”。
- 所有权、治理、保护与争夺：填写宗门、家族、城池、个人或无主状态，以及确权、守卫、封锁、开采额度、租用、税收、分配、走私、抢占、战争争夺和权属变化。
- 货币/兑换属性：填写是否充当通货、计价单位、兑换比例、品阶折算和流通限制。
- 环境依赖与系统反馈：填写地质、灵气、季节、阵法或秘境状态如何影响资源，以及资源对灵气浓度、修炼速度、宗门选址、生态、地下结构和秘境稳定的反向影响；过度开采后的反馈也在此记录。
- 核心效果：填写资源自身能够补充、储存、传导或释放能量，驱动其他系统，提升环境或持续产出资源等内在作用；不重复具体使用场景。
- 用途/下游去向：填写直接吸收、修炼、交易、炼丹、炼器、布阵、法宝驱动、宗门供给、战争消耗，以及加工、消耗或派生后形成的新对象。
- 限制、风险与异常处置：填写固有边界、枯竭、污染、过度开采、品阶下降、泄漏、爆裂、争夺和依赖风险，并按作品记录异常征兆、停采、封锁、疏导、修复、净化、替代供给、恢复可能和最终后果。
- 关键案例与变化链：填写能够验证资源生命周期的一次发现、勘探、开采、分配、争夺、过度消耗、污染、枯竭或恢复事件，可包含初始状态、发现与进入、正常产出、外部干预、状态变化、异常处置、环境与势力影响、最终去向及信息依据。
- 稀有度：按作品自身描述填写。
- 适用境界/阶段：填写明确适用的修炼和势力阶段。
- 别名/同物异名：填写不同地域、品阶体系和货币体系中的别名。

### 天然灵液与精华卡片字段

- 子类：填写天然灵液、真露、灵泉原液、灵液池原液、玉液、毒液、分泌物、天地凝露或其他液态精华。
- 准入理由：说明对象为何是天然形成或作为原料采集的液态资源，而不是已经完成配伍和炼制的药物成品。
- 信息依据与判断边界：标明关键结论属于原文明确、由持续产出或实际使用直接确认、合理推断、角色或旁人推测、原文未说明或本次未覆盖；合理推断需给出依据、替代解释和不确定之处，并说明对象为何仍是天然资源而不是药物成品。
- 形态/外观：填写液态、黏稠、雾化、凝露等状态，以及颜色、光泽、气味和沉淀。
- 形成机制与原生条件：填写灵泉、灵植、妖兽、矿脉、天地异象、秘境和其他自然凝聚或分泌过程，以及形成所需环境、周期和前置条件；当前所在地点统一放入下一字段。
- 分布、发现与可达性：填写地域、源头位置、数量、季节性、周期出现、隐藏或迁移情况，以及通过气味、光泽、异象、灵气波动、检测工具或生灵活动发现的方法；同时记录进入源头、辨别真伪和取得原液所需的路线、时机、权限、境界或环境承受条件。
- 自然产出周期、源头状态与环境反馈：填写源头如何积聚、分泌、凝露或循环产出，单次与周期产量、恢复条件、源头健康状态，以及采集、污染、季节、地形和灵气变化对产出的影响；同时记录灵液对周边生灵、灵植、土壤、水体和秘境的反馈。
- 浓度、纯度、品阶与规格：填写浓度、纯度、杂质、稀释状态、品阶、来源等级、批次和其他品质规格；不再在卡片末尾重复记录相同信息。
- 容量/剂量/计量：填写滴、瓶、池、斤、份或其他数量单位，以及单次使用量。
- 本征属性/药性/寒热偏性：分别填写金、木、水、火、土及其他本征属性、明确药性，与大寒、寒、凉、平、温、热、大热等寒热偏性，以及不同浓度、纯度、稀释或加工状态下的变化；不得由颜色、名称或用途反推。
- 效力/活性强度（1~100）：填写单位剂量在当前浓度、纯度、品阶和状态下产生的药效、腐蚀、催化、淬炼、供能或其他天然作用强度，注明评分对象、依据和证据性质；不同作用强度差异明显时分项评分，证据不足时写“原文未说明（不评分）”。
- 毒性：填写毒素性质、进入途径、作用对象或部位、剂量关系、发作与持续时间、可逆性、净化或解毒方式；有充分依据时可附毒性 0~100，未知不得写成无毒或 0。
- 温和度（1~100）：填写药性或能量是否平稳、是否容易吸收、炼化和混合，以及对经脉、脏腑、神魂或材料的刺激与排斥；越高越温和，注明评分依据，证据不足时写“原文未说明（不评分）”。
