# 有限视角与叙事日志模板

# 规范

本模板用于整理作品如何通过有限信息呈现世界：亲眼所见、神识探查、传闻、宗门公告、悬赏榜、战报、榜单、拍卖预告、玉简、魂牌、命灯、弟子汇报、商会消息、坊市闲谈、远方消息和误判。

重点不是复述全知事实，而是记录某个角色、组织或群体在某个时间点能知道什么、不能知道什么，以及这种信息差如何影响行动。不得把全知旁白当成玩家、主角、NPC 或某个势力已经知道的信息。

样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界、少数名场面或少数成功案例。低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

只整理原文有可靠依据的内容。原文没有说明的信息渠道、接收者、可信度、传播范围、时间滞后、误判原因、后续影响、境界、身份、地点、资源、关系或结果，统一写“原文未说明”，不要为了补齐结构而虚构。

同一事件在不同视角下可以拆成多个案例；例如亲眼所见、坊市传闻、宗门公告和敌方密报看到的信息范围不同，就应分别整理。文档不写总览、额外说明段、表格化项目字段映射或游戏化抽象，不用大段文学化文案替代信息结构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 信息渠道：亲眼所见、神识探查、战斗目击、宗门公告、悬赏榜、拍卖预告、坊市传闻、商会消息、战报、命灯、魂牌、玉简、弟子汇报、密探情报、敌方泄露。
- 接收者：主角、同行修士、宗门弟子、长老、商会、坊市散修、凡人、敌对势力、妖族、黑市、远方 NPC、玩家视角。
- 可信度表达：确认、亲眼所见、亲自探查、有人传来消息、听说、传闻、疑似、谣传、被证实、被否定、误传、刻意误导。
- 可见信息：地点、势力、人物、NPC、境界、物品、资源、事件阶段、关系、伤势、死亡、财富暴露、战斗结果、秘境开启。
- 不可见信息：隐藏修为、真实身份、背包详情、秘境内部、远方战争细节、敌方意图、幕后黑手、假消息传播链路、未公开交易。
- 叙事事件：突破、死亡、抢夺、复仇、师徒互动、宗门大比、拍卖、秘境开启、妖兽尸骸、世界状态变化、通缉、兽潮、宗门战争。
- 误判后果：追错人、低估敌人、高估敌人、暴露财富、错过机缘、误入陷阱、引发谣言、结仇、被势力利用、误伤盟友。
- 传播与滞后：传播范围、延迟时间、旧消息、过期情报、消息被封锁、消息被放大或被故意改写。
- 文本呈现方式：短日志、长日志、公告、传闻句、战报、榜单条目、弹窗、日记、传讯玉简、密报、旁听对话、事后复盘。

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
