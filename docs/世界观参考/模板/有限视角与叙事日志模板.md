# 有限视角与叙事日志模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：玩家有限视角、观察信息、日志文本和叙事呈现调研
> 目标详细程度：L2；涉及 UI/日志规则时提高到 L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文用于整理作品如何通过有限信息呈现世界：亲眼所见、神识探查、传闻、宗门公告、悬赏榜、战报、榜单、拍卖预告、玉简、魂牌、命灯、弟子汇报、商会消息、坊市闲谈、远方消息和误判。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不把全知旁白当成玩家、主角、NPC 或某个势力已经知道的信息。
- 不写大段文学化文案而忽略信息结构；重点是写清信息来源、接收者、可信度、可见内容、不可见内容、误判空间、传播范围、时间滞后和后续影响。
- 同一事件在不同视角下可以写成多个案例；例如亲眼所见、坊市传闻、宗门公告和敌方密报看到的信息范围不同，就应分别写。
- 如果原文没有说明信息来源、接收者、可信度、传播范围、时间滞后、误判原因或后续影响，不要补，可以写“原文未说明”。

## 参考范围（不局限于以下类别）

- **信息来源**：亲眼所见、神识探查、战斗目击、宗门公告、悬赏榜、拍卖预告、坊市传闻、商会消息、战报、命灯、魂牌、玉简、弟子汇报、密探情报、敌方泄露。
- **接收者**：主角、同行修士、宗门弟子、长老、商会、坊市散修、凡人、敌对势力、妖族、黑市、远方 NPC、玩家。
- **可信度表达**：确认、亲眼所见、亲自探查、有人传来消息、听说、传闻、疑似、谣传、被证实、被否定、误传、刻意误导。
- **可见信息**：地点、势力、NPC、境界、物品、资源、事件阶段、关系、伤势、死亡、财富暴露、战斗结果、秘境开启。
- **不可见信息**：隐藏修为、真实身份、背包详情、秘境内部、远方战争细节、敌方意图、幕后黑手、假消息来源、未公开交易。
- **叙事事件**：突破、死亡、抢夺、复仇、师徒互动、宗门大比、拍卖、秘境开启、妖兽尸骸、世界状态变化、通缉、兽潮、宗门战争。
- **误判后果**：追错人、低估敌人、高估敌人、暴露财富、错过机缘、误入陷阱、引发谣言、结仇、被势力利用、误伤盟友。
- **文本呈现方式**：短日志、长日志、公告、传闻句、战报、榜单条目、弹窗、日记、传讯玉简、密报、旁听对话、事后复盘。

## 完整信息呈现案例

### 案例 1：亲眼所见 / 近距离观察

信息呈现名：写具体事件或信息名称；例如“某修士亲眼见到秘境入口开启（亲眼所见 / 高可信度）”。

信息来源：写清是亲眼所见、神识探查、战斗旁观、近距离观察、同行见证，还是从现场痕迹推断。

接收者：写清谁知道这件事，是主角、同伴、某个 NPC、某个势力、围观修士，还是玩家视角。

发生场景：写清发生地点、时间、距离、是否在战斗中、是否有遮蔽、是否有阵法、迷雾、隐匿术或干扰。

可见内容：写清接收者确实能看到什么，例如人物外貌、出手方式、境界表现、法宝、伤势、死亡、资源暴露、谁先动手、谁逃走。

不可见内容：写清接收者看不到什么，例如真实身份、隐藏修为、背包详情、内心动机、秘境深处情况、幕后安排、暗中交易。

可信度表达：写清原文如何表达可信度，例如“亲眼看见”“神识扫过”“只见”“隐约察觉”“似乎”“不敢确定”；原文未说明则写“原文未说明”。

误判空间：写清可能误判什么，例如把分身当本体、把伪装身份当真、低估隐藏修为、误判死亡、误判法宝来源或误判敌我关系。

传播范围：写清这条信息是否只限现场少数人知道，是否会传到宗门、坊市、商会、敌对势力或凡俗区域。

时间滞后：写清信息是即时知道、事后才知道、隔天传开、数月后才传到远方，还是原文未说明。

文本呈现方式：写清适合怎样呈现为日志或叙事，例如短句、目击日志、战斗记录、现场描述、事后回忆；不要写成全知旁白。

后续行为影响：写清接收者会因此追杀、逃跑、交易、隐瞒、报信、求援、设伏、抢夺机缘或改变判断。

反转或证实：写清后续是否证明最初观察正确、被反转、被误导、被补充信息修正；原文未说明则写“原文未说明”。

适合记录的原文要点：写清应摘录或复述哪些原文事实，例如看到的动作、听到的话、现场痕迹、旁观者反应和后续确认。

### 案例 2：宗门公告 / 榜单 / 悬赏

信息呈现名：写具体公告、榜单、悬赏、任务发布或宗门通报名称。

信息来源：写清是宗门公告、执法堂通告、悬赏榜、功勋榜、战功榜、通缉令、任务堂消息、长老口谕，还是宗门内部文书。

接收者：写清谁能看到，是全宗弟子、内门弟子、长老、执法堂、附属家族、坊市散修，还是特定任务小队。

发生场景：写清公告发布地点、榜单张贴位置、任务堂、执法堂、宗门广场、坊市告示牌或传讯网络。

可见内容：写清公告公开了什么，例如姓名、画像、境界、罪名、奖励、任务地点、危险等级、目标势力、参与资格。

不可见内容：写清公告不会写什么，例如真实幕后原因、宗门内部交易、目标真实修为、任务隐藏风险、奖励真实来源。

可信度表达：写清公告是否被视为权威、是否可能滞后、是否可能被宗门有意隐瞒或夸大。

误判空间：写清接收者可能误判任务难度、目标实力、悬赏原因、宗门态度、政治风险或自己能否承受后果。

传播范围：写清公告只在宗门内部、附属坊市、区域通缉网、商会网络，还是跨势力传播。

时间滞后：写清公告发布和事件发生之间差多久，是否存在旧榜未更新、目标已逃离、死亡未确认等情况。

文本呈现方式：写清适合做成公告句、榜单条目、任务提示、悬赏描述、宗门日志或战报摘要。

后续行为影响：写清谁会接任务、追杀、避让、冒名、举报、抢功、结盟、坐地起价或制造假线索。

反转或证实：写清悬赏是否后来被撤销、目标洗清罪名、任务升级、榜单更新、宗门公开道歉或继续隐瞒。

适合记录的原文要点：写清公告原文、榜单排名、奖励数额、目标描述、围观反应、任务接取条件和后续更新。

### 案例 3：坊市传闻 / 商会消息 / 拍卖预告

信息呈现名：写具体传闻、商会放风、拍卖预告、坊市闲谈、黑市消息或情报买卖名称。

信息来源：写清是坊市闲谈、掌柜消息、拍卖行预告、商会放风、情报贩、黑市暗线、酒楼议论，还是路过修士转述。

接收者：写清谁听到了这条信息，是散修、主角、商会客户、拍卖参与者、黑市修士、宗门弟子，还是敌对势力。

发生场景：写清传闻出现在坊市、拍卖场、酒楼、客栈、商铺、黑市、交换会、传送阵附近还是路途中。

可见内容：写清传闻公开了什么，例如某物即将拍卖、某地有秘境、某人暴富、某妖兽尸骸出现、某宗门战败。

不可见内容：写清传闻不知道什么，例如消息源、真假、完整地点、拍品真实来源、买家身份、幕后推手、陷阱。

可信度表达：写清是“听说”“据商会说”“有人见过”“掌柜暗示”“坊间都在传”，还是已经由拍卖行确认。

误判空间：写清可能是托价、诱饵、假消息、旧消息、片面消息、刻意放风、财富暴露或黑市钓鱼。

传播范围：写清传闻在坊市小范围、区域修士圈、商会客户、黑市网络，还是已经传到宗门和敌对势力。

时间滞后：写清传闻是否提前预告、拍卖前几天扩散、事后才传出、已经过期或原文未说明。

文本呈现方式：写清适合做成传闻句、商会预告、拍卖公告、旁听对话、黑市情报或短日志。

后续行为影响：写清修士是否赶赴拍卖、埋伏截杀、抢夺机缘、抬价、隐藏身份、改变路线或购买情报。

反转或证实：写清传闻是否被拍卖验证、被证明是假消息、引发截杀、导致财富暴露或引出更大事件。

适合记录的原文要点：写清传闻措辞、传播者身份、听众反应、拍卖预告内容、价格变化和后续验证。

### 案例 4：战报 / 远方消息 / 势力情报

信息呈现名：写具体战报、远方消息、密探情报、势力汇报或传讯内容。

信息来源：写清是战报、密探、弟子汇报、传讯玉简、商会情报、宗门斥候、逃亡者口述，还是敌方泄露。

接收者：写清谁收到消息，是宗门高层、远方 NPC、主角、商会、敌对势力、凡俗王朝，还是某个任务队伍。

发生场景：写清消息从哪里传来，传到哪里，是否跨区域、跨界、隔着秘境、通过传送阵、飞剑传书或口口相传。

可见内容：写清战报说明了哪些事实，例如谁胜谁败、哪些地点失守、哪些人物死亡、资源损失、逃亡方向。

不可见内容：写清战报无法说明或故意不说什么，例如真实伤亡、叛徒、内部矛盾、失败原因、敌方后手、假投降。

可信度表达：写清消息是否来自权威渠道、密探是否可靠、是否多方印证、是否只是逃亡者片面说法。

误判空间：写清可能误判敌方实力、战局趋势、盟友忠诚、支援时机、伤亡规模、战争责任或幕后操盘者。

传播范围：写清情报是机密、半公开、区域扩散、商会售卖，还是已经成为坊市传闻。

时间滞后：写清消息到达时战局是否已经变化，远方 NPC 是否依据过期信息行动。

文本呈现方式：写清适合做成战报摘要、密报、传讯玉简、势力日志、远方事件日志或月度摘要。

后续行为影响：写清接收者是否撤离、支援、复仇、求援、割让资源、投靠、叛逃、设伏或误入过期战场。

反转或证实：写清战报是否后来被确认、被推翻、发现有假情报、发现还有幸存者或发现真正黑手。

适合记录的原文要点：写清战报措辞、传讯方式、延迟时间、接收者反应、后续行动和情报更新。

### 案例 5：命灯 / 魂牌 / 生死状态

信息呈现名：写具体命灯、魂牌、魂契、血契、留魂玉、宗门生死牌或生命感应机制。

信息来源：写清生死信息来自命灯熄灭、魂牌碎裂、魂契反应、血契断开、传讯失联，还是护道者感应。

接收者：写清谁能看到或感应到，是宗门、家族、师父、同门、主人、契约对象、执法堂，还是敌对势力。

发生场景：写清命灯或魂牌放在哪里，谁负责看守，何时发现异常，是否有人隐瞒或篡改。

可见内容：写清能知道什么，例如死亡、重伤、失联、方位模糊、神魂受创、契约断开、是否还活着。

不可见内容：写清不能知道什么，例如死因、凶手、完整地点、是否假死、是否夺舍、是否被秘境隔绝。

可信度表达：写清命灯/魂牌在原文中是否绝对可靠，是否可能被秘法遮蔽、误导、延迟或伪造。

误判空间：写清可能误判死亡、误判失踪、误判凶手、误判位置、误判是否被夺舍或魂魄是否还在。

传播范围：写清这类生死信息是否只在宗门内部、家族内部、师徒之间，还是会引发公开通缉和复仇。

时间滞后：写清生死变化是否即时反应，是否受距离、秘境、阵法、封印或跨界影响。

文本呈现方式：写清适合做成生死日志、宗门警报、师徒反应、家族通报、追凶开端或悬念提示。

后续行为影响：写清接收者是否派人追查、复仇、撤离、隐藏消息、争夺遗产、改立继承人或发布通缉。

反转或证实：写清后来是否发现是假死、残魂尚存、被夺舍、命牌被伪造、目标复活或死因另有隐情。

适合记录的原文要点：写清命灯/魂牌变化、发现者反应、原文限制、追查路线和后续确认。

### 案例 6：隐藏身份 / 假名 / 隐藏修为 / 误判

信息呈现名：写具体伪装、假名、隐藏修为、身份误判、法宝遮蔽或情报误导案例。

信息来源：写清接收者通过外貌、气息、修为表现、法宝、介绍人、身份令牌、传闻、榜单或他人转述认识此人。

接收者：写清谁被误导，是主角、敌人、宗门、商会、坊市散修、亲友、追杀者，还是玩家视角。

发生场景：写清伪装发生在坊市、拍卖会、宗门、秘境、战场、黑市、逃亡途中还是长期潜伏。

可见内容：写清伪装者主动展示了什么，例如假名、假境界、假身份、普通法器、受伤状态、低调行为。

不可见内容：写清隐藏了什么，例如真实修为、本命法宝、真实身份、杀人经历、背包资源、血脉、仇家、组织背景。

可信度表达：写清其他角色为什么相信，是否有令牌、介绍人、法术遮蔽、境界差距、社会常识或先入为主判断。

误判空间：写清误判点在哪里，例如把强者当弱者、把邪修当正派、把分身当本体、把敌人当盟友、把假死当真死。

传播范围：写清假身份在多大范围内成立，是只骗一人、骗过坊市、骗过宗门，还是长期欺骗多个势力。

时间滞后：写清身份何时暴露，暴露前持续多久，是否因战斗、拍卖、通缉、熟人认出或功法泄露而破局。

文本呈现方式：写清适合做成含糊日志、误判日志、传闻文本、事后反转、玩家未知信息隐藏或身份揭示。

后续行为影响：写清误判导致追杀失败、轻敌、交易失误、结仇、被反杀、暴露财富、潜伏成功或势力误判。

反转或证实：写清身份如何被揭穿，谁先发现，原先哪些线索被重新解释，是否仍有人不知道真相。

适合记录的原文要点：写清伪装手段、旁人判断、暴露瞬间、误判后果和后续传闻变化。
