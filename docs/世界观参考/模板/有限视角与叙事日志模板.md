# 有限视角与叙事日志模板

## 适用范围

本文用于整理作品如何通过有限信息呈现世界：亲眼所见、神识探查、传闻、宗门公告、悬赏榜、战报、榜单、拍卖预告、玉简、魂牌、命灯、弟子汇报、商会消息、坊市闲谈、远方消息和误判。

本文重点不是复述全知事实，而是记录某个角色、组织或群体在某个时间点能知道什么、不能知道什么，以及这种信息差如何影响行动。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角视角或少数名场面。
- 不把全知旁白当成玩家、主角、NPC 或某个势力已经知道的信息。
- 只整理原文有可靠依据的内容。原文未说明的信息来源、接收者、可信度、传播范围、时间滞后、误判原因或后续影响，写“原文未说明”。
- 同一事件在不同视角下可以拆成多个案例，例如亲眼所见、坊市传闻、宗门公告和敌方密报看到的信息范围不同。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **信息来源**：亲眼所见、神识探查、战斗目击、宗门公告、悬赏榜、拍卖预告、坊市传闻、商会消息、战报、命灯、魂牌、玉简、弟子汇报、密探情报、敌方泄露。
- **接收者**：主角、同行修士、宗门弟子、长老、商会、坊市散修、凡人、敌对势力、妖族、黑市、远方 NPC、玩家视角。
- **可信度表达**：确认、亲眼所见、亲自探查、有人传来消息、听说、传闻、疑似、谣传、被证实、被否定、误传、刻意误导。
- **可见信息**：地点、势力、人物、境界、物品、资源、事件阶段、关系、伤势、死亡、财富暴露、战斗结果、秘境开启。
- **不可见信息**：隐藏修为、真实身份、背包详情、秘境内部、远方战争细节、敌方意图、幕后黑手、假消息来源、未公开交易。
- **误判后果**：追错人、低估敌人、高估敌人、暴露财富、错过机缘、误入陷阱、引发谣言、结仇、被势力利用、误伤盟友。
- **传播与滞后**：传播范围、延迟时间、旧消息、过期情报、消息被封锁、消息被放大或被故意改写。
- **文本呈现方式**：短日志、长日志、公告、传闻句、战报、榜单条目、弹窗、日记、传讯玉简、密报、旁听对话、事后复盘。

## 案例

### 案例

| 信息类型 | 示例 | 重点 |
| --- | --- | --- |
| 亲眼所见 / 近距离观察 | 现场目击、神识探查、战斗旁观、同行见证 | 可见边界、不可见内容、误判空间、即时行动 |
| 宗门公告 / 榜单 / 悬赏 | 通缉令、任务榜、功勋榜、宗门通报 | 权威性、公开范围、隐藏原因、榜单更新 |
| 坊市传闻 / 商会消息 / 拍卖预告 | 酒楼闲谈、商会放风、拍卖公告、黑市情报 | 真假、托价、诱饵、财富暴露、传播扩散 |
| 战报 / 远方消息 / 势力情报 | 密探回报、传讯玉简、战报、逃亡者口述 | 时间滞后、片面性、决策影响、后续证实 |
| 命灯 / 魂牌 / 生死状态 | 命灯熄灭、魂牌碎裂、魂契断开、传讯失联 | 可知状态、不可知死因、误判死亡、复仇触发 |
| 隐藏身份 / 假名 / 隐藏修为 / 误判 | 假名潜伏、遮蔽修为、身份令牌、伪装交易 | 伪装信息、信任来源、暴露时机、反转后果 |

**通用信息卡片：**

- **信息呈现名**：写具体事件或信息名称，并标明信息类型。
- **信息来源**：写清亲眼所见、公告、传闻、战报、魂牌、密报、榜单或转述渠道。
- **接收者**：写清谁知道这件事，是个人、队伍、宗门、坊市、商会、敌对势力、凡人区域还是玩家视角。
- **发生场景**：写清地点、时间、距离、媒介、是否跨区域、是否受阵法、秘境、遮蔽或传送影响。
- **可见内容**：写清接收者确实能知道的人物、地点、境界表现、伤势、资源、事件阶段、结果或公开描述。
- **不可见内容**：写清接收者不知道的真实身份、隐藏修为、动机、幕后安排、背包资源、完整战局或内部交易。
- **可信度表达**：写清原文如何表达确认、传闻、疑似、权威通报、片面消息、刻意误导或后续证实。
- **误判空间**：写清可能误判的对象、实力、死亡、身份、因果、敌我关系、任务难度或消息真假。
- **传播范围**：写清信息只在现场、宗门、坊市、商会、黑市、区域势力或远方传播。
- **时间滞后**：写清信息是即时、事后、数日后、数月后、过期，还是原文未说明。
- **文本呈现方式**：写清适合写成日志、公告、榜单、密报、传闻句、战报摘要、对话或事后复盘。
- **后续行为影响**：写清接收者是否追杀、逃跑、报信、交易、求援、设伏、隐瞒、抬价、撤离或改变判断。
- **反转或证实**：写清后续是否被证实、推翻、补充、发现假情报、暴露真正身份或重新解释旧线索。
- **适合记录的原文要点**：摘录或复述动作、措辞、渠道、限制、听众反应、延迟时间、后续确认。
