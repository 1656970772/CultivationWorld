# 炼丹师模板

# 规范

用于整理作品中的炼丹师职业，以及与炼丹流程高度相关的医师、毒师、药师、灵植夫、药园管理、丹方研究、代炼丹药、药材辨识和解毒救治内容。

本模板重点不是收集丹药条目；丹药名称、功效、丹方和适用境界应放入 `丹药分析模板.md`。本模板重点分析“玩家如果选择炼丹师职业，这个职业在小说世界里如何运转”：从获取丹方、准备材料、选择环境、使用工具、操控火候、符纹封药、开炉炼制、成丹失败、售卖交换到职业成长的完整闭环。

本文只整理小说中出现过，或能由小说内容明确支撑的炼丹师职业、炼丹流程、职业分支、工具设施、炼丹环境、操作手法、特殊手段、收益方式和失败后果，不编造小说中不存在的职业体系。

整理时应按职业分支、炼丹环节、功效方向和适用境界尽可能覆盖完整：每一种职业分工、每一类炼丹用途、每一个境界阶段，只要小说中有对应内容，都应尽量写入对应段落。文档长度不设上限，宁可写长，也不要为了压缩篇幅遗漏有参考价值的职业样本、流程细节和失败案例。

如果某类职业分支、某个境界阶段，或输入资源、丹方获取方式、工具设施、炼丹环境、操作手法、特殊手段、成丹结果、限制/失败后果等字段在小说中没有可靠依据，可以写“原文未说明”；不得为了补齐职业等级、境界梯度、炼丹流程或数值体系而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 职业定位：写炼丹师是散修副业、宗门供奉、坊市职业、家族传承、医毒职业，还是高阶稀缺身份。
- 职业分支：写医师、毒师、药师、灵植夫、采药人、药园管事、代炼丹师、丹方研究者等相关分工。
- 处理对象：写灵草、灵果、妖兽内丹、精血、矿物药材、毒物、灵液、药散、药剂、残方、丹方、病患、毒伤和突破需求等对象。
- 输入资源：写主药、辅药、药引、火种、灵石、药园产物、药材获取渠道和资源消耗。
- 丹方获取与传承限制：写宗门传承、师承、家族传承、拍卖、坊市购买、遗迹残方、秘境机缘、交易、抢夺、自创和残方补全等方式，并说明稀缺性、保密性和推演可能。
- 工具设施：写丹炉、药鼎、火室、丹房、炼丹殿、药园、灵田、医馆、毒室、储药容器、控火法器等设施及其品阶、损坏风险和维护要求。
- 炼丹环境：写火脉、地火品质、灵气浓度、禁制防护、护法需求、药气泄露、炸炉和异象暴露等环境条件与风险。
- 操作者门槛：写修为、神识、控火、药性辨识、丹方理解、经验、传承资格、灵根/体质和火属性能力；若有学徒、丹师、大师、宗师等层级，按原文写。
- 炼丹流程：写辨药、处理药材、称量配伍、温炉、投药、控火、融药、去杂、凝液、凝丹、温养、开炉、分丹、验丹、保存、试药、出售或自用等环节；没有完整流程时，只写出现过的环节。
- 火候与控火方式：写凡火、地火、丹火、灵火、异火、兽火、阵法控火、神识控火、急火/文火切换和温养火候等内容。
- 符文/阵纹/禁制：写丹纹、药纹、阵纹、封药禁制等是否参与封存药性、稳定药力、压制丹毒、提升品质或延长保存时间；独立符箓体系放入 `符师模板.md`。
- 境界差异：写低阶依赖丹炉或地火，高阶神识控火、虚空炼丹、以天地为炉、同时炼多炉、远程控炉、借阵法或异火炼丹等差异。
- 特殊手段：写催熟、净化、补全残方、以毒炼丹、以妖丹入药、以血祭药、药灵辅助等不同于常规流程的手段。
- 成丹结果：写成丹数量、品相、丹纹、药效强弱、杂质、废丹、半成品、毒丹、副产物、丹毒、极品丹和异象丹等结果。
- 产出/效果：写修炼丹、突破丹、疗伤丹、解毒丹、延寿丹、毒丹、药散、药液、医治方案、灵植成果和丹方改良等职业产出。
- 时间成本：写采药、处理药材、开炉、温养、冷却和返工耗时；没有可靠依据时写“原文未说明”。
- 限制/失败后果：写炸炉、药材损毁、药性冲突、丹毒、误诊、中毒、反噬、火候失控、异象暴露、服用者受害和信誉受损等限制或后果。
- 收益方式：写自用、出售、宗门贡献、代炼抽成、任务委托、拍卖溢价、治疗人情、供奉待遇、交换丹方、换材料和建立人脉等收益。
- 出现情境：写宗门丹房、坊市丹铺、拍卖会、药园、医馆、毒室、秘境、洞府、战争补给和散修交易等场景。
- 适用境界：按作品自己的境界体系填写炼丹职业覆盖阶段、入门条件、可独立炼丹阶段和高阶特殊手段出现阶段。
