# 炼丹师模板

## 适用范围

用于整理作品中的炼丹师职业，以及与炼丹流程高度相关的医师、毒师、药师、灵植夫、药园管理、丹方研究、代炼丹药、药材辨识和解毒救治内容。

本模板重点不是收集丹药条目；丹药名称、功效、丹方和适用境界应放入 `丹药分析模板.md`。本模板重点分析“玩家如果选择炼丹师职业，这个职业在小说世界里如何运转”：从获取丹方、准备材料、选择环境、使用工具、操控火候、符纹封药、开炉炼制、成丹失败、售卖交换到职业成长的完整闭环。

## 前置声明

- 只整理原文出现过，或能由原文和可靠资料来源明确支撑的炼丹师职业与炼丹流程。
- 样本应覆盖职业分支、炼丹环节、功效方向和适用境界；不要只写主角或成功案例。
- 案例只是写法示范，不是数量上限；有价值的流程细节、失败案例和职业样本都应继续补充。
- 原文没有说明的职业等级、境界梯度、流程步骤、资源来源、成丹结果或失败后果，写“原文未说明”，不要补设定。
- 信息暂不完整但值得保留的内容，先放入 `### 待定案例`；后续补充摘要和来源，足够支撑案例后再转入 `### 案例`。

## 必须写什么

本节是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **职业定位与分支**：炼丹师是散修副业、宗门供奉、坊市职业、家族传承、医毒职业还是高阶稀缺身份；相关分支包括医师、毒师、药师、灵植夫、采药人、药园管事、代炼丹师、丹方研究者等。
- **处理对象与输入资源**：灵草、灵果、妖兽内丹、精血、矿物药材、毒物、灵液、药散、药剂、残方、丹方、病患、毒伤、突破需求；记录主药、辅药、药引、火种、灵石、药园产物和来源。
- **丹方来源与传承限制**：宗门传承、师承、家族传承、拍卖、坊市购买、遗迹残方、秘境机缘、交易、抢夺、自创、残方补全；写清稀缺性、保密性和推演可能。
- **工具设施与炼丹环境**：丹炉、药鼎、火室、丹房、炼丹殿、药园、灵田、医馆、毒室、储药容器、控火法器；记录品阶、损坏风险、火脉/地火品质、灵气浓度、禁制防护、护法需求和环境风险。
- **操作者门槛**：修为、神识、控火、药性辨识、丹方理解、经验、传承资格、灵根/体质、火属性能力；若有学徒、丹师、大师、宗师等层级，按原文写。
- **炼丹流程**：辨药、处理药材、称量配伍、温炉、投药、控火、融药、去杂、凝液、凝丹、温养、开炉、分丹、验丹、保存、试药、出售或自用。没有完整流程时，只写出现过的环节。
- **火候、符文、阵纹与禁制**：凡火、地火、丹火、灵火、异火、兽火、阵法控火、神识控火；丹纹、药纹、封药禁制等若有区别，按原文分别写。本段只写炼丹流程，独立符箓体系放入 `符师模板.md`。
- **境界差异与特殊手段**：低阶依赖丹炉或地火，高阶神识控火、虚空炼丹、以天地为炉、同时炼多炉、远程控炉、借阵法或异火炼丹等；特殊手段如催熟、净化、补全残方、以毒炼丹、以妖丹入药、以血祭药、药灵辅助。
- **成丹结果与产出**：成丹数量、品相、丹纹、药效强弱、杂质、废丹、半成品、毒丹、副产物、丹毒、极品丹、异象丹；产出包括修炼丹、突破丹、疗伤丹、解毒丹、延寿丹、毒丹、药散、药液、医治方案、灵植成果和丹方改良。
- **时间、限制与失败后果**：采药、处理药材、开炉、温养、冷却、返工耗时；失败包括炸炉、药材损毁、药性冲突、丹毒、误诊、中毒、反噬、火候失控、异象暴露、服用者受害、信誉受损。
- **收益方式、来源场景与适用境界**：自用、出售、宗门贡献、代炼抽成、任务委托、拍卖溢价、治疗人情、供奉待遇、交换丹方、换材料、建立人脉；场景包括宗门丹房、坊市丹铺、拍卖会、药园、医馆、毒室、秘境、洞府、战争补给和散修交易。

## 案例

### 案例

#### 特殊手段案例通用卡片

- **案例名称和类型**：如异火炼丹、毒丹炼制、残方补全、丹纹封药。
- **使用者**：写清人物、身份、境界、炼丹水平和所属势力。
- **使用场景**：写清是在闭关、突破、救人、斗法后疗伤、宗门委托、秘境应急、拍卖供货还是特殊环境中使用。
- **前置条件**：写清需要的丹方、主药、辅药、火源、丹炉、阵法、神识、护法、药园、传承或特殊体质。
- **具体过程**：详细写清操作步骤，不要只写“手法特殊”。例如如何处理药材、如何控火、如何注入灵力、如何封存药性、如何避免丹毒。
- **产出或效果**：写清成丹数量、品质、药效、特殊用途、与普通丹药的差异。
- **代价与风险**：写清炸炉、药材损毁、丹毒、反噬、火候失控、异象暴露、被人争夺、服用者受害等后果。
- **限制**：写清是否只有本人能用，是否依赖异火、血脉、丹炉、环境、传承、境界或稀有材料。
- **可参考点**：写清该案例对职业体系的参考价值，例如高阶职业差异、特殊资源依赖、失败风险、稀有丹药经济价值、NPC 职业路线。
