# 炼丹师模板

## 适用范围

本模板用于整理作品中的炼丹师职业，以及与炼丹流程直接相关的炼药师、丹师、药师、医师、毒师、灵植夫、药园管理者、丹方研究者、代炼者、药材辨识者和解毒救治者。整理时保留作品使用的职业称谓，不把作品专属称谓统一替换成“炼丹师”。

本模板重点分析炼丹类职业在作品世界中的运转方式，包括职业定位、分工、丹方与材料来源、工具与环境、操作者门槛、炼制流程、控火与特殊手段、成败结果、成本、收益、风险和成长阶段。

丹药名称、完整功效、服用效果、品质差异、具体丹方和适用对象等丹药本体信息，放入 `丹药分析模板.md`；独立符箓体系放入 `符师模板.md`。本模板只保留这些内容与炼丹职业机制直接相关的部分。

只持有、购买或服用丹药的人物不纳入职业卡；医师、药师、配药者、采药人等相关职业只有在参与炼药、配药、药材处理、丹方研究、药园供给或救治流程时才纳入，并说明其与炼丹体系的关系。

## 整理原则

1. **先判定职业关系**
   只整理作品中明确出现，或能从职业行为直接确认的炼丹、炼药及相关分工。不得因为人物懂药、持有丹药或服用丹药，就将其升格为炼丹师。

2. **保留作品称谓**
   使用作品中的“炼丹师”“炼药师”“丹师”“药师”“炼药弟子”“配药者”等名称。若同一职业存在别名、旧称、尊称或不同势力称呼，归并到同一张职业卡并注明称谓差异。

3. **一类职业一张卡**
   同一职业的不同阶段、等级、势力归属、炼制方式和后续补充，原则上归入同一张职业卡；只有职责、传承、操作闭环或社会身份明显不同的职业分支才单独建卡。

4. **围绕职业闭环整理**
   优先呈现“获得丹方与材料—准备环境与工具—处理材料—控火炼制—验丹与保存—交付或使用—承担失败后果—获得收益与成长”的完整链路。作品只展示部分环节时，只填写已明确的部分。

5. **多路线分项表达**
   同一字段存在多种独立的职业路线、资源来源、工具、环境、火源、炼制流程、特殊手段、收益方式或失败情形时，按作品中的名称或“方式1、方式2”分项。各项只保留能区分该路线的方式、效果、失败效果、限制等内容，不机械补齐不存在的子项。

6. **区分事实、未知与未覆盖**
   没有可靠内容时写“作品未说明”；只是当前整理范围尚未覆盖时写“本次未覆盖到明确内容”。不得为了补齐职业等级、境界梯度、炼制步骤、成功率、成本或数值体系而推测。

7. **保留成功与失败样本**
   成功、失败、半成功、炸炉、误诊中毒、废丹、丹雷或异象暴露等情况都可以收录。失败内容应落在对应流程、结果、风险或特殊案例中，不因结果不理想而省略。

8. **控制丹药本体信息**
   丹药名称和功效只保留到能够说明职业产出、任务目标、炼制难度或收益方式的程度，避免把职业报告写成丹药条目合集。

9. **覆盖作品中的阶段差异**
   长篇作品应兼顾前中后期出现的宗门丹房、坊市交易、职业组织、考核认证、高阶丹道、特殊火源和失败异象。不同境界或职业层级的差异分别整理，不用通用修仙设定填补作品空白。

10. **输出保持简洁**
    保留能体现职业体系、资源依赖、炼制规则、风险收益和成长路径的信息，不长篇复述剧情，不重复堆叠相同流程。

11. **输出前自检**
    检查职业准入是否准确、作品称谓是否保留、同类信息是否归并、多路线是否分项、规则是否与具体案例分离，以及丹药本体信息是否已控制在职业分析所需范围内。

## 字段说明

- **职业定位**：填写职业原称、身份属性、所属势力、社会位置和核心职责，如散修副业、宗门供奉、家族传承、坊市职业、医毒职业或高阶稀缺身份。
- **职业分支**：填写炼丹、炼药、配药、医治、制毒、灵植培育、药园管理、材料处理、代炼和丹方研究等实际分工；分支间职责或运作方式不同则分项记录。
- **处理对象**：填写该职业直接处理的灵草、灵果、妖兽内丹、精血、矿物药材、毒物、灵液、药散、残方、病患、毒伤或突破需求等。
- **输入资源**：填写主药、辅药、药引、火种、灵石、药园产物等投入，以及宗门配给、坊市购买、秘境采集、交易、自种或催熟等来源。
- **丹方获取与传承限制**：填写宗门、师承、家族、拍卖、坊市、遗迹、秘境、交易、自创或残方补全等来源，并记录身份门槛、保密要求、传承范围和推演限制。
- **工具设施**：填写丹炉、药鼎、丹房、炼丹殿、地火室、药园、灵田、医馆、毒室、储药容器和控火法器等，以及其使用方式、品阶影响、维护要求和损坏风险。
- **炼丹环境**：填写火脉、地火室、洞府、宗门丹房、药园、秘境或临时炼制场所的灵气、火源、防护、护法、暴露和干扰条件。
- **操作者门槛**：填写修为、神识、控火、药性辨识、丹方理解、经验、传承资格、灵根、体质和特殊火种等要求；存在学徒、丹师、大师、宗师等层级时分层记录。
- **炼丹流程**：填写作品实际出现的辨药、处理、称量、配伍、温炉、投药、控火、融药、去杂、凝液、凝丹、温养、开炉、分丹、验丹、保存、试药、交付或自用等环节。
- **火候与控火方式**：填写凡火、地火、丹火、灵火、异火、兽火、阵法控火、神识控火、急火、文火和温养火候等方式，以及其适用场景、效果和失控后果。
- **符文/阵纹/禁制**：填写直接参与封存药性、稳定药力、压制丹毒、提高品质或延长保存时间的丹纹、药纹、阵纹和禁制。
- **境界差异**：填写不同修为或职业阶段在工具依赖、神识强度、控火方式、可炼品阶、多炉操作、远程控炉、虚空炼丹或以天地为炉等方面的差异。
- **特殊手段**：填写催熟、净化、残方补全、丹方改良、以毒炼丹、以妖丹入药、以血祭药、药灵辅助等区别于常规流程的手段，并记录效果、失败效果和限制。
- **特殊案例列表**：填写能够体现职业机制的具体成功、失败、半成功或事故案例。每个案例可包含名称、类型、使用者、场景、前置条件、输入资源、工具/火源、过程、效果、失败效果、代价与风险、限制和可参考点。
- **成丹结果**：填写成丹数量、品相、丹纹、药效强弱、杂质、废丹、半成品、毒丹、副产物、丹毒、极品丹或异象丹等结果及其形成原因。
- **产出/效果**：填写修炼丹、突破丹、疗伤丹、解毒丹、延寿丹、毒丹、药散、药液、医治方案、灵植成果或丹方改良等职业产出。
- **时间成本**：填写采药、处理材料、开炉、温养、冷却、试错和返工耗时，以及时间压力对结果的影响。
- **限制/失败后果**：填写炸炉、材料损毁、药性冲突、丹毒、误诊、中毒、反噬、火候失控、设施损坏、异象暴露、服用者受害和信誉受损等触发条件与后续影响。
- **收益方式**：填写自用、出售、宗门贡献、代炼抽成、任务委托、拍卖溢价、治疗人情、供奉待遇、丹方交换、材料交换和人脉积累等收益。
- **出现情境**：填写宗门丹房、坊市丹铺、拍卖会、药园、医馆、毒室、秘境、洞府、战争补给、突破护法或散修交易等场景。
- **适用境界**：按作品自身体系填写职业入门、独立炼制、高阶丹药和特殊炼制手段对应的修为或成长阶段。

### 宗门供奉炼丹师

- 职业定位：宗门供养的专职炼丹者，领取宗门任务，为弟子和长老稳定提供修炼、突破、疗伤与解毒类丹药。
- 职业分支：
  - 丹房供奉：负责领取丹方与材料、安排开炉、验收成丹并交付任务。
  - 药园管事：负责种植、采收、辨识、保存和分配炼丹材料。
- 处理对象：灵草、灵果、妖兽内丹、药引、残方，以及宗门的修炼、突破、疗伤与解毒需求。
- 输入资源：
  - 宗门配给：宗门提供主药、辅药、丹方、灵石和地火室使用资格。
  - 自备材料：炼丹师通过坊市购买、采集或交换补充材料，成丹可自用或出售。
- 丹方获取与传承限制：
  - 宗门传承：以供奉身份和贡献换取丹方，受传承层级与保密规则限制。
  - 交易与残方补全：从坊市、拍卖或遗迹取得丹方，再以药理试验补全缺失部分；试错成本由炼丹师承担。
- 工具设施：
  - 丹炉与储药容器：用于投药、凝丹、温养、分丹和保存成品。
  - 丹房与地火室：提供稳定火源、防护禁制和集中储药条件。
- 炼丹环境：主要在宗门丹房中炼制，环境稳定且有禁制隔绝药气；秘境或洞府中的临时开炉容易受到护法不足、材料保存和外敌干扰影响。
- 操作者门槛：具备药性辨识、丹方理解、神识控火和独立开炉能力，并取得宗门丹房与对应丹方的使用资格。
- 炼丹流程：辨药与称量—处理主药和辅药—温炉—按次序投药—控火融药与去杂—凝丹温养—开炉验丹—装瓶保存—交付宗门。
- 火候与控火方式：
  - 地火控炉：借地火室和阵法调节火力，适合稳定完成常规任务。
  - 灵火控炉：以自身灵火配合神识处理难炼材料，耗神更高，失控时会灼毁药材或损伤丹炉。
- 符文/阵纹/禁制：丹房禁制用于隔绝药气和火势；储药容器上的封药禁制用于减缓药力流失。
- 境界差异：学徒负责辨药与处理材料；普通丹师可独立炼制常规丹药；高阶供奉能够使用灵火、改良丹方并处理高阶材料。
- 特殊手段：
  - 残方补全：以药理推演和小批材料试炼补全缺失配伍，成功后形成新丹方，失败时产生废丹或毒性偏差。
  - 灵火炼丹：以特殊火种提纯难炼材料并压低杂质，受修为、神识和火种稳定性限制。
- 特殊案例列表：
  - 地火室批量炼丹：
    - 类型：成功案例
    - 使用者：丹房供奉
    - 使用场景：宗门集中补充修炼丹药
    - 前置条件：完整丹方、成套材料、地火室使用资格
    - 输入资源：主药、辅药、药引、灵石
    - 工具/火源：丹炉、地火、控火阵法
    - 方式：分批处理材料，以地火稳定融药，凝丹后统一验丹装瓶
    - 效果：在固定周期内稳定交付多炉常规丹药
    - 失败效果：单炉火候偏差会产生杂质较多的次品或废丹
    - 代价与风险：消耗宗门材料、地火室配额和连续控火所需神识
    - 限制：依赖稳定火脉、丹房排期和材料供应
    - 可参考点：体现宗门炼丹的任务制、设施依赖和批量供给能力
- 成丹结果：
  - 正常成丹：数量与品质达到任务标准，可直接入库或分发。
  - 次品与废丹：火候、材料或配伍失衡导致杂质增加、药效不稳或无法服用。
- 产出/效果：常规修炼丹、突破辅助丹、疗伤丹、解毒丹，以及经过验证的丹方改良成果。
- 时间成本：材料处理、开炉、凝丹、温养、冷却和验丹占用完整任务周期；失败后需要重新领取或自筹材料返工。
- 限制/失败后果：药材配伍错误会导致药性冲突；控火失误会造成废丹、炸炉或丹炉损坏；任务连续失败会降低贡献评价与供奉待遇。
- 收益方式：供奉俸禄、宗门贡献、代炼抽成、剩余成丹分配、丹方与材料交换，以及由稳定交付积累的声誉和人脉。
- 出现情境：宗门丹房、地火室、药园、坊市采购、任务交付和拍卖供货。
- 适用境界：从负责材料处理的炼药学徒，到可独立开炉的丹师，再到掌握灵火与丹方改良的高阶供奉。
