# 阵法分析模板

## 适用范围

本模板用于整理玄幻、修仙作品中由原文明确出现或明确支撑的阵法、禁制、结界、法阵、传送阵、封印阵、护山护阁大阵、洞府禁制、战斗阵、合击阵，以及由阵旗、阵盘、阵眼、阵基、阵纹、令牌、灵石、地脉等要素构成或展开的阵法系统。

本模板重点分析阵法本体如何构成、布置、启动、运行、控制、切换、维持、失效、破解和修复，以及它在未启动、启动、生效、受击、超载、失控和崩解等状态下产生的实际效果与可观察表现。阵法师的传承、职业成长、委托收入和产业分工放入 `阵法师模板.md`；阵旗、阵盘等物品只有在承载完整阵法或参与具体阵法时才在本模板中说明，单独作为法宝分析时放入 `法宝分析模板.md`。

普通术法、符箓、法宝护罩、灵兽追踪、机关陷阱、自然地形和多人配合，不因功能近似而自动视为阵法。只有原文明确称其为阵法、禁制或结界，或明确呈现阵眼、阵基、阵纹、布阵、结阵、供能等阵法结构时，才建立阵法卡。

## 整理原则

1. 先做准入判定  
   可收录固定或半固定的空间结构、可由阵旗阵盘展开的便携阵法、依赖多人结阵的战斗阵法，以及具备明确阵法结构的禁制、结界、传送、封印、护山防御、困杀、幻化、聚灵和隔绝系统。百药园禁制、岳麓殿传送阵、迷踪旗展开的小型迷踪阵、颠倒五行阵、护阁大阵、化龙魔阵、噬灵绝生阵和洞府禁制均属于可判定对象。名称未出现但结构明确时，仍可按下一条规则建立卡片。

2. 无正式名称时使用描述性卡片名  
   提取对象是有价值的阵法案例，但原文没有给出具体名称时，可采用“关键作用对象 + 的 + 阵法”“地点或布置者 + 功能 + 阵法”等清晰、自然且不附加机制推断的描述性名称。例如，用于封困玄骨而小说原文未给出正式阵名的案例，卡片名可写为“困住玄骨的阵法”。描述性卡片名只作为整理索引，不视为原文正式名称；若动画、改编版或其他版本另有正式名称，应在“名称与别名”和“信息确定性”中注明版本来源。

3. 排除功能相似但不属于阵法的对象  
   云翅鸟监视韩立属于灵兽追踪，不建立阵法卡；普通侦察、一般护罩法宝、单次术法控制、独立符箓效果和纯机关陷阱也应排除。若法宝、符箓或灵兽只是阵法的阵眼、供能媒介、控制凭证或组成部分，应写入对应阵法卡，不另行改写成阵法。

4. 区分阵法本体、阵法工具与阵法师职业  
   本模板以阵法本体为核心。阵旗、阵盘、令牌、阵图和阵法道书只作为构成、控制或知识载体记录；辛如音、齐云霄背后的阵法师朋友、天星宗阵法产业等职业与势力信息，主要归入 `阵法师模板.md`。辛如音修复古传送阵时，可为古传送阵建立阵法卡并记录修复者与修复流程，但不在该卡中展开人物职业生涯。

5. 明确内容与推断分开  
   阵法名称、品阶、用途、外观、构成、状态表现、效果、代价和破解方式分别判断确定性，不得因相邻剧情或阵法名称补全未知信息。“九天雷狱阵”若原文没有光影、雷声或雷电形态描写，也不得仅凭名称补写雷霆特效。

6. 战斗阵法需要二次判定  
   多人站位或合击只有在明确结阵，或存在阵眼、主持者、反噬、阵纹、阵旗阵盘等结构时才纳入。九天雷狱阵由多人结阵、三人充当阵眼，阵眼被破坏会造成重伤或反噬，可以建立战斗阵法卡；只有协同攻击而没有阵法结构时，不建立阵法卡。飞行禁制、阵法封印、杀阵和禁空结构也按同一标准判断。

7. 一阵一卡，变体归并  
   同一阵法后续出现新的布置地点、使用者、构件、用途、效果、限制、破解或修复信息时，补入同一张阵法卡。若同名对象的核心结构、运行规则或功能实质不同，则分别建卡，并在名称中写明地点、版本或布置者等区分项；不得以“补充”“后期内容”等名义重复建卡。

8. 按阵法运行链整理  
   阵法卡的核心分析链统一为：来源传承 → 阵理属性 → 环境适配 → 外观结构 → 构件供能 → 布置校验 → 启动判定 → 模式运行 → 性能上限 → 状态特效 → 探测预警 → 联动冲突 → 容错降级 → 维护修复 → 升级变体 → 状态沿革。名称、类型、品阶、准入理由、信息确定性、布置者、位置用途、作用对象、效果、控制权限和限制风险作为对应环节的基础信息一并填写。
   颠倒五行阵的十八块阵盘、三十六根阵旗、玉简布置方法、准确位置、阵眼灵石和启动流程应归入相应字段；古传送阵的破损、样式辨认、材料准备、按图修复、符纹校验和另一端状态应归入修复与风险信息。
   “效果”只写阵法实际做到什么；“不同状态下的表现”只写阵法看起来、听起来或感知起来如何。光芒、颜色、阵纹流动、声响、威压、温度、雾气、空间扭曲、天地异象和崩解残留等不得代替实际效果。

9. 限制、代价和风险不可省略  
   阵法不得写成无条件生效的能力。灵石与材料消耗、能量储备、补充速度、环境依赖、布置时间、启动前置、承载上限、阵眼暴露、阵基损坏、符纹偏差、主持者反噬、地脉受损、误传送、封印破裂、权限限制、目标误判、兼容冲突、多人协作、备用机制和目的地失效等均应按原文填写；没有说明时写“原文未说明”，不得用常见设定补齐。

10. 保持类型和阶段覆盖  
   长篇作品应兼顾防御、困杀、幻象、隐匿、聚灵、隔绝、侦测、传送、封印、炼化、禁空和多人战阵，并覆盖未启动或潜伏、启动瞬间、稳定运行、功能生效、模式切换、受攻击或干扰、能量不足、超载失控、关闭、破阵崩解、修复和废弃等状态。百药园禁制与令牌、岳麓殿传送阵收费与守阵、迷踪旗和幻形阵旗展开阵法、颠倒五行阵布置、古传送阵修复、洞府牌符控制、化龙魔阵与噬灵绝生阵的代价等内容应按各自阵法关系整理，不因某一类型更显眼而忽略其他类型。

11. 缺失处理与输出自检  
    只填写原文明确说明或能由上下文直接确认的信息；输入材料缺失时写“数据缺失，不补写”，已经检查但没有相关内容时写“未检出”，尚未检查时写“未覆盖”。完成后检查：是否误收灵兽、普通法宝、一般术法或机关，是否把推断写成确定事实，是否遗漏名称、品阶规模、来源传承、阵理属性、环境适配、外观结构、构件、供能储备、布置校验、触发判定、模式切换、性能上限、效果、不同状态表现、探测预警、兼容联动、容错降级、权限、维持关闭、破解修复、升级变体、代价和风险，是否把特效当成功能，是否仅凭名称补写特效，同一阵法是否被重复拆卡。每张卡保留全部既定字段，只写阵法成立与运行所需信息，不长篇复述剧情。

## 字段说明

- 名称与别名：写阵法正式名称、别名、简称、旧称、版本名、地点称呼或布置者称呼；没有正式名称时使用“地点或布置者 + 功能或外观 + 无名阵法”的中性描述，不得擅自命名。
- 类型与形态：类型写防御、困敌、杀伐、幻象、隐匿、聚灵、隔绝、侦测、传送、封印、炼化、禁空、合击等；形态写固定、半固定、便携展开、多人结阵或复合阵法。
- 品阶、规模与覆盖范围：写作品内的阵法品阶、强度评价、完整或简化版本、参与人数、阵旗阵盘数量、阵法直径、覆盖地点、作用距离、可承载人数或目标数量；没有明确数值时只写原文定性描述，不按效果自行估级。
- 准入理由：简要说明该对象为何属于阵法、禁制或结界，如原文明确称为阵法，或具备阵眼、阵基、阵纹、结阵、供能等结构。
- 信息确定性：填写“原文明确”“上下文推断”或“原文未说明”；同一卡中不同信息的确定性不一致时，分别说明。
- 来源与传承：写创造者、阵法流派、所属宗门或族群、阵图玉简、古籍传承、残缺版本、仿制改造、前后代版本和获得方式；阵法师个人生涯仍归阵法师模板。
- 阵理、属性与法则基础：写阵法依托的五行、阴阳、风雷、冰火、空间、时间、神魂、血脉、地脉、星象、符文或其他底层规则，以及属性生克、能量转化、法则调用和各模块之间的理论关系；不得根据阵名推断属性或法则。
- 环境依赖与适配条件：写阵法对地形、灵脉、地脉、天气、时辰、星位、温度、灵气属性、空间稳定度、界面规则和建筑载体的依赖，以及换地点、移动、跨界、环境变化后的可用性和调整要求。
- 布置者/使用者：写布阵者、启动者、主持者、操控者、维护者、修复者及所属势力；身份不明时写“原文未说明”。
- 位置与用途：写阵法所在地点、覆盖范围及实际用途，如洞府防护、宗门守卫、战场困杀、远程传送、封印镇压或辅助修炼。
- 外观与空间结构：写阵法未启动或可见状态下的整体轮廓、几何形态、层级、方位、阵纹颜色与材质、阵旗阵盘位置、阵眼与阵基布局、入口出口、内外层、节点连接及阵内路线。此字段描述静态形制与空间关系，“构成要素”只列出由什么组成，“不同状态下的表现”另写运行时变化。
- 构成要素：写阵旗、阵盘、阵眼、阵基、阵纹、令牌、主持者、灵兽、法宝、材料、地形、地脉和其他组成部分。
- 能量来源与储备：写灵石、灵脉、地脉、施术者法力、血祭、阵中生灵、天地之力或其他供能方式，以及能量容量、补充方法、恢复速度、备用供能和枯竭条件；不明时写“原文未说明”。
- 布置流程：按原文写选址、勘测、定位、插旗、埋盘、刻纹、安置阵眼、连接节点、人员站位和布置所需时间，并记录布置后的阵纹校验、节点检查、试运行、误差修正、功能测试和验收标准；固定天然阵法或已成阵法不适用时说明。
- 启动与触发条件：写注入能量、放置灵石、令牌或口诀、主持者施法、多人同步、目标进入、定时、血脉、攻击触发和其他启动前置，以及启动所需时间和能否远程触发。
- 运行机制：写阵法如何连接构件、调动能量、识别目标、封锁空间、循环攻击、维持幻象、完成传送或实现其他功能。
- 作用对象与判定规则：写阵法作用于谁或什么，如阵内全部目标、指定敌人、持令牌者、特定血脉、某境界以下对象、魂体或空间坐标，以及敌我识别、目标锁定、豁免、误判、最大目标数和进出判定。
- 运行模式与状态切换：写待机、隐匿、警戒、防御、困敌、杀伐、传送、封印加固等模式，模式之间由谁、以什么条件切换，以及局部启动、全功率、自动反击、备用阵眼接管和降级运行等变化。
- 性能参数与承载上限：写防御或封印强度、攻击频率、传送距离与精度、作用速度、持续时间、响应延迟、最大目标数、可承载人数或重量、并发次数、冷却、过载阈值和对不同境界目标的实际效果；无明确数值时写原文定性结论。
- 效果：写防御、攻击、困敌、隐匿、聚灵、隔绝、传送、封印、炼化、侦测、削弱、增幅和对环境的影响。
- 不同状态下的表现：写阵法在“未启动/潜伏”“启动/触发瞬间”“稳定运行/功能生效”“受攻击/受干扰”“能量不足/超载/失控”“关闭/破阵/崩解”等状态中可观察或感知到的光芒与颜色、阵纹流动、能量形态、声响、气息威压、温度、雾气、风雷、空间扭曲、幻象、屏障、地形变化、天地异象和消散残留。复杂阵法可在每个状态下继续分“阵外可见”“阵内体验”“核心构件变化”；没有描写时逐状态写“原文未说明”。此字段只写表现和特效，实际功能仍写入“效果”。
- 可探测性、隐藏与预警：写未启动和运行中的阵法能否被肉眼、神识、灵目、阵法师、探测法器或特殊血脉发现，阵纹、能量波动、阵眼和边界如何隐藏，以及入侵、破坏、能量异常、权限错误和封印松动时如何预警并通知谁。
- 兼容、联动与冲突：写阵法与其他阵法、禁制、法宝、符箓、功法、血脉、灵兽、建筑、地形、灵脉和空间节点之间的嵌套、串联、共享供能、增幅、接管、干扰、排斥、冲突、覆盖和优先级。
- 容错、备用与降级机制：写阵眼或节点损坏后的备用阵眼、冗余线路、局部隔离、自动切断、主持者接管、备用能源、降功率运行、仅保留核心功能、安全停机和故障扩散限制；没有备用机制时也应如实说明。
- 控制与权限：写令牌、口诀、阵盘、身份、血脉、神识印记、主持位置、内外通行和敌我识别等控制方式。
- 维持、消耗与关闭：写持续供能、单位时间消耗、主持者维持、自动运行、轮值维护、补充能量、主动关闭、收阵、转移、冷却或自然消散方式。
- 限制/代价/风险：写材料与灵石消耗、布置时间、范围、地形、境界、人数、权限、阵眼暴露、反噬、误伤、误传送和失控风险。
- 破解/失效/修复：写破坏阵眼阵基、切断供能、取得权限、以力破阵、反向推演、内部关闭、自然耗尽等破解或失效方式，并记录故障定位、损坏传播、修复优先级、材料与人员需求、节点替换、符纹修补、重新校准、修复后试运行和功能复测。
- 强化、扩展与版本变体：写阵法升阶、扩容、增加阵眼、叠加模块、扩大范围、提高性能、简化便携、移动化、复合化、仿制、残缺版与完整版差异，以及升级所需材料、阵理、环境、阵法师能力和失败风险。
- 状态沿革与后续影响：按时间写阵法从建成、启用、改造、转移、受损、封存、失效、被破、修复到废弃的变化，以及其对人物、地点、势力和后续行动的影响；当前时刻的视觉表现仍归“不同状态下的表现”。

- 品阶、规模与覆盖范围：具体品阶原文未说明。小说版外层黄雾约方圆一里；破除外层后，内层黄色光罩覆盖约百余丈；动画版概括为三层阵法。
- 准入理由：动画明确称其为“恶贯满盈阵”；小说对应对象具有多层禁制、属性结构、光罩、火灵、核心封灵柱及明确破阵流程，符合复合阵法准入标准。

- 阵理、属性与法则基础：外层以风、土属性形成黄雾幻障；中层以复合光罩与能量光带继续封锁；最深层将区域塑造成三阳之地，使火系妖灵“翅恶”持续生成或恢复。动画版用“薄雾夺感官—烟兽震心胆—翅恶耗灵力”概括三层机制。
- 环境依赖与适配条件：固定在乱星海荒岛黄色土山缓坡处；最终杀阵依赖三阳之地环境维持翅恶。该岛没有可见灵脉且植被难生，阵法如何在此长期供能原文未说明；换址和移动使用不适用或原文未说明。
- 布置者/使用者：布置者原文未明确；破阵者包括韩立、石蝶，以及协助使用水属性法器的金青、曲魂、简姓修士和胡月。动画情节将其与玄骨遭封困的往事直接关联。
- 位置与用途：位于乱星海荒岛土山缓坡，覆盖通往封灵柱和地下大厅的区域；用于隐藏、阻挡和杀伤闯入者，并封锁玄骨骸骨所在的地下区域。

  - 外层：方圆约一里的浓厚黄色雾团伏在山坡上，寂静无声；动画概括为夺人感官的薄雾层。
