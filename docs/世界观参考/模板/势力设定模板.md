# 势力设定模板

# 规范

## 参考和要求

用于整理势力百科，为项目中差异化宗门、家族、商会、王朝、妖族、异族组织体系提供参考。

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 样本覆盖：覆盖不同势力类型、地域层级、阵营、发展阶段和结局；不要只写主角所在势力。
- 整理边界：不写项目字段映射，不写游戏化抽象，不把势力压缩成单一事件案例。
- 采集重点：优先整理有独特秘境、传承、组织制度、资源场所、职业体系、血脉、商业规则、族群生态或运营方式的势力。
- 取舍规则：结构普通、功能重复、只提供背景名字、缺少特色区域和制度的势力，不必为了凑数量单独写成百科案例。
- 缺失处理：没有可靠依据的信息写“原文未说明”，不要补设定。
- 势力类型：写正道宗门、魔道宗门、邪道宗门、中立宗门、修仙家族、凡人王朝、商会、拍卖行、坊市、情报组织、杀手组织、散修联盟、妖族、异族、学院、寺观、军团等基本性质和阵营。
- 势力定位：写综合宗门、剑修宗门、炼丹宗门、炼器宗门、阵法宗门、符箓宗门、御兽宗门、商业组织、情报组织、战斗宗门、血脉家族、王朝势力等立足方式。
- 核心区域：写山门主峰、分峰、内外门、禁地、秘境入口、修炼密室、聚灵阵、悟道场、传承殿、藏经阁、任务堂、丹堂、器堂、符堂、阵堂、药园、矿脉、灵兽园、坊市、商路、边境据点等位置、功能、进入要求、产出、风险和负责人。
- 组织结构：写掌门、宗主、族长、皇帝、太上长老、长老、继承人、真传、核心、内门、外门、杂役、执事、护法、供奉、客卿、堂主、暗线、附庸等人数、职位、职责、境界、派系和上下级关系；不明写“原文未说明”。
- 制度规则：写收徒、晋升、考核、贡献、月俸、任务、奖惩、禁令、闭关资格、秘境名额、继任、联姻、盟约、附属供奉、叛逃处理等进入条件、身份限制、消耗、次数、持续时间、效果、风险和副作用。
- 资源基础：写灵脉、矿脉、药园、功法传承、丹药库存、法宝库、妖兽材料、凡俗人口、情报网、商路、军备、秘境产出、传承名额等资源形成方式、产出周期、管理者和争夺风险。
- 特色体系：写宗门大比、试炼塔、悟道石、祖师传承、剑冢、丹炉地火、炼器火脉、阵法核心、灵兽血脉、特殊秘境、特殊职能堂口等最有辨识度的机制或区域。
- 成卡标准：有独特秘境、特殊传承、明确职业分工、特殊血脉或族群生态、独特交易规则、特殊试炼制度或修炼设施的势力可单独成卡；缺少特色时可在相关事件中顺带提及。
- 对外关系：写敌对、同盟、附庸、贸易、世仇、联姻、互相忌惮、共同抗敌、暗中合作、争夺秘境、争夺商路等关系成因、利益和变化。
- 势力历史：写创建缘由、祖师或开创者、传承变迁、迁徙、鼎盛、衰落、分裂、覆灭、重建、吞并、改名、掌权者更替、资源丢失、秘境开启、战争失败、关键历史人物等重要变化。

## 案例

### 案例

```md
# 《作品名》势力设定

## 势力卡片

### 势力名称

- 势力类型与定位：
- 核心区域：
- 组织结构：
- 制度规则：
- 资源基础与特色体系：
- 对外关系：
- 势力历史：

### 综合型修仙宗门

- 势力类型与定位：综合型修仙宗门；重点写弟子培养、功法传承、宗门任务和分峰堂口。
- 核心区域：山门、主峰、分峰、内外门、藏经阁、任务堂、秘境入口、试炼地、修炼设施等。
- 组织结构：宗主、长老、真传、核心弟子、内门弟子、外门弟子、杂役弟子、执事和各堂口负责人。
- 制度规则：收徒、晋升、贡献、任务、月俸、秘境名额、宗门大比、闭关资格和奖惩禁令。
- 资源基础与特色体系：功法传承、灵脉、药园、矿脉、丹堂、器堂、阵堂、宗门秘境和资源经营。
- 对外关系：同盟、敌对、附庸、贸易、秘境争夺、边境冲突和共同抗敌。
- 势力历史：创建、鼎盛、衰落、分裂、重建、掌权者更替和关键战争。

### 修仙家族

- 势力类型与定位：血缘传承型修仙家族；重点写族地、血脉、族规、嫡庶或旁系差异。
- 核心区域：族地、祖祠、祖地秘境、家族药园、矿脉、藏书处、议事堂和防护阵法。
- 组织结构：族长、长老、嫡系、旁系、供奉、客卿、年轻子弟和附庸凡俗族人。
- 制度规则：族内考核、继承、联姻、资源分配、奖惩、外出历练和叛族处理。
- 资源基础与特色体系：血脉传承、家族功法、祖传法宝、灵田、商路、盟约和外部靠山。
- 对外关系：姻亲、世仇、宗门依附、贸易伙伴、资源争夺和家族联盟。
- 势力历史：祖先开创、迁徙、兴衰、分支变化、族长更替和重大危机。

### 商会 / 拍卖行 / 坊市势力

- 势力类型与定位：商业交易型势力；重点写交易制度、信誉、情报、护送和纠纷处理。
- 核心区域：总部、拍卖场、鉴宝处、仓库、黑市、分会、商路、码头或坊市摊位。
- 组织结构：会长、掌柜、拍卖师、鉴宝师、护卫、账房、情报人员和合作供货方。
- 制度规则：入场资格、竞价、抽成、寄售、保密、赊账、护送、违约赔偿和纠纷仲裁。
- 资源基础与特色体系：货源渠道、商路网络、仓储、情报网、护卫力量、贵宾制度和特殊交易规则。
- 对外关系：客户、宗门家族、竞争商会、地下势力、地方统治者和护路盟约。
- 势力历史：创建、扩张、分会设立、信誉危机、商业战争和掌权者更替。

### 妖族 / 异族势力

- 势力类型与定位：族群血脉型势力；重点写族地、血脉等级、族群继承和对外战争。
- 核心区域：族地、巢穴、王庭、血脉池、祖地、禁地、试炼地、资源地和化形或进阶场所。
- 组织结构：族王、长老、血脉继承人、战士、祭司、护法、附庸族群和幼年族人。
- 制度规则：血脉觉醒、继承考核、族群试炼、领地分配、进阶仪式、禁地资格和战功奖惩。
- 资源基础与特色体系：血脉池、祖地传承、妖兽材料、特殊灵地、族群天赋和进阶资源。
- 对外关系：敌对族群、人族势力、附庸族群、盟约、领地争夺和共同大敌。
- 势力历史：族群起源、迁徙、王位更替、血脉衰落或复兴、战争和族地变迁。
```
