# 势力设定模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的宗门、门派、家族、王朝、商会、拍卖行、坊市、学院、寺观、军团、情报组织、杀手组织、散修联盟、妖族、异族、附庸组织等势力。

本模板只做势力设定整理，不展开人物传记、功法、物品、丹药、灵兽、单次事件、身份标签或社会现象。人物、功法、物品、丹药、灵兽、事件等只在所属势力的相关字段中作为成员、资源、制度或事件被提到；如果需要分析其本体，应放入对应模板。

## 整理原则

1. 先做准入判定  
   只有具备组织性、成员或归属关系、相对稳定的活动区域、资源、制度或对外关系的对象，才可建立势力卡。  
   人物、功法、物品、丹药、灵兽、身份标签、单次事件、社会现象不得作为势力卡。只有原文明确其背后存在独立组织时，才整理该组织。

2. 候选先盘点  
   先列出可能涉及的势力候选，再判断“成卡、并入、舍弃”。  
   结构普通、功能重复、只提供背景名字、缺少特色区域和制度的势力，可以并入相关势力、事件或“未成卡相关要素”。有组织行动线、成员层级、依附关系、资源危机或对外冲突的外部势力，不要漏掉。  
   例如：`象甲功`是功法，不单独成卡，可并入神手谷 / 墨大夫相关资源；`平安符`是物品，应舍弃或并入相关事件；`厉飞雨`是人物，可并入七玄门代表人物；`广源派`有弟子层级、依附关系和门派行动线，应成卡；`南华派`有外部组织身份和冲突线，可成卡或并入相关门派关系。

3. 一势力一卡  
   同一势力的主称、别名、旧称、异写、分部、后续阶段和关系变化，优先归并到同一张卡。  
   禁止另建“某势力（补充）”“某势力后期”“某势力别名”等新卡。差异写入同卡的名称、历史、对外关系或相关事件字段。

4. 字段完整  
   每张卡必须包含：名称与别名、原文类型与模板归类、势力规模与影响范围、势力外观描述、核心区域、组织结构、制度规则、资源基础与特色体系、势力目标与内部矛盾、关键资源 / 代表人物 / 相关事件、对外关系、势力历史。  
   无依据时写“原文未说明”；不得为了补齐外观、区域、层级、制度、资源或历史而自行虚构。

5. 使用原文体系术语  
   势力类型优先使用作品自己的世界观术语，再补模板归类。  
   例如斗气世界应写“原文类型：斗气家族；模板归类：血缘传承型家族”，不要硬套成“修仙家族”。

6. 区分势力、成员和资源  
   代表人物只作为势力成员、负责人或关系节点出现；功法、丹药、法宝、灵兽、秘境、商路等只作为势力资源或特色体系出现。  
   “势力外观描述”只记录能代表组织的共同视觉特征，如统一服饰、徽记或族群共相；个别人物的容貌仍归人物模板。不把人物外貌、性格、心理、单场战斗过程、完整剧情摘要塞进组织结构或制度规则。

7. 输出简化  
   保留能体现势力类型、视觉标识、组织层级、制度规则、资源机制、特色体系、对外关系和历史变化的信息。  
   不写项目字段映射，不写游戏化抽象，不为了凑数量扩写低信息量名词。

8. 生成后自检  
   检查是否把人物、物品、功法、丹药、灵兽、身份标签或单次事件误当势力；是否只写主角势力；是否每张卡保留全部字段；势力外观是否有原文依据并与核心区域、组织结构区分；是否把原文体系术语替换成模板术语；是否存在应成卡却被遗漏的外部组织。

## 字段说明

- 名称与别名：写势力主称、别名、旧称、异写、分部名或外界称呼；原文称呼不统一时，说明“原文异写未统一”。
- 原文类型与模板归类：先写作品自己的类型术语，再写模板归类，如综合型宗门、血缘传承型家族、商业交易型势力、族群血脉型势力、军团、学院、寺观等。
- 势力规模与影响范围：写成员数量、弟子或族人规模、凡俗依附人口、分部数量、领地范围、控制区域、商路覆盖、附庸数量、影响阶层、区域地位和势力辐射范围；不明写“原文未说明”。
- 势力外观描述：写能够代表势力的可见特征，如徽记、族徽、旗帜、主色、文字标识、令牌样式、核心驻地的建筑或地貌风格、成员统一服饰与饰物、族群共同体貌、制式装备、仪仗、阵法景象和标志性设施。简单势力可用一段概括；复杂势力按需分为“视觉标识”“核心驻地外观”“成员制式形象”“特殊设施/仪仗”2-4 块，不适用的分块可省略。此字段只写组织层面的共同视觉形象，不展开个别人物容貌；“核心区域”另写地点、功能、准入、产出与风险，二者不要重复。没有明确描写时写“原文未说明”，不得根据势力名称、类型或强弱自行补写。
- 核心区域：写山门、主峰、分峰、族地、王庭、总部、拍卖场、坊市、禁地、秘境入口、修炼设施、资源地、商路、边境据点等位置、功能、进入要求、产出、风险和负责人。
- 组织结构：写宗主、掌门、族长、皇帝、会长、长老、继承人、弟子层级、执事、护法、供奉、客卿、堂主、暗线、附庸等人数、职位、职责、境界、派系和上下级关系。
- 制度规则：按子字段整理，不适用或无依据时写“原文未说明”。
  - 准入与招收：写收徒、入族、入会、招募、客卿、供奉、附庸加入、入场资格等规则。
  - 身份晋升与考核：写弟子晋升、职位升降、继承人选拔、族内考核、职业考核、血脉觉醒或战功晋升等规则。
  - 任务贡献与供给：写任务、贡献、月俸、俸禄、供奉、抽成、分润、护送、族务、战功和日常资源供给。
  - 资源分配与特殊资格：写功法传承、闭关资格、秘境名额、祖地资格、血脉池、贵宾资格、仓储权限、商路使用权等。
  - 奖惩禁令与叛逃处理：写奖惩、禁令、违约赔偿、纠纷仲裁、叛逃、背叛、泄密、内鬼和违规处理。
  - 继承联姻与附属盟约：写掌权者继任、联姻、盟约、附属供奉、分会管理、支族关系、附庸族群关系等。
- 资源基础与特色体系：写灵脉、矿脉、药园、功法传承、丹药库存、法宝库、妖兽材料、凡俗人口、情报网、商路、军备、秘境产出、传承名额、试炼塔、剑冢、血脉池、特殊堂口等。
- 势力目标与内部矛盾：写势力当前目标、长期诉求、扩张方向、生存压力、继承危机、派系斗争、资源分配矛盾、理念冲突、附庸反噬或权力更替隐患等。
- 关键资源 / 代表人物 / 相关事件：写能说明势力制度、资源能力、组织变化或对外关系的资源、人物和事件。
- 对外关系：写关系对象、关系类型、成因、利益、当前变化和后果，如敌对、同盟、附庸、贸易、世仇、联姻、互相忌惮、共同抗敌、暗中合作、争夺秘境或争夺商路等。
- 势力历史：写创建缘由、祖师或开创者、传承变迁、迁徙、鼎盛、衰落、分裂、覆灭、重建、吞并、改名、掌权者更替、资源丢失、秘境开启、战争失败、关键历史人物等重要变化。

  - 奖惩禁令与叛逃处理：保密规则、赊账限制、违约赔偿、纠纷仲裁和内鬼处理。
  - 继承联姻与附属盟约：会长继任、分会管理、合作盟约、护路盟约和地方统治者关系。
- 资源基础与特色体系：货源渠道、商路网络、仓储、情报网、护卫力量、贵宾制度和特殊交易规则。

- 关键资源 / 代表人物 / 相关事件：核心商品、关键拍卖、掌柜、拍卖师、信誉危机和商业战争。

- 势力历史：创建、扩张、分会设立、信誉危机、商业战争和掌权者更替。
