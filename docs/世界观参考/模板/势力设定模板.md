# 势力设定模板


## 适用范围

- 本文用于整理势力百科，为项目中差异化宗门、家族、商会、王朝、妖族、异族组织体系提供参考。
- 本文不写证据段，不写项目字段映射，不写游戏化抽象，不把势力压缩成单一事件案例。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

- 不要只写“某宗门很强”“某家族很大”，要拆成势力定位、核心区域、组织结构、资源基础、制度规则、特色体系、对外关系和历史变化。
- 宗门、家族、商会、妖族等重要势力都要尽量写清势力历史，尤其是创建来源、祖师或开创者、传承变迁、迁徙、鼎盛、衰落、分裂、重建、掌权者更替和重大历史事件。
- 核心区域必须尽量详细，尤其是秘境、禁地、修炼密室、聚灵阵、悟道石、传承碑、藏经阁、武器堂、丹堂、任务堂、药园、矿脉、灵兽园、主峰、分峰等功能场所。
- 凡是原文写了开启条件、进入要求、身份限制、人数限制、消耗、使用次数、持续时间、进入效果、产出、风险和副作用，都要尽量写清。
- 组织结构里如果原文有人数、职位、职责、境界、派系、管理区域、上下级关系，要尽量写清；没有就写“原文未说明”。
- 势力百科不等于小人物名单，不需要罗列无功能、无职责、无影响的小角色；但关键岗位、代表人物和职位职责要写。
- 主角所在势力、反派势力、重要配角所属势力、商会、坊市、异族、妖族、散修组织等都可以写；不要只写主角宗门。
- 尽量选择有明显特色的势力，例如有独特秘境、特殊传承、特殊组织制度、特殊资源场所、特殊职业体系、特殊血脉、特殊商业规则、特殊族群生态或明显不同的运营方式。
- 差异不明显、结构和功能高度重复的普通宗门或普通家族不需要反复写。例如同类修仙家族、同质化小宗门、普通堡寨、普通山门，如果没有独特制度、资源、区域或剧情功能，可以跳过或只在相关事件中顺带提及。
- 像“普通家族堡垒”“普通地方宗门”“只有名字和少量人物、缺少特色设施和制度的势力”，不要为了凑数量单独写成百科案例。
- 原文没有说明规模、人数、区域、资源、制度、进入条件或功能效果时，不要补，可以写“原文未说明”。

参考范围不局限于以下类别：

- **势力类型**：正道宗门、魔道宗门、邪道宗门、中立宗门、修仙家族、凡人王朝、商会、拍卖行、坊市、情报组织、杀手组织、散修联盟、妖族族群、异族部落、学院、寺观、军团。
- **势力定位**：综合宗门、剑修宗门、炼丹宗门、炼器宗门、阵法宗门、符箓宗门、御兽宗门、商业组织、情报组织、战斗宗门、血脉家族、王朝势力。
- **核心区域**：山门主峰、分峰、内门区域、外门区域、禁地、秘境入口、修炼密室、聚灵阵、悟道场、传承殿、藏经阁、任务堂、丹堂、器堂、符堂、阵堂、药园、矿脉、灵兽园、坊市、商路、边境据点。
- **组织结构**：掌门、宗主、族长、皇帝、太上长老、长老、继承人、真传弟子、核心弟子、内门弟子、外门弟子、杂役弟子、执事、护法、供奉、客卿、堂主、暗线、附庸。
- **制度规则**：收徒、晋升、考核、贡献、月俸、任务、奖惩、禁令、闭关资格、秘境名额、继任、联姻、盟约、附属供奉、叛逃处理。
- **资源基础**：灵脉、矿脉、药园、功法传承、丹药库存、法宝库、妖兽材料、凡俗人口、情报网、商路、军备、秘境产出、传承名额。
- **特色体系**：宗门大比、试炼塔、悟道石、祖师传承、剑冢、丹炉地火、炼器火脉、阵法核心、灵兽血脉、特殊秘境、特殊职能堂口。
- **优先采集对象**：有独特秘境的宗门、有特殊传承的宗门、有明确职业分工的宗门、有特殊血脉或族群生态的家族/妖族、有独特交易规则的商会/拍卖行、有特殊试炼制度或修炼设施的势力。
- **可跳过对象**：结构普通、功能重复、只提供背景名字、缺少特色区域和制度的普通家族、小宗门、堡寨、临时据点。
- **对外关系**：敌对、同盟、附庸、贸易、世仇、联姻、互相忌惮、共同抗敌、暗中合作、争夺秘境、争夺商路。
- **宗门历史 / 势力历史**：创建来源、祖师或开创者、传承变迁、迁徙、鼎盛时期、衰落原因、分裂、覆灭、重建、吞并、改名、掌门更替、资源丢失、秘境开启、战争失败、关键历史人物。

## 案例

### 案例

#### 案例 1：综合型修仙宗门

势力类型：正道宗门 / 中立宗门 / 综合型修仙宗门；具体阵营按原文填写。

势力定位：以弟子培养、功法传承、宗门任务、秘境试炼、资源经营为主；如果宗门另有剑修、炼丹、炼器、御兽、阵法等特色，要单独写清。

核心区域：

- 山门主峰：写清位置、象征意义、主要功能、进入要求、负责人物和常驻职位；如原文写有掌门大殿、议事殿、祖师殿等，要分别说明。
- 内门区域：写清内门弟子居住、修炼、领任务、听讲法、参加比试的地点；如果原文有人数或进入条件，要写清。
- 外门区域：写清外门弟子、杂役弟子、低阶执事的活动范围、职责、资源待遇和晋升路径。
- 修炼密室 / 聚灵阵：写清进入要求、身份限制、消耗资源、修炼效果、使用时间、名额限制和副作用；原文未说明则写“原文未说明”。
- 秘境 / 禁地：写清开启条件、开启周期、进入要求、进入人数、境界限制、进入效果、主要产出、风险、死亡率和退出方式。
- 悟道石 / 传承碑 / 祖师殿：写清使用要求、身份限制、效果、次数限制、传承内容、失败后果和是否会改变地位。
- 藏经阁：写清功法等级、进入权限、兑换条件、守阁人物、借阅限制和违规后果。
- 武器堂 / 丹堂 / 符堂 / 阵堂 / 任务堂：分别写清负责什么、管理者是谁、职位职责、可领取或兑换的资源，以及与弟子晋升的关系。
- 药园 / 矿脉 / 灵兽园：写清产出资源、管理者、守护阵法、采集要求、上交比例、被盗或被袭后的影响。
- 分峰 / 支脉：如果宗门有多个山峰、堂口或支脉，要写清各自方向、负责人、弟子构成、资源差异和派系关系。

组织结构：

- 掌门 / 宗主：人数、职责、权力范围、境界、代表人物；原文未说明则写“原文未说明”。
- 太上长老 / 长老：人数、职责、管理区域、派系、是否参与宗门决策或只闭关护宗。
- 堂主 / 执事 / 护法：人数、职责、负责部门、日常事务、任务发布、资源分配、惩戒权限。
- 真传 / 核心 / 内门 / 外门 / 杂役：人数、晋升条件、职责、资源待遇、居住区域、考核方式。
- 客卿 / 供奉 / 附庸：人数、来源、职责、待遇、是否参与战争、炼丹炼器或护宗事务。

制度规则：写清收徒、入门检测、晋升、贡献、月俸、任务、宗门大比、闭关资格、秘境名额、奖惩、禁令、叛逃处理和继任规则。

资源基础：灵脉、矿脉、药园、丹药库存、法宝库、功法传承、秘境、坊市、附庸势力、凡俗人口、情报网等；有数量、等级、产出周期就写清。

特色体系：写清该宗门最有辨识度的地方，例如剑修传承、炼丹地火、炼器火脉、试炼塔、悟道石、护宗大阵、灵兽园、秘境名额、特殊大比。

对外关系：敌对宗门、盟友、附庸、贸易对象、共同探索秘境对象、世仇、联姻对象、互相忌惮的势力等。

宗门历史：写清创建来源、祖师或开创者、传承变迁、迁徙、鼎盛时期、衰落原因、掌门更替、关键长老陨落、秘境开启、战争、资源丢失、宗门覆灭或重建等。

#### 案例 2：修仙家族

势力类型：修仙家族 / 血脉家族 / 地域家族。

势力定位：以血缘传承、族地经营、联姻、矿脉药园、族内弟子培养和对外依附为主；如果有特殊血脉、传承功法或祖地秘境，要重点写。

核心区域：

- 族地 / 主宅：写清位置、家族核心建筑、议事地点、族长居所、防护阵法和进入要求。
- 祖祠 / 祖地：写清祭祀、传承、血脉检测、族谱、祖器、祖训和进入限制。
- 家族秘境 / 传承地：写清开启条件、血脉要求、境界要求、人数限制、进入效果、产出和失败后果。
- 药园 / 矿脉 / 商铺：写清产出、管理者、收益归属、守卫力量和被争夺后的影响。
- 修炼室 / 族学：写清族中子弟修炼、学习、考核、晋升和资源分配方式。

组织结构：

- 族长：人数、职责、权力范围、境界、继任方式。
- 长老 / 族老：人数、职责、派系、管理资源、是否掌握惩戒或分配权。
- 嫡系 / 旁系 / 外姓供奉：人数、地位差异、资源待遇、职责和矛盾。
- 年轻一代 / 继承人：人数、培养方式、竞争规则、婚姻安排和外出历练要求。

制度规则：写清血脉检测、族内考核、继承顺位、联姻、供奉制度、资源分配、族规、叛族惩罚和对外依附规则。

资源基础：族地灵脉、祖传功法、祖器、药园、矿脉、商铺、凡俗人口、附属村镇、联姻网络和外部靠山。

特色体系：特殊血脉、祖地传承、家族秘术、联姻体系、嫡庶竞争、族内试炼、祖器认可等。

对外关系：依附宗门、敌对家族、联姻家族、贸易伙伴、保护对象、被吞并或被扶持的势力。

势力历史：写清家族开创者、祖地来源、血脉传承变迁、家族崛起、衰落、迁徙、族长更替、继承争斗、血脉断绝、被宗门扶持、被敌族灭门或重建。

#### 案例 3：商会 / 拍卖行 / 坊市势力

势力类型：商会 / 拍卖行 / 坊市 / 情报交易组织。

势力定位：以资源流通、拍卖、鉴定、情报、护送、商路、黑市或跨区域贸易为主。

核心区域：

- 总部 / 主楼：写清位置、功能、进入要求、负责人和安全防护。
- 拍卖场：写清拍卖开启条件、进入资格、保证金、贵宾席、拍品来源、保密规则和竞价风险。
- 鉴宝处 / 交易柜台：写清鉴定流程、手续费、是否保密、是否可能压价或泄露情报。
- 仓库 / 宝库：写清存放资源、防护阵法、守卫力量、被劫风险和资源等级。
- 黑市 / 私下交易点：写清开启时间、进入方式、身份伪装、交易风险、黑吃黑和执法势力反应。
- 商路 / 分会：写清路线、护卫、传送阵、沿途风险、分会职责和收益来源。

组织结构：

- 会长 / 行主：人数、职责、权力范围、境界、代表人物。
- 管事 / 鉴定师 / 拍卖师：人数、职责、权限、是否掌握情报。
- 护卫 / 客卿 / 供奉：人数、职责、护送、镇场、追债、保密和反劫掠。
- 探子 / 情报人员：人数、渠道、负责收集拍品、通缉、秘境、强者动向等消息。

制度规则：写清入场资格、保证金、抽成、保密制度、违约惩罚、赊账、押物、护送规则、黑市规矩和交易纠纷处理。

资源基础：灵石库存、拍品来源、商路、护卫力量、鉴定师、情报网、贵宾客户、仓库、分会和黑市渠道。

特色体系：大型拍卖、匿名交易、贵宾等级、情报买卖、跨区域商路、黑市入口、护送任务、以物易物。

对外关系：合作宗门、依附强者、敌对劫修、黑市组织、执法势力、长期客户和被通缉者。

势力历史：写清商会创建来源、创始人、扩张路线、关键分会建立或被灭、重大拍卖、宝物泄露、信誉受损、会长更替、商路中断或恢复。

#### 案例 4：妖族 / 异族势力

势力类型：妖族族群 / 异族部落 / 王族血脉势力 / 禁地族群。

势力定位：以血脉、领地、族群传承、妖兽资源、化形制度、族群战争或界面生存为主。

核心区域：

- 族地 / 巢穴 / 王庭：写清位置、进入要求、守卫力量、族群等级和外人进入风险。
- 血脉池 / 祖地：写清开启条件、血脉要求、进入人数、觉醒效果、失败后果和族内地位变化。
- 禁地 / 试炼地：写清进入要求、试炼内容、产出、死亡风险和成功奖励。
- 资源地：写清灵药、妖兽材料、矿脉、特殊环境、领地边界和争夺对象。
- 化形或进阶场所：写清进阶条件、天劫场地、护法要求、失败后果和族群反应。

组织结构：

- 族长 / 妖王 / 王族首领：人数、职责、境界、血脉地位、统治范围。
- 长老 / 护法 / 战士：人数、职责、守护族地、训练族人、参与战争。
- 王族 / 普通族人 / 附属族群：人数、血脉差异、地位、资源待遇和职责。
- 幼兽 / 年轻一代：培养方式、试炼要求、血脉觉醒流程和外出限制。

制度规则：血脉等级、族内继承、试炼、领地分配、资源上交、附属族群供奉、外族通婚、叛族惩罚。

资源基础：领地、灵药、妖丹、血脉传承、族群战力、禁地资源、附属族群、特殊地形和跨族盟约。

特色体系：血脉觉醒、化形、天赋神通、族群威压、王族传承、兽潮号令、禁地试炼。

对外关系：人族宗门、猎妖修士、敌对妖族、附属族群、贸易对象、共同抵御强敌的盟友。

势力历史：写清族群起源、祖血来源、王族更替、族群迁徙、血脉衰落、族地被攻破、兽潮爆发、与人族战争、禁地开启或族群复兴。

### 待定案例

1. 对象名称：关键摘要（来源）；新增摘要（来源）。
