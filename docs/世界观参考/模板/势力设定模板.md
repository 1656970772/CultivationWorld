# 势力设定模板

## 适用范围

本模板用于整理作品中明确存在并能够持续组织成员、资源和集体行动的宗门、门派、家族、王朝、商会、拍卖行、坊市、学院、寺观、军团、情报组织、杀手组织、散修联盟、妖族、异族、附庸组织等。

本模板只整理势力本体：组织边界、共同认同、权力运行、成员生命周期、领地设施、资源闭环、核心能力、日常运行、外部关系、内部状态和历史阶段。地域、人物、功法、物品、丹药、灵兽、秘境、单次事件和社会现象只在相关字段中作为组织要素或变化结果简要出现，本体内容放入对应专题。

临时队伍、偶然合作的两人或数人组合、普通地名、松散社会区域、单个强者、个人附庸关系、一次性行动队和仅有共同敌人的群体，不具备稳定成员归属、共同目标、权力规则、资源基础和持续集体行动能力时，不建立完整势力卡。

## 整理原则

1. 先做势力准入：至少确认稳定成员归属、共同目标或认同、权力与规则、资源基础、持续集体行动中的主要条件；不足时降为关系记录、区域记录、人物关系或事件记录。
2. 先划清组织边界：区分本体、分部、业务机构、执行单位、附庸、外围成员、雇员、客户、盟友、临时合作者和受治理对象；相关者不自动等于成员。
3. 一势力一卡：同名、别名、旧称、分部、阶段变化和后续状态归入同一卡；只有成员边界、核心认同、权力体系和资源账已经实质分离的组织才另建卡。
4. 字段只写势力相关内容：不写人物传记、个人修炼、单件物品、完整功法、丹药效果、战斗招式、逐章剧情或无关地域描述；不设置或展开使用记录、事件记录和逐条过程日志。
5. 先写存在逻辑，再写组织清单：说明势力解决什么问题、成员为何留下、权力为何被接受、组织向成员和外部提供什么，再整理职位、领地、资源和能力。
6. 区分基础、运行、能力和状态：成员/权力/制度/领地/资源属于组织基础；招募/决策/执行/供给/监督属于运行；军事/生产/贸易/情报/治理属于可重复能力；正常/压力/异常/极端属于状态。
7. 资源、能力和产出分开：资源是组织控制或依赖的投入，能力是组织能够稳定完成的事情，产出是持续形成的产品、服务、秩序、保护、情报、人才或影响力。
8. 关系只写利益和变化：对外关系记录形成原因、交换或争夺的利益、依赖程度、当前状态和变化条件，不复述关系事件的完整经过。
9. 事实与归纳分开：使用“原文明确”“实际表现”“稳定归纳”“人物评价或传闻”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不得根据势力类型、名称或常见套路补齐制度、战略和文化。
10. 控制输出密度：普通字段以一至三条短句为主；低信息势力不机械展开所有子项；关键资源、代表人物和相关事件索引只保留少量对象，并将每项压缩为“对象名称 + 对势力的作用或变化”一句总结。

## 信息与输出规则

1. 世界观式势力卡只保留稳定结论：原文描写、对白、数字和事件顺序，只有在能说明成员边界、权力、资源、能力、关系或状态变化时，才压缩为一句组织设定。
2. 批次合并后统一当前状态：早期成员、目标和权力中心写入历史阶段；当前字段只保留同一状态截面，不混写互相冲突的阶段事实。
3. 低信息项如实处理：无证据时写“原文未说明”；范围不足时写“本次未覆盖到明确内容”；不适用时写“不适用”，不要用泛化语句填满字段。
4. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留总结结论和确定性类型。
5. 禁止具体事件清单：历史、状态、日常运行和关系字段不得写人物逐步行动、对白、战斗日志、交易明细或完整剧情复述。
6. 索引只写组织关联摘要：资源采用“资源名称 + 组织控制/依赖及用途”一句概括；人物采用“身份 + 组织功能或影响”一句概括；事件采用“事件名称 + 对权力、资源、成员、领地、关系或状态的结果变化”一句概括。每类只保留少量关键项，不摘录原文、不写人物传记、不写资源属性百科、不写事件经过或逐条过程。
7. 输出前自检：检查是否误收地域、人物、临时组合或单次事件；成员分类是否清楚；正式职位和实际权力是否区分；资源闭环、稳定能力、关系条件、阶段状态和信息边界是否完整且不重复。

## 字段说明

- 名称与别名：填写势力主称、别名、旧称、异写、分部名或外界称呼；同一组织只确定一个报告用名，异写不另建卡。
- 原文类型与模板归类：先写作品自身的类型术语，再写模板归类，如宗门、家族、王朝、商业势力、学院、军团、族群、情报组织或附庸组织。
- 核心定位、共同认同与合法性：总结势力为什么存在、成员为什么合作、权力为什么被接受以及组织向成员和外部提供的核心价值。
  - 核心定位：修炼、生产、治理、军事、贸易、情报、信仰、族群保护或其他稳定功能。
  - 创建或存续理由：势力解决的问题和继续存在的主要原因。
  - 共同认同：血缘、传承、信仰、利益、地域、敌人、使命或身份认同。
  - 权力合法性来源：血脉、推举、传承、武力、制度、神授、财富、信誉或外部承认。
  - 对成员的核心承诺：保护、资源、晋升、秩序、身份、信仰归属或其他回报。
- 组织边界、成员构成、规模与影响层级：区分谁属于势力、谁只是关联者，以及组织实际能够控制或影响到哪里。
  - 成员分类：正式成员、核心成员、外围成员、附庸与依附者、临时合作者、客户、盟友和受治理对象。
  - 成员规模与构成：数量、来源、地域、族群、血缘、修为或职业构成；没有依据时不估算。
  - 控制与影响范围：正式领地、据点、商路、人口、制度和间接影响区域。
  - 区域地位：霸主、强势参与者、地方组织、边缘势力或其他相对位置。
- 势力外观描述：填写徽记、族徽、旗帜、主色、文字标识、令牌、核心驻地风格、成员共同服饰、制式装备、仪仗和标志性设施；只写组织共同视觉，不写个别人物容貌或单次战斗特效。
- 领地、驻地与关键设施：填写实际控制或稳定依赖的山门、族地、王庭、总部、分部、商路、边境、资源地和关键设施，以及其主要功能、控制与准入、组织产出、承载能力和脆弱点。
- 组织结构与权力运行：同时写名义层级和实际权力。
  - 正式层级：掌权者、长老、继承人、执行层、基层成员和附庸的关系。
  - 决策机制：议题提出、决策、否决、授权和重大政策改变由谁负责。
  - 执行与反馈：堂口、分峰、军团、分会、支族、暗线等执行单位的职责，命令传递和结果反馈。
  - 监督与制衡：监察、审计、族规、誓约、阵法、长老牵制或其他约束。
  - 实际权力：名义职位与真实掌控者、派系、元老、供奉、姻亲、强者或财源控制者的差异。
- 制度规则与成员生命周期：按成员进入、培养、使用、晋升、任职、退出和替补整理，个别待遇不得直接概括为普遍制度。
  - 准入与招收：收徒、入族、招募、客卿、供奉、附庸加入和资格限制。
  - 培养与认同：教育、训练、仪式、师徒、族群教化和身份塑造。
  - 晋升与考核：弟子晋升、职位升降、继承选拔、族内考核、职业考核、血脉觉醒或战功晋升。
  - 义务与权利：任务、族务、服役、保密、纳贡、投票、申诉、保护和资源领取。
  - 资源与奖惩：贡献、俸禄、分润、战功、特殊资格、禁令、仲裁、违约、泄密和叛逃处理。
  - 脱离与补位：退役、毕业、分家、逐出、退出、死亡、失踪、叛逃和空缺补充。
- 资源基础与运行闭环：用“来源 -> 转化 -> 储运 -> 分配 -> 对外交换 -> 再生产”总结资源运行；若无法形成闭环，只写已确认环节。
  - 核心资源与获取渠道：灵脉、矿脉、药园、功法、人口、情报、商路、军备、设施，以及生产、采集、税赋、纳贡、贸易、任务、战争或外部供给。
  - 生产与转化：原料如何转成人才、丹器、战力、情报、财富、秩序或影响力。
  - 储运、分配与消耗：仓储、护送、账目、道路、传送、保密、分配标准和日常维护。
  - 对外交换与再生产：商品、服务、税赋、盟约交换，以及收益如何反哺生产、招募、训练、设施和关系网络。
  - 关键依赖与断供后果：最难替代的资源、渠道或人才，以及失去后的组织影响。
- 核心能力与组织产出：只写势力能够稳定、重复完成的能力，不把一次成功战斗或个别强者能力上推为组织能力。
  - 军事与防御：动员、指挥、攻坚、守土、威慑和持续作战。
  - 生产与经营：炼制、培育、制造、贸易、金融、教育或其他生产。
  - 情报、运输与后勤：侦察、通信、保密、调度、补给、医疗、撤离和驻守。
  - 外交与治理：谈判、盟约、仲裁、征税、治安、教化和附庸管理。
  - 稳定产出：人才、产品、服务、秩序、保护、情报或长期影响力。
  - 上限与短板：在规模、距离、资源、人才或敌我条件变化时能力如何下降。
- 日常运行与典型行动方式：总结势力平时如何决策、分工、协同、处理冲突并根据结果调整。
  - 日常决策循环：议题提出、决策、执行、反馈和修正。
  - 任务与协同：不同层级和单位的分工、命令和冲突处理。
  - 常规对内活动：训练、生产、会议、祭祀、巡查、征收、教育和成员服务。
  - 常规对外活动：贸易、招募、巡逻、外交、情报、传教、狩猎或其他稳定活动。
  - 竞争或战争方式：动员、封锁、谈判、渗透、撤退、迁徙和资源保护的惯用方式。
- 当前目标、发展战略与内部动态：区分当前待办事项、长期方向、发展阶段和可能的组织失稳来源。
  - 当前目标与长期战略：扩张、守成、复兴、垄断、迁徙、传承或生存方向。
  - 发展阶段与方向：创建、成长、扩张、成熟、收缩、转型或衰退，以及扩张或收缩的对象。
  - 凝聚力来源：认同、利益、威胁、制度、强者、血缘或信仰。
  - 派系与冲突：派系基础、利益分配、路线、族群、嫡旁、地域、使命和继承冲突。
  - 权力隐患：接班、代理、强者压制、权力真空和资源断裂。
- 对外关系、外部评价与环境互动：按关系对象总结关系形成、利益交换、依赖程度、当前状态和变化条件。
  - 关系对象与类型：敌对、同盟、附庸、贸易、联姻、竞争、共同抗敌或其他关系。
  - 交换或争夺的利益：资源、领地、人口、技术、身份、商路或安全。
  - 力量与依赖：关系是否对称，谁更依赖谁。
  - 当前状态与变化条件：稳定、改善、恶化、转向、冻结、破裂、升级或修复条件。
  - 外部评价：其他主体对该势力的信任、畏惧、依赖、排斥或轻视。
  - 环境互动：对市场、人口、职业、信仰、法律、秩序、资源分布、交通和生态的实际影响，以及外部环境对势力的反向制约。
- 正常运行、压力状态与极端状态：只记录组织结构和运行功能的变化，不把个别成员受伤或单次战斗直接等同于组织异常。
  - 正常运行：供给、命令、成员合作和对外活动如何稳定进行。
  - 压力状态：资源紧张、外敌、灾害、继承危机和内部竞争下的承压与调整。
  - 异常状态：命令失灵、派系失控、供给中断、附庸反噬、信誉崩坏等结构性故障。
  - 极端状态：内战、迁徙、解体、覆灭、族群灭绝风险或彻底转型。
  - 危机应对、恢复条件与不可逆损失：集权、动员、配给、谈判、撤退、迁徙、改革，以及无法恢复的成员、传承、领地、信誉和认同损失。
- 历史阶段、转型与后续影响：按势力生命周期总结形成前提、创建、早期生存、成长扩张、成熟、关键转折、衰退分裂、转型合并、覆灭、当前状态和遗留影响；未经历的阶段写“不适用”。
- 关键资源、代表人物与相关事件索引：作为“组织关联摘要”使用，每类只保留少量最能解释势力运行的对象；每项只写一句总结，不复制正文或原文。
  - 关键资源索引：填写“资源名称：组织对其的控制或依赖，以及它对组织运行的直接作用”；不写资源本体属性、来历、加工过程或个人持有物。
  - 代表人物索引：填写“成员身份：其在组织中的职责、权力或对组织状态的直接影响”；不写个人履历、境界、功法、装备和完整事迹。
  - 相关事件索引：填写“事件名称：该事件对势力的权力、资源、成员、领地、关系或状态造成的主要结果”；不写参与者名单、经过、对白、战斗过程和后续剧情。
- 信息边界与待确认项：区分原文明确、实际表现、稳定归纳、人物评价或传闻、上下文推断、其他合理解释、原文未说明、本次未覆盖到明确内容和不适用；不写任何来源位置或证据标注。
