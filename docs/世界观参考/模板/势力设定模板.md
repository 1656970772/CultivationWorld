# 势力设定模板

## 适用范围

用于整理势力百科，为项目中差异化宗门、家族、商会、王朝、妖族、异族组织体系提供参考。

## 前置声明

- 样本要覆盖不同势力类型、地域层级、阵营、发展阶段和结局；不要只写主角所在势力。
- 本文不写证据段，不写项目字段映射，不写游戏化抽象，不把势力压缩成单一事件案例。
- 优先整理有独特秘境、传承、组织制度、资源场所、职业体系、血脉、商业规则、族群生态或运营方式的势力。
- 结构普通、功能重复、只提供背景名字、缺少特色区域和制度的势力，不必为了凑数量单独写成百科案例。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 势力类型 | 正道宗门、魔道宗门、邪道宗门、中立宗门、修仙家族、凡人王朝、商会、拍卖行、坊市、情报组织、杀手组织、散修联盟、妖族、异族、学院、寺观、军团 | 写清基本性质和阵营。 |
| 势力定位 | 综合宗门、剑修宗门、炼丹宗门、炼器宗门、阵法宗门、符箓宗门、御兽宗门、商业组织、情报组织、血脉家族、王朝势力 | 写清靠什么立足。 |
| 核心区域 | 山门主峰、分峰、内外门、禁地、秘境入口、修炼密室、聚灵阵、悟道场、传承殿、藏经阁、任务堂、丹堂、器堂、药园、矿脉、灵兽园、坊市、商路、边境据点 | 写清位置、功能、进入要求、产出、风险和负责人。 |
| 组织结构 | 掌门、宗主、族长、皇帝、太上长老、长老、继承人、真传、核心、内门、外门、杂役、执事、护法、供奉、客卿、堂主、暗线、附庸 | 写清人数、职位、职责、境界、派系和上下级关系；不明写“原文未说明”。 |
| 制度规则 | 收徒、晋升、考核、贡献、月俸、任务、奖惩、禁令、闭关资格、秘境名额、继任、联姻、盟约、附属供奉、叛逃处理 | 写清进入条件、身份限制、消耗、次数、持续时间、效果、风险和副作用。 |
| 资源基础 | 灵脉、矿脉、药园、功法传承、丹药库存、法宝库、妖兽材料、凡俗人口、情报网、商路、军备、秘境产出、传承名额 | 写清资源来源、产出周期、管理者和争夺风险。 |
| 特色体系 | 宗门大比、试炼塔、悟道石、祖师传承、剑冢、丹炉地火、炼器火脉、阵法核心、灵兽血脉、特殊秘境、特殊职能堂口 | 写清该势力最有辨识度的机制或区域。 |
| 对外关系 | 敌对、同盟、附庸、贸易、世仇、联姻、互相忌惮、共同抗敌、暗中合作、争夺秘境、争夺商路 | 写清关系来源、利益和变化。 |
| 势力历史 | 创建来源、祖师或开创者、传承变迁、迁徙、鼎盛、衰落、分裂、覆灭、重建、吞并、改名、掌权者更替、资源丢失、战争失败 | 重要势力都要尽量写清历史变化。 |

通用势力卡字段：

- 势力类型与定位：不要只写“很强”或“很大”，要写清靠什么制度、资源或传承立足。
- 核心区域：尤其写秘境、禁地、修炼密室、聚灵阵、悟道石、传承碑、藏经阁、武器堂、丹堂、任务堂、药园、矿脉、灵兽园、主峰、分峰等功能场所。
- 组织结构：关键岗位、代表人物和职位职责要写；无功能、无职责、无影响的小人物不必罗列。
- 制度规则：凡是原文写了开启条件、进入要求、身份限制、人数限制、消耗、次数、持续时间、效果、产出、风险和副作用，都要写清。
- 资源基础与特色体系：写清资源如何支撑势力运转，以及最有辨识度的体系。
- 对外关系与势力历史：写清敌友、附庸、贸易、联姻、战争、迁徙、衰落、重建和掌权者更替。

## 案例

### 案例

#### 案例 1：综合型修仙宗门

按通用势力卡填写。重点写弟子培养、功法传承、宗门任务、秘境试炼、资源经营、分峰堂口、内外门晋升和宗门历史。

#### 案例 2：修仙家族

按通用势力卡填写。重点写血缘传承、族地、祖祠、祖地秘境、族内考核、嫡庶或旁系差异、联姻、族规、家族兴衰和外部靠山。

#### 案例 3：商会 / 拍卖行 / 坊市势力

按通用势力卡填写。重点写总部、拍卖场、鉴宝处、仓库、黑市、商路、分会、入场资格、抽成、保密、赊账、护送、情报和交易纠纷。

#### 案例 4：妖族 / 异族势力

按通用势力卡填写。重点写族地、巢穴、王庭、血脉池、祖地、禁地、试炼地、资源地、化形或进阶场所、血脉等级、族群继承和对外战争。
