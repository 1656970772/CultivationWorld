# 功法术法神通模板


## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的功法、心法、术法、神通、秘术、禁术、身法、遁术、剑诀、炼体法、神识法、御兽术、傀儡术、控虫术、采补术、夺舍法、封印法、占卜推演法等。

本模板只做功法术法神通分析，不展开材料、丹药、武器、法宝、职业流程本体。若某种功法依赖丹药、材料、法宝、阵法或职业技艺，可在“修炼前置条件”“限制/副作用”中说明，并交叉参考对应模板。

## 前置声明

- 覆盖不同类别、属性、功效类型和适用境界；不要只写主角功法或少数名场面。
- 只写原文、资料来源或可靠依据能支撑的功法体系。缺失字段写“原文未说明”，不得补造品阶、层数、效果或数值。
- 每一类功法术法、每一种用途、每一个境界阶段，只要原文有对应内容，都应尽量写成独立卡片。
- 案例只是最低写法示范，不是数量上限；有价值的功法、术法、神通和特殊法门都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充来源，成熟后转为 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 提示 |
|------|------|
| 名称 | 写小说中的功法、心法、术法、神通、秘术、禁术、身法、剑诀等名称。 |
| 类别 | 写修炼心法、攻击术法、防御术法、身法遁术、神识秘术、炼体法、御兽术、傀儡术、禁术等。 |
| 属性分类 | 写金木水火土、风雷冰毒、血魂、空间、时间、阴阳、剑道、体修、神识、妖兽、傀儡等；不明写“原文未说明”。 |
| 稀有度 | 按作品描述填写，如基础功法、宗门传承、家族秘传、上古残篇、禁忌秘术、仙界法门等。 |
| 功效 | 写修炼或施展后的基础效果。 |
| 特殊功效 | 写越阶、控兽、控傀、隐匿、吞噬血脉、夺舍、封印、推演、改变体质、引动法则等。 |
| 用途 | 写日常修炼、突破辅助、战斗、保命、赶路、侦查、传承、任务奖励等。 |
| 修炼前置条件 | 写灵根、体质、血脉、境界、神识、材料、法宝、阵法、契约、祭品、环境、心境、师承等。 |
| 层数/阶段 | 写层、卷、重、式、境等结构；不明写“原文未说明”。 |
| 每层效果 | 按原文整理每层、每重、每卷或每式的效果、门槛、变化和副作用。 |
| 载体/传承方式 | 写玉简、秘籍、石碑、口传、神魂、血脉、梦境、残篇、碑文、藏经阁、器灵传授等。 |
| 来源 | 写宗门、家族、师承、坊市、拍卖、秘境、遗迹、杀人夺宝、妖族传承、奇遇、任务奖励等。 |
| 限制/副作用 | 写门槛、走火入魔、反噬、寿元消耗、血祭、心魔、根基损伤、功法冲突、禁忌风险、正邪评价等。 |
| 适用境界 | 按作品自己的境界说法填写。 |

## 案例

### 案例

#### 类型示例

| 类型 | 示例 | 重点 |
|------|------|------|
| 基础修炼法 | 吐纳法、入门心法 | 入门条件、修炼上限、日常修炼效果。 |
| 战斗术法 | 攻击术、防御术、遁术、剑诀 | 施展条件、消耗、命中方式、克制与反制。 |
| 特殊法门 | 御兽术、傀儡术、控虫术、神识法 | 操控对象、契约或控制方式、失控风险。 |
| 禁忌秘术 | 夺舍法、血祭法、采补术、封印法 | 代价、副作用、正邪评价、失败后果。 |

#### 通用功法卡片

- **名称**：写原文名称。
- **类别 / 属性分类 / 稀有度**：按原文描述填写；不明写“原文未说明”。
- **功效 / 特殊功效 / 用途**：写实际效果和使用场景，不把推测当事实。
- **修炼前置条件**：写资质、境界、材料、法宝、环境、师承或契约等。
- **层数/阶段与每层效果**：按原文层级写；没有逐层信息则写“原文未说明”。
- **载体/传承方式与来源**：写从哪里、以什么方式获得。
- **限制/副作用与适用境界**：写门槛、反噬、冲突、代价和作品境界名称。
