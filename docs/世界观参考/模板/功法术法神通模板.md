# 功法术法神通模板

## 适用范围

本模板用于整理作品中出现过，或能由小说内容明确支撑的功法、心法、术法、神通、秘术、禁术、身法、遁术、剑诀、炼体法、神识法、御兽术、傀儡术、控虫术、采补术、夺舍法、封印法、占卜推演法等。

本模板只做功法、术法、神通、秘术和特殊法门分析，不展开材料、丹药、武器、法宝、阵法、职业流程本体。若某种功法依赖丹药、材料、法宝、阵法或职业技艺，只能在“修炼前置条件”“限制/副作用”中说明，不得把丹药、材料、职业体系、普通训练、普通医术或剧情说明写成主卡。

只有原文明确表现为修炼法门、施展术法、斗技招式、神通能力、禁术秘法、传承道书、口诀法诀、身法遁术、炼体神识法、御兽傀儡控虫法等，才进入本模板。普通道具、药物、急救手段、职业身份、战斗结果和泛泛的“提升实力”描述，不能单独成卡。

## 整理原则

1. 一法一卡  
   同一功法、术法、神通、斗技、口诀、道书、剑诀或特殊法门的正式名、别名、早期暂名、误称、阶段变化和后续补充，都必须归并到同一张卡。  
   后文出现正式名时，标题使用正式名，旧称写入“正式名/别名”。禁止另建“某某（补充）”“某某后期”“神秘某功法”等重复卡。

2. 字段完整  
   每张卡必须包含：名称、正式名/别名、类别、属性分类、稀有度/品阶、来历、功效、特殊功效、用途、修炼前置条件、总层数/阶段、每层效果、施法外观描述、载体/传承方式、来源、限制/副作用、适用境界、功法术法神通进阶、后续变化、纳入依据。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

3. 作品术语原样保留  
   境界、品阶、阶段、修炼体系和能力名称必须使用作品自己的说法。  
   不得把其他体系词汇套入当前作品，例如斗气体系不要写成炼气体系，斗技品阶、修仙境界、道书阶段、妖族血脉等都要按原文表述。

4. 边界清楚  
   丹药、药丸、材料、法宝、阵法、职业体系、医术、普通训练、普通武器和剧情说明不写成主卡。  
   这些内容只有在直接作为某门功法的前置条件、辅助资源、施展媒介、限制代价或背景来源时，才写入对应字段。

5. 合并去重  
   同一法门不同阶段不要拆成多个无关系卡片；可在“总层数/阶段”“每层效果”“后续变化”中承接。  
   标题和字段必须一致，不能出现标题是丹药、字段却写术法，或标题是某功法、内容混入另一人物训练流程的情况。

6. 具体化描述  
   “战斗、保命、修炼、提升实力”等泛化表述必须补充具体施展条件、效果边界、代价或限制。  
   品阶、层数、属性、适用境界、前置条件和副作用若原文没有明确说明，写“原文未说明”，不要用常识补齐。

7. 分层描述施法外观  
   施法外观应记录法门施展或运转时可直接观察到的形态、颜色、光影、法相、符文、气流、声音、覆盖范围和天地异象。  
   同一法门在不同层、重、卷、式或阶段的施法外观不同时，必须在“施法外观描述”下按作品原有层次名称建立子字段分别描述；外观无差异时直接填写共通内容，差异不明时写“原文未说明”。

8. 区分内在层次与后续进阶  
   “每层效果”记录法门原有层、重、卷、式的修炼效果；“功法术法神通进阶”记录后续强化、升阶、改造、补全、融合其他法门或演化为新形态的过程。  
   可以再次强化或融合时，必须按强化阶段分别写明强化条件和强化后效果；强化条件可包括前置层次、境界、材料、环境、血脉、法宝、传承、悟性或待融合功法。

9. 样本覆盖均衡  
   样本要覆盖不同类别、属性、用途、境界阶段和创造来源；不要只写主角、早期功法、少数名场面或成功案例。  
   攻击、防御、身法、遁术、神识、炼体、御兽、傀儡、控虫、夺舍、封印、推演、辅助修炼等类型，只要原文有支撑，都应纳入。

10. 输出简化  
   保留法门判断所需的名称、归类、来历、效果、施法外观、门槛、传承、进阶、限制和后续变化，不展开无关剧情背景。  
   不为补齐字段虚构品阶、层数、境界梯度、外观、进阶路线、数值体系、来源或副作用。

## 字段说明

- 名称：写小说中的功法、心法、术法、神通、秘术、禁术、身法、剑诀、御兽术、傀儡术等名称。
- 正式名/别名：写正式名、早期暂名、别称、误称、简称、不同阶段名称；没有写“原文未说明”。
- 类别：写修炼心法、攻击术法、防御术法、身法遁术、神识秘术、炼体法、剑诀、御兽术、傀儡术、控虫术、毒功、采补术、夺舍法、封印法、禁术等。
- 属性分类：写功法属性或倾向，如金、木、水、火、土、风、雷、冰、毒、血、魂、空间、时间、因果、阴阳、五行、剑道、体修、神识、妖兽、傀儡等；没有明确属性时写“原文未说明”。
- 稀有度/品阶：按作品自己的描述填写，如常见基础功法、宗门传承、家族秘传、上古残篇、禁忌秘术、仙界法门、黄阶斗技、玄阶低级等。
- 来历：较完整地描述法门出自何处、由谁创造或整理、创法背景、原始用途、传承起点、历史事件、改造过程及相关宗门、家族或族群；部分信息不明时保留已明确背景，并将不明项写为“原文未说明”，不要只写一个人名或地点。
- 功效：写修炼或施展后的基础效果。
- 特殊功效：写普通功效之外的特殊能力，如越阶战斗、控制妖兽、操控傀儡、隐藏气息、吞噬血脉、夺舍、封印、推演天机、改变体质、引动法则等。
- 用途：写功法术法被如何使用，如日常修炼、突破辅助、战斗、保命、赶路、侦查、控制妖兽、操控傀儡、宗门传承、任务奖励等。
- 修炼前置条件：写所需灵根、体质、血脉、境界、神识、法力、材料、法宝、阵法、契约、祭品、环境、心境、前置功法或师承资格；不明时写“原文未说明”。
- 总层数/阶段：写功法总共有多少层、多少卷、多少重、多少式、多少境；不明时写“原文未说明”。
- 每层效果：按原文整理每层、每重、每卷或每式的效果、门槛、变化和副作用；没有逐层信息时写“原文未说明”。
- 施法外观描述：写法门施展或运转时的动作、形态、颜色、光影、法相、符文、气流、声音、覆盖范围、天地异象和其他可直接观察到的表现；不同层次外观不同时，应在本字段下按层、重、卷、式或阶段分别描述；不明时写“原文未说明”。
- 载体/传承方式：写玉简、秘籍、石碑、口传、神魂传承、血脉传承、梦境传承、残篇、碑文、宗门藏经阁、器灵传授等。
- 来源：只写当前修炼者、持有者或样本人物如何获得该法门，如宗门传授、家族传承、师承、坊市购买、拍卖、秘境获得、遗迹石碑、杀人夺宝、妖族传承、奇遇、任务奖励等；法门的历史背景和创造过程写入“来历”。
- 限制/副作用：写修炼门槛、走火入魔、反噬、寿元消耗、血祭代价、心魔、根基损伤、功法冲突、禁忌风险、正邪评价等。
- 适用境界：按作品自己的境界说法填写，如炼气、筑基、金丹、元婴、斗之气、斗者、明气期等；不明时写“原文未说明”。
- 功法术法神通进阶：写法门后续强化、升阶、改造、补全、融合或演化过程；按“强化阶段1、强化阶段2……”分别列出“强化条件”和“强化后效果”。没有进阶设定时写“原文未说明”。
- 后续变化：写正式命名、修炼者变化、限制暴露、失传、传承转移、公开或封禁等历史变化；具体强化、补全、融合和演化过程写入“功法术法神通进阶”。无明显变化时写“原文未说明明显变化”。
- 纳入依据：写为什么进入本模板，如原文明确称为功法、斗技、术法、神通、口诀、道书、秘术、禁术，或具备可修炼、可施展、可传承的法门属性。
