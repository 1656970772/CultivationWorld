# 功法术法神通模板

## 适用范围

本模板用于整理作品中出现过，或能由小说内容明确支撑的功法、心法、术法、神通、秘术、禁术、身法、遁术、剑诀、炼体法、神识法、御兽术、傀儡术、控虫术、采补术、夺舍法、封印法、占卜推演法等。

本模板将功法、术法、神通、秘术和特殊法门视为可被创造、记录、传承、学习或觉醒，并在特定条件下运行和产生结果的能力系统。分析时应兼顾法门自身的静态结构、修炼者的学习与掌握、实际施展过程、外部表现、对象及环境互动、正常消耗、异常风险、后续进阶和历史变化。

本模板不展开材料、丹药、武器、法宝、阵法、职业流程本体。若某种法门依赖丹药、材料、法宝、阵法或职业技艺，只能在“核心原理与结构”“修炼/觉醒/施展条件”“交互/克制/协同”或“消耗/限制/异常与风险”等相关字段中说明，不得把这些依赖对象、普通训练、普通医术或剧情说明写成主卡。

只有原文明确表现为修炼法门、施展术法、斗技招式、神通能力、禁术秘法、传承道书、口诀法诀、身法遁术、炼体神识法、御兽傀儡控虫法等，才进入本模板。普通道具、药物、急救手段、职业身份、战斗结果和泛泛的“提升实力”描述，不能单独成卡。

## 整理原则

1. 准入边界：只收录能够学习、修炼、觉醒、施展或传承的独立法门。丹药、异火或其他资源、法宝、阵法、体质、境界能力、一次性武器、普通训练和单次能量表现不单独建卡；只有构成法门的条件、媒介、交互或限制时，才写入对应字段。
2. 一法一卡：同一法门的正式名、别名、阶段、变体、实例和后续补充统一归入同一张卡；核心结构、作用实质或传承来源不同的，分别建卡并写明区分项，不以“补充”“后期”或单次表现重复建卡。
3. 字段对应：每个字段只写本字段相关内容，不重复、不跨字段补充；不引入无关的具体事件、剧情过程或人物信息。除说明修炼、施展、失效或传承事实确有必要外，不展开事件经过，也不设置使用记录字段。
4. 原文优先：作品术语、境界、品阶、阶段和能力名称按原文保留；名称、来历、结构、条件、机制、效果、限制和进阶分别判断依据与确定性，不用常识、个案表现或同类设定补齐未知内容。
5. 字段完整：每张卡必须保留模板列出的全部字段。原文没有说明、检查范围内没有发现、材料尚未覆盖或客观不适用时，分别写“原文未说明”“未检出”“未覆盖”或“不适用”，不得省略字段。
6. 分层记录：区分修炼与掌握过程、每层效果、施展与运行机制、施法外观、作用范围、效果、用途、交互、消耗风险和进阶；外观不写机制，机制不写效果，效果不写用途，进阶不重复法门原有层级。
7. 生命周期与输出：按来历、传承、获取、修炼或觉醒、施展、运行、限制、异常、进阶和后续变化记录法门状态；只保留稳定规则和必要证据，不堆叠逐次战斗或修炼经过。获取或传承变化只作简短链式记录，格式为“xxx手中 -> xxx时间到xxx手中 -> xx地方被xxx所得”。

## 字段说明

- 名称：写小说中的功法、心法、术法、神通、秘术、禁术、身法、剑诀、御兽术、傀儡术等名称。
- 正式名/别名：写正式名、早期暂名、别称、误称、简称、不同阶段名称；没有写“原文未说明”。
- 类别：写修炼心法、攻击术法、防御术法、身法遁术、神识秘术、炼体法、剑诀、御兽术、傀儡术、控虫术、毒功、采补术、夺舍法、封印法、禁术等。
- 属性分类：写功法属性或倾向，如金、木、水、火、土、风、雷、冰、毒、血、魂、空间、时间、因果、阴阳、五行、剑道、体修、神识、妖兽、傀儡等；没有明确属性时写“原文未说明”。
- 纳入依据：写为什么进入本模板，如原文明确称为功法、斗技、术法、神通、口诀、道书、秘术、禁术，或具备可修炼、可施展、可传承的法门属性。
- 信息依据与确定性：分别标注信息来自旁白直接说明、法门文本、人物讲解、实际修炼或施展结果、他人评价、上下文直接推断或尚未说明，必要时附章节、段落或原文位置；不同结论依据不同时分别说明。
- 稀有度/品阶：按作品自己的描述填写，如常见基础功法、宗门传承、家族秘传、上古残篇、禁忌秘术、仙界法门、黄阶斗技、玄阶低级等。
- 来历：写法门出自何处、由谁创造或整理、原始用途和已确认的传承起点；只概述形成背景，不展开具体剧情或历史过程。强化、补全、融合和演化条件及结果写入“功法术法神通进阶”；不明项写“原文未说明”。
- 核心原理与结构：写法门的理论基础、口诀法诀、招式模块、手印、经脉路线、能量回路、观想对象、法则权柄、主辅部分、分支结构及主动或被动性质；只记录原文明确说明或上下文能够直接确认的内容，不得根据法门类别自行补写经脉、周天或符文回路。
- 载体/传承方式：写玉简、秘籍、石碑、口传、神魂传承、血脉传承、梦境传承、残篇、碑文、宗门藏经阁、器灵传授等。
- 获取方式/持有经历：只写当前修炼者或传承者如何获得、传授、转交或失去该法门；变化用简短链式记录，格式为“xxx手中 -> xxx时间到xxx手中 -> xx地方被xxx所得”，不展开获取过程或剧情经过。法门自身的历史背景和创造过程写入“来历”。
- 适用对象与境界：写能够修炼、觉醒或施展该法门的种族、体质、性别、血脉、职业、修炼体系和境界；按作品自己的说法填写，不明时写“原文未说明”。此处写谁能使用，法门作用于谁写入“作用对象/范围/持续”。
- 修炼/觉醒/施展条件：分别写修炼、觉醒或实际施展所需的灵根、体质、血脉、境界、神识、法力、材料、法宝、阵法、契约、祭品、环境、心境、前置功法、师承资格、动作、口诀或目标条件；不同阶段条件不同时分别说明。
- 修炼与掌握过程：写阅读、观想、吐纳、运功、练习招式、参悟、觉醒、灌顶、模仿或实战磨炼等掌握方式，以及所需时间、资源、循环步骤、瓶颈、成功标志、熟练度变化和修炼失败表现；先天神通没有学习过程时写“不适用”，并记录已知觉醒过程。
- 总层数/阶段：写法门总共有多少层、多少卷、多少重、多少式、多少境；不明时写“原文未说明”。
- 每层效果：按原文整理每层、每重、每卷或每式的门槛、修炼结果、能力变化和该层特有副作用；没有逐层信息时写“原文未说明”。
- 施展与运行机制：写法门是主动施展、被动触发还是持续运转，如何起手、念咒、结印、调动能量、锁定目标、维持、终止或被打断，以及力量如何在修炼者、媒介、目标和环境之间传导或转化；具体机制不明时写“原文未说明”。
- 施法外观描述：只写法门施展或运转时可直接观察到的动作、形态、颜色、光影、法相、符文、气流、声音、天地异象和残留痕迹；不同层次外观不同时，应在本字段下按层、重、卷、式或阶段分别描述；不明时写“原文未说明”。
- 作用对象/范围/持续：写施术者自身、指定目标、群体、区域、神魂、血脉、空间、因果等作用对象，以及距离、覆盖范围、敌我识别、持续时间、触发次数、冷却、锁定和目标脱离范围后的变化。
- 效果：分为“基础效果”和“特殊效果”；基础效果写法门修炼或施展后通常产生的直接或长期结果，特殊效果写普通作用之外的越阶、控制、隐藏、吞噬、夺舍、封印、推演、改变体质或引动法则等能力。同一结果不在两个子项重复填写。
- 用途：写法门实际用于何种场景，如日常修炼、突破辅助、战斗、保命、赶路、侦查、控制、炼制或其他明确用途；获取和传承场景不写入本字段。
- 交互/克制/协同：写法门与目标抗性、地形、天气、灵气环境、法则领域、其他功法术法、法宝阵法、血脉体质之间的增强、削弱、抵消、反制、叠加、融合或冲突关系，并区分实战已经验证与人物推测。
- 消耗/限制/异常与风险：消耗写修炼或施展时必然支付的法力、神识、寿元、精血、材料或时间；限制写境界、距离、次数、环境和目标等硬条件；异常写修炼失败、施展中断、失控或走火入魔；风险写强行越阶、透支、反噬、心魔、根基损伤、功法冲突、永久伤害、死亡及其他极端后果。正邪评价等社会限制应与能力本身的技术限制分开说明。
- 功法术法神通进阶：写法门后续强化、升阶、改造、补全、融合或演化过程；按“强化阶段1、强化阶段2……”分别列出“强化条件”和“强化后效果”。没有进阶设定时写“原文未说明”。
- 后续变化：只写正式命名、限制暴露、残缺、失传、传承转移、公开、封禁和最终状态等稳定变化，不展开逐次修炼或施展经过。法门对修炼者造成的直接或长期结果写入“效果”，强化、补全、融合和演化过程写入“功法术法神通进阶”；无明显变化时写“原文未说明明显变化”。
