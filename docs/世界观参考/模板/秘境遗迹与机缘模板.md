# 秘境遗迹与机缘模板

## 适用范围

本模板用于整理作品中明确出现的秘境、遗迹、洞府、洞天、小世界、传承地、试炼地、禁地、古战场、宝藏地、重大机缘、天地异象、传承考验、特殊入口和限时开放区域等。

本模板重点记录对象的特殊性、形成与沿革、入口与条件、空间或触发规则、当前状态、危险与收益、关闭或耗尽方式，以及对相关对象产生的后续影响。非地点型重大机缘只有在具备不可替代的获得规则、重大传承或路线转折时才可收录。

本模板不展开材料、丹药、功法、武器、法宝、妖兽、人物、势力或职业流程本体。秘境中的产出只在“机缘/产出”中简要说明，完整内容放入对应专题；普通地点、普通设施、普通交易、普通传功、日常考核、一般比赛、常规战斗和普通居所不单独建立本模板卡片。

## 整理原则

1. 先做准入判定：对象至少具备特殊空间、隐藏入口、限时开放、独立规则、进入限制、试炼机制、高风险收益、重大传承、稀有产出或路线转折中的一项；普通地点、人物、势力、物品和一般事件排除或转入对应专题。
2. 一境一卡，一条机缘链一卡：同一秘境、遗迹或洞府的别称、内部区域、不同开放阶段和后续状态归入同一卡；同一机缘链的获得过程、规则变化、产出和后续影响优先合并，不按每次测试、探索、使用或小步骤拆卡。
3. 独立对象才另开卡：内部普通区域、守护者、奖励物和附属事件写入主卡；只有形成独立空间、独立规则或独立重大机缘链的对象才另建卡，并说明与主对象的关系。
4. 字段只写字段相关内容：不跨字段重复堆叠，不引入无关人物对白、战斗招式、追逐过程、交易细节或剧情流水账；不设置或展开使用记录、事件记录和逐条过程日志。
5. 地点型与非地点型分开处理：地点型重点写入口、空间、环境、布局和运行规则；非地点型按触发地点、资格、获得规则和状态变化记录，无法对应地点的字段写“不适用”，不得虚构空间结构。
6. 只保留关键状态变化：按“形成/来源 -> 发现或触发 -> 开启或获得 -> 规则与状态变化 -> 关闭、耗尽或后续”提取必要节点；阶段字段写最短变化链，不要求复述完整探索过程。
7. 跨专题内容只写去向：材料、丹药、功法、法宝、妖兽、人物和势力只在相关字段中作为产出、参与条件、危险或影响简要出现，不在本卡展开其独立设定。
8. 信息不足时如实标注并保持简洁：使用“原文明确”“实际表现”“人物评价或传闻”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不得根据名称、类型、常识或同类设定补齐信息。

## 信息与输出规则

1. 事实与推断分开：规则字段只写已确认内容；传闻、角色判断和上下文推断统一放入“信息依据与判断边界”，并写明判断理由、替代解释和不确定处。
2. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留结论内容和确定性类型。
3. 阶段变化不写具体事件清单：每个阶段最多保留阶段名称、触发条件、规则或状态变化、危险、机缘/产出、失败后果和阶段结果；不记录人物逐步行动、对话或完整剧情过程。
4. 输出前自检：检查准入边界、一境一卡、机缘链合并、附属区域归属、跨专题对象、地点型与非地点型字段、状态变化、失败后果、信息边界和字段完整性。

## 字段说明

- 名称：使用作品中的秘境、遗迹、洞府、洞天、小世界、传承地、试炼地、禁地、机缘或天地异象名称；无正式名称时使用简洁的描述性名称。
- 入选理由：说明对象符合特殊区域或重大机缘的具体条件，以及与普通地点、设施、事件或物品的区别。
- 边界判定：填写“收录”“降级为附属事件”或“排除”；说明是否为地点主卡、独立子区域、非地点重大机缘、跨专题对象或普通事件。
- 类型：填写上古遗迹、古修洞府、洞天小世界、传承地、试炼地、禁地、古战场、资源秘境、妖兽巢穴、天地异象机缘或非地点型重大机缘等。
- 稀有度：按作品自身描述填写稀缺程度、知名度和控制范围；开放周期写入“开启条件”或“关闭/刷新规则”，不在本字段展开。
- 起源与沿革：填写形成来源、创造者或原始目的，以及对当前状态有影响的关键沿革；传闻和推测不得写成确定事实。
- 现状与控制归属：填写当前完整度、活跃程度、稳定状态、公开程度、名义归属、实际控制者、守护者和监视情况；非地点型机缘可填写尚未触发、进行中、已获得或已耗尽。
- 入口/位置：填写地理位置、空间入口、令牌入口、阵法传送点、异象出现地或触发地点；非地点型机缘没有入口时写“不适用”。
- 开启条件：填写开启时间、钥匙、令牌、血脉、境界、阵法、祭品、天地异象、名额或特殊触发条件。
- 进入限制：填写境界、人数、年龄、身份、血脉、阵营、名额和进入代价；非地点型机缘填写参与或获得资格。
- 外观描述：填写对象、入口和内部区域可直接观察到的形制、轮廓、尺度、材质、色彩、陈设、破损和标志性景观；非地点型机缘无可观察形态时写“不适用”，不得根据名称或功能补写。
- 场景环境描述：填写灵气、地貌、气候、光线、雾气、毒瘴、温度、声响、空间稳定度及常驻生态或守护存在；不重复外观和布局内容。
- 场景布局描述：填写外围区、核心区、传送点、洞府、宫殿、塔楼、阵眼、禁制节点和路线关系；没有独立空间布局时写“不适用”。
- 内部规则：填写时间流速、空间规则、禁飞、禁法、境界压制、随机传送、区域层级、试炼、禁制和判定机制；规则能量来源写入“运行基础/维持机制”。
- 运行基础/维持机制：填写空间锚点、能量来源、阵法核心、秘境意志、世界本源、资源循环、维护方式和消耗机制，以及机制受损后的状态变化；未说明时写“运行基础原文未说明”。
- 阶段变化：只按关键节点填写“阶段名 -> 触发条件 -> 规则或状态变化 -> 危险/机缘 -> 失败后果 -> 阶段结果”；异常、失控或崩塌时再补充征兆、恢复条件或不可逆节点，不写逐步剧情。
- 危险：填写妖兽、阵法、禁制、机关、毒雾、空间裂缝、守关者、竞争、杀人夺宝和失控灾变等与本对象规则直接相关的风险。
- 机缘/产出：填写材料、丹药、功法、神通、武器、法宝、传承、灵脉、妖兽、灵植、道果、身份资格和突破机会等，只保留与本卡风险收益结构有关的简要去向。
- 争夺机制：填写名额竞争、钥匙争夺、团队探索、试炼排名、守门势力、合作破裂、消息泄露和其他直接决定归属的机制。
- 关闭/刷新规则：填写正常退出、强制关闭、入口消失、产出刷新或恢复、禁制重闭、遗迹崩塌和一次性机缘耗尽等状态规则。
- 限制/失败后果：填写死亡、失踪、困死、重伤、境界压制、资源损失、被追杀、传承失败、空间崩塌和永久失去机缘等结果。
- 后续影响：填写对象关闭或机缘获得后，对获得者、失败者、秘境本体、周边环境和相关势力造成的持续变化；不展开后续剧情。
- 适用境界：按作品自身体系填写进入、探索、生存、争夺或承受机缘所需的阶段；无明确依据时写“原文未说明”。
- 信息依据与判断边界：按“原文明确、实际表现、人物评价或传闻、上下文推断、原文未说明、本次未覆盖到明确内容、不适用”区分结论性质；不写任何来源位置或证据标注。
