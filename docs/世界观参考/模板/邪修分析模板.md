# 邪修分析模板

# 规范

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文用于整理作品中邪修、魔修、禁术修炼者、掠夺式修炼路线、邪道组织、黑市邪术链条和社会追杀后果。
- 本文不写总览，不写表格，不写项目字段映射，不写游戏化抽象。
- 不要只写“这个人很邪恶”或“此功法很邪门”，必须写清修炼条件、资源渠道、修炼方式、主要功法、组织形态、收益、代价、弱点与社会反应。
- “修炼方式”是本模板重点，必须尽量详细写成流程：如何选择目标、如何接触或控制目标、如何取得资源、如何施法或修炼、消耗什么、得到什么、是否留下痕迹、失败或中断会怎样。
- 邪修、魔修、反派、异族、正道暗线、黑市修士不要混为一谈；按原文称呼和行为判断填写。
- 魔道宗门不一定等于无脑邪恶；如果原文只是修炼体系不同、阵营不同或政治敌对，不要强行写成邪修。
- 涉及炉鼎、采补、血祭、屠村、尸体、魂魄、毒蛊、控制他人等内容时，只写机制摘要、资源链和后果，不渲染细节。
- 原文没有说明修炼条件、资源渠道、功法名称、组织形态、收益、代价、弱点、社会反应或结局时，不要补，可以写“原文未说明”。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 名字和类型：写人物、组织、功法或资源链条名称，并标明血修、魂修、鬼修、尸修、毒修、蛊修、炉鼎/采补、夺舍、血祭、献祭、吞噬、魔功速成、邪丹邪器、黑市赃物等类型。
- 修炼条件：写境界、体质、功法、目标条件、地点、阵法、丹药、邪器、时间限制、组织庇护、虚弱时机或特殊环境等前置要求。
- 资源渠道：写血肉、魂魄、尸体、炉鼎、妖兽材料、禁药、毒蛊、战俘、凡人村镇、敌对修士、战场遗骸、黑市赃物等获取渠道。
- 修炼方式：写成流程，说明如何选择目标、接触或控制目标、取得资源、保存或炼化资源、施法或修炼、消耗什么、获得什么、留下什么痕迹、失败或中断会怎样。
- 主要功法：写功法、秘术、禁制、邪器、阵法、丹药、传承、魂幡、血池、尸傀、毒阵、蛊术、夺舍秘法等；无名称写“原文未说明”。
- 组织形态：写个人邪修、魔道宗门、邪教、黑市团伙、杀手组织、炼尸组织、蛊修家族、宗门内部暗线或被正道利用的灰色势力。
- 行为模式：写暗杀、诱骗、绑架、屠戮、伪装正派、散播恐惧、黑吃黑、掠夺洞府、尾随截杀、销赃、投靠魔宗、清理知情者等。
- 收益：写速成、延寿、保命、法宝强化、魂力提升、获得尸傀鬼物、控制他人、夺取资质、突破瓶颈、敛财或组织扩张等。
- 代价与限制：写心魔、反噬、名声败坏、通缉、围剿、资源依赖、身份暴露、同门内斗、修炼失控、神魂排异、肉身不合、被更强者吞并等。
- 弱点：写克制功法或法器、阳火雷法佛光、净化法术、镇魂法器、阵法破绽、资源链断裂、目标反抗、神魂不稳、肉身排异、毒蛊反噬、邪器噬主、赃物标记或情报失误等。
- 社会反应：写悬赏、追杀、执法堂任务、宗门战争、凡俗恐慌、尸灾鬼祸、黑市包庇、黑市交易、正邪阵营冲突或大势力暗中利用等。
- 结局或后续影响：写暴露、逃脱、被杀、被反噬、被吞并、灾害扩散、组织覆灭、身份变化、受害者复仇、通缉升级或长期隐患。
- 炉鼎/采补：重点写目标条件、控制方式、资源链、目标后果、暴露风险和社会追杀反应。
- 血修/魂修/尸修/鬼修：重点写血肉、魂魄、尸体、阴地鬼物或战场遗骸的收集、保存、炼化、反噬、克制手段和灾害扩散。
- 毒修/蛊修/邪丹邪器：重点写材料渠道、实验对象、试药投毒、炼制流程、扩散风险和解毒、驱蛊、毁器等弱点。
- 夺舍/吞噬/献祭：重点写目标选择、发动时机、肉身或神魂变化、身份处理、失败后果和后续稳定过程。
- 魔功速成/黑市赃物：重点写情报渠道、埋伏流程、分赃销赃、资源转化、追查风险和被反杀风险。

### 炉鼎/采补型邪修

- 名字和类型：写具体人物、组织或功法名称，并标明炉鼎、采补、控制型邪法等类型；如果原文没有明确称呼，按行为描述填写。
- 修炼条件：写清所需境界、体质、目标条件、修炼地点、阵法、丹药、邪器、时间限制、组织庇护或其他前置条件；原文未说明的字段写“原文未说明”。
- 资源渠道：写清炉鼎、被采补者、诱骗对象、战俘、门人、凡人、敌对修士、黑市买卖对象或宗门内部资源；涉及长期豢养、交易或抢夺时，要写清供给链条。
- 修炼方式：写清如何发现或挑选目标，如何接触、诱骗、控制、囚禁或交易目标，是否需要特殊功法、丹药、禁制、阵法或仪式，修炼时消耗目标的什么，修炼者获得什么，目标受到什么影响，是否能重复使用，是否留下痕迹，失败、被打断或目标反抗会怎样。
- 主要功法：写清采补功法、双修邪法、控制秘术、禁制、丹药、邪器、阵法、辅助功法或相关传承；没有明确名称就写“原文未说明”。
- 组织形态：写清是个人邪修、魔道宗门、采补门派、黑市团伙、家族暗线、宗门内部叛徒，还是被其他势力庇护或利用的修士。
- 行为模式：写清诱骗、绑架、交易、伪装正派、收徒、胁迫、暗杀灭口、逃亡、销赃、黑市交易或投靠魔宗等具体行为。
- 收益：写清修为增长、突破瓶颈、延寿、恢复伤势、强化神魂、控制他人、夺取体质或换取资源等。
- 代价与限制：写清心魔、反噬、目标要求苛刻、功法缺陷、次数限制、被识破风险、名声败坏、寿元损耗、身体异化、目标死亡或失控后的后果。
- 弱点：写清被特定功法、法器、阵法、丹药、血脉、体质、神魂秘术或执法追踪手段克制的情况，也要写清资源链、身份伪装、目标反抗、功法缺陷、修炼时机等薄弱点；原文未说明则写“原文未说明”。
- 社会反应：写清悬赏、追杀、执法堂任务、宗门清剿、凡俗恐慌、受害者亲友复仇、黑市包庇、正邪阵营冲突或暗中纵容。
- 结局或后续影响：写清此人后来如何暴露、逃脱、被杀、被反噬、被更强者吞并，或引发哪些后续冲突；原文未说明则写“原文未说明”。

### 血魂炼器型邪修

- 名字和类型：写具体人物、门派、邪法路线、魂幡血幡或炼器链条名称，并标明血修、魂修、尸修、鬼修、血祭炼器等类型。
- 修炼条件：写清需要的血肉、魂魄、尸体、阴地、战场、墓地、鬼物、法器、阵法、境界、体质、祭品、邪器胚胎或功法前置。
- 资源渠道：写清血肉、魂魄、尸体、战俘、凡人村镇、敌对修士、妖兽尸体、战场遗骸、黑市材料、宗门战利品等获取渠道。
- 修炼方式：写清如何杀戮或收集资源，如何保存血肉、魂魄或尸体，如何炼化、献祭、养尸、养鬼、炼魂或转化为修为和邪器威力，是否需要法器容器、阵法地点、持续时间、重复次数，资源不足时如何补充，修炼失败或资源反噬会怎样。
- 主要功法：写清血道功法、炼魂术、养尸术、御鬼术、鬼幡、魂幡、血池、尸傀、邪器、禁丹或辅助阵法；没有明确名称就写“原文未说明”。
- 组织形态：写清是个人邪修、尸道门派、鬼修宗门、战场拾荒团伙、黑市炼尸组织、杀手组织，还是正道势力暗中豢养的力量。
- 行为模式：写清暗杀、屠戮、收尸、拘魂、炼尸、养鬼、偷坟、战场捡尸、伪装义庄或医馆、黑吃黑、逃亡等行为。
- 收益：写清速成、魂力提升、获得尸傀或鬼物、法宝强化、保命替身、战力暴涨、控制他人或延寿。
- 代价与限制：写清阴气侵蚀、心神失控、尸毒反噬、魂魄反噬、资源暴露、被克制功法克制、名声败坏、同门内斗或被更强者吞并。
- 弱点：写清是否怕阳火、雷法、佛光、净化法术、镇魂法器、破邪阵法、控尸控鬼反制、尸毒反噬、魂幡被毁、主魂受创或资源链被切断；原文未说明则写“原文未说明”。
- 社会反应：写清悬赏、追杀、执法堂任务、宗门战争、凡俗恐慌、尸灾鬼祸、正邪阵营冲突和黑市材料交易。
- 结局或后续影响：写清邪修暴露、引发尸灾鬼祸、被围剿、逃入禁地、投靠魔宗、转化成更大灾害或被主角利用的后续。
