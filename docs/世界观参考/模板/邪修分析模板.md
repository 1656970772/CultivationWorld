# 邪修分析模板

## 适用范围

本模板用于整理作品中由原文明确呈现的邪修、魔修、禁术修炼者、掠夺式修炼路线、邪道组织，以及围绕邪术、邪器、邪丹、黑市交易形成的资源链与后果。

整理时将邪修视为“对象界定—形成与进入—主体结构—实施条件—资源流转—邪法运行—收益与成长—主体和环境互动—异常失控—外界应对—衰退与遗留”的完整系统。涉及炉鼎、采补、血祭、尸体、魂魄、毒蛊、控制他人等内容时，优先保留作品明确写出的对象、过程、表现和后果，不在作品内容之外自行扩写。

本文不写作品总览，不写表格、项目字段映射或游戏化抽象；材料、法宝、功法等仅在其确实构成邪修路线或关键手段时收录。原文未说明的内容统一写“原文未说明”，不得为补齐字段虚构。

## 整理原则

1. 先召回，再判定
   先在全书范围检索邪修、魔修、魔道、魔宗、邪教、夺舍、血祭、献祭、采补、炉鼎、魂魄、炼魂、炼尸、尸傀、魂幡、血炼、毒蛊、禁术、黑市、活魂等线索，并按不同阶段、身份、势力和类型复核语义。作品中已有的专属名称也应加入检索词，不能只整理前期或少数知名角色。

2. 明确准入条件
   候选对象至少满足下列一项才建立邪修卡：以掠夺他人血肉、魂魄、资质或修为作为资源；通过控制、拘禁、夺舍、采补等手段侵害他人；以血祭、炼魂、炼尸、毒蛊或禁术推进修炼；形成邪道组织、邪术交易或黑市资源链。
   例如，夺舍、尸虫丸控制、鬼灵门血灵大法、黑煞教抓人修邪功、魂殿拘取活魂、血宗血系修炼、化龙魔阵等，若作品明确其运行方式，可收录。

3. 区分对象类型与分析尺度
   人物卡分析个人如何进入和运行邪修路线；组织卡分析共同规则、角色分工和资源链；邪法卡分析能够脱离单一使用者传承的独立方法；资源链卡分析跨越多名主体并能独立运作的获取、处理和分配网络。对象类型和血修、魂修、尸修等路线类型应分别标明，不在同一名称中混为一类。

4. 先定结论，后填卡片
   每个候选先判为“收录”“排除”或“待核”。“收录”才展开完整邪修卡；“待核”只保留待补的判定问题，不把推测写成事实；“排除”只简述排除理由，不得硬填完整卡片。

5. 严格排除与多义词排歧
   普通反派、普通比赛作弊、普通妖兽或魔兽、普通心魔、单纯宗派政治冲突，以及只因名称带“魔、邪、毒”而无邪修运行方式的对象，默认排除。萧宁增气散、心魔入侵通常应排除；厉飞雨服用抽髓丸属于自损型速成，通常只作邪药或禁药边界项，不作为邪修卡。
   “炉鼎”须区分炼丹器具与采补对象；“魔道、魔宗”须区分阵营称呼与具体邪术行为；厄难毒体、魔毒斑等毒性设定须确认是否存在邪术修炼、掠夺关系或组织化资源链后再定结论。

6. 一个独立对象一张卡
   同一人物、组织、邪法或资源链在后文出现新的条件、手段、收益、阶段变化或结局时，补入原卡，不按阶段、别名或单次事件重复建卡。人物与其所属组织、使用邪法或参与资源链只有形成各自独立的运行规则时才分卡，并在相关字段说明彼此关系，避免重复抄写共同内容。

7. 优先保留作品实际内容
   优先使用作品已有术语、对象称谓、实施顺序、身体变化、场所痕迹、受害结果和后续影响。整理可以压缩重复叙述，但不能用“实施邪法”“获取资源”“造成伤害”等空泛概括替代作品已经写明的具体内容，也不得把人物猜测、传闻、名称联想或同类作品惯例写成确定结论。

8. 串联静态结构与动态过程
   静态部分写对象类型、主体结构、关键术法器物、资源种类和外在表现；动态部分写形成进入、资源流转、实施过程、收益分配、成长扩张、异常失控、外界应对、衰退终止和后续遗留。只罗列邪法、邪器或受害者名称而没有说明关系，不算完整邪修卡。

9. 区分资源链、运作流程和行为模式
   “资源链与获取”写资源来源、运输、储存、控制和补充；“修炼/运作流程”写资源如何被处理并转化为收益；“行为模式与隐蔽方式”写主体为获取资源、隐藏身份、维持组织或清除风险而反复采取的外部行动。相同内容只在主要字段完整描述。

10. 区分正常、差异、异常和极端状态
    正常成功时的运行和结果写入“修炼/运作流程”与“收益与分配”；因主体、目标、环境或资源差异造成的强弱、无效和结果变化写入“主体、目标与效果差异”；中断、反噬、失控、污染扩散、主体异变和灾害化写入“异常、失败与极端状态”。作品没有展示某类状态时不推演。

11. 记录主体与环境的双向影响
    记录境界、体质、身份、组织位置和目标条件如何改变邪法表现，也记录邪法对受害者、场所、生态、凡俗社会、修行势力和资源分布造成的影响。单一个体结果不能直接推广为路线通则，局部事件也不能自动推定为长期环境变化。

12. 记录形成、成长、衰退和遗留
    人物入道、组织建立、邪法传承和资源链形成写入“形成、传承与进入路径”；境界提升、邪法升级、组织扩张和资源需求变化写入“成长、扩张与阶段变化”；依赖加深、身体神魂衰退、资源枯竭和组织内耗写入长期代价；死亡、覆灭、失传、残留传承、污染和长期隐患写入最终字段。

13. 保留外观与身体异常的阶段结构
    “外观描述与身体异常表现”固定保留“常态外观”“修炼后变化”“施术/激发时变化”“失控/反噬/濒死时变化”四个子项，分别记录主体在不同阶段的外貌、身体和气息表现。人物卡写个人变化，组织或邪法卡写成员或修炼者的共同表现；没有明确主体时写“不适用”，作品没有描写时写“原文未说明”。器物、据点、受害者和周边环境留下的痕迹另写入“环境与场所痕迹”。

14. 明确信息与推断边界
    作品直接说明或能够由多处内容稳定归纳的信息按实际内容填写；必要的合理推断必须明确标注。不同人物判断、不同阶段表现或不同叙述互相冲突时并列保留；未知内容写“原文未说明”，缺少必要上下文时写“待核”。

15. 兼顾覆盖与取舍
    应覆盖个人邪修、组织邪道、邪法禁术、资源链和必要的边界项；魔道宗门不因阵营不同自动等同邪修。保留能够解释路线形成、运行、变化和影响的内容，不展开与邪修对象无关的人物经历、战斗过程或世界背景。

16. 输出前自检
    检查每张卡是否已通过准入判定、对象类型与路线类型是否区分、是否与其他卡重复、形成与运行是否连贯、资源链与运作流程是否混写、正常与异常状态是否混写、主体和环境影响是否双向覆盖、衰退与遗留是否有落点，以及未知和合理推断是否得到明确区分。完整字段只用于已收录对象；排除和待核对象不套用完整卡片。

## 字段说明

- 名称、对象类型与路线类型：写人物、组织、邪法或资源链名称，先标明分析对象类型，再标明夺舍、血修、魂修、尸修、鬼修、毒修、蛊修、采补、血祭、吞噬、邪丹邪器等路线类型。
- 准入理由：说明该对象实际满足哪一项准入条件；无法确认侵害、掠夺、禁术修炼或组织化资源链时应排除或待核。
- 形成、传承与进入路径：人物卡写开始修炼或转入邪修路线的原因、契机、引导者和获得传承的方式；组织卡写建立、招募和控制成员的方式；邪法与资源链卡写起源、传递、建立和延续方式。
- 主体、组织结构与分工：写实施者、控制者、首领、成员、执行者、资源提供者、被利用势力和受益者，以及各自身份、上下级关系和实际分工；个人独立行动时按实际情况填写。
- 实施前提与对象条件：写实施者所需境界、体质、身份、权限和准备，也写目标所需资质、肉身、神魂、状态，以及地点、阵法、时间、组织庇护、邪器和其他环境条件。
- 资源链与获取：写血肉、魂魄、尸体、炉鼎、妖兽材料、禁药、毒蛊、战俘、村镇、敌对修士、战场遗骸或黑市赃物等资源的来源、获取、运输、储存、控制、消耗和补充方式。
- 关键术法/器物：写功法、秘术、禁制、阵法、丹药、邪器、传承、魂幡、血池、尸傀、毒阵或蛊术，以及它们在路线中的具体作用；无名称写“原文未说明”。
- 修炼/运作流程：按作品实际顺序写选择与准备、取得资源、处理资源、施术或修炼、转化和获得结果的过程；失败、中断和失控结果写入异常字段。
- 收益与分配：写速成、延寿、保命、强化神魂或法宝、获得尸傀鬼物、控制他人、突破瓶颈、敛财或组织扩张等实际收益，并说明收益由实施者、组织、上级或其他主体如何取得和分配。
- 主体、目标与效果差异：写实施者的境界、体质、身份、熟练度和组织位置，以及目标的境界、资质、肉身、神魂、反抗能力等条件造成的收益、成功、弱效、失败或后果差异。
- 成长、扩张与阶段变化：写个人境界与邪法能力增长、功法升级、形态变化、资源需求上升，以及组织招募、据点增加、资源链扩张、分裂或转型等阶段变化。
- 行为模式与隐蔽方式：写暗杀、诱骗、绑架、伪装、掠夺、销赃、清理知情者、转移据点、投靠势力等与该路线直接相关的重复行为，以及隐藏身份、场所和资源流向的方式。
- 外观描述与身体异常表现：固定按“常态外观”“修炼后变化”“施术/激发时变化”“失控/反噬/濒死时变化”四个子项，写邪修或该路线直接造成的体型、姿态、肤色、血液、经脉、瞳色、纹路、尸化、兽化、鬼化、异味、寒热、邪气及其他可感知身体变化；不把天生容貌、普通伤势或与路线无关的特效算作身体异常。
- 环境与场所痕迹：写邪器、阵法、据点、处理场所、受害者和周边环境出现的声音、气味、光影、血迹、尸骸、残余力量、污染及其他可感知痕迹，并按常态、施术、失控或衰退等实际阶段说明变化。
- 持续依赖、限制与长期代价：写路线持续依赖的资源、境界、体质、组织和环境条件，次数、时机和规模限制，以及长期修炼造成的肉身神魂损害、心性变化、身份风险、资源枯竭、内部争夺和组织内耗。
- 异常、失败与极端状态：写准备失败、资源不符、目标反抗、施术中断、反噬、排异、失控、邪器噬主、主体异变、污染扩散和灾害化等状态的触发条件、实际表现、直接结果及是否可逆。
- 薄弱环节与克制方式：写功法缺陷、阵法破绽、资源链断点、组织内斗、目标反抗、邪器弱点、情报失误，以及能够识别、阻断、压制、解除或摧毁该路线的实际方式。
- 受害者、环境与长期波及：写受害者在肉身、神魂、身份和生活上的后果，以及对场所、生态、村镇、资源分布、凡俗社会和修行势力造成的直接或长期影响。
- 外界识别、追查与应对：写暴露征兆、知情者反应、悬赏追查、宗门清剿、凡俗恐慌、阵营冲突、势力包庇利用和其他外部反馈。
- 衰退、终止与后续遗留：写资源枯竭、依赖加深、成员流失、路线衰退、身份暴露、逃脱、被杀、反噬、吞并、组织覆灭和邪法失传，以及残留传承、器物、尸傀、污染、灾害与长期隐患。
- 信息边界与不确定项：写本卡中需要说明的合理推断、人物判断或传闻与实际表现之间的差异、不同阶段说法之间的冲突，以及会影响邪修路线理解的重要未知项。
