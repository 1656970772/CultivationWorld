# 邪修分析模板

## 适用范围

用于整理作品中邪修、魔修、禁术修炼者、掠夺式修炼路线、邪道组织、黑市邪术链条和社会追杀后果。

魔道宗门不一定等于邪修。如果原文只是体系不同、阵营不同或政治敌对，不要强行写成邪修；应按原文称呼、行为和后果判断。

## 前置声明

- 样本尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写反派名场面。
- 只写原文和可靠资料能支撑的修炼条件、资源来源、行为链、收益、代价、弱点和社会反应。
- 涉及炉鼎、采补、血祭、屠村、尸体、魂魄、毒蛊、控制他人等内容时，只写机制摘要、资源链和后果，不渲染细节。
- 原文没有说明功法名称、组织形态、弱点、社会反应或结局时，写“原文未说明”。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

通用卡片字段：

| 字段 | 写法提示 |
|------|----------|
| 名字和类型 | 写人物、组织、功法或链条名称，并标明血修、魂修、毒修、夺舍、献祭、黑市赃物等类型。 |
| 修炼条件 | 写境界、体质、功法、目标、地点、阵法、丹药、邪器、时间限制、组织庇护等。 |
| 资源来源 | 写血肉、魂魄、尸体、炉鼎、妖兽材料、禁药、战俘、凡人村镇、敌对修士、黑市赃物等。 |
| 修炼方式 | 写成流程：如何选目标、接触或控制、取得资源、施法或修炼、消耗什么、得到什么、留下什么痕迹、失败会怎样。 |
| 主要功法 | 写功法、秘术、禁制、邪器、阵法、丹药、传承；无名称写“原文未说明”。 |
| 组织形态 | 写个人邪修、魔道宗门、邪教、黑市团伙、杀手组织、正道暗线等。 |
| 行为模式 | 写暗杀、诱骗、绑架、伪装正派、黑吃黑、掠夺洞府、销赃、投靠魔宗等。 |
| 收益 | 写速成、延寿、保命、法宝强化、魂力提升、控制他人、夺取资质、敛财等。 |
| 代价与限制 | 写反噬、心魔、通缉、围剿、资源依赖、身份暴露、同门内斗、修炼失控等。 |
| 弱点 | 写克制功法、法器、阳火雷法佛光、阵法破绽、资源链断裂、目标反抗、神魂不稳、邪器噬主等。 |
| 社会反应 | 写悬赏、追杀、执法堂任务、宗门战争、凡俗恐慌、黑市包庇、正邪冲突等。 |
| 结局或后续影响 | 写暴露、逃脱、被杀、被反噬、被吞并、灾害扩散、组织覆灭或长期隐患。 |
| 来源依据 | 写原文位置、资料来源或可靠依据。 |

类型提示：

| 类型 | 示例 | 重点 |
|------|------|------|
| 炉鼎/采补 | 诱骗、交易、囚禁、控制或长期豢养目标。 | 目标条件、控制方式、资源链、目标后果、暴露风险。 |
| 血修/魂修/尸修/鬼修 | 收集血肉、魂魄、尸体、阴地鬼物或战场遗骸。 | 收集、保存、炼化、反噬、克制手段和灾害扩散。 |
| 毒修/蛊修/邪丹邪器 | 培养毒蛊、试药、投毒、炼制禁丹邪器。 | 材料来源、实验对象、扩散风险、解毒/驱蛊/毁器弱点。 |
| 夺舍/吞噬/献祭 | 残魂夺舍、吞噬神魂、献祭群体或转生。 | 目标选择、发动时机、肉身/神魂变化、失败后果。 |
| 魔功速成/黑市赃物 | 劫修团伙、杀手组织、掠夺洞府、销赃链条。 | 情报来源、埋伏流程、分赃销赃、追查与反杀风险。 |

## 案例

### 案例

| 案例方向 | 最小写法示例 | 不可漏写的重点 |
|----------|--------------|----------------|
| 炉鼎/采补型修士 | 某人通过诱骗、交易、控制或组织庇护获取目标，并用特定功法转化为修炼收益。 | 目标条件、资源来源链、控制流程、收益、目标后果、被追查后的社会反应。 |
| 血修/魂修/尸修/鬼修 | 某路线依赖血肉、魂魄、尸体、阴地或鬼物，通过收集、保存、炼化获得战力或修为。 | 收集过程、炼化方式、资源不足时的补充、反噬、克制、灾害或围剿。 |
| 毒修/蛊修/邪丹邪器 | 某人培养毒蛊、炼禁丹或邪器，用于暗杀、控制、敛财、速成或组织扩张。 | 材料来源、试药/下蛊/炼制流程、失败品处理、扩散风险、解法和后续追查。 |
| 夺舍/吞噬/献祭型修士 | 残魂、老怪或邪教通过目标肉身、神魂、祭品、阵法或法器完成转生、恢复或突破。 | 目标选择、削弱或控制方式、发动条件、成功后的身份处理、失败和反吞噬。 |
| 魔功速成/掠夺洞府/黑市赃物链条 | 劫修或组织用情报挑目标、埋伏抢夺、分赃销赃，再把战利品转为修为、法宝或组织资源。 | 情报渠道、目标选择、分赃规则、销赃风险、通缉追杀、组织内斗。 |
