# 邪修分析模板

## 适用范围

用于整理作品中邪修、魔修、禁术修炼者、掠夺式修炼路线、邪道组织、黑市邪术链条和社会追杀后果。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不要只写“这个人很邪恶”或“此功法很邪门”，必须写清修炼条件、资源来源、修炼方式、主要功法、组织形态、收益、代价、弱点与社会反应。
- “修炼方式”是本模板重点，必须尽量详细写成流程：如何选择目标、如何接触或控制目标、如何取得资源、如何施法或修炼、消耗什么、得到什么、是否留下痕迹、失败或中断会怎样。
- 邪修、魔修、反派、异族、正道暗线、黑市修士不要混为一谈；按原文称呼和行为判断填写。
- 魔道宗门不一定等于无脑邪恶；如果原文只是修炼体系不同、阵营不同或政治敌对，不要强行写成邪修。
- 涉及炉鼎、采补、血祭、屠村、尸体、魂魄、毒蛊、控制他人等内容时，只写机制摘要、资源链和后果，不渲染细节。
- 原文没有说明修炼条件、资源来源、功法名称、组织形态、收益、代价、弱点、社会反应或结局时，不要补，可以写“原文未说明”。

- **邪修类型**：血修、魂修、鬼修、尸修、毒修、蛊修、炉鼎/采补、夺舍、血祭、献祭、吞噬、魔功速成、邪丹邪器。
- **资源来源**：血肉、魂魄、尸体、炉鼎、妖兽材料、禁药、战俘、凡人村镇、敌对修士、黑市赃物。
- **行为模式**：暗杀、诱骗、绑架、屠戮、伪装正派、散播恐惧、黑吃黑、掠夺洞府、投靠魔宗。
- **组织形态**：个人邪修、魔道宗门、邪教、黑市团伙、杀手组织、被正道利用的暗线。
- **收益**：速成、延寿、保命、法宝强化、魂力提升、控制他人、夺取资质。
- **代价**：心魔、反噬、名声败坏、通缉、正道围剿、同门内斗、修炼失控、被更强者吞并。
- **弱点**：被克制功法、被特定法器压制、怕阳火雷法佛光、依赖资源来源、怕身份暴露、怕阵法被破、目标反抗、神魂不稳、肉身排异、毒蛊反噬、邪器噬主。
- **社会反应**：悬赏、追杀、执法堂任务、宗门战争、凡俗恐慌、黑市交易、正邪阵营冲突。

## 案例

### 案例

#### 案例 1：炉鼎 / 采补型修士

名字和类型：写具体人物或组织名称，以及邪修类型；格式示例：韩立（炉鼎/采补）。如果原文没有明确称呼，按行为描述填写。

修炼条件：写清需要的境界、体质、功法、炉鼎条件、目标修为、目标性别或体质要求、修炼地点、阵法、丹药、邪器、时间限制、组织庇护或其他前置条件；原文未说明的字段写“原文未说明”。

资源来源：写清炉鼎、被采补者、诱骗对象、战俘、门人、凡人、敌对修士、黑市买卖对象、宗门内部资源或其他来源；如果涉及长期豢养、交易或抢夺，也要写清来源链条。

修炼方式：非常详细写。写清如何发现或挑选目标，如何接触、诱骗、控制、囚禁或交易目标，是否需要特殊功法、丹药、禁制、阵法或仪式，修炼时消耗目标的什么，修炼者获得什么，目标会受什么影响，是否能重复使用，是否会留下痕迹，修炼失败、被打断或目标反抗会怎样。

主要功法：写清采补功法、双修邪法、控制秘术、禁制、丹药、邪器、阵法、辅助功法或相关传承；没有明确名称就写“原文未说明”。

组织形态：写清是个人邪修、魔道宗门、采补门派、黑市团伙、家族暗线、宗门内部叛徒，还是被其他势力庇护或利用的修士。

行为模式：写清诱骗、绑架、交易、伪装正派、收徒、胁迫、暗杀灭口、逃亡、销赃、黑市交易或投靠魔宗等具体行为。

收益：写清修为增长、突破瓶颈、延寿、恢复伤势、强化神魂、控制他人、夺取体质或换取资源等。

代价与限制：写清心魔、反噬、目标要求苛刻、功法缺陷、次数限制、被识破风险、名声败坏、寿元损耗、身体异化、目标死亡或失控后的后果。

弱点：写清这种路线最怕什么，例如被特定功法、法器、阵法、丹药、血脉、体质、神魂秘术或执法追踪手段克制；也要写清资源链、身份伪装、目标反抗、功法缺陷、修炼时机等薄弱点。原文未说明则写“原文未说明”。

社会反应：写清悬赏、追杀、执法堂任务、宗门清剿、凡俗恐慌、受害者亲友复仇、黑市包庇、正邪阵营冲突或暗中纵容。

结局或后续影响：写清此人后来如何暴露、逃脱、被杀、被反噬、被更强者吞并，或引发哪些后续冲突；原文未说明则写“原文未说明”。

#### 案例 2：血修 / 魂修 / 尸修 / 鬼修

名字和类型：写具体人物、门派、邪法路线或组织名称，以及血修、魂修、尸修、鬼修等类型。

修炼条件：写清需要的血肉、魂魄、尸体、阴地、战场、墓地、鬼物、法器、阵法、境界、体质、祭品或功法前置。

资源来源：写清血肉、魂魄、尸体、战俘、凡人村镇、敌对修士、妖兽尸体、战场遗骸、黑市材料、宗门战利品等来源。

修炼方式：非常详细写。写清如何杀戮或收集资源，如何保存血肉、魂魄或尸体，如何炼化、献祭、养尸、养鬼、炼魂或转化为修为，是否需要法器容器、阵法地点、持续时间、重复次数，资源不足时怎么补充，修炼失败或资源反噬会怎样。

主要功法：写清血道功法、炼魂术、养尸术、御鬼术、鬼幡、魂幡、血池、尸傀、邪器、禁丹或辅助阵法；没有明确名称就写“原文未说明”。

组织形态：写清是个人邪修、尸道门派、鬼修宗门、战场拾荒团伙、黑市炼尸组织、杀手组织，还是正道势力暗中豢养的力量。

行为模式：写清暗杀、屠戮、收尸、拘魂、炼尸、养鬼、偷坟、战场捡尸、伪装义庄或医馆、黑吃黑、逃亡等行为。

收益：写清速成、魂力提升、获得尸傀或鬼物、法宝强化、保命替身、战力暴涨、控制他人或延寿。

代价与限制：写清阴气侵蚀、心神失控、尸毒反噬、魂魄反噬、资源来源暴露、被克制功法克制、名声败坏、同门内斗或被更强者吞并。

弱点：写清是否怕阳火、雷法、佛光、净化法术、镇魂法器、破邪阵法、控尸控鬼反制、尸毒反噬、魂幡被毁、主魂受创或资源来源被切断；原文未说明则写“原文未说明”。

社会反应：写清悬赏、追杀、执法堂任务、宗门战争、凡俗恐慌、尸灾鬼祸、正邪阵营冲突和黑市材料交易。

结局或后续影响：写清邪修暴露、引发尸灾鬼祸、被围剿、逃入禁地、投靠魔宗、转化成更大灾害或被主角利用的后续。

#### 案例 3：毒修 / 蛊修 / 邪丹邪器

名字和类型：写具体人物、炼丹师、炼器师、蛊师、毒修门派或黑市组织名称，以及毒修、蛊修、邪丹、邪器等类型。

修炼条件：写清需要的毒物、蛊虫、药人、实验对象、妖兽材料、禁药、丹方、器方、炉鼎、炼丹炉、炼器炉、特殊环境、传承或组织支持。

资源来源：写清毒草、蛊虫、妖兽材料、尸体、战俘、凡人村镇、敌对修士、黑市赃物、禁药、失败丹药、邪器胚胎等来源。

修炼方式：非常详细写。写清如何培养毒物或蛊虫，如何试药、炼丹、炼器、投毒、下蛊、控制目标，材料如何消耗，失败品如何处理，成功后如何用于修炼、控制、杀戮或交易，是否会扩散成瘟疫、蛊灾或邪器反噬。

主要功法：写清毒功、蛊术、邪丹丹方、邪器炼制法、控蛊秘术、药人秘法、毒阵、蛊阵或相关法宝；没有明确名称就写“原文未说明”。

组织形态：写清是个人毒修、蛊修家族、邪丹师、邪器师、黑市药铺、杀手组织、魔道宗门附属堂口，还是被正道利用的暗线。

行为模式：写清诱骗试药、暗中下毒、操控蛊虫、出售禁药、炼制邪器、黑市交易、灭口、伪装医师或炼丹师、投靠魔宗等行为。

收益：写清速成、控制他人、暗杀能力、保命手段、法宝强化、敛财、延寿、突破瓶颈或制造组织战力。

代价与限制：写清中毒反噬、蛊虫反噬、丹毒积累、邪器噬主、材料稀缺、实验暴露、被解毒克制、组织内部互害等。

弱点：写清是否怕解毒丹、驱蛊术、净化法术、火焰焚烧、隔绝气味、断绝母蛊、毁掉炼炉或邪器核心、材料供应被切断、实验对象逃脱或反向下毒；原文未说明则写“原文未说明”。

社会反应：写清悬赏、追杀、执法堂任务、宗门禁令、黑市交易、凡俗恐慌、瘟疫或蛊灾处理、正邪冲突。

结局或后续影响：写清邪丹邪器流出、受害者追查、黑市链条暴露、组织被围剿、毒灾蛊灾扩散或被更强势力收编。

#### 案例 4：夺舍 / 吞噬 / 献祭型修士

名字和类型：写具体人物、残魂、老怪、夺舍者、吞噬者、祭祀组织或秘术名称，以及夺舍、吞噬、献祭等类型。

资源来源：写清目标肉身、敌对修士、弟子、血亲、战俘、凡人村镇、妖兽、秘境祭品、黑市购买对象、被骗入阵者等来源。

修炼方式：非常详细写。写清如何寻找目标，如何削弱、诱骗、控制或困住目标，如何发动夺舍、吞噬、献祭或转生，目标神魂和肉身如何变化，成功后身份如何处理，失败后残魂或肉身会怎样，是否需要多次献祭或后续稳定过程。

主要功法：写清夺舍秘术、吞噬功法、献祭阵法、转生法、寄魂法器、神魂秘术、血祭法阵或相关禁术；没有明确名称就写“原文未说明”。

组织形态：写清是个人老怪、魔宗传承、邪教祭司、家族禁术、秘境残魂、黑市术士，还是宗门内部暗线。

行为模式：写清伪装师长、诱骗传承、寄身法宝、夺取弟子肉身、献祭村镇、吞噬敌人、逃亡、改名换身份或清理知情者。

收益：写清延寿、重获肉身、夺取资质、突破瓶颈、恢复修为、继承记忆、控制组织、获得强大战力等。

代价与限制：写清神魂排异、肉身不合、记忆混乱、天劫或规则惩罚、身份暴露、目标反抗、秘术失败、寿元折损、被反吞噬等。

弱点：写清是否怕神魂攻击、镇魂法器、护体禁制、血脉排异、肉身不合、目标意志反抗、夺舍时机被打断、祭品不足、阵眼被破、真名或旧身份暴露；原文未说明则写“原文未说明”。

社会反应：写清通缉、围剿、宗门清查、亲友复仇、邪教战争、凡俗恐慌、黑市禁术交易和正邪阵营冲突。

结局或后续影响：写清夺舍成功后的身份变化、失败后残魂去向、献祭引发的灾变、组织覆灭、被主角识破或成为长期隐患。
