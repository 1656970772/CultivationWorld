# 邪修分析模板

## 适用范围

本模板用于整理作品中由原文明确呈现的邪修、魔修、禁术修炼者、掠夺式修炼路线、邪道组织，以及围绕邪术、邪器、邪丹、黑市交易形成的资源链与后果。

重点整理修炼或运作的机制：前提、资源、实施方式、收益、代价、弱点和波及。涉及炉鼎、采补、血祭、尸体、魂魄、毒蛊、控制他人等内容时，只概括机制、资源链和后果，不渲染细节。

本文不写作品总览，不写表格、项目字段映射或游戏化抽象；材料、法宝、功法等仅在其确实构成邪修路线或关键手段时收录。原文未说明的内容统一写“原文未说明”，不得为补齐字段虚构。

## 整理原则

1. 先召回，再判定
   先在全书范围检索邪修、魔修、魔道、魔宗、邪教、夺舍、血祭、献祭、采补、炉鼎、魂魄、炼魂、炼尸、尸傀、魂幡、血炼、毒蛊、禁术、黑市、活魂等线索，并按不同阶段、身份、势力和类型复核语义。作品中已有的专属名称也应加入检索词，不能只整理前期或少数知名角色。

2. 明确准入条件
   候选对象至少满足下列一项才建立邪修卡：以掠夺他人血肉、魂魄、资质或修为作为资源；通过控制、拘禁、夺舍、采补等手段侵害他人；以血祭、炼魂、炼尸、毒蛊或禁术推进修炼；形成邪道组织、邪术交易或黑市资源链。
   例如，夺舍、尸虫丸控制、鬼灵门血灵大法、黑煞教抓人修邪功、魂殿拘取活魂、血宗血系修炼、化龙魔阵等，若原文明确其机制，可收录。

3. 先定结论，后填卡片
   每个候选先判为“收录”“排除”或“待核”。“收录”才展开完整邪修卡；“待核”只保留待补的判定问题，不把推测写成事实；“排除”只简述排除理由，不得硬填完整卡片。

4. 严格排除与多义词排歧
   普通反派、普通比赛作弊、普通妖兽或魔兽、普通心魔、单纯宗派政治冲突，以及只因名称带“魔、邪、毒”而无邪修机制的对象，默认排除。萧宁增气散、心魔入侵通常应排除；厉飞雨服用抽髓丸属于自损型速成，通常只作邪药或禁药边界项，不作为邪修卡。
   “炉鼎”须区分炼丹器具与采补对象；“魔道、魔宗”须区分阵营称呼与具体邪术行为；厄难毒体、魔毒斑等毒性设定须确认是否存在邪术修炼、掠夺关系或组织化资源链后再定结论。

5. 一条主体或路线一张卡
   同一人物、组织或邪法路线在后文出现新的条件、手段、收益或结局时，补入原卡；不得按阶段、别名或单次事件重复建卡。人物与其独立运作的组织、功法或资源链确有不同分析对象时，才可分卡，并在卡内说明关联。

6. 字段按事实填写
   重点写清资源从何而来、如何被处理、修炼者得到什么、身体是否出现异常、受害者或周边受到什么影响、失败或中断会怎样。外观和身体异常按常态、修炼后、施术时、失控或反噬等实际阶段记录；可合理概括已明确的机制，但不得把猜测、传闻、名称联想或通用邪修形象写成确定结论。

7. 兼顾覆盖与取舍
   应覆盖个人邪修、组织邪道、邪法禁术、资源链和必要的边界项；魔道宗门不因阵营不同自动等同邪修。缺少某部作品、某段内容或关键上下文时，明确标注“数据缺失”或“待核”，不得据此推定不存在相关样本。

8. 输出前自检
   检查每张卡是否已通过准入判定、是否与其他卡重复、是否写明机制、外观与身体异常、代价，是否把多义词误收，以及未说明项是否如实标注。案例中的完整字段仅用于已收录对象；排除和待核对象不得套用完整卡片。

## 字段说明

- 名称与类型：写人物、组织、功法、邪器或资源链名称，并标明夺舍、血修、魂修、尸修、鬼修、毒修、蛊修、采补、血祭、吞噬、邪丹邪器等类型。
- 准入理由：说明该对象满足哪一项准入条件；无法说明时应排除或待核。
- 修炼前提：写境界、体质、目标条件、地点、阵法、时间、组织庇护、邪器或其他前置要求。
- 资源与获取：写血肉、魂魄、尸体、炉鼎、妖兽材料、禁药、毒蛊、战俘、村镇、敌对修士、战场遗骸或黑市赃物等资源及其获取方式。
- 修炼/运作方式：按“选择或准备—取得资源—处理或施行—获得结果—失败或中断后果”概括流程。
- 关键术法/器物：写功法、秘术、禁制、阵法、丹药、邪器、传承、魂幡、血池、尸傀、毒阵或蛊术；无名称写“原文未说明”。
- 组织与身份：写个人邪修、魔道宗门、邪教、黑市团伙、杀手组织、炼尸组织、蛊修家族、宗门暗线或被利用的灰色势力，以及其在其中的身份。
- 外观描述与身体异常表现：写邪修或该修炼路线直接造成的可见、可感知肉身变化，如体型与姿态改变、皮肤苍白/发黑/干枯/腐烂、血管或经脉凸显、瞳色和眼白异常、魔纹或尸斑、毛发/牙齿/指甲变化、骨骼与肢体畸变、伤口与血液异常、尸化/兽化/鬼化特征，以及伴随身体出现的异味、寒热、邪气或血雾。简单对象可直接概括；变化复杂时按“常态外观”“修炼后变化”“施术/激发时变化”“失控/反噬/濒死时变化”分项记录。只写原文明确由邪修路线造成的特征，不把人物天生容貌、普通伤势或通用魔气特效算作身体异常；实际损害、风险和限制另写入“代价与限制”。组织、功法或资源链卡应填写其修炼者的共同异常表现；没有明确主体或不适用时写“不适用”，没有描写时写“原文未说明”。
- 行为模式：写暗杀、诱骗、绑架、伪装、掠夺、销赃、清理知情者、投靠势力等与该路线直接相关的行为。
- 收益：写速成、延寿、保命、强化神魂或法宝、获得尸傀鬼物、控制他人、突破瓶颈、敛财或组织扩张等实际收益。
- 代价与限制：写反噬、心魔、通缉、资源依赖、身份暴露、修炼失控、神魂或肉身排异、同门内斗、次数或时机限制等。
- 弱点：写克制手段、阵法破绽、资源链断裂、目标反抗、邪器噬主、情报失误或其他已明确的薄弱处；无依据写“原文未说明”。
- 波及与反应：写受害者后果、悬赏追查、宗门清剿、凡俗恐慌、尸灾鬼祸、阵营冲突或势力利用等外部影响。
- 结局与后续：写暴露、逃脱、被杀、被反噬、被吞并、组织覆灭、灾害扩散、身份变化或长期隐患；无说明写“原文未说明”。

### 墨大夫

- 名称与类型：墨大夫；夺舍、控制型邪术。

- 修炼前提：需要适合夺舍的目标肉身和实施控制的条件；其余前提原文未说明。
- 资源与获取：目标肉身、被控制者；其他资源原文未说明。
- 修炼/运作方式：以尸虫丸建立控制，再围绕夺舍续命安排目标与时机；具体安排原文未说明。
- 关键术法/器物：尸虫丸、夺舍之法。
- 组织与身份：个人邪修；与余子童存在夺舍相关交集。

- 行为模式：控制目标、谋求夺舍。
- 收益：续命、获得新的肉身。
- 代价与限制：夺舍失败与控制失效的风险；其他限制原文未说明。

- 准入理由：以血祭、魂魄与阵法炼化推进修炼，符合邪术修炼与组织化资源链的准入条件。
- 修炼前提：组织成员、祭炼对象和相应阵法条件；其余前提原文未说明。
- 资源与获取：血肉、魂魄及祭炼所需投入；具体获取方式原文未说明。
- 修炼/运作方式：聚集资源后实施血祭与炼化，将资源转化为修炼或阵法收益；中断后果原文未说明。
- 关键术法/器物：血灵大法、阴火大阵。
- 组织与身份：鬼灵门的组织化邪法路线。
