# 记忆情绪与执念模板

## 适用范围

用于整理作品中事件记忆、情绪反应、长期执念与人生目标之间形成的完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条。

## 前置声明

- 覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角或成功案例。
- 只写原文、资料来源或可靠依据能支撑的记忆、情绪、执念和后续行为。缺失字段写“原文未说明”，不得补造心理链。
- 案例只是最低写法示范，不是数量上限；有价值的完整因果链都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充来源，成熟后转为 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

本文只整理完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条。不写总览、证据段或抽象规则表；不把读者感受、旁白气氛或单次心理描写直接当成长期执念。

每部作品至少挑选 20 个有代表性的完整案例。事件类型要尽量全面，不要全部选择主角相关案例；NPC、配角、反派、宗门成员、散修、妖兽、势力首领、家族成员之间的链条也应纳入候选。

每个案例写清：记忆类型、触发事件、相关角色、形成记忆、情绪变化、执念/目标、触发条件、行为后果、变化机制、消退或转化条件、长期影响。没有可靠依据的字段写“原文未说明”。

| 类型 | 示例 | 重点 |
|------|------|------|
| 记忆类型 | 救命、赠宝、背叛、羞辱、夺宝、失败、突破、灭门、被控制、被诬陷、见证灾害 | 必须是角色记住并影响后续行为的事件。 |
| 情绪 | 愤怒、恐惧、感激、羞耻、悲痛、悔恨、嫉妒、敬畏、怨恨、不甘、释然 | 写情绪变化，不只写单一情绪标签。 |
| 执念/目标 | 复仇、变强、守护、传承、夺权、报恩、护徒、护族、洗刷污名、追查真相 | 写目标如何从事件中形成。 |
| 触发条件 | 关系强度、境界差、损失价值、寿元压力、身份暴露、誓言、因果债、公开羞辱 | 写为什么该事件会被固化为长期驱动。 |
| 行为后果 | 追杀、求援、闭关、夺宝、投靠、叛逃、黑化、隐居、调查、培养继承人 | 写后续行动，而不是只写“心里记恨”。 |
| 变化机制 | 淡化、叠加、转化、被满足、被继承、因真相揭露而反转、因新仇覆盖旧仇 | 写执念如何变化、消退或升级。 |

如果案例重点其实是人物关系、冲突过程或修炼历程，应放到对应模板中。

## 案例

### 案例

#### 通用链条卡片

- **记忆类型**：写事件类别，如被控制、击杀亲友、救命、赠宝、背叛、羞辱等。
- **触发事件**：写事件发生的时间、地点、原因和直接经过。
- **相关角色**：写施加者、承受者、见证者、牵连者和所属势力。
- **形成记忆**：写角色记住了什么，不写读者感受。
- **情绪变化**：写从事件前到事件后的情绪转变。
- **执念/目标**：写形成的长期目标。
- **触发条件**：写关系、境界差、资源价值、寿元压力、身份暴露、誓言或因果债等。
- **行为后果**：写追杀、报恩、闭关、护徒、夺宝、隐居、调查等后续行动。
- **变化机制**：写叠加、淡化、转化、满足、反转或继承。
- **消退或转化条件**：写复仇完成、真相揭露、恩情偿还、目标死亡等；不明写“原文未说明”。
- **长期影响**：写该记忆如何影响后续选择。

#### 分类型示例

| 类型 | 写法重点 |
|------|----------|
| 戒备和求生执念 | 写控制、夺舍威胁、信息差、恐惧到谨慎的转化，以及后续防备行为。 |
| 复仇执念 | 写亲友死亡、加害者、境界/势力差、复仇准备、追杀或黑化结果。 |
| 报恩和守护执念 | 写救命或赠宝、亏欠感、偿还方式、守护行动，以及恩情完成后的变化。 |

### 待定案例

按如下格式记录，暂不补齐正式案例字段：

1. 对象名称：关键摘要（来源）；新增摘要（来源）。
