# 记忆情绪与执念模板

## 适用范围

本模板用于整理作品中事件记忆、情绪反应、长期执念与人生目标之间形成的完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条。

本模板只整理完整心理因果链，不写总览、抽象规则表、读者感受、旁白气氛、身份认知、短期心理、单次情绪描写或纯剧情设定。只有事件被角色记住，并持续影响后续行为、关系判断、修炼路线、势力立场或生死决策时，才写成卡片。

如果案例重点其实是人物关系、冲突过程、修炼历程、势力斗争、单次战斗或人物性格，应放到对应模板中；本模板只保留能形成长期驱动的记忆、情绪、执念和后续行为链。

## 整理原则

1. 一链一卡  
   每张卡只写一条主链：一个核心触发事件、一组情绪转折、一个主要执念目标和一组后续行为。  
   不要把多个独立事件、多个阶段仇怨或多个人物心理塞进同一张卡；跨阶段延续写入“变化机制”和“长期影响”。

2. 字段完整  
   每张卡必须包含：对象名称/链条名称、记忆类型、链条完整性、纳入依据、触发事件、相关角色、形成记忆、情绪变化、执念/目标、触发条件、行为后果、变化机制、消退或转化条件、长期影响。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

3. 准入门槛  
   必须同时具备“事件记忆、情绪反应、执念目标、后续行为”四个环节，才算有效卡片。  
   只有一时愤怒、短期害怕、场面震惊、旁白评价、读者感受、身份变化或人物关系说明的内容，不写成卡片。

4. 字段名严格  
   字段名必须完全匹配模板，不得写成近义字段。  
   禁止无标题字段块、重复字段、重复标题、标题与内容错位、上一卡吞并下一卡等结构问题。

5. 情绪要有转折  
   “情绪变化”必须写事件前、事件中、事件后的短期转折，不只写单一情绪标签。  
   长期性格、信仰和执念不要写成情绪变化。

6. 执念要落到行为  
   “执念/目标”必须能对应后续行动，如追杀、求援、闭关、夺宝、投靠、叛逃、黑化、隐居、调查、培养继承人等。  
   如果只有“心里记恨”“觉得震撼”“产生好感”等短期心理，而没有后续行为，写入其他模板或不收录。

7. 长期影响不泛化  
   “长期影响”必须写该记忆如何影响角色后续选择、关系判断、修炼路线、势力立场或生死决策。  
   不要泛泛写“影响性格”“埋下伏笔”“变得谨慎”；没有后续影响时写“原文未说明”。

8. 数量与覆盖  
   每部作品至少整理 20 个有效案例；不足 20 个时必须说明未达标原因。  
   样本要覆盖主角、NPC、配角、反派、宗门成员、散修、妖兽、势力首领、家族成员等不同身份，不要只写主角、单一地域、早期剧情或成功案例。

9. 不虚构心理链  
   只写原文或可靠依据能支撑的记忆、情绪、执念和后续行为。  
   缺失字段写“原文未说明”，不得为了补齐结构而补造心理链、长期动机或消退条件。

## 字段说明

- 对象名称/链条名称：写角色名加核心链条名，如“某某 / 退婚羞辱与变强执念”；不要只写泛泛标题。
- 记忆类型：写救命、赠宝、背叛、羞辱、夺宝、失败、突破、灭门、被控制、被诬陷、见证灾害等事件类别。
- 链条完整性：写完整、缺后续行为、缺消退条件、仅短期心理不纳入等；正式卡一般应为“完整”或说明缺口。
- 纳入依据：写为什么该内容属于完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条。
- 触发事件：写事件发生的时间、地点、原因和直接经过；没有可靠依据时写“原文未说明”。
- 相关角色：写施加者、承受者、见证者、牵连者和所属势力；不明时写“原文未说明”。
- 形成记忆：写角色记住了什么，以及该记忆如何被保留下来；不写读者感受。
- 情绪变化：写事件前、事件中、事件后的情绪转变，如愤怒、恐惧、感激、羞耻、悲痛、悔恨、嫉妒、敬畏、怨恨、不甘、释然等。
- 执念/目标：写复仇、变强、守护、传承、夺权、报恩、护徒、护族、洗刷污名、追查真相等长期目标，以及目标如何从事件中形成。
- 触发条件：写关系强度、境界差、损失价值、寿元压力、身份暴露、誓言、因果债、公开羞辱等使事件固化为长期驱动的条件。
- 行为后果：写追杀、求援、闭关、夺宝、投靠、叛逃、黑化、隐居、调查、培养继承人等后续行动，而不是只写“心里记恨”。
- 变化机制：写执念如何淡化、叠加、转化、被满足、被继承，或因真相揭露而反转、因新仇覆盖旧仇。
- 消退或转化条件：写复仇完成、真相揭露、恩情偿还、目标死亡、境界突破、关系修复等让执念变化的条件；不明时写“原文未说明”。
- 长期影响：写该记忆如何影响角色后续选择、关系判断、修炼路线、势力立场或生死决策。

```md
# 《作品名》记忆情绪与执念

## 记忆情绪与执念卡片

### 对象名称 / 链条名称

- 记忆类型：

- 相关角色：

- 消退或转化条件：
- 长期影响：

### 戒备和求生执念

- 对象名称/链条名称：角色 / 戒备和求生执念
- 记忆类型：被控制、夺舍威胁、信息差或生死危机
- 链条完整性：完整
- 纳入依据：存在明确生死威胁，角色形成长期戒备，并在后续行动中持续寻找自保和反制手段。
- 触发事件：角色在关键场景中遭遇控制、夺舍、诱骗或突然袭杀，意识到自身处境存在致命风险。
- 相关角色：受威胁者、施加威胁者、知情者、见证者及相关势力。
- 形成记忆：角色记住威胁发生的方式、暴露出的弱点，以及对方利用的信息差。
- 情绪变化：事件前可能处于信任、迟疑或不知情状态；事件中转为震惊、恐惧或愤怒；事件后转为长期戒备和主动求生。
- 执念/目标：变强、自保、识破控制手段、避免再次落入同类局面。
- 触发条件：境界差距、神魂弱点、身份暴露、契约限制、资源诱惑或生死压力。
- 行为后果：隐藏底牌、减少信任、调查真相、闭关修炼、寻找反制手段。
- 变化机制：随着实力提升或真相揭露而淡化；若再次遭遇同类威胁则叠加升级。
- 消退或转化条件：威胁解除、加害者死亡、反制手段成熟或角色获得新的安全依托。
- 长期影响：影响角色的信任边界、行动策略、修炼优先级和势力选择。

### 复仇执念

- 对象名称/链条名称：角色 / 复仇执念
- 记忆类型：亲友死亡、宗门覆灭、被背叛、被诬陷或遭公开羞辱
- 链条完整性：完整
- 纳入依据：重大损失被角色记住，并转化为追查、修炼、结盟或清算等后续行动。
- 触发事件：角色遭遇重大损失，并明确或逐步确认加害者、责任方或幕后势力。
- 相关角色：受害者、加害者、牵连亲友、旁观者、庇护势力或敌对势力。
- 形成记忆：角色记住损失本身、加害者行为、无力感和必须清算的因果。
- 情绪变化：事件前可能处于平稳、信任或自尊受损状态；事件中产生悲痛、愤怒、羞耻或不甘；事件后转为持续复仇意志。
- 执念/目标：追杀仇敌、洗刷污名、夺回失物、覆灭敌对势力或为死者讨还公道。
- 触发条件：关系强度、损失价值、境界差、势力差、公开羞辱、誓言或因果债。
- 行为后果：闭关变强、求援结盟、追查线索、夺取资源、伏杀仇敌或走向黑化。
- 变化机制：因新仇叠加而升级；因真相揭露、仇敌死亡或目标改变而反转或转化。
- 消退或转化条件：复仇完成、真相澄清、仇敌死亡、责任转移或角色主动放下。
- 长期影响：影响角色的阵营选择、修炼节奏、人际关系和道心走向。

### 报恩和守护执念

- 对象名称/链条名称：角色 / 报恩和守护执念
- 记忆类型：救命、赠宝、传功、庇护、收徒或危难扶持
- 链条完整性：完整
- 纳入依据：角色记住关键恩情，并在后续资源分配、风险承担或守护行为中持续偿还。
- 触发事件：角色在弱势、濒死、受困或缺少资源时得到关键帮助。
- 相关角色：受恩者、施恩者、被守护者、敌对方、见证者及所属势力。
- 形成记忆：角色记住对方给予的帮助、自己因此获得的转机，以及尚未偿还的亏欠。
- 情绪变化：事件前可能绝望、迷茫或戒备；事件中转为震动、感激或信任；事件后形成亏欠感或守护意愿。
- 执念/目标：报恩、护徒、护族、传承衣钵、保护恩人或完成恩人遗愿。
- 触发条件：救命之恩、资源价值、师徒名分、家族责任、誓言、因果债或传承义务。
- 行为后果：主动护持、承担风险、传授资源、替对方复仇、守护后人或延续传承。
- 变化机制：恩情偿还后淡化；若恩人死亡或后辈受难，则转化为守护或复仇执念。
- 消退或转化条件：恩情偿还、传承完成、被守护者独立、遗愿完成或关系破裂。
- 长期影响：影响角色的资源分配、风险承担、门派归属和后续人际选择。
```
