# 记忆情绪与执念模板

> 最后更新：2026-06-17
> 状态：模板
> 类型：事件记忆、情绪反应、长期执念与人生目标调研
> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条，不写总览，不写证据段，不写抽象规则表，也不把读者感受、旁白气氛或单次心理描写直接当成角色长期执念。

每部作品至少挑选 20 个有代表性的完整记忆执念案例。事件类型要尽量全面，不要全部选择主角相关案例；NPC、配角、反派、宗门成员、散修、妖兽、势力首领、家族成员之间形成的记忆、情绪和执念链也非常重要。只要原文能支撑完整因果链，都应纳入候选。

每个案例都按固定字段写清：记忆类型、触发事件、相关角色、形成记忆、情绪变化、执念/目标、触发条件、行为后果、变化机制、消退或转化条件、长期影响。没有可靠原文依据的字段写“原文未说明”；不得为了补齐情绪、执念或行为链而自行虚构。

下列类别是优先参考范围，不是封闭清单。若原文中出现其他能形成完整“事件记忆 - 情绪反应 - 执念目标 - 后续行为”链条的案例，也可以纳入本模板；但如果案例重点其实是人物关系、冲突过程或修炼历程，应放到对应模板中。

## 完整记忆执念案例

### 案例 1：韩立与墨大夫形成的戒备和求生执念

**记忆类型：** 被控制 / 被夺舍威胁 / 师徒关系反转 / 生存压力。

**触发事件：** 韩立进入七玄门后与墨大夫形成师徒或控制关系，墨大夫以培养、医术或修炼安排影响韩立，但其真实目的逐渐暴露，双方目标从表面合作转向生死冲突。

**相关角色：** 韩立、墨大夫、七玄门相关人物；其他旁观者或牵连者按原文填写，不明时写“原文未说明”。

**形成记忆：** 韩立形成“强者表面施恩也可能暗藏控制和夺取”的深刻记忆，对师徒关系、赠予资源、身体控制、功法来历和强者承诺保持长期警惕。

**情绪变化：** 起初可能是谨慎、依赖或疑惑；发现风险后转为恐惧、戒备、愤怒和强烈求生；结算后沉淀为长期谨慎和不轻信他人的心理习惯。

**执念/目标：** 摆脱控制、活下去、掌握主动权、隐藏底牌、谨慎求道。

**触发条件：** 境界差、信息不对称、师徒关系、禁制或身体威胁、弱者面对强者控制、修炼资源诱惑。

**行为后果：** 韩立更重视底牌、毒药、阵法、傀儡、逃生手段和信息遮蔽；面对强者、师承、交易和赠宝时更谨慎。

**变化机制：** 该记忆不会短期消退，会被后续强者控制、夺宝、追杀、背叛事件反复强化；当韩立拥有更强实力后，恐惧成分可能淡化，但谨慎习惯保留。

**消退或转化条件：** 原文若没有明确消退，写“原文未说明”；可记录其从早期恐惧转化为长期谨慎和主动布局。

**长期影响：** 该案例是韩立早期性格和行为方式的重要来源，影响其后续对人性、强者承诺、修炼机缘和危险交易的判断。

### 案例 2：亲友死亡引发的复仇执念

**记忆类型：** 击杀亲友 / 救援失败 / 仇怨记忆。

**触发事件：** 某角色的亲友、师长、弟子、道侣或宗门同伴被敌对角色或势力杀害，且该死亡与利益冲突、阵营冲突、通缉、夺宝或背叛有关。

**相关角色：** 死者、复仇者、加害者、旁观者、传信者、可能被牵连的宗门或家族；不明时写“原文未说明”。

**形成记忆：** 复仇者记住死亡场景、加害者身份、自己无力阻止的事实，以及与死者之间未完成的承诺或亏欠。

**情绪变化：** 悲痛、愤怒、悔恨、不甘、怨恨；若境界差过大，也可能先表现为恐惧和隐忍。

**执念/目标：** 复仇、变强、寻找凶手、守护剩余亲友、继承死者遗愿。

**触发条件：** 关系强度、死亡惨烈程度、加害者是否逍遥、是否有目击或遗言、复仇者性格、境界差和势力差。

**行为后果：** 闭关变强、追杀、求援、投靠势力、挑战仇敌、悬赏、潜伏、修炼禁术或黑化。

**变化机制：** 仇怨可因新证据、新仇、再次羞辱或加害者继续作恶而叠加；也可因复仇成功、真相反转、仇敌死亡或亲友遗愿被完成而转化。

**消退或转化条件：** 复仇完成后可能转为守护、避世、空虚、悔恨或继续追查幕后黑手；原文未说明时写“原文未说明”。

**长期影响：** 这类案例用于记录复仇如何驱动长期行动，而不是只记录“某人很愤怒”。

### 案例 3：救命之恩转化为报恩和守护

**记忆类型：** 救命 / 赠宝 / 被放过一命 / 亏欠。

**触发事件：** 某角色在危急时被他人救下，或在资源、境界、身份明显弱势时被对方放过、赠宝、传功或庇护。

**相关角色：** 施恩者、受恩者、追杀者、见证者、被牵连的同伴或势力；不明时写“原文未说明”。

**形成记忆：** 受恩者记住自己濒死或困境中的无力，以及施恩者付出的资源、风险或情面。

**情绪变化：** 恐惧缓解后转为感激、亏欠、依恋、敬畏，也可能夹杂羞愧或不甘。

**执念/目标：** 报恩、守护、追随、偿还因果、完成施恩者请求。

**触发条件：** 救命强度、施恩代价、双方关系基础、受恩者性格、是否有誓言或因果债。

**行为后果：** 护主、护徒、传信、赠宝、替对方承担风险、加入势力、长期追随或在关键时刻反向救援。

**变化机制：** 报恩可因多次互救而叠加，也可因施恩者背叛、真相反转或恩情偿还完成而转化。

**消退或转化条件：** 恩情偿还、施恩者死亡、双方决裂、发现施恩另有目的；原文未说明时写“原文未说明”。

**长期影响：** 这类案例用于记录恩义如何转化为长期关系和行动，而不是只写一次救人事件。
