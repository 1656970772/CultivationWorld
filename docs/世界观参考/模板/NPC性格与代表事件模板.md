# NPC性格与代表事件模板

## 适用范围

用于整理小说中由具体事件支撑的角色性格、欲望、行为选择和性格变化。

主角、配角、反派、宗门高层、家族成员、散修、妖修、邪修、普通弟子、旁观者和被牵连者等，只要原文有可靠依据，都可纳入。

## 前置声明

- 样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、名场面或成功案例。
- 案例只是最低写法示范，不是数量上限；原文有价值内容可以继续展开。
- 原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，写“原文未说明”，不要补设定。
- 待定案例用于暂存信息不足但值得追踪的对象；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。
- 不写总览、证据段、表格、数值区间或项目字段映射；性格判断必须有事件支撑，台词、外貌和旁人评价只能辅助。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **角色定位**：主角、配角、反派、散修、宗门弟子、长老、家族成员、妖修、邪修、普通人等，按原文填写。
- **核心性格**：不要只写单个形容词，要用代表事件证明。
- **欲望倾向**：长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、求道、报恩、求稳、掌控他人等。
- **决策场景**：强敌压迫、宝物诱惑、同门遇险、师徒关系、宗门命令、家族利益、背叛、寿元压力、突破失败、势力覆灭等。
- **代表行为**：逃跑、反击、杀人夺宝、放过敌人、报恩、背叛、隐忍复仇、护徒、收徒、交易、牺牲、闭关、求援、投靠、叛逃等。
- **变化原因**：亲友死亡、救命之恩、被背叛、宗门覆灭、夺宝成败、重伤濒死、寿元将尽、获得传承、突破失败、心魔刺激等。
- **行为后果**：结仇、结盟、被追杀、获得信任、失去靠山、转投势力、黑化、避世、改换修炼路线、被孤立、掌权、被清算等。

| 类型 | 示例 | 重点 |
|------|------|------|
| 谨慎隐忍型 | 求生优先、等待时机、准备后路 | 写清风险评估、延迟行动和长期后果。 |
| 贪婪冒险型 | 明知有风险仍夺宝、背叛队友 | 写清收益诱惑、短期选择和代价。 |
| 忠诚守护型 | 护徒、守诺、救援、断后 | 写清关系承诺、牺牲和关系余波。 |
| 复杂矛盾型 | 重情但狠辣、守护但控制欲强 | 写清多面性、冲突选择和变化节点。 |

正式案例建议字段：角色定位、核心性格、代表事件、性格变化、行为后果。核心角色尽量写 3 个以上代表事件，配角或短线角色可写 1 到 2 个典型事件。

## 案例

### 案例

#### 案例 1：谨慎隐忍型角色

角色定位：主角 / 散修 / 宗门弟子 / 其他身份按原文填写。

核心性格：谨慎、隐忍、重视生存、恩怨分明、重视利益边界。

代表事件：写角色面对强敌、未知风险、宝物诱惑或旧仇牵连时，如何隐藏实力、搜集情报、准备退路、评估收益，或等时机成熟再行动。

性格变化：若因救命之恩、亲友死亡、宗门变化、突破失败、寿元压力等改变行事方式，写清变化前后差异；没有明显变化写“原文未说明明显变化”。

行为后果：写这种性格如何帮助角色避开死局，也如何造成不信任、错过机会、长期复仇或因果牵连。

#### 案例 2：贪婪冒险型角色

角色定位：散修 / 邪修 / 宗门弟子 / 反派 / 临时队友等按原文填写。

核心性格：贪婪、冒险、短视、机会主义，也可能兼具胆大、果断或狠辣。

代表事件：写角色为宝物、丹药、传承、灵草或法宝冒险，如何隐瞒情报、背叛同伴、临阵倒戈，或在短期成功后继续扩大风险。

性格变化：若失败、重伤、被追杀或失去靠山后变得谨慎、疯狂或投靠他人，写清变化节点；没有变化写“原文未说明明显变化”。

行为后果：写夺宝、背叛、截杀、通缉、临时结盟破裂、死亡、失势或被清算等结果。

#### 案例 3：忠诚守护型角色

角色定位：弟子 / 护卫 / 长老 / 师傅 / 家族成员 / 道侣 / 追随者等按原文填写。

核心性格：忠诚、重情、守诺、愿意承担代价，也可能固执、保守或被关系束缚。

代表事件：写角色在宗门、师徒、家族或道侣关系受威胁时，如何救援、护送、断后、求援、牺牲资源，或拒绝利益诱惑。

性格变化：若守护对象死亡、背叛、失踪或堕落后转向复仇、避世、黑化或继续守护遗愿，写清触发事件和后续行为。

行为后果：写稳定联盟、师徒传承、追随关系、救援事件，也写被拖入内斗、争端、复仇链或牺牲结局。

#### 案例 4：复杂矛盾型角色

角色定位：主要配角 / 反派 / 宗门高层 / 家族继承人 / 妖修 / 邪修等按原文填写。

核心性格：同时存在两种以上明显倾向，如重情但狠辣、守护但控制欲强、求道但牺牲他人。

代表事件：写角色在私人情感和现实利益冲突时如何选择，在不同对象面前如何表现出不同面向，以及重大失败或压力如何放大某一面。

性格变化：重点写矛盾如何转移，如从守护变成控制，从求道变成执念，从忠诚变成复仇，从隐忍变成疯狂。

行为后果：写关系变化、势力冲突和因果余波，如既救人也害人、既被信任也被忌惮、既能结盟也可能反噬同伴。
