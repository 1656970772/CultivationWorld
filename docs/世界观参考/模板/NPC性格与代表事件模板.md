# NPC 性格与代表事件模板

> 最后更新：2026-06-17
> 状态：模板
> 类型：角色性格、代表事件、行为选择与性格变化调研
> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文只整理小说中能由具体事件支撑的角色性格、行为选择和性格变化。
- 本文不写总览，不写证据段，不写表格，不写数值区间，不写项目字段映射。
- 不能只写“谨慎”“贪婪”“忠诚”“狠辣”等单个形容词，必须用具体代表事件证明。
- 优先选择人物塑造饱满、行为选择有矛盾、有变化、有代价，能体现人物复杂性的角色。
- 主角、主要配角、反派、宗门高层、家族成员、散修、妖修、邪修、普通弟子等角色都可以写；不要只写主角。
- 核心角色尽量写 3 个以上代表事件，配角或短线角色可以只写 1 到 2 个典型事件。
- 同一角色如果在不同阶段性格发生变化，要按阶段写清变化原因和变化后的行为后果。
- 如果某个性格判断没有明确事件支撑，不要写；如果原文没有说明性格变化，可以写“原文未说明明显变化”。
- 台词风格、外貌描写、旁人评价只能作为辅助，不能代替具体行动。

## 参考范围（不局限于以下类别）

- **基础性格**：谨慎、勇敢、忠诚、冷漠、重情、贪婪、残忍、隐忍、骄傲、冲动、圆滑、正直、狠辣、怯懦、多疑、守信、忘恩、偏执。
- **欲望倾向**：长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、求道、报恩、求稳、掌控他人。
- **决策场景**：强敌压迫、宝物诱惑、同门遇险、师徒关系、道侣关系、宗门命令、家族利益、背叛、寿元压力、突破失败、势力覆灭。
- **代表行为**：逃跑、反击、杀人夺宝、放过敌人、报恩、背叛、隐忍复仇、护徒、收徒、交易、牺牲、闭关、求援、投靠、叛逃。
- **变化原因**：亲友死亡、救命之恩、被背叛、宗门覆灭、夺宝成功、夺宝失败、重伤濒死、寿元将尽、获得传承、突破失败、心魔刺激。
- **行为后果**：结仇、结盟、被追杀、获得信任、失去靠山、转投势力、黑化、避世、改变修炼路线、被孤立、掌权、被清算。

## 完整性格案例

### 案例 1：谨慎隐忍型角色

角色定位：主角 / 散修 / 宗门弟子 / 其他身份按原文填写。

核心性格：谨慎、隐忍、重视生存、恩怨分明、重视利益边界。

代表事件一：角色面对强敌、未知风险或信息不足的局面时，没有贸然出手，而是先隐藏实力、搜集情报、观察局势或准备后路；该事件体现其谨慎和求生优先。

代表事件二：角色遇到宝物、传承或机缘时，不是只看收益，还会评估敌人数量、境界差距、逃生路径、暴露风险和后续追杀；该事件体现其利益判断和风险控制。

代表事件三：角色遭到羞辱、背叛或旧仇牵连时，没有立即复仇，而是在修为、资源、情报或时机成熟后再行动；该事件体现其隐忍和长期记仇。

性格变化：如果角色因为救命之恩、亲友死亡、宗门变化、突破失败、寿元压力等改变行事方式，要写清变化前后的差异；没有明显变化则写“原文未说明明显变化”。

行为后果：这种性格可能让角色多次避开死局，也可能导致其不轻易信任他人、关系推进缓慢、错过部分机会，或在复仇、夺宝、逃亡中形成长期因果。

### 案例 2：贪婪冒险型角色

角色定位：散修 / 邪修 / 宗门弟子 / 反派 / 临时队友等按原文填写。

核心性格：贪婪、冒险、短视、机会主义，也可能兼具胆大、果断或狠辣。

代表事件一：角色看到宝物、丹药、传承、灵草或法宝后，明知有守护者、强敌或禁制，仍选择冒险夺取；该事件体现其贪婪和高风险偏好。

代表事件二：角色在组队、秘境或宗门任务中为了独吞收益，隐瞒情报、背叛同伴、临阵倒戈或引敌害人；该事件体现其利益优先和关系不稳定。

代表事件三：角色在短期成功后继续扩大冒险，最终引来追杀、反噬、围剿或更强势力注意；该事件体现其性格带来的长期代价。

性格变化：如果角色因失败、重伤、被追杀或失去靠山后变得谨慎、疯狂或投靠他人，要写清变化节点；没有变化则写“原文未说明明显变化”。

行为后果：这种性格容易推动夺宝、背叛、截杀、通缉和临时结盟破裂等事件，也常导致角色死亡、失势、被清算或把更多人卷入冲突。

### 案例 3：忠诚守护型角色

角色定位：弟子 / 护卫 / 长老 / 师傅 / 家族成员 / 道侣 / 追随者等按原文填写。

核心性格：忠诚、重情、守诺、愿意承担代价，也可能因此固执、保守或被关系束缚。

代表事件一：角色在宗门、师徒、家族或道侣关系受到威胁时，选择救援、护送、断后、求援或牺牲资源；该事件体现其忠诚和守护倾向。

代表事件二：角色面对利益诱惑、敌人招揽或安全撤退机会时，仍坚持原有承诺或关系立场；该事件体现其守信和关系优先。

代表事件三：角色因为守护对象死亡、背叛、失踪或堕落，转向复仇、避世、黑化、改投势力或继续守护遗愿；该事件体现忠诚性格在极端事件后的变化。

性格变化：如果角色从忠诚转向怀疑、复仇、失望、疯狂或超脱，要写清触发事件和后续行为；没有明显变化则写“原文未说明明显变化”。

行为后果：这种性格能带来稳定联盟、师徒传承、追随关系和救援事件，也可能让角色被拖入宗门内斗、家族争端、复仇链或牺牲结局。

### 案例 4：复杂矛盾型角色

角色定位：主要配角 / 反派 / 宗门高层 / 家族继承人 / 妖修 / 邪修等按原文填写。

核心性格：同时存在两种以上明显倾向，例如重情但狠辣、守护但控制欲强、求道但牺牲他人、忠诚但背叛旧主、胆怯但关键时刻敢拼命。

代表事件一：角色在私人情感和现实利益冲突时做出选择，写清其选择不是单纯善恶，而是受身份、资源、关系、压力共同推动。

代表事件二：角色在不同对象面前表现不同，例如对亲友守护、对外人冷酷，对宗门忠诚、对敌人狠辣；该事件体现人物的多面性。

代表事件三：角色因为一次重大失败、亲友死亡、势力崩塌、继承争夺或寿元压力改变立场，使原本性格中的某一面被放大或压制。

性格变化：重点写变化前后的矛盾如何转移，例如从守护变成控制，从求道变成执念，从忠诚变成复仇，从隐忍变成疯狂。

行为后果：复杂性格往往会制造更长的关系变化、势力冲突和因果余波，例如既救过人也害过人、既被信任也被忌惮、既能结盟也可能反噬同伴。
