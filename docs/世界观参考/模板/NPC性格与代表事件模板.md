# NPC性格与代表事件模板

# 规范

本模板用于整理小说中由具体事件支撑的 NPC 性格、欲望、行为选择和性格变化。样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；主角、配角、反派、宗门高层、家族成员、散修、妖修、邪修、普通弟子、旁观者和被牵连者，只要原文明确写到，都可纳入。

只记录能被具体事件支撑的判断。不能只写“谨慎”“贪婪”“忠诚”“狠辣”等单个形容词；台词风格、外貌描写、旁人评价只能作为辅助，不能代替具体行动。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文不写总览、表格、数值区间或项目字段映射。核心角色尽量整理多个代表事件；配角或短线角色可写典型事件。同一角色在不同阶段性格发生变化时，应写清变化原因、变化后的行为和后果；没有明显变化则写“原文未说明明显变化”。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 角色定位：主角、配角、反派、散修、宗门弟子、长老、家族成员、妖修、邪修、普通人、旁观者、被牵连者等，按原文填写。
- 角色称号：金阳上人、无极天尊、无始大帝、撼地千里、肉飞仙、极阴老祖等，写清称号、外号或尊称的来源和对应事件；来源不明写“原文未说明”。
- 基础性格：谨慎、勇敢、忠诚、冷漠、重情、贪婪、残忍、隐忍、骄傲、冲动、圆滑、正直、狠辣、怯懦、多疑、守信、忘恩、偏执等，必须用具体事件支撑。
- 欲望倾向：长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、求道、报恩、求稳、掌控他人等。
- 信仰/执念：角色长期坚持的道理、底线、偏见、誓言、心魔或不可放下之事；必须由具体事件支撑。若只是短期欲望，归入“欲望倾向”；若原文没有长期坚持，写“原文未说明”。
- 情绪变化：情绪是短期变化。写事件前、事件中、事件后的临时情绪转折，如恐惧转为谨慎、羞辱转为复仇、感激转为报恩、贪念转为冒险；不要写长期性格、信仰或执念；没有明显变化写“原文未说明明显变化”。

```md
# 《作品名》NPC性格与代表事件

## NPC性格与代表事件卡片

### 韩立
- 角色定位：黄枫谷弟子-炼气期，乱星海-散修，落云宗-太上长老
- 角色称号：
  -1.虫魔：乱星海外海时期的相关外号；韩立在虚天殿夺得重宝后远遁外星海，又长期猎妖取丹、使用灵虫手段，使外界将其与“虫魔”名号联系起来。后续也有人借“虫魔”名号假扮韩立杀人，引元婴修士追查，韩立识破后选择避祸远走。
  - 2.韩老魔：读者和相关解读中常用的外号，主要对应韩立杀伐果断、杀人夺宝、遇强远遁、处理隐患时不留后手的行事风格；乱星海猎妖取丹、虚天殿夺宝后避祸、为辛如音之事清算傅家等事件都强化了这一印象。
- 基础性格：
  - 1.勇敢：以结丹期修为参与虚天殿争夺，在多名元婴修士环伺的局面中夺得虚天鼎等重宝并成功逃离；后果是获得关键机缘，也因此被高阶修士盯上，被迫远走外星海避祸。
  - 2.奸诈：长期隐藏掌天瓶、真实实力和真实身份，常用“厉飞雨”等化名行动；面对强敌时先判断利弊、布置后手，打不过就远遁，打得过则尽量清除后患。后果是多次避开追杀和反噬，也形成“韩老魔”“韩跑跑”等外部印象。
- 欲望倾向：
  - 1.长生：韩立的核心目标是大道有成、长生有望；面对亲情、情爱、宝物和危险时，常以是否妨碍修仙长生为判断标准，能压下短期情绪和诱惑，优先选择修炼、保命和继续前行。
- 信仰/执念：
  - 1.大道长生：韩立长期坚持修仙求长生，将“大道有成、长生有望”置于多数短期牵绊之上；面对家人、故旧和情感牵连时虽有动摇和愧疚，最终仍选择继续前行。
  - 2.谨慎求生：墨居仁夺舍、七玄门生死局和多次高阶修士追杀，使韩立形成强烈的保命执念；之后常隐藏底牌、准备退路、避免无把握冲突，必要时远遁避祸。
- 情绪变化：
  - 1.墨居仁摊牌并试图夺舍时，韩立先是震惊和恐惧，随后被求生压力逼得冷静应对，抓住机会反制；事件结束后仍有后怕。
  - 2.离开家乡前远望父母亲人时，韩立一时不舍、酸楚和愧疚，但因身中余毒且前路未定，只能压下情绪转身离开。
  - 3.虚天殿夺得重宝后，韩立先有紧张和惊喜，随即因意识到元婴修士追查风险而转为警惕，马上选择远遁避祸。

```
