# NPC性格与代表事件模板

## 适用范围

本模板用于整理小说中由具体事件支撑的 NPC、配角、反派、核心视角人物的性格、欲望、执念、行为选择和变化。

不收录主角。“核心视角人物”仅指原文中拥有较多行动、视角或剧情影响力，但不是主角的人物。

## 整理原则

1. 一人一卡
   同名、别名、化名、称号、身份阶段、境界阶段、阵营变化，都必须归并到同一张角色卡。
   禁止另建“某某（补充）”“某某·后期”“某某别名”等新卡。阶段变化应更新到同卡的对应字段中。

2. 字段完整
   每张卡必须包含：角色定位、角色称号、基础性格、欲望倾向、信仰/执念、行为与后果、情绪变化。
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

3. 事件支撑判断
   只记录能支撑性格判断的事件。事件描述要简洁，但必须包含角色的主动行为和结果。
   不为补齐内容虚构境界、身份、地点、关系、动机、后果或后续影响。

4. 外貌与旁人评价限制
   外貌、气质、台词风格、旁人评价、他人反应只能作为辅助证据。
   不能仅凭“妩媚”“冷傲”“被众人畏惧”“气质不凡”等描写生成性格标签；性格判断必须绑定角色主动行为。

5. 输出简化
   保留代表性事件，不展开无关剧情背景。
   核心人物可记录多个事件；短线人物只记录最能体现性格的一到数个事件。

## 字段说明

- 角色定位：写角色在原文中的身份、阵营、剧情功能或阶段身份，如配角、反派、宗门弟子、长老、家族成员、散修、妖修、邪修、旁观者、被牵连者等。
- 角色称号：写称号、外号、尊称、化名及来源事件；来源不明写“原文未说明”。
- 基础性格：写由具体行为支撑的性格判断，如谨慎、重情、贪婪、残忍、隐忍、骄傲、圆滑、正直、狠辣、多疑、守信等。
- 欲望倾向：写角色反复表现出的追求，如长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、报恩、求稳、掌控他人等。
- 信仰/执念：写角色长期坚持的道理、底线、偏见、誓言、心魔或不可放下之事。短期目标归入“欲望倾向”。
- 行为与后果：写最能支撑性格判断的主动行为，以及该行为造成的直接结果或后续影响。
- 情绪变化：写事件前、中、后的短期情绪转折；不要把长期性格、信仰或执念写成情绪变化。

## 案例

```md
# 《作品名》NPC性格与代表事件

## NPC性格与代表事件卡片

### 角色名称

- 角色定位：
- 角色称号：
- 基础性格：
- 欲望倾向：
- 信仰/执念：
- 行为与后果：
- 情绪变化：

### 韩明

- 角色定位：黄枫谷弟子-炼气期，乱星海-散修，落云宗-太上长老
- 角色称号：
  - 1. 虫魔
  - 2. 韩老魔
- 基础性格：
  - 1. 勇敢：敢于参与虚天殿争夺。
  - 2. 谨慎：长期隐藏底牌并预留退路。
  - 3. 杀伐果断：确认威胁后及时反制并清除后患。
- 欲望倾向：
  - 1. 长生：优先修炼、保命和继续前行。
- 信仰/执念：
  - 1. 大道长生：长期坚持修仙求长生。
  - 2. 谨慎求生：面对风险时隐藏底牌、准备退路。
- 行为与后果：
  - 1. 墨居仁试图夺舍时，韩明冷静寻找反制机会，最终逃过夺舍并反杀对方，此后更加重视隐藏身份和准备后手。
  - 2. 虚天殿夺宝后，韩明判断元婴修士追查风险并远遁外星海，保住重宝和性命，也长期背负被追查的风险。
- 情绪变化：
  - 1. 面对墨居仁夺舍时，由震惊、恐惧转为冷静反制，事后仍有后怕。
  - 2. 离开家乡前，由不舍、酸楚和愧疚转为压下情绪、继续前行。
  - 3. 虚天殿夺宝后，由紧张、惊喜转为警惕，并立即远遁避祸。
```
