# NPC性格与代表事件模板

## 适用范围

本模板用于从一部作品的大量 NPC 中筛选具有创作参考价值的样本，整理其由具体事件支撑的身份阶段、形成条件、性格、欲望、执念、行为选择、环境互动和后续变化。目标不是穷尽所有出场人物，而是为游戏设计和小说创作保留足够典型、差异化且可复用的人物机制。

整理时将角色视为持续运行和变化的个体：从身份与形成条件出发，分析其内在倾向如何在具体处境中转化为情绪、判断、选择和行动，再记录行动结果、代价、关系影响、长期变化与最终状态。模板不要求补写完整生平，只收录能够解释角色性格和行为的内容。

不收录主角。“核心视角人物”仅指原文中拥有较多行动、视角或剧情影响力，但不是主角的人物。

## 整理原则

1. 一人一卡
   同名、别名、化名、称号、身份阶段、境界阶段、阵营变化，都必须归并到同一张角色卡。
   禁止另建“某某（补充）”“某某·后期”“某某别名”等新卡。阶段变化应更新到同卡的对应字段中。

2. 收录门槛与两层管理
   不按“有名字就收录”建立完整角色卡。进入完整角色卡的 NPC 必须同时满足：一是至少有一次能够确认的主动选择及其结果，二是至少能为人物塑造、关系设计、势力生态、游戏机制、事件结构或状态变化提供一种可复用参考。
   只有姓名、身份、外貌、传闻、台词，或者全程只是被动承受事件的人物，不建立完整角色卡。为避免遗漏和重复分析，可另建轻量人物索引，只记录姓名、身份、出场位置、候选或不收录理由；轻量索引不据此生成性格判断。

3. 优先对象、排除与去重
   优先收录：能够改变主要人物、势力格局、资源归属或关键事件走向的影响者；能够展示宗门、家族、职业、阶层、交易或秩序实际运行方式的机制承载者；具有典型角色模式、明显内在矛盾、完整变化链、常态与极端状态差异、关键关系模式或罕见合理选择的人物。
   通常不建立完整角色卡：只有工具性功能、缺少主动选择、仅靠他人评价成形、只是群体统一反应、原文证据不足，或者与已有样本在身份、欲望、决策方式、互动模式和结局上高度重复的人物。戏份少不是排除理由，戏份多也不是必收理由。
   同类人物优先保留证据最完整的典型样本；相同起点但策略不同、相同策略但环境或结果不同、极端状态下打破类型规律的人物，可作为差异样本继续收录。筛选完成后检查势力、社会层级、职业功能、性格机制、关系模式、人物历程和结果类型是否明显偏科。

4. 收录级别与详细程度
   收录级别表示所需分析深度，不单纯表示人物在原作中的地位。每张完整角色卡必须标明“收录级别”“收录理由”和“可复用方向”。

   - 核心样本：适用于影响重大、证据丰富，或同时承载多种人物机制的 NPC。使用完整字段，事件应尽量覆盖关键身份阶段、常态与受压或极端状态、重要关系、主要转折和最终状态，形成“形成条件→内在结构→情境选择→结果代价→长期变化”的连续分析链。原文缺失的完整字段写“原文未说明”，不靠推断补齐。
   - 代表样本：适用于能够代表某种职业、阶层、势力位置、性格机制或关系模式的 NPC。重点填写角色定位、身份轨迹、基础性格、欲望或底线、与代表模式直接相关的状态和关系、代表事件及结果；事件只需覆盖足以说明该模式的一到数个关键场景。形成条件、非关键关系、未展示的极端状态和完整终局没有证据时可省略，不追补完整生平。
   - 边界样本：适用于戏份有限，但在特殊压力、极端状态或罕见选择中提供不可替代参考的 NPC。只深挖使其值得收录的边界事件，至少保留身份、收录理由、可复用方向、触发与限制、主动选择、行动、结果与代价、情绪证据和证据位置；性格只能写“在该事件中表现为……”，不得由一次极端行为推导稳定性格。与边界事件无关的形成条件、长期欲望、关系网和人物终局可省略。

5. 字段完整
   本模板案例列出的是核心样本的完整字段集合。核心样本不得空字段；无依据时写“原文未说明”，无明显变化时写“原文未说明明显变化”。代表样本和边界样本按对应级别保留必需字段，可省略明确规定为非必需且无证据的字段，不需要堆叠“原文未说明”。
   不论级别，已输出的字段都必须有内容；不得为满足完整度虚构信息，也不为“原文未说明”的字段机械拆分子项。

6. 事件支撑判断
   只记录能支撑性格判断的事件。事件描述要简洁，但必须包含角色的主动行为和结果。
   不为补齐内容虚构境界、身份、地点、关系、动机、后果或后续影响。
   每个事件使用唯一编号；基础性格、欲望倾向、信仰/执念、状态化行为模式、情绪变化和人物变化应引用相应事件编号。稳定性格原则上由多个独立事件支撑；仅有单次表现时，应写“在该事件中表现为……”，不要直接定性为长期性格。

7. 外貌与旁人评价限制
   外貌、气质、台词风格、旁人评价、他人反应只能作为辅助证据。
   不能仅凭“妩媚”“冷傲”“被众人畏惧”“气质不凡”等描写生成性格标签；性格判断必须绑定角色主动行为。
   证据性质区分为“原文明示”“行为推断”“他人评价”。他人评价与角色实际行为不一致时，分别记录，不替角色行为下结论。

8. 输出简化
   保留代表性事件，不展开无关剧情背景。
   核心样本可记录多个事件；代表样本只保留足以说明其可复用模式的一到数个事件；边界样本只保留构成边界价值的事件及必要前因后果。
   形成条件只收录对性格、目标、执念或行为模式具有解释作用的经历；关键关系只收录能够暴露、强化或改变角色性格的互动，不扩写人物简历或完整关系网。

9. 状态与变化区分
   区分常态、受压状态和极端状态下的行为，不把一次失控或特殊处境中的表现直接视为稳定性格。
   区分事件内的短期情绪变化与跨事件、跨阶段的长期人物变化。没有极端状态、转折或最终结局证据时，明确写“原文未说明”，不要根据人物类型推演。

10. 事实与推断边界
   身份、行动、结果、台词和明确心理描写按原文事实记录；性格、动机、关系模式和长期影响如非原文明示，应标为“行为推断”。
   推断必须说明所依据的事件，并保留其他合理解释的可能；证据不足时写“原文未说明”，不把可能性写成事实。

## 字段说明

- 收录级别：填写“核心样本”“代表样本”或“边界样本”，用于决定卡片的分析深度和必需字段，不用于代替角色定位。
- 收录理由：用一句话说明如果删除这张卡，会损失哪一种重要的人物机制、互动模式、变化路径、世界运行样本或边界选择。不得只写“戏份多”“很重要”或“有特点”。
- 可复用方向：从人物塑造、关系设计、势力生态、游戏机制、事件结构、状态变化中选择一项或多项，并写明可借鉴的具体内容，避免只贴宽泛标签。
- 角色定位：写角色在原文中的人物类型和剧情功能，如配角、反派、核心视角人物、阻碍者、协助者、旁观者、被牵连者等。会随阶段变化的具体身份和阵营归入“身份与阵营轨迹”。
- 身份与阵营轨迹：按原文时间或剧情阶段，写角色的身份、阵营、境界、社会位置及其变化，如“宗门弟子→散修→宗门长老”。仅列原文能够确认的节点，不推演缺失阶段。
- 角色称号：写称号、外号、尊称、化名及来源事件；来源不明写“原文未说明”。
- 形成条件：写确实塑造或强化角色性格、目标、底线、执念、恐惧或行为模式的出身环境和关键经历。只写有因果证据的内容，不把一般履历都视为成因。
- 基础性格：写由具体主动行为支撑、在多个事件中相对稳定的性格判断，如谨慎、重情、贪婪、残忍、隐忍、骄傲、圆滑、正直、狠辣、多疑、守信等，并引用事件编号。单次表现应限定在对应情境中。
- 欲望倾向：写角色反复表现出的长期追求或回避，如长生、变强、复仇、守护、传承、夺权、避世、求名、报恩、求稳、掌控他人等。某次事件中的短期目标写入该事件的“触发与利害”，不要与长期欲望混写。
- 信仰/执念：写角色长期坚持的价值判断、信仰、底线、偏见、誓言、心魔或即使代价过高仍不可放下之事。一般目标归入“欲望倾向”，谨慎、隐忍等做事方式归入“基础性格”或“状态化行为模式”。
- 恐惧/弱点/内在矛盾：写能够影响选择或导致失衡的恐惧、能力或处境弱点，以及性格、目标、价值观之间有事件支撑的冲突，如“重情但为自保疏远亲近者”。不根据人物类型补写通用弱点。
- 状态化行为模式：分别概括角色在常态、受压和极端状态下如何判断、选择和行动，并引用事件编号。原文只展示其中某种状态时，其他状态写“原文未说明”。
- 关键关系与互动模式：只写能够暴露、强化或改变角色性格的关系，说明角色面对特定对象或群体时反复采用的互动方式，以及对方或环境产生的反馈。关系名称本身不能代替互动证据。
- 行为与后果：按事件编号记录最能支撑判断的事件。每个事件依次写“所处阶段”“触发与利害”“限制条件”“判断与主动选择”“行动”“直接结果”“长期影响与代价”“支撑判断”“证据位置与性质”；某项原文未说明时明确标注，不补写因果。
- 情绪变化：按事件编号写事件前、中、后的短期情绪转折，并与“行为与后果”中的同编号事件对应。不要把长期性格、信仰、执念或跨阶段变化写成情绪变化。
- 人物变化与最终状态：写跨事件或跨阶段的稳定变化，包括变化前状态、转折事件及原因、变化后状态、原文结束时的最终状态，以及对关系、组织或环境的后续影响。短期情绪不算人物变化；没有明显变化时写“原文未说明明显变化”。
- 证据位置与性质：作为每个代表事件的子项，写作品内可定位的位置，并标明“原文明示”“行为推断”或“他人评价”。章节不明时写“原文未说明”，不得伪造章节号。
