# NPC性格与代表事件模板

# 规范

本模板用于整理小说中由具体事件支撑的 NPC 性格、欲望、行为选择和性格变化。样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；主角、配角、反派、宗门高层、家族成员、散修、妖修、邪修、普通弟子、旁观者和被牵连者，只要原文明确写到，都可纳入。

只记录能被具体事件支撑的判断。不能只写“谨慎”“贪婪”“忠诚”“狠辣”等单个形容词；台词风格、外貌描写、旁人评价只能作为辅助，不能代替具体行动。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文不写总览、表格、数值区间或项目字段映射。核心角色尽量整理多个代表事件；配角或短线角色可写典型事件。同一角色在不同阶段性格发生变化时，应写清变化原因、变化后的行为和后果；没有明显变化则写“原文未说明明显变化”。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 角色定位：主角、配角、反派、散修、宗门弟子、长老、家族成员、妖修、邪修、普通人、旁观者、被牵连者等，按原文填写。
- 基础性格：谨慎、勇敢、忠诚、冷漠、重情、贪婪、残忍、隐忍、骄傲、冲动、圆滑、正直、狠辣、怯懦、多疑、守信、忘恩、偏执等，必须用具体事件支撑。
- 欲望倾向：长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、求道、报恩、求稳、掌控他人等。
- 决策场景：强敌压迫、宝物诱惑、同门遇险、师徒关系、道侣关系、宗门命令、家族利益、背叛、寿元压力、突破失败、势力覆灭等。
- 代表行为：逃跑、反击、杀人夺宝、放过敌人、报恩、背叛、隐忍复仇、护徒、收徒、交易、牺牲、闭关、求援、投靠、叛逃等。
- 变化原因：亲友死亡、救命之恩、被背叛、宗门覆灭、夺宝成功、夺宝失败、重伤濒死、寿元将尽、获得传承、突破失败、心魔刺激等。
- 行为后果：结仇、结盟、被追杀、获得信任、失去靠山、转投势力、黑化、避世、改换修炼路线、被孤立、掌权、被清算等。
