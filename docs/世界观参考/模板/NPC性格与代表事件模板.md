# NPC性格与代表事件模板

# 规范

本模板用于整理小说中由具体事件支撑的 NPC 性格、欲望、行为选择和性格变化。样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；主角、配角、反派、宗门高层、家族成员、散修、妖修、邪修、普通弟子、旁观者和被牵连者，只要原文明确写到，都可纳入。

只记录能被具体事件支撑的判断。不能只写“谨慎”“贪婪”“忠诚”“狠辣”等单个形容词；台词风格、外貌描写、旁人评价只能作为辅助，不能代替具体行动。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文不写总览、表格、数值区间或项目字段映射。核心角色尽量整理多个代表事件；配角或短线角色可写典型事件。同一角色在不同阶段性格发生变化时，应写清变化原因、变化后的行为和后果；没有明显变化则写“原文未说明明显变化”。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 角色定位：主角、配角、反派、散修、宗门弟子、长老、家族成员、妖修、邪修、普通人、旁观者、被牵连者等，按原文填写。
- 基础性格：谨慎、勇敢、忠诚、冷漠、重情、贪婪、残忍、隐忍、骄傲、冲动、圆滑、正直、狠辣、怯懦、多疑、守信、忘恩、偏执等，必须用具体事件支撑。
- 欲望倾向：长生、变强、夺宝、复仇、守护、传承、夺权、避世、求名、求道、报恩、求稳、掌控他人等。
- 决策场景：强敌压迫、宝物诱惑、同门遇险、师徒关系、道侣关系、宗门命令、家族利益、背叛、寿元压力、突破失败、势力覆灭等。
- 代表行为：逃跑、反击、杀人夺宝、放过敌人、报恩、背叛、隐忍复仇、护徒、收徒、交易、牺牲、闭关、求援、投靠、叛逃等。
- 变化原因：亲友死亡、救命之恩、被背叛、宗门覆灭、夺宝成功、夺宝失败、重伤濒死、寿元将尽、获得传承、突破失败、心魔刺激等。
- 行为后果：结仇、结盟、被追杀、获得信任、失去靠山、转投势力、黑化、避世、改换修炼路线、被孤立、掌权、被清算等。

## 案例

### 案例

```md
# 《作品名》NPC性格与代表事件

## NPC性格与代表事件卡片

### 角色名称

- 角色定位：
- 核心性格：
- 欲望倾向：
- 决策场景：
- 代表行为：
- 代表事件：
- 变化原因：
- 变化与后果：

### 谨慎隐忍型角色

- 角色定位：主角 / 散修 / 宗门弟子 / 其他身份按原文填写。
- 核心性格：谨慎、隐忍、重视生存、恩怨分明、重视利益边界。
- 欲望倾向：求稳、变强、避险、复仇或守护利益边界，按原文填写。
- 决策场景：面对强敌、未知风险、宝物诱惑或旧仇牵连。
- 代表行为：隐藏实力、搜集情报、准备退路、评估收益，或等时机成熟再行动。
- 代表事件：写清角色在具体事件中如何选择、如何行动，以及当时的关系和压力。
- 变化原因：原文未说明明显变化；如有重大刺激，按原文填写。
- 变化与后果：写清其如何避开死局，也如何造成不信任、错过机会、长期复仇或因果牵连。

### 贪婪冒险型角色

- 角色定位：散修 / 邪修 / 宗门弟子 / 反派 / 临时队友等按原文填写。
- 核心性格：贪婪、冒险、短视、机会主义，也可能兼具胆大、果断或狠辣。
- 欲望倾向：夺宝、变强、求名、夺权或掌控他人，按原文填写。
- 决策场景：面对宝物、丹药、传承、灵草、法宝或短期利益诱惑。
- 代表行为：隐瞒情报、背叛同伴、临阵倒戈、杀人夺宝，或在短期成功后继续扩大风险。
- 代表事件：写清其为何冒险、如何行动，以及同伴、敌人或势力的反应。
- 变化原因：失败、重伤、被追杀、失去靠山或夺宝成功后的欲望膨胀，按原文填写。
- 变化与后果：写清夺宝、背叛、截杀、通缉、死亡、失势或被清算等结果。

### 忠诚守护型角色

- 角色定位：弟子 / 护卫 / 长老 / 师傅 / 家族成员 / 道侣 / 追随者等按原文填写。
- 核心性格：忠诚、重情、守诺、愿意承担代价，也可能固执、保守或被关系束缚。
- 欲望倾向：守护、报恩、传承、求稳或维持宗门家族利益，按原文填写。
- 决策场景：宗门、师徒、家族或道侣关系受威胁。
- 代表行为：救援、护送、断后、求援、牺牲资源，或拒绝利益诱惑。
- 代表事件：写清守护对象、威胁发起方、行动代价和事件结果。
- 变化原因：守护对象死亡、背叛、失踪或堕落，按原文填写。
- 变化与后果：写清联盟、传承、追随、内斗、复仇链或牺牲结局。

### 复杂矛盾型角色

- 角色定位：主要配角 / 反派 / 宗门高层 / 家族继承人 / 妖修 / 邪修等按原文填写。
- 核心性格：同时存在两种以上明显倾向，如重情但狠辣、守护但控制欲强、求道但牺牲他人。
- 欲望倾向：私人情感、现实利益、求道、掌权或守护对象之间存在冲突，按原文填写。
- 决策场景：私人情感和现实利益冲突，或不同关系对象提出相反要求。
- 代表行为：在不同对象面前表现出不同面向，或因重大失败和压力放大某一性格面。
- 代表事件：写清矛盾如何出现、角色如何取舍，以及被牺牲或被保护的对象。
- 变化原因：重大失败、关系破裂、势力冲突、心魔刺激或长期压力，按原文填写。
- 变化与后果：写清矛盾如何转移，以及关系变化、势力冲突和因果余波。
```

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
