# 武器分析模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的武器、兵器、护具、战斗装备、制式装备、法宝武器，以及与战斗或武器装备制造、维护直接绑定的职业器具、训练器具。

整理时将武器视为“身份与边界—形成与品质—结构与表现—获取与归属—使用输入—正常运行—个体与环境互动—异常损坏—维护强化—最终去向”的完整装备系统。模板不要求所有武器机械填满每种状态，只记录作品实际涉及、能够形成连贯因果链的内容。

本模板只做武器分析，不展开功法、术法、斗技、身法、拳脚招式、剑法刀法、地形、建筑、容器、食物、药方、人物、生物、非战斗奇物、普通修炼资源和非战斗生产器具等内容。功法招式只在“关联功法/招式”中作为配套关系被提到；法宝、法器、灵器只有具备武器形制或明确用于攻防、控制、破禁、护身时，才进入本模板。

## 整理原则

1. 先做准入判定  
   只有具备武器形制，或明确用于攻击、防御、控制、破禁、护身、战斗辅助、装备生产、战斗训练的对象，才可建立武器卡。  
   功法、术法、斗技、身法、拳脚、剑法、刀法、地形、建筑、门墙、普通容器、食物、药方、人物、生物、非战斗奇物和不参与武器装备制造维护的职业器具不得作为武器卡。

2. 区分武器和关联对象  
   `象甲功`、`奔雷刀法`、`拂柳剑法`、`裂爪击`、`铁山拳`、`八极崩`、`燕返击`属于功法、武技或斗技，不单独成武器卡，可写入对应武器的关联招式。  
   `炼骨崖麻绳`、`竹竿`、`岩壁攀爬面`、`练功静室`、`青石大门`、`檀木盒`、`废弃硬青砖`、`黄栗丸`、`止痛药方`、`云翅鸟`、`神秘男子`默认不进入武器模板。

3. 法宝武器单独判定  
   法宝、法器、灵器、符宝、古宝并非天然进入武器模板。只有具备武器形制，或原文明确用于攻击、防御、控制、破禁、护身，才可作为法宝武器收录。  
   `金光上人飞剑`、`金蚨子母刃`、`青竹蜂云剑`、`飞天盾`、`飞剑符宝`、`玄重尺`、`玉尺法器`、`荡魂砚`、`宣命笔`、`如意神梭`属于高优先级候选；`神秘瓶子`、`残玉`这类非战斗奇物默认转入法宝/奇物类模板。

4. 职业器具和训练器具要收窄  
   职业器具只收与战斗、武器装备制造、维护或战斗职业作业直接相关的对象，并标明其不是普通战斗武器。炼药鼎、普通工艺器具和推演工具不因具有器物形制而进入武器卡。
   训练器具只有直接承担武器训练、攻防训练或战斗能力测试时才收录；普通计时、召集、陈设和生活器具不收录。

5. 先召回候选再过滤  
   整理前先按作品语境扫描候选，再判定是否成卡。通用候选词可包括：剑、刀、枪、矛、戟、斧、锤、棍、鞭、弓、弩、针、爪、盾、甲、尺、鼎、印、钟、环、幡、旗、梭、笔、砚、飞剑、法器、法宝、灵器、符宝、古宝、傀儡、机关、战舟等。  
   作品专属候选也要纳入，例如 `玄重尺`、`青竹蜂云剑`、`金蚨子母刃`、`玉尺`、`荡魂砚`、`如意神梭`。傀儡、机关和战舟只有整体以战斗为主要功能时才成卡；否则只记录其独立武装部分。

6. 一器一卡  
   同一武器的主称、别名、外观称呼、使用者称呼、后续升级、破损修复和新用途，优先归并到同一张卡。  
   例如 `厉师兄长刀`和`寒光长刀`应合并；`玄重尺`、`黑色巨剑`、`黑尺`、`重尺`应归并到同一张卡。

7. 字段完整  
   每张卡应使用统一字段串联武器的形成、结构、使用、互动、损坏和后续变化。明显武器直接填写分类；边界对象再补充准入说明。无可靠原文支撑时写“原文未说明”，不适用时写“不适用”；不得为了补齐内部结构、运行过程、个体差异、环境互动、异常状态或升级去向而自行推断。

8. 区分形制、结构和外部表现
   “形制”写对象属于剑、盾、甲、弓弩或其他器型；“结构、部件与工作机制”写内部组成、组合关系和实现作用的方式；“外观与状态表现”写静止、激活、命中和受损状态下可直接感知的特征。三者不得用同一句外形描述重复填充。

9. 区分形成、获取和归属
   “制作/形成与品质决定因素”记录对象如何产生及品质为何不同；“获取、流通与归属变化”记录稀有程度、获得、配发、交易、继承、持有、转手和被夺取。制造者、获得者和当前持有者不是同一概念，应按作品实际内容分别填写。

10. 区分功效、用途和运行过程
    “功效”记录武器使目标、使用者或环境发生什么变化；“用途”记录为何使用以及使用场景；“使用方式与运行过程”记录如何持握、装备、激活、释放、命中、防御、持续和回收。作品只说明结果而未说明过程时，运行过程写“原文未说明”。

11. 区分正常、弱效、异常和极端状态
    正常运行写入“功效”和“使用方式与运行过程”；因境界、体魄、属性、熟练度或目标差异造成的弱效、无效和表现差异写入“适用对象与表现差异”或“相互作用、环境适应与克制”；失控、卡滞、反噬、过载、断裂、自毁等写入“异常、极端状态与损坏结果”。作品没有展示某类状态时不推演。

12. 记录使用者、目标与环境互动
    记录武器与使用者体魄、境界、功法和职业的配合，也记录其与目标材质、防具、其他武器、阵法、地形、温度、水火、灵气或其他环境条件之间实际存在的增强、削弱、冲突和克制。不能仅因属性相反就推断克制关系，也不能把单个使用者的表现直接视为通用上限。

13. 记录成长、衰退和最终去向
    养炼、解封、升级、重铸和形态变化写入“维护、修复、强化与最终去向”；磨损、腐蚀、失效和性能下降也写入该字段。断裂、失控和自毁的触发及直接结果写入异常字段，之后能否修复、拆解、回收、继承或彻底毁灭写入最终去向。

14. 明确信息与推断边界
    作品直接说明或能够稳定归纳的信息按实际内容填写；必要的合理推断必须明确标注。人物判断、传闻、外观联想和题材惯例不能直接写成武器通则；不同阶段说法冲突时并列保留，未知内容写“原文未说明”。

15. 输出简化
   保留能体现武器形制、内部结构、攻防方式、使用者、装备体系、形成获取、运行限制、异常损坏、后续变化和关联专题的信息。
   不长篇复述剧情，不把人物评价、战斗过程、功法效果、建筑细节或非武器奇物塞满字段。

16. 生成后自检
   检查是否把功法、斗技、建筑、地形、容器、人物、生物、非战斗奇物和非战斗职业器具误当武器；是否漏掉高频核心武器、法器武器和战斗法宝；是否把同一武器拆成多张卡；形制、结构、功效、用途和运行过程是否重复；正常、弱效、异常和极端状态是否混写；形成、归属、维护和最终去向是否串联；合理推断是否明确标注。

## 字段说明

- 分类与准入说明：写武器、护具、战斗装备、法宝武器、武器装备生产维护器具或战斗训练器具等分类；明显属于武器的对象只写分类，边界对象补充其承担的实际战斗或装备功能。
- 名称与别名：写武器主称、别名、外观称呼、使用者称呼、旧称、套装名或同一对象的不同叫法。
- 形制：写剑、刀、枪、矛、戟、斧、锤、棍、鞭、弓、弩、针、爪、盾、甲、尺、鼎、印、钟、环、幡、旗、梭、笔、砚、飞剑、暗器、机关器械、舟船武装等。
- 结构、部件与工作机制：写主体、刃部、护手、弦、箭匣、弹仓、机关、子母部件、阵纹、器灵及其他内部组成，说明部件如何组合或驱动；整体式兵器或结构不明时按实际情况填写。
- 外观与状态表现：写颜色、尺寸、重量、材质观感、纹饰、光泽及其他静态特征，并记录激活、攻击、防御、命中、失效和受损时可直接观察到的形态、声光、气息、温度或破损变化。
- 品阶/品质：按作品自己的等级和质量体系填写，如凡兵、制式兵器、灵兵、法器、法宝、符宝、古宝、传承武器，以及下品、上品、完好、残缺、封印等品质或状态；稀有程度写入获取流通字段。
- 制作材料：写具体材料、通用材料规则及原文明示的材料作用，如精铁、玄铁、妖兽骨、妖兽筋、鳞甲、灵木、矿石、星辰铁等；不明时写“原文未说明”。
- 制作/形成与品质决定因素：写武器如何锻造、炼制、组装、改造、自然生成或由旧器转化，并记录原文明示的工艺、环境、制造者要求、成功率及决定品阶、品质和特殊能力的因素。
- 获取、流通与归属变化：写稀有程度、来源、宗门或军队配发、购买、拍卖、战利品、遗迹获得、家族传承、当前持有者或装备势力，以及后续转手、继承、遗失和被夺取等变化。
- 功效：写武器本身带来的效果，如攻杀、防御、护身、控制、破甲、破禁、远程狙杀、群攻、镇压神魂、增幅职业能力、辅助训练等。
- 用途：写武器被如何使用，如近战、远程、护身、偷袭、军阵、守城、破防、斗法、训练、装备制造维护、战斗职业作业、宗门制式装备等。
- 使用方式与运行过程：写持握、穿戴、架设、装填、瞄准、操控、祭炼、激活和释放方式，以及攻击、防御、控制、持续、回收、再次使用等实际运行过程；作品只说明结果时不补写过程。
- 适用对象与表现差异：写适用境界、体魄、职业、功法、属性、种族、熟练度或其他使用者条件，并记录这些条件造成的效果、操控难度、负担、弱效或失效差异。
- 限制、消耗与使用负荷：写修为、体魄、职业、权限和前置祭炼等门槛，以及能量、弹药、耐久、装填、冷却、持续时间和对使用者造成的体力、精神、经脉或其他负担。
- 相互作用、环境适应与克制：写武器与目标、防具、其他装备、功法、阵法及地形、温度、水火、灵气等环境条件之间实际存在的增强、削弱、冲突、穿透、防护、克制和失效关系。
- 异常、极端状态与损坏结果：写卡滞、失灵、失控、反噬、过载、错误操控、超限使用、断裂、自毁及其他异常或极端状态的触发条件、表现和直接结果。
- 维护、修复、强化与最终去向：写清洁、保养、补充、修复、养炼、解封、升级、重铸、形态变化、性能衰退，以及拆解、回收、封存、遗失、继承或彻底毁灭等后续变化。
- 关联功法/招式：写配套功法、斗技、剑法、刀法、职业技艺或训练方式；没有说明时写“原文未说明”。
- 关联专题：写已经准入武器卡的对象还与法宝、功法、材料、建筑设施、职业器具、交通工具或奇物等哪些专题相关；只记录关联，不在本字段重新判断准入。
- 信息边界与不确定项：写本卡中需要说明的合理推断、不同阶段说法之间的冲突，以及会影响武器理解的重要未知项；不得把人物猜测、外观联想或题材惯例直接写成确定规则。
