# 武器分析模板

## 适用范围

本模板用于整理作品中明确出现、具有独立装备形制并承担攻击、防御、控制、破禁、护身、战斗辅助或战斗训练功能的武器、兵器、护具、制式装备、法宝武器和战斗器械。

本模板只分析武器本体及其稳定的装备机制，不展开功法、术法、斗技、身法、拳脚招式、地形、建筑、普通容器、人物、生物、非战斗奇物、普通修炼资源和非战斗生产器具。功法和招式只在“关联功法/招式”中作为配套关系出现；材料、法宝奇物、职业器具和交通工具放入对应专题，除非其本体明确以武器或战斗装备为主要功能。

## 整理原则

1. 先做准入判定：对象必须具备独立武器形制，或明确作为独立装备承担攻击、防御、控制、破禁、护身、战斗辅助或战斗训练功能；一次性斗气、能量、异火、毒气、灵魂、阵法或招式效果不得直接建武器卡。
2. 区分武器和关联对象：功法、术法、斗技、身法、建筑、地形、普通容器、材料、生物、人物和非战斗奇物不因具有攻击描述或器物外形而进入本模板。
3. 法宝武器单独判定：法宝、法器、灵器、符宝和古宝只有具备武器形制或明确用于攻防、控制、破禁、护身时才收录；非战斗奇物转入法宝或奇物专题。
4. 一器一卡：同一武器的主称、别名、外观称呼、使用者称呼、升级、破损、修复和新用途归入同一卡；不按章节、批次、持有者或单次战斗拆卡。
5. 字段只写武器本体：不引入无关人物、地点、战斗对白、招式过程、剧情流水账或逐次使用记录；不设置“本窗口补充”“新使用”等批次字段。
6. 区分静态设定和运行机制：形制、结构、外观、材料和品质写稳定属性；功效写结果类型；用途写使用场景；使用方式与运行过程只写可重复的装备机制和运行链。
7. 使用过程只写机制摘要：按“使用准备 -> 输入/激活 -> 作用方式 -> 持续条件 -> 终止/回收”概括，不写某次战斗中的连续动作、命中对象、人物对白、逐次结果或每次未损坏。
8. 归属和状态按主线归并：获取、配发、继承、转手、遗失、修复和当前归属只保留必要变化链；历史状态写入对应阶段，不把批次信息写进名称或字段。
9. 区分正常、弱效和异常：正常运行写功效与运行机制；境界、体魄、属性、熟练度和目标差异写适用对象或相互作用；失控、过载、反噬、卡滞、断裂和自毁写异常字段。
10. 信息不足时如实标注并保持简洁：使用“原文明确”“实际表现”“稳定归纳”“人物评价或传闻”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不根据名称、材质常识、使用者境界或单次结果补齐品质、上限和机制。

## 信息与输出规则

1. 武器卡只保留总结结论：原文描写、对白、数字和战斗过程，只有能说明武器形制、结构、功效、限制、归属或稳定互动时，才压缩为一句设定。
2. 单次表现不等于通用规则：一次命中、一次破坏、一次克制或一次未损坏，只能作为实际表现或信息边界，不直接概括为武器的普遍上限、品质或制式属性。
3. 统一字段与状态：固定使用本模板字段；缺失内容写“原文未说明”，不适用写“不适用”，范围不足写“本次未覆盖到明确内容”。
4. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留总结结论和确定性类型。
5. 禁止实战日志：不单独建立使用记录或实战记录表；同一表现不得在使用、相互作用、异常和维护字段中重复展开。
6. 输出前自检：检查是否误收招式、能量形态、阵法、材料、容器、生物和非战斗奇物；检查同器归并、字段边界、运行链、归属状态、异常机制和关联专题是否清楚。

## 字段说明

- 分类与准入说明：填写武器、护具、战斗装备、法宝武器、制式装备、攻城器械、战斗傀儡或战斗训练器具等分类；边界对象说明其独立装备功能，纯招式或能量形态写排除理由。
- 名称与别名：填写主称、别名、外观称呼、使用者称呼、旧称、套装名和同一对象的其他叫法；章节名、批次名和“本窗口补充”不得写入名称。
- 形制：填写剑、刀、枪、矛、戟、斧、锤、棍、鞭、弓、弩、针、爪、盾、甲、尺、鼎、印、钟、环、幡、旗、梭、笔、砚、飞剑、暗器、机关器械或舟船武装等实际器型。
- 结构、部件与工作机制：填写主体、刃部、护手、弦、箭匣、弹仓、机关、子母部件、阵纹、器灵和其他内部组成，说明部件怎样组合或驱动；结构不明时写“原文未说明”。
- 外观与状态表现：填写颜色、尺寸、重量、材质观感、纹饰、光泽和静止状态；激活、攻击、防御、失效或受损时只总结稳定可感知的形态、声光、气息、温度和破损表现。
- 品阶/品质：按作品体系填写凡兵、制式兵器、灵兵、法器、法宝、符宝、古宝、传承武器以及下品、上品、完好、残缺、封印等品质；稀有程度写入获取、流通与归属变化。
- 制作材料：填写具体材料、通用材料规则和原文明示的材料作用；不明时写“原文未说明”，不因武器颜色或重量反推材质。
- 制作/形成与品质决定因素：填写锻造、炼制、组装、改造、自然生成或旧器转化方式，以及原文明示的工艺、环境、制造者要求、成功条件和决定品质或特殊能力的因素；不展开制作过程日志。
- 获取、流通与归属变化：填写来源、配发、购买、拍卖、遗迹获得、家族传承、当前持有或装备势力，以及必要的转手、继承、遗失和被夺变化；用“前一归属 -> 变化 -> 当前归属”简洁概括，不写时间位置或逐次持有记录。
- 功效：填写武器本身稳定提供的攻击、防御、护身、控制、破甲、破禁、远程、群攻、镇压、增幅或训练效果；不把单次战斗结果直接写成通用功效。
- 用途：填写近战、远程、护身、偷袭、军阵、守城、破防、斗法、训练、制式装备、战斗职业作业或其他稳定使用场景；只写用途，不写具体事件。
- 使用方式与运行过程：只填写可重复的运行机制，按“使用准备 -> 输入/激活 -> 作用方式 -> 持续条件 -> 终止/回收”概括；多个模式分项说明。不得写谁在某次战斗中怎样挥动、命中何人、连续施放、逐句动作、对白、战斗结果或每次是否损坏。作品只说明结果而未说明过程时写“运行过程原文未说明”。
- 适用对象与表现差异：填写适用境界、体魄、职业、功法、属性、种族、熟练度、权限或其他使用者条件，以及这些条件造成的操控难度、负担、弱效或失效差异；单个使用者的境界不等于武器通用适用范围。
- 限制、消耗与使用负荷：填写修为、体魄、职业、权限、前置祭炼、能量、弹药、耐久、装填、冷却、持续时间和对使用者造成的体力、精神、经脉或其他负担。
- 相互作用、环境适应与克制：填写武器与目标、防具、其他装备、功法、阵法、地形、温度、水火、灵气等之间已经确认的增强、削弱、冲突、穿透、防护、克制和失效关系；不列多次战斗过程。
- 异常、极端状态与损坏结果：填写卡滞、失灵、失控、反噬、过载、错误操控、超限使用、断裂、自毁及其他异常的触发条件、稳定表现和直接结果；同一损坏不在多个字段重复记录。
- 维护、修复、强化与最终去向：填写清洁、保养、补充、修复、养炼、解封、升级、重铸、形态变化和性能衰退，以及拆解、回收、封存、遗失、继承或彻底毁灭等最终状态；不逐条记录“某次使用后未损坏”。
- 关联功法/招式：只填写配套功法、斗技、剑法、刀法、职业技艺或训练方式的名称及配合关系；完整内容放入对应专题。
- 关联专题：填写与本武器相关且已经建立的法宝、功法、材料、建筑设施、职业器具、交通工具或奇物专题；只写关联，不在此重复本体分析。
- 信息边界与不确定项：区分原文明确、实际表现、稳定归纳、人物评价或传闻、上下文推断、其他合理解释、原文未说明、本次未覆盖到明确内容和不适用；不写任何来源位置或证据标注。
