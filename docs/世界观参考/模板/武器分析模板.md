# 武器分析模板

## 适用范围

用于整理作品中出现过，或能由原文、资料来源和可靠依据支撑的武器、兵器、护具、战斗装备、制式装备和职业器具。

普通兵器、护具、军阵装备和职业器具放入本模板。若某件武器还具备独立法宝效果、器灵、祭炼认主、本命温养、禁制、秘境钥匙或储物空间，也应同时进入 `法宝分析模板.md`；本模板侧重形制、战斗方式、制作材料、使用者和装备生产。

## 前置声明

- 只整理有原文或可靠资料支撑的内容，不补造武器、品阶、数值和境界梯度。
- 样本尽量覆盖不同形制、用途、境界、使用者和获得方式；案例数量不限。
- 原文没有说明材料、来源、限制、损耗、使用者或适用境界时，写“原文未说明”。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法提示 |
|------|----------|
| 武器名称 | 写原文名称；可包含兵器、护具、机关器械、职业器具或制式装备。 |
| 形制 | 写剑、刀、枪、矛、盾、甲、弓弩、暗器、傀儡武器、舟船武装等。 |
| 稀有度/品阶 | 按作品说法写，如凡兵、制式兵器、灵兵、法器武器、神兵、传承武器。 |
| 功效 | 写攻杀、防御、破甲、远程狙杀、群攻、破禁、护身、增幅招式等。 |
| 用途 | 写近战、远程、军阵、偷袭、守城、职业作业、宗门配发等。 |
| 制作材料 | 写精铁、玄铁、妖兽骨、鳞甲、灵木、矿石等；不明写“原文未说明”。 |
| 制作/获得方式 | 写锻造、炼制、配发、战利品、拍卖、遗迹、传承、妖兽材料改造等。 |
| 使用者/势力 | 写角色、职业、势力或适用人群；不明写“原文未说明”。 |
| 限制/损耗 | 写修为、体魄、职业、功法配套、磨损、断裂、修复、重铸、被克制等。 |
| 适用境界 | 按作品自己的境界体系填写。 |
| 来源依据 | 写原文位置、资料来源或可靠依据；不要用无来源推断补齐。 |
