# 武器分析模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的武器、兵器、护具、战斗装备、制式装备、法宝武器，以及与战斗或装备生产直接绑定的职业器具、训练器具。

本模板只做武器分析，不展开功法、术法、斗技、身法、拳脚招式、剑法刀法、地形、建筑、容器、食物、药方、人物、生物、非战斗奇物、普通修炼资源等内容。功法招式只在“关联功法/招式”中作为配套关系被提到；法宝、法器、灵器只有具备武器形制或明确用于攻防、控制、破禁、护身时，才进入本模板。

## 整理原则

1. 先做准入判定  
   只有具备武器形制，或明确用于攻击、防御、控制、破禁、护身、战斗辅助、装备生产、战斗训练的对象，才可建立武器卡。  
   功法、术法、斗技、身法、拳脚、剑法、刀法、地形、建筑、门墙、普通容器、食物、药方、人物、生物、非战斗奇物不得作为武器卡。

2. 区分武器和关联对象  
   `象甲功`、`奔雷刀法`、`拂柳剑法`、`裂爪击`、`铁山拳`、`八极崩`、`燕返击`属于功法、武技或斗技，不单独成武器卡，可写入对应武器的关联招式。  
   `炼骨崖麻绳`、`竹竿`、`岩壁攀爬面`、`练功静室`、`青石大门`、`檀木盒`、`废弃硬青砖`、`黄栗丸`、`止痛药方`、`云翅鸟`、`神秘男子`默认不进入武器模板。

3. 法宝武器单独判定  
   法宝、法器、灵器、符宝、古宝并非天然进入武器模板。只有具备武器形制，或原文明确用于攻击、防御、控制、破禁、护身，才可作为法宝武器收录。  
   `金光上人飞剑`、`金蚨子母刃`、`青竹蜂云剑`、`飞天盾`、`飞剑符宝`、`玄重尺`、`玉尺法器`、`荡魂砚`、`宣命笔`、`如意神梭`属于高优先级候选；`神秘瓶子`、`残玉`这类非战斗奇物默认转入法宝/奇物类模板。

4. 职业器具和训练器具要收窄  
   职业器具只收与战斗、装备生产或战斗职业作业直接相关的对象，并标明其不是普通战斗武器。  
   例如 `炎火精药鼎`可作为炼药职业器具候选，`铁铃铛`可作为训练器具候选；`竹筹`只是推演工具，默认不作为武器卡。

5. 先召回候选再过滤  
   整理前先按作品语境扫描候选，再判定是否成卡。通用候选词可包括：剑、刀、枪、矛、戟、斧、锤、棍、鞭、弓、弩、针、爪、盾、甲、尺、鼎、印、钟、环、幡、旗、梭、笔、砚、飞剑、法器、法宝、灵器、符宝、古宝、傀儡、机关、战舟等。  
   作品专属候选也要纳入，例如 `玄重尺`、`青竹蜂云剑`、`金蚨子母刃`、`玉尺`、`荡魂砚`、`如意神梭`。

6. 一器一卡  
   同一武器的主称、别名、外观称呼、使用者称呼、后续升级、破损修复和新用途，优先归并到同一张卡。  
   例如 `厉师兄长刀`和`寒光长刀`应合并；`玄重尺`、`黑色巨剑`、`黑尺`、`重尺`应归并到同一张卡。

7. 字段完整  
   每张卡必须包含：收录判定、名称与别名、形制、外观描述、稀有度/品阶、是否法宝/法器、是否战斗使用、功效、用途、制作材料、制作/获得方式、使用者/势力、限制/损耗、适用境界/阶段、关联功法/招式、跨模板归属。  
   无可靠原文支撑时写“原文未说明”；不得为了补齐材料、获得方式、境界、品阶或制作方式而自行推断。

8. 输出简化  
   保留能体现武器形制、攻防方式、使用者、装备体系、制作获得、限制损耗和跨模板归属的信息。  
   不长篇复述剧情，不把人物评价、战斗过程、功法效果、建筑细节或非武器奇物塞满字段。

9. 生成后自检  
   检查是否把功法、斗技、建筑、地形、容器、人物、生物、非战斗奇物误当武器；是否漏掉高频核心武器、法器武器和战斗法宝；是否把同一武器拆成多张卡；是否对材料、获得方式、境界做了无支撑推断。

## 字段说明

- 收录判定：写武器、护具、战斗装备、法宝武器、职业器具、训练器具等；不符合准入规则的对象不建卡。
- 名称与别名：写武器主称、别名、外观称呼、使用者称呼、旧称、套装名或同一对象的不同叫法。
- 形制：写剑、刀、枪、矛、戟、斧、锤、棍、鞭、弓、弩、针、爪、盾、甲、尺、鼎、印、钟、环、幡、旗、梭、笔、砚、飞剑、暗器、机关器械、舟船武装等。
- 外观描述：写颜色、尺寸、材质观感、纹饰、光泽、破损状态及其他可辨识的外部特征；无可靠原文支撑时写“原文未说明”。
- 稀有度/品阶：按作品自己的描述填写，如凡兵、制式兵器、职业器具、灵兵、法器、法宝、符宝、古宝、传承武器等；原文未说明则写“原文未说明”。
- 是否法宝/法器：写是、否、原文未说明；如果是，说明作品中的法宝、法器、灵器、符宝、古宝等称法。
- 是否战斗使用：写是、否、原文未说明；职业器具和训练器具应说明主要用途不是直接战斗。
- 功效：写武器本身带来的效果，如攻杀、防御、护身、控制、破甲、破禁、远程狙杀、群攻、镇压神魂、增幅职业能力、辅助训练等。
- 用途：写武器被如何使用，如近战、远程、护身、偷袭、军阵、守城、破防、斗法、炼药、训练、职业作业、宗门制式装备等。
- 制作材料：写具体材料或通用材料规则，如精铁、玄铁、妖兽骨、妖兽筋、鳞甲、灵木、矿石、星辰铁等；不明时写“原文未说明”。
- 制作/获得方式：写武器如何产生或取得，如锻造、炼制、宗门配发、战利品、拍卖、遗迹获得、家族传承、妖兽材料改造、职业器具购买等；不明时写“原文未说明”。
- 使用者/势力：写使用者、职业、势力或适用人群，如散修、宗门弟子、体修、剑修、军队、某家族、某角色；不明时写“原文未说明”。
- 限制/损耗：写修为限制、职业限制、体魄要求、功法配套、消耗、装填、磨损、断裂、修复、升级、重铸、被夺取、被克制等；没有说明时写“原文未说明”。
- 适用境界/阶段：按作品自己的境界或阶段说法填写；没有明确支撑时写“原文未说明”。
- 关联功法/招式：写配套功法、斗技、剑法、刀法、职业技艺或训练方式；没有说明时写“原文未说明”。
- 跨模板归属：写是否同时关联法宝、功法、材料、建筑设施、职业器具、奇物等模板；若应转入其他模板而不在本模板成卡，应在整理原则中排除。
