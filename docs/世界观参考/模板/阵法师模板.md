# 阵法师模板

## 适用范围

本模板用于整理作品中的阵法师职业，以及与阵法职业流程高度相关的禁制师、结界师、传送阵师、护山大阵维护者、洞府禁制布置者、阵旗阵盘制造者、阵眼阵基维护者、破阵者、解禁者和封印阵主持者。

本模板重点分析阵法职业如何运转，包括身份与稀缺性、传承与知识、阵图和布阵法器、材料与环境、选址布阵、启动维护、修复破阵、成本风险、委托收益和职业成长。单独出现的阵法名称，可以作为阵法流程案例收录，但不能替代阵法师职业闭环。

本模板侧重固定或半固定空间结构，以及由阵旗、阵盘等工具展开形成的阵法、禁制、结界、传送、封印和护山防御。独立符箓、符宝和符纸体系放入 `符师模板.md`；灵兽、一般法宝、普通术法、纯机关建筑等内容，除非明确参与阵法结构或职业流程，否则不在本模板展开。

## 整理原则

1. 先区分卡片类型
   本模板内部使用“阵法师职业卡”和“阵法工程／流程卡”两个模块。职业卡分析阵法师怎样形成能力、承接工作、成长和传承；工程卡分析具体阵法怎样被设计、布设、运行、维护、失效和处置。只出现阵法效果时不得推断操作者具有阵法师职业身份。

2. 做准入和边界判定
   可收录明确称为阵法、禁制或结界的固定或半固定空间结构，以及由阵旗、阵盘、阵眼、阵基、阵纹、能量和空间环境共同构成的阵法流程。普通护罩法宝、独立符箓、单次术法、灵兽侦察、纯机关陷阱和一般多人站位，除非明确参与阵法结构或职业流程，否则不建立阵法卡。

3. 按完整职业流程分析阵法师
   阵法师职业按“资质与传承 → 专业分化 → 接受需求 → 勘察设计 → 材料和人员准备 → 布设施工 → 校准交付 → 维护修复 → 收益与风险 → 成长、衰退和传承”整理。职业身份、一次布阵和一件阵法物不能互相替代。

4. 按完整工程流程分析阵法
   阵法工程按“需求 → 原理 → 结构 → 构件 → 环境 → 设计 → 布设 → 校准 → 启动 → 操控 → 监测 → 维护 → 失效 → 处置 → 停用与后续”整理。只写名称和效果，不足以形成完整阵法流程。

5. 区分参与者责任
   需求提出者、设计者、阵器制造者、布设者、主持者、操控者、维护者、修复者和破阵者可能是不同主体。必须分别填写，不得把持有阵盘、启动阵法或执行修复步骤的人自动认定为阵法师。

6. 写清核心原理和内部结构
   不能只列阵旗、阵盘和灵石。应说明阵法通过何种空间、五行、地脉、符纹、人数、血脉或其他机制产生效果，各构件怎样连接，能量怎样流动，控制权限怎样建立，哪些节点是单点故障位置。

7. 区分目标、实际效果和意外影响
   需求与目标写布阵前希望解决什么；实际效果与性能写运行后真正实现了什么；意外影响写没有计划但实际出现的人员、资源、地脉、生态或空间后果。三者不得混写。

8. 区分成本、限制和失效
   成本是成功建造和正常运行也必须支付的材料、能量、时间和人员投入；限制是阵法成立和发挥作用的边界；失效是条件不满足后实际出现的性能下降、局部故障或整体崩溃；极端后果是反噬、封印破裂、空间错乱或环境灾害。

9. 区分正常、异常和极端状态
   正常状态写供能、操控、监测和效果稳定的情况；异常状态写能量不稳、构件损坏、权限失灵、效果偏移和局部中断；极端状态写整体失控、反向控制、传送事故、封印破裂或主持者重创。还要记录应急切断、人员撤离、降级运行、修复和重启条件。

10. 同时观察阵法和环境
    环境不仅是布阵条件，还会被阵法反向改变。应整理地形、建筑、灵脉、地脉、空间、天候和时间怎样影响阵法，以及阵法对资源分布、交通、生态、区域安全和其他势力造成的长期影响。

11. 追踪职业成长和阵法生命周期
    职业层面整理入门、独立工作、复杂工程、创新、专业分化、能力衰退和传承中断；阵法层面整理建成、运行、老化、修复、升级、停用、拆除、迁移、废弃、失传和复燃。没有经历的阶段写“不适用”。

12. 同一对象归并整理
    同一阵法后续出现新的材料、结构、用途、维护、修复、破阵和成本时，补入同一工程卡；不同地点或操作者的独立实施过程可在同卡分项记录。阵法师的作品、委托和失败经历归入同一职业卡，不按每次提及重复建卡。

13. 明确信息与合理归纳的边界
    阵法存在、职业身份、设计者、结构、流程、效果、成本和后果分别判断明确程度。原文直接说明的内容按明确事实填写；由连续过程总结的内容标记为“谨慎归纳”；存在其他解释或无法确认时明确写出，不用类型惯例补齐原理和流程。

14. 输出简化并做自检
    “职业闭环命中项”只作为准入检查，不再作为正文分析字段。完成后检查：职业卡与工程卡是否混用；参与者责任是否区分；是否只写效果而没有原理、结构和流程；目标、实际效果和意外影响是否混淆；成本、限制和失效是否区分；是否遗漏监测、维护、应急处置和后续变化；明确信息与谨慎归纳是否区分。

- 资质、知识结构与传承：师承负责基础阵理和地脉测绘，长期工程经验形成故障诊断能力；核心地脉图只在正式弟子间传授。

### 阵法工程示例：山门复合防护阵

- 卡片类型与边界：工程卡；由阵基、阵眼、警戒子阵、防御子阵、地脉供能和控制令牌共同构成，不是单一护罩法宝。
- 需求、场景与目标：保护山门及内部人员；要求平时低耗警戒，遇袭后快速切换为封锁和防御状态。
- 阵法对象与核心原理：固定复合阵；以地脉持续供能，警戒子阵发现异常后联动防御子阵改变山门空间通行状态。
- 结构拓扑与关键节点：主阵眼负责调度，四处阵基维持边界，警戒和防御子阵可独立降级运行；主阵眼和地脉连接处是主要单点故障位置。
- 运行、操控与监测：平时自动监测身份令牌和边界波动，守阵者可人工提高防御等级；阵基回传能量和损伤状态。
- 正常、异常与极端状态：阵基受损时覆盖范围收缩；主阵眼失控可能误封内部通道；地脉逆流时必须切断供能并疏散阵眼附近人员。
- 维护、修复、升级与停用：定期校验令牌权限和阵基连接，损坏时先转入降级运行再更换构件；永久停用需逐段断开地脉，避免残余能量冲击。

### 修复与破阵示例：失效传送阵

- 卡片类型与边界：阵法工程／修复流程卡；执行者必须先识别结构和目的地条件，不能因照图更换材料就自动认定为原设计者。
- 相关主体与责任分工：委托者提供遗址和旧阵图；阵法师负责诊断与修复方案；材料师重制构件；操控者负责试运行；另一组人员确认目的地阵法状态。
- 阵法对象与核心原理：固定传送阵；通过成对坐标结构建立空间连接，起点修复成功不代表目的地仍然有效。
- 设计、制造、布设与校准：清理阵纹 → 复制现存结构 → 对照旧阵图定位缺损 → 更换材料 → 低功率供能 → 校准坐标 → 先以无生命物测试。
- 识阵、破阵与反制：修复前先排除被篡改阵纹和诱导坐标；发现异常时隔离控制节点，不直接强行启动。
- 正常、异常与极端状态：能量不稳表现为坐标漂移；局部错误可能导致物品损毁；整体误连可能造成失踪、空间撕裂或反向入侵。
- 成本、限制与后续影响：依赖完整坐标、空间材料、有效目的地和持续供能；废弃前需破坏坐标信息，避免被外部主体重新利用。
