# 阵法师模板

## 适用范围

用于整理作品中的阵法师职业，以及与阵法流程高度相关的禁制师、结界师、护山大阵维护者、传送阵建造者、洞府禁制布置者、阵图阵盘制造者、阵眼阵基维护者、破阵者、解禁者、封印阵主持者等内容。

本模板重点不是单独收集某个阵法名称；具体秘境禁制、洞府机关、建筑设施和地图场所可以在对应专题继续展开。本模板重点分析“玩家如果选择阵法师职业，这个职业在小说世界里如何运转”：从获取阵图或阵法传承、准备阵旗阵盘和阵基材料、勘察地形地脉、布置阵眼、刻画阵纹、嵌入灵石或灵脉、启动维护、改阵破阵、失控反噬、售卖委托到职业成长的完整闭环。

本模板不负责分析独立符箓、符宝和符纸体系；可携带、可预制、可消耗的术式载体放入 `符师模板.md`。本模板侧重固定或半固定空间结构中的阵法、禁制、结界、传送、封印、护山防御、洞府保护、秘境入口和战斗场地布置。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

本文只整理小说中出现过，或能由小说内容明确支撑的阵法师职业、布阵流程、职业分支、阵图传承、工具设施、布阵环境、操作手法、特殊手段、收益方式和失败后果，不编造小说中不存在的职业体系。

整理时应按职业分支、布阵环节、阵法用途和适用境界尽可能覆盖完整：每一种职业分工、每一类阵法用途、每一个境界阶段，只要小说中有对应内容，都应尽量写入对应段落。文档长度不设上限，宁可写长，也不要为了压缩篇幅遗漏有参考价值的职业样本、流程细节和失败案例。

如果某类职业分支、某个境界阶段，或输入资源、阵图来源、工具设施、布阵环境、操作手法、特殊手段、运行结果、限制/失败后果等字段在小说中没有可靠依据，可以写“原文未说明”；不得为了补齐职业等级、境界梯度、布阵流程或数值体系而自行虚构。

## 必须写什么

整理时必须覆盖阵法师职业定位、分支、处理对象、输入资源、阵图/阵法传承来源、工具/设施、布阵环境、操作者门槛、布阵流程、阵眼/阵基/阵旗/阵盘、符文/阵纹/禁制使用、不同境界的操作手法和特殊手段、运行结果、产出/效果、维护/改阵/破阵、时间成本、限制/失败后果、收益方式、来源/场景和适用境界。特殊案例要写清使用者、使用场景、前置条件、具体过程、效果、代价、限制和可参考点。

## 案例

### 案例

#### 特殊手段案例

- **案例名称和类型**：如护山大阵、传送阵、阵中阵、地脉大阵、临战改阵、破阵反制。
- **使用者**：写清人物、身份、境界、阵法水平和所属势力。
- **使用场景**：写清是在宗门防御、洞府保护、秘境入口、战场攻防、传送赶路、封印镇压、追杀围困还是破阵逃生中使用。
- **前置条件**：写清需要的阵图、阵旗、阵盘、阵眼、阵基、灵石、地脉、灵脉、空间材料、主持者、护法、时间或特殊地形。
- **具体过程**：详细写清如何选址、埋阵基、立阵眼、布阵旗、连接地脉、启动阵法、维持阵法、改阵或破阵，不要只写“布下大阵”。
- **产出或效果**：写清防御、困敌、杀伐、幻术、传送、封印、聚灵、侦测、隐匿等效果，以及与普通阵法的差异。
- **代价与风险**：写清灵石消耗、阵基损毁、阵眼暴露、误传送、封印破裂、阵法反噬、主持者受伤、地脉受损、被敌人反控等后果。
- **限制**：写清是否只有本人能用，是否依赖地形、阵图、空间坐标、灵脉、阵盘、主持者境界、多人协作或长期维护。
- **可参考点**：写清该案例对职业体系的参考价值，例如宗门防御、地图通行、秘境门槛、战斗场地效果、长期维护成本、破阵任务和 NPC 职业稀缺性。
