# 阵法师模板

# 规范

本模板用于整理作品中的阵法师职业，以及与阵法流程高度相关的禁制师、结界师、护山大阵维护者、传送阵建造者、洞府禁制布置者、阵图阵盘制造者、阵眼阵基维护者、破阵者、解禁者和封印阵主持者。

本模板重点不是单独收集阵法名称，而是分析阵法师职业在小说世界里如何运转：获取阵图或传承、准备阵旗阵盘和阵基材料、勘察地形地脉、布置阵眼、刻画阵纹、嵌入灵石或灵脉、启动维护、改阵破阵、失控反噬、售卖委托和职业成长。

独立符箓、符宝和符纸体系放入 `符师模板.md`。本模板侧重固定或半固定空间结构中的阵法、禁制、结界、传送、封印、护山防御、洞府保护、秘境入口和战斗场地布置。具体秘境禁制、洞府机关、建筑设施和地图场所，可在对应专题继续展开；本文只记录与阵法师职业闭环相关的内容。

样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、顶级阵法或成功案例。只整理原文有可靠依据的阵法师职业、布阵流程、职业分支、阵图传承、工具设施、环境、操作手法、收益方式和失败后果。原文未说明的内容写“原文未说明”，不要为了补齐职业等级、境界梯度、布阵流程或数值体系而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 职业定位：写阵法师、禁制师、结界师、传送阵师、破阵者、护山大阵维护者、封印主持者、阵图阵盘制造者等身份。
- 职业分支：写洞府禁制布置、护山大阵维护、传送阵建造、阵眼阵基维护、解禁、封印阵主持、临战布阵、阵盘阵旗制作等方向。
- 处理对象：写护山大阵、洞府禁制、秘境入口、传送阵、封印阵、杀阵、困阵、幻阵、聚灵阵、侦测阵、隐匿阵、阵中阵等对象。
- 输入资源：写阵图、阵旗、阵盘、阵基、阵眼、灵石、地脉、灵脉、空间材料、符文阵纹、主持者、护法、时间和特殊地形等资源。
- 能力门槛：写境界、神识、阵法传承、职业经验、势力权限、多人协作、地形判断、材料处理和稳定维护能力等门槛。
- 操作流程：写选址、勘察、埋阵基、立阵眼、布阵旗、刻阵纹、连接地脉、嵌入灵石、启动、维持、改阵、破阵、收阵等流程。
- 运行结果：写防御、困敌、杀伐、幻术、传送、封印、聚灵、侦测、隐匿、镇压、隔绝、牵引或改变战场等结果。
- 成本与风险：写灵石消耗、材料损毁、阵眼暴露、误传送、封印破裂、阵法反噬、主持者受伤、地脉受损、被敌人反控等成本和风险。
- 收益方式：写宗门职位、洞府委托、护山维护、传送收费、破阵报酬、阵盘售卖、战斗支援、秘境门槛和长期职业稀缺性等收益。

### 传送阵建造

- 案例类型：传送阵、空间阵法、地图通行
- 使用者：传送阵师、阵法师或掌握空间阵法的修士，按作品设定填写
- 使用场景：远距离赶路、宗门交通、坊市往来、秘境入口或战时撤离
- 前置条件：阵图、阵盘或阵基、空间材料、灵石、坐标、阵纹和主持者
- 具体过程：确定坐标，布置阵基，刻画阵纹，嵌入灵石，校验空间通道并启动传送
- 产出或效果：远距离移动、跨区域通行、快速支援或进入特殊地点
- 代价与风险：灵石消耗、误传送、空间波动、阵纹损坏、坐标错误或被敌人截断
- 限制：依赖空间坐标、材料品质、阵图完整度、主持者能力和目的地条件
- 可参考点：地图通行规则、势力交通网络、收费方式、空间材料消耗和职业门槛

### 破阵反制

- 案例类型：破阵、解禁、临战反制
- 使用者：破阵者、解禁者或精通阵法弱点的修士，按作品设定填写
- 使用场景：秘境探索、洞府闯入、战场脱困、追杀反围或破解封锁
- 前置条件：神识探查、阵法经验、破阵工具、阵图线索、地形判断和足够时间
- 具体过程：观察阵纹走向，寻找阵眼或薄弱处，扰乱阵基，切断灵力流转，解除或反控阵法
- 产出或效果：打开通路、解除禁制、削弱敌方阵法、反困敌人或夺取阵法控制权
- 代价与风险：触发杀阵、阵法反噬、暴露位置、工具损毁、误判阵眼或被敌人反控
- 限制：依赖阵法知识、神识强度、时间窗口、阵法复杂度和敌方干扰
- 可参考点：秘境门槛、职业对抗、战斗场地变化、解禁任务和阵法体系深度
