# 阵法师模板

## 适用范围

本模板用于整理作品中的阵法师职业，以及与阵法流程高度相关的禁制师、结界师、护山大阵维护者、传送阵建造者、洞府禁制布置者、阵图阵盘制造者、阵眼阵基维护者、破阵者、解禁者和封印阵主持者。

本模板重点不是单独收集阵法名称，而是分析阵法师职业在小说世界里如何运转：获取阵图或传承、准备阵旗阵盘和阵基材料、勘察地形地脉、布置阵眼、刻画阵纹、嵌入灵石或灵脉、启动维护、改阵破阵、失控反噬、售卖委托和职业成长。

独立符箓、符宝和符纸体系放入 `符师模板.md`。本模板侧重固定或半固定空间结构中的阵法、禁制、结界、传送、封印、护山防御、洞府保护、秘境入口和战斗场地布置。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、顶级阵法或成功案例。
- 只整理原文有可靠依据的阵法师职业、布阵流程、职业分支、阵图传承、工具设施、环境、操作手法、收益方式和失败后果。
- 原文未说明的职业等级、境界梯度、输入资源、阵图来源、工具设施、布阵环境、操作手法、运行结果、限制或失败后果，写“原文未说明”。
- 具体秘境禁制、洞府机关、建筑设施和地图场所，可在对应专题继续展开；本文只记录与阵法师职业闭环相关的内容。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **职业定位**：阵法师、禁制师、结界师、传送阵师、破阵者、护山大阵维护者、封印主持者、阵图阵盘制造者。
- **处理对象**：护山大阵、洞府禁制、秘境入口、传送阵、封印阵、杀阵、困阵、幻阵、聚灵阵、侦测阵、隐匿阵、阵中阵。
- **输入资源**：阵图、阵旗、阵盘、阵基、阵眼、灵石、地脉、灵脉、空间材料、符文阵纹、主持者、护法、时间和特殊地形。
- **能力门槛**：境界、神识、阵法传承、职业经验、势力权限、多人协作、地形判断、材料处理和稳定维护能力。
- **操作流程**：选址、勘察、埋阵基、立阵眼、布阵旗、刻阵纹、连接地脉、嵌入灵石、启动、维持、改阵、破阵、收阵。
- **运行结果**：防御、困敌、杀伐、幻术、传送、封印、聚灵、侦测、隐匿、镇压、隔绝、牵引或改变战场。
- **成本与风险**：灵石消耗、材料损毁、阵眼暴露、误传送、封印破裂、阵法反噬、主持者受伤、地脉受损、被敌人反控。
- **收益方式**：宗门职位、洞府委托、护山维护、传送收费、破阵报酬、阵盘售卖、战斗支援、秘境门槛和长期职业稀缺性。

## 案例

### 案例

| 案例类型 | 示例 | 重点 |
| --- | --- | --- |
| 护山与驻地防御 | 护山大阵、家族守阵、洞府防护 | 长期维护、阵眼阵基、资源消耗、失守后果 |
| 传送与空间阵法 | 传送阵、跨域阵、秘境入口阵 | 坐标、空间材料、误传送、通行门槛 |
| 战斗与围困阵法 | 杀阵、困阵、幻阵、阵中阵、临战改阵 | 布置时机、主持者风险、破阵反制 |
| 封印与镇压阵法 | 封印阵、镇压地脉、镇魔阵 | 长期稳定、封印破裂、主持者代价 |
| 破阵与解禁 | 洞府禁制、秘境机关、敌方阵法 | 识阵、试探、消耗、失败反噬、可参考手法 |

**特殊手段案例卡片：**

- **案例名称和类型**：如护山大阵、传送阵、阵中阵、地脉大阵、临战改阵、破阵反制。
- **使用者**：写清人物、身份、境界、阵法水平和所属势力。
- **使用场景**：写清宗门防御、洞府保护、秘境入口、战场攻防、传送赶路、封印镇压、追杀围困或破阵逃生。
- **前置条件**：写清阵图、阵旗、阵盘、阵眼、阵基、灵石、地脉、灵脉、空间材料、主持者、护法、时间或特殊地形。
- **具体过程**：写清选址、埋阵基、立阵眼、布阵旗、连接地脉、启动、维持、改阵或破阵；不要只写“布下大阵”。
- **产出或效果**：写清防御、困敌、杀伐、幻术、传送、封印、聚灵、侦测、隐匿等效果，以及与普通阵法的差异。
- **代价与风险**：写清灵石消耗、阵基损毁、阵眼暴露、误传送、封印破裂、阵法反噬、主持者受伤、地脉受损或被敌人反控。
- **限制**：写清是否依赖本人、地形、阵图、空间坐标、灵脉、阵盘、主持者境界、多人协作或长期维护。
- **可参考点**：写清该案例对职业体系的参考价值，例如宗门防御、地图通行、秘境门槛、战斗场地效果、维护成本、破阵任务和职业稀缺性。
