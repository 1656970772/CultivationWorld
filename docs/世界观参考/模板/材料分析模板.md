# 材料分析模板

## 适用范围

用于整理作品中出现过的材料、资源与产出源，包括灵石、灵脉、灵药、灵果、矿石、妖兽材料、妖丹、精血、骨骼、鳞甲、灵液、异火、空间材料、星辰材料、特殊天材地宝等。

本模板只做材料分析，不分析丹药成品、法宝成品、符箓成品、功法秘籍、装备、储物袋、飞舟等完整物品。这些成品只在“用途”中作为材料下游去向出现。

## 前置声明

- 只整理原文出现过，或能由资料来源明确支撑的材料、资源与产出源，不编造材料。
- 样本要按材料分类和适用境界尽量覆盖；原文有对应素材就列入。
- 原文没有可靠依据的分类、境界梯度、效果或数值，不为补齐结构而虚构。
- 信息不足但值得追踪的对象放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法要求 |
|------|----------|
| 材料名称 | 写小说中的材料名、资源名或产出源名称。 |
| 稀有度 | 按作品自己的描述填写，如最低级、较常见、稀有、非常稀有、传说级等。 |
| 效果 | 写材料本身效果，如增加真气、回复气血、延寿、强化肉身、提升炼器品质、产出灵石等。 |
| 用途 | 写材料如何被使用，如修炼、炼丹、炼器、布阵、交易、宗门资源、妖兽修炼等。 |
| 来源 | 写材料从哪里来，如矿脉、山脉、秘境、妖兽体内、天地凝聚、星辰坠落、宗门药园等。 |
| 适用境界 | 按作品自己的境界说法填写；原文未说明时写“原文未说明”。 |

可补充字段：采集条件、保存方式、加工方式、替代材料、使用风险、争夺事件、下游成品。没有可靠依据时不要补。
