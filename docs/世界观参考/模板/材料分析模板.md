# 材料分析模板

## 适用范围

本模板用于整理作品中明确出现的原料、基础资源、产出源、天然精华和非场景型天地奇物。按对象的存在形态、来源和使用方式，统一分为六类：

1. 灵植与药材：灵植、灵药、灵草、灵花、灵果、灵藤、灵木、菌类药材及其可采部位。
2. 矿物与炼器材料：矿石、金属、玉石、晶体、宝砂、实体空间材料、星辰材料和其他可加工固体材料。
3. 生灵与妖兽材料：妖丹、魔核、血液、精血、血池内可独立取用的血液精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶及其他来自生灵的原料。
4. 灵能资源与产出源：灵石、灵晶、灵髓、灵贝等可携带资源，以及灵脉、灵眼、矿脉、贝场和能够持续产出或汇聚资源的固定灵池、血池、灵液池等资源节点。
5. 天然灵液与精华：作为原料或天然资源存在的灵液、真露、灵泉原液、灵液池内可独立取用的原液、玉液、毒液、分泌物和天地凝露。
6. 天地奇物与有灵异质：独立存在且不是场景本体的异火、神雷、可收取或封印的雷池、血池、灵液池、邪祟之物、有灵异质和其他可捕获、炼化、控制或利用的天地奇物。

本模板不分析丹药成品、法宝成品、符箓成品、功法秘籍、装备、饰品、容器、检测工具、普通建筑、组织、身份、资质、技能和秘术。下游成品只在“用途”中出现；完整内容放入对应专题模板。

## 整理原则

1. 先分类，再建卡  
   每个对象先判断是否符合材料、基础资源、产出源、天然精华或非场景型天地奇物的准入条件，再从六类卡片中选择一类。不得用同一对象重复建立多类卡片；跨领域用途写入主卡的用途或关联字段。

2. 按存在形态确定主类  
   灵果属于灵植与药材；妖丹、精血、骨骼和鳞甲属于生灵与妖兽材料；灵石属于可携带灵能资源，灵脉属于产出源；实体空间晶石、星辰铁等归矿物与炼器材料；独立异火、神雷、雷池或邪祟异质归天地奇物与有灵异质。

3. 区分原料、成品和产出源  
   原料可被采集、消耗、加工或作为下游投入；成品已经具备完整用途和使用结构；产出源可持续或周期性地产出资源。灵果树与灵果、灵脉与灵石、妖兽与妖兽材料可以分别建立对应专题或卡片，但应通过来源和产出关系关联。

4. 池体与内容物分层整理  
   血池、灵液池、雷池等对象先区分“池中内容物”和“池本体”。池中精血、血液精华归生灵与妖兽材料；池中天然灵液或原液归天然灵液与精华。固定池体若持续产出或汇聚资源，归灵能资源与产出源；若重点是地点、建筑、阵法或修炼环境，转入秘境、场所、建筑或阵法模板；若整个池体可移动、收取、封印、认主、寄生或具有灵智，归天地奇物与有灵异质。内容物与池本体均有独立名称和机制时可以分别建卡，并通过产出、储存或寄生关系关联。

5. 一物一卡，派生物按独立性处理  
   同名、别名、同物异名、不同年份、品阶、纯度、属性和阶段用途归入同一卡。若加工或凝聚后形成有独立名称、性质和用途的新资源，可另建派生物卡，并在来源字段中连接原材料。

6. 使用对应类别的完整字段  
   每张卡只使用所属类别的字段，并保持字段完整。没有可靠内容时写“原文未说明”；本次整理范围不足时写“本次未覆盖到明确内容”；确实不适用时写“不适用”。不得用同类小说常识或使用者当前境界补齐材料设定。

7. 同类差异在卡内展开  
   年份、成熟度、品阶、纯度、大小、属性、来源物种、来源境界、能量浓度、灵性阶段等差异写入同一张卡的相应字段。差异会改变效果、用途、采集条件或风险时，在相关字段中分别描述。

8. 明确灵液与丹药边界  
   天然形成、作为原料采集或尚未成为命名药物的灵液归本模板。经过炼制、配伍或加工，能够直接服用、外用并作为完整药物产生疗伤、突破、解毒或毒杀效果的药液、真露和灵液，归入 `丹药分析模板.md`。

9. 明确有灵奇物与场景、生灵、法宝边界  
   固定存在并以地形、环境或区域规则为核心的火域、雷域、天然雷池和邪地，归入秘境、场所或世界环境类模板。可脱离地点独立存在、能够移动、收取、封印、认主、寄生、炼化或控制的异火、神雷、雷池和邪祟异质，归入第六类。具备稳定物种、生理结构和完整生物行为的对象归妖兽或人物；被人为炼成完整器物的对象归法宝。

10. 保留材料链条，不展开下游成品  
   记录采集、开采、提纯、保存、交易、消耗和加工损耗，以及材料对炼丹、炼器、布阵、修炼或势力资源的作用。下游丹药、武器、法宝和阵法只作为用途或产出去向，不在本卡中展开完整效果。

11. 输出前自检  
    检查六类归属是否唯一、成品是否误收、产出源与产出物是否混为一物、池中内容物与池本体是否正确分层、同名材料是否重复建卡、灵液是否与丹药重叠、异火神雷雷池是否满足非场景判定、妖兽材料是否写清来源，以及案例区是否只包含实际输出字段和示例内容。

## 字段说明

### 灵植与药材卡片字段

- 子类：填写灵植、灵药、灵草、灵花、灵果、灵藤、灵木、菌类药材或可采部位等。
- 准入理由：说明对象为何属于可生长、采摘、培育或入药的植物性材料。
- 生物形态/外观：填写植株、根、茎、叶、花、果、种子、菌体的形态、颜色、气味和显著特征。
- 生长环境：填写灵田、药园、山脉、秘境、洞府、寒地、火域、水泽等环境条件。
- 生长与成熟周期：填写发芽、生长、开花、结果、成熟、休眠和再次产出的周期。
- 年份/品阶/成熟度：填写药龄、年份、品阶、成熟或未成熟、枯萎和变异状态。
- 可用部位/采收产量：填写根、茎、叶、花、果、种子、汁液等可用部位，以及单株或单次产出。
- 培育/催熟/移植：填写种植、催熟、嫁接、移植、灵气供养、阵法培育和失败条件。
- 采摘与初步处理：填写采摘时机、工具、禁忌、去杂、晾晒、切分和药性保护。
- 保存与药性流失：填写保存容器、温度、灵气、封禁要求，以及枯萎、腐坏和药性衰减。
- 核心特性/效果：填写药性、灵气属性、疗伤、淬体、延寿、毒性或其他材料特性。
- 用途/下游去向：填写炼丹、配药、制毒、直接食用、培育、交易或任务用途。
- 限制/毒性：填写误食、相克、成熟度不足、采摘损伤、体质要求和其他风险。
- 稀有度：按作品自身描述填写。
- 适用境界/阶段：填写明确适用的修炼阶段；不明时写“原文未说明”。
- 别名/同物异名：填写俗称、不同地域叫法和同物异名。

### 矿物与炼器材料卡片字段

- 子类：填写矿石、金属、玉石、晶体、宝砂、空间材料、星辰材料或其他固体材料。
- 准入理由：说明对象为何可以开采、提纯、熔炼、雕琢或作为炼器、布阵材料。
- 形态/外观：填写矿块、金属、玉料、晶体、粉末、砂粒等形态与颜色、光泽、纹理。
- 物理性质：填写硬度、韧性、密度、延展性、脆性、耐热、导能和稳定性。
- 能量属性/相性：填写五行、雷、空间、星辰、阴阳等属性，以及与其他材料的相容或冲突。
- 纯度/品阶/规格：填写原矿或精炼态、纯度、品阶、大小、重量和可用比例。
- 产地/形成方式：填写矿脉、地层、星辰坠落、空间凝结、秘境生成和其他形成条件。
- 开采/取得条件：填写采矿工具、修为、环境危险、禁制、所有权和开采成本。
- 提纯/精炼方式：填写去杂、熔炼、锻打、阵法提纯、切割、研磨和特殊处理。
- 加工损耗/废料：填写提纯损耗、灵性流失、废渣、裂损、失败后降品和回收方式。
- 材料相容/替代关系：填写可搭配材料、冲突材料、替代品和替材造成的品质变化。
- 核心特性/效果：填写坚硬、聚灵、导能、稳定空间、承载阵纹或强化成品等作用。
- 用途/下游去向：填写炼器、布阵、建筑、修复、货币、交易和其他用途。
- 稀有度：按作品自身描述填写。
- 适用境界/阶段：填写明确适用的炼器或修炼阶段。
- 别名/同物异名：填写俗称、矿名、精炼后名称和地域叫法。

### 生灵与妖兽材料卡片字段

- 子类：填写妖丹、魔核、血液、精血、血池精华、骨骼、鳞甲、皮毛、角、筋、兽牙、毒囊、魂晶或其他生灵材料。
- 准入理由：说明对象为何是从妖兽、生灵或特殊血脉个体取得的可用原料。
- 来源物种/个体：填写来源妖兽、灵兽、魔兽、真灵、修士或其他生灵。
- 来源部位/存在形态：填写体内核心、血液、池中汇聚的血液精华、骨、鳞、皮、角、筋、囊、结晶或魂体残留。
- 来源境界/血脉：填写来源对象的境界、阶位、血脉、变异和成熟阶段。
- 外观描述：填写颜色、大小、质地、气味、纹理、灵光和完整度。
- 完整度/鲜度/活性：填写完整、破损、鲜活、凝固、干枯、失活、污染和保存时间。
- 取得条件：填写猎杀、自然脱落、蜕皮、取血、抽取、交易、遗骸发现和取得风险。
- 残余能量/意志/毒性：填写妖力、血脉力量、残魂、怨念、狂暴能量、毒素和排异。
- 净化/处理/保存：填写放血、去毒、炼化、封魂、冷藏、封禁、分割和防止灵性流失的方法。
- 直接使用条件：填写吞服、炼化、移植、沐浴或其他直接使用方式及其限制。
- 核心特性/效果：填写补充能量、淬体、强化血脉、承载能力、毒性和其他作用。
- 用途/下游去向：填写炼丹、炼器、制符、布阵、血祭、修炼、交易和任务用途。
- 限制/风险：填写余毒、血脉冲突、残魂反噬、污染、保存失败和势力追责。
- 稀有度：按来源物种与作品描述填写。
- 规格/品质/等级：填写阶位、血脉纯度、部位品质、完整度和数量。
- 适用境界/阶段：填写明确适用的修炼或加工阶段。
- 别名/同物异名：填写妖丹/内丹、魔核/魔晶等同物异名。

### 灵能资源与产出源卡片字段

- 子类/资源形态：填写可携带能源货币、修炼资源、矿脉、灵脉、灵眼、贝场、固定灵池、固定血池、固定灵液池或其他汇聚与产出节点。
- 准入理由：说明对象为何是可消耗灵能资源、货币，或能持续产出资源的源头。
- 形态/外观：填写晶石、贝珠、灵髓、矿层、脉络、泉眼或能量节点等形态。
- 能量属性/纯度：填写灵气、魔气、星力等属性，以及纯度、稳定度和杂质。
- 单位/品阶/规格：填写上中下品、块、枚、斤、储量等级、矿脉规模和其他计量。
- 产地/形成方式：填写天地凝聚、矿脉生成、生灵产出、宗门培育和其他来源。
- 储量/规模：填写单体含量、矿藏储量、灵脉覆盖范围和可支持人数。
- 产出/再生/枯竭：填写产出物、产出周期、恢复条件、开采速度、衰退和枯竭后果。
- 开采/采集/使用方式：填写挖掘、抽取、切割、炼化、布阵引流和直接消耗方式。
- 所有权/控制方式：填写宗门、家族、城池、个人或无主状态，以及争夺、租用和封锁。
- 货币/兑换属性：填写是否充当通货、计价单位、兑换比例、品阶折算和流通限制。
- 环境与修炼影响：填写对灵气浓度、修炼速度、宗门选址、生态和秘境稳定的影响。
- 核心效果：填写补充能量、驱动阵法法宝、提升环境或持续产出资源等作用。
- 用途/下游去向：填写修炼、交易、炼丹、炼器、布阵、宗门供给和战争消耗。
- 限制/风险：填写枯竭、污染、过度开采、品阶下降、争夺和依赖风险。
- 稀有度：按作品自身描述填写。
- 适用境界/阶段：填写明确适用的修炼和势力阶段。
- 别名/同物异名：填写不同地域、品阶体系和货币体系中的别名。

### 天然灵液与精华卡片字段

- 子类：填写天然灵液、真露、灵泉原液、灵液池原液、玉液、毒液、分泌物、天地凝露或其他液态精华。
- 准入理由：说明对象为何是天然形成或作为原料采集的液态资源，而不是已经完成配伍和炼制的药物成品。
- 形态/外观：填写液态、黏稠、雾化、凝露等状态，以及颜色、光泽、气味和沉淀。
- 来源/形成方式：填写灵泉、灵植、妖兽、矿脉、天地异象、秘境和自然凝聚过程。
- 浓度/纯度/品阶：填写浓度、纯度、杂质、稀释状态、品阶和批次差异。
- 容量/剂量/计量：填写滴、瓶、池、斤、份或其他数量单位，以及单次使用量。
- 直接使用方式/效果：填写服用、外敷、浸泡、淬洗、灌注等直接使用方式和效果。
- 原料用途：填写炼丹、炼器淬火、制符、布阵、培育灵植和调和其他材料。
- 稀释/混合/反应：填写与水、药材、血液、矿物或其他灵液混合后的变化。
- 容器/保存条件：填写玉瓶、葫芦、池体、封禁、温度和灵气环境等要求。
- 挥发/变质/污染：填写药性或灵性流失、沉淀、腐坏、泄漏、污染和失效条件。
- 核心特性/效果：填写补充能量、洗髓、催生、淬炼、解毒、腐蚀或其他天然作用。
- 限制/毒性：填写剂量、体质、境界、直接服用风险和相克反应。
- 用途/下游去向：填写原料、修炼、培育、交易、任务和其他用途。
- 稀有度：按作品自身描述填写。
- 规格/品质/等级：填写品阶、纯度、浓度、容量和来源等级。
- 适用境界/阶段：填写明确适用的修炼或加工阶段。
- 别名/同物异名：填写真露、玉液、灵泉液等作品内别名。

### 天地奇物与有灵异质卡片字段

- 子类：填写异火、神雷、独立雷池、可移动或有灵的独立血池与灵液池、邪祟之物、有灵异质或其他非场景型天地奇物。
- 准入理由：说明对象为何能独立存在并作为可捕获、封印、炼化、控制或利用的特殊资源收录。
- 独立性/非场景判定：填写是否可脱离原地点存在，是否可移动、收取、封印、认主、寄生或随持有者转移。
- 存在形态/外观：填写火焰、雷霆、雷池、雾气、晶核、灵胎、影状物或其他形态和视觉特征。
- 伴生异象：填写温度、雷鸣、光色、天象、腐蚀、幻觉、阴气、空间扭曲和其他外显现象。
- 灵性/意识：填写无意识、本能、初生灵智、完整意识、性情、趋利避害和交流能力。
- 核心属性/规则：填写火、雷、阴邪、空间、星辰、腐蚀、吞噬等属性及其运行规则。

- 活动/影响范围：填写静止、游移、寄生、追逐目标、影响半径和离开载体后的变化。

- 载体/容器/寄主：填写火种、雷种、雷池核心、封印器、肉身、魂体或其他承载对象。
- 成长/融合/分裂：填写吞噬、融合、蜕变、灵智成长、分火、分雷、污染扩散和退化。
- 核心效果：填写炼丹炼器、战斗、淬体、破禁、净化、污染、夺舍、侵蚀和其他作用。
- 用途/下游去向：填写职业火源、炼体资源、法宝驱动、阵法核心、战斗手段、封印研究和交易。
- 反噬/污染/邪异性：填写灼伤、雷劫反噬、灵智反抗、寄生、污染、心智侵蚀、失控和扩散。
