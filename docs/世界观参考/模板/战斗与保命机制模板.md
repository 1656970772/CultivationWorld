# 战斗与保命机制模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的战斗、追击、逃生、隐匿、防御、控制、治疗、临战增幅、替死和战后损伤等机制，以及能够体现这些机制如何运作的独立事件。

本模板既记录单场事件中的行动链，也归纳可重复使用或由作品明确说明的稳定机制。普通交易、技能传授、资源获取、人物玩笑、单纯的能力背景和没有现实危险的日常冲突，不单独作为战斗与保命事件；只有它们直接呈现触发条件、效果、消耗、限制、克制或实际保命结果时才可收录。

法术、功法、法宝、符箓、丹药、阵法、毒物、傀儡、灵宠和特殊体质等对象，只整理其在战斗与保命中的实际作用，不展开为对应对象的完整分析。

## 整理原则

1. 先区分稳定机制与具体事件
   机制总览回答“这种手段通常怎样工作”，事件卡回答“它在本次危险中怎样实际运行”。单次成功只能说明本次有效；只有多次独立复现或作品明确说明通用规则时，才可提升为稳定机制。

2. 先做准入和边界判定
   可收录真实战斗、追杀、伏击、逃遁、隐匿、护主、替死、急救、战后疗伤，以及能够明确展示威力、消耗、限制或失败风险的训练与测试。普通交易、技能传授、能力背景和没有现实危险的日常冲突，不单独建立事件卡。

3. 把机制视为完整生存系统
   分析顺序为“来源与构成 → 适用威胁 → 触发与控制 → 运作与性能 → 协同与备用 → 消耗、限制和克制 → 异常失效 → 恢复和后续变化”。不能只写招式名称和表面效果。

4. 把事件视为连续状态变化
   事件按“目标与风险 → 开始前状态和信息 → 威胁识别 → 决策和先手 → 关键阶段交互 → 资源和伤势变化 → 备用机制切换 → 结束追击 → 战后恢复”整理。阶段数量按实际情况增减，不强制一至三个轮次。

5. 区分参与方和环境
   主要观察主体、敌方、队友、保护对象、第三方、援军和环境威胁分别填写。治疗、训练、灾害和多人混战不能强行套用“敌方先行动、主体再抵抗”的二元结构。

6. 记录信息、判断和决策阈值
   不只写使用了什么，还要写主体当时知道什么、误判什么、为什么在此时触发机制、为何没有采用其他方案，以及哪些信息改变了后续选择。

7. 同时追踪空间、节奏和状态
   关键阶段记录位置、距离、地形、掩体、阵法边界、主动权、行动节奏、资源、伤势和控制状态。只有真正改变威胁、选择或结果的变化才保留，不逐动作复述剧情。

8. 区分目标、实际效果和意外影响
   战术或保命目标写主体想实现什么；实际效果写机制本次真正做到什么；意外影响写对队友、第三方、环境和后续局势造成的非计划结果。训练目标和测试结果不得直接等同于实战效果。

9. 区分消耗、限制、克制和失效
   消耗是成功使用也必须支付的资源或损伤；限制是距离、时间、境界、环境和次数等性能边界；克制是敌方或环境主动使其受限的方法；失效是机制实际怎样从性能下降转为局部或整体失败。

10. 区分正常、异常和极端状态
    正常状态写机制或战斗按预期运行；异常状态写性能下降、控制中断、判断失误、伤势恶化或备用层失效；极端状态写彻底失控、永久损伤、替死失败、无法脱离或死亡。还要记录应急切换、援救、恢复和不可逆结果。

11. 写清组合机制和生存层级
    单一护盾、遁术或治疗不等于完整保命体系。应整理预警、常规防御、减伤、解控、脱离、替死、外援和战后稳定之间的前后关系，以及上一层失败后怎样切换下一层。

12. 追踪机制成长和衰退
    同一机制后续出现熟练度提升、境界增强、升级变体、新协同、新克制、能力受损、淘汰或丢失时，补入同一总览。不同事件保留各自行动链，不建立“后期版”“补充版”等重复条目。

13. 明确信息与合理归纳的边界
    原文直接说明的内容按明确事实填写；由多个稳定表现总结的内容标记为“谨慎归纳”；存在其他合理解释时明确列出；原文未说明的空间、动机、能力和结果不补写。一次表现能够支持的结论必须保持最小范围。

14. 输出简化并做自检
    完成后检查：机制总览与事件卡是否混淆；是否遗漏来源、构成、决策、协同和备用层级；参与方和环境是否完整；训练与实战是否混淆；关键阶段是否写清机制交互和状态变化；消耗、限制、克制和失效是否区分；正常、异常和极端状态是否区分；战后恢复和长期变化是否遗漏；明确信息与谨慎归纳是否区分。
## 字段说明

### 机制总览字段

- 分类与机制层级：确定机制的主要功能和可泛化程度。
  - 主要分类：写攻击、防御、控制、追击、逃生、隐匿、治疗、替死、临战增幅、战后恢复等。
  - 次要分类：存在稳定次要功能时填写；没有则写“不适用”。
  - 机制层级：填写单次案例、多次复现或明确设定。
  - 收录边界：说明为什么属于战斗或保命机制，以及不应扩展到哪些相邻能力。
- 机制定位、来源与内部构成：说明机制在战术或生存体系中的作用。
  - 主要战术或保命角色：
  - 能力来源：
  - 力量载体：
  - 核心组成：
  - 各部分协同：
  - 依赖的外部资源或主体：
- 威胁模型与适用边界：写机制主要解决什么危险以及适用范围。
  - 主要应对威胁：
  - 适用主体：
  - 适用目标：
  - 适用战斗阶段：
  - 有效距离和空间：
  - 适用环境：
  - 不适用情况：
- 触发、决策与控制：写机制怎样被调用以及为什么在此时使用。
  - 主动或被动触发：
  - 触发阈值：
  - 前置准备：
  - 判断依据：
  - 操作和控制方式：
  - 是否可以取消：
  - 被打断后的状态：
- 运作阶段与状态转换：按机制自身的运行过程整理。
  - 调用或蓄力：
  - 生效过程：
  - 持续和维持：
  - 效果衰减：
  - 正常结束：
  - 中断或切换：
  - 使用后恢复：
- 实际效果与性能：写机制实际能够达到的稳定表现。
  - 主要效果：
  - 次要效果：
  - 作用范围：
  - 响应速度：
  - 持续时间：
  - 强度或承载量：
  - 可靠性：
  - 可观察特征：
  - 意外影响：
- 协同、冲突与备用层级：写机制在完整战术或保命链中的位置。
  - 前置机制：
  - 后续机制：
  - 可协同手段：
  - 相互冲突的手段：
  - 主机制失败后的备用方案：
  - 外援或团队配合：
- 消耗与恢复成本：只写成功使用也必须承担的投入和后续恢复。
  - 能量与资源消耗：
  - 装备、丹药或一次性物品消耗：
  - 身体与神魂负担：
  - 寿元或长期代价：
  - 准备和使用时间：
  - 使用后恢复方式与时间：
- 性能限制：写机制在什么条件下不能充分发挥。
  - 境界、体质或权限要求：
  - 次数、冷却或蓄力限制：
  - 距离与空间限制：
  - 环境限制：
  - 目标限制：
  - 性能上限：
- 克制、反制与规避：写外部主体或环境怎样主动处理该机制。
  - 发现和识别方式：
  - 已知克制：
  - 打断方式：
  - 绕过方式：
  - 压制和削弱：
  - 反向利用或控制：
  - 使用者的反反制：
- 正常、异常与极端状态：写机制从正常运行到崩溃的状态变化。
  - 正常状态：
  - 性能下降：
  - 局部失效：
  - 完全失效：
  - 反噬或反控：
  - 极端后果：
  - 应急切换：
  - 恢复条件：
  - 不可逆损失：
- 习得、成长、衰退与后续变化：追踪机制的能力生命周期。
  - 获得方式：
  - 入门门槛：
  - 熟练度影响：
  - 境界或阶段成长：

  - 新增协同或克制：
  - 被替代或淘汰：
  - 能力受损和丢失：
  - 遗留影响：
- 环境和外部影响：写机制与战场及非目标对象的双向作用。
  - 环境对机制的增强或削弱：
  - 机制对地形和设施的影响：
  - 对队友和协作者的影响：
  - 对旁观者和非目标的影响：
  - 对后续追击、隐匿和恢复的影响：
- 关联事件与结果分布：只列能体现不同状态和结果的事件，不重复事件卡正文。
  - 成功事件：
  - 失败事件：
  - 被克制或反转事件：
  - 极端状态事件：
  - 训练或测试事件：
- 信息边界与待确认项：统一说明机制总览的明确程度。
  - 原文明确：
  - 谨慎归纳：
  - 其他合理解释：
  - 原文未说明：
  - 仅单次表现，不可泛化：

### 事件卡片字段

- 参与方与角色：区分各方在本次事件中的责任和立场。
  - 主要观察主体：
  - 直接敌方：
  - 队友与协作者：
  - 保护或治疗目标：
  - 第三方与援军：
  - 环境威胁：
- 场景性质与收录理由：说明事件类型及其分析价值。
  - 场景性质：填写实战、训练、测试、追击、逃生、治疗、保命触发或战后处置。
  - 收录理由：写事件实际展示了哪种机制、状态、限制、克制或保命结果。
  - 现实危险程度：区分无现实危险的测试、受控风险和真实生死危险。
- 事件目标、风险和终止条件：写各方希望达成什么以及事件何时结束。
  - 主体目标：
  - 对方目标：
  - 保护或治疗目标：
  - 失败后果：
  - 胜利或生存条件：
  - 主动撤离条件：
  - 事件终止条件：
- 开始前状态与信息态势：只保留会影响本次事件的条件。
  - 主体身体、修为和伤势：
  - 主体可用资源与底牌：
  - 对方状态与已知能力：
  - 队友和第三方状态：
  - 各方已知信息：
  - 误判和未知：
  - 各方空间位置与距离：
  - 地形、掩体和环境：
  - 阵法或区域边界：
- 威胁识别、先手与决策：写事件怎样启动以及首次选择怎样形成。
  - 谁先发现威胁：
  - 谁掌握先手：
  - 首次威胁判断：
  - 首次选择的机制：
  - 选择理由：
  - 未采用的方案及原因：
- 关键阶段行动链：按“第1阶段、第2阶段……”重复填写，只保留改变战局的阶段。
  - 阶段触发：
  - 各方目标：
  - 各方位置和距离：
  - 各方行动与使用机制：
  - 机制交互、克制或协同：
  - 资源、伤势与控制状态：
  - 空间和节奏变化：
  - 转折点：
  - 阶段结果：
  - 信息明确程度：
- 生存链、备用方案与援救：总结多层保命机制怎样连接。
  - 预防和预警：
  - 常规防御：
  - 受创缓冲：
  - 解控与脱离：
  - 紧急底牌：
  - 外部援救：
  - 失败切换顺序：
  - 实际改变的生死结果：
- 事件状态变化：区分不同强度下的事件状态。
  - 正常交战或正常处置状态：
  - 异常状态：
  - 极端状态：
  - 恢复或脱离状态：
- 资源消耗、伤势和损失：记录本次实际发生的代价。
  - 能量和资源消耗：
  - 一次性物品与装备损毁：
  - 身体和神魂伤势：
  - 寿元或长期损失：
  - 队友、第三方和环境损失：

  - 结束方式：

  - 死亡、俘虏、逃脱或援救：
  - 战利品与装备变化：
  - 短期治疗和恢复：
  - 长期损伤或能力变化：
  - 情报、仇怨和关系后果：
  - 对环境和第三方的后续影响：
- 机制判断与总览更新：说明本事件能够怎样更新稳定机制。
  - 本次支持的最小结论：
  - 本次不能支持的结论：
  - 成功或失败的主要原因：
  - 新限制或新克制：
  - 升级、变体或失效样本：
  - 对机制层级的影响：
- 信息边界与待确认项：统一说明事件卡的明确程度。

### 稳定机制示例：替伤护印

- 分类与机制层级：防御、受创缓冲、一次性保命；虚构示例中的明确设定。
- 机制定位、来源与内部构成：预先刻入护符的替伤结构在主体受到致命攻击时接管部分伤害；由感应层、储能层和承伤载体共同组成。
- 触发、决策与控制：被动触发；只有伤害超过预设阈值才启动，触发后无法取消。
- 实际效果与性能：能够替主体承担一次直接伤害，但不能解除毒、诅咒、持续灼烧或空间放逐。
- 协同、冲突与备用层级：位于常规防御失效之后、主动逃遁之前；触发产生的短暂僵直会与需要连续施法的遁术冲突。
- 消耗与恢复成本：护符永久损毁，主体仍承受剩余冲击；重新制作需要材料和时间。
- 正常、异常与极端状态：正常时完成一次替伤；储能不足时只减轻伤害；识别层错误可能替无关伤害触发并提前耗尽底牌。
- 信息边界与待确认项：本例为虚构结构示例，实际作品中的阈值、承伤比例和适用伤害类型均须重新确认。

### 真实交战示例：狭桥伏击与反突围

- 参与方与角色：主要观察主体为被伏击者；直接敌方为桥头与桥尾两组伏击者；一名负伤队友需要保护；桥下急流构成环境威胁。
- 事件目标、风险和终止条件：主体目标是带队友离开封锁；敌方目标是拖延并等待援军；桥尾形成可通行缺口即满足主动撤离条件。
- 开始前状态与信息态势：主体知道桥头可能有敌人，但不知道桥尾已有第二组；主体保留护盾、一次解控和短距位移手段。
- 威胁识别、先手与决策：敌方先以控制术封锁桥头；主体判断正面击杀耗时过长，选择制造桥尾缺口而不是继续争夺桥头。
- 关键阶段行动链：第1阶段，桥头控制迫使主体后退并触发护盾；第2阶段，桥尾伏击暴露，主体以解控保护队友并用范围攻击制造空间；第3阶段，护盾破裂后切换短距位移越过桥尾封锁，队友由协作者带离。
- 生存链、备用方案与援救：预警失败 → 护盾承担首轮攻击 → 解控防止被固定 → 范围攻击制造距离 → 位移完成脱离；任何一步延迟都会让敌方援军到达。
- 事件状态变化：正常突围转为前后夹击的异常状态；护盾破裂时接近极端状态；位移越过封锁后进入脱离状态。
- 机制判断与总览更新：本次支持护盾只能争取时间、解控需要配合空间制造、位移适合越过单层封锁；不能据此推定主体能够稳定突破所有包围。
- 信息边界与待确认项：本例为虚构结构示例，实际事件中的位置、距离、资源和决策原因均须重新确认。

### 追击逃生示例：封锁城门后的隐匿脱离

- 场景性质与收录理由：真实追击与逃生；展示隐匿、伪装、路线切换和外援之间的连续保命链。
- 事件目标、风险和终止条件：逃亡者需要在搜捕范围收紧前离城；进入追踪手段无法覆盖的水道后才算脱离。
- 开始前状态与信息态势：逃亡者知道城门会核验身份，但不知道水道出口也有巡查；追击方掌握外貌和常用气息特征。
- 关键阶段行动链：先用伪装通过普通街区；城门核验使伪装失效后转入隐匿；隐匿被范围侦测压制后切换地下水道；协作者制造错误踪迹分散追兵。
- 生存链、备用方案与援救：伪装降低初始关注 → 隐匿切断目视和气息 → 水道改变追踪环境 → 外援制造假路线；四层分别应对不同追踪方式。
- 事件状态变化：常规潜行 → 身份核验异常 → 范围搜捕极端收紧 → 路线切换后脱离。
- 结束、追击与战后恢复：逃亡者成功离城，但伪装身份和城内联络点暴露，后续必须更换身份网络。
- 机制判断与总览更新：隐匿并非无条件消失，其效果依赖追踪方式、环境和主体是否留下替代线索。
- 信息边界与待确认项：本例为虚构结构示例，实际作品中的侦测范围、隐匿原理和外援作用均须重新确认。
