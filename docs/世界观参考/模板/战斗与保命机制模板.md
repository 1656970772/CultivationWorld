# 战斗与保命机制模板

## 适用范围

本模板用于整理作品中的战斗方式、伤害类型、逃生保命和战斗后果。重点是原文中真实出现，或能由原文明确支撑的战斗行动链。

本文只写行动链，不写总览、证据段、抽象规则表或项目字段映射。行动链应按原文先后顺序写清：开战前状态、谁先出手、使用什么手段、如何防御或克制、如何受伤、撤退、追杀、保命、死亡或逃脱。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角越级胜利或少数名场面。
- 只整理原文有可靠依据的内容。原文没有写持续时间、追杀时间、疗伤时间、法宝冷却、触发条件或代价时，不要补。
- 主角的重要战斗链要尽量完整。配角、NPC、反派、妖兽、宗门长老、散修和势力首领若有完整战斗链，也应记录。
- 保命、逃生、替死、遁术、残魂逃逸、元婴出窍、传送、隐匿、假死等情节，必须写清触发条件、消耗、限制和被克制方式。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **战斗形态**：法术对轰、法宝碰撞、剑修斗法、体修近战、神魂攻击、毒、诅咒、阵法困杀、傀儡、灵宠、妖兽厮杀、群战、偷袭、暗杀、追杀、伏击、越级战、宗门战争、秘境混战。
- **使用手段**：法术、神通、功法招式、法宝、符箓、丹药、阵法、毒物、傀儡、灵宠、护体灵光、护盾、甲胄、遁术、传送、替死、分身、元婴出窍、残魂逃逸、隐匿、假死、空间法宝。
- **消耗内容**：灵力、法力、真元、神识、气血、寿元、丹药、符箓、灵石、法宝耐久、阵盘、傀儡、灵宠伤势、身体损伤、神魂损伤、一次性保命物。
- **效果变化**：轻伤、重伤、断肢、跌境、神魂受创、中毒、封印、禁制、护盾抵消、法宝挡伤、阵法困敌、灵宠护主、替死生效、残魂逃逸。
- **获得或损失**：死亡、逃脱、俘虏、掉落、夺宝、法宝损毁、丹药耗尽、符箓耗尽、战利品、情报、仇怨、通缉、关系变化、消息传播。
- **境界与状态**：境界压制、越级、跌境、突破中断、伤势恶化、疗伤需求、神魂不稳、法力耗尽、心魔加重、战后闭关、战后逃亡。

## 案例

### 案例

**通用行动链字段：**

- **战斗名和类型**：写具体战斗或保命事件名称，并标明战斗形态。
- **开战前状态**：写清双方境界、人数、位置、地形、阵法、资源、伤势、是否被偷袭。
- **逐步行动链**：按原文顺序写清每一轮出手、防御、克制、受伤、消耗、获得、损失和状态变化。
- **保命节点**：若出现逃生、替死、传送、隐匿、分身、残魂、元婴、师长护持等，写清触发条件、代价和限制。
- **追击与结束**：写清追杀、撤退、死亡、俘虏、逃脱、夺宝、任务完成或冲突扩大。
- **战后清算**：写清丹药、符箓、法宝耐久、灵力、伤势、神魂、战利品、仇怨、通缉、疗伤或逃亡路线。

#### 案例 1：越级战斗后依靠遁术逃生

**行动链：**

1. 开战前，角色处于某境界，敌方境界更高或人数更多；地点、地形、阵法和是否被偷袭按原文填写。
2. 敌方先出手，使用法术、法宝、神魂攻击或阵法压制；写清伤害、防御效果或控制效果。
3. 角色用护体灵光、防御法宝、符箓、阵盘或灵宠抵挡；写清消耗、法宝损坏和伤势。
4. 角色反击，使用法术、法宝、毒、傀儡或神通；写清是否破防、逼退或造成伤害。
5. 战斗进入消耗阶段；有持续时间就写时间，没有就只写事件。
6. 角色判断无法取胜，使用遁术、传送符、血遁、隐匿、假死或空间法宝逃生；写清触发条件、消耗、伤势和代价。
7. 敌方追击或失去目标；写清追杀时间、追击手段、通缉或仇怨。
8. 战后清点损失和收获；写清资源、伤势、神魂、法宝、战利品和后续路线。

#### 案例 2：秘境混战中的法宝损毁与夺宝

**行动链：**

1. 角色进入秘境或遗迹；写清初始境界、同行者、目标资源和限制条件。
2. 因灵药、法宝、传承、出口或禁制核心，与其他修士发生冲突。
3. 双方试探，使用法术、法宝、傀儡、毒、符箓或阵法；逐步写清消耗和效果。
4. 强力法宝、禁制或地形改变战局；写清伤害、防御、重伤或死亡。
5. 角色为保命或夺宝消耗丹药、符箓、法宝耐久或一次性底牌。
6. 角色夺得资源、击退敌人、放弃部分资源或带伤逃离；写清获得和损失。
7. 若出现法宝损毁、灵宠受伤、神魂受创、境界不稳或中毒，写入对应节点。
8. 秘境结束后，写清出口截杀、消息传播、仇怨、追杀、交易或闭关炼化。

#### 案例 3：保命手段触发后的后续代价

**行动链：**

1. 角色遭遇致命伤害；写清来源：境界碾压、法宝一击、阵法绞杀、毒、神魂攻击、天劫、妖兽攻击或偷袭。
2. 保命手段触发，例如替死符、护身符、分身、血遁、元婴出窍、残魂逃逸、传送阵、空间法宝或师长护持。
3. 写清触发条件：自动触发、主动催动、提前准备、距离限制、境界限制或媒介限制。
4. 写清消耗：符箓耗尽、法宝破碎、寿元损失、气血损失、神魂受创、修为跌落、肉身损毁、灵宠代死、未知传送。
5. 写清敌方反应：继续追杀、误以为死亡、夺走遗留资源、发布通缉、封锁出口或转攻同伴。
6. 写清逃脱后状态：境界、伤势、神魂、资源、法宝、同行者和藏身地点。
7. 写清后续恢复：疗伤、夺舍、重塑肉身、闭关、寻找丹药、修复法宝、隐藏身份或转移地图；有时间和消耗则写清。
