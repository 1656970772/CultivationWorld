# 战斗与保命机制模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的战斗、追击、逃生、隐匿、防御、控制、治疗、临战增幅、替死和战后损伤等机制，以及能够体现这些机制如何运作的独立事件。

本模板既记录单场事件中的行动链，也归纳可重复使用或由作品明确说明的稳定机制。普通交易、技能传授、资源获取、人物玩笑、单纯的能力背景和没有现实危险的日常冲突，不单独作为战斗与保命事件；只有它们直接呈现触发条件、效果、消耗、限制、克制或实际保命结果时才可收录。

法术、功法、法宝、符箓、丹药、阵法、毒物、傀儡、灵宠和特殊体质等对象，只整理其在战斗与保命中的实际作用，不展开为对应对象的完整分析。

## 整理原则

1. 先做准入判定

   可收录真实战斗、追杀、伏击、逃遁、隐匿、护主、替死、急救、战后疗伤，以及能明确展示威力、消耗或失败风险的训练和测试。韩立银针急救厉飞雨、尸虫丸控制、夜遇奸细时隐匿躲避、云翅鸟追踪监视，以及聚生散的临战增幅、紫隐羽衣的防御作用，都属于可判断的战斗或保命机制。

   韩立按时给厉飞雨送止痛药、厉飞雨传授缠丝手、偷取七绝堂秘籍、张衍拥有前世战斗经验等内容，本身不构成独立事件卡；若后续在具体危险中实际发挥作用，再写入对应事件。宁冲玄赐予的物品若只说明“可保性命”而未展示运作方式，只能记录为信息尚不完整的保命物线索，不补写未知机制。

2. 一个独立事件一张卡

   同一张事件卡的行动链必须属于同一场连续事件。回忆、训练背景、后续补充或另一次冲突不得伪装成连续动作。萧炎与萧玉的后山冲突和后续房间内的“不敲门”事件应拆成两张卡，不得合并为一场战斗。

3. 区分事件和机制层级

   事件卡记录“当时发生了什么”，机制总览归纳“这种手段通常如何运作”。机制层级分为“单次案例”“多次复现”和“明确设定”。单次成功只能说明该次有效；至少有多个相互独立的实际表现，或作品已明确说明通用规则时，才可提升为稳定机制。

   例如八极崩首次成功、吸掌与吹火掌组合测试只能按训练或测试结果填写；符宝的驱动时间、防御硬撑和耗尽报废若在多个独立事件中反复出现，才可归纳为可复现机制。法会比斗中修士多依赖法宝、飞剑，而资源不足者更多依靠身体等内容，可作为明确设定写入机制总览，不虚构具体战斗过程。

4. 标明场景性质，不混淆权重

   每张事件卡必须区分实战、训练、测试、追击、逃生、治疗、保命触发和战后清算。训练与测试可以展示手段的威力、消耗和限制，但不能与真实战斗中的成功率、抗压能力和生死结果等同。药老以斗气鞭挞训练萧炎并配合筑基灵液修复、萧炎首次成功使用八极崩，都应明确标为训练或测试。

5. 用关键攻防轮次写空间行动链

   行动链只保留一至三个改变战局的关键攻防轮次，不逐动作复述剧情。每轮按“敌方的位置与距离、敌方使用的手段 → 卡片主体的位置或距离变化、卡片主体使用的抵抗手段 → 本轮结果”填写。空间位置可写前后左右、空中或地面、室内或室外、高低差、掩体、阵内阵外等；距离优先填写原文数值，只有相对关系时写贴身、近距、中距或远距，无法判断时写“原文未说明”。

   “卡片主体”指本卡重点记录的一方，不固定为作品主角。战斗卡必须同时交代敌方如何接近或出手，以及卡片主体如何格挡、闪避、反制、拉开距离或撤退；位置和距离没有变化时也应明确写出。治疗、训练等没有敌方的事件，将对应项写为“不适用”，并记录目标的位置和距离。

6. 强制写出代价、限制和克制

   保命、逃生、替死、遁术、残魂逃逸、元婴出窍、传送、隐匿、临战增幅和一次性底牌，不得写成无代价能力；也不得把主角的越级胜利泛化为普通成功率，或给特定角色预设无条件免死。银针急救只能暂时救醒、尸虫丸依赖解药且清灵散无效、八极崩使用后脱力并有伤臂风险、吸掌与吹火掌组合会大量消耗斗气、筑基灵液负责修复训练损伤、增气散换取短时实力后需卧床一个月，均应落到对应字段。聚生散以短时刺激脑力为代价透支精元并缩短寿数，紫隐羽衣可抵挡寻常法宝飞剑，也要同时记录效果边界。紫云翼逃生与强行施展焰分噬浪尺之间的取舍、佛怒火莲作为最后底牌的后遗症、药老介入或附体式保命的条件和代价，也应完整记录。

7. 不把推断写成事实

   原文没有明确说明的结论写入“不确定/推断”，并保留其不确定性。缠丝手能够解开死结，不能据此直接扩展为捕人、制敌的稳定能力；长春功带来的夜视帮助角色避险，不能擅自断言没有夜视必然死亡；眨眼剑法是否适配修仙者灵力，也不能由修炼条件直接推定。

8. 合并同一机制的后续信息

   同一手段后续出现新的用法、消耗、限制、克制、失败样本或效果反转时，应补入同一机制条目，并用不同事件卡保留各自行动链。不要只记录首次出现，也不要为同一机制反复建立“后期版”“补充版”等重复条目。

9. 保持跨阶段和跨类型覆盖

   样本应覆盖作品早期、中期和后期，并兼顾不同境界、身份、势力、地域、战斗形态和结局；不能只收录主角早期的成功案例，配角、反派、妖兽、宗门长老、散修和势力首领的完整事件也应纳入。整理《凡人修仙传》时，除早期急救、控制和隐匿外，还应检查魔银手对罗烟步、金光上人与金罩和飞剑术、符宝的驱动与报废、金蚨子母刃、水罩、飞天盾和金光砖符宝等后续机制。整理《斗破苍穹》时，除八极崩、吸掌与吹火掌、筑基灵液和增气散外，还应检查紫云翼、焰分噬浪尺、异火与飞行逃生、佛怒火莲、药老介入或附体式保命等内容。

10. 缺失和自检

    某一范围没有检出相关内容时写“未检出”；尚未检查时写“未覆盖”；输入材料缺失时写“数据缺失，不补写”。完成后检查：普通交易或传授是否被误收，训练和实战是否混淆，同一卡片是否混入不同事件，单次表现是否被泛化，战斗卡是否同时写明敌方与卡片主体的位置、距离和所用手段，卡片主体的抵抗是否缺失，以及触发、代价、限制、克制、后果和后期高频机制是否遗漏。

## 字段说明

### 机制总览字段

- 分类：写攻击、防御、控制、追击、逃生、隐匿、治疗、替死、临战增幅、战后恢复等，可按实际情况并列。
- 机制层级：填写单次案例、多次复现或明确设定；不确定的归纳不得提升层级。
- 适用对象/场景：写适用角色、境界、目标、环境或战斗阶段；原文未说明则写“原文未说明”。
- 触发条件：写主动施展、受击触发、濒死触发、服用、蓄力、预先布置、持有特定物品等前提。
- 运作方式：概括机制从触发到生效的过程，只写原文能够支撑的规则。
- 消耗/代价：写灵力、斗气、真元、气血、神识、寿元、药物、符箓、法宝耐久、身体或神魂损伤等。
- 限制/克制：写使用次数、冷却、境界或体质要求、距离、环境、准备时间、失效条件和已知破解方式。
- 失败风险：写未触发、被打断、反噬、重伤、失去底牌、无法逃脱或死亡等风险。
- 关联事件：列出能够体现该机制的事件名称；多个事件只列名称，不在此重复行动链。
- 不确定/推断：集中填写尚未明确、只能推测或存在矛盾的信息；没有则写“无”。

### 事件卡片字段

- 卡片主体：填写本卡重点记录的一方；不固定为作品主角，也可以是配角、反派、妖兽或群体。
- 敌方/目标：战斗、追击和逃生场景填写敌方；治疗、训练和测试场景填写受治者或测试目标。
- 场景性质：填写实战、训练、测试、追击、逃生、治疗、保命触发或战后清算。
- 收录理由：简要说明该事件实际展示了哪一种战斗或保命机制。
- 开始前状态：写双方的境界、伤势、资源和已知差距，只保留会影响事件的信息。
- 开始前空间态势：分别写敌方与卡片主体的空间位置、相互距离、朝向、高低差、掩体或阵法边界；没有说明的项目不补写。
- 关键攻防行动链：只写一至三个关键轮次。每轮固定写“敌方：位置、距离、手段 → 卡片主体：位置或距离变化、抵抗手段 → 结果”，不拆解无关小动作。
- 保命节点：写逃遁、隐匿、替死、援救、治疗、护盾、法宝挡伤等改变生死结果的节点；没有则写“无”。
- 消耗/代价：写本次实际发生的资源消耗、伤势、反噬、寿元损失或底牌损毁。
- 限制/克制：写本次表现出的使用上限、准备条件、弱点、破解方式或失败原因。
- 追击与结束：写是否追杀、撤退、俘虏、死亡、逃脱、被援救或主动停战。
- 战后清算：写伤势、疗伤、跌境、闭关、战利品、法宝损毁、情报、仇怨、通缉和后续追杀等结果。
- 可归纳机制：写本事件能够支持的最小机制结论，并标明属于单次案例、多次复现或明确设定。
- 不确定/推断：填写空间位置、距离、行动链或机制中无法确认的部分；没有则写“无”。

```md
- 失败风险：
- 关联事件：
- 不确定/推断：

### 尸虫丸控制

- 分类：控制、延时致死、解药依赖
- 机制层级：明确设定
- 适用对象/场景：被迫服下尸虫丸者的长期控制
- 触发条件：目标服下尸虫丸
- 运作方式：虫卵在体内潜伏一年；未获得解药时发作并吞噬内脏
- 消耗/代价：受控者的生命长期受制于解药
- 限制/克制：清灵散无效；其他解除方式原文未说明
- 失败风险：未及时获得解药会死亡
- 关联事件：韩立受尸虫丸控制
- 不确定/推断：其他药物能否解除原文未说明

## 事件卡片

### 战斗或保命事件名称

- 卡片主体：
- 敌方/目标：
- 场景性质：
- 收录理由：
- 开始前状态：
- 开始前空间态势：
  - 敌方位置/距离：
  - 卡片主体位置/距离：
- 关键攻防行动链：
  - 第一轮：敌方（位置、距离、手段）→ 卡片主体（位置或距离变化、抵抗手段）→ 结果
  - 第二轮：敌方（位置、距离、手段）→ 卡片主体（位置或距离变化、抵抗手段）→ 结果
- 保命节点：
- 消耗/代价：
- 限制/克制：
- 追击与结束：
- 战后清算：
- 可归纳机制：
- 不确定/推断：

### 韩立银针急救厉飞雨

- 卡片主体：韩立
- 敌方/目标：厉飞雨（救治目标）
- 场景性质：治疗、临时保命
- 收录理由：事件完整展示了急救手段、施救负担和只能暂时救醒的限制
- 开始前状态：厉飞雨急症发作；韩立具备银针施救能力
- 开始前空间态势：
  - 敌方位置/距离：不适用；厉飞雨处于韩立可近身施针的位置
  - 卡片主体位置/距离：韩立位于厉飞雨近身处
- 关键攻防行动链：
  - 第一轮：救治目标（近身、急症发作）→ 韩立（保持近身、连续施下数十针）→ 厉飞雨暂时苏醒，韩立明显出汗
- 保命节点：银针使厉飞雨从急症中暂时苏醒
- 消耗/代价：连续施针对韩立造成明显体力负担
- 限制/克制：只能救醒一时，不能根治急症
- 追击与结束：不适用
- 战后清算：厉飞雨暂时恢复意识，原有病症仍未解除
- 可归纳机制：银针可用于紧急唤醒，但本次表现不支持根治结论；单次案例
- 不确定/推断：无

### 萧炎首次成功使用八极崩

- 卡片主体：萧炎
- 敌方/目标：测试用树木
- 场景性质：训练、测试
- 收录理由：事件展示了八极崩的威力、斗气消耗和身体承受上限
- 开始前状态：萧炎处于第六段斗之气，以树木测试八极崩
- 开始前空间态势：
  - 敌方位置/距离：不适用；树木位于萧炎近身攻击范围内
  - 卡片主体位置/距离：萧炎位于树木近身处
- 关键攻防行动链：
  - 第一轮：测试目标（近身、无反击）→ 萧炎（保持近身、施展八极崩）→ 树木受到明显破坏，萧炎手臂酸麻并脱力
- 保命节点：无
- 消耗/代价：一次施展已大量消耗斗气，并使手臂酸麻脱力
- 限制/克制：当前阶段最多施展一次；强行继续可能损伤手臂
- 追击与结束：测试结束
- 战后清算：萧炎需要恢复斗气和手臂状态
- 可归纳机制：八极崩在当前阶段属于高消耗、高身体负担的爆发手段；单次案例
- 不确定/推断：无
```
