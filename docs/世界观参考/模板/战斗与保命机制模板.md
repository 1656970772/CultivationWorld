# 战斗与保命机制模板

# 规范

本模板用于整理作品中的战斗方式、伤害类型、逃生保命和战斗后果。重点是原文中真实出现，或能由原文明确支撑的战斗行动链。

每个案例只写行动链，不写总览、抽象规则表或项目字段映射。行动链应按原文先后顺序写清：开战前双方状态、谁先出手、使用什么手段、如何防御或克制、如何受伤、撤退、追杀、保命、死亡或逃脱。

样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角越级胜利、单一境界、少数名场面或少数成功案例。主角的重要战斗链要尽量完整，配角、NPC、反派、妖兽、宗门长老、散修和势力首领若有完整战斗链，也应记录。

行动链里的每个小节点都尽量写清“时间 / 使用手段 / 消耗 / 伤害或防御效果 / 获得或损失 / 境界变化 / 伤势变化”。原文写了战斗持续时间、追杀时间、疗伤时间、法宝冷却或保命手段触发时机，就写进对应节点；没有写的不要补。

不要把主角越级胜利当作普通概率，不给特定角色开无条件免死特权，不把“锁血”“逃脱”“替死”写成无代价能力。凡是出现保命、逃生、替死、遁术、残魂逃逸、元婴出窍、传送、隐匿、假死等情节，都要尽量写清触发条件、消耗、限制和被克制方式。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 战斗形态：法术对轰、法宝碰撞、剑修斗法、体修近战、神魂攻击、毒、诅咒、阵法困杀、傀儡、灵宠、妖兽厮杀、群战、偷袭、暗杀、追杀、伏击、越级战、宗门战争、秘境混战。
- 使用手段：法术、神通、功法招式、法宝、符箓、丹药、阵法、毒物、傀儡、灵宠、护体灵光、护盾、甲胄、遁术、传送、替死、分身、元婴出窍、残魂逃逸、隐匿、假死、空间法宝。
- 消耗内容：灵力、法力、真元、神识、气血、寿元、丹药、符箓、灵石、法宝耐久、阵盘、傀儡、灵宠伤势、身体损伤、神魂损伤、逃生底牌、一次性保命物。
- 伤害或防御效果：轻伤、重伤、断肢、跌境、神魂受创、中毒、封印、禁制、护盾抵消、法宝挡伤、阵法困敌、灵宠护主、师长护持、伤害转移、替死生效、残魂逃逸。
- 获得或损失：死亡、逃脱、俘虏、掉落、夺宝、法宝损毁、丹药耗尽、符箓耗尽、战利品、情报、仇怨、通缉、关系变化、消息传播、后续追杀。
- 境界与状态变化：境界压制、越级、跌境、突破中断、伤势恶化、疗伤需求、神魂不稳、法力耗尽、心魔加重、战后闭关、战后逃亡。
