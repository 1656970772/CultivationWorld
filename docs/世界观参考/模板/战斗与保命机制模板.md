# 战斗与保命机制模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：战斗方式、伤害类型、逃生保命和战斗后果调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的战斗与保命行动链，不写总览，不写证据段，不写抽象规则表，不单独拆“战斗类型、伤害来源、保命手段、项目映射”等表格字段。

每个案例只写行动链。行动链要按原文先后顺序逐步写清战斗如何发生：开战前双方状态、谁先出手、使用了什么法术/法宝/肉身/神魂/阵法/毒/符箓/傀儡/灵宠，如何防御或克制，如何受伤、撤退、追杀、保命、死亡或逃脱。

行动链里的每个小节点都尽量写清“时间 / 使用手段 / 消耗 / 伤害或防御效果 / 获得或损失 / 境界变化 / 伤势变化”。如果原文写了战斗持续时间、追杀时间、疗伤时间、法宝冷却或保命手段触发时机，要写进对应小节点。原文写了多少就写多少；没有写的不要补。

主角的重要战斗链要尽量完整，尤其是影响后续修炼、资源、仇怨、法宝、伤势或逃亡路线的战斗。配角、NPC、反派、妖兽、宗门长老、散修、势力首领等角色如果有完整战斗链，也应写完整；如果原文只给出一段精彩战斗或保命片段，就只写该片段。

不要把主角越级胜利当作普通概率，不给特定角色开无条件免死特权，不把“锁血”“逃脱”“替死”写成无代价能力。凡是出现保命、逃生、替死、遁术、残魂逃逸、元婴出窍、传送、隐匿、假死等情节，都要尽量写清触发条件、消耗、限制和被克制方式。

- **消耗内容**：灵力、法力、真元、神识、气血、寿元、丹药、符箓、灵石、法宝耐久、阵盘、傀儡、灵宠伤势、身体损伤、神魂损伤、逃生底牌、一次性保命物。
- **伤害或防御效果**：轻伤、重伤、断肢、跌境、神魂受创、中毒、封印、禁制、护盾抵消、法宝挡伤、阵法困敌、灵宠护主、师长护持、伤害转移、替死生效、残魂逃逸。

## 完整战斗与保命行动链案例

### 案例 1：越级战斗后依靠遁术逃生

**行动链：**

1. 开战前，角色处于某境界，敌方境界更高或人数更多；双方所在地点、地形、阵法或是否被偷袭按原文填写。
2. 敌方先出手，使用某法术、法宝、神魂攻击或阵法压制；写清造成的伤害、防御效果或控制效果。
3. 角色使用护体灵光、防御法宝、符箓、阵盘或灵宠抵挡；写清消耗了什么、法宝是否受损、角色是否受伤。
4. 角色反击，使用某法术、法宝、毒、傀儡或神通；写清对敌方造成的伤害、是否逼退、是否破防。
5. 战斗进入消耗阶段，写清持续时间；如果原文没有时间，写事件本身，不补时间。
6. 角色判断无法取胜，使用遁术、传送符、血遁、隐匿、假死或空间法宝逃生；写清触发条件、消耗、伤势或代价。
7. 敌方追击或失去目标；写清追杀持续时间、追击手段、是否留下通缉或仇怨。
8. 战后角色清点损失：丹药、符箓、法宝耐久、灵力、伤势、神魂状态、获得的战利品或失去的资源。
9. 后续角色闭关疗伤、修复法宝、购买补给、躲避追杀或改变行动路线；写清时间和消耗，原文未写则不补。

### 案例 2：秘境混战中的法宝损毁与夺宝

**行动链：**

1. 角色进入秘境或遗迹，初始境界、同行者、目标资源和限制条件按原文填写。
2. 因发现灵药、法宝、传承、出口或禁制核心，与其他修士发生冲突。
3. 双方先试探，使用法术、法宝、傀儡、毒、符箓或阵法；写清每次手段的消耗和效果。
4. 某一方使用强力法宝或禁制改变战局；写清造成的伤害、防御是否成功、是否有人重伤或死亡。
5. 角色为了保命或夺宝，消耗丹药、符箓、法宝耐久或一次性底牌。
6. 角色夺得资源、击退敌人、被迫放弃部分资源或带伤逃离；写清获得和损失。
7. 如果战斗导致法宝损毁、灵宠受伤、神魂受创、境界不稳或中毒，要写进对应节点。
8. 秘境结束后，写清是否出现出口截杀、消息传播、仇怨、追杀、交易或闭关炼化所得资源。

### 案例 3：保命手段触发后的后续代价

**行动链：**

1. 角色遭遇致命伤害，写清致命来源：境界碾压、法宝一击、阵法绞杀、毒、神魂攻击、天劫、妖兽攻击或偷袭。
2. 保命手段触发，例如替死符、护身符、分身、血遁、元婴出窍、残魂逃逸、传送阵、空间法宝或师长护持。
3. 写清触发条件：是否自动触发、是否需要主动催动、是否要求提前准备、是否有距离或境界限制。
4. 写清消耗：符箓耗尽、法宝破碎、寿元损失、气血损失、神魂受创、修为跌落、肉身损毁、灵宠代死、传送到未知地点。
5. 写清敌方反应：继续追杀、误以为死亡、夺走遗留资源、发布通缉、封锁出口或转攻同伴。
6. 写清角色逃脱后的状态：境界、伤势、神魂、资源、法宝、同行者、藏身地点。
7. 写清后续恢复：疗伤、夺舍、重塑肉身、闭关、寻找丹药、修复法宝、隐藏身份或转移地图；有时间和消耗则写清，没有则不写。
