# 丹药分析模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的丹药、药剂、药散、药丸、毒药、毒丹、禁丹、解药、药液，以及可直接服用、外用或产生药效的灵液、真露等。

本模板只做丹药分析，不展开材料本体、炼丹器具、法宝、香炉、功法、丹炉、药园、炼丹师职业体系等内容。药材、灵草、妖兽材料、矿材、灵液等材料只在“丹方”中作为投入材料或配方规则被提到；如果需要分析材料本身，放入 `材料分析模板.md`。

## 整理原则

1. 先做准入判定  
   只有可服用、外用，或能直接产生疗伤、修炼、突破、解毒、毒杀、洗髓、补魂、延寿等药效的对象，才可建立丹药卡。  
   纯材料、器具、香炉、丹炉、容器、法宝、功法、药园、职业身份，不得作为丹药卡。

2. 一药一卡  
   同名、别名、不同品阶、不同品质、不同剂型、不同阶段用法、后续功效补充，都必须归并到同一张丹药卡。  
   禁止另建“某丹药（补充）”“某丹药·后期”“某丹药低品质”等新卡。差异写入同卡的相关字段。

3. 字段完整  
   每张卡必须包含：分类、准入理由、品阶/品质/丹纹、外观描述、稀有度、功效、用途、丹方、炼制/形成方式、炼制失败品及作用、药渣及作用、限制/副作用、适用境界/阶段。  
   无依据时写“原文未说明”；不涉及炼制时，“炼制失败品及作用”和“药渣及作用”写“不适用”。不得为了补齐品阶、境界梯度、效果类型、丹方、失败产物或副作用而自行虚构。

4. 等阶差异逐字段展开  
   同一丹药存在下品、中品、上品、极品、丹纹、几转、无暇、完美或作品自定义品级时，先在“品阶/品质/丹纹”中列出实际存在的等阶。  
   外观、稀有度、功效、用途、丹方、炼制/形成方式、炼制失败品、药渣、限制/副作用、适用境界等任一字段因等阶而不同时，必须在该字段下按作品原有等阶名称建立子字段分别描述。没有差异的字段直接填写共通内容；差异不明时写“原文未说明”，不得自行推断。

5. 记录炼制失败品和药渣  
   同一丹药炼制失败产生的废丹、残丹、焦丹、药性失衡丹等失败品，以及炼制结束后的药渣，统一记录在主丹药卡的对应字段中。  
   重点写失败品和药渣的残余药效、毒性或副作用、处理方式、再利用方式、交易价值、研究价值及其他后续作用；没有明确内容时写“原文未说明”。

6. 区分丹药、材料和器具  
   可直接产生药效的灵液、真露、药液、毒药、解药可以收录。  
   只作为原料的灵草、矿材、妖兽材料不单独建丹药卡；只用于辅助修炼或炼药的器具也不单独建丹药卡。

7. 合并后续用法  
   同一丹药在后文出现新的用量、限制、副作用、炼制难度、适用场景或功效反转时，补入原卡。  
   禁止只记录首次用法后忽略后续变化，也禁止把人物推测写成确定结论。

8. 输出简化  
   保留能体现丹药体系、药效规则、炼制规则、使用限制和后续影响的信息。  
   不长篇复述剧情，不把人物评价、拍卖反应、战斗场面或炼丹过程细节塞满字段。

## 字段说明

- 分类：写命名丹药、药散药丸、药液灵液真露、毒药、解药、禁丹、无名药物等。
- 准入理由：说明该对象为什么属于丹药、药剂、药液、毒药或解药；若只是材料、器具或容器，应排除，不建卡。
- 品阶/品质/丹纹：按作品自己的质量体系填写，如下品、中品、上品、极品、丹纹数量、几转、无暇、完美等；没有明确划分时写“原文未说明”。
- 外观描述：写丹药或药液可直接观察到的形态、颜色、大小、质地、光泽、气味、丹纹、杂质或其他显著特征；没有明确描写时写“原文未说明”，不得根据名称或功效推断。
- 稀有度：按作品自己的描述填写，如常见、稀有、宗门垄断、传说级、仙界罕见等；原文未说明则写“原文未说明”。
- 功效：写服用或使用后的效果，如增加真气、辅助突破、疗伤、解毒、延寿、短期爆发、洗髓、补魂、毒杀等。
- 用途：写丹药被如何使用，如修炼、突破、疗伤、战斗、解毒、延寿、交易、喂养灵兽、任务奖励等。
- 丹方：写具体材料或通用材料规则，如百年人参、青灵草、火属性三阶妖兽内丹、冰属性灵草、数种珍稀灵药；不明时写“原文未说明”。
- 炼制/形成方式：写丹药如何产生，如炼丹师炼制、天地生成、妖兽体内凝结、古修遗留、仙界流传；不明时写“原文未说明”。
- 炼制失败品及作用：写炼制失败后产生的废丹、残丹、焦丹、药性失衡丹或其他失败品，以及其残余药效、毒性、副作用、处理方式、再利用方式、交易或研究价值；不明时写“原文未说明”，不涉及炼制时写“不适用”。
- 药渣及作用：写炼制后剩余药渣的残余药性、毒性、处理方式，以及是否可用于制药、喂养、培育灵植、回收材料、研究或交易；不明时写“原文未说明”，不涉及炼制时写“不适用”。
- 限制/副作用：写丹毒、耐药、境界限制、服用间隔、透支潜力、毒性、体质要求等；没有说明时写“原文未说明”。
- 适用境界/阶段：按作品自己的境界或阶段说法填写；没有明确依据写“原文未说明”。
