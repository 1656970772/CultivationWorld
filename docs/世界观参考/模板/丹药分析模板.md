# 丹药分析模板

# 规范

用于整理作品中出现过，或能由小说内容明确支撑的丹药、药剂、药散、毒丹、禁丹、药液，以及可直接服用并产生药效的灵液等。

本模板只做丹药分析，不展开材料本体分析。药材、灵草、妖兽材料、矿材、灵液等材料只在“丹方”中作为投入材料或配方规则被提到；如果需要分析材料本身，放入 `材料分析模板.md`。

本文只整理小说中出现过，或能由小说内容明确支撑的丹药、药剂、药散、毒丹、禁丹、药液等，不编造小说中不存在的丹药。

整理时应按功效类型和适用境界尽可能覆盖完整：每一类功效、每一个境界阶段，只要小说中有对应丹药，都应尽量写成独立卡片。文档长度不设上限，宁可写长，也不要为了压缩篇幅遗漏有参考价值的丹药。

如果某类丹药、某个境界阶段，或丹方、炼制方式、限制/副作用等字段在小说中没有可靠依据，可以写“原文未说明”；不得为了补齐丹药品阶、境界梯度、效果类型或数值体系而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 丹药名称：写小说中的丹药、药剂、药散、毒丹、禁丹、药液等名称。
- 稀有度：按作品自己的描述填写，如常见、稀有、宗门垄断、传说级、仙界罕见等。
- 功效：写服用或使用后的效果，如增加真气、辅助突破、疗伤、解毒、延寿、短期爆发、洗髓、补魂、毒杀等。
- 用途：写丹药被如何使用，如修炼、突破、疗伤、战斗、解毒、延寿、交易、喂养灵兽、任务奖励等。
- 丹方：写具体材料或通用材料规则，如百年人参、青灵草、火属性三阶妖兽内丹、冰属性灵草、数种珍稀灵药；不明时写“原文未说明”。
- 炼制方式：写丹药如何产生，如炼丹师炼制、天地生成、妖兽体内凝结、古修遗留、仙界流传；不明时写“原文未说明”。
- 限制/副作用：写丹毒、耐药、境界限制、服用间隔、透支潜力、毒性、体质要求等；没有说明时写“原文未说明”。
- 适用境界：按作品自己的境界说法填写，如炼气、筑基、金丹、元婴，或该作品特有境界。

## 案例

### 案例

```md
# 《作品名》丹药分析

## 丹药卡片

### 聚气丹

- 丹药名称：聚气丹
- 稀有度：常见
- 功效：增加真气
- 用途：日常修炼、补充修炼资源
- 丹方：聚气类灵草、辅药若干
- 炼制方式：炼丹师炼制
- 限制/副作用：可能有丹毒或耐药，按作品设定填写
- 适用境界：炼气、筑基

### 筑基丹

- 丹药名称：筑基丹
- 稀有度：稀有
- 功效：辅助突破筑基
- 用途：突破境界、宗门奖励
- 丹方：筑基主药、妖兽内丹、珍稀辅药
- 炼制方式：炼丹师炼制
- 限制/副作用：服用对象和突破阶段受限
- 适用境界：炼气圆满

### 疗伤丹

- 丹药名称：疗伤丹
- 稀有度：较常见
- 功效：回复气血、修复伤势
- 用途：战斗后疗伤、任务补给
- 丹方：疗伤灵草、温养类辅药
- 炼制方式：炼丹师炼制
- 限制/副作用：原文未说明
- 适用境界：炼气、筑基、金丹

### 毒丹

- 丹药名称：毒丹
- 稀有度：稀有
- 功效：毒杀、削弱或控制目标
- 用途：暗杀、战斗、邪修手段
- 丹方：毒草、毒虫、阴属性材料
- 炼制方式：炼丹师或邪修炼制
- 限制/副作用：对使用者或目标可能有强副作用
- 适用境界：按作品设定填写

### 天地灵液

- 丹药名称：天地灵液
- 稀有度：非常稀有
- 功效：直接提升修为或洗髓
- 用途：修炼、突破、疗伤
- 丹方：原文未说明
- 炼制方式：天地生成
- 限制/副作用：原文未说明
- 适用境界：按作品设定填写
```
