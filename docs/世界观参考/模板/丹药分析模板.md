# 丹药分析模板

## 适用范围

用于整理作品中出现过，或能由资料来源明确支撑的丹药、药剂、药散、毒丹、禁丹、药液，以及可直接服用并产生药效的灵液等。

本模板只做丹药分析，不展开材料本体分析。药材、灵草、妖兽材料、矿材、灵液等材料只在“丹方”中作为投入材料或配方规则出现；材料本体放入 `材料分析模板.md`。

## 前置声明

- 只整理原文出现过，或能由资料来源明确支撑的丹药、药剂、药散、毒丹、禁丹、药液等，不编造丹药。
- 样本要按功效类型和适用境界尽量覆盖；原文有对应丹药就列入。
- 原文没有可靠依据的品阶、境界梯度、效果类型、数值、丹方、炼制方式、来源、限制或副作用，写“原文未说明”。
- 信息不足但值得追踪的对象放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法要求 |
|------|----------|
| 丹药名称 | 写小说中的丹药、药剂、药散、毒丹、禁丹、药液等名称。 |
| 稀有度 | 按作品自己的描述填写，如常见、稀有、宗门垄断、传说级、仙界罕见等。 |
| 功效 | 写服用或使用后的效果，如增加真气、辅助突破、疗伤、解毒、延寿、短期爆发、洗髓、补魂、毒杀等。 |
| 用途 | 写丹药如何被使用，如修炼、突破、疗伤、战斗、解毒、延寿、交易、喂养灵兽、任务奖励等。 |
| 丹方 | 写具体材料或通用材料规则；不明时写“原文未说明”。 |
| 炼制方式 | 写丹药如何产生，如炼丹师炼制、天地生成、妖兽体内凝结、古修遗留、仙界流传等。 |
| 来源 | 写丹药从哪里获得，如宗门兑换、坊市购买、拍卖、秘境、遗迹丹瓶、任务奖励、杀人夺宝等。 |
| 限制/副作用 | 写丹毒、耐药、境界限制、服用间隔、透支潜力、毒性、体质要求等；没有说明时写“原文未说明”。 |
| 适用境界 | 按作品自己的境界说法填写；原文未说明时写“原文未说明”。 |

可补充字段：服用流程、药效持续时间、失败风险、替代丹药、搭配材料、炼制失败后果、争夺事件。
