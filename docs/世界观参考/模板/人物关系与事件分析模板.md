# 人物关系与事件分析模板

> 最后更新：2026-06-17
> 状态：模板
> 类型：关系网、事件因果与关系驱动行为调研
> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的人物关系变化链，不写总览，不写证据段，不写抽象规则表，不单独拆“关系类型、关键关系边、事件因果链、项目映射”等表格字段。

每个案例只写关系变化链。关系变化链要简洁写清：谁和谁一开始是什么关系，关系因什么事件发生变化，最后变成什么关系，并带来什么关系后果。事件只作为推动关系变化的节点，不展开成完整剧情。

关系链可以是一对一，也可以是多人关系链，例如“主角 - 师傅 - 同门好友”“主角 - 道侣 - 对方宗门”“主角 - 仇敌 - 仇敌背后势力”。不要只写“关系很好/很差”，要写关系如何建立、强化、削弱、反转、公开、隐藏、断裂或延续。

每条关系变化链尽量写清“初始关系 / 变化节点 / 关系变化方向 / 是否公开 / 是否对称 / 关系终态 / 后续关系后果”。如果原文没有写公开状态、对称性或后续后果，不要硬补。

主角的重要关系链要写，但不要只写主角关系。NPC、配角、反派、宗门内部、势力之间、人妖关系、灵宠关系、师徒关系、血亲关系、道侣关系、恩义和仇怨关系都可以写。

## 参考范围（不局限于以下类别）

- **人际关系**：师徒、道侣、血亲、同门、好友、盟友、竞争者、宿敌、恩人、仇人、主仆、上下级、债主/欠债者、救命者/被救者、施恩者/受恩者。
- **势力关系**：同盟、附庸、贸易、世仇、联姻、共同抗敌、暗线渗透、背叛、吞并、归顺、宗门庇护、宗门牵连。
- **人妖/异族关系**：灵宠、坐骑、契约兽、妖兽仇敌、族群报复、化形合作、半驯化共生、跨族道侣、族群庇护。
- **建边事件**：拜师、收徒、救命、赠宝、传功、背叛、羞辱、击杀亲友、同门初始化、联姻、退婚、交易、共同探索、战争、通缉、护送、夺宝、共同守秘。
- **关系变化方向**：亲近、疏远、反目、敌对、和解、依附、庇护、道侣化、师徒化、同盟化、从公开转秘密、从秘密转公开、从个人关系扩展到势力关系。
- **关系后果**：护短、传功、报恩、复仇、追杀、背叛、求援、继承遗志、争夺继承、放过、加害、逃亡、宗门牵连、资源支持、身份暴露、通缉、声誉变化。
- **关系终态**：长期牵挂、敌对未解、死亡终止、关系断裂、归入同一势力、成为道侣、成为师徒、成为仇敌、成为长期同盟、秘密关系保留。

## 完整人物关系变化链案例

### 案例 1：萧炎、药老、韩枫

**关系变化链：**

萧炎最初只是戒指的持有者，药老隐藏在戒指中，二人关系从“未知存在与被吸取斗气者”开始。药老现身后，转为师徒关系，药老传萧炎炼药、焚诀和异火路线，萧炎逐渐依赖药老作为修炼引路人。后来药老旧事牵出韩枫，韩枫从药老曾经的弟子变成背叛师门的仇敌，萧炎与韩枫也因此从无直接关系变成师门仇怨关系。药老被魂殿牵连后，萧炎和药老关系进一步从师徒变成救师与复仇的长期关系链。

### 案例 2：萧炎、纳兰嫣然、萧战、云岚宗

**关系变化链：**

萧炎和纳兰嫣然原本有婚约，关系是家族约定下的未婚夫妻。纳兰嫣然加入云岚宗后，身份和地位上升，亲自到萧家退婚，使两人的关系从婚约变成羞辱和对立。萧战作为萧炎父亲被退婚事件牵连，萧家和纳兰家、云岚宗之间也从旧交变成尴尬敌对。萧炎立下三年之约后，个人婚约关系转为公开挑战关系，最后三年之约又把这条关系链推向萧炎与云岚宗的更大冲突。

### 案例 3：萧炎、萧薰儿、古族

**关系变化链：**

萧炎和萧薰儿早期在萧家一起成长，关系是青梅竹马和长期支持者。萧炎低谷时，薰儿仍然维护和信任他，使两人关系从普通族中亲近转为稳定情感牵挂。随着薰儿真实背景逐渐显露，她背后的古族身份让这段关系不只是个人关系，也牵出萧炎与古族、远古族群层面的身份差距。后来萧炎实力提升，这条关系从弱小时被支持，逐渐变成并肩面对古族压力和更高层世界的关系链。

### 案例 4：萧炎、美杜莎、蛇人族

**关系变化链：**

萧炎和美杜莎最初围绕异火、进化和蛇人族利益产生冲突，关系是敌对和互相利用。美杜莎进化后与萧炎产生更深牵连，二人的关系从敌对转为复杂绑定。后来美杜莎以彩鳞身份与萧炎关系逐渐稳定，蛇人族也因此和萧炎产生间接联系。这条关系从资源冲突，变成危险牵连，再变成互相承认和道侣、族群牵连。

### 案例 5：萧炎、云韵、云岚宗

**关系变化链：**

萧炎和云韵最初在特殊遭遇中相识，关系带有隐瞒身份下的互助和暧昧。后来云韵云岚宗宗主身份揭开，而萧炎又因纳兰嫣然和云岚宗产生冲突，两人的私人关系被宗门立场撕裂。云韵对萧炎并非单纯敌人，但她背后的云岚宗与萧炎走向敌对，使关系从个人好感变成私人情感与宗门立场冲突的链条。
