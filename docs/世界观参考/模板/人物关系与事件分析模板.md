# 人物关系与事件分析模板

# 规范

## 参考和要求

用于整理作品中出现过，或能由小说内容明确支撑的人物关系网、关系变化链、事件因果与关系驱动行为。

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 样本覆盖：覆盖不同境界、身份、地域、势力、立场和结局；主角重要，但不能只写主角或少数成功案例。
- 内容依据：只写原文或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 案例数量：数量不限；模板案例只是最低写法示范，不是上限。
- 整理边界：本文只写关系变化链，不写总览、抽象规则表或项目映射；事件只作为推动关系变化的节点，不展开完整剧情。
- 关系链字段：每条关系变化链建议写清初始关系、变化节点、关系变化方向、是否公开、是否对称、关系终态、后续关系后果；原文没有公开状态、对称性或后续后果时，直接写“原文未说明”。
- 人际关系：整理师徒、道侣、血亲、同门、好友、盟友、竞争者、宿敌、恩人、仇人、主仆、上下级、债主/欠债者、救命者/被救者、施恩者/受恩者等关系的建立、强化、削弱、反转、断裂或延续。
- 势力关系：整理同盟、附庸、贸易、世仇、联姻、共同抗敌、暗线渗透、背叛、吞并、归顺、宗门庇护、宗门牵连等关系，关注个人关系是否扩展为势力牵连。
- 人妖/异族关系：整理灵宠、坐骑、契约兽、妖兽仇敌、族群报复、化形合作、半驯化共生、跨族道侣、族群庇护等关系，关注是否跨越种族、契约、族群利益或长期仇怨。
- 建边事件：整理拜师、收徒、救命、赠宝、传功、背叛、羞辱、击杀亲友、同门初始化、联姻、退婚、交易、共同探索、战争、通缉、护送、夺宝、共同守秘等让双方从无关系变成有关系的事件。
- 变化方向：写清亲近、疏远、反目、敌对、和解、依附、庇护、道侣化、师徒化、同盟化、公开化、秘密化、个人关系扩展到势力关系等方向，不只写“很好/很差”。
- 关系后果：整理护短、传功、报恩、复仇、追杀、背叛、求援、继承遗志、争夺继承、放过、加害、逃亡、宗门牵连、资源支持、身份暴露、通缉、声誉变化等关系变化带来的行为或代价。
- 关系终态：整理长期牵挂、敌对未解、死亡终止、关系断裂、归入同一势力、成为道侣、成为师徒、成为仇敌、成为长期同盟、秘密关系保留等阶段性结果。

## 案例

### 案例

```md
# 《作品名》人物关系与事件分析

## 人物关系与事件卡片

### 关系链名称

- 对象：人物甲 / 人物乙 / 相关势力或第三方
- 初始关系：原文明确支撑的起点关系
- 变化节点：触发关系变化的事件或行为
- 变化方向：亲近、敌对、公开、秘密、反目、和解、依附、牵连等
- 是否公开：公开 / 秘密 / 原文未说明
- 是否对称：对称 / 单向 / 原文未说明
- 关系终态：阶段性终局或最新状态
- 后续后果：资源支持、追杀、庇护、背叛、宗门牵连、身份暴露等

### 师徒链

- 对象：师父 / 徒弟 / 相关宗门
- 初始关系：陌生接触或长辈考察
- 变化节点：收徒、传承、传功、庇护或救援
- 变化方向：师徒化、亲近、庇护或传承延续
- 是否公开：按作品设定填写；不明时写“原文未说明”
- 是否对称：按作品设定填写；不明时写“原文未说明”
- 关系终态：长期师徒、反目或传承终止
- 后续后果：传功、护短、继承遗志、宗门牵连等

### 仇怨链

- 对象：人物甲 / 人物乙 / 牵连势力
- 初始关系：陌生、竞争、同门或旧识
- 变化节点：羞辱、夺宝、击杀亲友或背叛
- 变化方向：敌对升级、反目或势力牵连
- 是否公开：按作品设定填写；不明时写“原文未说明”
- 是否对称：按作品设定填写；不明时写“原文未说明”
- 关系终态：和解、死亡终止或敌对未解
- 后续后果：追杀、复仇、通缉、宗门卷入等

### 道侣链

- 对象：人物甲 / 人物乙 / 牵连势力
- 初始关系：相识、同行、契约牵连或旧识
- 变化节点：情感强化、立场冲突、共同危机或公开承认
- 变化方向：亲近、道侣化、公开化、秘密化或分离
- 是否公开：按作品设定填写；不明时写“原文未说明”
- 是否对称：按作品设定填写；不明时写“原文未说明”
- 关系终态：道侣、分离或势力牵连
- 后续后果：互相庇护、资源支持、身份暴露、宗门牵连等

### 势力链

- 对象：个人 / 家族 / 宗门 / 族群
- 初始关系：陌生、旧交、竞争、附属或敌对
- 变化节点：个人事件、共同抗敌、交易、背叛、吞并或归顺
- 变化方向：同盟化、附庸化、敌对化、归顺或反目
- 是否公开：按作品设定填写；不明时写“原文未说明”
- 是否对称：按作品设定填写；不明时写“原文未说明”
- 关系终态：同盟、附庸、吞并、背叛或共同抗敌后的阶段性关系
- 后续后果：资源支持、战争、通缉、宗门牵连、声誉变化等

### 人妖/异族链

- 对象：人物 / 妖兽 / 异族 / 族群
- 初始关系：猎杀、敌对、交易、契约或陌生接触
- 变化节点：救命、契约、驯化、共同危机、族群报复或族群庇护
- 变化方向：合作、驯化、仇怨、庇护、跨族关系或长期敌对
- 是否公开：按作品设定填写；不明时写“原文未说明”
- 是否对称：按作品设定填写；不明时写“原文未说明”
- 关系终态：灵宠、族群合作、跨族关系或长期敌对
- 后续后果：战斗协助、坐骑牵连、族群介入、报复或庇护等
```
