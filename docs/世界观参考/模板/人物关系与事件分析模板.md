# 人物关系与事件分析模板

## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的人物关系网、关系变化链、事件因果与关系驱动行为。

## 前置声明

- 样本要覆盖不同境界、身份、地域、势力、立场和结局；主角重要，但不能只写主角或少数成功案例。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 案例数量不限；模板案例只是最低写法示范，不是上限。
- 信息不足但符合主题的内容，先写入 `### 待定案例`。后续获得新信息时，在同一待定项追加摘要和来源；信息足够后，复核来源并转为正式案例。
- 本文只写关系变化链，不写总览、证据段、抽象规则表或项目映射。事件只作为推动关系变化的节点，不展开完整剧情。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 人际关系 | 师徒、道侣、血亲、同门、好友、盟友、竞争者、宿敌、恩人、仇人、主仆、上下级、债主/欠债者 | 关系如何建立、强化、削弱、反转、断裂或延续。 |
| 势力关系 | 同盟、附庸、贸易、世仇、联姻、共同抗敌、暗线渗透、背叛、吞并、归顺、宗门庇护 | 个人关系是否扩展为势力牵连。 |
| 人妖/异族关系 | 灵宠、坐骑、契约兽、妖兽仇敌、族群报复、化形合作、半驯化共生、跨族道侣、族群庇护 | 是否跨越种族、契约、族群利益或长期仇怨。 |
| 建边事件 | 拜师、收徒、救命、赠宝、传功、背叛、羞辱、击杀亲友、联姻、退婚、交易、共同探索、战争、通缉、夺宝 | 哪个事件让双方从无关系变成有关系。 |
| 变化方向 | 亲近、疏远、反目、敌对、和解、依附、庇护、道侣化、师徒化、同盟化、公开化、秘密化 | 关系方向要写清，不只写“很好/很差”。 |
| 关系后果 | 护短、传功、报恩、复仇、追杀、背叛、求援、放过、加害、逃亡、宗门牵连、资源支持、身份暴露、通缉、声誉变化 | 关系变化带来了什么行为或代价。 |
| 关系终态 | 长期牵挂、敌对未解、死亡终止、关系断裂、归入同一势力、成为道侣、成为师徒、成为仇敌、成为长期同盟、秘密保留 | 终态可以是阶段性结果，不必强行圆满。 |

每条关系变化链建议写清：初始关系 / 变化节点 / 关系变化方向 / 是否公开 / 是否对称 / 关系终态 / 后续关系后果。原文没有公开状态、对称性或后续后果时，直接写“原文未说明”。

主角的重要关系链要写，但不要只写主角关系。NPC、配角、反派、宗门内部、势力之间、人妖关系、灵宠关系、师徒关系、血亲关系、道侣关系、恩义和仇怨关系，只要有可靠依据，都可以写。

## 案例

### 案例

#### 案例 1：萧炎、药老、韩枫

**关系变化链：**

萧炎最初只是戒指持有者，药老隐藏其中，二人从“未知存在与被影响者”开始。药老现身后，关系转为师徒，药老传授炼药、焚诀和异火路线。韩枫旧事暴露后，他从药老旧徒变成背叛师门的仇敌，萧炎也被卷入师门仇怨。药老被魂殿牵连后，这条链继续转为救师、复仇和长期对抗。

#### 案例 2：萧炎、纳兰嫣然、萧战、云岚宗

**关系变化链：**

萧炎和纳兰嫣然原有婚约，是家族约定下的未婚夫妻。纳兰嫣然加入云岚宗后登门退婚，使关系从婚约转为羞辱和公开对立。萧战与萧家被事件牵连，个人婚约扩展为萧家、纳兰家和云岚宗的势力冲突。三年之约进一步把私人关系推向公开挑战和后续大战。

#### 案例 3：萧炎、美杜莎、蛇人族

**关系变化链：**

萧炎和美杜莎最初围绕异火、进化和蛇人族利益发生冲突，关系是敌对和互相利用。美杜莎进化后与萧炎产生更深牵连，关系从敌对转为复杂绑定。后来美杜莎以彩鳞身份与萧炎关系稳定，蛇人族也因此与萧炎产生间接联系。这条链从资源冲突，转为危险牵连，再转为道侣与族群牵连。
