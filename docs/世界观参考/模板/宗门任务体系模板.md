# 宗门任务体系模板

## 适用范围

本模板用于整理宗门或组织如何发布任务、分配资源、考核弟子、奖励贡献、维持秩序和推动成员成长。

本文不写大型网游式任务面板，除非原文有类似制度。宗门任务不要和散修悬赏混为一类；散修悬赏、自由接活、生存任务放 `散修生存方式模板.md`。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角任务、战斗任务或成功案例。
- 只整理原文有可靠依据的任务制度、接取条件、行动流程、奖励来源、失败后果和组织回流。
- `接取条件`、`任务来源`、`任务目标`、`成功奖励`、`失败后果` 必须尽量详细；原文未说明时写“原文未说明”，不要用泛泛一句带过。
- 同一宗门任务体系里，如果日常、战斗、探索、生产、考核、外交任务规则明显不同，应分别写成案例。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **任务类型**：日常杂务、资源维护、猎妖清剿、护送驻守、秘境探索、生产上交、考核晋升、宗门大比、外交情报、卧底渗透。
- **发布者**：任务殿、执事、长老、堂口、药园、矿脉、灵兽园、执法堂、边境据点、掌门、情报堂、商会委托方、附属势力。
- **接取者**：杂役、外门、内门、真传、执事、长老、职业堂口成员、附庸修士、客卿、强制征召人员、秘密派遣者。
- **接取条件**：境界、身份、职位、贡献、声望、队伍人数、时间窗口、前置任务、物品门票、宗门许可、担保人、押金、名额、保密契约。
- **任务来源**：宗门日常运转、资源成熟、边境告急、邪修作乱、秘境开启、库存不足、职位空缺、外交需求、情报缺口。
- **任务目标**：采集、巡逻、守护、猎杀、活捉、护送、驻守、探索、绘图、炼制、上交、考核、谈判、潜伏、带回情报或证据。
- **行动流程**：接取、审核、组队、领取工具或令牌、前往地点、执行任务、处理异常、验收、交付成果、结算奖励、复盘追责。
- **所需资源**：工具、令牌、地图、丹药、符箓、法器、阵盘、飞舟、传讯符、材料、工坊、队友、护卫、撤离路线。
- **奖励**：灵石、贡献、丹药、功法、法宝、材料、洞府、职位、指导、人情、声望、秘境资格、免罚、晋升机会、隐藏赏赐。
- **奖励来源**：宗门库存、堂口预算、矿脉收益、药园产出、商会委托、战利品、上交资源分成、长老赏赐、战争预算。
- **失败后果**：罚款、扣贡献、降级、受伤、死亡、关系变差、资源损失、宗门稳定下降、被追责、目标死亡、声望受损、秘密身份暴露。
- **组织回流**：资源入库、边境稳定、商路维护、弟子筛选、职业人才培养、库存补充、情报获得、盟约达成、宗门声望变化。

## 案例

### 案例

| 任务类型 | 示例 | 重点 |
| --- | --- | --- |
| 日常杂务与资源维护 | 采药、采矿、巡逻、看守山门、打理药园、照料灵兽、维护阵法 | 轮值规则、验收标准、低阶弟子收益、失败扣罚 |
| 猎妖 / 清剿 / 战斗任务 | 猎妖、清剿邪修、追杀叛徒、剿灭盗匪、通缉悬赏 | 情报来源、战斗风险、证明物、战利品分配、追责 |
| 护送 / 守矿 / 边境防御 | 护送商队、驻守矿脉、守药园、边境防御、守城 | 驻守时长、交接流程、求援机制、失守后果 |
| 秘境 / 遗迹 / 禁地探索 | 秘境试炼、古修洞府、遗迹发掘、地图绘制、异象探查 | 名额门槛、进入规则、资源归属、死亡或失踪风险 |
| 生产与上交任务 | 炼丹、炼器、制符、布阵、修复法宝、培育灵药、炼制阵盘 | 职业资格、材料权限、品质验收、失败赔偿 |
| 考核 / 晋升 / 宗门大比 | 入门考核、外门升内门、真传选拔、职位考核、宗门大比 | 报名资格、评分标准、名次奖励、派系影响 |
| 外交 / 情报 / 卧底任务 | 出使、联姻谈判、附属势力巡查、秘密调查、卧底渗透 | 保密等级、身份伪装、撤离路线、宗门是否承认失败 |

**通用任务卡片：**

- **任务名和类型**：写具体任务名称，并标明任务类型。
- **发布者**：写清任务由哪个宗门部门、长老、堂口、据点、附属势力、商会或秘密上级发布。
- **接取者**：写清参与者身份、境界、职位、队伍结构、是否自愿、轮值、征召或秘密派遣。
- **接取条件**：详细写身份层级、境界、贡献、声望、前置任务、名额、令牌、押金、担保、保密契约、队伍配置和时间窗口。
- **任务来源**：详细写任务为什么出现，资源或事件从哪里来，不要只写“宗门发布”。
- **任务目标**：详细写要完成什么、完成标准、数量、品质、时限、证明物、验收方式、公开目标和隐藏目标。
- **行动流程**：按原文顺序写清接取、准备、出发、执行、异常处理、交付、验收、奖励或追责。
- **所需资源**：写清工具、令牌、材料、丹药、法器、阵盘、地图、队友、护卫、传讯和撤离手段。
- **成功奖励**：详细写奖励内容、分配方式、按数量/品质/战功/名次/队伍分成，或由管事、长老临时赏赐。
- **奖励来源**：写清奖励来自宗门库存、堂口预算、资源点收益、委托方、战利品、上交资源分成或长老私赏。
- **失败后果**：详细写死亡、重伤、扣贡献、赔偿、降级、任务目标损失、宗门声望下降、外交破裂、身份暴露等后果。
- **追责方式**：写清由谁追责，是否登记、调查、扣罚、赔偿、禁接任务、交执法堂、宗门否认或重新派任务。
- **对宗门的回流**：写清任务如何反哺宗门，例如库存、资源线、防御、商路、人才筛选、情报、盟约或声望。
- **相关人物关系**：写清管事、同门、队友、师长、商会、附属势力、敌人或被保护对象之间的关系变化。
- **升级或连锁任务**：写清任务如何引出调查、复仇、战争、秘境线、职业考核、派系斗争或长期潜伏。
- **结束方式与后续影响**：写清任务完成、失败、延期、取消、升级、转交、撤离，以及角色资源、地位、仇怨、声望和后续安排。
