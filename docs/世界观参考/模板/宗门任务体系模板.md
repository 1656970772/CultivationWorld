# 宗门任务体系模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：任务、贡献、奖励、晋升与组织运行调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文用于整理宗门或组织如何发布任务、分配资源、考核弟子、奖励贡献、维持秩序和推动成员成长。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不写大型网游式任务面板，除非原文有类似制度。
- 不只列任务目标和奖励，必须写清发布者、接取者、接取条件、任务来源、任务目标、行动流程、所需资源、成功奖励、奖励来源、失败后果、追责方式和组织回流。
- `接取条件`、`任务来源`、`任务目标`、`失败后果`、`成功奖励` 必须非常详细写清楚；原文没有说明时写“原文未说明”，不要用泛泛一句带过。
- 不把宗门任务和散修悬赏混为一类；散修悬赏、自由接活、生存任务放 `散修生存方式模板.md`。
- 同一宗门任务体系里，如果日常任务、战斗任务、探索任务、生产任务、考核任务、外交任务的规则明显不同，应分别写成案例。文档长度不是问题。

## 参考范围（不局限于以下类别）

- **日常任务**：采药、采矿、巡逻、看守山门、打理药园、照料灵兽、跑腿送信、维护阵法、杂役、抄录文书。
- **战斗任务**：猎妖、清剿邪修、追杀叛徒、护送、守矿、边境防御、宗门战争、通缉悬赏、剿灭盗匪。
- **探索任务**：秘境试炼、古修洞府、遗迹发掘、地图绘制、禁地侦查、传承考核、探查异象。
- **生产任务**：炼丹、炼器、制符、布阵、修复法宝、上交材料、培育灵药、饲养灵兽、炼制阵盘。
- **社交/组织任务**：收徒、传功、考核、宗门大比、联姻、外交、情报收集、卧底渗透、附属势力巡查。
- **接取条件**：境界、职位、贡献、声望、队伍人数、时间窗口、前置任务、物品门票、宗门许可、担保人、押金、名额。
- **奖励**：灵石、贡献、丹药、功法、法宝、材料、洞府、职位、指导、人情、声望、秘境资格、免罚、晋升机会。
- **失败后果**：罚款、扣贡献、降级、受伤、死亡、关系变差、宗门稳定下降、被追责、目标死亡、资源损失、声望受损。

## 完整宗门任务案例

### 案例 1：日常杂务与资源维护任务

任务名和类型：写具体任务名称，以及采药、采矿、巡逻、看守山门、打理药园、照料灵兽、跑腿送信、维护阵法、杂役等类型。

发布者：写清由谁发布，是任务殿、执事、长老、堂口、药园管事、矿脉管事、灵兽园、外门管事还是临时负责人。

接取者：写清谁会接这种任务，例如杂役弟子、外门弟子、内门弟子、低阶执事、附庸修士、惩罚期弟子或缺资源弟子。

接取条件：非常详细写。包括身份层级、境界要求、职位、贡献、声望、前置任务、队伍人数、是否需要担保人、是否需要令牌/名额/押金/任务凭证、是否有时间窗口、是否限制外门/内门/真传/长老、是否允许附庸参与。原文没有就写“原文未说明”。

任务来源：非常详细写。写清任务为什么出现：宗门日常运转需要、药园成熟、矿脉开采、灵兽园维护、阵法损耗、山门巡逻、管事分派、弟子惩罚、资源短缺、外门轮值等。要写清资源或事件从哪里来，不要只写“宗门发布”。

任务目标：非常详细写。写清要完成什么、完成标准是什么、是否要带回药材/矿石/灵兽饲料/巡逻记录/维护结果/文书，是否要守住某处多少天，是否有数量、品质、时间、完整度或验收标准。原文没有完成标准就写“原文未说明”。

行动流程：写清领取任务、领取工具或令牌、前往地点、执行日常工作、登记产出、上交物资、管事验收、领取奖励或被扣罚的过程。

所需资源：写清工具、灵石、阵盘、储物袋、药锄、矿镐、灵兽饲料、巡逻令牌、宗门制服、队友或护卫。

成功奖励：非常详细写。包括灵石、贡献、低阶丹药、修炼资源、食宿待遇、免除杂役、管事好感、晋升机会、任务积分、长期岗位资格等。还要写清奖励是固定、按数量/质量分配、按贡献分配，还是由管事临时赏赐。

奖励来源：写清奖励来自宗门库存、药园产出、矿脉收益、任务殿预算、堂口配额、管事私赏或上交物资的一部分。

失败后果：非常详细写。包括罚灵石、扣贡献、延长杂役期、失去岗位、被管事责罚、资源损坏赔偿、灵兽逃脱、药园损失、阵法故障、巡逻失职、关系变差等。若原文只写失败但没说惩罚，写“原文未说明”。

追责方式：写清由谁追责，是否登记在案，是否扣贡献、公开批评、交执法堂、赔偿资源、降级或改派更危险任务。

对宗门的回流：写清任务如何反哺宗门，例如维持药园、增加矿石、稳定灵兽园、维护阵法、保证山门安全、培养低阶弟子纪律。

相关人物关系：写清弟子与管事、同门、灵兽、药园负责人、矿脉管事之间的关系变化。

升级或连锁任务：写清日常任务如何升级为盗窃调查、妖兽袭击、矿脉争夺、药园被毁、灵兽失控或执法任务。

结束方式：写清任务完成、失败、延期、转交、被取消、被惩罚或发展成新任务链。

后续影响：写清角色获得资源、积累贡献、被管事记住、进入更高等级任务、被派去危险区域或卷入宗门事务。

### 案例 2：猎妖 / 清剿 / 战斗任务

任务名和类型：写具体猎妖、清剿邪修、追杀叛徒、剿灭盗匪、通缉悬赏、宗门战斗任务名称。

发布者：写清任务由宗门、执法堂、长老、边境据点、附属家族、商会委托、受害弟子家族还是上级势力发布。

接取者：写清参与者是外门弟子、内门弟子、真传、执法队、长老带队、临时小队、附庸修士还是强制征召人员。

接取条件：非常详细写。包括境界下限、战斗经验、队伍人数、是否需要带队者、是否需要宗门许可、是否需要追踪能力、是否限执法堂成员、是否需要押金/令牌/担保、是否允许跨境界组队。原文未说明就写“原文未说明”。

任务来源：非常详细写。写清妖兽袭击、邪修作乱、叛徒逃亡、商路被劫、矿脉被占、弟子死亡、附属家族求援、宗门边境告急、通缉令发布、仇怨升级等来源。

任务目标：非常详细写。写清要杀死谁、活捉谁、驱逐谁、带回什么证明，例如妖丹、人头、尸体、令牌、法宝、情报、受害者遗物、地点清剿结果。写清是否要保护平民、守住地点、限时完成或查明幕后。原文未说明完成标准就写“原文未说明”。

行动流程：写清接任务、组队、领取情报、准备丹药法器、赶赴地点、侦查、战斗、追击、收尸、验明目标、回宗交付的过程。

所需资源：写清丹药、符箓、法器、追踪工具、地图、飞行法器、护卫、情报、队友和应急撤离手段。

成功奖励：非常详细写。包括灵石、贡献、战利品分成、妖兽材料、法宝、功法、执法堂声望、晋升资格、通缉赏金、长老赏识、后续任务资格等。写清固定奖励、按贡献分配、队伍分成、战利品自留或上交后分配。

奖励来源：写清奖励来自宗门悬赏、受害者家族、商会委托、战利品、妖兽材料出售、执法堂预算或附属势力赔付。

失败后果：非常详细写。包括死亡、重伤、目标逃脱、情报泄露、宗门声望下降、附属势力受损、扣贡献、被追责、队友死亡、敌人报复、边境失守。原文未说明惩罚则写“原文未说明”。

追责方式：写清任务失败后谁追责，是否调查逃兵、追究带队者、扣贡献、赔偿损失、禁足、交执法堂或重新派任务。

对宗门的回流：写清清除威胁、获取材料、稳定边境、保护商路、提升声望、震慑叛徒、训练战斗弟子。

相关人物关系：写清队友信任、师门评价、仇人结怨、受害者家族感谢、执法堂记录和敌方报复关系。

升级或连锁任务：写清目标逃脱、幕后势力暴露、妖兽族群复仇、邪修同伙出现、通缉升级或宗门战争引发的新任务。

结束方式：写清目标被杀/捕、任务失败、队伍撤退、上级接手、线索中断或升级为长期追杀。

后续影响：写清角色获得战功、伤势、仇怨、声望、资源、执法资格或被卷入更大冲突。

### 案例 3：护送 / 守矿 / 边境防御任务

任务名和类型：写具体护送、守矿、守药园、驻守边境、保护商队、看守资源点、守城或防御任务名称。

发布者：写清宗门、商会、矿脉管事、边境据点、附属家族、长老、执法堂或战争前线发布者。

接取者：写清接任务者是弟子小队、守卫队、执法队、客卿、附庸修士、轮值弟子还是强制征召人员。

接取条件：非常详细写。包括境界、人数、驻守时长、是否需要阵法/医修/战斗修士搭配、是否要求忠诚、是否要签守密约、是否要接受轮值、是否需要押金或担保。原文未说明则写“原文未说明”。

任务来源：非常详细写。写清资源点重要、矿脉被盯上、商路危险、边境不稳、妖兽活动、敌宗袭扰、商会委托、战争动员、上级命令等来源。

任务目标：非常详细写。写清要护送谁/什么，守住哪里多久，保护哪些资源，巡逻哪些路线，阻止谁进入，出现敌袭时做到什么程度，是否要求带回报告或保持资源产出。原文未说明完成标准就写“原文未说明”。

行动流程：写清接取、领取路线/令牌、出发、交接防区、巡逻、处理异常、战斗或求援、换班、提交报告、领取奖励。

所需资源：写清地图、令牌、阵盘、传讯符、补给、飞舟、护卫、战斗法器、驻守营地和医疗资源。

成功奖励：非常详细写。包括灵石、贡献、驻守补贴、资源分成、商会报酬、战功、职位评价、长期驻地资格、长老记名等。写清按天、按风险、按战功、按队伍分配还是任务结束统一发放。

奖励来源：写清来自宗门、矿脉收益、商会委托、边境军费、资源点产出、附属家族供奉或战争预算。

失败后果：非常详细写。包括护送目标死亡、资源被抢、矿脉失守、商队覆灭、边境被破、队伍伤亡、扣贡献、赔偿、降职、被调查、宗门声望受损。原文未说明则写“原文未说明”。

追责方式：写清由任务殿、边境主事、商会、宗门长老或执法堂追责，是否追究失守、逃跑、泄密、贪污或误报。

对宗门的回流：写清保护资源、维护商路、稳定边境、保障税收/供奉、训练弟子、保持附属势力忠诚。

相关人物关系：写清护送对象、商会、队友、守军、附属家族、边境敌人之间的信任或仇怨。

升级或连锁任务：写清护送遇袭、矿脉被夺、边境失守、内鬼泄密、商队失踪后如何引出调查、清剿或战争任务。

结束方式：写清安全抵达、驻守期满、换防、目标被毁、撤退、上级接管或任务失败。

后续影响：写清资源线稳定、商会关系提升、边境战争升级、弟子获得战功或被追责。

### 案例 4：秘境 / 遗迹 / 禁地探索任务

任务名和类型：写具体秘境试炼、古修洞府探索、遗迹发掘、地图绘制、禁地侦查、传承考核、异象探查任务名称。

发布者：写清宗门、长老、任务殿、秘境管理者、掌门、家族、商会委托或上级势力发布者。

接取者：写清参与者是某境界弟子、真传、队伍、探路者、阵法师、带队长老、附庸修士还是选拔胜出者。

接取条件：非常详细写。包括境界、年龄、身份、名额、贡献、前置试炼、令牌、秘境钥匙、队伍配置、阵法能力、是否需要长老批准、是否限制外人。原文未说明则写“原文未说明”。

任务来源：非常详细写。写清秘境定期开启、古修洞府线索、遗迹出现、天地异象、宗门需要地图、禁地异常、传承考核、资源短缺或竞争势力行动等来源。

任务目标：非常详细写。写清是探索地图、采集资源、取得传承、找到入口、绘制路线、确认危险、带回令牌/材料/功法线索，还是完成试炼排名。写清完成标准和阶段目标；原文未说明则写“原文未说明”。

行动流程：写清报名、筛选、领取令牌、组队、进入、探索、采集、记录、应对危险、争夺机缘、退出、上交成果和复盘。

所需资源：写清秘境令牌、地图、丹药、阵盘、破禁工具、传送符、队友、护法、储物工具和保命手段。

成功奖励：非常详细写。包括秘境产出自留比例、宗门贡献、传承资格、丹药、法宝、功法、名次奖励、长老关注、真传资格、后续秘境名额。写清按排名、按上交资源、按探索成果还是固定名额分配。

奖励来源：写清来自秘境产出、宗门奖励、长老赏赐、上交资源分成、试炼排名奖励或传承本身。

失败后果：非常详细写。包括死亡、被困、重伤、失去名额、资源损失、地图错误、队友死亡、传承失败、宗门资源浪费、扣贡献、被追责。原文未说明则写“原文未说明”。

追责方式：写清是否追究带队者、记录探索失败、扣除名额、调查内斗、惩罚私吞资源或追查队友死亡。

对宗门的回流：写清获取地图、资源、传承、情报、弟子筛选结果、秘境控制权和下一轮探索经验。

相关人物关系：写清队伍合作、同门争夺、师门评价、长老关注、敌宗冲突、救命恩情或背叛。

升级或连锁任务：写清发现新区域、古修残魂、敌宗队伍、传承线索、秘境崩塌或队友失踪后引出的后续任务。

结束方式：写清限时退出、完成试炼、被传送离开、失败撤退、入口关闭、队伍失踪或长老救援。

后续影响：写清角色获得机缘、被同门嫉恨、宗门掌握秘境、引发争夺、开启传承线或形成长期任务链。

### 案例 5：生产与上交任务

任务名和类型：写具体炼丹、炼器、制符、布阵、修复法宝、上交材料、培育灵药、饲养灵兽、炼制阵盘等任务名称。

发布者：写清丹堂、器堂、符堂、阵法堂、药园、灵兽园、仓库、任务殿、长老、战争前线或商会委托方。

接取者：写清炼丹师、炼器师、符师、阵法师、药园弟子、灵兽师、杂役、内门弟子或职业堂口成员。

接取条件：非常详细写。包括职业资格、熟练度、境界、职位、配方权限、材料权限、贡献、担保、失败赔偿、是否要签保密约、是否允许学徒参与。原文未说明则写“原文未说明”。

任务来源：非常详细写。写清宗门库存不足、战争消耗、弟子月俸、秘境准备、商会订单、长老炼宝、药园成熟、灵兽繁殖、阵法维护等来源。

任务目标：非常详细写。写清要炼制/上交什么，数量、品质、时间、配方、材料标准、验收方式、失败品处理、是否允许替代材料和超额奖励。原文未说明则写“原文未说明”。

行动流程：写清领取配方和材料、登记、生产、失败处理、验收、上交成品、结算奖励、记录功劳或赔偿损耗。

所需资源：写清材料、丹炉、器炉、符纸、阵材、药田、灵兽饲料、助手、工坊、火脉和时间。

成功奖励：非常详细写。包括贡献、灵石、成品分成、材料边角料、职业声望、配方学习资格、堂口职位、长老赏识、后续高阶任务资格。写清固定、按品质、按数量、按超额或由堂口赏赐。

奖励来源：写清来自堂口预算、成品出售、宗门库存配额、战争物资预算、商会订单、长老个人赏赐或材料节余。

失败后果：非常详细写。包括材料赔偿、扣贡献、职业信誉下降、禁接任务、被师长责罚、库存延误、战争物资不足、灵兽死亡、药田损失。原文未说明则写“原文未说明”。

追责方式：写清由堂口、管事、长老、仓库或任务殿追责，是否查账、赔偿、降级、禁用工坊或公开批评。

对宗门的回流：写清补充库存、供给弟子、支持战争、提升职业堂口、增加收入、培养职业人才。

相关人物关系：写清师徒、同门竞争、堂口管事、客户、长老和队伍之间的评价变化。

升级或连锁任务：写清高品质成品引发长老关注、材料短缺引出采集任务、失败引出调查、订单扩大或职业考核。

结束方式：写清成品验收、失败赔偿、任务延期、材料耗尽、订单取消或升级为长期供应任务。

后续影响：写清角色职业成长、获得配方、积累名声、负债、进入高阶堂口或被派往资源点。

### 案例 6：考核 / 晋升 / 宗门大比任务

任务名和类型：写具体入门考核、外门升内门、内门升真传、宗门大比、传承考核、职位考核等名称。

发布者：写清掌门、长老会、任务殿、考核堂、传功长老、执法堂、某峰主或宗门制度。

接取者：写清参加者是杂役、外门、内门、核心、真传候选、执事候选、长老候选或附属家族子弟。

接取条件：非常详细写。包括身份、年龄、境界、贡献、前置任务、推荐人、报名费、名额、考核资格、派系限制、失败后冷却期、是否必须参加。原文未说明则写“原文未说明”。

任务来源：非常详细写。写清宗门定期选拔、资源重新分配、职位空缺、传承开启、长老收徒、宗门大比、战后补员、弟子晋升制度等来源。

任务目标：非常详细写。写清考什么，完成标准是什么，例如击败对手、通过试炼、取得名次、完成任务链、上交成果、守住擂台、得到长老认可、通过心性考验。原文未说明则写“原文未说明”。

行动流程：写清报名、资格审核、抽签、试炼、比斗、评分、排名、复核、公布结果、发放奖励、安排新身份。

所需资源：写清报名费、令牌、推荐信、法器、丹药、队伍、考核场地、裁判、护法和疗伤资源。

成功奖励：非常详细写。包括晋升、职位、洞府、月俸、贡献、丹药、功法、师承、真传资格、秘境名额、公开声望、资源倾斜。写清按名次、按成绩、按长老选择还是固定制度发放。

奖励来源：写清来自宗门制度、长老赏赐、职位资源、月俸体系、藏经阁权限、秘境名额配额或峰主私赏。

失败后果：非常详细写。包括失去名额、冷却期、受伤、死亡、扣贡献、派系失势、被嘲笑、降级、资源减少、被调去杂务或失去师门机会。原文未说明则写“原文未说明”。

追责方式：写清是否有人追责作弊、违规、误伤、逃赛、串通、假赛、伤人过重或考核事故。

对宗门的回流：写清筛选人才、重新分配资源、激励弟子、巩固派系、展示实力、确定继承序列。

相关人物关系：写清师徒选择、同门竞争、派系站队、长老关注、仇怨、结盟和公开名声变化。

升级或连锁任务：写清考核后进入真传线、秘境线、派系斗争、报复、师门任务或宗门大比后续。

结束方式：写清排名确定、资格授予、失败淘汰、作弊取消、事故中止或考核升级。

后续影响：写清角色地位变化、资源变化、敌友变化、宗门安排、长期派系影响。

### 案例 7：外交 / 情报 / 卧底任务

任务名和类型：写具体外交出使、情报收集、卧底渗透、联姻谈判、附属势力巡查、秘密调查等任务名称。

发布者：写清掌门、长老、情报堂、执法堂、外交堂、商会盟友、上级势力或某个派系。

接取者：写清使者、真传、长老、情报弟子、暗线、卧底、商会联络人、附属家族代表或被秘密派遣者。

接取条件：非常详细写。包括身份可信度、口才、境界、关系网、保密等级、伪装能力、前置任务、推荐人、是否需要魂誓/保密契约、是否有撤离路线。原文未说明则写“原文未说明”。

任务来源：非常详细写。写清联盟需求、敌宗动向、附属势力不稳、商路争端、战争前谈判、联姻安排、情报缺口、卧底需求、叛徒调查等来源。

任务目标：非常详细写。写清要谈成什么、查到什么、传回什么、接触谁、隐藏身份多久、带回情报/契约/名单/地图/证据，是否有公开目标和隐藏目标。原文未说明则写“原文未说明”。

行动流程：写清接密令、准备身份、出发、接触目标、谈判或潜伏、收集情报、传讯、撤离、交付成果和销毁痕迹。

所需资源：写清身份令牌、礼物、灵石、伪装法器、传讯符、暗号、接头人、护卫、假身份和撤退路线。

成功奖励：非常详细写。包括贡献、秘密赏赐、职位、信任、情报堂资格、长老庇护、外交声望、联姻资源、隐藏奖励或免罪。写清公开奖励和暗中奖励是否不同。

奖励来源：写清来自宗门高层、情报堂、派系私赏、外交成果分成、商会盟友、附属势力回礼或秘密库房。

失败后果：非常详细写。包括身份暴露、被杀、被俘、宗门关系恶化、外交破裂、情报泄露、卧底牺牲、家族被牵连、宗门否认、追责或灭口。原文未说明则写“原文未说明”。

追责方式：写清失败后宗门是否承认、是否救援、是否追责、是否销毁证据、是否惩罚泄密者或牺牲棋子。

对宗门的回流：写清获得情报、达成盟约、稳定附属势力、破坏敌宗、扩大商路、避免战争或准备战争。

相关人物关系：写清使者与目标势力、卧底与接头人、联姻对象、派系、上级长老之间的信任和风险。

升级或连锁任务：写清谈判失败引发战争、情报发现叛徒、卧底暴露引发营救、联姻引发派系争斗等后续。

结束方式：写清谈判完成、情报带回、身份暴露、任务中止、目标死亡、撤离成功或卧底转为长期潜伏。

后续影响：写清势力关系变化、角色身份变化、长期暗线形成、宗门战略改变、个人被信任或被牺牲。
