# 物资产出与消耗模板

> 最后更新：2026-06-17
> 状态：模板
> 类型：资源产出、流通、消耗、价值变化与风险调研
> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文只整理小说中明确出现过，或能由具体剧情支撑的资源产出、获得、流通、消耗和后续影响。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写经济抽象。
- 不写没有来源的价格表；价格只写原文明确出现的内容，没有就写相对贵贱、稀缺程度或“原文未说明”。
- 每个案例都要同时写产出和消耗，只写“获得宝物”“得到灵石”“找到材料”不算完整资源流转。
- 资源流转要尽量写清谁产出、谁获得、谁持有、怎么交易或转移、最终被谁消耗，以及消耗后造成什么变化。
- 灵石、贡献、战功、声望、人情、权限、情报、材料、丹药、法宝等不要混成同一种资源，要按作品实际写清差别。
- 主角资源流转要尽量完整；配角、宗门、家族、商会、坊市、邪修、妖族、战场等资源流转如果原文有清楚表现，也要补充。
- 原文没有说明数量、价格、持有者、流通渠道、消耗结果或价值变化时，不要补，可以写“原文未说明”。

## 参考范围（不局限于以下类别）

- **资源种类**：灵石、贡献、战功、丹药、灵草、矿材、妖兽材料、法宝、符箓、阵盘、功法、情报、声望、人情、洞府权限。
- **产出来源**：灵矿、灵脉、药园、野外采集、猎妖掉落、秘境收获、任务奖励、宗门俸禄、拍卖收益、战争掠夺、贡赋、商贸套利、代工报酬、传承遗产。
- **获得者**：个人、队伍、宗门、家族、商会、坊市、散修、邪修、妖族、战场胜方、继承者、截杀者。
- **流通方式**：坊市、拍卖会、宗门兑换、黑市、商会、悬赏、战利品分配、以物易物、高阶私下交易、师徒赠予、上交宗门。
- **消耗去向**：日常修炼、突破、疗伤、法宝购买、法宝维修、法宝升级、符箓消耗、阵法维护、洞府租赁、传送、情报购买、悬赏、战争、弟子培养。
- **价值变化**：低阶资源贬值、高阶资源稀缺、地域价差、境界替换、紧急溢价、拍卖溢价、战争涨价、稀缺材料刚需。
- **风险代价**：财富暴露、被劫道、黑吃黑、假货、宗门克扣、税贡、交易欺诈、携带成本、资源过期、药性流失、被通缉追杀。
- **后续影响**：修为提升、突破失败、关系变化、势力库存变化、任务奖励变化、物价变化、争夺升级、通缉追杀、势力资源再分配。

## 完整资源流转案例

### 案例 1：灵石资源流转

资源类型：货币 / 灵石。

产出来源：灵矿开采、任务奖励、宗门俸禄、战利品分配、拍卖收益、商贸交易或截杀掠夺；具体来源按原文填写。

获得者：写清谁获得灵石，是个人、队伍、宗门、家族、商会、散修还是截杀者；如果有分配比例或上交要求，也要写清。

流通方式：灵石可用于坊市交易、拍卖竞价、宗门兑换、黑市购买、情报购买、洞府租赁、传送费用、雇佣他人等；按原文出现的方式填写。

消耗去向：灵石被用于日常修炼、购买丹药、购买材料、租借洞府、支付传送、参与拍卖、交纳贡赋或维持阵法。

价值变化：低阶灵石在高境界阶段可能购买力不足，高阶灵石或稀缺灵石可能更保值；地域价差、拍卖溢价、战乱涨价按原文填写。

风险代价：灵石数量暴露可能引来跟踪、劫道、黑吃黑、勒索、宗门克扣或商会压价；携带大量灵石也可能增加逃亡和交易风险。

后续影响：灵石消耗后可能带来修为提升、突破准备、法宝购置、交易成功，也可能因财富暴露引发截杀、通缉、结仇或势力介入。

### 案例 2：灵草与丹药资源流转

资源类型：材料 / 灵草 / 丹药。

产出来源：药园种植、野外采集、秘境采摘、妖兽守护灵药、宗门任务奖励、拍卖购得、炼丹师炼制或战利品获得。

获得者：写清采摘者、守护者、炼丹师、购买者、宗门、队伍或截杀者是谁；如果有多人争夺或分配，要写清分配结果。

流通方式：灵草可上交宗门、交给炼丹师代炼、进入坊市或拍卖会、私下交易、作为报酬赠予，也可能被直接吞服。

消耗去向：灵草被炼成丹药、直接服用、用于疗伤、突破、解毒、续命、喂养灵兽或交换其他资源；丹药再被角色服用或转卖。

价值变化：成熟年份、稀缺程度、用途刚需、炼丹成功率和丹药品阶都会影响价值；原文未说明具体价格时写相对稀缺性。

风险代价：灵草成熟地可能有妖兽、禁制、敌人和队友背叛；丹药可能失败、药性不足、反噬、引来争夺或暴露炼丹能力。

后续影响：资源消耗后可能促成修为突破、伤势恢复、寿元延长、毒性解除，也可能因炼丹失败、分配不均、灵草暴露引发冲突。

### 案例 3：妖兽材料资源流转

资源类型：材料 / 妖兽尸骸 / 妖丹 / 皮骨血肉。

产出来源：猎妖、兽潮、秘境战斗、宗门任务、妖兽互斗、修士截杀妖兽或战场清理。

获得者：写清击杀者、队伍、宗门、商会、炼器师、炼丹师或旁观捡漏者；如果有人抢夺尸体或妖丹，要写清结果。

流通方式：妖兽材料可出售给坊市、商会、炼器师、炼丹师，也可上交宗门兑换贡献，或被角色自用炼器、炼丹、制符。

消耗去向：妖丹用于炼丹、修炼、喂养灵兽或特殊功法；皮骨用于炼器、防具、阵法材料；血肉可能用于药浴、饲养或恢复。

价值变化：妖兽阶位、稀有血脉、材料完整度、需求场景和地域差异决定价值；高阶妖兽材料通常更稀缺也更容易引发争夺。

风险代价：猎妖有死亡风险，材料携带会暴露战利品，妖兽族群可能报复，高阶材料可能引来强者、商会压价或黑市截杀。

后续影响：妖兽材料消耗后可能带来法宝升级、丹药炼成、贡献增加、任务完成，也可能引发兽潮、妖族仇怨或修士之间的分赃冲突。

### 案例 4：宗门贡献与权限流转

资源类型：贡献 / 战功 / 权限 / 宗门资源。

产出来源：完成宗门任务、猎妖上交、采药上交、守卫边境、参加战争、完成炼丹炼器委托、立功、救援同门或发现秘境线索。

获得者：宗门弟子、长老、任务队伍、战场幸存者或提供关键情报者；如果宗门克扣、分配不公或按职位分配，要写清。

流通方式：贡献通常在宗门内部兑换功法、丹药、材料、洞府、护法资源、任务资格、传送资格或秘境名额。

消耗去向：角色消耗贡献换取修炼资源、突破资源、法宝材料、进入秘境资格、闭关地点、师长指点或宗门保护。

价值变化：不同境界对贡献的需求不同；低阶贡献可能只能换基础资源，高阶资源需要更多贡献、身份权限或额外功劳。

风险代价：贡献获取可能伴随危险任务、宗门派系斗争、被同门抢功、任务失败惩罚、贡献被扣或被迫承担额外义务。

后续影响：贡献消耗后可能带来修炼加速、突破准备、身份提升、师承变化，也可能因资源名额争夺引发同门矛盾和势力站队。
