# 物资产出与消耗模板

## 适用范围

本模板用于整理作品中由原文明确出现或直接支撑的资源产出、获得、持有、分配、流通、消耗、兑现和后续影响。

本模板关注“资源如何进入角色或势力手中，又如何被使用、交换、兑现或消耗，并改变修炼、交易、战争、关系或势力格局”。资源可以是灵石、金币、贡献、战功、丹药、灵草、矿材、妖兽材料、法宝器物、符箓、功法典籍、情报服务、权限名额、人情承诺、洞府资格、拍卖收益、战争缴获等。

本模板不整理纯剧情事件、普通人物出场、心理危机、身份变化本身、单纯移动、单次对话或没有资源状态变化的道具描写。若某个身份、名额、资格或人情确实打开了资源机会，才按“权限/人情资源”整理，并写清它被如何获得、兑现或消耗。

## 整理原则

1. 先做资源边界判定
   只有参与了产出、获得、持有、分配、交易、上交、炼制、学习、租用、兑现、消耗或改变资源格局的对象，才可建立物资流转卡。
   灵石、金币、贡献、战功、丹药、灵草、矿材、妖兽材料、法宝、符箓、功法、情报、人情、洞府权限、秘境名额等可以入选；张铁失踪、墨大夫回谷带人、修炼进度检查与对峙、韩立留书外出等普通剧情节点不得写成物资卡。

2. 区分链条状态
   完整流转必须同时具备“产出/获得、持有/转移、消耗/兑现、后续影响”。只有获得而没有使用的资源，写为未闭环伏笔；只有世界经济规则而没有具体流转对象的内容，写为体系背景；非资源内容直接排除。
   例如心魔入侵若没有明确消耗平安符，不应写成完整物资闭环；炼药师地位、道书黑市规则、拍卖制度可以作为体系背景，不与完整流转卡混在同一层级。

3. 完整链条优先
   每张完整流转卡都要写清资源从哪里来、谁拿到、怎样流通、最终被谁消耗或兑现，以及消耗后造成什么变化。
   小绿瓶绿液从产出、保存失败、催熟三乌草、配制黄龙丹/清灵散/金髓丸/养精丹到服用突破，属于完整资源链；筑基灵液从购买低级材料、药老炼制、拍卖场鉴定拍卖、金币回流到再采购材料，也应按同一资源循环整理。

4. 功法、权限和人情不硬套“消耗品”
   功法典籍、斗气阁选择权、秘境名额、洞府权限、传送资格、人情承诺等不是普通消耗品，但可以写成资源流转。
   消耗去向应写“学习后形成传承”“占用选择权”“兑换机会被使用”“承诺被兑现”“权限开启新场景”等，不要硬写成物品被吃掉或用完。

5. 合并重复阶段
   同一资源在同一条循环中的采购、炼制、鉴定、拍卖、结算、再投入，应合并到一张卡的“流转阶段”中。
   例如低品质筑基灵液炼制、七瓶筑基灵液批量炼制、七瓶拍卖现场和七瓶结算，不应拆成互相孤立的多张卡；小绿瓶的产液、阴雨延迟、保存限制和催熟效果，也应按阶段归入同一条资源链。

6. 差异化取样
   同类资源或使用方式相同的资源，不要全部逐条成卡；优先提取能体现不同来源、不同流通方式、不同消耗结果、不同风险代价或不同后续影响的重要样本。
   如果多个丹药都只是日常修炼服用，多个灵石交易都只是普通购买，多个材料都以相同方式用于炼制，可合并为一张类型卡或归入同一链条阶段；只有来源、价格、渠道、用途、结果或影响明显不同，才单独成卡。

7. 数量、价格和稀缺度按原文填写
   明确数额要保留，例如四万金币、二十八万五千金币、十万金币、纹银三百两、米谷五百斤、二十三粒致和丹等。
   原文没有数量、价格、税费、价值变化或稀缺程度时，写“原文未说明”；不要用常识补齐境界价格、市场行情或消耗数量。

8. 控制叙事噪声
   字段只写资源流转需要的信息，不长篇复述人物外貌、场景气氛、吵架过程、战斗招式或心理描写。
   后续影响应落在修为提升、突破失败、库存变化、资金回流、关系改变、争夺升级、任务结算、势力资源再分配等资源后果上。

9. 覆盖不同资源类型
   整理时不要只写主角资源或最早出现的名场面。应兼顾货币、丹药、材料、功法、法宝、符箓、权限、情报、人情、拍卖收益、战争缴获等不同类型。
   暖阳宝玉、引魂钟、金光上人相关符纸/法器、金纹符书、耋寿拂尘、降浊鼎、灵贝、灵贝玉液等后续资源，出现时也要判断是否形成流转、伏笔或体系背景。

10. 区分事实、未说明和推断
   原文明确出现的产出、数量、价格、用途、效果和归属按事实写；原文没有交代的持有者、后续用途、最终归属、价值变化和影响写“原文未说明”。
   若需要做有限归纳，应放在“推断说明”中，并说明是哪一项存在推断，不能把推断写成确定事实。

11. 输出自检
   输出后检查是否存在纯剧情事件成卡、未消耗伏笔冒充完整闭环、同一资源重复建卡、体系背景混入完整流转卡、价格数量无原文支撑、字段被剧情复述塞满、重要资源类型明显缺漏等问题。

## 字段说明

- 整理范围：写本次整理覆盖的是全书、当前提供材料、指定篇幅或用户指定材料。
- 资源/事件名称：一句话概括资源流转对象或资源循环，不要只写人物名。
- 链条状态：写完整闭环、未闭环伏笔、仅产出、仅消耗、体系背景。完整闭环必须有产出/获得、持有/转移、消耗/兑现和后续影响。
- 资源边界判定：写为什么属于物资资源、权限资源、情报服务、人情关系或体系背景；若只是普通剧情节点，不建卡。
- 资源类型：写货币、贡献/战功、丹药、灵液、灵草、矿材、妖兽材料、法宝器物、符箓、功法典籍、权限名额、情报服务、人情承诺、拍卖收益等。
- 产出者与产出渠道：写资源由谁产出或从何处出现，如灵矿、药园、野外采集、猎妖掉落、秘境收获、炼制、拍卖、任务、俸禄、战争掠夺、商贸套利、传承遗留等。
- 获得者、持有者与分配：写谁获得、谁暂时持有、是否上交、如何分配，以及最终掌握在谁手中。
- 流通方式：写坊市、拍卖会、宗门兑换、黑市、商会收购、悬赏、战利品分配、以物易物、师徒赠予、上交宗门、私下交易等。
- 消耗者与消耗去向：写谁使用或兑现资源，用于修炼、突破、疗伤、购买、炼制、维修、升级、制符、阵法维护、洞府租赁、传送、情报购买、战争、培养弟子、学习功法、开启权限等。
- 数量/价格/稀缺度：写明确数量、价格、税费、价值等级、相对贵贱、稀缺程度；没有说明时写“原文未说明”。
- 价值变化：写低阶资源贬值、高阶资源稀缺、地域价差、紧急溢价、拍卖溢价、战争涨价、加工增值、药性流失、材料完整度变化等。
- 风险代价：写财富暴露、劫道、黑吃黑、假货、克扣、税费、欺诈、携带成本、保存失败、过期失效、分赃冲突、通缉追杀等。
- 流转阶段：复杂链条按第1阶段、第2阶段、第3阶段展开；每个阶段写产出/获得、流通/持有、消耗/兑现和阶段影响。简单链条可写“原文未分阶段”。
- 后续影响：写资源消耗或兑现后的修为变化、突破结果、库存变化、资金回流、关系变化、任务奖励变化、物价变化、争夺升级、势力资源再分配等。
- 未说明项：集中列出原文未交代的数量、价格、持有者、用途、后果、价值变化或归属。
- 推断说明：写无；或写哪些内容属于归纳推断，避免与原文事实混写。

    - 产出/获得：水月滟沉沙、玉圭沙等珍稀材料进入交换链。
    - 流通/持有：材料在求解者与解读者之间流转。
    - 消耗/兑现：材料用于答谢、换书或换取知识服务。
    - 阶段影响：普通服务交易升级为稀缺材料和名声牵连。
- 后续影响：解读名声、资源交换和世家压力继续引出后续冲突。

### 致和丹赌约

- 链条状态：完整闭环
- 资源边界判定：致和丹以明确数量和价值进入赌约，属于丹药资源和约战筹码。
- 资源类型：丹药 / 赌约筹码 / 修炼辅助资源
- 产出者与产出渠道：致和丹来源原文未说明。
- 获得者、持有者与分配：卞桥持有二十三粒致和丹，并将其作为赌约筹码。
- 流通方式：赌约交换。
- 消耗者与消耗去向：赌约胜负决定致和丹归属；丹药可用于辟谷养生、固本培元、活血通脉等。
- 数量/价格/稀缺度：二十三粒致和丹；每粒价值千金。
- 价值变化：丹药从持有资源转为约战筹码，价值与胜负关系绑定。
- 风险代价：败者可能失去丹药或承担自散修为、下山等代价。
- 流转阶段：
  - 第1阶段：
    - 产出/获得：卞桥拿出二十三粒致和丹。
