# 物资产出与消耗模板

## 适用范围

用于整理作品中明确出现过，或能由原文、资料来源和可靠依据支撑的资源产出、获得、流通、消耗和后续影响。

本模板不写总览、项目字段映射或经济抽象；重点是资源怎样从来源进入角色或势力，又怎样被消耗并改变局势。

## 前置声明

- 样本尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角或少数成功案例。
- 每个案例都要同时写产出和消耗；只写“获得宝物”“得到灵石”不算完整资源流转。
- 价格只写原文明确内容；没有价格时写相对贵贱、稀缺程度或“原文未说明”。
- 灵石、贡献、战功、声望、人情、权限、情报、材料、丹药、法宝等要按作品实际区分，不要混成一种资源。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法提示 |
|------|----------|
| 资源类型 | 写灵石、贡献、战功、丹药、灵草、矿材、妖兽材料、法宝、符箓、阵盘、功法、情报、声望、人情、洞府权限等。 |
| 产出来源 | 写灵矿、药园、野外采集、猎妖、秘境、任务奖励、俸禄、拍卖、战争、贡赋、代工、传承遗产等。 |
| 获得与持有 | 写谁获得、谁持有、是否上交、如何分配，涉及个人、队伍、宗门、家族、商会、坊市、散修、邪修、妖族等。 |
| 流通方式 | 写坊市、拍卖会、宗门兑换、黑市、商会、悬赏、战利品分配、以物易物、师徒赠予等。 |
| 消耗去向 | 写修炼、突破、疗伤、购买、维修、升级、制符、阵法维护、洞府租赁、传送、情报购买、战争、弟子培养等。 |
| 价值变化 | 写地域价差、境界替换、紧急溢价、拍卖溢价、战争涨价、高阶稀缺、材料刚需等。 |
| 风险代价 | 写财富暴露、劫道、黑吃黑、假货、克扣、税贡、欺诈、携带成本、药性流失、通缉追杀等。 |
| 后续影响 | 写修为提升、突破失败、关系变化、库存变化、物价变化、争夺升级、势力资源再分配等。 |
| 来源依据 | 写原文位置、资料来源或可靠依据；没有说明的字段写“原文未说明”。 |

常见类型提示：

| 类型 | 示例 | 重点 |
|------|------|------|
| 货币流转 | 灵石、灵晶、贡献、战功 | 谁产出、谁分配、怎么交易、最终买了什么。 |
| 材料流转 | 灵草、矿材、妖兽皮骨、妖丹 | 采集/猎取风险、加工方式、炼丹炼器后的去向。 |
| 权限流转 | 洞府、秘境名额、传送资格、宗门兑换资格 | 权限如何获得，消耗后打开了什么机会。 |
| 情报/人情流转 | 线索、地图、承诺、庇护 | 信息或关系如何变现，是否带来后续牵连。 |

## 案例

### 案例

| 案例方向 | 最小写法示例 | 不可漏写的重点 |
|----------|--------------|----------------|
| 灵石资源流转 | 灵石来自灵矿、任务、俸禄、拍卖或战利品；经坊市、拍卖、宗门兑换或黑市流通；被用于修炼、购买丹药、租洞府、传送或维持阵法。 | 产出者、获得者、持有者、消耗者、价格或稀缺度、财富暴露风险、消耗后的变化。 |
| 灵草与丹药流转 | 灵草来自药园、秘境、野外或任务；可上交、代炼、出售、直接吞服；炼成丹药后用于突破、疗伤、解毒、续命或转卖。 | 成熟年份、守护风险、分配结果、炼制成败、药性后果、争夺或关系变化。 |
| 妖兽材料流转 | 妖兽尸骸、妖丹、皮骨血肉来自猎妖、兽潮、秘境或战场；可出售、上交、炼器、炼丹、制符或喂养灵兽。 | 击杀者、分赃、材料完整度、阶位价值、携带风险、妖族报复或后续争夺。 |
| 宗门贡献与权限流转 | 贡献来自任务、战争、上交材料、救援同门或提供线索；可兑换功法、丹药、洞府、秘境资格或护法资源。 | 宗门分配规则、克扣或抢功、身份权限、兑换后的修炼或关系变化。 |
