# 物资产出与消耗模板

# 规范

## 参考和要求

- 整理范围：写作品中明确出现过，或能由原文内容直接支撑的资源产出、获得、流通、消耗和后续影响。
- 模板边界：不写总览、项目字段映射或经济抽象；重点写资源怎样进入角色或势力，又怎样被消耗并改变局势。
- 覆盖要求：样本尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界、少数名场面或少数成功案例。
- 完整流转：每个案例都要同时写产出和消耗；只写“获得宝物”“得到灵石”不算完整资源流转。
- 价格写法：价格只写原文明确内容；没有价格时写相对贵贱、稀缺程度或“原文未说明”。
- 资源区分：灵石、贡献、战功、声望、人情、权限、情报、材料、丹药、法宝等要按作品实际区分，不要混成一种资源。
- 流转链条：尽量写清谁产出、谁获得、谁持有、怎么交易或转移、最终被谁消耗，以及消耗后造成什么变化。
- 角色范围：主角资源流转要尽量完整；配角、宗门、家族、商会、坊市、散修、邪修、妖族、战场等资源流转如果原文有清楚表现，也要补充。
- 未说明处理：原文没有说明数量、价格、持有者、流通渠道、消耗结果或价值变化时，不要补，可以写“原文未说明”。
- 待定处理：信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充后，足以成例再转入 `### 案例`。
- 资源类型：写灵石、灵晶、贡献、战功、丹药、灵草、矿材、妖兽材料、法宝、符箓、阵盘、功法、情报、声望、人情、洞府权限等。
- 产出渠道：写灵矿、灵脉、药园、野外采集、猎妖掉落、秘境收获、任务奖励、俸禄、拍卖收益、战争掠夺、贡赋、商贸套利、代工报酬、传承遗产等。
- 获得与持有：写谁获得、谁持有、是否上交、如何分配，涉及个人、队伍、宗门、家族、商会、坊市、散修、邪修、妖族、战场胜方、继承者、截杀者等。
- 流通方式：写坊市、拍卖会、宗门兑换、黑市、商会、悬赏、战利品分配、以物易物、高阶私下交易、师徒赠予、上交宗门等。
- 消耗去向：写修炼、突破、疗伤、购买、维修、升级、制符、阵法维护、洞府租赁、传送、情报购买、悬赏、战争、弟子培养等。
- 价值变化：写低阶资源贬值、高阶资源稀缺、地域价差、境界替换、紧急溢价、拍卖溢价、战争涨价、材料刚需等。
- 风险代价：写财富暴露、劫道、黑吃黑、假货、克扣、税贡、欺诈、携带成本、资源过期、药性流失、通缉追杀等。
- 后续影响：写修为提升、突破失败、关系变化、库存变化、任务奖励变化、物价变化、争夺升级、通缉追杀、势力资源再分配等。
- 货币流转：包括灵石、灵晶、贡献、战功等，重点写谁产出、谁分配、怎么交易、最终买了什么。
- 材料流转：包括灵草、矿材、妖兽皮骨、妖丹等，重点写采集或猎取风险、加工方式、炼丹炼器后的去向。
- 权限流转：包括洞府、秘境名额、传送资格、宗门兑换资格等，重点写权限如何获得，消耗后打开了什么机会。
- 情报/人情流转：包括线索、地图、承诺、庇护等，重点写信息或关系如何变现，是否带来后续牵连。

## 案例

### 案例

```md
# 《作品名》物资产出与消耗

## 物资流转卡片

### 资源或流转事件名称

- 资源类型：
- 产出渠道：
- 获得与持有：
- 流通方式：
- 消耗去向：
- 价格/稀缺度：
- 价值变化：
- 风险代价：
- 后续影响：

### 灵石资源流转

- 资源类型：灵石、灵晶、贡献、战功等，按作品设定填写
- 产出渠道：灵矿、任务、俸禄、拍卖或战利品
- 获得与持有：写产出者、获得者、持有者和分配结果
- 流通方式：坊市、拍卖、宗门兑换、黑市或私下交易
- 消耗去向：修炼、购买丹药、租洞府、传送或维持阵法
- 价格/稀缺度：写明确价格；没有价格时写相对贵贱、稀缺程度或“原文未说明”
- 价值变化：低阶资源贬值、高阶资源稀缺、地域价差或紧急溢价，按作品设定填写
- 风险代价：财富暴露、劫道、黑吃黑、克扣或携带成本
- 后续影响：资源消耗后的修为变化、库存变化、关系变化或局势变化

### 灵草与丹药流转

- 资源类型：灵草、丹药、药材年份或炼丹材料
- 产出渠道：药园、秘境、野外采集或任务奖励
- 获得与持有：写采集者、守护者、上交对象、代炼对象和最终持有者
- 流通方式：上交、代炼、出售、直接吞服、宗门兑换或坊市交易
- 消耗去向：突破、疗伤、解毒、续命、转卖或培养弟子
- 价格/稀缺度：写成熟年份、阶位价值、稀缺程度或“原文未说明”
- 价值变化：炼制成败、药性保留、紧急需求或境界替换带来的价值变化
- 风险代价：采集风险、守护妖兽、药性流失、炼丹失败或争夺冲突
- 后续影响：突破结果、伤势变化、关系变化、库存变化或后续争夺

### 妖兽材料流转

- 资源类型：妖兽尸骸、妖丹、皮骨血肉、妖兽材料
- 产出渠道：猎妖、兽潮、秘境或战场
- 获得与持有：写击杀者、分赃结果、上交对象和最终持有者
- 流通方式：出售、上交、战利品分配、商会收购或以物易物
- 消耗去向：炼器、炼丹、制符、喂养灵兽或任务交付
- 价格/稀缺度：写阶位价值、材料完整度、稀缺程度或“原文未说明”
- 价值变化：材料完整度、阶位差异、战争需求或加工成品带来的价值变化
- 风险代价：携带风险、妖族报复、分赃冲突或后续追杀
- 后续影响：法宝炼制、丹药产出、关系变化、争夺升级或势力资源再分配

### 宗门贡献与权限流转

- 资源类型：宗门贡献、战功、洞府权限、秘境名额、兑换资格
- 产出渠道：任务、战争、上交材料、救援同门或提供线索
- 获得与持有：写完成者、登记者、分配规则和实际持有者
- 流通方式：宗门兑换、任务结算、身份授予、名额分配或内部转让
- 消耗去向：兑换功法、丹药、洞府、秘境资格或护法资源
- 价格/稀缺度：写兑换成本、名额稀缺程度、身份门槛或“原文未说明”
- 价值变化：境界提升、任务难度、战争局势或宗门规则变化导致的价值变化
- 风险代价：克扣、抢功、身份限制、名额争夺或宗门惩罚
- 后续影响：修炼条件变化、师门关系变化、资源再分配或后续任务变化
```

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
