# 妖兽与修士关系分析模板

# 规范

本模板用于整理妖兽、灵兽、凶兽、异兽、灵虫、虫群、化形妖修、妖族势力与人族修士之间的长期关系、互动模式和事件闭环。

本模板重点写关系：谁主动、谁被动、为什么互动、如何触发、如何升级、如何结束，以及产生什么资源、仇怨、任务、交易、契约或长期后果。单个妖兽的能力、掉落、弱点、特殊用途和生态细节，放入 `妖兽分析模板.md`。

整理时应覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角、单一关系或少数成功案例。只整理原文有可靠依据的内容，原文没有说明的参与方、主动方、触发原因、互动流程、资源流向、升级条件、结束方式或后续影响，写“原文未说明”。

同一妖兽可以多次出现，但每次应对应不同关系，例如“被猎杀”“被契约”“引发兽潮”“化形后建势力”。原文中有关系价值的人妖互动、猎妖闭环、驯养制度、妖族冲突或资源循环，都应继续补充。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 关系类型：猎杀、被猎杀、守药冲突、领地冲突、驯化、契约、灵宠、坐骑、护山兽、交易、供奉、复仇、兽潮、共同守护、妖族建势力。
- 参与方：修士、宗门、商会、坊市、猎妖队伍、驯兽师、妖兽个体、妖兽族群、化形妖修、妖族势力、第三方。
- 触发原因：资源争夺、修炼材料、妖丹、妖核、灵药、矿脉、秘境、兽潮、幼兽、血脉、仇怨、护族、宗门任务、商会收购。
- 互动方向：修士主动猎妖、妖兽主动袭击、双方互相忌惮、长期交易、主人与灵宠、宗门与护山兽、妖族与宗门战争。
- 互动流程：发现、侦查、接任务、组队、捕捉、猎杀、交易、契约、守护、报复、谈判、停战或长期共处。
- 资源闭环：妖兽产出、猎妖任务、战利品处理、材料交易、宗门奖励、坊市买卖、灵宠培养、妖兽尸骸机会点。
- 关系升级：复仇、兽潮、通缉、宗门围剿、妖族报复、领地封锁、资源点易主、契约反噬、灵兽失控。
- 关系限制：契约代价、驯养条件、忠诚风险、血脉压制、灵智差异、化形后身份变化、族群规矩、人妖阵营边界。
- 长期后果：资源循环、仇怨延续、任务链、势力战争、生态失衡、修士暴富露财、妖族迁徙、区域危险等级变化。
