# 妖兽与修士关系分析模板

## 适用范围

本模板适用于妖兽生态、人妖关系、猎妖资源闭环调研。最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

- 本文用于整理妖兽、灵兽、凶兽、异兽、灵虫、虫群、化形妖修、妖族势力与人族修士之间的长期关系、互动模式和事件闭环。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 本文不重复整理单个妖兽的完整能力、掉落、弱点、特殊用途和生态细节；这些放入 `妖兽分析模板.md`。
- 本文重点写关系：谁主动、谁被动、为什么互动、如何触发、如何升级、如何结束、产生什么资源、仇怨、任务、交易、契约或长期后果。
- 同一妖兽可以在本文出现多次，但每次应对应不同关系，例如“被猎杀”“被契约”“引发兽潮”“化形后建势力”等。
- 文档长度不是问题；只要原文出现过有关系价值的人妖互动、猎妖闭环、驯养制度、妖族冲突或资源循环，就应尽量记录。
- 原文没有说明参与方、主动方、触发原因、互动流程、资源流向、升级条件、结束方式或后续影响时，不要补，可以写“原文未说明”。

## 必须写什么

- **关系类型**：猎杀、被猎杀、守药冲突、领地冲突、驯化、契约、灵宠、坐骑、护山兽、交易、供奉、复仇、共同守护、妖族建势力。
- **触发原因**：资源争夺、修炼材料、妖丹、妖核、灵药、矿脉、秘境、兽潮、幼兽、血脉、仇怨、护族、宗门任务、商会收购。
- **互动方向**：修士主动猎妖、妖兽主动袭击、双方互相忌惮、长期交易、主人与灵宠、宗门与护山兽、妖族与宗门战争。
- **资源闭环**：妖兽产出、猎妖任务、战利品处理、材料交易、宗门奖励、坊市买卖、灵宠培养、妖兽尸骸机会点。
- **关系升级**：复仇、兽潮、通缉、宗门围剿、妖族报复、领地封锁、资源点易主、契约反噬、灵兽失控。
- **关系限制**：契约代价、驯养条件、忠诚风险、血脉压制、灵智差异、化形后身份变化、族群规矩、人妖阵营边界。
- **长期后果**：资源循环、仇怨延续、任务链、势力战争、生态失衡、修士暴富露财、妖族迁徙、区域危险等级变化。

## 案例

### 案例

#### 案例 1：修士猎妖与资源回收

关系名：写具体关系或事件名称，例如“散修猎杀低阶妖兽换取材料（修士主动猎妖）”。

关系类型：猎杀 / 被猎杀 / 猎妖任务 / 材料回收 / 悬赏狩猎；按原文填写。

参与方：写清参与的修士、队伍、宗门、商会、妖兽、妖兽族群或中间人。

主动方：写清是修士主动寻猎、宗门发布任务、商会收购驱动，还是妖兽先袭击后被反杀。

被动方：写清被猎杀妖兽、族群、幼兽、王兽或其守护资源；如妖兽并非被动，也要写清反击方式。

触发原因：写清为什么发生猎妖，例如需要妖丹、妖骨、妖兽皮、毒囊、精血、宗门任务、坊市悬赏、突破材料或自保。

发生地点：写清山脉、森林、海域、秘境外围、药园、矿脉、商路、宗门周边、妖兽领地或坊市附近。

互动流程：详细写清修士如何获得消息，如何接任务或组队，如何寻找妖兽，如何设伏、交战、收尸、分配战利品、交付任务或出售材料。

资源流向：写清妖兽尸体、妖丹、皮骨、精血、毒囊、灵虫卵等资源流向谁，进入炼丹、炼器、宗门库存、坊市交易还是个人修炼。

关系变化：写清猎杀后是否形成仇怨、惊动族群、引起妖兽迁徙、改变修士名声或触发后续追杀。

风险与代价：写清受伤、死亡、误入领地、材料被抢、战利品分赃、被妖兽族群报复、暴露财富或被黑吃黑。

升级条件：写清什么情况下会从普通猎妖升级为兽潮、宗门围剿、族群复仇、资源点争夺或跨势力冲突。

结束方式：写清妖兽被杀、修士撤退、任务交付、材料售出、族群迁走、仇怨暂止或冲突扩大。

后续影响：写清角色获得资源、提升修为、被盯上、宗门库存增加、坊市价格变化、区域妖兽减少或危险升级。

与妖兽分析的关联：只写关联妖兽名称和需要另查的本体信息，例如“该妖兽能力、掉落、弱点见《作品名》妖兽分析”；不要在本文重复妖兽百科。

#### 案例 2：妖兽守药 / 守矿 / 守巢冲突

关系名：写具体资源守护关系，例如“妖兽守护灵药，修士偷采引发冲突”。

关系类型：守药冲突 / 守矿冲突 / 守巢冲突 / 资源点争夺 / 领地入侵。

参与方：写清守护资源的妖兽或族群、采集修士、宗门队伍、商会队伍、散修、妖兽幼崽或第三方抢夺者。

主动方：写清是修士主动进入资源点，还是妖兽主动驱赶入侵者。

被动方：写清被侵入的一方、被偷采的一方、被惊扰的幼兽或被卷入的第三方。

触发原因：写清灵药成熟、矿脉发现、巢穴暴露、秘境开放、商会收购、修士缺材料、妖兽护幼或族群护地。

发生地点：写清药园、灵草谷、矿脉、妖兽巢穴、秘境资源区、山洞、灵泉、沼泽或特殊地形。

互动流程：详细写清修士如何发现资源，如何侦查守护妖兽，如何引开、偷采、围攻或谈判，妖兽如何守护、追击、呼唤族群或报复。

资源流向：写清灵药、矿石、妖兽材料、幼兽、兽卵、巢穴资源最终归谁，是否进入拍卖、炼丹、炼器或宗门任务。

关系变化：写清妖兽是否记仇、族群是否迁移、资源点是否易主、修士是否被标记、当地生态是否改变。

风险与代价：写清偷采失败、被妖兽追杀、被其他修士截胡、资源未成熟、误伤幼兽、引来王兽或触发兽潮。

升级条件：写清资源价值过高、妖兽族群强大、修士反复侵入、幼兽被杀、守护兽被灭时如何升级。

结束方式：写清资源被采、妖兽被杀、双方撤退、达成供奉/交易、资源点封锁或宗门接管。

后续影响：写清资源争夺引发任务、拍卖、复仇、宗门介入、妖兽迁徙、区域危险提升或长期领地冲突。

与妖兽分析的关联：只写守护妖兽和资源名称，妖兽本体能力、掉落和特殊用途放 `妖兽分析模板.md`。

#### 案例 3：灵宠 / 坐骑 / 契约兽关系

关系名：写具体灵宠、坐骑、契约兽、护主妖兽或虫群控制关系名称。

关系类型：契约 / 灵宠 / 坐骑 / 护主 / 驯化 / 虫群控制 / 主仆关系 / 伙伴关系。

参与方：写清主人、妖兽、灵兽、虫群、驯兽师、宗门、家族、商会或原族群。

主动方：写清是修士主动捕捉、妖兽主动认主、宗门赐予、商会交易、族群交换，还是共同经历后形成关系。

被动方：写清被契约妖兽、被捕捉幼兽、原族群、主人或被迫接受契约的一方。

触发原因：写清修士需要战斗伙伴、坐骑、护主、寻宝、血脉培养、特殊用途、虫群控制或宗门奖励。

发生地点：写清野外捕捉地、灵兽园、拍卖场、宗门、秘境、妖兽巢穴、商会或驯兽场。

互动流程：详细写清如何发现妖兽，如何捕捉、交换、购买、认主、立契、培养、喂养、训练、共同战斗或解除关系。

资源流向：写清修士投入丹药、饲料、材料、灵石、功法，妖兽提供战力、坐骑、寻宝、护主、产出或特殊用途。

关系变化：写清从敌对到认主、从工具到伙伴、忠诚提升、反噬、背叛、灵智提升、化形后关系改变。

风险与代价：写清契约反噬、忠诚不足、饲养成本、主人死亡、灵兽失控、原族群追索、被敌人夺取或情感牵绊。

升级条件：写清妖兽进阶、主人突破、共同战斗、血脉觉醒、契约改变、化形或灵智提升时关系如何变化。

结束方式：写清灵兽死亡、解除契约、背叛、放归族群、转赠、传承给后人、化形独立或反客为主。

后续影响：写清主人战力变化、行动范围扩大、被妖族盯上、形成伙伴羁绊、引发复仇或改变修士身份。

与妖兽分析的关联：只写妖兽名称、契约方式和关系变化；妖兽能力、特殊用途、弱点、产出另见 `妖兽分析模板.md`。

#### 案例 4：宗门豢养 / 护山兽 / 灵兽园

关系名：写具体宗门豢养体系、护山兽、灵兽园、族群供养或宗门守护关系名称。

关系类型：宗门豢养 / 护山兽 / 灵兽园 / 族群供奉 / 宗门守护 / 灵兽资源循环。

参与方：写清宗门、家族、灵兽园管理者、护山兽、妖兽族群、弟子、饲养者和外敌。

主动方：写清是宗门主动豢养、妖兽主动依附、祖辈约定、战败臣服、交易获得，还是长期共生。

被动方：写清被豢养妖兽、弟子、宗门、敌对入侵者或被牵连的周边族群。

触发原因：写清宗门需要守山、战力、坐骑、材料、试炼对象、传承象征、血脉资源或威慑敌人。

发生地点：写清灵兽园、山门、护宗大阵周边、药园、矿脉、宗门禁地、族群领地或饲养场。

互动流程：详细写清宗门如何获得妖兽，如何饲养，谁负责管理，如何训练或调遣，如何处理失控、繁殖、死亡和资源产出。

资源流向：写清宗门投入饲料、灵石、药材、洞府、保护，妖兽提供守卫、坐骑、幼崽、材料、试炼或威慑。

关系变化：写清妖兽忠诚、族群依附、宗门地位、弟子态度、护山兽进阶、管理者更替和失控风险。

风险与代价：写清灵兽暴走、饲养成本高、妖兽反噬、敌人策反、护山兽死亡、族群不满、弟子误伤。

升级条件：写清宗门被攻、护山兽死亡、灵兽园被盗、妖兽进阶、族群繁殖失控或资源断供时如何升级。

结束方式：写清契约解除、妖兽死亡、族群迁离、宗门覆灭、灵兽园关闭、护山兽叛逃或重新签订盟约。

后续影响：写清宗门防御变化、弟子任务变化、资源供应变化、妖兽关系恶化、兽潮风险或势力声望变化。

与妖兽分析的关联：本模板只写宗门与妖兽的制度关系；具体护山兽/灵兽本体信息放 `妖兽分析模板.md`。

#### 案例 5：妖兽复仇 / 兽潮 / 领地战争

关系名：写具体复仇、兽潮、领地冲突、族群战争或妖兽报复事件名称。

关系类型：复仇 / 兽潮 / 领地战争 / 妖兽报复 / 宗门围剿 / 区域灾害。

参与方：写清妖兽族群、妖王、受害修士、宗门、城池、商队、凡人、散修和第三方势力。

主动方：写清是妖兽主动复仇、修士先入侵导致报复、宗门主动围剿，还是资源点长期争夺升级。

被动方：写清被袭击的修士、宗门、城池、商路、凡俗村镇或妖兽族群。

触发原因：写清幼兽被杀、巢穴被毁、王兽被猎、资源被夺、领地被侵、修士屠戮、封印破裂或环境变化。

发生地点：写清山脉、城池外、宗门边境、商路、矿区、药园、妖兽领地、秘境出口或凡俗区域。

互动流程：详细写清冲突如何从小摩擦变成报复或兽潮，妖兽如何集结，修士如何预警、防御、求援、反攻或撤离。

资源流向：写清兽潮后尸骸、妖丹、战利品、损毁资源、救援物资、宗门奖励和区域资源点如何变化。

关系变化：写清人妖仇怨加深、领地重新划分、宗门加强防御、妖族迁徙、商路中断或形成长期禁区。

风险与代价：写清伤亡、资源损毁、城池被破、宗门弟子死亡、妖兽族群衰落、生态失衡和恐慌传播。

升级条件：写清妖王出手、高阶修士介入、宗门围剿失败、商路被断、凡俗受害或妖族联盟时如何升级。

结束方式：写清妖兽退去、妖王被杀、宗门赔偿、领地封锁、双方停战、迁徙、封印或持续拉锯。

后续影响：写清区域危险等级变化、任务增加、妖兽材料价格变化、仇怨延续、宗门声望变化和后续战争。

与妖兽分析的关联：只写复仇/兽潮关系和族群行为；具体兽群能力、掉落和特殊用途另查 `妖兽分析模板.md`。

#### 案例 6：化形妖修 / 妖族势力与人族关系

关系名：写具体化形妖修、人族宗门、妖族势力、妖王、异族部落或人妖联盟/敌对关系名称。

关系类型：化形交往 / 妖族势力 / 人妖交易 / 联盟 / 战争 / 联姻 / 互相忌惮 / 共同守护。

参与方：写清化形妖修、妖族族群、人族宗门、商会、修士个体、王朝、凡人势力或第三方敌人。

主动方：写清是妖族主动接触、人族主动谈判、商会中介、共同抗敌、资源争夺，还是某个化形妖修个人行动。

被动方：写清被结盟、被欺骗、被交易、被攻击、被保护或被卷入的人族/妖族一方。

触发原因：写清资源、领地、秘境、共同敌人、血脉传承、贸易、复仇、政治联姻、化形身份暴露或族群危机。

发生地点：写清妖族领地、人族城池、宗门边境、商路、秘境、禁地、王庭、坊市或中立场所。

互动流程：详细写清双方如何接触，如何试探、谈判、交易、结盟、背叛、开战、停战或长期共处。

资源流向：写清妖兽材料、灵药、矿脉、血脉资源、人族丹药、法宝、情报、庇护、领地和战力如何交换。
