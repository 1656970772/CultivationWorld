# 妖兽与修士关系分析模板

## 适用范围

本模板用于整理妖兽、灵兽、凶兽、异兽、灵虫、虫群、化形妖修、妖族势力与人族修士之间的长期关系、互动模式和事件闭环。

本模板重点写关系：谁主动、谁被动、为什么互动、如何触发、如何升级、如何结束，以及产生什么资源、仇怨、任务、交易、契约或长期后果。单个妖兽的能力、掉落、弱点、特殊用途和生态细节，放入 `妖兽分析模板.md`。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一关系或少数成功案例。
- 只整理原文有可靠依据的内容。原文未说明的参与方、主动方、触发原因、互动流程、资源流向、升级条件、结束方式或后续影响，写“原文未说明”。
- 案例只是最低写法示范，不是数量上限。原文中有关系价值的人妖互动、猎妖闭环、驯养制度、妖族冲突或资源循环，都可继续补充。
- 同一妖兽可以多次出现，但每次应对应不同关系，例如“被猎杀”“被契约”“引发兽潮”“化形后建势力”。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **关系类型**：猎杀、守药冲突、领地冲突、驯化、契约、灵宠、坐骑、护山兽、交易、供奉、复仇、兽潮、共同守护、妖族建势力。
- **参与方**：修士、宗门、商会、坊市、猎妖队伍、驯兽师、妖兽个体、妖兽族群、化形妖修、妖族势力、第三方。
- **触发原因**：资源争夺、妖丹、妖核、灵药、矿脉、秘境、幼兽、血脉、仇怨、护族、宗门任务、商会收购。
- **互动方向**：修士主动猎妖、妖兽主动袭击、双方互相忌惮、长期交易、主人与灵宠、宗门与护山兽、妖族与宗门战争。
- **互动流程**：发现、侦查、接任务、组队、捕捉、猎杀、交易、契约、守护、报复、谈判、停战或长期共处。
- **资源闭环**：妖兽产出、猎妖任务、战利品处理、材料交易、宗门奖励、坊市买卖、灵宠培养、尸骸机会点。
- **关系升级**：复仇、兽潮、通缉、宗门围剿、妖族报复、领地封锁、资源点易主、契约反噬、灵兽失控。
- **关系限制**：契约代价、驯养条件、忠诚风险、血脉压制、灵智差异、化形后身份变化、族群规矩、人妖阵营边界。
- **长期后果**：资源循环、仇怨延续、任务链、势力战争、生态失衡、暴富露财、妖族迁徙、区域危险等级变化。

**通用关系卡片：**

- **关系名和类型**：写具体事件或关系名称，并标明关系类型。
- **参与方**：写清修士、队伍、宗门、商会、妖兽、族群、妖族势力和第三方。
- **主动方与被动方**：写清谁先行动，谁被侵入、被猎杀、被契约、被交易、被保护或被卷入。
- **触发原因**：写清资源、任务、仇怨、领地、血脉、商会需求、宗门命令或共同敌人。
- **发生地点**：写清山脉、海域、秘境、巢穴、药园、矿脉、坊市、宗门、商路、边境或妖族领地。
- **互动流程**：按原文顺序写清发现、接触、冲突、谈判、交易、契约、战斗、追杀或停战。
- **资源流向**：写清妖兽材料、灵药、幼兽、灵石、丹药、法宝、情报、战利品或领地最终归谁。
- **关系变化**：写清敌对、合作、认主、背叛、复仇、族群迁徙、交易稳定或战争爆发。
- **风险与代价**：写清伤亡、饲养成本、契约反噬、身份暴露、被追索、资源损失、生态失衡。
- **升级条件**：写清什么情况会升级为兽潮、围剿、族群复仇、跨势力冲突、黑市争夺或长期战争。
- **结束方式**：写清猎杀完成、任务交付、交易结束、契约解除、双方撤退、停战、迁徙或冲突扩大。
- **后续影响**：写清资源循环、任务链、仇怨、声望、危险等级、商路、边境或势力关系变化。
- **与妖兽分析的关联**：只写关联妖兽名称和需另查的本体信息，不重复妖兽百科。
