# 妖兽分析模板

## 适用范围

本模板用于整理妖兽、灵兽、异兽、凶兽、荒兽、真灵、神兽、妖族个体、灵虫、虫群、海兽、飞禽、蛇蛟龙类、魂兽、毒兽，以及可产出资源的非人生命。

本模板侧重单个妖兽、灵虫、族群或妖族个体本身。若重点是妖兽与修士之间的长期社会关系、冲突制度、驯化制度或族群关系，另参考 `妖兽与修士关系分析模板.md`。

## 前置声明

- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、强大妖兽或少数名场面。
- 只整理原文有可靠依据的内容。原文未说明的等级、区域、习性、能力、弱点、资源、用途、驯养方式、化形规则、族群繁殖或后续影响，写“原文未说明”。
- 案例只是最低写法示范，不是数量上限。原文中有等级、区域、能力、资源、用途、关系、事件或设定价值的对象，都可继续补充。
- 妖兽不只写成战斗单位。应同时关注栖息地、习性生态、行动模式、资源产出、资源用途、特殊用途、驯养关系和与修士的影响。
- 信息不足但值得保留的内容，先放入 `### 待定案例`。后续有新依据时追加摘要和来源；信息足以支撑案例后，再整理进 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **基础身份**：名称、类型、等级或阶段、幼体/成体/王兽差异、对应修士阶段。
- **生存环境**：出现区域、栖息环境、灵气/食物/地形需求、巢穴、族群、繁殖、迁徙。
- **行为生态**：独居或群居、领地、巡游、护巢、护幼、守护资源、捕食对象、是否主动攻击修士。
- **战斗能力**：肉身、防御、速度、毒、飞行、遁地、隐匿、神魂攻击、群体战术、血脉威压、天赋神通、化形智慧、特殊克制。
- **弱点限制**：属性克制、阵法、神魂、毒火雷冰、血脉压制、首领死亡、巢穴被毁、资源断供、契约反制。
- **资源产出**：妖丹、妖核、内丹、兽骨、兽皮、鳞甲、精血、毒囊、翅翼、角爪、宝骨、虫卵、兽魂、尸骸、特殊器官。
- **资源用途**：炼丹、炼器、淬体、血脉/灵根补益、制符、布阵、培养灵兽、解毒、制毒、任务奖励、交易。
- **特殊用途**：拉动法宝、开启机关、破解禁制、寻宝探路、吞噬材料、辅助功法或术法、化成护甲、飞遁、破阵、护主、侦查、传承钥匙。
- **驯养关系**：灵宠、坐骑、护山兽、契约兽、虫群控制、血脉进化、宗门豢养、妖族势力、兽潮、修士猎妖。
- **事件后果**：狩猎、试炼、守药、袭击、兽潮、交易、驯养、资源争夺，以及死亡、收服、迁徙、追杀或生态变化。

## 案例

### 案例

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 低阶可狩猎妖兽 | 山林低阶妖兽、坊市周边猎物、任务目标 | 可猎杀性、资源回收、低阶修士风险、族群反应 |
| 守护资源型妖兽 | 守护灵药、矿脉、灵泉、秘境入口、传承地 | 资源关系、守护行为、偷采流程、资源被取后的后果 |
| 灵虫 / 虫群 / 毒兽 | 灵虫、蛊虫、毒蛇、毒蜂、虫王、毒兽 | 群体规模、毒性、繁殖、控制方式、虫潮或毒灾 |
| 可驯养灵兽 / 坐骑 / 护山兽 | 灵宠、坐骑、宗门灵兽、家族守护兽 | 认主条件、饲养成本、忠诚风险、护主或守山用途 |
| 高阶化形妖兽 / 妖族个体 | 妖王、化形妖修、族群首领、异族强者 | 灵智、社会结构、血脉等级、人妖关系、族群责任 |
| 真灵 / 神兽 / 上古异兽 | 真灵、神兽、上古异兽、界外生灵、血脉源头 | 传说层级、后裔、血脉资源、界面限制、传承影响 |

**通用妖兽卡片：**

- **名字和类型**：按原文填写名称、称呼和类型；类型不明则写原文称呼。
- **等级或阶段**：写清品阶、修为阶段、幼体/成体/王兽/化形差异；未说明则写“原文未说明”。
- **出现区域与栖息环境**：写清地点、地形、灵气、食物、巢穴、毒瘴、水域、矿石、灵草或界面限制。
- **习性与行动模式**：写清群居、独居、巡游、觅食、伏击、护巢、迁徙、休眠、追踪、受伤反应。
- **战斗能力与弱点**：写清攻击、防御、天赋、克制效果、环境加成，以及能被何种手段反制。
- **资源产出与用途**：写清可取材料、伴生资源、使用场景、交易或任务价值。
- **特殊用途**：写清普通材料以外的功能，例如寻宝、破禁、驱动法宝、护主、侦查、传承钥匙。
- **驯养或契约**：写清能否捕捉、饲养、认主、血契、虫群控制、护山或成为坐骑。高阶化形妖兽、妖族个体、真灵/神兽一般不按普通驯养处理；若原文出现盟约、血誓、主仆、护道、联姻、守护、后裔契约或神兽蛋孵化，应写清关系性质、限制和代价。
- **族群、繁殖与进阶**：写清族群结构、幼崽、虫卵、血脉、化形、变异、返祖或进阶条件。
- **与修士关系**：写清猎杀、交易、避让、驯养、供奉、任务、复仇、合作或长期冲突。
- **代表事件**：按原文写清狩猎、守药、袭击、兽潮、认主、交易、传承或战争过程。
- **结局或后续影响**：写清死亡、被捕、被契约、族群迁移、资源点暴露、追杀、兽潮或生态变化。
