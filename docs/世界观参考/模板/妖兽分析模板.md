# 妖兽分析模板

## 适用范围

本模板用于整理作品中明确存在的妖兽、灵兽、异兽、凶兽、荒兽、真灵、神兽、妖族个体、灵虫、虫群、海兽、飞禽、蛇蛟龙类、魂兽、毒兽，以及具备独立灵性和持续存在能力的元素生命等非人生命。

本模板重点记录生物对象本身及其生态、能力、资源、驯养和状态变化。人物、普通人类、灵根、器物、纯药材、纯材料、法宝、傀儡、阵法和临时能力形态分别放入对应专题；它们只在相关字段中作为来源、关系、环境或结果简要出现。

## 整理原则

1. 先做实体准入：对象必须是原文明确存在的非人生命，或具备独立灵性、自主行动和持续存在能力的元素生命；人物、器物、纯材料、阵法、能力效果和临时战斗形态不得直接建妖兽卡。
2. 先判定实体层级：区分物种、族群、个体、变身/进化形态、元素生命、战斗造物、尸骸/资源和临时能力形态；不同层级不混成同一张卡，并在关系中说明上下级或来源关系。
3. 一对象一卡：同名、别名、幼体与成体、阶段变化、后续能力、归属变化和最终状态归入同一卡；同种不同个体、族群与个体只有在对象边界明确时分别建卡，不能因事件相同重复建卡。
4. 元素生命单独判定：火焰、雷霆、灵魂或能量凝聚物只有具备独立意识、持续存在、自主行动和稳定个体特征时，才作为元素生命收录；依附施术者、一次性生成或无法独立存续的形态转入功法、术法、异火、阵法或战斗造物专题。
5. 字段只写生物本体：不跨字段堆叠，不引入人物传记、战斗招式、对白、逐章剧情、材料加工过程或使用记录；不设置或展开事件记录和战斗日志。
6. 区分生物规律与单次表现：栖息地不等于喜好，出现地点不等于稳定分布，一次扑击不等于习性，一次受伤不等于弱点，一次能力成功不等于通用上限；单次情况只能标为实际表现或上下文推断。
7. 区分能力、战斗和弱点：天赋能力写能做什么及稳定发动条件；战斗方式写惯用模式和行为结构；弱点写已确认的结构、属性、环境或机制限制，不重复同一战斗过程。
8. 资源与生物分开：妖丹、魔核、兽血、鳞甲、伴生资源和巢穴产物只写为生物产出及用途；材料本体放入生灵与妖兽材料或对应资源模板。
9. 族群、个体与关系分开：族群卡写共同结构和生态规律；个体卡只写自身差异、身份、能力和状态；人物、势力和修士关系只记录关系性质与影响，不复制对方专题内容。
10. 信息不足时如实标注并保持简洁：使用“原文明确”“实际表现”“稳定归纳”“人物评价或传闻”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不得根据动物常识、名称、属性或等级补齐繁殖、生理、习性和血脉。

## 信息与输出规则

1. 妖兽卡只保留总结结论：原文描写、对白、数字和事件顺序，只有能说明生物结构、规律、关系、能力、资源或状态变化时，才压缩为一句设定。
2. 后续信息覆盖早期推测：最终确认的身份、阶段、能力、归属和结局写入当前字段；早期猜测只在信息边界中简要说明，不与最终结论并列堆叠。
3. 关键变化摘要不写具体事件清单：只保留少量改变身份、阶段、能力、归属、资源关系或结局的节点，按“初始状态 -> 关键变化 -> 结果状态”总结，不写人物逐步行动、战斗过程、对白或章节列表。
4. 低信息对象不机械扩写：所有固定字段保留，但没有内容时直接写“原文未说明”“不适用”或“本次未覆盖到明确内容”，不使用类型常识填充。
5. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留结论内容和确定性类型。
6. 输出前自检：检查准入、实体层级、一兽一卡、物种与个体关系、元素生命边界、字段边界、能力与战斗区分、喜恶与弱点区分、生态关系、资源去向、后续状态和未知项是否清楚且不重复。

## 字段说明

- 名字和类型：填写名称、别名、族属、对象类型和实体层级；实体层级可填写物种、族群、个体、进化/变身形态、元素生命、战斗造物、尸骸/资源或待判定对象。类型不明时沿用作品称呼，不从材料名称反推生物名称。
- 稀有度与分布状态：填写作品对常见、少见、稀有、濒危、近乎灭绝、唯一个体等的评价，以及数量、种群密度、地域分布和变化；稀有度不等于战斗等级，不因单次发现或强大能力推定稀有。
- 起源与血脉来源：填写天地孕育、自然族群、上古遗种、真灵或神兽后裔、混血、返祖、人工培育、污染变异、异界迁入或元素凝聚等已确认来源；传闻和推断分开标注。
- 等级或阶段：填写品阶、修为、幼体、成体、王兽、化形、元素生命阶段或其他作品阶段，并区分个体等级与族群等级；不根据对手或使用者境界反推。
- 外观描述：填写体型与尺度、整体轮廓、头部与感官、躯干与肢体、翅翼/尾/角/爪、体表覆盖、颜色纹理、斑纹、伤痕、气息和标志性特征；幼体、成体、化形、变异和受伤状态分项概括，不复制场景描写。
- 生理特征与生存需求：填写食性和摄食、饮水或灵气需求、呼吸、体温、血液、内核或特殊器官、能量循环、休眠、蜕皮换羽、伤势恢复、再生、毒素反应、环境耐受和维持生存所需的资源；只写“活下去需要什么”。
- 出现区域与栖息环境：填写稳定分布或长期栖息地点、地形、巢穴、灵气、食物、毒瘴、水域、矿脉、灵草、界面和环境限制；单次出现地点标为实际表现，不直接写成栖息地。
- 灵智、性格与沟通方式：填写灵智、记忆、学习能力、情绪、警惕、凶暴、温顺、忠诚、记仇等稳定倾向，以及叫声、姿态、气味、神识、血脉感应、兽语、人言或化形交流；个体性格不得无依据泛化为族群特征。
- 习性与行动模式：填写独居或群居、领地、觅食、伏击、护巢、护幼、迁徙、休眠、追踪、探索和受伤反应等稳定行为模式；不写单次战斗动作清单。
- 喜恶描述：分别填写明确喜欢、主动趋近、长期选择的食物、气味、声音、光线、温度、灵气、地形、巢材、物品、活动、同类、其他生物或特定对象，以及明确厌恶、排斥、回避、畏惧或受刺激会攻击的对象；喜恶不自动等于生存需求或战斗弱点。
- 族群与社会结构：填写独居种、家庭群、兽群、虫群、部族、王族、蜂巢式结构等组织形态，以及首领、王兽、工虫、护卫、幼体、附庸、领地分工、群体协作和内部竞争；个体不适用时写“不适用”。
- 生态位与种间关系：填写食物链位置、猎物、天敌、竞争者、共生或寄生对象、守护或传播的资源、对地貌与灵气的改造，以及数量变化造成的生态后果；与修士的社会关系写入“与修士关系”。
- 繁殖方式与生命周期：填写性别差异、求偶与配对、胎生/卵生/分裂/寄生/血脉孕育等方式、繁殖条件、孕育/孵化周期、后代数量、巢穴与护幼、幼体成活、成熟、寿命、衰老和自然死亡；完全没有设定时写“原文未说明”或“不适用”。
- 成长、变异与进阶：填写幼体到成体、突破品阶、化形、血脉纯化、返祖、蜕变、异化、污染、突变、进阶条件、资源需求、失败风险、能力与外观变化及成长上限；不同阶段按结果分项，不写成长剧情。
- 天赋能力与发动表现：填写肉身、属性、毒、飞行、遁地、隐匿、感知、神魂、血脉威压、天赋神通或元素生命能力的来源、触发条件、作用对象、范围、持续、消耗、限制，以及发动时稳定的光影、声响、气息、形态和环境变化；不展开具体战术过程。
- 战斗方式：填写近战、远程、伏击、追猎、群攻、毒杀、围猎、空战、水战、领地防御、护幼作战或元素生命的稳定攻击模式，以及能力组合、目标选择、群体配合、受伤反应、追击和撤退倾向；只写模式，不写某场战斗经过。
- 弱点与克制：填写身体结构、属性相克、感知盲区、发动前置、能力间隔、环境限制、血脉压制、天敌、驯兽手段和其他已确认反制方式；区分稳定弱点、单次有效手段和情境限制。
- 资源产出与用途：填写可取得的妖丹、魔核、骨皮、鳞甲、精血、毒囊、兽魂、虫卵和伴生资源，以及炼丹、炼器、交易、任务等用途；只写生物产出和去向，不展开材料本体。
- 特殊用途：填写材料产出以外的寻宝、破禁、驱动法宝、护主、侦查、飞遁、传承开启、守护资源或其他稳定利用方式；妖兽自身能力先写入“天赋能力与发动表现”。
- 驯养或契约：填写捕捉、饲养、认主、契约、虫群控制、护山、坐骑和血脉培养关系；高阶化形妖兽、妖族、真灵和神兽不套用普通灵宠规则。
- 与修士关系：填写猎杀、交易、避让、供奉、驯养、合作、复仇、任务、长期冲突或族群关系；只写关系性质、利益和影响，不写双方完整故事。
- 关键变化摘要：填写少量能够说明身份、阶段、能力、归属、资源关系或结局变化的节点，按“初始状态 -> 关键变化 -> 结果状态”总结；不写章节号、事件经过、对白、战斗日志或逐条使用记录。
- 结局或后续影响：填写死亡、被捕、被契约、放养、迁徙、进阶、资源点暴露、追杀、兽潮、族群变化或生态变化等最终状态和持续影响；没有确认结果时写“原文未说明”。
