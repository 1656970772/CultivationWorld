# 妖兽分析模板

## 适用范围

本模板用于整理作品中的妖兽、灵兽、异兽、凶兽、荒兽、真灵、神兽、妖族个体、灵虫、虫群、海兽、飞禽、蛇蛟龙类、魂兽、毒兽，以及具备灵性、等级、特殊能力、驯养关系、资源价值或设定价值的其他非人生命。

本模板侧重生物对象本身及其生态、能力、资源、驯养和后续变化。若重点是妖兽与修士之间的长期社会关系、冲突制度、驯化制度或族群关系，另参考 `妖兽与修士关系分析模板.md`；非生命器物、纯药材、纯材料和法宝应转入对应模板。

## 整理原则

1. 先做准入判定
   原文明确存在的妖兽、灵兽、魔兽、妖族个体、灵虫或族群，才建立妖兽卡。只出现妖丹、魔核、兽血、灵毛、伴生资源等材料，而来源生物没有足够信息时，不得反推出一张信息完整的生物卡。
   非生命器物、纯药材、纯材料、普通比喻、宗门名、灵根名默认不收录。例如“神秘小瓶”是器物，不得因其能产出绿液而建立妖兽卡；“灵兽山”“真灵根”分别是门派名和灵根术语，不属于妖兽对象。

2. 普通动物和边界对象按设定价值取舍
   普通动物只有具备灵性或等级，参与契约、驯养、战斗、资源产出，或承载明确的剧情与世界观设定时才单独建卡。仅用于试验且没有上述价值的灰毛野兔、普通灰鸟等不单独收录。
   兼具生物与制成物属性的对象按核心机制判断。例如“尸虫丸”本质是经秘法泡制、可寄生孵化并受解药控制的虫卵，可作为寄生灵虫的边界对象收录，但不能按普通丹药或普通妖兽泛化填写。

3. 同一对象归并并持续追踪
   同名、别名、幼体与成体、不同阶段、后续能力补充和归属变化应归入同一张卡，并写清阶段差异。不得只记录首次出现后便作终局判断。
   例如“云翅鸟”应合并其受墨大夫驱使监视、控制方法转交韩立、被韩立继续使用、放养太岳山脉并最终飞野离去的完整变化，不能停留在“持续监视”的早期状态。

4. 区分原文明确、合理推断和未说明
   字段内容应标明“原文明确”“合理推断”或“原文未说明”。合理推断只能保留必要结论并说明推断关系，不得把类型常识写成作品事实；没有信息时统一写“原文未说明”。
   例如吞木狐的具体栖息地不能仅因乌坦城邻近魔兽山脉、佣兵在当地售卖魔晶便写成确定事实；“二级水属性魔核”只能说明来自未命名的二级水属性魔兽，不能据此补写该魔兽的种名、外观、喜恶、生理、灵智、繁殖、栖息地、习性或族群。

5. 生物对象与产出资源保持关联但不混同
   已知生物对象时，在生物卡中填写其资源产出与用途；只知材料时，不单独建立妖兽卡，也不补写来源生物信息。伴生资源应说明其与生物的生产、守护或栖息关系，但不得当作生物本体。
   例如蛇涎果可记录为与五阶蛇形魔兽巢穴相关的资源，二级水属性魔核属于未命名来源魔兽的材料；紫晶翼狮王与伴生紫晶源应分别作为生物对象及其关联资源处理。

6. 保持覆盖面并做候选盘点
   整理应覆盖多境界、多身份、多地域、多势力、多场景和多结局对象，不只收录主角相关、早期出现或战斗力强的对象。完成前应按作品自身术语盘点妖兽、魔兽、灵兽、妖族、灵虫、魔核、坐骑、巢穴、驯养、化形、兽潮等候选，并逐一判断收录或排除。
   候选盘点示例包括：三尾猫、金睛猿、吃金鼠、麒麟阁灵兽；吞木狐、青木鼠、蓝鹰“小岚”、黑焰紫云雕、紫晶翼狮王；蛇精罗萧、五彩灵蜥、红毛灵蝼、贝王与贝子玄珠。即使某对象信息较少，也应先判断其是否具备收录价值，不能因只出现材料、坐骑用途或后期情节而直接漏掉。

7. 字段完整且按生物链整理
   每张卡应保留：名字和类型、稀有度与分布状态、起源与血脉来源、等级或阶段、外观描述、生理特征与生存需求、出现区域与栖息环境、灵智、性格与沟通方式、习性与行动模式、喜恶描述、族群与社会结构、生态位与种间关系、繁殖方式与生命周期、成长、变异与进阶、天赋能力与发动表现、战斗方式、弱点与克制、资源产出与用途、特殊用途、驯养或契约、与修士关系、代表事件、结局或后续影响。原文没有说明的内容直接写“原文未说明”。
   按“起源—外观—生理—灵智—喜恶—习性—族群—生态—繁殖—成长—能力—战斗—资源—关系—后续”的链条整理，不使用妖兽类型常识补齐未知设定，不长篇复述剧情。

8. 完成后自检
   检查是否误收器物、纯材料、普通动物、宗门名或比喻；是否把材料反推成完整生物；是否混淆原文信息与推断；外观、喜恶、生理、灵智和繁殖是否有原文依据；是否把栖息地误写成喜好、把偏爱食物误写成生存必需、把厌恶对象误写成战斗弱点；天赋能力、战斗方式和特殊用途是否混写；族群结构、繁殖过程和进阶路线是否分开；是否合并同一对象的后续变化；所有妖兽卡是否使用了既定字段。

## 字段说明

- 名字和类型：填写原文名称、别名、族属和对象类型；类型不明时沿用原文称呼。
- 稀有度与分布状态：填写常见、少见、稀有、濒危、近乎灭绝、唯一个体等原文评价，以及数量、种群密度、地域分布、是否为某地特有种和分布变化；稀有度不等同于战斗等级，没有依据时写“原文未说明”。
- 起源与血脉来源：填写天地孕育、自然族群、上古遗种、真灵或神兽后裔、混血、返祖、人工培育、炼制改造、污染变异、异界迁入等来源，以及已确认的祖先、血脉纯度和血脉分支；传闻与推测应明确标注。
- 等级或阶段：填写品阶、修为、幼体/成体/王兽/化形等阶段及其与修士阶段的对应关系。
- 外观描述：填写妖兽可直接观察到的体型与尺度、整体轮廓、头部与感官器官、躯干与肢体、翅翼/尾/角/爪等附属结构、毛发/羽毛/鳞甲/甲壳等体表覆盖、颜色纹理、斑纹、伤痕、气息和其他标志性特征；幼体、成体、化形、变异、返祖、战斗或受伤时外观不同的，按阶段或状态分项记录。简单对象可直接概括；复杂对象可按“整体轮廓与体型”“头部与感官特征”“躯干/肢体/附属结构”“体表颜色与覆盖物”“阶段/状态变化”分块。没有明确描写时写“原文未说明”，不得根据名称、属性、能力或现实动物原型自行补写。
- 生理特征与生存需求：填写食性与实际摄食方式、饮水或灵气需求、呼吸方式、体温、血液、内核或特殊器官、能量循环、休眠、蜕皮换羽、伤势恢复、再生能力、疾病毒素反应、环境耐受范围，以及维持生存必须持续获得的食物、灵物或能量。此字段记录“活下去需要什么”，喜恶描述记录“主动偏好或排斥什么”，二者不要混写。
- 出现区域与栖息环境：填写地点、地形、巢穴、灵气、食物、毒瘴、水域、矿脉、灵草或界面条件。
- 灵智、性格与沟通方式：填写灵智水平、记忆与学习能力、情绪、警惕/凶暴/温顺/忠诚/记仇等稳定性格倾向，以及叫声、姿态、气味、神识、血脉感应、兽语、人言或化形交流方式；个体性格不得无依据泛化为整个族群特征。
- 习性与行动模式：填写独居或群居、领地、觅食、伏击、护巢、护幼、迁徙、休眠、追踪及受伤反应。
- 喜恶描述：分别填写妖兽明确喜欢、亲近、主动追逐或长期选择的食物、气味、声音、光线、温度、灵气属性、地形环境、巢材、物品、活动、同类、其他生物或特定人物，以及明确厌恶、排斥、回避、畏惧或受到刺激会攻击的对应对象。喜恶应以原文陈述、反复选择、主动趋近、明显回避或稳定应激反应为依据；栖息于某地不等于喜爱该环境，厌恶或畏惧某物也不自动构成战斗弱点。没有明确内容时，喜好与厌恶分别写“原文未说明”。
- 族群与社会结构：填写独居种、家庭群、兽群、虫群、部族、王族、蜂巢式结构等组织形态，以及首领、王兽、工虫、护卫、幼体、附庸、领地分工、等级秩序、群体协作和内部竞争。
- 生态位与种间关系：填写其在食物链和环境中的位置、主要猎物、天敌、竞争者、共生或寄生对象、守护或传播的灵植资源、对地貌与灵气环境的改造，以及数量变化造成的生态后果；与修士的制度性关系另写入“与修士关系”。
- 繁殖方式与生命周期：填写性别差异、求偶与配对、胎生/卵生/分裂/寄生/血脉孕育等繁殖方式、繁殖季节或条件、孕育/孵化周期、每次后代数量、巢穴与护幼、幼体成活、成熟时间、寿命、衰老和自然死亡。不得根据现实动物原型补写；完全没有性别或繁殖设定时写“原文未说明”或“不适用”。
- 成长、变异与进阶：填写幼体到成体的成长阶段、突破品阶、化形、血脉纯化、返祖、蜕变、异化、污染、突变、进阶条件、所需资源、失败风险、能力与外观变化及成长上限。
- 天赋能力与发动表现：填写肉身天赋、属性能力、毒、飞行、遁地、隐匿、感知、神魂、血脉威压、天赋神通等能力的来源、发动条件、作用对象、范围、持续时间、消耗、冷却或次数限制，以及发动时的光影、声响、气息、形态和环境变化。此字段写“能做什么以及如何发动”，不展开具体战术。
- 战斗方式：填写近战、远程、伏击、追猎、群攻、毒杀、围猎、空战、水战、领地防御、护幼作战等战斗模式，以及起手方式、能力组合、目标选择、群体配合、受伤反应、追击和撤退行为。
- 弱点与克制：填写身体结构、属性相克、感知盲区、发动前摇、能力间隔、环境限制、血脉压制、天敌、驯兽手段及其他明确反制方式；单纯厌恶或回避某物不能直接写成弱点。
- 资源产出与用途：填写可取得的妖丹、魔核、骨皮、鳞甲、精血、毒囊、兽魂、虫卵、特殊器官和伴生资源，以及炼丹、炼器、交易、任务等用途。
- 特殊用途：填写修士、势力或其他对象如何利用该妖兽完成材料产出以外的寻宝、破禁、驱动法宝、护主、侦查、飞遁、传承开启等任务；妖兽自身具备的能力先写入“天赋能力与发动表现”。
- 驯养或契约：填写捕捉、饲养、认主、契约、虫群控制、护山、坐骑及血脉培养关系；高阶化形妖兽、妖族个体、真灵或神兽按原文社会关系填写，不套用普通灵宠规则。
- 与修士关系：填写猎杀、交易、避让、供奉、驯养、合作、复仇、任务或长期冲突。
- 代表事件：简要填写最能体现对象能力、习性、关系或设定价值的事件。
- 结局或后续影响：填写死亡、被捕、被契约、放养、迁徙、进阶、资源点暴露、追杀、兽潮或生态变化。

## 案例

```md
# 《作品名》妖兽分析

## 妖兽卡片

### 妖兽名称

- 名字和类型：按原文填写名称、称呼和类型；类型不明则写原文称呼。
- 稀有度与分布状态：写清数量、种群密度、分布范围、是否为地域特有种，以及常见、稀有、濒危或灭绝状态。
- 起源与血脉来源：写清自然族群、天地孕育、血脉祖先、混血、返祖、人工培育、污染变异或异界来源。
- 等级或阶段：写清品阶、修为阶段、幼体/成体/王兽/化形差异；未说明则写“原文未说明”。
- 外观描述：写清体型、轮廓、头部、躯干、肢体、翅翼/尾/角/爪、体表覆盖、颜色纹理、标志性特征及不同阶段或状态的外观变化；复杂对象按需分块。
- 生理特征与生存需求：写清食性与摄食、呼吸、体温、血液、特殊器官、能量循环、休眠、恢复再生、环境耐受和生存必需资源。
- 出现区域与栖息环境：写清地点、地形、灵气、食物、巢穴、毒瘴、水域、矿石、灵草或界面限制。
- 灵智、性格与沟通方式：写清智慧、记忆、学习、情绪、稳定性格倾向，以及叫声、姿态、气味、神识、兽语、人言或化形交流。
- 习性与行动模式：写清群居、独居、巡游、觅食、伏击、护巢、迁徙、休眠、追踪、受伤反应。
- 喜恶描述：分别写清喜欢或主动趋近的对象，以及厌恶、排斥、回避或畏惧的对象；没有明确内容时分别写“原文未说明”。
- 族群与社会结构：写清族群组织、首领与成员层级、领地分工、群体协作和内部竞争。
- 生态位与种间关系：写清猎物、天敌、竞争、共生或寄生对象、守护资源、环境作用及生态后果。
- 繁殖方式与生命周期：写清性别、求偶、繁殖方式与条件、孕育或孵化、后代数量、护幼、成熟、寿命、衰老和自然死亡。
- 成长、变异与进阶：写清成长阶段、突破、化形、血脉纯化、返祖、变异、所需资源、失败风险和成长上限。
- 天赋能力与发动表现：写清能力来源、发动条件、范围、持续、消耗、限制，以及发动时的光影、声响、气息、形态或环境变化。
- 战斗方式：写清近战、远程、伏击、围猎、空战、水战、能力组合、目标选择、追击与撤退。
- 弱点与克制：写清身体弱点、属性相克、感知盲区、能力间隔、环境限制、血脉压制及明确反制手段。
- 资源产出与用途：写清可取材料、伴生资源、使用场景、交易或任务价值。
- 特殊用途：写清普通材料以外的功能，例如寻宝、破禁、驱动法宝、护主、侦查、传承钥匙。
- 驯养或契约：写清能否捕捉、饲养、认主、血契、虫群控制、护山或成为坐骑；高阶化形妖兽、妖族个体、真灵/神兽一般不按普通驯养处理。
- 与修士关系：写清猎杀、交易、避让、驯养、供奉、任务、复仇、合作或长期冲突。
- 代表事件：按原文写清狩猎、守药、袭击、兽潮、认主、交易、传承或战争过程。
- 结局或后续影响：写清死亡、被捕、被契约、族群迁移、资源点暴露、追杀、兽潮或生态变化。

### 噬金虫

- 名字和类型：噬金虫；上古奇虫、群居灵虫，在奇虫榜中排名第十二。
- 稀有度与分布状态：在天南修仙界已绝迹多年；韩立发现的是自上古时期遗留并在小寰岛地下长眠的一批幼虫，后经人工培育形成大规模虫群。其他自然种群分布原文未说明。
- 起源与血脉来源：上古已有的奇虫；更早起源、祖先与血脉分支原文未说明。
- 等级或阶段：幼虫—银壳阶段—金银斑阶段—成熟体；作品后期还提到噬金虫王，但普通虫群进阶虫王的完整条件原文另有专门育虫体系，本卡不据零散信息补写。
- 外观描述：
  - 幼虫/早期：虫壳以银色为主；具体尺寸和细部结构原文未完整说明。
```
