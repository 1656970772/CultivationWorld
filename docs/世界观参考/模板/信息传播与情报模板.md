# 信息传播与情报模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的信息产生、个人感知、公开传播、私密传递、偷听截获、误传谣言、封锁隐瞒、身份伪装，以及这些信息差引发的行动和影响。

整理时将信息传播与情报视为“事实产生—形成传播版本—源头处理—媒介承载—渠道传播—接收理解—筛选失真—核验纠错—信息差与对抗—决策利用—价值衰减—反馈再传播”的完整信息生命周期。模板不要求每条信息机械经历全部状态，只记录作品实际涉及、能够形成认知和行动变化的环节。

整理对象可以是个人、队伍、师徒、家族、宗门、商会、坊市、散修、妖族、情报组织或其他势力。信息内容可以涉及秘境与传承、宝物与资源、身份与实力、通缉与悬赏、势力行动、拍卖交易、强者陨落、战争局势等，但必须存在角色层面的知晓变化、传播链或信息差。

本模板不整理纯旁白设定、单纯心理变化、普通战斗过程或只有读者知道而角色没有感知的信息；除非它们随后进入角色认知，造成明确的信息差或引发具体行动。

## 整理原则

1. 先做事件准入判定
   只有存在“什么事实产生了哪些信息版本、谁通过什么媒介获得、如何理解或利用”的角色层信息流，才建立卡片。公开宣告、秘密传递、偷听截获、误传、封锁、伪装和追踪侦查可以收录；个人发现只有造成明确的信息差、决策或后续传播时才收录。

2. 排除没有信息链的普通剧情
   单纯心理宣言、成长感悟、普通战斗结果、清理现场、办事能力和纯世界观百科不得直接建卡。旁白介绍不能自动写成角色普遍知晓；只有信息通过具体感知或传播渠道进入角色认知，并改变判断、行动或传播策略时才收录。

3. 区分事实状态与传播版本
   先写作品能够确认的事实状态，再分别记录源头说法、公开版本、私密版本、残缺版本、误传版本和伪造版本。角色只知道某个版本时，不得把完整事实写成其已知内容；客观状态本身仍不明确时写“原文未说明”。

4. 记录信息生成目的和源头立场
   记录最初感知者、发布者、隐瞒者或伪造者，以及其告知、求助、交易、宣传、试探、威慑、诱导、甩责或保密目的。源头掌握事实不等于愿意完整传播，传播内容应与其立场和目的分开记录。

5. 先写主要信息链，再展开各环节
   每张卡先用“事实或源头 → 表达与媒介 → 中继节点 → 接收者 → 接收后行动 → 反馈或新信息”写出一条主要信息链，使信息如何进入认知并形成后续变化能够直接看清。“主要信息链”只作一句话总览；媒介保密、传播参数、接收状态、行为结果和反馈细节分别写入后续字段，不在总览中重复展开。

6. 区分媒介、传播运行和行为后果
   “表达形式、媒介与保密方式”写信息如何被编码、储存和限制访问；“传播范围、时效与成本”写传播运行参数；“利用、决策与行为后果”单独写接收者实际采取的行动。

7. 记录传播环境与运行条件
   记录距离、地形、战乱、组织层级、语言、阵法、灵气干扰、传音范围、信使速度和渠道可靠性如何影响传播速度、范围、成本、延迟和中断，也记录信息传播如何反向改变组织警戒、人员流动和环境控制。

8. 区分接收、理解和信任
   收到信息不等于注意到，注意到不等于正确理解，理解也不等于相信。每个关键主体按需要记录未收到、收到未读、部分理解、误解、相信、怀疑、拒绝和遗忘等状态，不用身份或群体人数推定统一认知。

9. 区分失真过程与可信度判断
   “筛选、失真与异常传播”写删减、压缩、延迟、夸大、误传、篡改、泄露和异常扩散是怎样发生的；“核验、纠错与可信度”写角色如何通过目击、交叉消息、再次调查或权威确认判断和修正。失真是传播过程，可信度是核验后的认知结果。

10. 区分知晓状态与信息差
   “接收、理解与信任状态”逐个记录主体掌握到什么程度；“信息差、权限与行动优势”比较主体之间的内容、时间、权限和判断差异，以及这些差异实际带来的主动权。没有改变判断或行动的信息差不必机械展开。

11. 记录信息封锁与主动对抗
    记录加密、暗号、权限隔离、封口、销毁媒介、清理知情者、拦截、反跟踪、伪装身份、投放诱饵和制造假消息等行为，以及它们是否成功、是否被绕过和是否引发反向暴露。

12. 区分正常、异常和极端传播
    正常传递写入传播链；延迟、丢失、残缺和个别误解写入异常传播；渠道全面中断、核心秘密大规模泄露、伪造消息引发群体恐慌或组织错误动员等写入极端结果。作品没有展示某类状态时不推演。

13. 追踪信息价值、衰减和失效
    记录情报在何种时间和局势内有效，何时因公开、过期、目标转移、事实变化、身份暴露或新消息出现而贬值、失效或被推翻。旧信息被重新解释、归档或用于下一轮调查时，也记录其后续用途。

14. 记录行动反馈和次生信息
    接收者利用信息采取追踪、设伏、赶赴、交易、封锁或动员后，应记录行动如何改变现实、暴露新的主体、产生新线索或触发下一轮信息传播。即时行动与长期反馈不得混写。

15. 明确信息与推断边界
    “所有、全体、必然、传遍”等判断只有作品明确支持时才能使用。人物判断、二手传闻、商业宣传、合理推断、不同版本冲突和重要未知项分别记录；不能把读者知道的信息直接视为角色知道，也不能把未发生的汇报或行动写成确定事实。

16. 合并重复事件并做输出自检
    同一事实及其连续传播在后文新增接收者、版本、渠道、误判、核验或影响时补入原卡，不重复建卡。输出前检查主要信息链是否闭合、事实与版本是否混写、媒介与传播参数是否重复、知晓状态与信息差是否重复、失真与可信度是否混写、即时行动与反馈是否混写，以及是否遗漏信息过期和修正结果。

## 字段说明

- 事件类型：填写公开传播、私密传递、偷听或截获、误传或谣言、封锁或隐瞒、身份伪装、个人发现等最贴切的类型；同一事件存在多种机制时可并列。
- 准入理由：说明该事件如何形成角色层的信息获得、传播、认知差异、信息对抗、行动或反馈，而不是普通剧情、旁白设定或单纯心理变化。
- 事实状态与传播版本：分别写当前能够确认的事实状态，以及源头、公开渠道、私密渠道、转述者、误传者或伪造者实际传播的不同版本；事实本身未知时写“原文未说明”。
- 信息生成、源头与目的：写最初感知者、消息发布者、隐瞒者或伪造者，说明其通过目击、神识、阵法、命灯魂牌、占卜、跟踪、搜魂、偷听、战报或回报等方式获得信息，以及发布、出售、求助、试探、威慑、诱导或保密目的。
- 表达形式、媒介与保密方式：写口述、文字、公告、传音、玉简、符箓、暗号、令牌、魂牌、榜单、商品宣传及其他表达媒介，并记录加密、权限、身份验证、封存、销毁和访问限制。
- 主要信息链：按“事实或源头 → 表达与媒介 → 中继节点 → 接收者 → 接收后行动 → 反馈或新信息”用一句话概括主链；没有外部传播时写“事实或感知 → 个人认知 → 个人行动 → 后续反馈”。
- 传播范围、时效与成本：写传播方向、空间和组织范围、速度、延迟、持续时间、资源投入、信使风险和暴露成本，以及距离、地形、阵法、灵气和组织网络造成的影响。
- 接收、理解与信任状态：按关键主体记录是否收到、注意、理解、相信、怀疑、拒绝、误解或遗忘，以及明确知晓、明确不知、部分知晓和原文未说明的范围。
- 筛选、失真与异常传播：写信息在获取、编码、转述和扩散过程中发生的选择性保留、删减、压缩、延迟、夸大、误解、篡改、泄露、丢失、渠道中断和极端扩散。
- 核验、纠错与可信度：写角色通过亲眼确认、交叉消息、权威回报、再次调查、试探或反向验证进行核验和修正的过程，并说明当前版本的可信程度及仍未解决的问题。
- 信息差、权限与行动优势：写不同角色或势力在内容完整度、获知时间、访问权限、理解和可信判断上的差异，以及这些差异如何改变主动权、风险和可选行动。
- 信息封锁、反侦察与对抗：写隐瞒、加密、封口、销毁媒介、清理知情者、拦截、反跟踪、身份伪装、诱饵和假消息等措施，以及实际成功、失败或反向暴露结果。
- 利用、决策与行为后果：只写接收者因信息采取的实际行动，如赶赴、准备、逃避、追踪、设伏、交易、结盟、背叛、封锁、试探或调动势力，以及行动的即时结果。
- 信息价值、过期与失效：写信息在哪一时间窗口和局势下有效，何时因公开、过期、目标转移、事实变化、身份暴露、新消息或核验结果而贬值、失效、被推翻或转为历史记录。
- 后续影响与反馈循环：写信息利用已经造成的争夺升级、身份暴露、关系变化、通缉、机会错失等影响，以及行动产生的新线索、新目击、新传闻和下一轮传播。
- 信息边界与不确定项：写人物判断、二手传闻、商业宣传、合理推断、不同版本冲突，以及传播范围、接收状态、可信度、行为结果、失效时间和后续影响等重要未知项。

### 抽髓丸秘密暴露

- 事件类型：私密传递 / 秘密揭示。
- 准入理由：韩立辨明抽髓丸的成分和副作用后当面告知在场接收者，使原本不对称的药物信息进入双方共同认知。
- 事实状态与传播版本：能够确认的事实是抽髓丸具有特定成分和副作用；韩立传播的版本为其辨明后的药物真相，其他版本原文未说明。
- 信息生成、源头与目的：韩立根据已有认知辨明药物并成为信息源；其当面揭示信息的完整目的原文未说明。
- 表达形式、媒介与保密方式：通过当面对话口头说明，传播限于在场人员；没有使用额外媒介或加密方式。
- 主要信息链：抽髓丸的成分和副作用 → 韩立辨明 → 当面对话 → 在场接收者 → 获得药物风险信息 → 原本单方掌握的秘密进入共同认知。
- 传播范围、时效与成本：传播限于在场人员，未出现外部中继并即时完成；其他传播范围、时间和成本原文未说明。
- 接收、理解与信任状态：韩立明确知晓，在场接收者收到相关说明；接收者理解程度和是否完全相信原文未说明，其他人是否知晓原文未说明。
- 筛选、失真与异常传播：信息由韩立直接说明，没有中间转述；是否存在选择性隐瞒、表述偏差或后续误传原文未说明。
- 核验、纠错与可信度：韩立基于已有认知辨明药物；在场接收者是否另行核验以及最终可信判断原文未说明。
- 信息差、权限与行动优势：韩立此前掌握抽髓丸的成分和副作用，在场接收者此前未掌握完整信息；当面揭示缩小了双方的信息差。
- 信息封锁、反侦察与对抗：抽髓丸信息此前处于不对称状态；是否有人主动封锁成分与副作用、是否采取反制原文未说明。
- 利用、决策与行为后果：在场接收者得知相关信息；其是否据此改变用药、关系判断或后续行动原文未说明。
- 信息价值、过期与失效：该信息在判断抽髓丸风险和相关人物意图时具有价值；是否因药物停用、公开或后续核验而失效原文未说明。
- 后续影响与反馈循环：抽髓丸的成分和副作用不再由韩立单方掌握；是否继续向外传播或产生新的调查原文未说明。
- 信息边界与不确定项：接收者范围、相信程度、核验过程、具体行动和后续扩散原文未说明。

### 筑基灵液拍卖宣传

- 事件类型：公开传播 / 商业宣传。
- 准入理由：拍卖场公开七瓶筑基灵液即将拍卖的消息，接收者据此关注拍卖并准备竞价，商业宣传改变了拍品的知晓范围和竞争状态。
- 事实状态与传播版本：能够确认的事实是七瓶筑基灵液将进入拍卖；公开版本包含拍品数量和拍卖安排，药效评价是否包含宣传性放大原文未说明。
- 信息生成、源头与目的：拍卖场掌握拍品和交易安排并发布消息，目的是吸引潜在竞买者参与拍卖。
- 表达形式、媒介与保密方式：通过商业宣传向相关势力发布；具体采用口头传告、公告、请柬或其他媒介原文未说明，拍品来源和非公开交易信息未随宣传公开。
- 主要信息链：七瓶筑基灵液即将拍卖 → 拍卖场发布商业宣传 → 收到消息的相关势力 → 关注并准备竞价 → 筑基灵液转为公开竞争资源。
- 传播范围、时效与成本：消息经商业宣传到达相关势力，并在拍卖开始前具有准备价值；传播速度、具体组织范围和成本原文未说明。
- 接收、理解与信任状态：收到宣传的势力明确知道七瓶筑基灵液将拍卖；具体个人范围、对药效的理解和信任程度原文未说明。
- 筛选、失真与异常传播：拍卖场选择公开拍品数量和安排，其他细节保留；是否存在夸大、二次转述、误传或宣传外泄原文未说明。
- 核验、纠错与可信度：拍品数量和拍卖安排由拍卖场直接发布，可信度较高；外部势力是否检查实物或核验药效原文未说明。
- 信息差、权限与行动优势：拍卖场掌握拍品、来源和完整交易安排，外部势力只掌握公开内容；提前获知消息者获得筹集资金和准备竞价的时间优势。
- 信息封锁、反侦察与对抗：拍品来源、卖方身份和其他非公开细节是否被拍卖场保护原文未说明；各势力是否隐瞒竞价意图原文未说明。
- 利用、决策与行为后果：收到消息的势力关注拍卖并准备竞价；具体资金调配、结盟和竞价行动原文未说明。
- 信息价值、过期与失效：消息在拍卖开始前具有准备价值，成交或拍卖结束后其预告价值失效；拍品归属信息是否继续保密原文未说明。
- 后续影响与反馈循环：筑基灵液由非公开资源转为公开竞争的拍品；竞买准备是否进一步暴露相关势力的需求和财力，以及后续传播范围，原文未说明。
- 信息边界与不确定项：收到消息的具体势力和个人、宣传媒介、药效表述、核验方式、竞价准备和最终扩散范围原文未说明。

### 赵元修炼出岔子消息传播

- 事件类型：误传 / 误判 / 现场传播。
