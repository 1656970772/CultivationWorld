# 信息传播与情报模板

# 规范

- 本文只整理小说中明确出现过，或能由具体剧情支撑的信息产生、感知、传播、误判、封锁和后续影响。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不能把读者知道的信息当成角色知道的信息；每个案例都要写清角色实际知道什么。
- 每个案例都要尽量写清“谁知道、谁不知道、谁只知道一部分、谁误判”，因为信息差本身就是事件因果的一部分。
- 不要只写“消息传开了”，要写清信息来源、传播渠道、知晓范围、可信度、延迟或失真，以及由此引发的具体行动。
- 主角、配角、反派、宗门、家族、商会、坊市、散修、妖族、情报组织等都可以作为信息传播节点；不要只写主角获得消息。
- 假消息、误导、封锁、身份伪装、迟到消息、被截断的消息也要写，它们往往比真实消息更能推动冲突。
- 原文没有说明传播范围、可信度、误差、传播时间或谁知道时，不要补，可以写“原文未说明”。
- 样本尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、少数名场面或少数成功案例。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 信息内容：秘境开启、宝物出世、传承现世、强者陨落、宗门大战、通缉追杀、拍卖会、妖兽尸骸、身家暴露、身份暴露、叛逃、继承争夺等。
- 感知方式：目击、神识、阵法探测、灵兽侦查、命灯魂牌、传音符、玉简、占卜推演、天机感应、跟踪、搜魂、偷听、战报、弟子回报等。
- 传播渠道：口耳相传、宗门公告、坊市传闻、商会消息、拍卖宣传、悬赏榜、通缉令、情报贩、队伍邀请、战报、族群传讯等。
- 知晓范围：个人、队伍、师徒、家族、宗门、坊市、商会、区域、跨州、跨界面、敌对势力、旁观势力等。
- 可信度与误差：亲眼确认、可靠消息、二手传闻、谣言、夸大、延迟、假消息、误导、封锁、信息不完整、身份伪装等。
- 信息差：读者知道角色不知道、主角知道旁人不知道、敌方误判主角实力、宗门误判局势、队友隐瞒收益、商会放大宣传等。
- 行为后果：赶赴机会点、提前准备、逃避追杀、抢先偷袭、设局诱敌、误判风险、结盟、背叛、恐慌扩散、势力调动等。
- 后续影响：争夺升级、身份暴露、关系破裂、通缉升级、势力站队、机会错失、长期敌对等。
- 机会点消息：重点写谁最先知道秘境、宝物或传承线索，消息是否完整，谁因此赶赴、设伏、结盟或截杀。
- 资源暴露：重点写宝物、身家、丹方、材料、法宝或特殊能力如何暴露，谁亲眼确认，谁只是听说，价值是否被夸大。
- 通缉悬赏：重点写发布方掌握多少信息，被通缉者是否知情，追杀者是否误判身份、实力或悬赏价值。
- 假消息设局：重点写真相掌握者、被骗者、半信半疑者各自知道什么，误判来自哪里，错误行动造成什么损失或收益。

### 案例

```md
# 《作品名》信息传播与情报

## 信息传播与情报卡片

### 信息事件名称

- 信息内容：
- 感知方式：
- 传播渠道：
- 知晓范围：
- 可信度与误差：
- 信息差：
- 行为后果：
- 后续影响：

### 秘境开启消息传播

- 信息内容：某处秘境出现开启异象，传闻其中有古修士遗留传承，但入口限制、危险程度和准确开启时间只有部分角色掌握。
- 感知方式：最初由目击异象的散修、探查地形的宗门弟子或保存古籍线索的势力发现；若原文没有说明最初发现者，写“原文未说明”。
- 传播渠道：消息经坊市传闻、情报贩转卖、宗门弟子回报、队伍邀请或玉简记录继续扩散。
- 知晓范围：早期可能只限发现者和其所属小队，随后扩展到宗门、坊市、敌对势力或旁观势力；跨区域扩散范围以原文为准。
- 可信度与误差：异象和入口位置可被亲眼确认，传承价值、危险程度和开启时间可能来自二手传闻、古籍误读或故意夸大。
- 信息差：先知者知道入口条件或禁制弱点，后来者只知道秘境位置；敌对势力可能误判主角是否掌握完整地图。
- 行为后果：各方提前准备破禁法器、招募队友、设伏入口、跟踪持图者或临时结盟争夺名额。
- 后续影响：秘境争夺升级，幸存者暴露宝物或功法线索，可能引发追杀、宗门问责、势力站队或长期敌对。

### 拍卖露富引发追杀

- 信息内容：角色在拍卖会、交易摊位或商会结算中暴露大量灵石、珍贵材料、丹方、法宝或特殊身份线索。
- 感知方式：旁观者亲眼见到竞价、交割或鉴定过程，商会人员可能通过账册、鉴宝流程或包厢身份判断其身家。
- 传播渠道：消息经拍卖会现场议论、商会内部流转、情报贩转述、尾随者回报或敌对势力悬赏继续扩散。
- 知晓范围：现场参与者直接知道部分事实，商会和追踪者可能知道更多细节，坊市散修多半只听到被夸大的传闻。
- 可信度与误差：成交价和物品出现可视为较可靠信息，真实身家、物品实际归属、角色境界和后台势力可能被夸大或误判。
- 信息差：追杀者以为角色孤身且可轻易截杀，角色可能已经察觉尾随并反向设局；旁观者不知道物品是否为代拍或伪装身份购买。
- 行为后果：追踪、试探、截杀、商会拉拢、同伴求援、角色改换身份或故意泄露假路线。
- 后续影响：身份进一步暴露，敌对关系形成，商会信誉或立场受到牵连，后续通缉、悬赏或报复行动升级。
```
