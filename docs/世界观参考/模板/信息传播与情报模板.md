# 信息传播与情报模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的信息产生、个人感知、公开传播、私密传递、偷听截获、误传谣言、封锁隐瞒、身份伪装，以及这些信息差引发的行动和影响。

整理对象可以是个人、队伍、师徒、家族、宗门、商会、坊市、散修、妖族、情报组织或其他势力。信息内容可以涉及秘境与传承、宝物与资源、身份与实力、通缉与悬赏、势力行动、拍卖交易、强者陨落、战争局势等，但必须存在角色层面的知晓变化、传播链或信息差。

本模板不整理纯旁白设定、单纯心理变化、普通战斗过程或只有读者知道而角色没有感知的信息；除非它们随后进入角色认知，造成明确的信息差或引发具体行动。

## 整理原则

1. 先做事件准入判定
   只有存在“谁获得了什么信息、信息如何到达、接收者如何理解或行动”的角色层信息流，才建立卡片。公开宣告、秘密传递、偷听截获、误传、封锁、伪装、追踪侦查等可以收录；个人发现只有在造成明确的信息差或后续行动时才收录，并注明“无外部传播，仅个人感知”。

   例如，七玄门招徒、张铁失踪引发门内反应、抽髓丸秘密被当面揭示、韩立夜遇奸细并截获残缺信息、厉飞雨偷取藏书及晋升护法的消息、赵元修炼出岔子引发误会、周家追踪张衍，均存在明确的信息获得或传递过程，可以收录。

2. 排除没有信息链的普通剧情
   单纯心理宣言、人物成长感悟、普通战斗结果、清理现场、内部办事能力或纯世界观百科不得直接建卡。韩立首次救人后的心理转变、平安符抵御心魔、韩立清理兔子爆炸现场、韩立命运自主宣言，若没有向他人传递信息或改变后续信息策略，应排除。炼药师职业设定也不能仅因旁白介绍就写成“所有修炼者都知道”；拍卖场一天内备齐药材也不能仅因体现办事能力就作为信息事件。只有角色通过具体渠道获知信息并据此行动时才收录。

3. 写清完整传播链
   每张卡用简洁的一句话写清“源头 → 渠道或媒介 → 接收者 → 接收后的行动”。不能只写“消息传开了”。若只有个人感知，应写“无外部传播，仅个人感知 → 角色据此采取的行动”，并降低整理优先级。

4. 区分不同知晓状态
   知晓情况应同时检查：谁明确知晓、谁明确不知、谁只知道一部分或发生误判、哪些范围原文未说明。不能把读者知道的信息当成角色知道的信息，也不能用某个群体的人数或身份反推整个群体都知情。

   例如，原文能支持韩立一家七口知晓某事时，可以写“明确知晓：韩立一家七口”；若没有交代同村情况，应写“原文未说明是否传至同村”，不能写“同村无人知晓”。韩立修炼遇到瓶颈且药物耗尽时，墨大夫若只能通过把脉得知一部分，就应归入“部分知晓”，不能写成掌握完整情况。

5. 限制范围扩大和后验推断
   “所有、全体、必然、一定、传遍、外界都会”等全称或确定性判断，只有在原文明确支持时才能使用。否则应缩小到已明确的接收者，改写为角色推测，或写“原文未说明”。

   例如，葛叶目睹金色火焰后逃离，可以写其已经目睹并受到震慑；若原文没有写其随后汇报，就不能写“葛叶必然会向云岚宗汇报”。周子尚听取下人打探来的张衍消息以及张衍名声扩散，可以写明现有传播关系，但不能自行扩大为所有门派都已知晓。

6. 区分事实、角色判断和待确认影响
   亲眼目击、正式公告、可靠回报、二手传闻、角色推断、故意误导的可信度不同，应在“可信度与失真”中说明。行为后果只写接收信息后实际采取的行动；后续影响只写原文已发生的结果，尚未发生或无法确认的方向写“待确认”，不得当作确定事实。

7. 控制卡片长度和剧情复述
   每张卡只保留信息流所需内容。信息内容只写被传递或感知的核心事实；行为后果只写接收者据此采取的行动；不要把完整剧情、人物评价或战斗过程塞入字段。

8. 兼顾不同阶段、主体和情报节点
   整理长篇作品时，应兼顾作品前期、中期、后期，并覆盖个人、势力与专业情报节点，避免只整理主角早期经历。除显性名场面外，还应留意广源斋一类情报组织、拍卖场与坊市宣传、门派间打探、通缉悬赏、探子侦查、传音玉简、命灯魂牌、搜魂偷听、谣言和封锁等信息网络。

   退婚现场、萧家测验、成人仪式适合检查公开见证与声望变化；雅妃借萧炎宣传、筑基灵液拍卖宣传适合检查商业放大；黑角域情报交叉、魂殿消息、毒宗探查以及门派弟子打探张衍虚实，适合检查势力级情报网络。是否建卡仍以实际存在角色层信息流为准。

9. 合并重复事件并做输出自检
   同一信息事件在后文补充了新接收者、新误判、新渠道或新影响时，应补入原卡，不得重复建卡。生成后检查标题是否重复、字段是否齐全且无重复、是否存在无依据的全称断言、传播链是否闭合、作品前中后阶段与非主角节点是否明显缺失。例如“厉师兄名望传播”重复出现时，应合并为一张卡；“王大胖与张长贵冲突事件传播”出现两个“信息差”字段时，应合并字段内容并保留一个字段。

## 字段说明

- 事件类型：填写公开传播、私密传递、偷听/截获、误传/谣言、封锁/隐瞒、身份伪装、个人发现等最贴切的类型；同一事件存在多种机制时可并列，但不要堆砌无关标签。
- 信息内容：只写角色实际获得、传递、隐瞒或误解的核心信息，不复述完整剧情。
- 源头/感知方式：写信息最初从何而来，以及角色通过目击、神识、阵法、灵兽、命灯魂牌、传音符、玉简、占卜、跟踪、搜魂、偷听、战报、弟子回报等何种方式获得；原文未说明时如实填写。
- 传播链：按“源头 → 渠道或媒介 → 接收者 → 接收后的行动”填写。没有外部传播时，写明仅个人感知及其引发的行动。
- 知晓情况：在同一字段内按需写“明确知晓”“明确不知”“部分知晓/误判”“原文未说明”，只列对事件因果有影响的角色或势力。
- 可信度与失真：说明信息属于亲眼确认、可靠回报、二手传闻、残缺信息、角色推断、夸大、延迟、假消息、故意误导或身份伪装，并指出关键误差。
- 信息差：写不同角色或势力掌握内容的差异，以及这种差异如何影响判断；没有明确差异时写“原文未说明”。
- 行为后果：只写接收者因该信息采取的实际行动，如赶赴、准备、逃避、追踪、设伏、结盟、背叛、封锁、试探或调动势力。
- 后续影响：写信息事件已经造成的争夺升级、身份暴露、关系变化、通缉升级、机会错失等结果；尚未发生或无法确认时写“待确认”或“原文未说明”。

## 案例

```md
# 《作品名》信息传播与情报

## 信息传播与情报卡片

### 信息事件名称

- 事件类型：
- 信息内容：
- 源头/感知方式：
- 传播链：
- 知晓情况：
- 可信度与失真：
- 信息差：
- 行为后果：
- 后续影响：

### 抽髓丸秘密暴露

- 事件类型：私密传递
- 信息内容：韩立当面说出抽髓丸的成分和副作用。
- 源头/感知方式：韩立根据已有认知辨明药物，并当面对话告知。
- 传播链：韩立 → 当面对话 → 在场接收者 → 重新判断抽髓丸及相关人物的意图。
- 知晓情况：明确知晓：韩立与在场接收者；其他人是否知晓原文未说明。
- 可信度与失真：直接说明；接收者是否完全相信原文未说明。
- 信息差：韩立掌握药物真相，接收者此前未掌握完整成分与副作用。
- 行为后果：接收者据此重新评估药物风险和双方关系。
- 后续影响：原文已发生：抽髓丸不再是单方掌握的秘密。

### 筑基灵液拍卖宣传

- 事件类型：公开传播
- 信息内容：拍卖场将七瓶筑基灵液即将拍卖的消息告知乌坦城各方势力。
- 源头/感知方式：拍卖场发布交易宣传，各方通过商业消息获知。
- 传播链：拍卖场 → 商业宣传 → 乌坦城各方势力 → 关注并准备参与拍卖。
- 知晓情况：明确知晓：收到宣传的各方势力；个人层面的知晓范围原文未说明。
- 可信度与失真：拍品数量与拍卖安排由拍卖场发布，可靠性较高；药效评价可能受商业宣传放大。
- 信息差：拍卖场掌握拍品与交易安排，外部势力只掌握公开信息。
- 行为后果：各方势力关注拍卖并准备竞价。
- 后续影响：原文已发生：筑基灵液成为公开争夺的交易资源。

### 赵元修炼出岔子消息传播

- 事件类型：误传/误判
- 信息内容：赵元的修炼状况被他人理解为修炼出了岔子。
- 源头/感知方式：相关人物根据现场表现和转述形成判断。
- 传播链：现场异常 → 人物观察与转述 → 赵英、闵楼、卞桥等人 → 分别作出维护或借机发难的反应。
- 知晓情况：明确知晓：相关人物知道赵元出现异常；部分知晓/误判：各方对原因和严重程度判断不同。
- 可信度与失真：异常表现可被观察，原因解释带有角色推断和立场偏差。
- 信息差：赵元的实际情况与旁人据表象形成的判断不完全一致。
- 行为后果：闵楼出面维护，卞桥借题发难。
- 后续影响：原文已发生：误判转化为人物间的公开冲突。

### 周家追踪张衍

- 事件类型：个人发现、私密传递
- 信息内容：周家通过牵魂术变化和尾随行动追查张衍的去向与情况。
- 源头/感知方式：周幼楚感知牵魂术消失，周子尚下山查探并安排尾随。
- 传播链：牵魂术异常 → 周家内部判断与安排 → 周子尚及执行者 → 下山查探、尾随张喜并收集消息。
- 知晓情况：明确知晓：周家相关行动者；张衍一方掌握多少追踪信息原文未说明。
- 可信度与失真：牵魂术变化是直接感知，目标位置与原因仍需查探确认。
- 信息差：周家知道正在追查张衍，张衍一方是否察觉以及掌握多少原文未说明。
- 行为后果：周子尚下山并通过尾随和打探继续获取信息。
- 后续影响：原文已发生：对张衍的关注由内部感知转为实际追踪。
```
