# 信息传播与情报模板

## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的感知、传闻、情报、可信度、信息差与误判相关内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

- 本文只整理小说中明确出现过，或能由具体剧情支撑的信息产生、感知、传播、误判和后续影响。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不能把读者知道的信息当成角色知道的信息；每个案例都要写清角色实际知道什么。
- 每个案例都要尽量写清“谁知道、谁不知道、谁只知道一部分、谁误判”，因为信息差本身就是事件因果的一部分。
- 不要只写“消息传开了”，要写清信息来源、传播渠道、知晓范围、可信度、延迟或失真，以及由此引发的具体行动。
- 主角、配角、反派、宗门、家族、商会、坊市、散修、妖族、情报组织等都可以作为信息传播节点；不要只写主角获得消息。
- 假消息、误导、封锁、身份伪装、迟到消息、被截断的消息也要写，它们往往比真实消息更能推动冲突。
- 原文没有说明传播范围、可信度、误差、传播时间或谁知道时，不要补，可以写“原文未说明”。

## 必须写什么

- **感知方式**：神识、目击、阵法探测、灵兽侦查、命灯魂牌、传音符、玉简、占卜推演、天机感应、跟踪、搜魂、偷听。
- **传播渠道**：口耳相传、宗门公告、坊市传闻、商会消息、拍卖宣传、悬赏榜、通缉令、情报贩、弟子汇报、战报、族群传讯。
- **信息内容**：秘境开启、宝物出世、强者陨落、宗门大战、通缉追杀、拍卖会、妖兽尸骸、身家暴露、身份暴露、叛逃、继承争夺。
- **可信度状态**：亲眼确认、可靠消息、二手传闻、谣言、夸大、延迟、假消息、误导、封锁、信息不完整、身份伪装。
- **知晓范围**：个人、队伍、师徒、家族、宗门、坊市、商会、区域、跨州、跨界面、敌对势力、旁观势力。
- **信息差类型**：读者知道角色不知道、主角知道旁人不知道、敌方误判主角实力、宗门误判局势、队友隐瞒收益、商会放大宣传。
- **行为后果**：赶赴机会点、提前准备、逃避追杀、抢先偷袭、设局诱敌、误判风险、结盟、背叛、恐慌扩散、势力调动。

## 案例

### 案例

#### 案例 1：秘境开启消息传播

信息类型：秘境消息 / 机会点消息。

信息来源：最初由目击者、宗门探子、商会、散修、阵法异动、古籍线索或异象发现；具体来源按原文填写。

传播渠道：消息可能通过坊市传闻、宗门内部通知、商会交易、队伍邀请、玉简、传音符、情报贩或拍卖宣传扩散。

知晓范围：写清哪些角色、队伍、宗门、家族或区域势力知道消息；哪些人不知道；哪些人只知道秘境存在但不知道入口、时间、危险或真实收益。

可信度与误差：消息可能是亲眼确认，也可能是二手传闻、夸大收益、隐瞒危险、延迟消息或敌方设局；可信度按原文填写。

角色反应：有人赶赴秘境，有人观望，有人提前准备破阵、丹药、法器和队友，有人误判危险后贸然进入，也有人利用消息设伏。

后续影响：消息传播引发秘境争夺、组队、背叛、截杀、宝物暴露、势力调动、通缉追杀或长期关系变化。

#### 案例 2：宝物或身家暴露

信息类型：宝物消息 / 身家暴露 / 资源暴露。

信息来源：角色在交易、拍卖、战斗、救人、炼丹、炼器、使用法宝或出售材料时暴露资源；也可能由旁观者、同伴、敌人或商会泄露。

传播渠道：消息通过目击者口耳相传、坊市传闻、商会内部、同门汇报、敌人追踪、悬赏和通缉扩散。

知晓范围：写清谁亲眼看见，谁只是听说，谁知道宝物名称，谁只知道“此人身家丰厚”，谁完全不知道真实价值。

可信度与误差：消息可能被夸大、误认、截取一部分，也可能因角色隐藏身份、改换外貌、伪装修为而失真。

角色反应：觊觎者可能跟踪、试探、邀约、设局、围杀或雇佣他人；被暴露者可能逃离、换身份、反杀、求援、闭关或出售赃物。

后续影响：引发夺宝、追杀、关系破裂、势力介入、通缉升级、身份暴露或新的机会点。

#### 案例 3：通缉令或悬赏消息扩散

信息类型：通缉消息 / 悬赏消息 / 声誉消息。

信息来源：宗门、家族、城池、商会、执法势力、受害者亲友或敌对势力发布通缉或悬赏。

传播渠道：通缉令、悬赏榜、坊市公告、宗门传讯、商会渠道、追杀队伍口耳相传、情报贩转卖。

知晓范围：写清发布方知道多少，追杀者知道多少，普通散修知道多少，被通缉者是否知道自己被通缉，旁观势力是否跟进。

可信度与误差：通缉内容可能准确，也可能夸大战力、隐瞒真相、误判身份、错认凶手或故意栽赃。

角色反应：追杀者集结、散修试图领赏、商会拒绝交易、宗门要求避嫌，被通缉者隐藏身份、改路线、清除线索或反设埋伏。

后续影响：形成追杀链、悬赏升级、声誉变化、势力敌对、关系牵连、亲友受压或新的冲突事件。

#### 案例 4：假消息与误判设局

信息类型：假消息 / 误导消息 / 战术情报。

信息来源：敌方故意放出假情报，或角色隐藏实力、伪装身份、制造假线索、泄露部分真相来误导他人。

传播渠道：假消息通过内奸、俘虏、情报贩、坊市传闻、伪造玉简、假通缉、假拍卖消息或故意留下的痕迹传播。

知晓范围：写清谁知道真相，谁只知道假消息，谁半信半疑，谁因为旧情报或自负产生误判。

可信度与误差：假消息可能混合部分真实内容，因此更容易被相信；要写清误差来自伪装、延迟、立场偏见、境界差距还是情报来源不可靠。

角色反应：被骗者可能错误集结、进入埋伏、错失机会、追错目标或误判敌人境界；设局者借此逃跑、反杀、夺宝或转移注意力。

后续影响：假消息可能导致伤亡、结仇、信任破裂、势力判断失误、通缉对象变化，或让真正目标暂时脱身。
