# 信息传播与情报模板

## 适用范围

用于整理作品中出现过，或能由原文、资料来源和可靠依据支撑的感知、传闻、情报、可信度、信息差、误判和后续影响。

本模板只写角色在作品内如何知道、误知、传递或封锁信息；不能把读者知道的信息当成角色知道的信息。

## 前置声明

- 样本尽量覆盖主角、配角、反派、宗门、家族、商会、坊市、散修、妖族、情报组织、旁观者和被牵连者。
- 每个案例都要写清“谁知道、谁不知道、谁只知道一部分、谁误判”。
- 不要只写“消息传开了”；要写来源、渠道、范围、可信度、延迟或失真，以及由此引发的行动。
- 假消息、误导、封锁、身份伪装、迟到消息、被截断的消息也要写。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法提示 |
|------|----------|
| 信息类型 | 写秘境消息、宝物出世、身家暴露、强者陨落、宗门大战、通缉追杀、拍卖会、身份暴露等。 |
| 信息来源 | 写目击、神识、阵法探测、灵兽侦查、命灯魂牌、玉简、占卜推演、跟踪、搜魂、偷听、战报等。 |
| 传播渠道 | 写口耳相传、宗门公告、坊市传闻、商会消息、拍卖宣传、悬赏榜、通缉令、情报贩、弟子汇报等。 |
| 知晓范围 | 写个人、队伍、师徒、家族、宗门、坊市、商会、区域、跨州、跨界面、敌对势力、旁观势力等。 |
| 可信度与误差 | 写亲眼确认、可靠消息、二手传闻、谣言、夸大、延迟、假消息、误导、封锁、信息不完整、身份伪装等。 |
| 信息差 | 写读者知道角色不知道、主角知道旁人不知道、敌方误判主角实力、队友隐瞒收益、商会放大宣传等。 |
| 行为后果 | 写赶赴机会点、提前准备、逃避追杀、抢先偷袭、设局诱敌、误判风险、结盟、背叛、恐慌扩散、势力调动等。 |
| 后续影响 | 写争夺升级、身份暴露、关系破裂、通缉升级、势力站队、机会错失或长期敌对等。 |
| 来源依据 | 写原文位置、资料来源或可靠依据；传播范围、时间和可信度不明时写“原文未说明”。 |

常见类型提示：

| 类型 | 示例 | 重点 |
|------|------|------|
| 机会点消息 | 秘境开启、宝物出世、传承现世。 | 谁最先知道，消息是否完整，谁因此赶赴或设伏。 |
| 资源暴露 | 宝物、身家、丹方、材料、法宝或特殊能力暴露。 | 暴露路径、知晓范围、夸大失真、跟踪截杀或求援。 |
| 通缉悬赏 | 通缉令、悬赏榜、宗门追杀、声誉变化。 | 发布方、追杀者、被通缉者是否知情、身份是否误判。 |
| 假消息设局 | 伪造线索、故意放风、封锁真相、误导敌人。 | 真相掌握者、被骗者反应、误判来源、设局后的损失或收益。 |

## 案例

### 案例

| 案例方向 | 最小写法示例 | 不可漏写的重点 |
|----------|--------------|----------------|
| 秘境开启消息传播 | 异象、探子、古籍线索、商会或散修发现秘境消息，经坊市、宗门、玉简、情报贩或队伍邀请扩散。 | 最初来源、知晓范围、消息完整度、可信度、赶赴者反应、争夺或截杀后果。 |
| 宝物或身家暴露 | 角色在交易、拍卖、战斗、炼丹炼器或出售材料时暴露资源，被旁观者、同伴、敌人或商会泄露。 | 谁亲眼看见，谁只是听说，价值是否被夸大，跟踪试探或身份变化。 |
| 通缉令或悬赏消息扩散 | 宗门、家族、城池、商会、执法势力或受害者发布通缉，经公告、悬赏榜、情报贩和追杀队伍扩散。 | 发布方掌握多少，被通缉者是否知情，追杀者是否误判，悬赏是否升级。 |
| 假消息与误判设局 | 敌方放出假情报，或角色伪装身份、制造假线索、泄露部分真相来误导他人。 | 谁知道真相，谁半信半疑，误差来自哪里，被骗者采取什么错误行动。 |

### 待定案例

1. 对象名称：关键摘要（来源）；新增摘要（来源）。
