# 动态事件与机会点模板

## 适用范围

本模板用于整理小说中由原文明确支撑的动态事件、机会点和限时参与行动链。动态事件必须具有明确的触发或消息来源、时间窗口、参与条件或准备行为，并产生参与、错过、失败、收益或余波差异。

本文不写总览、抽象规则表，也不把普通剧情、地理背景、单人修炼过程、能力突破、物品发现、普通救治、单次监视、普通对话、纯心理变化或世界设定说明写成动态事件。

主角遇到的机缘可以写，但不要只写主角机缘。NPC、配角、宗门、商会、邪修、妖兽、旁观势力、失败者和被牵连者对同一动态事件的知晓、准备、参与、错过和余波，也应尽量纳入同一事件链。

## 整理原则

1. 先做准入判定  
   每张卡必须同时满足：有触发或消息渠道、有时间窗口、有参与条件或准备行为、有参与/错过/失败差异、有结算或阶段性余波。  
   任一条件不满足，不得作为动态事件与机会点卡片。

2. 一事一卡  
   同一触发、同一机会、同一时间窗口、同一结算结果的事件必须归并到同一张卡。  
   禁止另建“某事件（补充）”“某机会点后续”等新卡。阶段性发展写入同卡的“事件阶段”或“行动链节点”。

3. 区分合并与拆分  
   同一地点、同一资源或同一组织不代表同一事件。若时间窗口、参与者、资源批次、交易对象、收益结算不同，应拆成不同卡。  
   连续修炼阶段、普通训练过程、个人技能开发，不应为了凑机会链而拆成动态事件。

4. 字段完整  
   每张卡必须包含：事件类型、准入理由、事件阶段、触发/预兆、时间窗口、地点/范围、消息渠道与知晓范围、参与条件、准备行为、行动链节点、参与者覆盖、收益、风险与失败、余波。  
   无依据时写“原文未说明”；无明显余波写“原文未说明明显余波”；禁止空字段。

5. 只保留动态机会价值  
   保留能体现预告、传播、准备、赶往、参与、争夺、交易、采集、错过、失败、结算和余波的信息。  
   不长篇复述剧情，不展开与机会链无关的外貌、气氛、心理、打斗或日常描写。

6. 记录多方差异  
   同一事件应尽量记录至少两类参与视角，如主角、竞争者、组织方、失败者、旁观势力、被牵连者。  
   如果原文只说明单方视角，参与者覆盖写“原文未说明更多参与方”。

7. 进行中事件谨慎收录  
   尚未结算的事件可以收录，但必须在“事件阶段”“行动链节点”或“余波”中说明当前只到哪一步。  
   禁止把未发生的收益、结局或后续影响写成确定事实。

## 字段说明

- 事件类型：写开启类机会、交易类机会、资源类机会、势力类事件、悬赏追捕、战争动员、遗迹探索、宗门选拔、限时试炼等。
- 准入理由：说明该事件为什么满足动态机会链，而不是普通剧情、修炼过程、背景设定或单次冲突。
- 事件阶段：按原文先后写预兆、传闻、公告、暗中传播、准备、赶路、开启、进入、争夺、交易、结算、关闭、过期、错过、余波等阶段。
- 触发/预兆：写天象、灵气波动、令牌感应、地图线索、遗迹异动、妖兽迁徙、拍卖预告、通缉榜更新等提示事件将发生的内容。
- 时间窗口：写预告时间、准备周期、开启时间、持续时间、结束时间、赶路时间、过期时间等。
- 地点/范围：写事件发生地、入口位置、坊市或商会地点、战场范围、传播范围、能否跨地域影响等。
- 消息渠道与知晓范围：写目击、传闻、坊市消息、宗门公告、商会情报、令牌感应、地图线索等渠道，以及哪些角色、势力或旁观者知道。
- 参与条件：写境界、令牌、地图、队伍、距离、身份、关系、灵石、资源准备、宗门资格、商会邀请、时间窗口、保命手段等限制。
- 准备行为：写购买丹药符箓、修复法宝、打探情报、组队、取得令牌、赶路、隐藏身份、闭关调整状态、雇佣护卫、联系宗门或商会等行动。
- 行动链节点：逐步写清参与、争夺、交易、采集、破禁、结算、错过或失败等节点；每个节点尽量写明条件、消耗、收益、风险和后果。
- 参与者覆盖：写主角、竞争者、组织方、失败者、旁观势力或被牵连者在同一事件中的不同选择与结果。
- 收益：写物品、功法、材料、境界突破资源、关系、人情、声望、职位、情报、战利品、妖兽材料、拍卖所得、传承等。
- 风险与失败：写死亡、重伤、被抢、被追杀、队友背叛、事件过期、资源不足、误信传闻、赶路失败、令牌被夺、错过开启窗口、被困秘境、惹上仇怨等。
- 余波：写宝物流入坊市、追杀、通缉、宗门关系变化、消息传播、资源价格变化、势力重新洗牌、下一轮事件被触发等。

### 示例案例一：秘境开启与多人争夺

### 秘境开启与多人争夺

- 事件类型：开启类机会 / 遗迹探索
- 准入理由：秘境开启有预兆、传播、准备、进入、争夺、关闭和余波，参与者会因是否及时进入、是否持有条件、是否成功撤离而产生不同结果。
- 事件阶段：预兆、传闻、准备、赶路、开启、进入、争夺、结算、关闭、余波
- 触发/预兆：某地出现天象、灵气波动、令牌异动、遗迹入口松动或妖兽异常；按原文写清最初发现者和异动表现。
- 时间窗口：写预告时间、准备周期、开启时间、持续时间、关闭时间；原文没有说明时写“原文未说明”。
- 地点/范围：写秘境入口位置、影响地域、各方抵达路线和传播范围。
- 消息渠道与知晓范围：写宗门、散修、坊市、商会或相关角色通过公告、传闻、情报、令牌感应等渠道知晓的顺序和范围。
- 参与条件：令牌、地图、境界限制、队伍要求、赶路时间、宗门资格、灵石或保命手段等。
- 准备行为：购买丹药符箓、修复法宝、组队、打探情报、隐藏身份、提前赶往入口。
- 行动链节点：
  - 预兆与传播：秘境异动出现后，消息从最初发现者扩散到相关角色或势力；写清可信度、传播范围和传播速度。
  - 准备与抵达：参与者根据条件准备资源并赶往入口；写清消耗、同行者、路途风险和是否有人错过。
  - 开启与探索：秘境开启后进入采药、寻宝、破禁、争夺传承或遭遇妖兽；写清节点收益、伤势、法宝损耗或关系变化。
  - 争夺与结算：秘境内发生合作、背叛、截杀或分配；写清谁获得资源、谁失去资源、谁死亡或失踪。
  - 关闭与错过：秘境关闭或窗口结束；写清迟到者、未出来者、被困者和失败者的后果。
- 参与者覆盖：写主角、竞争者、组织方、失败者或旁观势力的准备、参与、错过和结算差异；原文未说明更多参与方时如实标注。
- 收益：灵药、材料、功法、法宝、传承、妖兽材料、人情、声望或后续线索。
- 风险与失败：死亡、重伤、被抢、被困秘境、令牌被夺、赶路失败、错过开启窗口、惹上仇怨。
- 余波：宝物流入坊市或拍卖，幸存者被追杀，宗门关系变化，消息继续传播，引发下一轮冲突或修炼行动链。


### 示例案例二：拍卖会引发准备、竞价和截杀
### 拍卖会引发准备、竞价和截杀

- 事件类型：交易类机会 / 商会盛会
- 准入理由：拍卖会有预告、传播、入场条件、资源准备、竞价结算和离场风险，参与者会因财力、身份和退路不同产生不同结果。
- 事件阶段：预告、传播、准备、赶路、入场、竞价、成交、离场、截杀、余波
- 触发/预兆：某坊市、商会或大城发布拍卖会预告，并公开重点拍品、入场资格或交易规则。
- 时间窗口：写预告时间、准备周期、拍卖开始时间、持续时间、离场追踪或截杀发生时间。
- 地点/范围：写拍卖地点、主办方势力范围、参与者来处和离场路线。
- 消息渠道与知晓范围：写宗门、散修、家族、邪修或相关角色通过商会预告、坊市传闻、熟人提醒、情报渠道等方式知晓。
- 参与条件：灵石、抵押物、可交易材料、商会邀请、身份遮掩、护卫力量、入场资格等。
- 准备行为：筹集灵石、整理材料、雇佣护卫、隐藏身份、打探拍品、安排退路。
- 行动链节点：
  - 预告与筹备：拍卖消息扩散后，参与者判断拍品价值并准备资源；写清准备周期和消耗。
  - 赶路与入场：参与者抵达拍卖地点，途中可能遭遇盘查、跟踪、护送任务或截杀预兆。
  - 竞价与成交：关键拍品开始竞价，写清抬价、争抢、消耗灵石、身份暴露和最终获得物。
  - 离场与冲突：拍卖结束后，因财富暴露或宝物价值引发跟踪、截杀、交易、交换、结盟或通缉。
- 参与者覆盖：写卖方、买方、竞价者、旁观势力、跟踪者或失败竞拍者的准备、竞价、离场和后续差异；原文未说明更多参与方时如实标注。
- 收益：丹药、材料、法宝、功法、情报、传承线索、商会关系或拍卖所得。
- 风险与失败：竞价失败、灵石不足、身份暴露、被抬价、被跟踪、离场遭截杀、交易物被抢。
- 余波：拍品改变角色修炼路线，资源价格变化，商会声誉变化，夺宝冲突或后续秘境事件被触发。


### 示例案例三：强者洞府消息扩散形成机会点


### 强者洞府消息扩散形成机会点

- 事件类型：资源类机会 / 强者遗泽
- 准入理由：强者洞府线索会经历发现、隐瞒、泄露、准备、抵达、破禁、探索和带出资源等阶段，参与者会因消息真假、准备程度和撤离能力不同产生不同结果。
- 事件阶段：发现、隐瞒、泄露、售卖、误传、准备、抵达、破禁、探索、分赃、逃离、余波
- 触发/预兆：某强者洞府、遗泽或坐化地点被发现，原文写到地点、最初线索或禁制异动时逐项记录。
- 时间窗口：写洞府出现、禁制松动、队伍集结、破禁、探索、封闭或错过的时间。
- 地点/范围：写洞府位置、周边封锁范围、多方势力抵达路线和影响地域。
- 消息渠道与知晓范围：写发现者隐藏、泄露、售卖、误传或被他人截获消息的过程，以及哪些势力或散修知晓。
- 参与条件：地图、破禁手段、法宝、丹药、队伍、退路、境界、阵法知识、保命手段等。
- 准备行为：判断价值和风险，准备地图、破禁器具、法宝、丹药、队伍、退路，或与他人谈判合作。
- 行动链节点：
  - 发现与扩散：洞府线索出现后，消息被隐藏、泄露、售卖或误传；写清知晓范围和假消息影响。
  - 抵达与试探：多方势力或散修抵达洞府附近，发生封锁、谈判、偷袭、试探或组队。
  - 破禁与探索：洞府开启或禁制被破，参与者进入探索；写清材料、功法、法宝、尸骸、灵药或情报获得情况。
  - 冲突与逃离：洞府内出现机关、残魂、妖兽、禁制、分赃冲突或背叛；写清伤亡、消耗和逃生。
  - 带出与追逐：洞府资源被带出或遗失，部分参与者被追杀、通缉、交换或被迫交易。
- 参与者覆盖：写发现者、隐瞒者、买消息者、破禁者、夺宝者、失败者或追杀者的参与、错过和结算差异；原文未说明更多参与方时如实标注。
- 收益：材料、功法、法宝、尸骸线索、灵药、传承、情报、人情或后续遗迹线索。
- 风险与失败：禁制反噬、机关伤亡、妖兽袭击、残魂夺舍、背叛、分赃冲突、被追杀、资源遗失。
- 余波：洞府传承影响角色修炼，宝物流向坊市，死亡消息传播，幸存者形成仇怨或下一轮夺宝事件。
