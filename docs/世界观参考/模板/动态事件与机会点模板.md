# 动态事件与机会点模板

## 适用范围

用于整理小说中出现过，或能由资料来源明确支撑的动态事件行动链。

本模板不写总览、证据段、抽象规则表，也不单独拆“事件类型、生命周期、信息传播、项目映射”等表格字段。普通剧情若没有窗口期、传播过程和参与选择，应放入更合适的模板。

## 前置声明

- 样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角机缘或成功案例。
- 案例只是最低写法示范，不是数量上限；原文有价值内容可以继续展开。
- 原文没有说明的时间、地点、消息来源、参与条件、消耗、收益、风险、结果或余波，写“原文未说明”。
- 信息不足但值得追踪的事件放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

每个案例只写事件行动链。事件必须能形成“知道消息 - 做准备 - 赶往/参与 - 获得或失败 - 产生余波”的链条。

| 类型 | 示例 | 重点 |
|------|------|------|
| 开启类机会 | 秘境开启、遗迹开放、强者洞府、飞升通道 | 写清预兆、开启窗口、进入条件和关闭后果。 |
| 交易类机会 | 拍卖会、商会盛会、坊市消息 | 写清预告、准备资源、竞价、交易和截杀余波。 |
| 资源类机会 | 灵药成熟、矿脉发现、宝物出世、妖王陨落 | 写清发现、传播、争夺、采集或带出后的影响。 |
| 势力类事件 | 宗门大比、兽潮、宗门战争、通缉悬赏 | 写清公告、动员、参与资格、奖励、伤亡和势力变化。 |

行动链节点可写：时间、事件阶段、消息来源与知晓范围、参与条件、准备行为、消耗、收益、风险、错过或失败后果、余波。原文写了多少就写多少，不补空白。

常见阶段：预兆、传闻、公告、暗中传播、准备、赶路、开启、进入、争夺、结算、关闭、过期、错过、余波。

## 案例

### 案例

#### 案例 1：秘境开启与多人争夺

**事件行动链：**

1. 某地出现秘境预兆，如天象、灵气波动、令牌异动、遗迹入口松动或妖兽异常；写清时间、地点、持续时间和最初发现者。
2. 消息由宗门、散修、坊市、商会或主角知晓并传播；写清消息来源、可信度、范围和速度。
3. 参与条件明确，如令牌、地图、境界、队伍、赶路时间、宗门资格或灵石准备。
4. 参与者购买丹药、符箓、法宝，修复装备，组队，打探情报，隐藏身份，提前赶往入口。
5. 秘境开启；写清开启时间、持续时间、入口位置、人数或境界限制。
6. 参与者采药、寻宝、破禁、争夺传承或遭遇妖兽；写清消耗、收益、伤势、法宝损耗和关系变化。
7. 秘境关闭或窗口结束；写清迟到、未出、被困、失踪或死亡后果。
8. 余波：宝物流入坊市或拍卖，幸存者被追杀，宗门关系变化，引发下一轮冲突或修炼行动链。

#### 案例 2：拍卖会引发准备、竞价和截杀

**事件行动链：**

1. 坊市、商会或大城发布拍卖会消息；写清预告时间、地点、主办方和重点拍品。
2. 消息传播到宗门、散修、家族、邪修或主角手中；写清谁提前知道、谁临时知道、谁通过情报渠道知道。
3. 参与者准备灵石、抵押物、可交易材料或护卫力量；写清准备周期和消耗。
4. 参与者赶往拍卖地点，途中可能遭遇盘查、跟踪、护送任务或截杀预兆。
5. 拍卖开始；写清关键拍品、竞价过程、消耗灵石、抬价、争抢或身份暴露。
6. 拍卖结束后，因财富暴露或宝物价值引发跟踪、截杀、交易、交换、结盟或通缉。
7. 余波：拍品改变角色修炼路线，资源价格变化，商会声誉变化，后续夺宝或秘境事件被触发。

#### 案例 3：强者洞府消息扩散形成机会点

**事件行动链：**

1. 强者洞府、遗泽或坐化地点被发现；写清发现者、地点、时间和最初线索。
2. 消息被隐藏、泄露、售卖或误传；写清来源、知晓范围和真假信息。
3. 参与者判断价值和风险，准备地图、破禁手段、法宝、丹药、队伍或退路。
4. 多方势力或散修抵达洞府附近，发生试探、封锁、谈判、偷袭或组队。
5. 洞府开启或禁制被破；写清材料、功法、法宝、尸骸、灵药或情报如何被获得。
6. 洞府内出现机关、残魂、妖兽、禁制、分赃冲突或背叛；写清伤亡、消耗和逃生。
7. 余波：资源被带出或遗失，幸存者被追杀、通缉或被迫交易，传承影响后续修炼和仇怨。
