# 动态事件与机会点模板


## 适用范围

本文只整理小说中出现过，或能由小说内容明确支撑的动态事件行动链，不写总览，不写证据段，不写抽象规则表，不单独拆“事件类型、生命周期、信息传播、项目映射”等表格字段。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

每个案例只写事件行动链。事件行动链要按原文先后顺序逐步写清一个有时间窗口的事件如何出现：预兆、消息传播、参与者知晓、准备、开启、参与、结算、错过、过期和余波。

行动链里的每个小节点都尽量写清“时间 / 事件阶段 / 消息来源与知晓范围 / 参与条件 / 准备行为 / 消耗 / 收益 / 风险 / 错过或失败后果 / 余波”。如果原文写了预告时间、准备周期、开启时间、结束时间、赶路时间、传播范围、令牌要求、境界限制、队伍要求、奖励或死亡风险，要写进对应小节点。原文写了多少就写多少；没有写的不要补。

不要把一次没有窗口期、没有传播过程、没有参与选择的普通剧情写成动态事件。只有当事件能形成“知道消息 - 做准备 - 赶往/参与 - 获得或失败 - 产生余波”的链条时，才放入本模板；否则应放到冲突事件、世界状态、角色修炼历程或其他更合适的模板中。

主角遇到的机缘要写，但不要只写主角机缘。NPC、配角、宗门、商会、邪修、妖兽、旁观势力对同一动态事件的知晓、准备、参与、错过和余波也很重要。

参考范围不局限于以下类别：

- **事件类型**：秘境开启、宗门大比、拍卖会、宝物出世、强者洞府、妖王陨落、高手遗泽、兽潮、宗门战争、通缉悬赏、飞升通道、灵药成熟、矿脉发现、商会盛会、遗迹开放。
- **事件阶段**：预兆、传闻、公告、暗中传播、准备、赶路、开启、进入、争夺、结算、关闭、过期、错过、余波。
- **消息来源**：目击、传闻、坊市消息、宗门公告、商会情报、令牌感应、天象、地图线索、遗迹异动、妖兽迁徙、通缉榜、拍卖预告。
- **参与条件**：境界、令牌、地图、队伍、距离、身份、关系、灵石、资源准备、宗门资格、商会邀请、时间窗口、保命手段。
- **准备行为**：购买丹药、购买符箓、修复法宝、打探情报、组队、取得令牌、赶路、隐藏身份、闭关调整状态、雇佣护卫、联系宗门或商会。
- **收益**：物品、功法、材料、境界突破资源、关系、人情、声望、职位、情报、战利品、妖兽材料、拍卖所得、传承。
- **风险与失败**：死亡、重伤、被抢、被追杀、队友背叛、事件过期、资源不足、误信传闻、赶路失败、令牌被夺、错过开启窗口、被困秘境、惹上仇怨。
- **余波**：宝物流入坊市、追杀、通缉、宗门关系变化、消息传播、资源价格变化、势力重新洗牌、下一轮事件被触发。

## 案例

### 案例

#### 案例 1：秘境开启与多人争夺

**事件行动链：**

1. 某地出现秘境预兆，例如天象、灵气波动、令牌异动、遗迹入口松动或妖兽异常；写清时间、地点、持续时间和最初发现者。
2. 消息开始传播，先由某宗门、散修、坊市、商会或主角知晓；写清消息来源、可信度、传播范围和传播速度。
3. 参与条件逐渐明确，例如需要令牌、地图、特定境界、队伍、赶路时间、宗门资格或灵石准备。
4. 参与者开始准备：购买丹药、符箓、法宝，修复装备，组队，打探情报，隐藏身份，提前赶往入口。
5. 秘境开启，写清开启时间、持续时间、入口位置、能进入的人数或境界限制。
6. 参与者进入秘境，采药、寻宝、破禁、争夺传承或遭遇妖兽；每个小事件写清消耗、收益、伤势、法宝损耗或关系变化。
7. 秘境内发生争夺、背叛、截杀或合作；写清谁获得资源、谁失去资源、谁死亡或失踪。
8. 秘境关闭或窗口结束；写清未出来者后果、迟到者是否错过、留在秘境内是否被困。
9. 余波：宝物流入坊市或拍卖，幸存者被追杀，宗门关系变化，消息传播，引发下一轮冲突或修炼行动链。

#### 案例 2：拍卖会引发准备、竞价和截杀

**事件行动链：**

1. 某坊市、商会或大城发布拍卖会消息；写清预告时间、地点、主办方和已公开的重点拍品。
2. 消息传播到宗门、散修、家族、邪修或主角手中；写清谁提前知道、谁临时知道、谁通过情报渠道知道。
3. 参与者准备灵石、抵押物、可交易材料或护卫力量；写清准备周期和消耗。
4. 参与者赶往拍卖地点，途中可能遭遇盘查、跟踪、护送任务或截杀预兆。
5. 拍卖开始，写清关键拍品、竞价过程、消耗灵石、是否发生抬价、争抢或身份暴露。
6. 某角色拍得丹药、材料、法宝、功法、情报或传承线索；写清获得物和消耗物。
7. 拍卖结束后，因财富暴露或宝物价值引发跟踪、截杀、交易、交换、结盟或通缉。
8. 余波：拍品改变某角色修炼路线，资源价格变化，商会声誉变化，夺宝冲突或后续秘境事件被触发。

#### 案例 3：强者洞府消息扩散形成机会点

**事件行动链：**

1. 某强者洞府、遗泽或坐化地点被发现；写清发现者、地点、时间和最初线索。
2. 消息可能被隐藏、泄露、售卖或误传；写清消息来源、知晓范围和是否有假消息。
3. 参与者判断价值和风险，准备地图、破禁手段、法宝、丹药、队伍或退路。
4. 多方势力或散修抵达洞府附近，发生试探、封锁、谈判、偷袭或组队。
5. 洞府开启或禁制被破，参与者进入并探索；写清每个阶段获得的材料、功法、法宝、尸骸、灵药或情报。
6. 洞府内出现机关、残魂、妖兽、禁制、分赃冲突或背叛；写清伤亡、消耗和逃生。
7. 洞府资源被带出或遗失，部分参与者被追杀、通缉或被迫交易。
8. 余波：洞府传承影响角色修炼，宝物流向坊市，死亡消息传播，幸存者形成仇怨或下一轮夺宝事件。
