# 世界观设定模板

# 规范

用于整理作品中的世界区域风貌、地图分区、自然地理、人文风俗与生态参考。

- 样本要覆盖不同界面、地域、势力、族群、生态和时代状态；不要只写主角走过的少数地点。
- 本文写成“地理志 / 风物志 / 地图区设定”，不写剧情梗概、任务流程、资源危险清单或势力制度详解。
- 每个区域都要尽量写出它“看起来是什么样、住着什么人、有什么地形、什么建筑、什么衣着风俗、有什么妖兽灵草、整体气质是什么”。
- 可以参考现实区域写法：黄土高原有黄土沟壑，中东有沙漠石城与面纱长袍，海南有海滩椰林和湿热海风。修仙世界也要写出类似可感知的区域差异。
- 只写原文或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 原文没有说明衣着打扮、建筑样式、具体妖兽种类、灵草灵果或地貌细节时，不要硬补，可以写“原文未说明”。但可以写清“可确认的风貌倾向”，例如海域、草原、冰寒、山地宗门、魔化森林等。
- 主角经历只有在能揭示地貌、人文、生态或地图功能时才引用。
- 背景时间线只用于说明区域风貌为什么形成，例如古战场、封印地、传送阵、界面战争、飞升通道重启。
- 底层世界规则只写会影响区域风貌的部分，例如灵气浓淡、魔气、阴气、寒气、瘴气、界面压制和空间节点。
- 不把其他专题模板已经承载的细节搬进本文：境界突破去境界模板，宗门制度去势力模板，秘境机制去秘境模板，交易细节去交易模板，灾变机制去世界状态与灾变模板。

## 参考和要求
本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 界面层级：人界、灵界、仙界、魔界、冥界、神界、小世界、洞天、星域、诸天万界、附属空间；写清层级关系、通道、压制或差异。
- 区域类型：凡俗王朝、宗门山门、散修坊市、妖族地盘、魔道区域、边荒、海域、草原、山脉、冰原、荒漠、地下世界、禁区、飞升通道；写清区域功能和地图位置。
- 自然地理：山川、河流、海岛、港口、草原、沙漠、雪原、森林、沼泽、峡谷、洞窟、灵脉、矿脉、魔气区、阴气区、瘴气区；写清可感知的地貌和环境。
- 聚落建筑：凡人村镇、王朝都城、宗门山门、洞府、坊市、港口、岛城、草原部落、边境要塞、仙城、魔族要塞、古遗迹、封印建筑；写清建筑形态、聚落功能和进入限制。
- 风俗人文：衣着打扮、语言称呼、生活方式、贸易习惯、宗门弟子风貌、凡人对修士的态度、修士对凡俗的干预、地域性审美和礼俗；写清人如何生活，而不只写地点名。
- 生物生态：普通野兽、妖兽、灵兽、魔兽、灵虫、毒虫、鬼物、异族生物、灵草、灵果、灵木、药园、灵田、海兽、草原兽群、魔化植物；写清生态分布和区域差异。
- 修仙痕迹：护山大阵、坊市禁制、传送阵、灵气浓淡、灵脉山、妖兽巢穴、魔气污染、古战场、封印地、飞升台、秘境入口；写清修仙元素如何出现在地图上。
- 区域气质：宗门化、商业化、海域化、游牧化、边疆化、冰寒、荒凉、繁荣、封闭、流动、古老、魔化、仙气缥缈；给地图、美术和氛围生成参考。
- 区域风貌卡字段：正式条目按下列卡片字段整理。

- 区域定位：新手区、凡俗农耕区、宗门山地、海域贸易区、草原边疆、冰寒禁地、魔化战区、地下深渊、上界仙域等。
- 地图位置与相邻关系：方位、连接区域、靠海/靠草原/靠禁区/靠传送阵/靠跨界通道；不明写“原文未说明精确方位”。
- 地形地貌与自然环境：山脉、平原、海岛、沙漠、冰原、森林、地下、湿热、寒冷、干旱、灵气或魔气浓淡。
- 城镇、建筑与聚落形态：村镇、都城、山门、坊市、港口、部落、要塞、仙城、洞府、宫殿、遗迹、封印建筑。
- 风俗与人文地理：衣着、称呼、生活方式、贸易习惯、宗门日常、凡人和修士关系。
- 生物种类与生态：妖兽、灵兽、普通动物、灵虫、鬼物、魔兽、灵草、灵果、药园、灵田、海兽、草原兽群。
- 修仙痕迹：灵脉山、护山大阵、传送阵、试炼禁地、封印地、古战场、魔气污染、妖兽巢穴、药园、洞府、飞升台。
- 视觉关键词：用短词概括，例如黄土沟壑、海岛港口、黑色魔气森林、冰雪宫殿、草原帐篷、古山封印、仙城云海。

### 案例

#### 区域案例：区域名

```md
# 《作品名》世界观设定

## 世界区域风貌卡片

### 区域名称

- 区域定位：
- 地图位置与相邻关系：
- 地形地貌与自然环境：
- 城镇、建筑与聚落形态：
- 风俗与人文地理：
- 生物种类与生态：
- 修仙痕迹：
- 视觉关键词：

### 人界区域

- 区域定位：凡俗聚落、宗门山门、坊市、山川地貌、低阶生态和地图入口。
- 地图位置与相邻关系：按作品设定填写；不明时写“原文未说明精确方位”。
- 地形地貌与自然环境：山川、平原、森林、河流、低阶灵气环境等，按作品设定填写。
- 城镇、建筑与聚落形态：凡人村镇、王朝都城、宗门山门、散修坊市等，按作品设定填写。
- 风俗与人文地理：凡人与修士关系、地域生活方式、衣着称呼和贸易习惯，按作品设定填写。
- 生物种类与生态：普通动物、低阶妖兽、灵草、灵田或药园等，按作品设定填写。
- 修仙痕迹：护山大阵、坊市禁制、传送阵、试炼禁地、洞府或低阶秘境入口。
- 视觉关键词：按作品设定填写，例如凡俗城镇、宗门山地、坊市街巷、低阶灵田。

### 灵界区域

- 区域定位：上层界面区域、强族或宗门分布区、跨界通道或特殊生态区域。
- 地图位置与相邻关系：按作品设定填写；不明时写“原文未说明精确方位”。
- 地形地貌与自然环境：灵气环境、区域压制、特殊地貌和强族生存环境，按作品设定填写。
- 城镇、建筑与聚落形态：灵界城池、强族聚落、宗门驻地、跨界节点建筑等，按作品设定填写。
- 风俗与人文地理：强族风貌、上层界面生活方式、地域性礼俗和贸易习惯。
- 生物种类与生态：高阶妖兽、灵兽、异族生物、灵草灵果和特殊生态。
- 修仙痕迹：跨界通道、传送阵、灵脉山、强族禁地、上层界面禁制。
- 视觉关键词：按作品设定填写，例如灵气山川、异族城池、跨界通道、强族禁地。

### 仙界区域

- 区域定位：仙域层级、飞升者活动区、上界势力分区或仙界资源环境。
- 地图位置与相邻关系：按作品设定填写；不明时写“原文未说明精确方位”。
- 地形地貌与自然环境：仙域地貌、资源环境、空间层级和与下界不同的环境特征。
- 城镇、建筑与聚落形态：仙城、宫殿、洞府、仙域势力建筑和飞升相关场所。
- 风俗与人文地理：仙界修士生活方式、势力交往方式、飞升者处境和地域秩序。
- 生物种类与生态：仙界灵兽、仙草仙木、特殊资源生态和高阶异类生物。
- 修仙痕迹：飞升台、仙阵、仙域通道、上界禁地、势力控制节点。
- 视觉关键词：按作品设定填写，例如仙城云海、飞升台、仙域宫殿、上界灵山。
```
