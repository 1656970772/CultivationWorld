# 世界观设定模板

## 适用范围

用于整理作品中的世界区域风貌、地图分区、自然地理、人文风俗与生态参考。

## 前置声明

- 样本要覆盖不同界面、地域、势力、族群、生态和时代状态；不要只写主角走过的少数地点。
- 本文写成“地理志 / 风物志 / 地图区设定”，不写剧情梗概、任务流程、资源危险清单或势力制度详解。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 主角经历只有在能揭示地貌、人文、生态或地图功能时才引用。
- 信息不足但符合主题的内容，先写入 `### 待定案例`。后续获得新信息时，在同一待定项追加摘要和来源；信息足够后，复核来源并转为正式案例。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 界面层级 | 人界、灵界、仙界、魔界、冥界、神界、小世界、洞天、星域、附属空间 | 写清层级关系、通道、压制或差异。 |
| 区域类型 | 凡俗王朝、宗门山门、散修坊市、妖族地盘、魔道区域、边荒、海域、草原、冰原、荒漠、禁区、飞升通道 | 写清区域功能和地图位置。 |
| 自然地理 | 山川、河流、海岛、港口、森林、沼泽、洞窟、灵脉、矿脉、魔气区、阴气区、瘴气区 | 写清可感知的地貌和环境。 |
| 聚落建筑 | 村镇、都城、山门、洞府、坊市、港口、岛城、部落、边境要塞、仙城、魔族要塞、古遗迹、封印建筑 | 写清建筑形态、聚落功能和进入限制。 |
| 风俗人文 | 衣着、语言称呼、生活方式、贸易习惯、宗门弟子风貌、凡人对修士的态度、地域礼俗 | 写清人如何生活，而不只写地点名。 |
| 生物生态 | 普通野兽、妖兽、灵兽、魔兽、灵虫、毒虫、鬼物、异族生物、灵草、灵果、灵木、药园、灵田、海兽 | 写清生态分布和区域差异。 |
| 修仙痕迹 | 护山大阵、坊市禁制、传送阵、灵气浓淡、妖兽巢穴、魔气污染、古战场、封印地、飞升台、秘境入口 | 写清修仙元素如何出现在地图上。 |
| 区域气质 | 宗门化、商业化、海域化、游牧化、边疆化、冰寒、荒凉、繁荣、封闭、流动、古老、魔化、仙气缥缈 | 给地图、美术和氛围生成参考。 |

写作提示：

- 背景时间线只用于说明区域风貌为什么形成，例如古战场、封印地、传送阵、界面战争、飞升通道重启。
- 底层世界规则只写会影响区域风貌的部分，例如灵气浓淡、魔气、阴气、寒气、瘴气、界面压制和空间节点。
- 不把其他专题模板已经承载的细节搬进本文：境界突破去境界模板，宗门制度去势力模板，秘境机制去秘境模板，交易细节去交易模板，灾变机制去世界状态与灾变模板。

区域风貌卡字段：

- 区域定位：新手区、凡俗农耕区、宗门山地、海域贸易区、草原边疆、冰寒禁地、魔化战区、地下深渊、上界仙域等。
- 地图位置与相邻关系：方位、连接区域、靠海/靠草原/靠禁区/靠传送阵/靠跨界通道；不明写“原文未说明精确方位”。
- 地形地貌与自然环境：山脉、平原、海岛、沙漠、冰原、森林、地下、湿热、寒冷、干旱、灵气或魔气浓淡。
- 城镇、建筑与聚落形态：村镇、都城、山门、坊市、港口、部落、要塞、仙城、洞府、宫殿、遗迹、封印建筑。
- 风俗与人文地理：衣着、称呼、生活方式、贸易习惯、宗门日常、凡人和修士关系。
- 生物种类与生态：妖兽、灵兽、普通动物、灵虫、鬼物、魔兽、灵草、灵果、药园、灵田、海兽、草原兽群。
- 修仙痕迹：灵脉山、护山大阵、传送阵、试炼禁地、封印地、古战场、魔气污染、妖兽巢穴、药园、洞府、飞升台。
- 视觉关键词：用短词概括，例如黄土沟壑、海岛港口、黑色魔气森林、冰雪宫殿、草原帐篷、古山封印、仙城云海。

### 案例

#### 人界区域案例：区域名

#### 灵界区域案例：区域名

按区域风貌卡填写。重点写上层界面差异、灵气环境、强族或宗门分布、跨界通道、特殊生态和区域压制。

#### 仙界区域案例：区域名

按区域风貌卡填写。重点写仙域层级、建筑气质、资源环境、飞升者位置、势力分区和与下界不同的视觉关键词。
