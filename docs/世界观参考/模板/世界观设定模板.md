# 世界观设定模板

## 适用范围

本模板用于将作品中的空间资料整理为总结式的地理志、风物志和区域设定，主要记录界面与区域层级、地图分区、自然地理、气候体感、聚落建筑、居民生计、风俗人文、生物生态和超凡痕迹。

可独立成卡的对象包括界面、大陆、国家、州郡、城市、宗门山门、坊市港口、生态区、禁区、重要交通节点，以及长期存在并具有独立空间功能的特殊区域。房间、个人住所、训练点、临时聚集点和单次事件地点，只有在反复出现、具有独立地图功能、视觉差异明显或承载关键世界规则时才单独成卡，否则并入父级区域。

本模板不收录人物、完整生灵、势力组织、制度层级、功法、丹药、法宝、交易价格、战斗过程、修炼流程和单次剧情事件。其他专题中的内容，只记录其对区域空间、居民生活、生态分布、交通运行和整体气质产生的最小结果。

## 整理原则

1. 先做区域准入：对象必须具有稳定的空间边界、独立地图功能、长期运行的区域功能或可重复识别的环境特征；人物、势力、制度、物品和单次事件不得包装成区域卡。
2. 先建层级再建卡：先确定界面/大陆、国家/州郡、城市/山门、子区域/特殊空间的父子关系，再决定成卡、并入父卡、不纳入本文或本次未覆盖；层级总览是后续建卡的约束。
3. 同级同尺度，一处区域一张卡：同一区域的别名、时代变化和后续风貌归入同一卡；普通房间、训练点、仪式场地、附属设施和临时地点归入父卡，只有具备独立空间功能时才另建卡。
4. 输出总结式设定：每个字段只写稳定结论、空间关系和可供地图/美术/场景使用的信息；不复制原文长句，不堆叠人物对白、剧情经过、战斗过程、制度说明或逐章记录。
5. 静态结构优先，动态只写结果：形成、扩张、稳定、衰退、毁坏、重建、迁移等动态内容，只记录其对地貌、生态、聚落、人口、交通、区域功能和整体气质造成的结果，不复述事件过程。
6. 严格区分相邻字段：位置写外部拓扑，地标与动线写内部通行；建筑写整体形态，子区域写功能分区；自然环境写非生命底盘，生态写生命系统；超凡痕迹写人工设施、长期改造或遗留影响。
7. 机制只写空间影响：修炼、炼药、交易、势力制度、秘境规则和灾变只保留其对区域分布、建筑功能、居民生计、生态和区域气质的影响，不展开机制本体或事件经过。
8. 正常、异常和极端状态分开：常态写稳定风貌与功能；异常和极端状态只写触发条件、空间影响、交通/生态/聚落变化及恢复、持续衰退或不可逆结果；没有相关内容时写“作品未说明”。
9. 信息不足时如实标注：使用“原文明确”“稳定归纳”“实际表现”“合理推断”“作品未说明”“本次未覆盖到明确内容”“不适用”等确定性类型；不得根据题材常识、名称或单一场景补写区域通则。
10. 控制文档密度并自检：普通字段以一至三条短句为主，视觉关键词保留 5—8 个稳定、可感知的短词；检查准入、层级、字段边界、重复卡、未知项和总结程度。

## 信息与输出规则

1. 世界观文档只保留提炼后的结论：原文中的描写、对白、数字、价格、人物动作和事件顺序，只有在能直接说明区域结构、生活方式、生态关系或空间结果时，才压缩为一句设定结论。
2. 不以素材数量代替设定质量：同一事实只在最合适的字段完整描述，其他字段只记录本字段产生的不同层面结果；连续未知字段可统一写“作品未说明”，不反复扩写同义句。
3. 禁止证据标注：任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留总结结论和确定性类型。
4. 禁止具体事件清单：异常、阶段变化、居民互动和运行节律不得写成逐步剧情、人物行程、战斗日志、交易明细或原文摘录。
5. 术语表只收空间相关术语：保留区域名、空间名、地理称呼和与区域痕迹直接相关的作品术语；人物、功法、丹药、法宝、能力和战斗招式转入对应专题，不在本表展开。
6. 事实与推断分开：人物判断、传闻和由多处内容归纳出的结论统一标明性质；存在冲突时并列记录不同状态，不擅自将未确认内容写成稳定世界规则。

## 字段说明

- **区域层级总览**：用表格列出区域层级、区域/空间、类型、处理方式和简要说明，统一父子关系与成卡尺度。处理方式填写“成卡”“并入父卡”“不纳入本文”或“本次未覆盖”。
- **原文术语与异名**：只列区域、空间、地理和区域痕迹相关术语，确定一个报告用名，保留作品用名或异写；同一报告用名不得重复建行。
- **区域定位**：用一句话概括区域的空间性质和主要功能，如凡俗农耕区、宗门山地、海域贸易区、冰寒禁地、魔化战区、上界仙域或洞天空间。
- **父级区域与层级**：填写直接父级及本对象所处层级，如界面、大陆、国家、州郡、城市、宗门山门、子区域或特殊空间。
- **地图位置与相邻关系**：填写区域在父级地图中的方位、边界、相邻对象、外部交通节点，以及与海域、草原、禁区、传送阵或跨界通道的连接关系；不写内部游览动线。
- **形成基础与阶段变化**：总结区域因自然演化、资源聚集、族群迁入、势力建设、超凡力量或历史变化形成的空间结果，以及扩张、稳定、衰退、毁坏、重建和永久变化；不复述形成事件。
- **地形地貌与自然环境**：填写山脉、平原、海岛、沙漠、冰原、森林、地下、河流、矿脉、灵脉以及灵气、斗气、道法气机、魔气、阴气和瘴气等非生命环境条件。
- **气候、季节与环境体感**：填写冷暖、湿干、昼夜温差、季节、风、雾、海潮、沙尘、寒气、热浪、气味、声音和身体压迫感；单一场景表现不得直接扩展为全区通则，必要时标为合理推断。
- **色彩、材质与光线**：填写区域主色、地表质感、建筑材质、光线明暗、雾气颜色、火光、水光、雪光、云光和稳定的超凡能量色调；不写人物衣着或单件道具颜色。
- **城镇、建筑与聚落形态**：填写村镇、都城、山门、坊市、港口、部落、要塞、学院、仙城、洞府、宫殿、遗迹和封印建筑的整体外观、密度、布局逻辑与空间关系；内部功能写入“子区域与空间功能”。
- **子区域与空间功能**：填写父级区域下的重要功能区、建筑群、交通节点和特殊空间，以及各子区域的用途、边界和视觉差异；普通房间和一次性地点不单独展开。
- **居民构成、生计方式与环境互动**：填写居民类型、聚居方式、主要生计、资源依赖、环境适应和生产建设对区域的反向影响；不写人物履历、境界、个人能力或组织制度细节。
- **地标、动线与进入感**：填写醒目地标、入口、内部道路、栈桥、山门、港口、传送阵、飞舟码头、驿道和主街，以及进入、离开或穿越区域时稳定的空间顺序与感知变化。
- **运行节律、要素流动与对外交换**：填写昼夜、季节、集市、法会、生产、迁徙等区域运行节律，以及人员、物资、生物、能量和信息的来源、去向、集散点、阻断点和外溢影响；不写价格表、交易过程或完整制度。
- **风俗与人文地理**：填写衣着风格、语言称呼、待客方式、饮食居住、节庆礼俗、行为习惯、地域审美和日常生活节奏；只写区域性、可归纳的共同特征。
- **生物种类与生态**：填写普通动物、妖兽、灵兽、魔兽、灵虫、毒虫、鬼物、异族生物、灵草、灵果、灵木和兽群的区域分布、迁徙、依存、竞争与环境反馈；只列与区域生态有关的对象，不展开单个生灵设定。
- **超凡体系痕迹**：按作品体系填写护山大阵、禁制、传送阵、斗气设施、魔气污染、古战场遗留、封印地、飞升台、洞天水府和灵穴洞府等人工设施、长期环境改造或事件遗留；只写其在地图、建筑、生态和区域气质上的结果。
- **异常、极端状态与恢复**：只按“触发条件 -> 影响范围 -> 地貌/生态/建筑/交通/居民功能变化 -> 恢复、持续衰退或不可逆结果”总结；人物交锋、招式过程、对白和剧情细节转入事件专题。
- **信息边界与不确定项**：填写合理推断、不同阶段或叙述之间的冲突，以及影响区域理解的重要未知项；只写信息性质和结论边界，不写来源位置或证据标注。
- **视觉关键词**：用 5—8 个短词概括最稳定、最有辨识度且可直接观察或感知的区域视觉；删去人物关系、制度判断、数量统计和剧情动作。
