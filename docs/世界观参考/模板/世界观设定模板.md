# 世界观设定模板

## 适用范围

本模板用于整理作品中的界面与区域层级、地图分区、自然地理、气候体感、聚落建筑、居民生计、风俗人文、生物生态和超凡痕迹，形成可供地图、美术、场景和氛围设计参考的“地理志 / 风物志 / 地图区设定”。

整理时将区域视为“层级与边界—形成与演变—自然与人文结构—日常运行—内外互动—异常变化—后续状态—感知表现”的完整空间系统。模板不要求每个区域机械填满所有状态，只记录作品实际涉及、能够形成连贯区域图景的内容。

可独立成卡的对象包括界面、大陆、国家、州郡、城市、宗门山门、坊市港口、生态区、禁区、重要交通节点，以及长期存在并具有独立空间功能的特殊区域。

房间、个人住所、训练点、临时聚集点和单次事件地点，只有在反复出现、具有独立地图功能、视觉差异明显或承载关键世界规则时才单独成卡；其他情况并入父级区域。物品、个体生物、人物身份、制度层级、功法、丹药和交易价格不建立区域卡，只保留其对父级区域风貌产生的最小影响。

境界突破、势力制度、秘境机制、交易规则和灾变过程由对应专题承载；本模板只记录这些机制在空间、生态、建筑、居民生活和区域气质上留下的结果。

## 整理原则

1. **先建立区域层级**

   正式建卡前先整理界面/大陆、国家/州郡、城市/宗门山门、子区域/场景和特殊空间之间的父子关系，并确定各对象是独立成卡、并入父卡还是不纳入本文。

2. **同级区域保持同一尺度**

   不在同一层级混排大陆、城市、山门、房间和单次地点。父级区域下的药园、厨房、石室、弟子居所、殿堂、法会道场和洞府区，原则上作为子区域或建筑形态记录。

3. **一处区域一张卡**

   同一区域的别名、不同译名、时代变化和后续风貌补充归入同一张卡。区域发生永久地貌变化、空间层级改变或被分裂为独立区域时，在同卡分阶段记录；只有形成新的独立空间实体时才另建卡。

4. **兼顾静态结构与动态过程**

   静态结构记录区域在某一阶段的自然底盘、空间组织、居民、生物和超凡痕迹；动态过程记录区域如何形成、如何运行、如何与外部交换，以及异常后如何恢复或转入新阶段。不得只罗列景物名称而缺少彼此关系，也不得用大段剧情代替区域变化结果。

5. **记录形成与阶段变化**

   对作品明确涉及的形成原因、扩张、稳定、衰退、毁坏、重建、迁移或永久变化，按阶段记录其对地貌、生态、聚落、人口、交通和区域功能造成的结果。形成过程或中间阶段没有说明时写“作品未说明”，不依据题材常识补写。

6. **区分正常、异常和极端状态**

   常态写区域稳定运行时的风貌与功能；异常状态写季节反常、局部污染、交通中断、资源波动或短期冲突造成的变化；极端状态写灾变、战争、封印失效、生态崩溃、区域毁灭等接近或越过承载极限的结果。作品没有展示某类状态时不推演，也不机械补齐三类状态。

7. **记录区域运行与双向互动**

   记录人员、物资、生物、能量和信息在区域内外的实际流动，以及居民如何依赖、适应和改造环境，区域又如何反向影响生计、聚落、交通和相邻地区。制度、交易和修炼机制只保留能够落到空间分布、运行节律或环境反馈的部分。

8. **优先呈现可感知差异**

   每张卡尽量回答区域看起来是什么样、体感如何、住着什么人、如何生活、有哪些建筑和动线、分布什么生物、超凡力量如何留在地图上，以及整体气质是什么。风貌描述应落实到地形、色彩、材质、光线、声音、气候和生活痕迹。

9. **覆盖不同区域与时代状态**

   样本应尽量覆盖不同界面、地域、势力、族群、生态和时代状态，不只整理主角走过的少数地点。主角经历只有能够揭示地貌、人文、生态或空间功能时才纳入。

10. **保留作品术语和异名**

   同一区域存在异写、别名或不同译名时，确定一个报告用名，并保留作品用名与异写。超凡体系字段应使用作品对应称谓，如修仙痕迹、斗气痕迹、道法痕迹、武学痕迹或魔法痕迹。

11. **只写区域风貌结果**

   修炼、炼药、交易、势力制度和资源规则只记录其对空间分布、建筑功能、居民生计和区域气质造成的结果，不展开完整机制、价格表、炼制流程或能力效果。

12. **谨慎使用背景变化**

   古战场、封印、界面战争、飞升通道重启和灾变等背景，只用于解释地貌、生态、聚落、交通或区域气质如何形成，不展开事件经过。

13. **明确信息与推断边界**

   作品直接说明或能够由多处内容稳定归纳的信息按实际内容填写；基于已知地形、功能或关系作出的必要推断，必须明确标为“合理推断”。作品没有说明的衣着、建筑样式、具体生物、植物、方位、地貌、运行周期或异常后果写“作品未说明”；不同阶段或叙述互相冲突时并列保留，不擅自裁定。

14. **明确相邻字段边界**

   “地图位置与相邻关系”写区域外部拓扑，“地标、动线与进入感”写内部通行和感知顺序；“城镇、建筑与聚落形态”写整体布局，“子区域与空间功能”写内部功能分区；“地形地貌与自然环境”写非生命底盘，“生物种类与生态”写生命系统，“超凡体系痕迹”写人工设施、长期改造或事件遗留。相同内容只在主要字段完整描述，其他字段只写其产生的不同层面结果。

15. **控制字段长度**

    每个字段以一至三条短句为主；信息较多时按子区域、族群或时代阶段分项。避免将单个字段写成长篇制度说明或剧情复述。

16. **视觉关键词保持可视化**

    视觉关键词只使用能够直接观察、感知或由区域风貌确认的短词，不写抽象制度判断、具体道具名称或未经确认的本质结论。

17. **输出前自检**

   检查区域准入与层级是否一致、父子区域是否重复成卡、静态与动态信息是否形成连贯链条、相邻字段是否重复、正常与异常状态是否混写、术语是否适配作品体系、其他专题内容是否过度展开、案例是否保留实际风貌，以及未知内容和合理推断是否得到明确区分。

## 字段说明

- **区域层级总览**：列出层级、区域/空间、类型、处理方式和说明，用于统一父子关系和成卡尺度。处理方式填写成卡、并入父卡、不纳入本文或本次未覆盖到明确内容。
- **原文术语与异名**：列出报告用名、作品用名/异写和处理方式；同一区域只选一个报告用名，其他称谓作为异名保留。
- **区域定位**：填写区域在世界中的性质与功能，如凡俗农耕区、宗门山地、海域贸易区、草原边疆、冰寒禁地、魔化战区、上界仙域、斗气城镇或玄门洞天。
- **父级区域与层级**：填写界面、大陆、国家、州郡、城市、宗门山门、子区域或特殊空间等层级，以及直接父级区域。
- **地图位置与相邻关系**：填写区域在父级地图中的方位、边界、相邻对象、外部交通节点，以及与海域、草原、禁区、传送阵或跨界通道的连接关系；不在本字段展开内部游览动线。
- **形成基础与阶段变化**：填写区域因自然演化、资源聚集、族群迁入、势力建设、超凡力量或历史事件而形成的空间结果，以及扩张、稳定、衰退、毁坏、重建和后续永久变化；只写作品实际涉及的阶段，不复述完整事件过程。
- **地形地貌与自然环境**：填写山脉、平原、海岛、沙漠、冰原、森林、地下、河流、矿脉、灵脉，以及灵气、斗气、道法气机、魔气、阴气和瘴气等非生命环境条件；生物分布和人工设施分别写入对应字段。
- **气候、季节与环境体感**：填写冷暖、湿干、昼夜温差、季节、风、雾、海潮、沙尘、寒气、热浪、气味、声音和身体压迫感。
- **色彩、材质与光线**：填写区域主色、地表质感、建筑材质、光线明暗、雾气颜色、火光、水光、雪光、云光和超凡能量色调。
- **城镇、建筑与聚落形态**：填写村镇、都城、山门、坊市、港口、部落、要塞、学院、仙城、洞府、宫殿、遗迹和封印建筑的整体外观、密度、布局逻辑与空间关系；具体子区域用途写入“子区域与空间功能”。
- **子区域与空间功能**：填写父级区域下的药园、殿堂、斗气阁、拍卖场、法会道场、洞府区、港口和传送点，以及各子区域的用途和视觉差异。
- **居民构成、生计方式与环境互动**：填写农人、渔民、药农、矿工、佣兵、商旅、散修、宗门弟子、学院学生、部族、船夫和摊贩等居民，他们如何依靠和适应当地环境生活，以及生产、建设、采集或修炼活动如何反向改变区域。
- **地标、动线与进入感**：填写醒目地标、入口、内部道路、栈桥、山门、港口、传送阵、飞舟码头、驼道和主街，并描述进入、离开或穿越区域时的内部空间与感知变化。
- **运行节律、要素流动与对外交换**：填写昼夜、季节、集市、法会、生产、迁徙等实际存在的运行周期，以及人员、物资、生物、能量和信息在区域内部及相邻区域之间的来源、去向、集散点、阻断点和外溢影响。
- **风俗与人文地理**：填写衣着打扮、语言称呼、待客方式、饮食居住、交易称呼、节庆礼俗、行为习惯、地域审美和日常生活节奏。
- **生物种类与生态**：填写普通动物、妖兽、灵兽、魔兽、灵虫、毒虫、鬼物、异族生物、灵草、灵果、灵木、海兽和兽群的区域分布、迁徙、依存、竞争及其他生态关系；药园、灵田等人工空间写入建筑或子区域字段。
- **超凡体系痕迹**：按作品体系改名，填写护山大阵、禁制、传送阵、斗气测验场、斗气阁、魔气污染、古战场、封印地、飞升台、洞天水府和灵穴洞府等人工设施、长期环境改造或事件遗留；自然能量环境和生物巢穴分别写入自然环境与生态字段。
- **异常、极端状态与恢复**：填写区域偏离常态时的触发条件、影响范围、地貌与生态变化、建筑和交通状态、居民反应、功能中断，以及恢复、重建、持续衰退或不可逆后果；未出现异常或极端状态时写“作品未说明”。
- **信息边界与不确定项**：填写本卡中需要说明的合理推断、不同阶段或叙述之间的冲突，以及会影响区域理解的重要未知项；不得把题材惯例、人物猜测或单一场景表现直接写成区域通则。
- **视觉关键词**：用少量短词概括最稳定、最有辨识度的区域视觉，如黄土沟壑、海岛港口、黑色魔气森林、冰雪宫殿、草原帐篷、仙城云海或玄龟背水府。

### 斗气世界·乌坦城
