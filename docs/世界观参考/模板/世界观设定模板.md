# 世界观设定模板

## 适用范围

本模板用于整理作品中的界面与区域层级、地图分区、自然地理、气候体感、聚落建筑、居民生计、风俗人文、生物生态和超凡痕迹，形成可供地图、美术、场景和氛围设计参考的“地理志 / 风物志 / 地图区设定”。

可独立成卡的对象包括界面、大陆、国家、州郡、城市、宗门山门、坊市港口、生态区、禁区、重要交通节点，以及长期存在并具有独立空间功能的特殊区域。

房间、个人住所、训练点、临时聚集点和单次事件地点，只有在反复出现、具有独立地图功能、视觉差异明显或承载关键世界规则时才单独成卡；其他情况并入父级区域。物品、个体生物、人物身份、制度层级、功法、丹药和交易价格不建立区域卡，只保留其对父级区域风貌产生的最小影响。

境界突破、势力制度、秘境机制、交易规则和灾变过程由对应专题承载；本模板只记录这些机制在空间、生态、建筑、居民生活和区域气质上留下的结果。

## 整理原则

1. **先建立区域层级**

   正式建卡前先整理界面/大陆、国家/州郡、城市/宗门山门、子区域/场景和特殊空间之间的父子关系，并确定各对象是独立成卡、并入父卡还是不纳入本文。

2. **同级区域保持同一尺度**

   不在同一层级混排大陆、城市、山门、房间和单次地点。父级区域下的药园、厨房、石室、弟子居所、殿堂、法会道场和洞府区，原则上作为子区域或建筑形态记录。

3. **一处区域一张卡**

   同一区域的别名、不同译名、时代变化和后续风貌补充归入同一张卡。区域发生永久地貌变化、空间层级改变或被分裂为独立区域时，在同卡分阶段记录；只有形成新的独立空间实体时才另建卡。

4. **优先呈现可感知差异**

   每张卡尽量回答区域看起来是什么样、体感如何、住着什么人、如何生活、有哪些建筑和动线、分布什么生物、超凡力量如何留在地图上，以及整体气质是什么。风貌描述应落实到地形、色彩、材质、光线、声音、气候和生活痕迹。

5. **覆盖不同区域与时代状态**

   样本应尽量覆盖不同界面、地域、势力、族群、生态和时代状态，不只整理主角走过的少数地点。主角经历只有能够揭示地貌、人文、生态或空间功能时才纳入。

6. **保留作品术语和异名**

   同一区域存在异写、别名或不同译名时，确定一个报告用名，并保留作品用名与异写。超凡体系字段应使用作品对应称谓，如修仙痕迹、斗气痕迹、道法痕迹、武学痕迹或魔法痕迹。

7. **只写区域风貌结果**

   修炼、炼药、交易、势力制度和资源规则只记录其对空间分布、建筑功能、居民生计和区域气质造成的结果，不展开完整机制、价格表、炼制流程或能力效果。

8. **谨慎使用背景变化**

   古战场、封印、界面战争、飞升通道重启和灾变等背景，只用于解释地貌、生态、聚落、交通或区域气质如何形成，不展开事件经过。

9. **不补全未知细节**

   作品没有说明的衣着、建筑样式、具体生物、植物、方位或地貌细节写“作品未说明”。可以记录能够确认的风貌倾向，如海域、草原、冰寒、山地宗门、魔化森林、斗气城镇或玄门洞天，但不得据此虚构具体细节。

10. **控制字段长度**

    每个字段以一至三条短句为主；信息较多时按子区域、族群或时代阶段分项。避免将单个字段写成长篇制度说明或剧情复述。

11. **视觉关键词保持可视化**

    视觉关键词只使用能够直接观察、感知或由区域风貌确认的短词，不写抽象制度判断、具体道具名称或未经确认的本质结论。

12. **输出前自检**

    检查区域准入与层级是否一致、父子区域是否重复成卡、术语是否适配作品体系、自然与人文信息是否都能落到区域、其他专题内容是否过度展开、案例是否保留实际风貌，以及未知内容是否避免补设定。

## 字段说明

- **区域层级总览**：列出层级、区域/空间、类型、处理方式和说明，用于统一父子关系和成卡尺度。处理方式填写成卡、并入父卡、不纳入本文或本次未覆盖到明确内容。
- **原文术语与异名**：列出报告用名、作品用名/异写和处理方式；同一区域只选一个报告用名，其他称谓作为异名保留。
- **区域定位**：填写区域在世界中的性质与功能，如凡俗农耕区、宗门山地、海域贸易区、草原边疆、冰寒禁地、魔化战区、上界仙域、斗气城镇或玄门洞天。
- **父级区域与层级**：填写界面、大陆、国家、州郡、城市、宗门山门、子区域或特殊空间等层级，以及直接父级区域。
- **地图位置与相邻关系**：填写区域方位、连接对象、边界、交通节点，以及与海域、草原、禁区、传送阵或跨界通道的关系。
- **地形地貌与自然环境**：填写山脉、平原、海岛、沙漠、冰原、森林、地下、河流、矿脉、灵脉，以及灵气、斗气、道法气机、魔气、阴气和瘴气等环境。
- **气候、季节与环境体感**：填写冷暖、湿干、昼夜温差、季节、风、雾、海潮、沙尘、寒气、热浪、气味、声音和身体压迫感。
- **色彩、材质与光线**：填写区域主色、地表质感、建筑材质、光线明暗、雾气颜色、火光、水光、雪光、云光和超凡能量色调。
- **城镇、建筑与聚落形态**：填写村镇、都城、山门、坊市、港口、部落、要塞、学院、仙城、洞府、宫殿、遗迹和封印建筑的外观、布局与空间功能。
- **子区域与空间功能**：填写父级区域下的药园、殿堂、斗气阁、拍卖场、法会道场、洞府区、港口和传送点，以及各子区域的用途和视觉差异。
- **居民构成与生计方式**：填写农人、渔民、药农、矿工、佣兵、商旅、散修、宗门弟子、学院学生、部族、船夫和摊贩等居民，以及他们如何依靠当地环境生活。
- **地标、动线与进入感**：填写醒目地标、入口、道路、栈桥、山门、港口、传送阵、飞舟码头、驼道和主街，并描述进入、离开或穿越区域时的空间变化。
- **风俗与人文地理**：填写衣着打扮、语言称呼、待客方式、饮食居住、交易称呼、节庆礼俗、行为习惯、地域审美和日常生活节奏。
- **生物种类与生态**：填写普通动物、妖兽、灵兽、魔兽、灵虫、毒虫、鬼物、异族生物、灵草、灵果、灵木、药园、灵田、海兽和兽群的区域分布与生态关系。
- **超凡体系痕迹**：按作品体系改名，填写护山大阵、禁制、传送阵、灵脉山、斗气测验场、斗气阁、妖兽巢穴、魔气污染、古战场、封印地、飞升台、洞天水府和灵穴洞府等地图痕迹。
- **视觉关键词**：用少量短词概括最稳定、最有辨识度的区域视觉，如黄土沟壑、海岛港口、黑色魔气森林、冰雪宫殿、草原帐篷、仙城云海或玄龟背水府。

### 修仙世界·彩霞山七玄门

- 区域定位：凡俗江湖门派山门、早期武学活动区、修仙线索的前置空间。
- 父级区域与层级：凡俗地域下的山门区域；彩霞山为父级山地，七玄门各堂口、神手谷和炼骨崖为子区域。
- 地图位置与相邻关系：以山路连接附近村镇和门派入口；作品未说明更大范围内的精确方位。
- 地形地貌与自然环境：山地、崖壁、林木、山谷、水潭和药园共同构成封闭而层次分明的山门环境。
- 气候、季节与环境体感：山地空气清冷，谷地较为湿润，林木遮蔽处光线偏暗，神手谷带有明显草木与药材气息。
- 色彩、材质与光线：灰褐山石、深色木屋、绿色药草、幽暗石室和水潭反光形成主要色调。
- 城镇、建筑与聚落形态：山门、堂口、弟子居所、大屋、药园和石室沿山路与谷地分布。
- 子区域与空间功能：神手谷承担药园、医治和隐秘活动功能；炼骨崖承担训练与试炼功能；各堂口组织弟子日常活动。
- 居民构成与生计方式：门派弟子、杂役、药园照管者及附近村镇居民依靠堂口分工、山地资源和药园维持生活。
- 地标、动线与进入感：由山门沿山路进入堂口区域，再通过谷口抵达神手谷；崖壁、药园入口和石室通道形成内部辨识点。
- 风俗与人文地理：居民生活围绕门派秩序、习武作息、堂口称呼和山地往来展开，整体带有凡俗江湖门派气息。
- 生物种类与生态：山林普通动物、鸟类、水潭生物和药园植物构成基础生态，特殊生物集中在隐秘谷地和修仙线索附近。
- 修仙痕迹：神手谷中的修仙者活动、隐秘石室和特殊资源使凡俗山门出现早期修仙痕迹。
- 视觉关键词：彩霞山门、山谷药园、江湖堂口、崖壁水潭、幽暗石室。

### 斗气世界·乌坦城

- 区域定位：斗气大陆早期城镇、家族聚居区、坊市与拍卖场资源流通节点。
- 父级区域与层级：斗气大陆下的城镇区域；家族宅邸、测验广场、斗气阁、坊市和拍卖场为子区域。
- 地图位置与相邻关系：位于加玛帝国境内，通过道路连接其他城镇与佣兵活动区域。
- 地形地貌与自然环境：以内陆城镇街市、家族院落、广场和坊市巷道为主，自然地貌在城内表现较弱。
- 气候、季节与环境体感：街市人流密集，坊市嘈杂拥挤，开阔广场日照明显，深处巷道与室内交易空间较为昏暗。
- 色彩、材质与光线：石质广场、木石宅邸、坊市布棚、拍卖大厅灯光和深色帷幕构成主要视觉层次。
- 城镇、建筑与聚落形态：家族宅邸、测验广场、斗气阁、坊市店铺、拍卖大厅、鉴宝室和贵宾区域共同组成城镇功能区。
- 子区域与空间功能：斗气阁承担家族资源分配，测验广场承担资质与等级展示，坊市和拍卖场承担材料与物品流通。
- 居民构成与生计方式：家族成员、护卫、坊市摊贩、店铺掌柜、佣兵、拍卖场人员和普通居民依靠家族产业与交易活动生活。
- 地标、动线与进入感：家族大门、测验广场、坊市主街、坊市深处和拍卖场入口构成主要动线，身份差异影响可进入的空间。
- 风俗与人文地理：家族称呼、公开测验、坊市议价、拍卖礼仪和佣兵往来塑造竞争性较强的斗气城镇生活。
- 生物种类与生态：城内自然生态不突出，魔兽材料和药材主要通过佣兵、商旅和拍卖场进入城市。
- 斗气痕迹：测验魔石碑、斗气阁、炼药师活动、家族修炼空间和魔兽材料交易构成城内的斗气体系痕迹。
- 视觉关键词：斗气城镇、家族广场、坊市街巷、测验石碑、拍卖大厅。

### 玄门道法世界·苍梧山

- 区域定位：玄门下院山门、早期道法学习区、由峰观水涧构成的宗门地理空间。
- 父级区域与层级：东华洲下的宗门山门；善渊观、浩觉峰、荡云峰上泽观及各峰洞府区为子区域。
- 地图位置与相邻关系：十八峰与水涧组成内部山水网络，峰路、栈道、观宇和洞府将讲道、居住与修行区域连接起来。
- 地形地貌与自然环境：山峰、水涧、洞壁岩府、木板栈道、千人岩、飞瀑和流泉形成高差明显的山门环境。
- 气候、季节与环境体感：山中清冷多雾，水涧带来湿气与水声，峰间风声显著，洞府区域幽静封闭。
- 色彩、材质与光线：灰色岩壁、深色木栈道、观宇瓦木、碑刻铜柱、流泉水光和山雾共同形成清冷色调。
- 城镇、建筑与聚落形态：观宇、殿堂、法会道场、洞府、栈道、碑刻、铜柱和石雕依山势分布。
- 子区域与空间功能：善渊观构成山门与殿堂轴线；上泽观承担法会活动；各峰洞府区承担居住与修行。
- 居民构成与生计方式：下院弟子、观中道人、讲道人、听讲者、供奉者和洞府修行者围绕讲道、修行与山门日常往来。
- 地标、动线与进入感：山门、观宇轴线、木板栈道、洞壁岩府、法会道场、水涧与峰路构成层层上行的进入路径。
- 风俗与人文地理：衣着称呼、问道听讲、法会往来、供奉习惯和观宇作息形成清静而有秩序的玄门山居生活。
- 生物种类与生态：山林、水涧和洞府周边存在普通山中生态，仙鹤与玄龟主要作为玄门空间意象出现。
- 道法痕迹：蚀文、灵穴洞府、洞天水府、法会道场、山门道观和道法气机共同塑造玄门地理。
- 视觉关键词：十八峰水涧、洞壁岩府、木板栈道、玄门道观、法会道场。

### 灵界区域

- 区域定位：上层界面、强族与高阶宗门分布区、跨界通道和特殊生态汇聚区域。
- 父级区域与层级：位于人界之上的独立界面层级，内部包含强族领地、城池、灵脉山和禁地。
- 地图位置与相邻关系：通过跨界通道和传送节点与下界及内部各区域连接，空间距离与通行限制强于普通地域。
- 地形地貌与自然环境：高浓度灵气、灵脉山、异族领地、禁地和空间节点构成主要环境，部分区域存在界面压制。
