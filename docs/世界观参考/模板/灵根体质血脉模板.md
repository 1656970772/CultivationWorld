> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文只整理小说中明确出现过，或能由具体剧情支撑的灵根、体质、血脉、种族天赋、神魂天赋等资质信息。
- 本文不写总览，不写证据段，不写表格，不写游戏化抽象，不写项目字段映射。
- 不要只写“天才”“废柴”“资质很好”这类笼统评价，必须写清资质类型、获得方式、影响方向和风险代价。
- 灵根、体质、血脉、功法效果、丹药效果、法宝效果不要混写；如果某种能力来自功法或丹药，应放到对应模板中。
- 同一种资质如果存在不同获得方式，例如先天拥有、后天觉醒、洗髓改造、血脉融合、夺舍继承等，要分开写清。
- 同一种资质如果在不同境界、不同角色、不同族群身上表现不同，要分别写清，不要强行合并成通用规则。
- 主角资质样本要尽量完整；配角、反派、宗门天才、家族血脉、妖族、异族、特殊体质角色如果原文有清楚表现，也要补充。
- 原文没有说明获得方式、成长上限、风险代价、社会评价或后续变化时，不要补设定，可以写“原文未说明”。
- 不要把主角唯一体质、剧情外挂、特殊血脉返祖或不可复制机缘当成普通角色可批量拥有的通用资质。

## 完整资质案例

### 灵根篇

#### 案例 1：天灵根

类型：灵根 / 天灵根。

获得方式：先天出生具备；通常通过宗门、家族或修仙者检测发现；是否可后天获得按原文填写。

影响方向：修炼速度更快，瓶颈难度可能更低，宗门收徒价值更高，更容易获得师长、丹药、功法、洞府等资源倾斜；具体表现按原文填写。

风险代价：容易被宗门、家族、敌对势力、夺舍者或联姻对象关注；如果原文没有写被觊觎、被控制或后续代价，则写“原文未说明”。

#### 案例 2：伪灵根 / 多灵根

类型：灵根 / 伪灵根或多属性灵根。

获得方式：先天出生具备；检测后被判定资质较差或修炼速度受限。

影响方向：修炼速度较慢，突破更依赖丹药、灵石、功法、机缘和长期积累；可能导致角色在宗门评价、资源分配、师承机会中处于劣势。

风险代价：资源消耗更高，境界停滞概率更大，容易被同门轻视或放弃培养；如果角色靠机缘、丹药或特殊功法弥补，要写清补足方式。

### 体质篇

#### 案例 1：特殊道体 / 圣体 / 神体

类型：体质 / 道体、圣体、神体或同类高阶体质。

获得方式：多为先天拥有，也可能在血脉觉醒、传承改造、特殊环境洗礼后显现；按原文填写。

影响方向：可能提高修炼速度、战斗强度、肉身承受力、属性亲和、神通领悟或高境界成长上限；如果只在某一阶段显现，也要写明阶段。

风险代价：可能需要特殊资源培养，也可能引来夺体、夺舍、追杀、控制、联姻、宗门争夺等事件；若体质有反噬、封印、寿元或心魔问题，要单独写清。

#### 案例 2：毒体 / 寒体 / 火体等危险体质

类型：体质 / 毒体、寒体、火体、雷体或其他危险属性体质。

获得方式：先天携带、后天污染、吞服特殊灵物、修炼失控、血脉变异等；按原文填写。

影响方向：可能带来强属性攻击、抗性、特殊感知或修炼捷径，也可能限制可修功法、可用资源和日常行动。

风险代价：体质失控、反噬自身、伤害亲友、需要压制资源、被他人当作炉鼎或材料、被正邪势力争夺；具体代价按原文填写。

### 血脉篇

#### 案例 1：真灵血脉 / 神兽血脉

类型：血脉 / 真灵血脉、神兽血脉或高阶妖族血脉。

获得方式：先天继承、血脉返祖、吞噬血脉资源、传承觉醒、血脉融合；按原文填写。

影响方向：可能提升肉身、寿元、妖力、天赋神通、威压、族群地位和成长上限；如果血脉分阶段觉醒，要按阶段写清。

风险代价：血脉被觊觎、被猎杀取材、返祖失败、血脉冲突、族群控制、天劫压力、化形风险等；原文未说明则写“原文未说明”。

#### 案例 2：古族 / 王族 / 魔族血脉

类型：血脉 / 古族血脉、王族血脉、魔族血脉或异族血脉。

获得方式：血统继承、族群出生、血脉觉醒、混血显现、外力改造等。

影响方向：可能影响身份继承、族群地位、传承资格、特殊秘术、肉身或神魂强度、可进入的秘境和可获得的资源。

风险代价：族内斗争、继承争夺、血脉纯度歧视、被敌族追杀、被迫承担族群责任、血脉暴露后引发通缉或争夺。

### 神魂与天赋篇

#### 案例 1：神识强大 / 悟性异常

类型：神魂天赋 / 感知天赋 / 悟性天赋。

获得方式：先天具备、修炼中显现、神魂受刺激后觉醒、传承影响、夺舍或重修带来；按原文填写。

影响方向：可能提升神识探查、炼丹炼器、阵法符箓、功法领悟、战斗预判、心魔抵抗或秘术修炼效率。

风险代价：神魂负担更重，容易被高阶修士发现、夺舍、搜魂或利用；如果神识过强导致反噬、头痛、心魔或寿元损耗，要写清。

### 种族天赋篇

#### 案例 1：妖族 / 灵族 / 异族天赋

类型：种族天赋 / 妖族天赋、灵族天赋、异族天赋或特殊界面族群天赋。

获得方式：族群出生自带，或在成年、化形、血脉觉醒、传承仪式后显现。

影响方向：可能影响寿元、肉身、法力属性、天赋神通、环境适应、族群等级、领地控制和与人族修士的互动方式。

风险代价：受到族群身份限制，可能被敌对族群追杀、被修士捕猎、被当作材料或坐骑，也可能因血脉、领地、传承资格卷入族群内斗。
