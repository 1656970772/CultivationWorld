# 灵根体质血脉模板

## 适用范围

本文只整理小说中明确出现过，或能由具体剧情支撑的灵根、体质、血脉、种族天赋、神魂天赋等资质信息。

本文不写总览，不写证据段，不写游戏化抽象，不写项目字段映射；案例区简表只用于提示类型差异。

## 前置声明

- 只整理原文出现过，或能由原文和可靠资料来源明确支撑的灵根、体质、血脉、种族天赋和神魂天赋。
- 样本应覆盖多境界、多身份、多族群、多势力、多结局；不要只写主角、天才或成功案例。
- 不要只写“天才”“废柴”“资质很好”；必须写清类型、获得方式、影响方向和风险代价。
- 灵根、体质、血脉、功法效果、丹药效果、法宝效果不要混写；来源不同就放到对应模板。
- 原文没有说明的获得方式、成长上限、社会评价、风险代价或后续变化，写“原文未说明”，不要补设定。
- 信息暂不完整但值得保留的内容，先放入 `### 待定案例`；后续补充摘要和来源，足够支撑案例后再转入 `### 案例`。

## 必须写什么

本节是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **灵根类型**：五行灵根、单灵根、双灵根、三灵根、四灵根、五灵根、伪灵根、天灵根、异灵根、变异灵根、隐灵根、废灵根。
- **体质类型**：道体、圣体、神体、魔体、妖体、毒体、寒体、火体、剑体、雷体、肉身体质、炉鼎体质、长生体质、诅咒体质。
- **血脉类型**：妖兽血脉、神兽血脉、真灵血脉、王族血脉、古族血脉、魔族血脉、异族血脉、返祖血脉、混血血脉、可觉醒血脉。
- **神魂与感知天赋**：神识强大、悟性异常、天机感应、灵觉敏锐、阵法天赋、炼丹天赋、炼器天赋、御兽天赋、符箓天赋。
- **种族天赋**：妖族天赋、魔族天赋、灵族天赋、古族天赋、海族天赋、特殊界面族群天赋。
- **获得方式**：先天出生、检测发现、自然觉醒、境界突破觉醒、吞服灵物、洗髓、换血、血脉融合、传承改造、夺舍继承、诅咒污染。
- **影响方向**：修炼速度、突破难度、资源消耗、属性亲和、战斗能力、生存能力、寿元变化、神识变化、肉身变化、成长上限、身份地位、师承机会、婚姻联姻、被觊觎程度。
- **风险代价**：反噬、血脉冲突、体质失控、寿元损耗、心魔风险、被夺舍、被追杀、被势力控制、修炼路线受限、需要特殊资源维持。

写作要求：

- 同一种资质有多种获得方式时，分开写清。
- 同一种资质在不同境界、角色或族群身上表现不同时，分别记录，不强行合并。
- 主角资质样本要尽量完整；配角、反派、宗门天才、家族血脉、妖族、异族和特殊体质角色，有原文支撑就补充。
- 不要把主角唯一体质、剧情外挂、特殊返祖或不可复制机缘当成普通角色可批量拥有的资质。

## 案例

### 案例

#### 类型示例与重点

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 灵根 | 天灵根、异灵根、伪灵根、多灵根、废灵根 | 检测方式、修炼速度、突破难度、资源倾斜或资源劣势。 |
| 体质 | 道体、圣体、神体、毒体、寒体、火体、炉鼎体质 | 获得方式、阶段表现、可修路线、反噬、封印、被争夺风险。 |
| 血脉 | 真灵血脉、神兽血脉、古族血脉、王族血脉、魔族血脉 | 继承、返祖、觉醒、血脉冲突、族群地位、猎杀或控制风险。 |
| 神魂与悟性 | 神识强大、悟性异常、天机感应、灵觉敏锐 | 炼丹炼器、阵法符箓、功法领悟、战斗预判、搜魂或夺舍风险。 |
| 种族天赋 | 妖族、灵族、异族、特殊界面族群天赋 | 成年、化形、传承仪式、环境适应、天赋神通、族群责任。 |

#### 通用案例卡片

- **类型**：灵根 / 体质 / 血脉 / 神魂天赋 / 种族天赋。
- **对象**：写清人物、族群、身份、境界和所属势力。
- **获得方式**：先天、检测发现、觉醒、洗髓、换血、血脉融合、传承改造、夺舍继承、污染或诅咒等。
- **表现阶段**：首次显现、成长阶段、境界突破后的变化；只在某一阶段生效也要写清。
- **影响方向**：修炼速度、突破难度、资源消耗、属性亲和、战斗能力、寿元、神识、肉身、成长上限、身份地位和师承机会。
- **风险代价**：反噬、血脉冲突、体质失控、寿元损耗、心魔、夺舍、追杀、控制、路线受限或特殊资源依赖。
- **限制**：是否可复制、是否只能本人使用、是否依赖血统、境界、资源、传承或特殊环境。
- **可参考点**：写清该案例对资质体系的参考价值，不把唯一特例泛化。
