# 灵根体质血脉模板

# 规范

本文只整理小说中明确出现过，或能由具体剧情支撑的灵根、体质、血脉、种族天赋、神魂天赋等资质信息。

本文不写总览，不写游戏化抽象，不写项目字段映射；案例区只使用卡片段落。

- 只整理原文出现过，或能由原文内容明确支撑的灵根、体质、血脉、种族天赋和神魂天赋。
- 样本应覆盖多境界、多身份、多族群、多势力、多结局；不要只写主角、天才或成功案例。
- 不要只写“天才”“废柴”“资质很好”；必须写清类型、获得方式、影响方向和风险代价。
- 灵根、体质、血脉、功法效果、丹药效果、法宝效果不要混写；内容性质不同就放到对应模板。
- 原文没有说明的获得方式、成长上限、社会评价、风险代价或后续变化，写“原文未说明”，不要补设定。
- 信息暂不完整但值得保留的内容，先放入 `### 待定案例`；信息足够完整后再转入 `### 案例`。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 灵根类型：写五行灵根、单灵根、双灵根、三灵根、四灵根、五灵根、伪灵根、天灵根、异灵根、变异灵根、隐灵根、废灵根等。
- 体质类型：写道体、圣体、神体、魔体、妖体、毒体、寒体、火体、剑体、雷体、肉身体质、炉鼎体质、长生体质、诅咒体质等。
- 血脉类型：写妖兽血脉、神兽血脉、真灵血脉、王族血脉、古族血脉、魔族血脉、异族血脉、返祖血脉、混血血脉、可觉醒血脉等。
- 神魂与感知天赋：写神识强大、悟性异常、天机感应、灵觉敏锐、阵法天赋、炼丹天赋、炼器天赋、御兽天赋、符箓天赋等。
- 种族天赋：写妖族天赋、魔族天赋、灵族天赋、古族天赋、海族天赋、特殊界面族群天赋等。
- 获得方式：写先天出生、检测发现、自然觉醒、境界突破觉醒、吞服灵物、洗髓、换血、血脉融合、传承改造、夺舍继承、诅咒污染等。
- 影响方向：写修炼速度、突破难度、资源消耗、属性亲和、战斗能力、生存能力、寿元变化、神识变化、肉身变化、成长上限、身份地位、师承机会、婚姻联姻、被觊觎程度等。
- 风险代价：写反噬、血脉冲突、体质失控、寿元损耗、心魔风险、被夺舍、被追杀、被势力控制、修炼路线受限、需要特殊资源维持等。
- 拆分规则：同一种资质有多种获得方式时，分开写清。
- 差异记录：同一种资质在不同境界、角色或族群身上表现不同时，分别记录，不强行合并。
- 样本覆盖：主角资质样本要尽量完整；配角、反派、宗门天才、家族血脉、妖族、异族和特殊体质角色，有原文支撑就补充。
- 特例处理：不要把主角唯一体质、剧情外挂、特殊返祖或不可复制机缘当成普通角色可批量拥有的资质。

## 案例

### 案例

```md
# 《作品名》灵根体质血脉

## 灵根体质血脉卡片

### 资质名称

- 类型：灵根 / 体质 / 血脉 / 神魂天赋 / 种族天赋。
- 对象：写清人物、族群、身份、境界和所属势力。
- 获得方式：先天、检测发现、觉醒、洗髓、换血、血脉融合、传承改造、夺舍继承、污染或诅咒等。
- 表现阶段：首次显现、成长阶段、境界突破后的变化；只在某一阶段生效也要写清。
- 影响方向：修炼速度、突破难度、资源消耗、属性亲和、战斗能力、寿元、神识、肉身、成长上限、身份地位和师承机会。
- 风险代价：反噬、血脉冲突、体质失控、寿元损耗、心魔、夺舍、追杀、控制、路线受限或特殊资源依赖。
- 限制：是否可复制、是否只能本人使用、是否依赖血统、境界、资源、传承或特殊环境。
- 可参考点：写清该案例对资质体系的参考价值，不把唯一特例泛化。

### 天灵根

- 类型：灵根
- 对象：人物、身份、境界和所属势力按作品设定填写。
- 获得方式：先天出生或检测发现，按作品设定填写。
- 表现阶段：入门检测、修炼成长、境界突破等阶段按作品设定填写。
- 影响方向：修炼速度、突破难度、资源倾斜或资源劣势。
- 风险代价：被争夺、被控制、路线受限等；不明时写“原文未说明”。
- 限制：是否可复制、是否依赖血统或特殊环境，按作品设定填写。
- 可参考点：用于记录灵根资质对修炼效率、宗门评价和资源分配的影响。

### 特殊体质

- 类型：体质
- 对象：人物、身份、境界和所属势力按作品设定填写。
- 获得方式：先天、觉醒、传承改造、污染或诅咒等，按作品设定填写。
- 表现阶段：首次显现、封印解除、境界突破后的变化按作品设定填写。
- 影响方向：可修路线、战斗能力、寿元、肉身、神识或成长上限。
- 风险代价：反噬、封印、体质失控、被争夺风险。
- 限制：是否只能本人使用、是否依赖特殊资源或环境，按作品设定填写。
- 可参考点：用于记录体质带来的优势、限制和剧情代价。

### 特殊血脉

- 类型：血脉
- 对象：人物、族群、身份、境界和所属势力按作品设定填写。
- 获得方式：继承、返祖、觉醒、换血或血脉融合等，按作品设定填写。
- 表现阶段：成年、觉醒仪式、血脉突破或战斗激发阶段按作品设定填写。
- 影响方向：族群地位、天赋神通、环境适应、战斗能力或成长上限。
- 风险代价：血脉冲突、猎杀、控制、族群责任或特殊资源依赖。
- 限制：是否依赖血统、传承、境界或族群环境，按作品设定填写。
- 可参考点：用于记录血脉对身份、能力和族群关系的影响。
```

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
