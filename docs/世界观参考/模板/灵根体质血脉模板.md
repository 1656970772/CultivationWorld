# 灵根体质血脉模板

## 适用范围

本模板用于整理作品中明确出现，或能由具体设定直接确认的灵根、体质、血脉、神魂天赋、感知天赋和种族天赋等资质信息。

整理时保留作品使用的术语。凡人修仙类作品可使用灵根、体质、血脉、神魂和种族天赋；斗气类作品可使用灵魂强度、灵魂属性、斗气属性、特殊体质、瞳术、魔兽血脉或古族血脉；开脉类作品可使用脉象、玄根、开脉相属或灵根自种等本书机制。不得把作品专属体系统一改写成“灵根”。

本模板不收录单纯的功法效果、丹药效果、法宝加成、外挂能力、境界进度、资源待遇、外貌魅力、身份地位或人物关系。只有作品明确表明某种能力来自先天或后天形成的资质、体质、血脉、神魂或种族特性时，才纳入本模板。

本模板使用资质卡片，不写跨作品总览、游戏化属性换算或项目字段映射。

## 整理原则

1. **先做准入判断**

   每张卡都要能说明对象为什么属于灵根、体质、血脉、神魂天赋、感知天赋或种族天赋。普通聪明、经验、心计、战斗意识，以及功法带来的短期强化，不单独建卡。

2. **保留作品术语**

   优先使用作品中的正式名称、别名和族群称谓。没有正式命名但存在明确资质评价时，原文术语写“无命名，仅资质评价”，不得自行创造体质名或血脉名。

3. **同类信息归并**

   同一种资质的别名、不同持有者、不同觉醒阶段、不同境界表现和后续变化归入同一张卡，并在对应字段中分项记录。名称相同但来源、机制或性质明显不同的资质分别建卡。

4. **区分资质与外部因素**

   修炼速度、战斗能力、社会地位或资源待遇可能同时受到资质、功法、丹药、法宝、机缘、境界和势力影响。只把能够归因于资质本身的部分写入影响方向，其余内容在边界说明中简要区分。

5. **标明信息确定程度**

   明确区分“原文明确”“由连续行为直接确认”“合理推断”“角色或旁人推测”“传闻归纳”“作品未说明”和“本次未覆盖到明确内容”。合理推断必须同时写出依据和不确定之处，推测、评价和传闻不能提升为确定设定；存在其他合理成因时，在信息边界中列出替代解释。

6. **多方式和差异分项记录**

   同一种资质存在先天、觉醒、洗髓、换血、融合、传承改造或污染等多种获得方式，或在不同角色、族群、境界上表现不同时，分别记录对应对象、阶段、影响、风险和限制，不强行合并成单一结论。

7. **按完整生命机制链深入整理**

   对具有特殊性质的资质，按照“形成来源—持有者与分布—构成载体—核心机制—外观与检测—激活条件—可逆状态—能力表现—长期成长或退化—培养维持—控制与相容—个体影响—社会处境与生存—风险与克制—传承夺取—消亡后续”的顺序整理。形成来源说明资质如何产生，检测说明资质如何被发现，激活条件说明资质如何开始发挥作用，三者不得混写；临时休眠、暴走、封印和恢复归入可逆状态，返祖、晋升、永久退化和资质破坏归入不可逆演化；直接能力、个体后果和社会处境分别记录，不混写。

8. **谨慎处理唯一特例**

   主角外挂、唯一机缘、转世因果、特殊返祖或不可复制改造可以作为特殊样本收录，但必须在限制和可参考点中说明其唯一性，不能泛化为普通角色可批量获得的资质。

9. **兼顾不同类型与结果**

   样本应尽量覆盖不同境界、身份、族群、势力和结局。除主角、天才和成功觉醒者外，也保留资质平常但机制明确、觉醒失败、体质失控、遭受反噬、被觊觎、被势力控制、隐匿逃亡、资质衰退、传承中断或死亡后仍产生影响的案例。

10. **不补全未知设定**

    作品没有说明的形成来源、构成载体、运行机制、外观特征、激活条件、运行状态、成长上限、控制方式、相容关系、社会处境、克制方式、传承可能、消亡后续、风险代价或其他内容写“作品未说明”，不使用通用修仙设定补齐。

11. **控制输出范围**

    只保留能说明资质分类、形成方式、表现机制、成长变化、影响、风险和边界的信息，不长篇复述剧情，不重复罗列由同一机制产生的相似表现。

12. **输出前自检**

    检查入选对象是否属于资质体系、作品术语是否保留、形成与检测是否分开、可逆状态与不可逆演化是否分开、外部加成是否剥离、确定与不确定信息是否区分、同类信息是否归并、个体影响与社会处境是否区分、特例是否避免泛化，以及关键案例是否覆盖触发、变化、结果和后续。

## 字段说明

- **原文术语**：填写作品中的正式名称、别名或专属体系称谓；没有命名时写“无命名，仅资质评价”。
- **类型**：填写灵根、体质、血脉、神魂天赋、感知天赋、种族天赋或作品自定义的资质类别。
- **持有者与分布**：填写持有者或持有族群，以及与资质表现直接相关的身份、境界、所属势力、地域、族群范围、血脉支系、稀有程度和已知分布；多人共享同一种资质时分项记录个体差异，不因样本稀少推定唯一性。
- **准入依据与信息边界**：说明对象为何属于资质体系，以及资质与修炼、属性、肉身、神魂、血统或种族能力之间的直接关系；标明关键结论属于原文明确、由连续行为直接确认、合理推断、角色或旁人推测、传闻归纳或不确定，合理推断需给出依据和替代解释；同时区分资质本身与功法、丹药、法宝、外挂、境界、资源、身份、容貌和人物关系造成的效果。
- **形成来源与获得方式**：填写资质的历史或祖源来源，以及个体通过先天出生、自然形成、境界突破、吞服灵物、洗髓、换血、血脉融合、传承改造、夺舍继承、污染、感染或诅咒等方式真正形成或获得资质的过程；检测发现不属于获得方式，统一放入“外显特征与检测方式”。
- **构成载体与层级**：填写资质依附的肉身、血液、经脉、灵根结构、神魂、种族器官或其他载体，以及属性数量、纯度、祖源成分、显隐层级、主次结构和各部分之间的关系；局部损伤、替换或剥离是否影响整体也在此记录，作品只说明效果而未说明结构时写“作品未说明”。
- **核心性质/运行机制**：填写资质通过上述载体作用于灵气、肉身、神魂、血液、经脉或其他对象的基本原理，以及吸收、转化、储存、增幅、排斥、吞噬、再生、感知等关键机制；不重复构成描述。
- **外观描述**：填写由该灵根、体质或血脉直接造成的可见身体特征与变化，如体型、肤色、发色、瞳色、纹路、鳞甲、羽翼、角、尾、伤痕、光泽、血液颜色，以及激活、返祖、暴走、永久退化或失效时的外观变化。常态与激活状态差异较大时分阶段填写；没有明确描写时写“作品未说明”，不得把角色本来的容貌或通用特效当作资质外观。
- **外显特征与检测方式**：填写不以身体外观为主的可感知征兆和确认方式，如气息、威压、脉象、血液反应、灵力属性反应、异象，以及测试法器、仪式、神识探查、血脉感应、发现时间、隐藏、伪装和误判情况；与“外观描述”不重复。
- **激活条件**：填写资质从休眠转为生效、从常态进入强化或失控状态的触发条件、阈值和前置要求；常驻生效或无需激活时也应明确记录。
- **运行状态与可逆变化**：填写资质在常态、休眠、激活、强化、封印、暴走、衰弱和恢复等可以往返的运行状态，以及状态转换条件、持续时间和恢复路径；首次检测、长期成长和永久退化不放入本字段。
- **具体能力表现**：填写资质直接产生的能力、作用对象、作用范围和表现形式，如属性亲和、毒素转化、血脉威压、肉身再生、特殊感知或天赋神通。
- **成长、退化与不可逆演化**：填写资质纯化、返祖、二次觉醒、血脉晋升、体质蜕变、能力永久解锁、不可逆退化、资质破坏和成长上限，以及各阶段之间的条件与最终结果；不重复临时激活、封印或恢复。
- **培养与维持条件**：填写资质成长、稳定或持续生效所需的环境、灵气属性、毒物、血食、灵物、仪式、功法、周期性补充或其他资源。
- **稳定性与控制方式**：填写持有者能否主动控制，失控阈值和持续时间，以及封印、疏导、压制、平衡、净化、恢复等控制手段及其效果。
- **相容、冲突与环境响应**：填写资质与功法、属性、丹药、法宝、其他体质或血脉，以及极寒、毒域、祖地、特殊灵气、灵气枯竭等环境之间的增益、排斥、污染、覆盖、融合、适应和冲突结果。
- **个体综合影响**：填写具体能力对持有者修炼速度、突破难度、资源消耗、战斗与生存能力、寿元、神识、肉身、心理状态和成长上限造成的后续影响；身份待遇、社会评价和被觊觎程度统一放入下一字段。
- **社会认知、处境与生存策略**：填写社会、族群和势力如何识别、评价、培养、利用、婚配、隔离、研究、争夺或迫害该资质，持有者是否依附宗门、家族、族群或强者换取保护与培养资源，以及面对身份暴露、追捕、控制、夺取或保护失效时采用的隐藏资质、伪造检测、压制气息、谈判、求援、反制、逃亡或转投策略及其代价。
- **风险代价**：填写反噬、血脉冲突、体质失控、寿元损耗、心魔、夺舍、修炼路线受限、特殊资源消耗，以及社会威胁对持有者造成的直接代价；具体应对统一放入“社会认知、处境与生存策略”。
- **弱点与克制方式**：填写能够压制、封锁、干扰、剥离、净化或破解该资质的外部手段，以及资质在特定属性、环境或状态下可被利用的薄弱点；不重复资质自身的固有边界。
- **传承、复制、转移、夺取与消亡后续**：分别填写自然遗传、血脉稀释、返祖，人工复制、移植、换血、夺舍继承、剥离和强行夺取的可行性、条件与后果，以及持有者死亡、血脉断绝、资质剥离或永久失效后的遗骸利用、力量残留、污染扩散、后代延续和最终去向。
- **限制**：填写资质能力的固有边界，以及对本人、血统、族群、境界、资源、传承、封印、环境和觉醒条件的依赖；不重复风险代价和外部克制内容。
- **关键案例与变化链**：填写能够验证资质机制的一次觉醒、失控、控制、返祖、退化、剥离、夺取、传承或消亡事件。每个案例可包含持有者、初始状态、触发事件、检测或外显、状态变化、能力表现、控制或失控过程、外部干预、个体结果、社会处境变化、后续成长或传承及信息依据。
- **可参考点**：概括该案例对资质体系设计的参考价值，如优势与代价的平衡、成长阶段、族群关系、社会评价、生存策略或不可复制性；不把特例推广为普遍规则。

### 天灵根

- 原文术语：天灵根
- 类型：灵根
- 持有者与分布：宗门新入门弟子，炼气期；同类资质在其他地域、势力和族群中的数量与分布作品未说明。
- 准入依据与信息边界：入门检测明确确认其具有单一属性灵根，资质与属性亲和、修炼速度和突破难度存在直接关系，属于作品明示；宗门额外配给的功法、丹药和修炼资源属于身份待遇，不视为灵根自身能力。
- 形成来源与获得方式：先天形成；入门测试只是发现资质，不是获得资质。
- 构成载体与层级：由单一属性灵根构成，并表现出较高纯度；灵根在身体或神魂中的具体位置、结构和受损机制作品未说明。
- 核心性质/运行机制：灵根对单一属性灵气具有集中亲和，吸收和炼化同属性灵气时干扰较少。
- 外观描述：持有者在常态与修炼时均无稳定可见的身体外观特征；具体容貌不由灵根决定。
- 外显特征与检测方式：入门测试法器呈现单一且纯净的属性反应，由此发现并确认资质；是否能够隐藏、伪装或被误判，以及其他可感知征兆作品未说明。
- 激活条件：常驻生效，开始引气修炼后体现修炼优势。
- 运行状态与可逆变化：常态下持续生效，不需要在休眠与激活之间切换；未出现封印、暴走、衰弱或恢复等可逆状态。
- 具体能力表现：更高效地感应、吸收和炼化对应属性灵气。
- 成长、退化与不可逆演化：灵根是否能够纯化、增加属性、永久退化或被破坏作品未说明。
- 培养与维持条件：对应属性的修炼环境与功法能够充分发挥灵根优势。
- 稳定性与控制方式：性质稳定，无需主动控制，未出现暴走或失效状态。
- 相容、冲突与环境响应：与同属性功法和灵气环境相容；跨属性修炼或长期处于属性不匹配的环境会削弱单一亲和优势。
- 个体综合影响：提升修炼效率，减少对应属性修炼中的干扰并形成突破优势；对寿元、肉身和神魂的其他直接影响作品未说明。
- 社会认知、处境与生存策略：宗门通过检测识别其价值，提供核心师承和更多资源，同时可能限制其离开或转投；面对其他势力招揽、争夺或控制时，持有者主要依靠宗门身份和保护，是否隐藏资质、伪造检测或主动逃离作品未说明。
- 风险代价：资质本身未显示反噬；因稀有价值受到争夺、控制或资源安排约束属于社会性代价。
- 弱点与克制方式：作品未说明。
- 传承、复制、转移、夺取与消亡后续：是否遗传、复制、转移或夺取，以及持有者死亡后灵根是否残留作品未说明。
- 限制：优势集中在对应属性修炼路线；是否绝对不能转移作品未说明，不作确定结论。
- 关键案例与变化链：
  - 入门检测与核心培养：
    - 初始状态：持有者先天具备单一属性灵根，但尚未被宗门确认。

### 特殊体质·厄难毒体

- 原文术语：厄难毒体
