# 法宝分析模板

## 适用范围

本模板用于整理小说中出现过，或能由小说内容明确支撑的宝物、法宝、法器、秘宝、异宝、灵宝、仙器、神器、道器、极道帝兵、传承宝物、本命法宝、储物类法宝、阵盘阵旗、药鼎丹炉、飞舟遁器、符宝灵符、傀儡类法宝、秘境钥匙、宗门重宝和其他特殊功能宝物等。

普通兵器、普通护具、普通容器、普通暗器、普通训练器具、普通货币卡、普通身份证明、普通材料、普通丹药/药剂、灵兽/灵禽不放入本模板。若某件物品主要作为武器形制和战斗招式出现，优先放入 `武器分析模板.md`；若主要属于丹药、材料、灵兽、功法、货币或身份凭证，应转入对应模板。

原文是否直接称其为“法宝”不作为唯一准入条件。宝玉、手串、佩饰、衣物、牌符、香炉等普通形制物品，只要明确具备抵御心魔、温养神魂、辅助修炼、辟邪护体、遮掩气息、镇压气运、储物、认主、禁制、成长强化等超凡功能，也应作为特殊功能宝物收录，例如暖阳宝玉、抵御心魔的手串等。

## 整理原则

1. 一宝一卡  
   同一法宝的标准名、别名、同类名、主人变化、品阶变化、损毁修复和功能演化，都必须归并到同一张卡。  
   禁止另建“某某（补充）”“某某后期”“某某别名”等重复卡；后续变化写入同卡的“后续变化”。

2. 字段完整  
   每张卡必须包含：宝物名称、别名/同类名、类别、形态、外观描述、激发后表现、主人/持有者/所属势力、稀有度/品阶、功效、用途、宝物来历、炼制材料、形成/炼制方式、绑定/认主/驱动方式、限制/副作用/损耗、损坏原因与修复条件、适用境界、宝物进阶、后续变化、纳入依据。  
   无依据时写“原文未说明”；无明显变化时写“原文未说明明显变化”。禁止空字段。

3. 纳入边界清楚  
   原文直接称为法宝、法器、灵宝、仙器、神器、道器、秘宝、本命法宝、储物法宝、符宝、药鼎、丹炉、飞舟、袖囊、阵盘、阵旗、傀儡核心、传承令牌等，默认纳入或至少作为法宝候选判断。  
   未被原文命名为法宝，但具备抵御心魔、温养神魂、辅助修炼、辟邪护体、遮掩气息、储物、认主、祭炼、本命温养、器灵、禁制、破禁、镇压、封印、炼丹炼器增幅、飞行遁行、传承开启、秘境进入、傀儡控制等独立超凡功能的物品，同样纳入。

4. 排除边界明确  
   普通暗器、普通盒袋、普通短剑、普通铃铛、普通训练器具、普通药丸、普通药液、普通材料、魔核、货币卡、贵宾卡、身份卡、灵禽灵兽等，不因“有用”就写成法宝卡。  
   宝玉、手串、佩饰等物品若只有装饰、身份象征或普通材质价值，也不纳入；只有明确具备特殊功能时才建立宝物卡。若边界不清，只能在纳入依据中说明不确定性，不能把常识推测当成原文设定。

5. 同类归并  
   通用储物戒指、纳戒、储物袋、乾坤袋、袖囊等，可按“类型卡 + 代表实例”处理。  
   同类符宝、灵符、阵旗、飞舟、药鼎、傀儡等也可合并为类型卡，但要写清代表实例和差异，不要把多个无关法宝混进同一张卡。

6. 不虚构设定  
   不得为了补齐宝物品阶、境界梯度、外观、激发后表现、来历、创造者、材料、数值、绑定关系、使用代价、损坏原因、修复条件或进阶路线而自行虚构。  
   角色推测、传闻、误称和后续未坐实的说法，应在“纳入依据”中写清不确定性。

7. 输出简化  
   保留宝物判断所需的主人、类别、外观、激发后表现、功效、用途、来历、损坏修复、进阶、限制和后续变化，不展开无关剧情背景。  
   具体案例应写真实功能和边界，不用泛泛写“很强”“很珍贵”“有传承限制”。

## 字段说明

- 宝物名称：写小说中的宝物、法宝、法器、秘宝、异宝、灵宝、仙器、神器、道器、极道帝兵、传承宝物、本命法宝或特殊功能物品名称。
- 别名/同类名：写别称、俗称、同类通称或类型名，如纳戒/储物戒指、飞舟/遁器、药鼎/丹炉；没有写“原文未说明”。
- 类别：写特殊功能宝物、本命法宝、储物法宝、攻杀法宝、防御法宝、阵法法宝、炼丹法宝、飞行法宝、传承宝物、秘境钥匙、傀儡法宝、极道帝兵等。
- 形态：写法宝载体或外形，如鼎、塔、钟、印、镜、旗、幡、葫芦、珠、瓶、图、卷、书、舟、阵盘、阵旗、傀儡、灵虫袋、储物袋、戒指、手镯、飞剑、甲胄、盾、伞等。
- 外观描述：写宝物可直接观察到的颜色、大小、材质、纹理、光泽、气息、铭文、图案、破损痕迹及其他显著特征；没有明确描写时写“原文未说明”，不得根据名称或功效推断。
- 激发后表现：写法宝被激发、驱动或持续生效时可观察到的表现，如光芒与颜色变化、能量形态、符文亮起、虚影法相、体积或形态变化、飞行轨迹与残影、声响、气息威压、灵力波动、天地异象、空间变化，以及效果消散时的表现。此字段只描述“看起来、听起来或感知起来如何”；攻杀、防御、镇压等实际能力仍写入“功效”。没有明确描写时写“原文未说明”，不得按常见特效自行补写。
- 主人/持有者/所属势力：写当前主人、曾经持有者、炼制者、赠予者、所属宗门或家族；多人转手时按顺序简写。
- 稀有度/品阶：按作品自己的描述填写，如普通法器、稀有秘宝、宗门重宝、传说灵宝、仙器、神器等；不明时写“原文未说明”。
- 功效：写法宝本身带来的效果，如攻杀、防御、困敌、镇压、封印、飞行、储物、隐匿、传送、破禁、保命、替死、召唤、炼丹炼器加成等。
- 用途：写法宝被如何使用，如战斗、护身、逃遁、赶路、储物、布阵、炼丹、炼器、秘境开启、宗门镇压、传承考验等。
- 宝物来历：写宝物出自何处，如宗门、家族、秘境、遗迹、上界、天地孕育地等，以及由谁创造、炼制、孕育或最初持有；地点或创造者不明时分别写“原文未说明”。
- 炼制材料：炼制类法宝写具体材料或材料规则，如星辰铁、妖兽骨、火属性妖丹、空间晶石、阵纹材料等；非炼制类写“非炼制”；不明时写“原文未说明”。
- 形成/炼制方式：写法宝如何产生，如炼器师炼制、本命温养、血祭重炼、宗门炼器房打造、天地孕育、先天生成、古修遗留、秘境核心凝结、仙界流传等。
- 绑定/认主/驱动方式：写滴血认主、神魂绑定、本命温养、器灵择主、法力驱动、神识驱动、口诀驱动、传承限制、不可转让、可被夺取等；不明时写“原文未说明”。
- 限制/副作用/损耗：写修为限制、神识消耗、法力消耗、使用次数、反噬、耐久损耗、器灵反噬、环境限制等；没有说明时写“原文未说明”。
- 损坏原因与修复条件：分写宝物受损、破裂、失效或器灵沉寂的直接原因，以及修复所需材料、环境、修为、炼器方法、时间或特定人物；未发生明确损坏或修复时写“原文未说明”。
- 适用境界：按作品自己的境界说法填写，如炼气、筑基、金丹、元婴，或该作品特有境界；不明时写“原文未说明”。
- 宝物进阶：宝物可强化、升阶、重炼或解锁新形态时，按阶段分别写“强化条件”“强化后效果”“强化后外观”；强化条件应包含所需材料、环境、修为、方法或其他前置要求。没有进阶设定时写“原文未说明”。
- 后续变化：写转手、认主变化、功能解锁、失效、被夺取、封存、归属变化等历史变化；进阶过程和损坏修复分别写入对应字段。无明显变化时写“原文未说明明显变化”。
- 纳入依据：写为什么进入法宝模板，如原文直接称为法器、具备储物空间、需要祭炼认主、可被驭器驱动、能增幅炼丹、可作为秘境钥匙等；边界不清时写明不确定性。
