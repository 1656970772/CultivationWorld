# 法宝分析模板

## 适用范围

本模板用于整理小说中出现过，或能由小说内容明确支撑的宝物、法宝、法器、秘宝、异宝、灵宝、仙器、神器、道器、极道帝兵、传承宝物、本命法宝、储物类法宝、阵盘阵旗、药鼎丹炉、飞舟遁器、符宝灵符、傀儡类法宝、秘境钥匙、宗门重宝和其他特殊功能宝物等。

整理时将法宝视为“材料—结构—权限—能量—功能—反馈—演化”系统：从对象层级、来历和内部构成出发，记录归属权限、能量输入、激活操控、运行输出、使用者与环境互动、正常或异常状态、损耗修复、成长衰退、流转和最终影响。模板不要求每件法宝机械展示所有状态，只记录原文实际涉及且能够形成因果链的内容。

普通兵器、普通护具、普通容器、普通暗器、普通训练器具、普通货币卡、普通身份证明、普通材料、普通丹药/药剂、灵兽/灵禽不放入本模板。若某件物品主要作为武器形制和战斗招式出现，优先放入 `武器分析模板.md`；若主要属于丹药、材料、灵兽、功法、货币或身份凭证，应转入对应模板。

原文是否直接称其为“法宝”不作为唯一准入条件。宝玉、手串、佩饰、衣物、牌符、香炉等普通形制物品，只要明确具备抵御心魔、温养神魂、辅助修炼、辟邪护体、遮掩气息、镇压气运、储物、认主、禁制、成长强化等超凡功能，也应作为特殊功能宝物收录，例如暖阳宝玉、抵御心魔的手串等。

## 整理原则

1. 一宝一卡：同一法宝的别名、归属变化、状态变化和功能变化统一归入同一张卡，不重复建卡。
2. 对象边界：先判断是类型卡、个体卡还是成套法宝；只收录原文明确称为法宝或具备独立超凡功能的物品，普通物品不纳入。
3. 字段对应：每个字段只写本字段相关内容，不重复、不跨字段补充；除说明字段内容确有必要外，不引入无关的具体事件、剧情背景或人物信息。
4. 原文优先：只记录原文明确说明或能够直接支撑的内容，不根据常识、名称、品阶或同类设定推测；没有依据时写“原文未说明”，不适用时写“不适用”。
5. 分类记录：归属、功效、运行、权限、消耗、异常、损坏、进阶、流转和最终状态分别写入对应字段，不混写；流转历史只保留简短持有变化链。
6. 简洁输出：只保留判断法宝所需的信息，不展开无关剧情，不为了填满字段补写内容。

## 字段说明

- 对象层级：填写“类型卡”“个体卡”或“成套法宝”。类型卡需列代表实例和差异；个体卡需记录具体归属与生命周期；成套法宝需说明单件、组合和缺件状态。
- 宝物名称：写小说中的宝物、法宝、法器、秘宝、异宝、灵宝、仙器、神器、道器、极道帝兵、传承宝物、本命法宝或特殊功能物品名称。
- 别名/同类名：写别称、俗称、同类通称或类型名，如纳戒/储物戒指、飞舟/遁器、药鼎/丹炉；没有写“原文未说明”。
- 类别：写特殊功能宝物、本命法宝、储物法宝、攻杀法宝、防御法宝、阵法法宝、炼丹法宝、飞行法宝、传承宝物、秘境钥匙、傀儡法宝、极道帝兵等。
- 形态：写法宝载体或外形，如鼎、塔、钟、印、镜、旗、幡、葫芦、珠、瓶、图、卷、书、舟、阵盘、阵旗、傀儡、灵虫袋、储物袋、戒指、手镯、飞剑、甲胄、盾、伞等。
- 外观描述：写宝物可直接观察到的颜色、大小、材质、纹理、光泽、气息、铭文、图案、破损痕迹及其他显著特征；没有明确描写时写“原文未说明”，不得根据名称或功效推断。
- 激发后表现：写法宝被激发、驱动或持续生效时可观察到的表现，如光芒与颜色变化、能量形态、符文亮起、虚影法相、体积或形态变化、飞行轨迹与残影、声响、气息威压、灵力波动、天地异象、空间变化，以及效果消散时的表现。此字段只描述“看起来、听起来或感知起来如何”；攻杀、防御、镇压等实际能力仍写入“功效”。没有明确描写时写“原文未说明”，不得按常见特效自行补写。
- 品阶/品质：按作品自己的能力等级和质量体系填写，如法器、法宝、灵宝、仙器、神器、残缺、无暇等；不根据稀有度推断品阶。
- 稀有度与获取方式：写数量、主要来源、垄断或管制情况、交易、奖励、传承、争夺和获得条件；价格只有原文明示时才记录，不根据品阶推断稀有度。
- 归属/持有/控制关系：分别写名义归属、当前持有者、实际控制者和所属势力，以及多人共用、借用、封存或争夺情况。炼制者、赠予者和最初持有者归入“宝物来历”。
- 功效：写法宝本身带来的效果，如攻杀、防御、困敌、镇压、封印、飞行、储物、隐匿、传送、破禁、保命、替死、召唤、炼丹炼器加成等。
- 用途：写法宝被如何使用，如战斗、护身、逃遁、赶路、储物、布阵、炼丹、炼器、秘境开启、宗门镇压、传承考验等。
- 宝物来历：写宝物出自何处，如宗门、家族、秘境、遗迹、上界、天地孕育地等，以及由谁创造、炼制、孕育或最初持有；地点或创造者不明时分别写“原文未说明”。
- 炼制材料：炼制类法宝写具体材料或材料规则，如星辰铁、妖兽骨、火属性妖丹、空间晶石、阵纹材料等；非炼制类写“非炼制”；不明时写“原文未说明”。
- 构成与核心部件：写主体、核心、阵纹、禁制、能源部件、内部空间、意识载体、可拆卸部件，以及成套法宝的单件关系；原文未说明内部结构时不根据功能反推。
- 形成/炼制与品质决定因素：写法宝如何产生，以及原文明示的炼制步骤、火候、时间、炼器者要求、环境、成功率和决定品质的因素；本命温养、天地孕育等非普通炼制方式也在此记录。
- 器灵与自主性：条件字段。写器灵来源、意识状态、独立意志、自主行动范围、择主、拒绝命令、护主、欺骗、反噬、沉睡、成长或消亡；没有器灵证据时不得因法宝高级而推断存在器灵。
- 绑定/权限/转移规则：写滴血认主、神魂绑定、本命关系、血脉或传承权限，以及解除、继承、夺取、借用、多人共用、原主人死亡后的权限变化；不明时写“原文未说明”。
- 激活/操控/能量来源：写口诀、法力、神识、阵诀、血脉或器灵响应等启动和操控方式，能量来源、停止、收回及能量不足时的表现；不明时写“原文未说明”。
- 运行过程与性能参数：按“激活→能量进入→结构响应→功能输出→维持→停止或冷却”记录原文明示的运行链，并写作用对象、范围、容量、距离、目标数、持续时间、启动时间、精度、成功率和能量上限等参数；没有数值时只写原文可支持的相对表现。
- 适配对象与效果差异：写境界、修为、神识、血脉、体质、种族、功法、属性、本命关系及原主人身份造成的使用门槛或效果差异；单个使用者的表现不得直接推广为固定性能。
- 相互作用/克制/环境影响：写与其他法宝、功法、阵法、符箓、丹药、禁制、结界、天地规则、空间、地形、灵气环境和特定对象发生的增强、削弱、克制、破解、污染、夺取或封印关系，并说明条件和结果。
- 使用条件与性能边界：写修为、神识、权限、距离、环境、布置时间、配套部件、使用次数及功能上限等正常使用条件；能量消耗、反噬和结构损坏分别写入对应字段。
- 消耗/冷却/维护：写法力、神识、精血、寿命、灵石等消耗，使用次数、冷却、蓄能，以及温养、祭炼、补能、清理、保管和封存要求；没有说明时写“原文未说明”。
- 副作用/反噬/失控：写对使用者造成的负担或伤害、器灵反抗、控制中断、敌我不分和其他脱离预期控制的结果，并说明触发条件。
- 故障/异常/极端状态：写能量不足、缺件、阵纹中断、权限冲突、污染、器灵沉睡、过载、自爆、空间崩塌等状态下的表现、仍可使用的功能和直接后果；没有展示时不推演。
- 损坏原因与修复条件：分写宝物受损、破裂、失效或器灵沉寂的直接原因，以及修复所需材料、环境、修为、炼器方法、时间或特定人物；未发生明确损坏或修复时写“原文未说明”。
- 宝物进阶：宝物可强化、升阶、重炼或解锁新形态时，按阶段分别写“强化条件”“强化后效果”“强化后外观”；强化条件应包含所需材料、环境、修为、方法或其他前置要求。没有进阶设定时写“原文未说明”。
- 流转历史：只用简短链式记录转手、借用、被夺、遗失、封存、归属或控制权变化，格式为“xxx手中 -> xxx时间到xxx手中 -> xx地方被xxx所得”；不展开使用过程、进阶或损坏修复细节。
- 最终状态与遗留影响：写原文结束时的归属、持有者、完好、损坏、封存、遗失或毁灭状态，以及残片、器灵、内部空间、传承或势力影响是否继续存在。
- 纳入依据：条件字段。写边界对象为什么进入法宝模板，如具备储物空间、需要祭炼认主、能增幅炼丹或可作为秘境钥匙等；原文已明确称为法宝、法器等时可简写，边界不清时说明不确定性。
