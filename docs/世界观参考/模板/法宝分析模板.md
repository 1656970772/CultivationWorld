# 法宝分析模板

## 适用范围

用于整理作品中出现过，或能由资料来源明确支撑的法宝、秘宝、灵宝、仙器、神器、道器、传承宝物、本命法宝、储物类法宝、阵盘阵旗、傀儡类法宝等。

普通兵器、普通护具不放入本模板；只有具备独立法宝效果、祭炼认主、本命温养、器灵、禁制、成长、秘境钥匙、储物空间等属性时，才进入法宝分析。若主要作为武器形制和战斗招式出现，优先放入 `武器分析模板.md`。

## 前置声明

- 只整理原文出现过，或能由资料来源明确支撑的法宝、秘宝、灵宝、仙器、神器、道器、传承宝物、本命法宝等，不编造法宝。
- 样本要按形态、功效类型和适用境界尽量覆盖；原文有对应法宝就列入。
- 炼制类法宝必须写清炼制材料；非炼制类在“炼制材料”中写“非炼制”或“原文未说明”，并写清形成方式。
- 原文没有可靠依据的形态、稀有度、材料、形成/炼制方式、来源、绑定/认主、限制或副作用，写“原文未说明”。
- 信息不足但值得追踪的对象放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法要求 |
|------|----------|
| 法宝名称 | 写小说中的法宝、秘宝、灵宝、仙器、神器、道器、传承宝物、本命法宝等名称。 |
| 形态 | 写载体或外形，如鼎、塔、钟、印、镜、旗、幡、葫芦、珠、瓶、图、卷、书、舟、阵盘、阵旗、傀儡、灵虫袋、储物袋、戒指、手镯、飞剑、甲胄、盾、伞等。 |
| 稀有度 | 按作品自己的描述填写，可包含作品内品阶或层级。 |
| 功效 | 写法宝效果，如攻杀、防御、困敌、镇压、封印、飞行、储物、隐匿、传送、破禁、保命、替死、召唤、炼丹炼器加成等。 |
| 用途 | 写法宝如何被使用，如战斗、护身、逃遁、赶路、储物、布阵、炼丹、炼器、秘境开启、宗门镇压、传承考验等。 |
| 炼制材料 | 炼制类写具体材料或通用材料规则；非炼制类写“非炼制”；不明时写“原文未说明”。 |
| 形成/炼制方式 | 写炼器师炼制、本命温养、血祭重炼、宗门打造、天地孕育、先天生成、古修遗留、秘境核心凝结、仙界流传等。 |
| 来源 | 写宗门赐予、拍卖、遗迹、杀人夺宝、秘境奖励、传承、坊市购买、家族流传等。 |
| 绑定/认主 | 写滴血认主、神魂绑定、本命温养、器灵择主、传承限制、不可转让、可被夺取等；没有说明时写“原文未说明”。 |
| 限制/副作用 | 写修为限制、神识消耗、法力消耗、反噬、损毁、修复条件、器灵反噬、使用次数、环境限制等。 |
| 适用境界 | 按作品自己的境界说法填写；原文未说明时写“原文未说明”。 |

可补充字段：成长方式、修复方式、器灵性格、失控风险、被夺取条件、相关冲突事件。
