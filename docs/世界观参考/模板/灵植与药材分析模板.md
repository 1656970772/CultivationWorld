# 灵植与药材分析模板

## 适用范围

本模板用于整理作品中明确出现的灵植、灵药、灵草、灵花、灵果、灵藤、灵木、菌类药材及其可采部位。

本模板不分析丹药成品、法宝成品、符箓成品、功法秘籍、装备、饰品、容器、检测工具、普通建筑、组织、身份、资质、技能和秘术。矿物、生灵材料、灵能资源、天然灵液和天地奇物分别放入对应材料模板；下游成品只在“用途/下游去向”中出现，完整内容放入对应专题模板。

## 整理原则

1. 先做准入判定：只收可生长、繁殖、采摘、培育或入药的植物性生命及其植物来源材料；矿物、精血、自然灵液、能量结晶、丹药成品、完整生灵和场景群落转入对应专题或另作区域记录。
2. 一物一卡：同名、别名、不同年份、品阶、成熟度、生长阶段、完整植株和可采部位原则上归入同一卡；只有具备独立形成机制、独立名称和独立用途的派生物才另建卡，并写清母株关系。
3. 字段只写字段相关内容：不跨字段重复堆叠，不引入无关人物、地点、战斗、交易或剧情；不设置或展开使用记录、事件记录和逐条过程日志。
4. 差异与状态在对应字段内说明：年份、成熟度、健康、病害、变异、鲜干状态和处理状态分别写入相关字段；生命周期只保留已确认的关键阶段与变化，不强行补齐完整植物志。
5. 原料与下游分开：灵植和药材只写自身形态、药性、采收、保存、直接作用及下游去向；丹药、法宝或其他成品的完整效果放入对应专题。
6. 信息不足时如实标注：可使用“原文明确”“实际表现”“人物评价”“上下文推断”“原文未说明”“本次未覆盖到明确内容”“不适用”等确定性类型，不以现实植物学、名称、颜色或同类设定补齐内容。
7. 输出简洁并自检：保留模板字段，但连续未知项可简写；检查准入、对象层级、母株与派生关系、字段边界、量化纪律和案例范围，避免把候选对象、批次标题或区域群落直接当作正式单物种卡。

## 属性记录与量化规则

1. 分开记录药性维度
   “五行药性/寒热偏性”同时容纳两套不同性质：五行填写金、木、水、火、土中的单一、复合、偏向或相克关系；寒热填写大寒、寒、凉、平、温、热、大热等作品实际出现的偏性。寒性不自动等于水属性，热性不自动等于火属性。

2. 药力使用 1~100
   药力表示单位可用部位在当前年份、成熟度、品阶和处理状态下能够产生的已确认药效强度。仅在原文给出数值，或同一作品内有明确等级、对比及实际使用结果时评分，并写明“数值 + 依据 + 原文明示/相对折算”。相对折算可使用 1~20 极弱、21~40 较弱、41~60 中等、61~80 较强、81~100 极强五档；证据不足时写“原文未说明（不评分）”，不同作品的折算分数默认不可直接比较。

3. 毒性与温和度独立
   毒性记录正常剂量、过量、误食、接触、混用或错误成熟度下的毒害，可在证据充分时附 0~100；0 只用于原文明示或实际验证无毒。温和度使用 1~100，越高表示药性越平稳、越容易吸收和调和、对经脉脏腑刺激越小，越低表示越猛烈、冲突或难以承受。无毒不等于温和，高药力也不必然低温和度。

4. 按状态分别评分
   不同年份、成熟度、部位、鲜品/干品、变异状态和炮制方式存在差异时，在同一字段内分项记录，不取一个平均值掩盖差异。量化值只作同作品内检索和比较，原文描述与证据始终优先。

5. 证据优先
   将关键结论区分为“原文明确”“实际表现”“合理推断”“角色或旁人评价”“原文未说明”和“本次未覆盖到明确内容”。合理推断必须写明判断理由、替代解释和不确定之处；不得根据名称、颜色、现实植物药理或同类修仙设定补齐药性和分数。

6. 禁止证据标注
   任何字段不得写章节号、段落号、页码、情节锚点、原文位置、括号出处或其他来源标注；只保留结论内容和上述确定性类型。量化字段写“评分理由 + 确定性类型”，不写来源位置。

## 字段说明

- 子类、对象层级与派生关系：填写灵植、灵药、灵草、灵花、灵果、灵藤、灵木、菌类药材等子类，并区分完整活植株、根茎花果等可采部位、鲜品、干品和初步处理药材；说明植株、采收物与具有独立名称和机制的派生物之间的关系。
- 准入理由：说明对象为何属于可生长、繁殖、采摘、培育或入药的植物性生命及其材料，而不是成品药物、完整生灵或场景本体。
- 信息依据与判断边界：标明形态、生长、药性、效果和风险等结论属于原文明确、实际表现、合理推断、角色或旁人评价、原文未说明或本次未覆盖；合理推断需给出判断理由、替代解释和不确定之处，量化评分同时记录评分对象、评分理由和确定性类型，不写来源位置。
- 生物形态、内部结构与灵性表现：填写植株、根、茎、叶、花、果、种子、菌体的形态、颜色、气味和显著特征，以及药性或灵气集中部位、汁液与组织结构、灵核或其他内部载体；具有感知、趋利避害、伪装、缠绕、攻击、护果等本能时一并记录，完整人格与社会行为则转入生灵或人物模板。
- 分布、生境依赖、生态互动与可达性：填写地域分布、野生数量、灵田、药园、山脉、秘境、洞府、寒地、火域、水泽等生境，以及土壤、水分、灵气、温度、光照、季节和地形依赖；同时记录共生对象、天敌、传粉或传播者、竞争、环境反馈、发现征兆、隐藏情况、进入路线和接近障碍。
- 完整生命周期、繁殖与种群更新：填写种子、孢子、分株等来源与繁殖方式，以及萌发、生长、开花、结果、成熟、休眠、衰老、死亡、再次产出和后代更新的顺序、周期与条件；无法自然繁殖或依赖特殊仪式时也应说明。
- 年份、品阶、成熟度与健康状态：填写药龄、年份、品阶、成熟或未成熟，以及健壮、营养不足、受损、病害、枯萎、死亡和变异状态；不同状态对外观、药性和产量的影响分项记录。
- 可用部位、采收产量与母株后续：填写根、茎、叶、花、果、种子、汁液等可用部位，单株或单次产出，以及采根、剥皮、截枝、采叶、取汁和摘果后母株是否存活、再生、减产或死亡。
- 繁育、培育、催熟、移植与驯化：填写留种、播种、孢子、分株、扦插、嫁接、组织繁殖、灵气供养、阵法培育、催熟、移植、多代栽培和野生种驯化，以及资源投入、成功条件、性状变化和失败结果。
- 采摘与初步处理：填写采摘时机、工具、人员门槛、禁忌、止损措施、去杂、晾晒、切分和药性保护，以及误采、过早采摘、损伤母株和初步处理失败的后果。
- 保存、储运与药性流失：填写保存容器、温度、灵气、封禁、包装、运输和交接要求，以及枯萎、腐坏、污染、破损、药性衰减和途中损耗；记录鲜品、干品、切片等状态差异。
- 五行药性/寒热偏性：分别填写金、木、水、火、土药性与大寒、寒、凉、平、温、热、大热等寒热偏性，并记录复合、偏向、相克及不同部位、年份、成熟度或处理状态的变化；两者均须以原文证据为准。
- 药力（1~100）：填写当前可用部位、年份、成熟度、品阶和处理状态下的药效强度，并注明评分理由与确定性类型；不同状态差异明显时分项评分，证据不足时写“原文未说明（不评分）”。
- 毒性：填写毒素性质、毒性强弱、作用对象或部位、发作方式、剂量关系、潜伏与持续时间、可逆性和解毒方式；有充分依据时可附毒性 0~100，未知不得写成无毒或 0。
- 温和度（1~100）：填写药性是否平稳、是否易于吸收和调和、对经脉脏腑或神魂的刺激及排异程度；越高越温和，越低越猛烈，注明评分理由与确定性类型，证据不足时写“原文未说明（不评分）”。
- 核心活性与直接作用：填写灵植或药材自身已确认的活性、灵气积累或释放方式，以及直接作用结果；下游丹药或其他成品的完整效果不下沉到本字段，药性、药力、毒性和温和度分别写入专门字段，避免重复堆叠。
- 用途/下游去向：填写炼丹、配药、制毒、直接食用、繁育、培育、交易、任务或其他用途；加工后形成独立名称和机制的新对象时关联派生卡。
- 所有权、保护与采集压力：填写野生、无主、个人、药园、宗门、家族或秘境归属，以及守护者、采集许可、采收额度、禁采期、留种、封山、交易、垄断、偷采、争夺、战争征用、过度采集和种群保护恢复措施。
- 限制、风险与异常处置：填写生境、年份、成熟度、体质、剂量、相克、误食和使用等固有边界，以及病虫害、灵气骤变、移植失败、催熟失衡、变异失控、采摘损伤、药园毁坏和过采等异常的征兆、隔离、除害、补救、移栽、留种、环境修复、恢复可能和最终结果；材料本身的毒性仍写入“毒性”。
- 关键案例与变化链：只填写能说明对象状态、母株—采收物—派生物关系或材料去向的最短变化链；按“初始状态 -> 关键变化 -> 结果状态”记录，不展开具体事件、人物行动、章节过程或使用记录。没有明确变化链时写“原文未说明”。
- 稀有度：按作品自身描述填写；不因单次发现或价格昂贵直接推定稀有，需记录作品评价或分布证据。
- 适用对象与修炼/加工阶段：填写明确适用的使用者、体质、修炼境界，以及采摘者、药师或炼丹师能够辨识、处理和利用该材料的阶段；不明时写“原文未说明”。
- 别名/同物异名：填写俗称、不同地域叫法、不同生长阶段和采收状态下的同物异名。
