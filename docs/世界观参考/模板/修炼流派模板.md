# 修炼流派模板

## 适用范围

用于整理作品中反复出现的修炼流派、修炼路线、资源路径、行为模式和长期选择。

本模板不单独整理“人生取向”。长生、夺宝、护道、夺权、复仇、守护、逍遥、忠诚、避世等观念，只作为具体流派的核心目标与价值取向来写。不把“功法属性”误当成修炼流派；剑修、体修、炼丹、御兽、傀儡等只有形成稳定资源路径、行动链和风险偏好时，才写成流派。

## 前置声明

- 不为只出现一次的桥段创造流派；至少要有多个样本，或一个很强的代表角色/事件链。
- 样本尽量覆盖多境界、多身份、多地域、多势力、多结局；不要只写主角或成功路线。
- 不把流派写成道德判断；重点写目标、资源偏好、风险偏好、行动链、优势、代价和失败后果。
- 若流派中有人转向邪修，必须写清原因：资源断供、突破无望、亲友被杀、被宗门背叛、被追杀、邪法诱惑等。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 字段 | 写法提示 |
|------|----------|
| 流派名称 | 写剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流等。 |
| 形成条件 | 写资质、师承、功法、资源、身份、地域、遭遇、组织环境或长期选择。 |
| 核心目标与价值取向 | 写长生避险、夺宝求富、护道传承、夺取权力、复仇、守护亲友、逍遥、忠于宗门、养老避世等。 |
| 资源偏好 | 写丹药、功法、法宝、灵石、灵脉、妖兽材料、传承、情报、道侣/炉鼎、弟子、势力职位、血脉资源等。 |
| 资源获取方式 | 写闭关、游历、猎妖、夺宝、交易、拜师、收徒、入宗、叛逃、夺权、暗杀、血祭、掠夺、飞升准备等。 |
| 风险倾向 | 写谨慎、赌命、激进、隐忍、抱团、单干、仗势、投机、牺牲他人、重情义、低调苟活等。 |
| 典型行动链 | 写“起点 -> 资源积累 -> 关键突破 -> 组织/关系变化 -> 长期结果”。 |
| 优势与代价 | 写战力、生产能力、保命、组织价值、资源依赖、反噬、被围剿、关系破裂等。 |
| 成功路径 | 写长期积累、获得传承、拜入势力、炼制关键资源、建立人脉、突破瓶颈、创立势力等。 |
| 失败路径 | 写身死道消、被夺宝、走火入魔、资源耗尽、堕为邪修、被围剿、众叛亲离、寿元耗尽、传承断绝等。 |
| 转向邪修原因 | 如有样本，写事件链和动机；没有明确样本写“原文未说明”。 |
| 来源依据 | 写原文位置、资料来源或可靠依据。 |

类型提示：

| 类型 | 示例 | 重点 |
|------|------|------|
| 生产型流派 | 炼丹、炼器、阵法、符箓。 | 技艺传承、材料来源、市场/宗门价值、失败成本。 |
| 战斗型流派 | 剑修、体修、神魂、御兽、傀儡。 | 战斗方式、训练成本、资源消耗、克制关系。 |
| 阵营/体系型流派 | 魔修、佛修、儒修、妖修、血脉流。 | 价值取向、组织环境、资源路径、与主流秩序的关系。 |
| 高风险掠夺型流派 | 血修、鬼修、毒修、掠夺速成。 | 资源来源、社会反应、反噬、是否转入邪修模板。 |

## 案例

### 案例

| 案例方向 | 最小写法示例 | 不可漏写的重点 |
|----------|--------------|----------------|
| 炼丹流 | 角色因师承、丹方、火种、药材渠道或市场需求形成“采集/交易 -> 炼制 -> 自用或换资源 -> 反哺修炼”的路线。 | 形成条件、材料链、炼制风险、市场关系、成功闭环和失败成本。 |
| 血修流 | 角色或组织因功法、复仇、资源断供、邪器反噬或速成诱惑，转向依赖血肉、魂魄或掠夺资源的路线。 | 转向原因、资源来源、社会追杀、反噬、是否归入邪修案例。 |
| 阵法流 | 角色或势力依靠阵法、符箓、地势节点和组织协同，形成防御、控场、护山、封锁或战场调度路线。 | 师承/职能、节点资源、协同方式、阵眼风险、节点失守后的连锁后果。 |
