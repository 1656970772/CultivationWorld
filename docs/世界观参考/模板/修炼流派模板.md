# 修炼流派模板

# 规范

- 本文用于整理作品中反复出现的修炼流派、修炼路线、资源路径、行为模式和长期选择。
- 本文不写总览，不写表格，不写项目字段映射，不写游戏化抽象。
- 本文不单独整理“人生取向”；长生、夺宝、护道、夺权、复仇、守护、逍遥、忠诚、避世等观念，只作为具体流派的核心目标与价值取向来写。
- 不把“功法属性”误当成修炼流派；剑修、体修、炼丹、御兽、傀儡等只有在形成稳定资源路径、行动链和风险偏好时，才写成流派。
- 不为只出现一次的桥段创造流派；至少要有多个样本，或一个非常强的代表角色/事件链。
- 不把流派写成道德判断；要写目标、资源偏好、风险偏好、行动链、优势、代价、失败后果，以及是否可能转向邪修。
- 如果某个流派中有人后来变成邪修，必须写清变成邪修的原因：是哪些事件导致心态变化、资源断供、复仇执念、被追杀、被诱导，还是主动加入邪修门派。
- 原文没有说明流派形成条件、资源偏好、风险偏好、变成邪修原因、成功样本或失败样本时，不要补，可以写“原文未说明”。
- 样本尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界或少数成功路线。

## 参考和要求

- 整理范围：用于整理写作要求与参考整理范围；参考范围不是限定范围，仅用于提示检索方向，原文有其他相关内容也应继续补充。
- 正式案例：每个正式案例围绕一个稳定修炼流派写，不写总览或表格；流派可以是剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流等，也可以是作品中明确形成长期路线的其他流派。
- 流派名称：写具体修炼流派名称，例如炼丹流派、剑修流派、御兽流派、血修流派等。
- 形成条件：写资质、师承、功法、资源、身份、地域、遭遇、组织环境或长期选择。
- 核心目标与价值取向：写长生避险、夺宝求富、护道传承、夺取权力、复仇、守护亲友、逍遥、忠于宗门、养老避世、飞升成仙等。
- 资源偏好与获取方式：写偏好的丹药、功法、法宝、灵石、灵脉、妖兽材料、传承、情报、道侣/炉鼎、弟子、势力职位、血脉资源等，以及通过闭关、游历、猎妖、夺宝、交易、拜师、收徒、入宗、叛逃、夺权、暗杀、血祭、掠夺、飞升准备等方式取得资源。
- 风险倾向与行动链：写谨慎、赌命、激进、隐忍、抱团、单干、仗势、投机、牺牲他人、重情义、低调苟活等倾向，并按“起点 -> 资源积累 -> 关键突破 -> 组织/关系变化 -> 长期结果”写清过程。
- 优势、代价与失败后果：写战力、生产能力、保命、组织价值、资源依赖、反噬、被围剿、关系破裂、身死道消、被夺宝、走火入魔、资源耗尽、众叛亲离、寿元耗尽或传承断绝等。
- 转向邪修原因：如有样本，写清资源断供、突破无望、亲友被杀、被宗门背叛、被追杀、被强者夺宝、复仇执念、寿元将尽、邪法诱惑或主动投靠邪修门派等事件链；没有明确样本写“原文未说明”。
- 覆盖方向：检索时可以有意识地覆盖不同资源路径和行为模式，例如以技艺换资源、以战斗磨炼、以灵兽/傀儡协同、以掠夺速成、以宗门职位积累资源等；但正式案例必须落到具体修炼流派，不用抽象分类替代流派名称。

## 案例

### 案例

```md
# 《作品名》修炼流派

## 修炼流派卡片

### 流派名称

- 形成条件：
- 核心目标与价值取向：
- 资源偏好与获取方式：
- 风险倾向与行动链：
- 优势、代价与失败后果：
- 转向邪修原因：

### 炼丹流派

- 形成条件：写角色如何进入炼丹路线，例如师承炼丹师、宗门分工、家族传承、火属性条件、神识控制能力、丹炉丹方获取渠道，或因修炼资源不足而主动学习炼丹。
- 核心目标与价值取向：写该流派是为了自给自足、辅助突破、疗伤解毒、换取灵石和人脉，还是以丹药供给绑定宗门、家族或势力。
- 资源偏好与获取方式：写灵草、丹方、丹炉、火源、辅药、药园、坊市材料、宗门兑换、秘境采药、炼丹委托和拍卖渠道。
- 风险倾向与行动链：写从识药、收集丹方、试炉失败、炼成低阶丹药，到获得订单、换取修炼资源、炼制关键突破丹药的链条。
- 优势、代价与失败后果：写丹药产出、议价能力、宗门价值和人情网络，也写材料损耗、炸炉、丹毒、丹方被夺、被势力控制或炼丹瓶颈。
- 转向邪修原因：如出现为追求禁丹、炉鼎、血丹、魂丹或快速突破而转向邪修的样本，写清事件链；没有样本写“原文未说明”。

### 剑修流派

- 形成条件：写角色如何进入剑修路线，例如师门剑诀、剑道天赋、本命飞剑、剑冢传承、战斗经历、宗门分支或个人长期选择。
- 核心目标与价值取向：写该流派是追求杀伐、护道、防身、越级挑战、宗门战力、独行生存，还是借剑道突破心境和境界。
- 资源偏好与获取方式：写剑诀、飞剑、剑胚、剑阵、剑意传承、磨剑场所、战斗机会、强敌压力、剑修宗门或秘境剑冢。
- 风险倾向与行动链：写从入门剑诀、养剑练剑、实战磨炼、领悟剑意，到成名、护道、越级对敌或承担宗门战事的链条。
- 优势、代价与失败后果：写爆发力、单体杀伤、越级空间和威慑力，也写资源单一、剑毁伤身、心境偏执、杀伐过重或被克制。
- 转向邪修原因：如因复仇、走火入魔、杀戮成性、被魔剑污染或剑道执念失控而偏向邪修，写清触发事件；没有样本写“原文未说明”。

### 御兽流派

- 形成条件：写角色如何进入御兽路线，例如宗门传承、家族兽园、灵兽契约、血脉亲和、幼兽机缘、妖兽巢穴、驯兽术或长期饲养经验。
- 核心目标与价值取向：写该流派是为了战斗助力、侦查代步、守护洞府、经营兽园、收集材料，还是借灵兽成长反哺修炼。
- 资源偏好与获取方式：写兽卵、幼兽、灵兽口粮、妖丹、兽栏、御兽法诀、契约法器、兽潮战场、秘境捕捉和宗门驯兽设施。
- 风险倾向与行动链：写从获得幼兽、建立契约、喂养训练、协同作战，到灵兽进阶、反哺主人或形成御兽队伍的链条。
- 优势、代价与失败后果：写多单位协同、侦查、防守和材料产出，也写饲养成本、契约反噬、灵兽死亡、失控伤人或被强者夺走。
- 转向邪修原因：如出现血祭驯兽、魂控妖兽、强行夺舍妖兽或以邪法催熟灵兽的样本，写清事件链；没有样本写“原文未说明”。

### 血修流派

- 形成条件：写角色如何进入血修路线，例如邪法传承、寿元压力、重伤求生、复仇执念、战败逃亡、资源断供、邪修组织诱导或主动选择。
- 核心目标与价值取向：写该流派是为了快速变强、延寿、复仇、控制他人、逃命，还是绕开正统资源门槛获得突破机会。
- 资源偏好与获取方式：写精血、血池、祭品、尸体、战场残骸、炉鼎、血道法器、黑市材料、弱者猎杀或邪修组织供给。
- 风险倾向与行动链：写从接触血道法门、取得第一批血源、短期提升修为，到反噬、被追杀、加入邪修网络或被正道围剿的链条。
- 优势、代价与失败后果：写速成、压制力、恢复力和恐吓效果，也写反噬、失控、心性异化、众叛亲离、被围剿或身死道消。
- 转向邪修原因：必须写清事件链；如果作品中血修本身就被定义为邪修，也要说明它与普通高风险修炼、邪修模板之间的边界。
```
