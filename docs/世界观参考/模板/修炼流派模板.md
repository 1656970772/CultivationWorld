# 修炼流派模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：修炼路线、资源路径、行为模式与长期选择调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文用于整理作品中反复出现的修炼流派、修炼路线、资源路径、行为模式和长期选择。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 本文不单独整理“人生取向”；长生、夺宝、护道、夺权、复仇、守护、逍遥、忠诚、避世等观念，只作为具体流派的核心目标与价值取向来写。
- 不把“功法属性”误当成修炼流派；剑修、体修、炼丹、御兽、傀儡等只有在形成稳定资源路径、行动链和风险偏好时，才写成流派。
- 不为只出现一次的桥段创造流派；至少要有多个样本，或一个非常强的代表角色/事件链。
- 不把流派写成道德判断；要写目标、资源偏好、风险偏好、行动链、优势、代价、失败后果，以及是否可能转向邪修。
- 如果某个流派中有人后来变成邪修，必须写清变成邪修的原因：是哪些事件导致心态变化、资源断供、复仇执念、被追杀、被诱导，还是主动加入邪修门派。
- 原文没有说明流派形成条件、资源偏好、风险偏好、变成邪修原因、成功样本或失败样本时，不要补，可以写“原文未说明”。

## 参考范围（不局限于以下类别）

- **修炼路线**：剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流。
- **核心目标与价值取向**：长生避险、夺宝求富、护道传承、夺取权力、报仇雪恨、守护亲友、逍遥自在、忠于宗门、养老避世、飞升成仙。
- **资源偏好**：丹药、功法、法宝、灵石、灵脉、妖兽材料、传承、情报、道侣/炉鼎、弟子、势力职位、血脉资源。
- **资源获取方式**：闭关、游历、猎妖、夺宝、交易、拜师、收徒、入宗、叛逃、夺权、暗杀、血祭、掠夺、飞升准备。
- **风险倾向**：谨慎、赌命、激进、隐忍、抱团、单干、仗势、投机、牺牲他人、重情义、低调苟活。
- **转向邪修原因**：资源断供、突破无望、亲友被杀、被宗门背叛、被追杀、被强者夺宝、复仇执念、寿元将尽、邪法诱惑、主动投靠邪修门派。
- **成功路径**：长期积累、获得传承、拜入势力、炼制关键资源、建立人脉、突破瓶颈、掌握特殊功法、创立势力。
- **失败路径**：身死道消、被夺宝、走火入魔、资源耗尽、堕为邪修、被围剿、众叛亲离、寿元耗尽、传承断绝。

## 完整修炼流派案例

### 案例 1：谨慎长生流

流派名称与类型：写具体流派名称和类型，例如“谨慎长生流 / 苟道修炼路线”。名称和类型合并写，不单独拆成两个字段。

核心目标与价值取向：写清这个流派最看重什么，例如活得久、少冒险、稳步突破、保命优先、远离大势力冲突、避免无谓争斗；这里可以包含长生、避险、养老、低调等观念。

代表角色：写清哪些角色体现该流派，角色在什么阶段、什么事件中表现出这种路线。

适用境界：写清该流派常见于炼气、筑基、金丹、元婴或作品自己的境界；不同境界策略不同则拆开写。

形成条件：写清什么出身、资质、经历、资源状态、敌对环境、寿元压力或失败经验会让角色选择这种路线。

资源偏好：写清偏好丹药、保命法宝、隐匿术、逃遁符、洞府、灵石、稳妥功法、可靠情报、低风险机缘等。

资源获取方式：写清如何获取资源，例如低风险任务、稳定交易、长期闭关、种田、炼丹、避开争夺、积累人情、选择可靠队友。

风险偏好：写清谨慎到什么程度，遇到高收益机会是否放弃，如何判断危险，是否宁可少赚也不冒险。

典型行动链：详细写清从发现机会、评估风险、准备保命手段、行动、撤离、隐藏收益到继续闭关的完整链条。

突破瓶颈方式：写清如何突破瓶颈，是靠长期积累、丹药、闭关、护法、低风险秘境、前辈指点，还是原文未说明。

社交策略：写清是否低调结交、少欠人情、依附安全势力、避免派系斗争、保持普通身份或隐藏实力。

优势：写清这种流派的优势，例如死亡率低、资源消耗可控、能避开大冲突、适合长程积累、能保存实力。

代价与限制：写清进境慢、错过机缘、被人轻视、资源上限低、难以争夺核心传承、长期隐忍带来的代价。

变成邪修的原因：写清该流派是否会因寿元将尽、突破无望、长期被压榨、保命执念过重、亲友被杀或被邪法诱惑而转向邪修；如果没有就写“原文未说明”。

失败后果：写清谨慎过度导致错失突破、被强者逼迫、闭关失败、寿元耗尽、资源断供或被卷入不可避冲突。

成功样本：写清代表角色如何依靠谨慎路线活下来、突破、逃过大劫或积累到关键资源。

失败样本：写清代表角色如何因为太谨慎、资源不足、判断错误或被迫卷入冲突而失败。

后续影响：写清这种流派对角色关系、资源积累、长期目标、势力选择和后续剧情的影响。

### 案例 2：夺宝冒险流

流派名称与类型：写具体流派名称和类型，例如“夺宝冒险流 / 机缘争夺路线”。

核心目标与价值取向：写清是否追求暴富、机缘、快速突破、强法宝、强传承，是否相信富贵险中求。

代表角色：写清哪些角色通过夺宝、秘境、拍卖、截杀、探险等事件体现这种路线。

适用境界：写清常见境界和阶段；低阶夺宝、高阶争传承、寿元将尽者抢机缘可拆开写。

形成条件：写清资源短缺、天资不足、宗门资源竞争、被压制、见过暴富案例、寿元压力或复仇需求如何催生此流派。

资源偏好：写清偏好秘境钥匙、地图、法宝、古宝、传承、丹药、稀缺材料、拍卖压轴品、他人战利品。

资源获取方式：写清秘境探险、杀人夺宝、拍卖竞价、截杀、黑市交易、临时组队、抢遗迹、跟踪富修等方式。

风险偏好：写清是否敢赌命、是否接受高死亡率、是否会背叛队友、是否会在机缘面前突破底线。

典型行动链：详细写清获取消息、筹备资源、组队或伪装、进入危险区、争夺机缘、处理战利品、规避追杀的流程。

突破瓶颈方式：写清是否靠抢来的丹药、传承、法宝、秘境资源、强者遗留或杀人夺宝完成突破。

社交策略：写清临时组队、表面结盟、暗中防备、依附强者、背刺、分赃谈判、逃亡换身份等。

优势：写清收益上限高、突破速度快、容易获得稀缺资源、可能跨越阶层、适合弱背景角色逆袭。

代价与限制：写清死亡率高、仇家多、信誉低、容易财富暴露、队友不可信、容易被更强者截胡。

变成邪修的原因：写清是否因夺宝失败、被追杀、资源欲望膨胀、杀人夺宝成习惯、被邪修组织招揽、走投无路而加入邪修门派。

失败后果：写清被杀、被夺宝、被通缉、被队友背叛、秘境困死、落入黑市、成为他人机缘。

成功样本：写清代表角色如何通过冒险夺宝获得突破资源、法宝或传承。

失败样本：写清代表角色如何因贪心、情报错误、轻敌或背叛而失败。

后续影响：写清这种流派如何改变角色名声、敌友关系、财富状态和长期风险。

### 案例 3：宗门权力流

流派名称与类型：写具体流派名称和类型，例如“宗门权力流 / 职位资源路线”。

核心目标与价值取向：写清是否追求职位、话语权、资源分配权、弟子势力、掌门继承、家族利益或宗门稳定。

代表角色：写清掌门、长老、执事、真传、派系首领、家族子弟等代表人物。

适用境界：写清常见于哪些境界和职位阶段，例如内门竞争、真传争位、长老派系、掌门继承。

形成条件：写清出身、派系、宗门制度、资源分配不均、家族支持、师承关系和权力空缺如何形成该流派。

资源偏好：写清偏好职位、贡献体系、弟子、堂口、资源仓库、秘境名额、任务发布权、执法权、联姻资源。

资源获取方式：写清完成宗门任务、拉拢弟子、立功、派系斗争、联姻、打压对手、争夺长老支持、掌握堂口。

风险偏好：写清是否愿意政治冒险、是否隐忍、是否借刀杀人、是否避免正面冲突、是否牺牲弟子或同门。

典型行动链：详细写清积累贡献、建立人脉、获得职位、控制资源、排挤对手、影响继承或派系斗争的流程。

突破瓶颈方式：写清是否依赖宗门资源、长老护法、秘境名额、职位带来的丹药功法和弟子供奉。

社交策略：写清收徒、结盟、联姻、依附强者、培养心腹、打压异己、维护声望或伪装公正。

优势：写清资源稳定、可调动人手、能获得保护、影响任务和奖励、长期安全性高。

代价与限制：写清被宗门规矩束缚、卷入内斗、背负责任、声誉压力、失败后牵连家族或弟子。

变成邪修的原因：写清是否因权力斗争失败、被逐出宗门、掌门继承失败、被同门背叛、资源被夺或复仇而投靠邪修势力。

失败后果：写清失势、被废、被流放、派系覆灭、弟子被清算、宗门内乱或被外敌利用。

成功样本：写清代表角色如何通过宗门权力获得资源、地位和突破机会。

失败样本：写清代表角色如何在权力斗争、继承争议或派系冲突中失败。

后续影响：写清该流派如何影响宗门制度、资源分配、弟子命运和外部势力关系。

### 案例 4：传承护道流

流派名称与类型：写具体流派名称和类型，例如“传承护道流 / 师承守护路线”。

核心目标与价值取向：写清是否重视传承延续、师徒责任、护道、培养后辈、守护宗门或守护某条道统。

代表角色：写清师父、护道人、传承守护者、宗门长老、家族老祖、器灵或古修残魂等代表。

适用境界：写清多见于高阶修士、老修士、掌握传承者，还是低阶角色也可能承担护道。

形成条件：写清寿元将尽、传承断绝、宗门危机、弟子出现、旧恩旧诺、道统责任如何形成该流派。

资源偏好：写清偏好弟子、传承功法、护道法宝、洞府、藏经、秘境、血脉后人、可信继承者。

资源获取方式：写清收徒、试炼、传功、挑选继承人、守护传承地、保存法宝、培养弟子和筛选心性。

风险偏好：写清是否愿意为弟子冒险，是否牺牲自己，是否严苛筛选，是否为了传承不择手段。

典型行动链：详细写清发现继承者、考验、传授、护道、安排资源、处理仇敌、传承完成或失败的流程。

突破瓶颈方式：写清是否通过弟子反馈、传承延续、道心稳固、旧伤恢复或原文未说明。

社交策略：写清师徒关系、护道人关系、宗门关系、同门传承争夺、对外隐藏传承等。

优势：写清能获得稳定师承、保护、功法资源、传承连续性和长期关系纽带。

代价与限制：写清资源投入大、容易被弟子背叛、卷入后辈因果、传承失败、保护对象拖累。

变成邪修的原因：写清是否因传承断绝、弟子被杀、守护失败、被宗门背叛、复活传承者执念而使用邪法或投靠邪修门派。

失败后果：写清传承断绝、弟子死亡、师徒反目、护道人陨落、传承被邪修夺走。

成功样本：写清代表角色如何完成传承、培养弟子或延续道统。

失败样本：写清代表角色如何因识人不明、资源不足、仇敌强大或执念过重而失败。

后续影响：写清传承流向、师徒关系、宗门格局和后续剧情。

### 案例 5：职业副业流

流派名称与类型：写具体流派名称和类型，例如“炼丹资源流 / 炼器谋生流 / 阵法破禁流 / 御兽资源流”。

核心目标与价值取向：写清是否通过职业能力换资源、提升地位、减少正面战斗、形成稳定收入或掌握特殊话语权。

代表角色：写清炼丹师、炼器师、阵法师、符师、御兽师、傀儡师、医修等代表。

适用境界：写清职业在不同境界阶段的资源门槛、收益和风险。

形成条件：写清资质限制、功法路线、师承、职业天赋、资源缺口、战斗弱势或市场需求如何促成该路线。

资源偏好：写清偏好材料、丹方、器方、阵图、灵火、炉鼎、妖兽、符纸、客户、人脉和安全工坊。

资源获取方式：写清接单、代工、交易、开店、依附商会、加入宗门堂口、探索材料地、培养客户。

风险偏好：写清是否规避战斗，是否敢接高风险订单，是否卷入黑市、禁丹、邪器、机密阵法。

典型行动链：详细写清获得订单、收集材料、炼制/布阵/培养、交付、收款、维护声誉和处理失败的流程。

突破瓶颈方式：写清是否靠职业收入换丹药功法、靠职业传承突破、靠客户资源换护法或秘境资格。

社交策略：写清客户、人脉、师承、商会、宗门堂口、保密约定、合作队伍和同行竞争。

优势：写清收入稳定、社会地位高、资源渠道多、可用技术换保护、战斗弱者也能积累资源。

代价与限制：写清材料依赖、失败赔偿、职业瓶颈、被大势力控制、卷入客户仇怨、战斗力不足。

变成邪修的原因：写清是否因追求禁丹邪器、客户逼迫、材料短缺、职业失败、黑市利润、复仇或寿元压力而走邪路。

失败后果：写清炸炉、赔偿、信誉崩塌、被客户追杀、职业断路、被迫投靠势力或黑市。

成功样本：写清代表角色如何靠职业能力获得资源、地位和突破机会。

失败样本：写清代表角色如何因职业失败、黑市牵连或材料争夺而失败。

后续影响：写清职业路线对交易、势力、资源循环和角色命运的影响。

### 案例 6：邪道速成 / 掠夺流

流派名称与类型：写具体流派名称和类型，例如“邪道速成流 / 掠夺修炼路线 / 血修吞噬流”。

核心目标与价值取向：写清是否追求快速突破、延寿、复仇、夺取资质、控制他人、摆脱底层处境或不择手段。

代表角色：写清邪修、魔修、血修、鬼修、夺舍者、采补者、血祭者、投靠邪派者等代表。

适用境界：写清这种路线出现在哪些境界，低阶和高阶邪修路线有何差异。

形成条件：写清资源断供、寿元将尽、亲友被杀、被宗门背叛、长期受压迫、仇恨执念、邪法诱惑等条件。

资源偏好：写清血肉、魂魄、炉鼎、尸体、禁丹、邪器、战俘、凡人村镇、敌对修士、黑市赃物。

资源获取方式：写清暗杀、诱骗、绑架、血祭、采补、夺舍、吞噬、黑市交易、投靠邪修门派等方式。

风险偏好：写清是否赌命、是否隐藏身份、是否愿意牺牲他人、是否接受通缉和围剿风险。

典型行动链：详细写清从心态变化、接触邪法、获取资源、实施邪术、隐藏身份、被发现、逃亡或加入邪派的链条。

突破瓶颈方式：写清是否靠血祭、吞噬、采补、邪丹、夺舍、献祭、邪器或邪修门派资源突破。

社交策略：写清伪装正派、投靠魔宗、黑市交易、控制弟子、拉同伙、灭口、逃亡和背叛。

优势：写清短期提升快、资源来得猛、可绕开正道资源限制、能控制他人或夺取特殊资质。

代价与限制：写清心魔、反噬、通缉、名声败坏、资源来源暴露、正道围剿、同伙背叛、功法缺陷。

变成邪修的原因：非常详细写。写清哪些事件导致心态变化或主动加入邪修门派，例如亲友被杀、被宗门抛弃、机缘被夺、突破无望、寿元将尽、被邪修救下、被邪法诱惑、被黑市牵连、复仇执念失控。

失败后果：写清被围剿、反噬、魂灭、被更强邪修吞并、暴露身份、亲友反目、成为通缉对象。

成功样本：写清代表角色如何通过邪道速成获得修为、寿元、战力或复仇机会。

失败样本：写清代表角色如何因反噬、暴露、围剿或更强者利用而失败。

后续影响：写清邪修路线如何引发通缉、冲突、因果链、势力围剿和社会恐慌。

### 案例 7：复仇执念流

流派名称与类型：写具体流派名称和类型，例如“复仇执念流 / 仇怨驱动修炼路线”。

核心目标与价值取向：写清是否以报仇、洗雪耻辱、杀死仇敌、夺回家族或复兴势力为核心。

代表角色：写清复仇者、灭门幸存者、被背叛者、被夺宝者、亲友被杀者等代表。

适用境界：写清复仇路线在不同境界的表现，低阶隐忍和高阶清算可拆开写。

形成条件：写清灭门、亲友被杀、师门背叛、机缘被夺、被废修为、被通缉、被羞辱等事件。

资源偏好：写清偏好杀伤法宝、情报、仇敌线索、隐匿手段、毒、暗杀、盟友、突破资源。

资源获取方式：写清卧薪尝胆、打工积累、投靠势力、拜师、黑市买情报、临时结盟、杀敌夺宝。

风险偏好：写清是否愿意赌命，是否会牺牲自己，是否保持理智，是否因执念走向极端。

典型行动链：详细写清受害、逃亡、积累资源、查找仇人、提升实力、接近目标、复仇、处理后果的链条。

突破瓶颈方式：写清是否靠仇恨驱动、机缘、拜师、黑市资源、邪法或原文未说明。

社交策略：写清隐藏身份、寻找盟友、利用仇敌敌人、投靠强者、伪装和长期潜伏。

优势：写清目标明确、意志强、愿意忍耐、行动力强、能承受长期苦修和高风险。

代价与限制：写清容易失去理智、忽视其他机会、关系紧张、被仇敌反利用、复仇后失去目标。

变成邪修的原因：写清是否因复仇执念过重、正道无助、资源不足、被邪法诱惑、仇敌太强、亲友再度被杀而转向邪修。

失败后果：写清复仇失败、被仇敌杀死、牵连同伴、堕为邪修、被仇恨吞噬、复仇后空虚。

成功样本：写清代表角色如何完成复仇并继续修炼或重建生活。

失败样本：写清代表角色如何因执念、资源不足、判断错误或邪法反噬失败。

后续影响：写清复仇如何改变关系、势力格局、角色心态和后续路线。

### 案例 8：守护亲友 / 重情义流

流派名称与类型：写具体流派名称和类型，例如“守护亲友流 / 情义驱动修炼路线”。

核心目标与价值取向：写清是否以保护亲友、道侣、弟子、家族、宗门或凡俗故人为核心。

代表角色：写清护短者、师长、兄弟朋友、道侣、家族守护者、护道人等代表。

适用境界：写清低阶互助、高阶庇护、老修士护后辈等阶段差异。

形成条件：写清亲情、友情、师徒恩、救命恩、家族责任、宗门责任或失去亲友后的转变。

资源偏好：写清偏好疗伤丹、护身法宝、传讯符、保命手段、洞府、安全地、可供亲友使用的资源。

资源获取方式：写清任务、交易、护送、保护、炼丹、为亲友争夺名额、冒险取药、对抗敌人。

风险偏好：写清为亲友是否愿意冒险，是否牺牲自己，是否放弃机缘，是否因情义被敌人拿捏。

典型行动链：详细写清亲友遇险、角色筹备资源、救援、复仇、防御、安排退路、承担后果的链条。

突破瓶颈方式：写清是否因守护责任加强道心、获得亲友帮助、师门支持或原文未说明。

社交策略：写清维护小圈子、结义、师徒、家族关系、道侣关系、恩情互助和长期信任。

优势：写清信任度高、有人护法、资源互助、关系稳定、能形成小团队和长期支持。

代价与限制：写清容易被亲友拖累、被威胁、资源分散、情感决策、仇怨扩大和难以割舍。

变成邪修的原因：写清是否因亲友被杀、救人无门、复活执念、被宗门抛弃、为救亲友使用邪法或投靠邪修。

失败后果：写清亲友死亡、自己被杀、资源耗尽、情义被利用、守护失败后心态崩溃。

成功样本：写清代表角色如何保护亲友、传承关系或建立稳定小团体。

失败样本：写清代表角色如何因情义被利用、救援失败或过度牺牲而失败。

后续影响：写清情义关系如何推动长期剧情、结盟、复仇、传承或势力形成。
