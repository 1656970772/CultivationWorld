# 修炼流派模板

## 适用范围

本模板用于整理作品中能够被辨认出来的**长期修炼路线**。流派的核心不是人数、名气、组织规模或是否拥有正式名称，而是修炼者是否围绕相对稳定的修炼方向，形成了持续功课、力量转化、成长变化、行动方式和风险代价。

剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修等可以构成流派；作品中特有的修炼方式，只要形成完整、长期且可辨认的修炼路线，也可以谨慎归纳为流派。

## 整理原则

1. **分清什么是流派**
   流派必须是一条完整、长期、可辨认，并且明显区别于一般修炼者常规修炼方式的特殊路线，能够体现独特而稳定的修炼功课、力量转化、成长变化、行动方式和风险代价，例如鬼修、魂修，或围绕吞噬和炼化异火持续进阶的修炼路线。人数多少不影响流派成立；功法、斗技、体质、血脉、资源、势力、组织和家族传承本身都不是流派，只有围绕它们形成这种具有明显特点的完整长期修炼路线时，才能建立流派卡。

2. **还原流派的修炼过程**
   简要归纳进入条件、日常功课、资源获取与转化、稳定产出、成长阶段、关键门槛、上限、风险和路线变化，只保留流派的主要修炼链。

3. **所有字段都简要总结**
   每个字段只写核心结论，使用简短、概括的语言重新归纳；不得抄录原文，不复述完整情节，也不展开人物、功法、斗技、体质、势力或资源的详细资料。

4. **案例最多5个并动态替换**
   每张流派卡所有字段中的案例合计最多5个，不必凑满。每个案例只写1—3句简要概述，相同人物、机制或结论不重复；后续出现更合适的案例时，用它替换原有较弱案例，不得继续追加或扩写旧案例。

5. **所有描述都不得出现章节信息**
   流派卡的任何字段、摘要和案例都不得写章号、章节编号、章节标题、章节范围、窗口编号或原文证据位置。章节信息只能用于内部判断，不能写入最终报告。

6. **原文未说明就明确标注**
   只填写原文能够支持的结论；原文没有说明或无法确认的字段，统一写“原文未说明”，不得猜测或补写。


## 字段说明

### 修炼流派字段

- **原文称谓：** 填写作品明确使用的流派或修炼路线称谓；没有明确称谓时写“原文未说明”。功法名、斗技名、家族名、势力名和人物称号不得直接充当流派称谓。
- **归纳名称：** 对已经形成长期路线但没有统一原名的对象，使用中性、描述性的名称。名称应描述“怎样修”，不能直接拿功法、体质、家族或组织名称代替流派名称。**该字段的实际值同时作为本卡片的三级标题。**
- **一句话流派定义：** 用一句话写清长期修炼对象、核心机制、主要产出和关键限制，并能直接区别于其他路线。
- **准入依据与流派边界：** 简要说明该对象为什么构成长期修炼路线，以及它与功法、斗技、体质、资源、势力、家族传承和短期强化的区别。**人数少不能作为不成立的理由，修炼链不完整才是。**
- **根本理念、修炼伦理与身份认同：** 简要归纳该流派怎样理解和使用力量、推崇或禁止什么；不得把单个角色的私人动机写成全流派共识。
- **修炼对象、力量来源与核心载体：** 分别说明主要修什么、力量从哪里来、通过什么载体保存和发挥；只保留支撑流派机制所必需的信息。
- **体系构成与内部协同：** 简要说明功课、能力、载体和辅助条件如何配合。涉及功法、斗技、体质、势力、资源等内容时只作简短引用，不展开专题细节。
- **形成条件与适配人群：** 简要说明资质、身体、心性、师承、地域和资源门槛，以及更适合或不适合进入该路线的人群。
- **日常功课与资源循环：** 简要概括修炼者长期反复做什么，以及“资源输入 → 获取与转化 → 能力或产出 → 反哺修炼”的循环；需要时附关键案例。案例计入整张流派卡最多5个的总上限，每个案例只写1—3句。
- **成长阶梯、关键门槛与上限：** 只写简短摘要，概括入门、成长、主要瓶颈、质变和上限；需要时附关键人物案例，不罗列所有人物成长史。案例计入整张流派卡最多5个的总上限，每个案例只写1—3句。
- **标志性能力与识别特征：** 只归纳整个流派最主要、最稳定的能力组合和外在识别特征，区分流派共性与个人特例。**不得把遇到的该流派人物逐个描写。**
- **典型战斗、生产或行动范式：** 只写简短摘要，概括该流派通常如何战斗、生产、辅助、侦察、交易或解决问题；需要时附关键人物案例，不复述完整行动过程。案例计入整张流派卡最多5个的总上限，每个案例只写1—3句。
- **优势、短板、克制与协同：** 只分析流派本身，并按“优势、短板、克制对象、受制手段、协同对象、成立条件”**一条一条分开写**。不得把所有人物的战绩和遭遇汇总进来。
- **环境、组织与社会关系：** 只写简短摘要，概括流派与地域、材料、市场、组织和社会评价的主要关系；需要时附关键人物案例，不展开完整势力设定。案例计入整张流派卡最多5个的总上限，每个案例只写1—3句。
- **常规代价、失稳方式与极端状态：** 只归纳流派普遍存在的主要成本、失稳方式和极端后果，并清楚区分三个层级。**不得按人物逐个罗列遭遇。**
- **修复、退出与路线转换：** 只做总结性说明，写清主要修复方式、能否退出或改修、哪些变化不可逆；不枚举所有具体情况。
- **传承、组织、分支与兴衰：** 只做总结性说明，概括该流派怎样延续、是否存在主要分支，以及兴盛或衰退的核心原因；不枚举所有组织、人物和事件。家族或组织只是流派的承载环境，不得反过来当作流派主体。
- **转向邪修原因：** 只填写原文明确的转变过程、“原文未说明”或“非邪修/不适用”。


每张卡片直接以归纳名称作为三级标题。例如归纳名称为“炼药修”，标题就写成 `### 炼药修`。**不得输出 `### 流派名称`，也不得保留任何占位文字。**
