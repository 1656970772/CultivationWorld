# 修炼流派模板

## 适用范围

本模板用于整理作品中反复出现或由强代表角色完整体现的修炼流派、长期修炼路线、职业型修炼路线、稳定资源路径、行为模式和风险选择。

修炼流派可以是剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流，也可以是作品中特有的功法进化路线、技艺换资源路线或其他长期修炼体系。长生、复仇、守护、夺权、逍遥、忠于宗门、避世等人生取向，只作为具体流派的目标与价值取向，不单独建卡。

单一功法、斗技、丹药、阶段能力、训练方法、战斗事件、修炼事故、交易关系、职业称号或组织进修经历，默认不属于正式修炼流派；其中对理解修炼路线有价值的内容，可以整理为“非流派修炼要素”。

## 整理原则

1. 先做正式流派准入判定
   正式流派至少要满足以下条件：存在原文明确称谓或可谨慎归纳的长期路线；有多个样本，或一个强代表角色的完整修炼链；具备相对稳定的形成条件、资源路径、行动链和风险偏好。缺少其中关键环节时，先放入“非流派修炼要素”，不要勉强升格。

   长春功长期修炼、象甲功外功淬体、绿液催熟药草再炼丹的资源闭环、炼药师职业型路线、焚诀吞噬异火进化路线，均具有持续修炼或稳定资源链，可以作为正式流派候选。是否最终建卡，仍需结合完整内容判断。

2. 用非流派修炼要素承接重要细节
   重要但不足以独立成流派的功法、斗技、丹药、能力节点、阶段训练、组织资源路径和修炼事故，不得挤占正式流派卡，应进入“非流派修炼要素”。

   王大胖一次同门比试、拂柳剑法、长春功第五层带来的过目不忘、心魔入侵经历，更适合作为战斗事件、单一招式、阶段能力或修炼事故。眨眼剑谱虽有特殊条件和多项秘技训练，也要在形成完整长期链条后才能作为正式流派，不能只因剑谱重要就直接升格。温养/筑基灵液、斗气鞭挞训练、吸掌与吹火掌组合，属于萧炎的阶段性修炼方案或斗技组合；迦南学院属于组织资源路径，不能仅凭这些内容单独命名为流派。

3. 区分原文称谓与归纳名称
   原文明确使用剑修、血修、魔修、炼药师等称谓时，在“原文称谓”中照实填写。原文没有明确命名但长期路线成立时，可以使用中性、描述性的“归纳名称”，并与原文称谓分开。不得把其他作品或其他体系的术语强套到当前对象上。

   抽髓丸体现的是以寿命换取武功精进的药物速成要素，原文没有把厉飞雨或抽髓丸定义为血修，因此不能命名为“抽髓丸血修流派”。如完整事件链足以形成路线，可归纳为“透支寿命的武学速成路线”；否则只保留为非流派修炼要素。

4. 同一人物同一路线合并整理
   同一功法的别称、同一路线的阶段能力、配套丹药、训练细节、资源补充和后续变化，应并入同一张正式流派卡。先消歧，再判断是否确有不同路线，不要用“细节”“补充”“后期”等后缀重复建卡。

   奔雷刀法与风雷刀法出现在厉飞雨同一刀法上下文时，应先合并消歧；“象甲功”和“象甲功修炼细节”应合并；长春功的心魔经历、黄龙丹与金髓丸辅助突破、第五层过目不忘、第六层伪真气等，应作为同一路线的阶段信息，而不是各自升格为流派。

5. 保持数字、期限、境界和品阶准确
   数字、时间期限、境界、品阶和能力效果必须按原文明确内容填写，不能根据人物已经修炼或服药的时间自行换算，也不能把角色推测改成确定事实。原文未说明时如实填写。

   抽髓丸的限制是第一次用药后的十年内必定丢命，不能根据厉飞雨已服药数年改写成“五年内必死”。

6. 严格处理转向邪修原因
   “转向邪修原因”只写三类结果：原文明确的转变事件链、原文未说明、非邪修/不适用。没有明确转变时，不得用“可能导致心态异化”“暗示”“埋下伏笔”等推测补齐。若流派本身被原文定义为邪修路线，应说明其形成条件和与普通高风险修炼的边界。

7. 写清资源闭环和长期行动链
   资源偏好不能只列物品名称，应写获取方式和用途；行动链按“起点 → 资源积累 → 关键突破 → 组织或关系变化 → 长期结果”整理。职业型路线还要体现职业能力如何换取资源、地位或势力价值；功法进化路线要体现进化条件与持续代价。

   例如，“灵液辅助修炼 → 拍卖变现 → 购买材料 → 继续修炼”属于可识别的资源闭环；炼药师具备资质门槛、材料与火种需求、经济价值和势力价值，可作为职业型修炼路线，而不只是职业身份。

8. 兼顾不同阶段与候选遗漏
   整理长篇作品时，应兼顾作品前期、中期、后期，并覆盖不同境界、身份、地域、势力和结局，避免只整理主角早期路线。发现扛鼎力士、金纹符书、炼丹、炼器、灵贝等候选信号时，应先做准入判定；输入内容缺失时只能标记为待确认候选，不能凭关键词补写正式流派。

9. 控制篇幅并做输出自检
   每张正式卡围绕一条稳定路线，简洁呈现形成条件、资源闭环、行动链、优势与代价，不长篇复述剧情。生成后检查：正式卡是否通过准入判定；原文称谓与归纳名称是否混淆；单一要素是否误升格；同源路线是否重复拆卡；数字与期限是否被改写；转向邪修原因是否含无依据推测；代表样本是否覆盖成功与失败结果。

## 字段说明

### 正式修炼流派字段

- 原文称谓：填写作品明确使用的流派、路线、功法或职业型修炼身份称谓；没有明确称谓时写“原文未说明”。
- 归纳名称：对已经形成长期路线但没有统一原名的对象，使用中性、描述性的名称；有明确原名且无需归纳时可与原文称谓一致。
- 准入理由：说明该对象具备哪些长期形成条件、资源路径、行动链、风险偏好或强代表样本，以及为什么不是单一功法、一次事件或阶段能力。
- 形成条件：写资质、师承、功法、资源、身份、地域、遭遇、组织环境或长期选择。
- 核心目标与价值取向：写长生避险、夺宝求富、护道传承、夺取权力、复仇、守护亲友、逍遥、忠于宗门、飞升等长期目标。
- 资源偏好与获取方式：写偏好的丹药、功法、法宝、灵石、灵脉、材料、传承、情报、灵兽、职位等，以及闭关、游历、交易、拜师、入宗、猎妖、夺宝、炼制或掠夺等获取方式。
- 风险倾向与行动链：写谨慎、激进、隐忍、抱团、单干、投机、赌命等倾向，并按长期过程呈现起点、积累、突破、关系变化和结果。
- 优势、代价与失败后果：写战力、生产能力、保命能力、组织价值，以及资源依赖、反噬、围剿、关系破裂、走火入魔、资源耗尽、寿元耗尽或传承断绝等代价。
- 转向邪修原因：只填写明确转变事件链、“原文未说明”或“非邪修/不适用”。
- 代表样本：列出最能体现该路线完整过程的角色或群体；样本不足时如实说明。

### 非流派修炼要素字段

- 类型：填写功法/斗技、丹药/药物、能力节点、阶段训练、组织资源路径、修炼事故、战斗事件、交易关系或其他合适类型。
- 要素内容：简述该要素在修炼中的具体作用、条件或影响。
- 不升格为正式流派的原因：说明它缺少稳定资源路径、长期行动链、风险偏好、多个样本或强代表链中的哪些部分。
- 可并入的正式流派：填写该要素所属或可补充的正式路线；无法确认时写“原文未说明”。
- 代表样本：填写使用、经历或体现该要素的角色或群体。

### 长春功修炼路线

- 原文称谓：无名口诀、长春功
- 归纳名称：长春功修炼路线
- 准入理由：该路线具有灵根与年龄门槛、持续功法修炼、丹药资源辅助、多个阶段能力和长期突破过程。
- 形成条件：具备灵根与适合修炼的年龄条件，获得墨大夫传授口诀并持续修炼。
- 核心目标与价值取向：提升功力、突破层次、获得修仙能力并增强自保能力。
- 资源偏好与获取方式：修炼口诀、黄龙丹、金髓丸及绿液催熟所得药材；通过传授、催熟和炼制获得。
- 风险倾向与行动链：取得口诀 → 自行修炼 → 借丹药突破 → 获得阶段能力 → 继续提升层次并进入更广阔的修仙体系。
- 优势、代价与失败后果：可持续提升修为并产生阶段能力；依赖资质、药物和长期修炼，修炼过程中出现过瓶颈与心魔风险。
- 转向邪修原因：非邪修/不适用
- 代表样本：韩立

### 炼药师职业型修炼路线

- 原文称谓：炼药师
- 归纳名称：炼药师职业型修炼路线
- 准入理由：该路线具有明确资质门槛、材料与火种需求、长期技艺成长、资源变现能力和势力价值。
- 形成条件：具备火木属性条件、灵魂感知力，并获得炼药知识与实践条件。
- 核心目标与价值取向：炼制药物辅助修炼、换取财富与材料、建立人脉并提高势力地位。
- 资源偏好与获取方式：药材、魔核、火种、药方与炼制器具；通过采购、交易、采集和势力支持获得。
- 风险倾向与行动链：满足资质条件 → 学习炼药 → 收集材料与火种 → 炼制药物 → 自用或交易 → 以技艺换取后续修炼资源。
- 优势、代价与失败后果：具有资源生产、经济交换和势力协作价值；依赖稀缺资质、材料、火种与长期练习。
- 转向邪修原因：原文未说明
- 代表样本：萧炎、药老

### 焚诀吞噬异火进化路线

- 原文称谓：焚诀
- 归纳名称：焚诀吞噬异火进化路线
- 准入理由：该功法具有持续进化机制、明确进化条件、高风险资源目标和长期修炼方向。
- 形成条件：获得并修炼焚诀，具备寻找、接触和吞噬异火的条件。
- 核心目标与价值取向：通过功法进化提升修炼上限与战力。
- 资源偏好与获取方式：异火；具体获取方式原文未说明。
- 风险倾向与行动链：修炼焚诀 → 寻找异火 → 承担吞噬风险 → 推动功法进化 → 继续追寻新的异火与突破。
- 优势、代价与失败后果：具备持续进化潜力；吞噬异火的具体代价与失败后果原文未说明。
- 转向邪修原因：非邪修/不适用
- 代表样本：萧炎

- 代表样本：迦南学院学员
