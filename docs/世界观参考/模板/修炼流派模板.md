# 修炼流派模板

## 适用范围

本模板用于整理作品中反复出现或由强代表角色完整体现的修炼流派、长期修炼路线、职业型修炼路线、稳定资源路径、行为模式和风险选择。

修炼流派可以是剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流，也可以是作品中特有的功法进化路线、技艺换资源路线或其他长期修炼体系。长生、复仇、守护、夺权、逍遥、忠于宗门、避世等人生取向，只作为具体流派的典型追求，不单独建卡。

单一功法、斗技、丹药、阶段能力、训练方法、战斗事件、修炼事故、交易关系、职业称号或组织进修经历，默认不属于修炼流派。只有当相关内容形成稳定的修炼对象、力量机制、核心功课、成长阶梯、行动范式、资源循环和风险结构时，才建立流派卡。

## 整理原则

1. 先用一句话辨认流派
   先回答“修什么、靠什么修、主要换来什么、最受什么限制”，再展开其他字段。一句话定义可使用“以某种对象或载体为核心，通过某种修炼与转化机制，形成某类主要能力，并受某种关键条件制约”的结构。若换成其他流派名称后仍然成立，说明定义没有抓住特点。

2. 再判定准入和边界
   修炼流派至少要有原文明确称谓或可谨慎归纳的长期路线，并由多个样本或一个强代表角色体现完整修炼链。判断它成立所必需的条件，说明它与相邻流派、兼修路线、单一功法和短期手段的区别。缺少核心对象、稳定机制、长期功课、成长过程或代表性行动方式时，不建立流派卡。

3. 拆解静态结构
   依次识别流派的根本理念、修炼对象、力量来源、核心载体和内部构成。内部构成可包括功法、术法、身体、神魂、器物、契约对象、生产技艺、辅助资源和组织规则，要写清各部分如何协同，不能只列名词。

4. 还原实际修炼过程
   按“进入条件 → 日常功课 → 资源获取与转化 → 稳定产出 → 阶段提升 → 关键瓶颈 → 上限或转向”还原路线。日常功课回答修炼者平时反复做什么，资源循环回答这些活动怎样持续，成长阶梯回答能力结构何时发生质变，三者不要混写。

5. 提炼标志性表现和行动范式
   不只罗列能力，要找出一眼能够辨认该流派的外在特征、招牌能力组合和解决问题的典型方式。战斗型流派要写接敌、控场、攻防、续航和撤退方式；生产型流派要写生产流程、产物、失败控制和交换方式；辅助或复合型流派要写协同、情报、调度和环境利用方式。

6. 通过比较确定真正特点
   单独写“强大、消耗资源、存在风险”没有辨识度。应比较该流派在相同境界、相同资源和相同任务下，相对其他流派更擅长什么、更不擅长什么，克制谁、受谁克制、适合与谁协同，以及这些关系成立的条件。没有明确比较内容时如实说明。

7. 放回世界环境中观察
   整理流派对地域、灵气、材料、物种、市场、宗门制度、团队分工和社会评价的依赖与反作用。既要看环境怎样塑造流派，也要看流派扩张后怎样改变资源分布、组织权力、职业结构和生态关系。

8. 区分正常、异常和极端状态
   正常状态写流派如何稳定运行及其常规代价；异常状态写瓶颈、反噬、失控、资源循环中断、关系破裂或心性偏移；极端状态写彻底异化、修为崩毁、死亡、环境灾变或传承断绝。还要检查是否存在修复、降级、退出、改修或不可逆状态，不把所有问题都写成笼统的“失败”。

9. 追踪流派自身的生命周期
   区分个人成长和流派演变。流派层面要看如何招募、筛选、教学、认证和组织修炼者，怎样产生正统、支系、地域变体或内部争议，又因何兴盛、衰退、失传、复兴或被其他路线吸收，以及最终留下什么长期影响。

10. 严格处理转向邪修原因
    “转向邪修原因”只写三类结果：原文明确的转变过程、原文未说明、非邪修/不适用。没有明确转变时，不得用暗示、可能性或类型惯例补齐。若流派本身被原文定义为邪修路线，应写清其核心机制、伦理边界和与普通高风险修炼的区别。

11. 明确信息与合理归纳的边界
    原文直接说明的内容按明确事实填写；由多个长期表现才能总结出的内容标记为“谨慎归纳”；无法确认的条件、机制、比较关系、变化或结局写“原文未说明”。不得把单一样本、角色猜测、短期表现或常见类型套路改写成流派的确定规律。

12. 控制篇幅并做输出自检
    每张卡应形成“定义—结构—修炼—表现—比较—环境—失稳—演变”的完整画像，而不是剧情复述或设定名词表。生成后检查：删掉流派名称后是否仍能辨认对象；核心功课和招牌行动是否具体；相邻流派边界是否清楚；资源运行与成长阶梯是否混写；优势是否同时写明短板和成立条件；正常成本、异常状态和极端后果是否区分；个人经历是否误写成流派规律；明确内容与谨慎归纳是否区分。

## 字段说明

### 修炼流派字段

- 原文称谓：填写作品明确使用的流派、路线、功法或职业型修炼身份称谓；没有明确称谓时写“原文未说明”。
- 归纳名称：对已经形成长期路线但没有统一原名的对象，使用中性、描述性的名称；有明确原名且无需归纳时可与原文称谓一致。
- 一句话流派定义：用一句话写清修炼对象或载体、核心机制、主要产出和关键限制。定义应能把该流派与其他路线直接区分。
- 准入依据与流派边界：说明该对象为什么构成稳定流派，成立所必需的条件是什么，与相邻流派、兼修路线、单一功法、短期强化和职业称号有什么区别。
- 根本理念、修炼伦理与身份认同：写该流派怎样理解力量、修炼者与世界的关系，推崇或禁止什么，如何看待自身身份，以及由此形成的典型追求；不要把单个角色的私人动机写成全流派共识。
- 修炼对象、力量来源与核心载体：分别写主要改造或培养什么，力量从哪里产生、吸收或转化，通过身体、神魂、器物、阵地、契约对象、血脉或其他载体保存和发挥。
- 体系构成与内部协同：写核心功法、术法、器物、身体、神魂、契约对象、生产技艺、辅助资源和组织规则等组成部分，以及缺少其中某一部分会怎样影响整体运行。
- 形成条件与适配人群：写资质、身体、心性、师承、身份、地域、资源和组织门槛，以及什么样的修炼者更适合或不适合进入该流派。
- 日常功课与资源循环：写修炼者长期反复进行的训练、温养、观想、炼制、布置、培育、采集或实战活动，并按“资源输入 → 获取与转化 → 能力、产品或地位产出 → 反哺后续修炼”说明如何维持。
- 成长阶梯、关键门槛与上限：写入门、成熟、高阶和极限状态的能力质变，突破所需条件，常见瓶颈、成长速度、后期上限和可能的兼修、改修或停滞点。
- 标志性能力与识别特征：写最能代表该流派的能力组合，以及身体、神魂、器物、气息、行为、职业身份或环境痕迹上的可观察特征；区分稳定特征和个体特例。
- 典型战斗、生产或行动范式：写该流派通常怎样接敌、控场、攻防、续航和撤退，或怎样生产、辅助、侦察、调度、交易和解决问题，突出能力之间的组合顺序与决策偏好。
- 优势、短板、克制与协同：在同等境界、资源或任务条件下，比较该流派的突出优势、结构性短板、适合对付的对象、容易受制的手段、适合协同的流派及比较成立的条件。
- 环境、组织与社会关系：写流派对地域、灵气、材料、物种、市场、宗门、团队和社会评价的依赖，以及它对资源分布、组织权力、职业结构和生态关系造成的反作用。
- 常规代价、失稳方式与极端状态：区分稳定运行时持续承担的成本，瓶颈、反噬、失控、循环中断等异常状态，以及修为崩毁、死亡、彻底异化、环境灾变或传承断绝等极端结果。
- 修复、退出与路线转换：写异常后能否修复、需要付出什么，是否可以降级、退出、兼修、改修或转入其他流派，哪些变化可逆，哪些会永久改变修炼者。
- 传承、组织、分支与兴衰：写招募、筛选、教学、认证和组织方式，正统、支系、地域变体和内部争议，以及流派兴盛、衰退、失传、复兴、被吸收和留下长期影响的过程。
- 转向邪修原因：只填写明确转变过程、“原文未说明”或“非邪修/不适用”。
- 信息边界与待确认项：分别标明哪些内容为原文明确、哪些属于谨慎归纳、哪些尚未说明，仅记录信息明确程度与待确认内容。
- 代表样本：列出最能体现该流派修炼过程、典型表现和不同结果的角色或群体；样本不足时如实说明。

### 剑修

- 原文称谓：剑修
- 归纳名称：本命剑器型剑修
- 一句话流派定义：以剑器作为修为和剑道意志的共同载体，通过长期祭炼、御使与实战磨合，把多数资源集中转化为高强度攻伐能力，但剑器受损会直接动摇整条修炼路线。
- 准入依据与流派边界：本命剑器、剑诀、剑道感悟和持续实战共同构成稳定体系；只会使用剑形兵器、只掌握一门剑法或临时御剑不属于该流派。以剑阵为主要力量来源者是否仍属剑修，要看剑器与个人修为的联结是否仍是核心。
- 根本理念、修炼伦理与身份认同：把剑视为求道方式而非普通工具，重视意志与技艺的纯化，倾向围绕一条明确道路长期积累；是否强调决绝、守诺或正面交锋，取决于具体作品设定。
- 修炼对象、力量来源与核心载体：修炼对象包括自身修为、剑道感悟和剑器品质；力量来自修为运转、剑诀转化和人剑联结；本命剑器是储存、放大并释放力量的核心载体。
- 体系构成与内部协同：剑诀负责运转和操控，剑器承载力量，神念负责御使，剑道感悟决定技法上限，炼材与温养维持剑器成长，实战把分散部分磨合为稳定的攻防体系。失去剑器后仍可运转剑诀，但核心战力和成长路径会显著受损。
- 形成条件与适配人群：需要剑道传承、适配剑器、持续炼材和较强操控或感悟能力；更适合愿意长期集中资源、接受核心载体风险并持续磨炼技艺的修炼者，不适合频繁更换主修方向者。
- 日常功课与资源循环：日常反复进行运剑、养剑、磨炼剑诀、感悟剑道和实战校正；通过任务、交易或探索获取炼材和战斗机会，转化为剑器品质与剑术提升，再以高攻伐能力取得更高阶资源。
- 成长阶梯、关键门槛与上限：从掌握稳定御剑和基础剑招，发展到人剑协同、形成个人剑意，再到剑器与剑道共同质变；关键门槛是剑器承载力、操控精度和剑道感悟能否同步。后期上限取决于剑器能否继续晋升以及个人道路能否突破既有剑理。
- 标志性能力与识别特征：招牌表现是剑器远近转换、攻势集中、剑气或剑意贯穿多种招式，并以少数核心剑器形成连续攻击；可观察特征通常集中在随身剑器、御剑习惯和对剑器的高度重视上。
- 典型战斗、生产或行动范式：先以机动和剑势试探并压缩对手空间，再把神念、修为和剑器力量集中于短时间破防；若首轮不能建立优势，则通过御剑距离和剑招变化继续寻找一点突破，不适合无条件承受长期消耗。
- 优势、短板、克制与协同：同等资源下更擅长把力量集中到单体攻坚、快速破防和远近切换；短板是能力过度集中于核心剑器，面对封禁剑器、扰乱神念、强制持久战或大量低价值目标时效率下降。适合与能够控场、补充防御或制造破绽的阵法、符箓等路线协同。
- 环境、组织与社会关系：依赖高品质炼材、铸剑与修复能力、剑道传承和稳定实战环境，容易与炼器体系形成互补；成熟剑修群体可能提高剑材价值，并围绕名剑、剑诀和传承资格形成组织竞争。
- 常规代价、失稳方式与极端状态：常规代价是大量炼材、温养时间和心神投入；异常状态包括剑器与修为不匹配、剑意停滞、操控失衡和本命剑受创；极端情况下剑器崩毁可能导致修为反噬、道路断裂或死亡。
- 修复、退出与路线转换：轻度剑器损伤可通过修复和重新温养恢复，核心联结受损则可能需要重铸、改换载体或降低境界；退出后可转向普通术法或其他兵器路线，但已经形成的剑道结构未必能够完全保留。
- 传承、组织、分支与兴衰：通过剑诀、铸剑法、养剑法、师徒教习和实战试炼传承，可按单剑、多剑、重剑、快剑、剑阵或剑意方向形成支系；高阶剑材断绝、核心剑诀失落或修复体系崩溃会使流派衰退。
- 转向邪修原因：非邪修/不适用
- 信息边界与待确认项：本例全部内容均为结构演示；用于具体作品时，剑是否必须为本命载体、剑意是否存在、战斗范式、克制关系和剑毁后果均须重新确认。

### 体修

- 原文称谓：体修
- 归纳名称：损伤适应型体修
- 一句话流派定义：以身体本身同时充当修炼对象、储能载体和战斗武器，通过反复负荷、受损、修复与适应提高承受上限，换取稳定近战和生存能力，但成长速度受恢复资源与身体不可逆损耗限制。
- 准入依据与流派边界：长期淬炼、稳定修复、身体质变和独立近战体系共同构成路线；一次锻体、短期强化、单纯修炼近战武技或依靠外置护甲不属于该流派。血脉能力只有在持续改造身体并形成独立成长链时才与体修重合。
- 根本理念、修炼伦理与身份认同：认为身体不是承载法力的容器，而是可以持续开发的力量本体；重视承受、适应和对自身状态的直接控制。是否崇尚苦修、正面战斗或肉身纯粹性，取决于具体流派文化。
- 修炼对象、力量来源与核心载体：修炼对象是皮肉、筋骨、脏腑、血液和整体生命状态；力量来自身体结构强化、生命能量积累和对外界刺激的适应；身体本身是唯一不可轻易替换的核心载体。
- 体系构成与内部协同：淬体功法规定刺激和转化方式，负荷训练制造成长压力，药浴或灵材负责恢复，呼吸和运劲方法把身体强度转为实际攻防，状态感知用于防止暗伤积累。任何一环失衡都可能使训练从强化变成单纯损耗。
