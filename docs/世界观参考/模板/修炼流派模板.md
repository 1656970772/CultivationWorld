# 修炼流派模板


## 适用范围

- 本文用于整理作品中反复出现的修炼流派、修炼路线、资源路径、行为模式和长期选择。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 本文不单独整理“人生取向”；长生、夺宝、护道、夺权、复仇、守护、逍遥、忠诚、避世等观念，只作为具体流派的核心目标与价值取向来写。
- 不把“功法属性”误当成修炼流派；剑修、体修、炼丹、御兽、傀儡等只有在形成稳定资源路径、行动链和风险偏好时，才写成流派。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

- 不为只出现一次的桥段创造流派；至少要有多个样本，或一个非常强的代表角色/事件链。
- 不把流派写成道德判断；要写目标、资源偏好、风险偏好、行动链、优势、代价、失败后果，以及是否可能转向邪修。
- 如果某个流派中有人后来变成邪修，必须写清变成邪修的原因：是哪些事件导致心态变化、资源断供、复仇执念、被追杀、被诱导，还是主动加入邪修门派。
- 原文没有说明流派形成条件、资源偏好、风险偏好、变成邪修原因、成功样本或失败样本时，不要补，可以写“原文未说明”。

参考范围不局限于以下类别：

- **修炼路线**：剑修、体修、神魂、炼丹、炼器、阵法、符箓、御兽、傀儡、毒修、血修、鬼修、魔修、佛修、儒修、妖修、血脉流。
- **核心目标与价值取向**：长生避险、夺宝求富、护道传承、夺取权力、报仇雪恨、守护亲友、逍遥自在、忠于宗门、养老避世、飞升成仙。
- **资源偏好**：丹药、功法、法宝、灵石、灵脉、妖兽材料、传承、情报、道侣/炉鼎、弟子、势力职位、血脉资源。
- **资源获取方式**：闭关、游历、猎妖、夺宝、交易、拜师、收徒、入宗、叛逃、夺权、暗杀、血祭、掠夺、飞升准备。
- **风险倾向**：谨慎、赌命、激进、隐忍、抱团、单干、仗势、投机、牺牲他人、重情义、低调苟活。
- **转向邪修原因**：资源断供、突破无望、亲友被杀、被宗门背叛、被追杀、被强者夺宝、复仇执念、寿元将尽、邪法诱惑、主动投靠邪修门派。
- **成功路径**：长期积累、获得传承、拜入势力、炼制关键资源、建立人脉、突破瓶颈、掌握特殊功法、创立势力。
- **失败路径**：身死道消、被夺宝、走火入魔、资源耗尽、堕为邪修、被围剿、众叛亲离、寿元耗尽、传承断绝。

## 案例

### 案例

#### 案例 1：炼丹流（《斗破苍穹》）

- 形成条件：萧炎在11岁时斗气突退成废，随后戒指中大陆第一炼药师药老醒来吸收其斗气并传授焚诀，萧炎因此转入“炼药+异火”主导的修炼路径。  
- 核心目标与价值取向：先修复自身修炼连续性，再通过炼药和异火构建长期竞争力。  
- 资源偏好：炼药术、异火、丹药、焚诀、炼药市场相关素材。  
- 资源获取方式：师徒传承、魔兽山脉与塔戈尔沙漠历练夺取异火、帝都炼药师交易市场。  
- 风险倾向：前期谨慎修复，后期转向高压博弈，面对资源争夺时偏激进。  
- 典型行动链：失势修复→拜师承业→异火收集→以炼药术强化自身与同盟→以交易与合作推动势力上位。  
- 成功路径：持续提升炼药/异火链条后可从“废柴”逆转到高位强者，形成可复制的成长闭环。  
- 失败路径：资源中断或斗气体系失衡时，修行停滞、失去对抗空间并陷入围剿风险。  
- 转向邪修可能性：当前文本主要写其以正向成长线为主，未出现明确主动入邪修的样本。  
- 结局走向：可进入主流大陆权力体系的核心竞争层，典型是以资源供给换取势力整合。  

#### 案例 2：血修流（《诛仙》）

- 形成条件：张小凡在草庙村被屠后被青云门收养，天资平平却得“道法与法宝‘噬魂’”；随后其修行出现佛、道、魔三修分流，并承接炼血系因素。  
- 核心目标与价值取向：先求自保与复仇，再以高回报补偿策略重建支配力。  
- 资源偏好：噬血珠、佛道法门、魔修相关法术、魔性/戾气型增幅手段。  
- 资源获取方式：宗门授法（青云门、天音寺）、关键法宝继承（噬魂/噬血珠）、魔道支系关联。  
- 风险倾向：情绪驱动强，激进且赌命，容易因反噬导致长期代价。  
- 典型行动链：初期低位修行→同时吸收多体系法术→关键法宝介入形成血性修持→在仇杀压力下持续强化。  
- 成功样本：由平常弟子跃升为高强度对抗型角色，短时间内具备可观生存与反击能力。  
- 失败路径：文本中明确出现“噬血珠反噬”与魔道化倾向，伴随人脉关系恶化、被追杀与身份不稳。  
- 转向邪修原因：父母被杀引发仇恨、追杀压力、以及噬血机制反噬，是其向三修/魔化偏移的核心驱动。  
- 结局走向：呈现“强敌化”轨迹，兼具成就与持续风险，后续路径对宗门秩序是结构性冲击。  

#### 案例 3：阵法流

- 形成条件：小说《诛仙》中的青云门系统分峰化明显，风回峰以“擅长阵法和炼丹”为职能，落霞峰以奇门遁甲和符箓为主要修炼内容。  
- 核心目标与价值取向：建立可重复的控场体系，用阵法/符箓支撑宗门防御与跨场景协同。  
- 资源偏好：阵法诀法、符箓体系、地理位点与能量节点、峰门师承。  
- 资源获取方式：依附门派分峰修行、接受峰师授课、持续抄录与实战调度。  
- 风险倾向：偏守势、讲求协同，重视外围安全与节点冗余。  
- 典型行动链：选定修向→在峰内积累基础阵法/符箓 → 将阵势用于防御与战场调度 → 在危机中扩展到宗门治理。  
- 成功样本：构建“单人可控-群体可托”双层结构，在对抗中降低失败率并提升整体生存。  
- 失败路径：节点失守、阵势失衡、核心符源被断会导致连锁崩盘并扩大组织风险。  
- 转向邪修可能性：原文以阵法作为宗门正向治理路径为主，未出现大规模该流派必然转邪修的结构性叙事。  
- 结局走向：多数角色走向军师/护境型角色，偏向长期组织协同与秩序维持。
