# 炼器师模板

## 适用范围

用于整理作品中的炼器师职业，以及与炼器流程高度相关的锻造师、铸剑师、工坊供奉、法宝炼制、装备修复、器灵处理、祭炼认主、阵纹禁制和材料加工内容。

本模板重点不是收集武器或法宝条目；武器名称、形制、制作材料和适用境界应放入 `武器分析模板.md`，法宝名称、功效、炼制材料、绑定/认主和适用境界应放入 `法宝分析模板.md`。本模板重点分析“玩家如果选择炼器师职业，这个职业在小说世界里如何运转”：从获取器方/图纸、准备材料、选择环境、使用工具、熔炼塑形、铭刻符文/阵纹/禁制、成器失败、修复升级、售卖委托到职业成长的完整闭环。

## 前置声明

- 只整理原文出现过，或能由原文和可靠资料来源明确支撑的炼器师职业与炼器流程。
- 样本应覆盖职业分支、炼器环节、器物类型和适用境界；不要只写主角或成功案例。
- 案例只是写法示范，不是数量上限；有价值的流程细节、失败案例和职业样本都应继续补充。
- 原文没有说明的职业等级、境界梯度、流程步骤、资源来源、成器结果或失败后果，写“原文未说明”，不要补设定。
- 信息暂不完整但值得保留的内容，先放入 `### 待定案例`；后续补充摘要和来源，足够支撑案例后再转入 `### 案例`。

## 必须写什么

本节是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

- **职业定位与分支**：炼器师是散修副业、宗门工坊核心、坊市职业、家族传承、战争军备职业，还是高阶法宝炼制的稀缺身份；相关分支包括锻造师、铸剑师、工坊供奉、阵器师、飞舟制造者、储物器制造者、法宝修复师、器灵培养者等。
- **处理对象与输入资源**：矿石、灵金、妖兽骨皮、鳞甲、灵木、异火、精血、魂魄、旧器残片、器方、图纸、武器、护具、法宝、阵盘、飞舟、储物器、傀儡部件；记录主材、辅材、灵石、火种、阵纹材料、禁制材料、器灵胚胎和来源。
- **器方、图纸与传承限制**：宗门传承、师承、家族传承、拍卖、坊市购买、遗迹残图、古器拆解、秘境机缘、交易、抢夺、自创、残图补全；写清稀缺性、保密性、传承限制和仿制可能。
- **工具设施与炼器环境**：炼器炉、锻台、锤砧、熔炉、火室、炼器室、宗门工坊、阵纹工具、禁制刻刀、冷却池、材料库、修复台；记录品阶、损坏风险、火脉/雷火环境、灵气浓度、材料存放、禁制防护、护法需求和环境风险。
- **操作者门槛**：修为、神识、控火、材料理解、阵纹知识、禁制理解、器方掌握、锻造经验、传承资格、体魄力量、火属性能力；若有学徒、炼器师、大师、宗师等层级，按原文写。
- **炼器流程**：辨材、选材、净化、熔炼、塑形、锻打、淬火、铭刻阵纹、布设禁制、注灵、封灵、祭炼、温养、开炉、验器、试用、修整、出售或自用。没有完整流程时，只写出现过的环节。
- **炉火、阵纹、禁制与器灵**：凡火、地火、真火、灵火、异火、雷火、阵法熔炉、神识控火；铭纹、刻阵、封禁、嵌灵石、驱动核心、注入魂魄、培养器灵、器灵择主、禁制认主、储物空间开辟。独立符箓体系放入 `符师模板.md`。
- **境界差异与特殊手段**：低阶依赖炉火和锻台，高阶神识控器、虚空炼器、以天地为炉、以自身真火炼材、同时炼多件器物、远程控炉、借阵法或异火炼器；特殊手段包括血祭炼器、魂魄入器、旧器重铸、吞噬材料升级、本命温养、器灵养成、空间开辟。
- **成器结果、产出与旧器处理**：成器数量、品相、品阶、灵性、器灵、阵纹完整度、耐久、残次品、废器、半成品、反噬器、异象器；产出包括武器、护具、法宝、阵盘、阵旗、储物器、飞舟、炼丹炉、傀儡部件、修复件、升级件、器方改良；旧器处理写修复、补纹、替材、重铸、升级、温养、拆解和降品风险。
- **时间、限制与失败后果**：采矿、材料处理、熔炼、塑形、铭纹禁制、温养、冷却、修复返工耗时；失败包括材料报废、器胚损毁、炸炉、火候失控、阵纹崩坏、禁制反噬、器灵失控、品质下降、法宝损毁、炼器师受伤、异象引争。
- **收益方式、来源场景与适用境界**：自用装备、出售器物、宗门贡献、私人定制、代炼抽成、修复收费、升级收费、战争军备订单、拍卖溢价、交换器方、换材料、建立人脉；场景包括炼器堂、坊市工坊、拍卖会、矿脉、战场、秘境、洞府、法宝修复、飞舟制造和散修交易。

## 案例

### 案例

#### 特殊手段案例通用卡片

- **案例名称和类型**：如血祭炼器、旧器重铸、器灵养成、本命法宝温养。
- **使用者**：写清人物、身份、境界、炼器水平和所属势力。
- **使用场景**：写清是在宗门工坊、洞府闭关、战场军备、秘境应急、法宝修复、拍卖委托还是逃亡途中使用。
- **前置条件**：写清需要的主材、辅材、旧器残片、器方图纸、火源、炉具、阵纹、禁制、魂魄、器灵胚胎、神识、护法或特殊环境。
- **具体过程**：详细写清操作步骤，不要只写“炼制特殊”。例如如何净化材料、如何熔炼塑形、如何铭刻阵纹、如何封禁器灵、如何认主或温养。
- **产出或效果**：写清成器类型、品质、特殊能力、成长性、认主方式、与普通器物的差异。
- **代价与风险**：写清材料报废、器胚崩坏、器灵反噬、禁制失控、炼器师受伤、异象暴露、委托失败、器物反主等后果。
- **限制**：写清是否只有本人能用，是否依赖本命精血、魂魄、异火、雷火、阵图、传承、地形、境界或长期温养。
- **可参考点**：写清该案例对职业体系的参考价值，例如法宝成长路线、装备经济、军备制造、器灵风险、修复升级玩法、NPC 职业稀缺性。
