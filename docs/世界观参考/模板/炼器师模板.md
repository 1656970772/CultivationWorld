# 炼器师模板

# 规范

用于整理作品中的炼器师职业，以及与炼器流程高度相关的锻造师、铸剑师、工坊供奉、法宝炼制、装备修复、器灵处理、祭炼认主、阵纹禁制和材料加工内容。

本模板重点不是收集武器或法宝条目；武器名称、形制、制作材料和适用境界应放入 `武器分析模板.md`，法宝名称、功效、炼制材料、绑定/认主和适用境界应放入 `法宝分析模板.md`。本模板重点分析“玩家如果选择炼器师职业，这个职业在小说世界里如何运转”：从获取器方/图纸、准备材料、选择环境、使用工具、熔炼塑形、铭刻符文/阵纹/禁制、成器失败、修复升级、售卖委托到职业成长的完整闭环。

本文只整理小说中出现过，或能由小说内容明确支撑的炼器师职业、炼器流程、职业分支、工具设施、炼器环境、操作手法、特殊手段、收益方式和失败后果，不编造小说中不存在的职业体系。

整理时应按职业分支、炼器环节、器物类型和适用境界尽可能覆盖完整：每一种职业分工、每一类炼器用途、每一个境界阶段，只要小说中有对应内容，都应尽量写入对应段落。文档长度不设上限，宁可写长，也不要为了压缩篇幅遗漏有参考价值的职业样本、流程细节和失败案例。

如果某类职业分支、某个境界阶段，或输入资源、器方/图纸获取方式、工具设施、炼器环境、操作手法、特殊手段、成器结果、限制/失败后果等字段在小说中没有可靠依据，可以写“原文未说明”；不得为了补齐职业等级、境界梯度、炼器流程或数值体系而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 职业定位与分支：写炼器师是散修副业、宗门工坊核心、坊市职业、家族传承、战争军备职业，还是高阶法宝炼制的稀缺身份；相关分支包括锻造师、铸剑师、工坊供奉、阵器师、飞舟制造者、储物器制造者、法宝修复师、器灵培养者等。
- 处理对象与输入资源：写矿石、灵金、妖兽骨皮、鳞甲、灵木、异火、精血、魂魄、旧器残片、器方、图纸、武器、护具、法宝、阵盘、飞舟、储物器、傀儡部件；记录主材、辅材、灵石、火种、阵纹材料、禁制材料、器灵胚胎和获取方式。
- 器方、图纸与传承限制：写宗门传承、师承、家族传承、拍卖、坊市购买、遗迹残图、古器拆解、秘境机缘、交易、抢夺、自创、残图补全；写清稀缺性、保密性、传承限制和仿制可能。
- 工具设施与炼器环境：写炼器炉、锻台、锤砧、熔炉、火室、炼器室、宗门工坊、阵纹工具、禁制刻刀、冷却池、材料库、修复台；记录品阶、损坏风险、火脉/雷火环境、灵气浓度、材料存放、禁制防护、护法需求和环境风险。
- 操作者门槛：写修为、神识、控火、材料理解、阵纹知识、禁制理解、器方掌握、锻造经验、传承资格、体魄力量、火属性能力；若有学徒、炼器师、大师、宗师等层级，按原文写。
- 炼器流程：写辨材、选材、净化、熔炼、塑形、锻打、淬火、铭刻阵纹、布设禁制、注灵、封灵、祭炼、温养、开炉、验器、试用、修整、出售或自用；没有完整流程时，只写出现过的环节。
- 炉火、阵纹、禁制与器灵：写凡火、地火、真火、灵火、异火、雷火、阵法熔炉、神识控火；铭纹、刻阵、封禁、嵌灵石、驱动核心、注入魂魄、培养器灵、器灵择主、禁制认主、储物空间开辟。独立符箓体系放入 `符师模板.md`。
- 境界差异与特殊手段：写低阶依赖炉火和锻台，高阶神识控器、虚空炼器、以天地为炉、以自身真火炼材、同时炼多件器物、远程控炉、借阵法或异火炼器；特殊手段包括血祭炼器、魂魄入器、旧器重铸、吞噬材料升级、本命温养、器灵养成、空间开辟。
- 成器结果、产出与旧器处理：写成器数量、品相、品阶、灵性、器灵、阵纹完整度、耐久、残次品、废器、半成品、反噬器、异象器；产出包括武器、护具、法宝、阵盘、阵旗、储物器、飞舟、炼丹炉、傀儡部件、修复件、升级件、器方改良；旧器处理写修复、补纹、替材、重铸、升级、温养、拆解和降品风险。
- 时间、限制与失败后果：写采矿、材料处理、熔炼、塑形、铭纹禁制、温养、冷却、修复返工耗时；失败包括材料报废、器胚损毁、炸炉、火候失控、阵纹崩坏、禁制反噬、器灵失控、品质下降、法宝损毁、炼器师受伤、异象引争。
- 收益方式、场景与适用境界：写自用装备、出售器物、宗门贡献、私人定制、代炼抽成、修复收费、升级收费、战争军备订单、拍卖溢价、交换器方、换材料、建立人脉；场景包括炼器堂、坊市工坊、拍卖会、矿脉、战场、秘境、洞府、法宝修复、飞舟制造和散修交易。
