# 事件因果链（长程因果图）模板

# 规范

## 参考和要求

用于整理作品中出现过，或能由小说内容明确支撑的跨事件、跨地点、跨势力、长时间发酵的长程因果链。

本模板关注“一件事如何滚成另一件事”。单场战斗、单次机缘、单段关系变化，不要硬扩展成长程因果。只有具备较长时间跨度、多阶段传播、多地点转移、多方参与、长期余波或后续事件触发的内容，才放入本文。

每部作品至少选择 10 条有代表性的长程因果链。不要只选主角相关链条，NPC、配角、反派、宗门、家族、商会、妖族、魔道、凡俗国家之间的长程因果同样重要。样本应尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局。

只写小说内容能够明确支撑的内容。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 因果链类型：参考资源争夺链、宝物出世链、秘境余波链、宗门战争链、正魔冲突链、通缉追杀链、复仇链、师门背叛链、邪修暴露围剿链、拍卖截杀链、跨区域逃亡链、族群战争链、飞升或跨界链、历史封印复燃链、旧债牵连链等，写清主因和次因。
- 起点事件：参考宝物出现、秘境开启、功法泄露、强者陨落、弟子叛逃、亲友被杀、身份暴露、资源短缺、战争爆发、封印松动、传承出世、黑市消息泄露、宗门任务失败、误杀或误判等，不要只写“某人得到机缘”。
- 深层背景：参考资源稀缺、境界瓶颈、势力旧怨、功法路线冲突、地域贫瘠、正邪对立、族群仇怨、师承背叛、寿元压力、宗门衰落、强者布局、凡俗王朝变化等，写清为什么会发生。
- 阶段形态：参考预兆、起点、消息扩散、试探、准备、第一次冲突、升级、转移、追杀、势力介入、公开化、暂时结算、余波、二次触发、长期沉淀等，中间环节不要省略。
- 传播方式：参考目击、传闻、坊市消息、宗门公告、通缉令、黑市情报、商会预告、弟子回报、灵兽或傀儡侦查、法器感应、天象异变、幸存者泄露、敌人放风等，写清谁知道、如何知道、传播到哪里。
- 地点轨迹：参考凡俗村镇、宗门山门、坊市、洞府、秘境、战场、边境、海域、草原、荒漠、古地、禁地、传送阵、跨界通道、异族区域、黑市、拍卖场等，写清事件如何移动。
- 资源流转：参考法宝、丹药、功法、灵石、灵草、妖丹、尸体、魂魄、地图、令牌、传承、秘钥、情报、人情、职位、地盘、矿脉、商路、灵脉、俘虏等，写清谁得到、谁失去、谁因此暴露。
- 人物与势力变化：参考结怨、结盟、背叛、投靠、复仇、追杀、通缉、庇护、灭门、迁移、分裂、吞并、隐姓埋名、公开身份、转修功法、进入邪道等，写清关系和身份变化。
- 长期后果：参考区域局势变化、资源价格变化、宗门实力变化、NPC 修炼路线改变、关系网重组、后续秘境或战斗触发、角色性格变化、世界状态恶化或恢复等，写清余波如何继续影响后文。

每条因果链建议按以下卡片整理：

- 因果链名称：一句话概括主链。
- 因果链类型：可以有多个类型，但要区分主因和次因。
- 起点事件：发生在哪里，谁参与，谁最早知道，涉及什么资源、身份、仇怨或机会。
- 深层背景：资源、势力、功法、寿元、战争、境界、族群或历史旧账。
- 阶段链：起点如何发生 / 消息如何扩散 / 各方如何反应 / 冲突如何升级 / 地点如何转移 / 资源如何流转 / 关系如何改变 / 阶段性结算。
- 长期余波：后续又引出什么新事件、追杀、交易、战争、迁移、性格变化或区域局势。
- 集中补充：波及范围 / 信息传播链 / 资源流转链 / 关系变化链 / 机会点与错过点 / 最终结果 / 可作为参考的点。

阶段链不能写成一段概要；若原文支持，应至少按“起点发生 / 消息扩散 / 各方反应 / 冲突升级 / 地点转移 / 资源流转 / 关系改变 / 阶段性结算”逐段展开，并写清每一步为什么触发下一步。

如果某个事件只在一个场景内完成，放入 `冲突事件分析模板.md`；如果重点是时间窗口、参与条件、准备过程和错过后果，放入 `动态事件与机会点模板.md`；如果重点是关系改变，放入 `人物关系与事件分析模板.md`。

```md
## 事件因果链卡片

- 集中补充：

### 隐秘控制转为长期性格影响

- 因果链类型：师徒控制链 / 夺舍因果链 / 性格形成链。
- 起点事件：弱者被强者以培养、传授、保护等名义纳入控制范围。
- 深层背景：强者需要棋子、容器、传承对象或长期控制对象，弱者缺少信息、资源和自保能力。
- 阶段链：
  - 起点发生：弱者接受培养、传授或保护，进入强者安排的路径。
  - 消息扩散：控制关系通常保持隐秘，外部只看到师承、交易或庇护表象。
  - 各方反应：受控者起初依赖强者，旁观者可能误判双方关系。
  - 冲突升级：受控者逐步察觉异常，控制目的从培养转为生死威胁。
  - 地点转移：冲突可从修炼场所、洞府、秘境或逃亡途中转移到公开对抗。
  - 资源流转：关键功法、认知、底牌或身体控制权发生转移。
  - 关系改变：师徒、庇护或交易关系破裂，转为敌对、逃亡或反杀。
  - 阶段性结算：控制者失败、受控者脱身，或隐患暂时被压下。
- 长期余波：影响角色后续对强者、交易、师承、陌生修士和底牌暴露的信任边界。
- 集中补充：适合整理“隐秘事件如何长期塑造角色性格”和“凡人进入修仙世界的第一条因果链”。

### 秘境开启引发多方争夺

- 因果链类型：秘境余波链 / 宝物争夺链 / 多方势力入局链 / 资源流转链。
- 起点事件：秘境、传承、古修遗留或高价值宝物出现，进入资格、地图、令牌或开启条件开始流通。
- 深层背景：高价值资源稀缺，势力需要传承、宝物或突破机会，散修和小势力也试图借机翻身。
- 阶段链：
  - 起点发生：秘境线索、传承消息或开启条件被发现。
  - 消息扩散：地图、令牌、传闻、坊市消息或势力公告引来更多参与者。
  - 各方反应：宗门、家族、散修和敌对势力开始准备、结盟或设伏。
  - 冲突升级：进入秘境后争夺宝物，临时合作因分配不均或身份暴露破裂。
  - 地点转移：冲突从入口、秘境内部、出口延伸到坊市、宗门或逃亡路线。
  - 资源流转：地图、令牌、传承、宝物和情报在争夺中易主或暴露。
  - 关系改变：幸存者结怨、结盟、背叛或互相追索。
  - 阶段性结算：秘境关闭，宝物归属暂定，失败方继续追查。
- 长期余波：幸存者消息、宝物用途、失败方追索和资源归属继续影响后续交易、追杀与势力判断。
- 集中补充：适合整理“机会点如何从秘境延伸为长期风险”和“高价值资源如何改变人物关系”。

### 区域战争改变修炼生态

- 因果链类型：区域战争链 / 宗门迁移链 / 正魔冲突链 / NPC 命运改写链。
- 起点事件：宗门、正魔、族群、王朝或区域势力矛盾升级，局部冲突扩散为长期战争压力。
- 深层背景：资源分配、地盘控制、旧怨、正邪立场、族群矛盾或王朝变动积累到无法调和。
- 阶段链：
  - 起点发生：边境摩擦、据点失守、任务失败或关键人物遇袭引爆冲突。
  - 消息扩散：宗门命令、坊市传闻、战报或逃难人群把局势传向周边。
  - 各方反应：宗门调动弟子，商会调整路线，散修避险或投靠，凡俗势力被卷入。
  - 冲突升级：战场扩大，资源紧张，任务、征召、追杀和撤离频率上升。
  - 地点转移：冲突从边境、坊市、战场扩散到宗门腹地、迁移路线或避难区域。
  - 资源流转：灵石、丹药、法器、地盘、商路和俘虏在战争中重新分配。
  - 关系改变：角色结盟、复仇、背叛、投靠或被迫改变修炼路线。
  - 阶段性结算：一方退让、迁移、被吞并或形成新的区域秩序。
- 长期余波：区域格局、宗门实力、资源价格、角色迁移、复仇结盟和修炼路线持续变化。
- 集中补充：适合整理“大势如何推动小人物迁移”和“战争如何生成任务、逃亡、资源消耗与关系变化”。
```
