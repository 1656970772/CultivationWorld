# 事件因果链（长程因果图）模板

## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的跨事件、跨地点、跨势力、长时间发酵的长程因果链。

## 前置声明

- 本文关注“一件事如何滚成另一件事”。单场战斗、单次机缘、单段关系变化，不要硬扩展成长程因果。
- 只有具备较长时间跨度、多阶段传播、多地点转移、多方参与、长期余波或后续事件触发的内容，才放入本文。
- 每部作品至少选择 10 条有代表性的长程因果链。不要只选主角相关链条，NPC、反派、宗门、家族、商会、妖族、魔道、凡俗国家之间的长程因果同样重要。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 信息不足但符合主题的内容，先写入 `### 待定案例`。后续获得新信息时，在同一待定项追加摘要和来源；信息足够后，复核来源并转为正式案例。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 因果链类型 | 资源争夺链、宝物出世链、秘境余波链、宗门战争链、正魔冲突链、通缉追杀链、复仇链、师门背叛链、邪修暴露围剿链、拍卖截杀链、跨区域逃亡链、族群战争链、跨界链、历史封印复燃链、旧债牵连链 | 写清主因和次因。 |
| 起点事件 | 宝物出现、秘境开启、功法泄露、强者陨落、弟子叛逃、亲友被杀、身份暴露、资源短缺、战争爆发、封印松动、传承出世、消息泄露、任务失败、误杀或误判 | 不要只写“某人得到机缘”。 |
| 深层背景 | 资源稀缺、境界瓶颈、势力旧怨、功法路线冲突、地域贫瘠、正邪对立、族群仇怨、师承背叛、寿元压力、宗门衰落、强者布局 | 写清为什么会发生。 |
| 阶段形态 | 预兆、起点、消息扩散、试探、准备、第一次冲突、升级、转移、追杀、势力介入、公开化、暂时结算、余波、二次触发、长期沉淀 | 中间环节不要省略。 |
| 传播方式 | 目击、传闻、坊市消息、宗门公告、通缉令、黑市情报、商会预告、弟子回报、法器感应、天象异变、幸存者泄露、敌人放风 | 写清谁知道、如何知道、传播到哪里。 |
| 地点轨迹 | 村镇、宗门、坊市、洞府、秘境、战场、边境、海域、草原、荒漠、古地、禁地、传送阵、跨界通道、黑市、拍卖场 | 写清事件如何移动。 |
| 资源流转 | 法宝、丹药、功法、灵石、灵草、妖丹、尸体、魂魄、地图、令牌、传承、秘钥、情报、人情、职位、地盘、矿脉、商路、俘虏 | 写清谁得到、谁失去、谁因此暴露。 |
| 人物与势力变化 | 结怨、结盟、背叛、投靠、复仇、追杀、通缉、庇护、灭门、迁移、分裂、吞并、隐姓埋名、公开身份、转修功法、进入邪道 | 写清关系和身份变化。 |
| 长期后果 | 区域局势变化、资源价格变化、宗门实力变化、NPC 修炼路线改变、关系网重组、后续秘境或战斗触发、角色性格变化、世界状态恶化或恢复 | 写清余波如何继续影响后文。 |

案例格式建议：

- 因果链名称：一句话概括主链。
- 因果链类型：可以有多个类型，但要区分主因和次因。
- 起点事件：发生在哪里，谁参与，谁最早知道，涉及什么资源、身份、仇怨或机会。
- 深层背景：资源、势力、功法、寿元、战争、境界、族群或历史旧账。
- 阶段链：起点如何发生 / 消息如何扩散 / 各方如何反应 / 冲突如何升级 / 地点如何转移 / 资源如何流转 / 关系如何改变 / 阶段性结算。
- 长期余波：后续又引出什么新事件、追杀、交易、战争、迁移、性格变化或区域局势。
- 集中补充：波及范围 / 信息传播链 / 资源流转链 / 关系变化链 / 机会点与错过点 / 最终结果 / 可作为参考的点。

阶段链不能写成一段概要；若原文支持，应至少按“起点发生 / 消息扩散 / 各方反应 / 冲突升级 / 地点转移 / 资源流转 / 关系改变 / 阶段性结算”逐段展开，并写清每一步为什么触发下一步。

如果某个事件只在一个场景内完成，放入 `冲突事件分析模板.md`；如果重点是时间窗口、参与条件、准备过程和错过后果，放入 `动态事件与机会点模板.md`；如果重点是关系改变，放入 `人物关系与事件分析模板.md`。

## 案例

### 案例

#### 案例 1：韩立与墨大夫、余子童的早期夺舍因果链

**因果链类型：** 师徒控制链 / 夺舍因果链 / 凡人踏入修仙路链 / 性格形成链。

**阶段链：**

1. 起点发生：韩立进入七玄门后被墨大夫纳入培养和控制范围；表面是医术、修炼和师徒关系，实质牵连墨大夫身体衰败、延续自身和夺舍目的。
2. 消息扩散：夺舍目的没有公开扩散，只在墨大夫、韩立和余子童残魂相关信息中逐步暴露；外部旁观者是否知情按原文填写。
3. 各方反应：墨大夫继续培养和控制韩立，韩立在有限信息下学习、观察和自保，余子童残魂信息让韩立接触夺舍、残魂和修仙界风险。
4. 冲突升级：韩立逐步发现异常，师徒关系从培养转为生死控制，夺舍风险变成直接威胁。
5. 地点转移：链条从七玄门内部、医馆或修炼场景，转向夺舍冲突和后续离开凡俗武林的修仙入口。
6. 资源流转：医术、修炼法门、残魂情报、夺舍认知和修仙线索从墨大夫/余子童相关链条转移到韩立手中。
7. 关系改变：师徒信任破裂，韩立从被培养者变成反制者，也形成对强者、交易和陌生修士的长期警惕。
8. 阶段性结算：控制关系破裂，夺舍失败，韩立摆脱早期束缚并获得进入修仙世界的关键线索。

**长期余波：** 这条链影响韩立后续对师承、交易、强者和陌生修士的信任边界，也成为他重视保命、信息差和底牌隐藏的早期来源。

**集中补充：** 信息传播链写墨大夫隐瞒目的、余子童残魂透露修仙界风险、韩立逐步拼出真相；资源流转链写医术、修炼法门、残魂信息和后续修仙线索如何转移；机会点与错过点写韩立何时发现异常、何时可反制或逃离；最终结果写控制关系破裂、夺舍失败、韩立获得修仙入口并形成长期谨慎性格。

**可作为参考的点：** 弱者被强者培养并控制、夺舍风险、凡人进入修仙世界的第一条因果链、隐秘事件如何长期影响角色性格。

#### 案例 2：虚天殿开启与虚天鼎争夺因果链

**因果链类型：** 秘境余波链 / 宝物争夺链 / 多方势力入局链 / 资源流转链。

**阶段链：** 虚天殿开启消息或进入条件出现后，乱星海多方修士围绕名额、令牌、地图、同行者、保命手段和虚天鼎等宝物做准备。进入后，潜在竞争变成围绕宝物、灵药、通道、禁制和虚天鼎的争夺、合作、背叛或追杀。链条从坊市、洞府或集合地点转入虚天殿内部，再延伸到离开后的宝物归属、消息传播和后续追索。

**长期余波：** 虚天鼎、灵兽特殊用途、幸存者消息和各方失败后的追索，会继续影响后续修炼、交易、追杀和势力判断。

**可作为参考的点：** 秘境开启如何引发长程因果、高价值宝物如何改变资源流转、特殊能力如何成为关键钥匙、机会点如何延伸为追杀和势力判断。

#### 案例 3：天南魔道入侵与正魔大战因果链

**因果链类型：** 区域战争链 / 宗门迁移链 / 正魔冲突链 / NPC 命运改写链。

**阶段链：** 天南正道、魔道及相关宗门矛盾升级，边境冲突、宗门任务、情报传递、资源紧张和弟子调动开始影响低阶修士。消息通过宗门命令、坊市传闻、逃亡修士和任务安排扩散。小规模冲突扩大为宗门战争，地点从山门、边境任务点、坊市和战场，转移到撤离路线、新驻地或其他修仙区域。战争消耗丹药、符箓、法器、灵石和人手，也带来战利品、遗产、黑市交易和迁移机会。

**长期余波：** 大战改变区域秩序、宗门格局、角色迁移、资源来源和关系网络，后续的宗门重组、复仇、结盟、避世都可能由此延伸。

**可作为参考的点：** 区域战争如何改变地图状态、大势如何推动小人物迁移、正魔冲突如何形成长期世界压力、宗门战争如何生成任务和资源消耗。
