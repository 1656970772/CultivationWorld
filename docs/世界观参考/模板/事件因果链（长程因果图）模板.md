# 事件因果链（长程因果图）模板

## 适用范围

本模板用于整理作品中由原文明确出现或可由连续机制谨慎归纳的跨事件、跨阶段、长时间发酵的因果链。

本模板关注“一种状态为什么会演变成另一种状态”，重点整理初始结构、直接触发、行动主体、作用机制、传递载体、分支汇合、反馈循环、状态升级、衰减终止和长期余波。空间、势力或人物数量可以帮助判断长程性，但不是必须同时满足的硬门槛。

可收录的典型链条包括：资源争夺链、宝物出世链、秘境余波链、宗门战争链、正魔冲突链、通缉追杀链、复仇链、师门背叛链、邪修暴露围剿链、拍卖截杀链、跨区域逃亡链、族群战争链、飞升或跨界链、历史封印复燃链、旧债牵连链、长期资源经营链等。

单场战斗、单次机缘、一次修炼、一次对话或一段短期关系变化，默认只作为长程链中的节点。只有当它继续改变后续行动条件、主体关系、资源分布、环境状态或制度安排，并形成多个不可合并的因果阶段时，才单独建立长程因果链。

## 整理原则

1. 先确定核心因果问题
   每条链先用“为什么A最终导致B”或“某种状态如何演变为另一种状态”锁定主线。标题只概括对象，核心因果问题负责说明真正需要解释的变化。若卡片只是围绕人物、物品或时间顺序罗列事件，尚未形成因果链。

2. 再划定起止边界
   明确从哪个状态变化开始追踪，到哪个相对稳定、终止或转入新机制的状态结束。更早的内容只作为初始条件，更晚但已经更换主要主体、目标、资源或作用机制的内容拆为新链。不能因为存在更早背景或更远余波就无限向前后扩展。

3. 区分条件、诱因和结果
   初始结构、长期矛盾和脆弱点只是可能条件，不等于直接原因；触发事件负责让链条启动；临界条件解释为什么偏偏在此时跨过阈值；阶段结果必须是前一因果边实际产生的新状态。不得把所有背景统一写成“原因”。

4. 逐条建立因果边
   每个阶段必须回答“什么前置状态或事件，通过什么机制和载体，在什么条件下，促使哪个主体作出何种行动，最终产生什么新状态”。只写“随后”“后来”“与此同时”不构成因果说明。

5. 在因果边上判断明确程度
   同一条长链可能同时包含原文明确、可谨慎归纳、存在其他合理解释和仅时间相邻的连接。不能只给整条链一个笼统强度；每条关键连接都要单独判断。仅时间相邻的事件不得接入主因果链。

6. 识别分支、汇合和反馈
   不把所有链条强行写成直线。一个事件可以产生多条分支，多项条件可以汇合成同一结果，后果也可能反过来强化或削弱前面的条件。应区分主路径、次路径、正反馈、负反馈、循环报复和间歇复燃。

7. 同时记录放大、抑制和中断
   不只写冲突如何升级，还要写哪些条件让影响延迟、减弱、转向或停止。阶段内的阻碍只解释当前因果边；全链的放大、抑制和中断条件只总结跨越多个阶段的结构性因素，避免重复。

8. 只记录真正参与因果传递的变化
   信息、资源、空间、关系、权力、身份、规则和环境都可能成为因果载体，但不是每条链、每个阶段都同时具备。只记录它们如何改变主体的能力、认知、选择或处境，不把无关地点移动和物品易主当成因果。

9. 区分正常、异常和极端演化
   正常状态写原系统怎样运行；异常状态写原有循环被扰动、误判、失控或中断；极端状态写战争、崩溃、灭亡、跨区域扩散等质变。还要追踪链条怎样潜伏、启动、扩散、放大、衰减、稳定、终止或复燃，不默认所有链都会不断升级。

10. 同时观察个体和环境影响
    结果不仅是主要人物得到或失去什么，还要看旁观者、组织、地区、制度和生态环境如何受影响。区分直接结果、间接结果、意外结果、受益者和受损者，不把所有变化压缩为一句“局势改变”。

11. 区分终点、余波和新链
    终点状态是本链边界内最后形成的稳定或暂时稳定状态；长期余波是该终点继续产生的影响；若余波形成独立主体、目标、资源和运行机制，应标记为新链起点，不再塞入当前链。

12. 做反事实和其他解释检查
    检查移除关键条件后结果是否仍会发生，以及是否存在另一项因素同样能够解释结果。反事实只用于约束因果判断，不补写作品中没有发生的剧情。

13. 明确信息与合理归纳的边界
    原文直接说明的内容按明确事实填写；能够由连续机制总结的内容标记为“谨慎归纳”；存在其他合理解释时明确列出；无法确认的状态、动机、机制或结果写“原文未说明”。不得把传闻、角色猜测、类型惯例或单纯时间相邻改写成确定因果。

14. 合理合并、拆分和自检
    围绕同一核心问题、同一主要机制和连续状态变化的节点优先合并；更换主要主体、目标、资源或作用机制后优先拆分。链条数量由作品中实际成立的独立因果机制决定，不设机械数量要求。输出后检查：每条阶段边是否写清作用机制；是否遗漏分支、反馈、抑制或中断；阶段内容与全链摘要是否重复；正常、异常和极端状态是否区分；终点、余波和新起点是否混淆；明确内容与谨慎归纳是否区分。

## 字段说明

- 因果链名称：一句话概括主链，避免只写人物名或物品名。
- 核心因果问题：用“为什么A最终导致B”或“某种状态如何演变为另一种状态”说明本链需要解释的核心变化。
- 因果链类型与结构形态：区分内容类型和因果结构。
  - 主类型：写资源争夺链、秘境余波链、复仇链、战争链、拍卖链、逃亡链等主要类型。
  - 次类型：存在稳定次要机制时填写；没有则写“不适用”。
  - 结构形态：写线性推进、单点分叉、多线汇合、连锁扩散、正反馈、负反馈、循环或间歇复燃。
- 链条边界与长程性：说明为什么建立本链，以及哪些内容不属于本链。
  - 起始边界：写从哪个状态变化开始追踪。
  - 终止边界：写在哪个相对稳定、终止或转入新机制的状态停止。
  - 时间跨度：写链条持续时间；不明时如实填写。
  - 空间与组织范围：写涉及的地点、区域、组织或世界层级；没有变化时可写单一范围。
  - 关键参与方：写启动、推动、阻止或承受结果的主要主体。
  - 长程性依据：写多阶段传递、延迟影响、主体扩展、反馈、制度变化或长期遗留怎样成立。
  - 排除的前史：写哪些更早内容只作为初始条件。
  - 拆出的后续：写哪些余波已经具备独立成链条件。
- 初始状态与结构性条件：还原触发前的正常运行状态和长期脆弱点。
  - 主体状态：写主要人物或群体当时的能力、目标、需求和限制。
  - 关系与权力状态：写联盟、控制、依附、敌对或权力分布。
  - 资源与利益状态：写资源存量、来源、稀缺性、控制权和主要利益。
  - 规则与组织状态：写制度、惯例、禁令、承诺和组织运行方式。
  - 环境状态：写地域、交通、生态、灾害、灵气或其他外部条件。
  - 潜在矛盾与脆弱点：写尚未爆发但可能放大后续事件的结构问题。
- 触发事件与临界条件：区分长期条件和真正启动链条的变化。
  - 直接诱因：写让原有状态首次发生变化的事件或行动。
  - 行动主体：写谁主动触发、谁被动卷入。
  - 主体信息状态：写触发时掌握、误判、隐瞒或缺失的信息。
  - 临界条件：写为什么事件在此时跨过阈值，而不是更早或更晚。
  - 首个直接结果：写触发后立即形成的新状态。
- 主因果链：按“第1阶段、第2阶段……”重复填写；只保留实际存在的阶段。
  - 阶段名称：概括本阶段发生的核心变化。
  - 前置状态或事件：写本阶段开始前已经成立的状态。
  - 因果角色：填写必要条件、直接触发、促成因素、放大因素、抑制因素或替代路径。
  - 行动主体与决策：写谁采取了什么行动，以及为什么作出该选择。
  - 主体信息状态：写决策时掌握、误判、隐瞒或缺失的信息。
  - 作用机制：写前因通过什么过程改变了后续状态。
  - 传递载体：按需填写信息、资源、空间移动、关系、权力、身份、规则、情绪或环境变化。
  - 生效条件：写该机制成立所需的资源、时机、能力、制度或环境条件。
  - 阻碍与中断因素：写哪些因素延迟、减弱、改变或阻止了作用。
  - 产生的新状态或事件：写本阶段真正造成的变化。
  - 时间延迟：写前因到后果之间的等待、潜伏或累积时间；不明时如实填写。
  - 因果明确程度：填写原文明确、谨慎归纳、存在其他合理解释或仅时间相邻；仅时间相邻时不得接入主链。
  - 阶段结果：写本轮因果暂时收束后的资源、关系、身份、组织或环境状态。
- 分支、汇合与反馈：整理非线性结构；没有相应结构时写“不适用”。
  - 分支点：写哪个事件同时打开了多条路径。
  - 各分支路径：分别写每条路径的触发条件、主要过程和结果。
  - 汇合点：写哪些独立路径共同形成了同一结果。
  - 反馈类型：写正反馈、负反馈、循环报复、资源复利、恐慌扩散等。
  - 反馈过程：写结果怎样反过来强化或削弱前面的条件。
  - 主路径与次路径：说明哪条路径主导当前结果，哪些只产生辅助影响。
- 放大、抑制与中断条件：总结跨越多个阶段、持续影响全链强度的因素。
  - 放大因素：写使影响扩散、升级或加速的主体、资源、信息、制度或环境条件。
  - 抑制因素：写使影响减弱、延迟或局部化的条件。
  - 中断节点：写链条曾在哪里被阻止、暂停或改向。
  - 未发生路径：写本来可能发生但最终未发生的结果。
  - 未发生原因：写缺少什么条件、受到何种阻止或被哪条路径替代。
- 关键流转与状态变化：只做全链总览，不重复阶段细节；不相关的子项写“不适用”。
  - 信息变化：写消息的产生、隐瞒、失真、泄露、传播和公开。
  - 资源变化：写资源的发现、生产、消耗、易主、垄断、断供和毁损。
  - 空间变化：写人物、资源或冲突怎样跨地点、区域或世界层级移动。
  - 关系与权力变化：写结盟、背叛、控制、庇护、追杀、吞并、分裂和权力重组。
  - 身份、规则与制度变化：写身份公开、资格变化、规则调整、禁令、契约和制度重组。
  - 环境变化：写地形、生态、灵气、交通、人口或区域安全状态变化。
- 状态轨迹与演化阶段：按需填写链条从产生到衰减的过程，没有经历的状态写“不适用”。
  - 潜伏状态：写矛盾和条件怎样积累但尚未启动。
  - 启动状态：写触发后最初形成的变化。
  - 扩散状态：写影响怎样进入更多主体、地点或资源系统。
  - 放大状态：写反馈、势力入局或资源集中怎样推动升级。
  - 异常状态：写链条偏离常规运行后的失真、失控或局部崩坏。
  - 极端状态：写战争、毁灭、跨区域灾害等最高强度结果；未发生时写“不适用”。
  - 衰减状态：写动力怎样减弱、资源怎样耗尽或参与方怎样退出。
  - 稳定、终止或复燃：写链条最终稳定、暂时终止、彻底结束或再次启动的状态。
- 结果与影响分布：区分结果性质和影响对象。
  - 终点状态：写本链边界内最后形成的稳定或暂时稳定状态。
  - 直接结果：写主因果链直接造成的结果。
  - 间接结果：写经后续主体行动或环境变化继续传导的结果。
  - 预期结果：写行动主体试图达成的结果。
  - 意外结果：写不在主要主体计划中但实际出现的后果。
  - 受益者及收益：写谁获得资源、地位、安全、信息或其他利益。
  - 受损者及损失：写谁承担资源、关系、生命、身份或环境损失。
  - 个体影响：写能力、认知、性格、目标和生存状态变化。
  - 关系与组织影响：写联盟、权力、制度和组织运行变化。
  - 区域与环境影响：写资源格局、人口、市场、秩序和生态变化。
- 长期余波、新起点与终止方式：说明旧链如何结束以及什么仍在继续。
  - 终止或衰减原因：写目标达成、资源耗尽、外部干预、主体退出、制度吸收或其他原因。
  - 持续余波：写当前链直接留下且仍在发挥作用的影响。
  - 路径依赖：写哪些既成结果限制了后续选择，使事件难以回到初始状态。
  - 复燃条件：写哪些残留矛盾、资源或关系可能再次启动相似过程。
  - 新链起点：写哪些后续已形成新的主体、目标、资源或运行机制。
  - 拆分建议：写新链适合采用的名称和类型；没有时写“不适用”。
- 反事实检查与其他解释：用于检查因果判断是否稳固。
  - 移除关键条件：写若移除某个条件，主要结果是否仍可能发生。
  - 替代原因：写是否存在其他因素可以独立或共同解释结果。
  - 路径替代：写当前路径受阻时，是否可能通过另一条路径得到相近结果。
  - 检查结论：填写关键因果仍成立、只能视为促成因素、存在多种解释或无法判断。
- 信息边界与待确认项：统一说明全链的信息明确程度。
  - 原文明确：列出可以确定的关键状态、行动和因果连接。
  - 谨慎归纳：列出由连续机制总结但未被直接定性的内容。
  - 其他合理解释：列出不能排除的不同解释。
  - 原文未说明：列出无法确认的动机、身份、时滞、机制或结果。
  - 仅时间相邻：列出发生顺序明确但不能建立因果关系的事件。
- 可迁移因果模式：将本链抽象为可复用结构；项目不需要跨作品比较时可以省略。
  - 抽象结构：用“条件 → 触发 → 机制 → 结果 → 反馈或终止”概括。
  - 适用条件：写该模式在什么主体、资源、制度或环境条件下可能成立。
  - 失效条件：写缺少什么条件时不能套用该模式。

### 线性推进结构示例：通缉令推动跨区域逃亡

```md
- 核心因果问题：一次身份暴露为什么会持续推动当事人跨区域逃亡？
- 因果链类型与结构形态：
  - 主类型：通缉追杀链。
  - 次类型：跨区域逃亡链。
  - 结构形态：线性推进。
- 初始状态与结构性条件：
  - 主体状态：当事人依赖公开身份和固定住所活动。
  - 关系与权力状态：地方势力控制交通和身份核验。
  - 潜在矛盾与脆弱点：当事人缺乏合法庇护，身份一旦公开便难以留在原地。
- 触发事件与临界条件：
  - 直接诱因：当事人身份被公开并进入通缉名单。
  - 临界条件：通缉信息能够到达交通节点，且地方执行者愿意配合。
  - 首个直接结果：固定住所和原有交通路线失去安全性。
- 主因果链：
  - 第1阶段：身份公开 → 地方搜捕 → 原居地失去安全性。
  - 第2阶段：离开原居地 → 通缉信息沿交通网络传播 → 常规路线持续关闭。
  - 第3阶段：逃亡者改用边缘路线 → 资源与关系逐步耗尽 → 被迫进入陌生区域。
- 放大、抑制与中断条件：
  - 放大因素：统一通缉制度、悬赏和交通节点核验。
  - 抑制因素：信息延迟、地方庇护和身份伪装。
  - 中断节点：获得足以撤销通缉的身份或进入通缉权力无法覆盖的区域。
- 状态轨迹与演化阶段：正常定居 → 身份暴露 → 地方搜捕 → 跨区域传播 → 资源衰减 → 获得庇护或彻底脱离追捕范围。
- 反事实检查与其他解释：若通缉信息不能跨区域传播，身份暴露只能造成地方逃离，不能独立解释长程逃亡。
- 可迁移因果模式：身份暴露 → 制度化传播 → 活动空间连续收缩 → 被迫迁移。
```

### 分叉汇合结构示例：遗迹消息泄露引发多方争夺

```md
- 核心因果问题：一条不完整消息为什么会让多个原本独立的主体最终汇合到同一场争夺？
- 因果链类型与结构形态：
  - 主类型：秘境争夺链。
  - 次类型：情报扩散链。
  - 结构形态：单点分叉后多线汇合。
- 触发事件与临界条件：
  - 直接诱因：消息持有者将不同部分分别交给多个交易对象。
  - 主体信息状态：各方只掌握局部消息，并误以为自身拥有独占优势。
  - 临界条件：遗迹开启时间有限，各方无法等待完整核实。
- 分支、汇合与反馈：
  - 分支点：同一消息被拆分传播。
  - 各分支路径：宗门组织探索队；商会准备交易；散修根据传闻自行前往。
  - 汇合点：各方在唯一入口同时出现。
  - 反馈类型：威胁判断放大。
  - 反馈过程：竞争者出现使各方提高遗迹价值判断并追加投入，追加投入又强化其他方的威胁判断。
  - 主路径与次路径：宗门动员是主路径，市场传闻和散修聚集是次路径。
- 放大、抑制与中断条件：
  - 放大因素：资源稀缺、入口有限、消息不完整和缺少统一协调者。
  - 抑制因素：消息真实性存疑、共同外部威胁和探索成本。
  - 未发生路径：各方联合验证后按规则分配进入资格。
  - 未发生原因：时间不足且没有可信执行者。
- 可迁移因果模式：消息分叉 → 独立动员 → 空间汇合 → 竞争反馈 → 资源与关系重组。
```

### 反馈循环结构示例：资源优势形成垄断后反向暴露

```md
- 核心因果问题：稳定资源优势为什么会先形成扩张反馈，随后又因扩张本身而暴露并衰减？
- 因果链类型与结构形态：
  - 主类型：长期资源经营链。
  - 次类型：身份暴露风险链。
  - 结构形态：前期正反馈，后期负反馈。
- 初始状态与结构性条件：
  - 资源与利益状态：目标资源长期稀缺，市场愿意为稳定供给支付高价。
  - 潜在矛盾与脆弱点：供给方法必须保密，但扩大交易会产生可识别规律。
- 主因果链：
  - 第1阶段：稳定供给 → 获得利润 → 利润投入生产与渠道 → 供给继续扩大。
  - 第2阶段：供给扩大 → 市场依赖提高 → 议价权与利润继续上升。
  - 第3阶段：交易规模形成规律 → 竞争者和调查者汇总信息 → 保密成本上升并迫使减产。
- 分支、汇合与反馈：
  - 反馈类型：资源复利正反馈与暴露成本负反馈。
  - 反馈过程：利润扩大供给，供给提高利润；规模同时提高可识别性，可识别性增加调查压力，调查压力反过来压缩供给。
  - 主路径与次路径：扩产和暴露是主路径，自用、分散交易和更换渠道是调节路径。
- 状态轨迹与演化阶段：稀缺市场 → 小规模供给 → 复利扩张 → 局部垄断 → 异常暴露 → 主动收缩 → 分散经营或终止。
- 长期余波、新起点与终止方式：
  - 终止或衰减原因：暴露和调查成本超过集中经营的新增收益。
  - 路径依赖：供给者已无法恢复完全匿名，市场也不再接受单一来源依赖。
  - 新链起点：调查者围绕异常供给来源建立独立追查链。
- 反事实检查与其他解释：若市场无法汇总交易规律，资源优势仍可能扩张，但不会因规模本身形成同样的暴露负反馈。
- 可迁移因果模式：稳定稀缺供给 → 利润再投入 → 市场控制正反馈 → 规模暴露 → 调查成本负反馈 → 收缩或转型。
```
