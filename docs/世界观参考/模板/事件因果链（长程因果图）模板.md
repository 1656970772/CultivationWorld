# 事件因果链（长程因果图）模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的跨事件、跨地点、跨势力、长时间发酵的长程因果链。

本模板关注“一件事如何滚成另一件事”，重点记录起点事件、深层背景、信息传播、资源流转、地点转移、人物或势力关系变化，以及长期余波。单场战斗、单次机缘、单次修炼、单段关系变化、一次对话或一个短场景，不得硬扩展成长程因果链。

可收录的典型链条包括：资源争夺链、宝物出世链、秘境余波链、宗门战争链、正魔冲突链、通缉追杀链、复仇链、师门背叛链、邪修暴露围剿链、拍卖截杀链、跨区域逃亡链、族群战争链、飞升或跨界链、历史封印复燃链、旧债牵连链、长期资源经营链等。

## 整理原则

1. 先做长程性判定
   每条链必须同时具备较长时间跨度、多阶段推进、至少两个地点或势力层面的变化，并能说明后续事件如何被前一事件触发。
   若只是单场景、单次修炼、一次试验、一次入门测试或一次对话，只能作为大链节点，不单独成链。

2. 每部作品保持足够覆盖
   每部作品至少整理 10 条有代表性的长程因果链；不足 10 条时应明确写“本次整理未达 10 条”。
   样本应覆盖主角、配角、反派、宗门、家族、商会、妖族、魔道、凡俗国家等不同主体，不要只整理主角相关链条。

3. 合并连续小节点
   同一资源、人物或势力在连续阶段中的发现、试验、掌握、转化，应优先合并为一条链。
   例如小绿瓶从发现、吸光、试验、催熟药草、建立资源优势，应合并为“小绿瓶从异常发现到资源体系建立的长程因果链”，不要拆成砸不开、异象、野兔试验、药草催熟等多张卡。

4. 拆分过载余波
   长期余波只写当前链直接引出的后果。若余波中出现两个以上新的起点事件，或已经转入新主角、新势力、新资源、新冲突，应拆成新链。
   例如药老链中的坊市冲突、黑铁片、筑基灵液拍卖、风卷决竞价，不应全部塞进药老卡尾部；可拆成资源经营链、拍卖链或功法争夺链。

5. 阶段链必须表达因果
   每个阶段都要写清“因为什么，所以触发什么”。只写“随后发生”“后来又出现”不算因果节点。
   阶段链使用“第1阶段 / 第2阶段 / 第3阶段……”的可重复结构；每个阶段都应覆盖起点发生、消息扩散、各方反应、冲突升级、地点转移、资源流转、关系改变和阶段性结算。原文没有的环节写“原文未说明”。

6. 区分事实、归纳和未说明
   不要把原文中的模糊判断、传闻评价或旁观者猜测，升级成明确等级、确定动机、真实身份、势力结论或最终结果，除非原文明确说明。
   人物性格总结、世界残酷性、底层逻辑等只能作为长期余波中的归纳，不得替代具体因果边。

7. 结构自检
   输出后检查卡片数量是否达到要求，标题是否重复，是否存在无标题字段，是否把多个独立链条塞进一个“长期余波”，是否有单个字段过长，是否有只按时间顺序排列而缺少因果触发的节点。

8. 代表案例保留
   七玄门扩招与野狼帮压力、小绿瓶资源体系、墨大夫隐秘控制、尸虫丸控制、厉飞雨情报链、眨眼剑谱、退婚三年之约、药老从斗气异常到师徒链、萧宁成人仪式挑战、筑基灵液拍卖资源链、千丈岩解读蚀文引发卞桥冲突、周氏压迫、玄文法会入局、莫远堵门复仇等，符合长程性判定时应整理为独立或合并后的因果链。

## 字段说明

- 因果链名称：一句话概括主链，避免只写人物名或物品名。
- 因果链类型：写资源争夺链、秘境余波链、师门控制链、复仇链、战争链、拍卖链、跨区域逃亡链等；可多选，但要区分主因和次因。
- 长程性判定：写时间跨度、地点变化、参与方数量、信息/资源流转、后续影响是否成立。
- 因果强度：写强因果、中因果、弱因果或仅时间相邻；弱因果要说明不确定点。
- 起点事件：写事件在哪里发生，谁参与，谁最早知道，涉及什么资源、身份、仇怨或机会。
- 深层背景：写资源稀缺、境界瓶颈、势力旧怨、功法路线冲突、地域贫瘠、正邪对立、族群仇怨、师承背叛、寿元压力、宗门衰落、强者布局等。
- 阶段链：按“第1阶段、第2阶段、第3阶段……”展开；每个阶段固定填写起点发生、消息扩散、各方反应、冲突升级、地点转移、资源流转、关系改变和阶段性结算。
- 信息传播链：写消息如何被目击、传闻、坊市消息、宗门公告、通缉令、黑市情报、商会预告、幸存者泄露、敌人放风等方式传出去。
- 地点轨迹：写事件如何在凡俗村镇、宗门山门、坊市、洞府、秘境、战场、边境、海域、荒漠、禁地、传送阵、跨界通道等地点之间移动。
- 资源流转链：写法宝、丹药、功法、灵石、灵草、妖丹、尸体、魂魄、地图、令牌、传承、秘钥、情报、人情、职位、地盘、矿脉、商路等如何易主、暴露或被消耗。
- 关系变化链：写结怨、结盟、背叛、投靠、复仇、追杀、通缉、庇护、灭门、迁移、分裂、吞并、隐姓埋名、公开身份等变化。
- 长期余波：只写当前链直接引出的后续事件、追杀、交易、战争、迁移、性格变化、资源格局或区域局势。
- 阶段性结算：作为每个阶段的子项，写一轮因果如何暂时收束，例如宝物归属暂定、敌人退走、秘境关闭、身份暴露、关系破裂、战局重组。
- 最终结果：写链条目前达到的结果；不明时写“原文未说明”。
- 不确定项：写原文未说明的境界、身份、动机、后果、流转细节或关系变化，不用推断补齐。
- 可参考点：写这条链对长程因果、资源经营、势力入局、人物性格形成或世界局势变化的参考价值。

### 小绿瓶从异常发现到资源体系建立

- 因果链类型：长期资源经营链 / 宝物异常链 / 修炼资源转化链。
- 长程性判定：
  - 时间跨度：从发现异常到反复试验、掌握催熟效果并转化为修炼资源。
  - 地点变化：从发现地点、试验地点、药草培育地点延伸到后续修炼与资源交换场景。
  - 参与方：持有者、试验对象、后续受资源影响的人或势力。
  - 信息/资源流转：未知小瓶、绿液、药草、灵药、丹药或修炼资源发生转化。
  - 后续影响：影响持有者修炼资源、保密策略和后续交易/修炼路线。
- 因果强度：强因果。
- 起点事件：角色发现异常小瓶，并确认其非同寻常。
- 深层背景：低阶修炼资源稀缺，角色缺少稳定资源来源。
- 阶段链：
  - 第1阶段：异常发现与初步试探
    - 起点发生：小瓶异常被发现，持有者确认其非同寻常。
    - 消息扩散：信息主要停留在持有者手中，外界尚不知情。
    - 各方反应：持有者开始私下观察，并避免暴露异常来源。
    - 冲突升级：小瓶无法按普通器物理解，引发继续验证的需求。
    - 地点转移：从发现地点转入隐蔽试探地点。
    - 资源流转：未知小瓶从普通拾获物转为被重点保管的异常物。
    - 关系改变：持有者与外界形成信息差。
    - 阶段性结算：小瓶被确认为可继续试验的异常物。
  - 第2阶段：危险试验与效果确认
    - 起点发生：持有者需要确认小瓶具体效果和风险。
    - 消息扩散：试验过程被压在私下范围，外界只可能察觉异常结果。
    - 各方反应：持有者根据试验结果调整使用方式和保密方式。
    - 冲突升级：试验暴露出危险或异常收益，使小瓶价值上升。
    - 地点转移：从隐蔽试探地点转向药草试验地点。
    - 资源流转：绿液效果转化为药草年份提升的信息。
    - 关系改变：持有者对交易、师承和旁人窥探更加戒备。
    - 阶段性结算：催熟效果被确认。
  - 第3阶段：资源体系建立
    - 起点发生：可重复催熟的效果为持有者提供稳定资源入口。
    - 消息扩散：异常来源继续被隐藏，外界只接触到药草、灵药或丹药结果。
    - 各方反应：持有者围绕小瓶安排培育、修炼、交易和自保。
    - 冲突升级：资源优势可能引来怀疑、交易牵连或追夺风险。
    - 地点转移：从药草培育地点延伸到修炼、坊市和交易场景。
    - 资源流转：小瓶/绿液 -> 药草年份提升 -> 灵药/丹药/修炼资源。
    - 关系改变：持有者逐渐形成围绕资源保密、交易和自保的关系策略。
    - 阶段性结算：异常物转化为长期资源经营体系。
- 信息传播链：异常信息由持有者主动压制；外界只可能通过资源变化间接察觉。
- 地点轨迹：发现地点 -> 试验地点 -> 药草培育地点 -> 修炼或交易场景。
- 资源流转链：小瓶/绿液 -> 药草年份提升 -> 灵药/丹药/修炼资源。
- 关系变化链：从无依靠的低阶角色，逐渐形成围绕资源保密、交易和自保的关系策略。
- 长期余波：改变角色修炼资源结构，也推动后续保密、交易、追杀或资源经营链条。
- 最终结果：按原文填写。
- 不确定项：小瓶早期品阶、来源和本质未明确时写“原文未说明”。
- 可参考点：适合整理“单个异常物如何通过反复试验变成长程资源系统”。

### 退婚引发三年之约

- 因果链类型：羞辱复仇链 / 家族关系链 / 长期约战链。
- 长程性判定：
  - 时间跨度：从退婚冲突延伸到长期约定与后续修炼目标。
  - 地点变化：家族大厅、修炼地点、后续约战地点。
  - 参与方：当事人、双方家族、宗门或外部势力。
  - 信息/资源流转：婚约、名誉、家族立场和修炼目标发生变化。
  - 后续影响：推动角色修炼、复仇目标、家族关系和势力判断。
- 因果强度：强因果。
- 起点事件：一方公开提出退婚，另一方受到羞辱并立下长期约定。
- 深层背景：天赋评价、家族地位、宗门背景、婚约利益和少年尊严冲突。
- 阶段链：
  - 第1阶段：公开退婚与名誉冲突
    - 起点发生：一方在公开场合提出退婚。
    - 消息扩散：家族成员、宗门相关人物和旁观者得知冲突。
    - 各方反应：被退婚一方受到羞辱，双方家族立场出现变化。
    - 冲突升级：婚约解除不再只是私事，转为名誉和尊严冲突。
    - 地点转移：冲突集中在家族大厅或公开议事场所。
    - 资源流转：婚约、名誉、家族面子和宗门背景被卷入冲突。
    - 关系改变：原本的婚约关系破裂。
    - 阶段性结算：公开退婚完成，矛盾被推到台面。
  - 第2阶段：三年之约确立
    - 起点发生：被羞辱一方提出以期限证明自身。
    - 消息扩散：约定通过在场人物扩散为双方都无法轻易回避的承诺。
    - 各方反应：当事人确立修炼或复仇目标，旁观者重新评估其心性。
    - 冲突升级：口头羞辱转为明确期限的约战。
    - 地点转移：冲突从家族场所转向后续修炼和历练场景。
    - 资源流转：名誉压力转化为修炼动力、外部助力和资源需求。
    - 关系改变：双方从婚约对象转为长期对立或竞争者。
    - 阶段性结算：三年之约成立，短期冲突转为长期目标。
  - 第3阶段：长期修炼与势力评价变化
    - 起点发生：三年之约迫使当事人持续提升实力。
    - 消息扩散：约定和修炼进展影响家族、宗门及外部势力评价。
    - 各方反应：支持者、轻视者和敌对者围绕约战调整态度。
    - 冲突升级：个人约定逐渐牵动家族声望和宗门立场。
    - 地点转移：从修炼地点、历练区域最终指向约战地点。
    - 资源流转：修炼资源、人情、指点和名誉围绕约战聚集或消耗。
    - 关系改变：当事人完成从受辱者到挑战者的关系位置转变。
    - 阶段性结算：约战成为后续主线节点和名誉重塑的核心。
- 信息传播链：退婚事件经家族、宗门和旁观者扩散，改变各方对当事人的评价。
- 地点轨迹：家族大厅 -> 修炼地点 -> 历练区域 -> 约战地点。
- 资源流转链：婚约与名誉被消耗，修炼资源和外部助力开始围绕约战聚集。
- 关系变化链：未婚关系破裂，家族关系紧张，当事人形成长期对立。
- 长期余波：推动主角修炼路线、势力接触、后续战斗和名誉重塑。
- 最终结果：按原文填写。
- 不确定项：未说明的旁支势力反应写“原文未说明”。
- 可参考点：适合整理“公开羞辱如何转化为长期修炼目标和势力关系变化”。

### 千丈岩解读蚀文引发卞桥冲突

- 因果链类型：知识服务链 / 资源交换链 / 世家冲突链。
- 长程性判定：
  - 时间跨度：从设摊解读到资源交换、索回经诗和后续势力入局。
  - 地点变化：千丈岩、交易或调解地点、法会或山门相关场所。
  - 参与方：解读者、求解者、卞桥、周氏或相关世家人物。
  - 信息/资源流转：蚀文解读、丹药、经诗、名声和人情发生流转。
  - 后续影响：引出索回、调解、世家压力和后续法会入局。
- 因果强度：强因果。
- 起点事件：角色在千丈岩解读蚀文，以知识服务换取资源和名声。
- 深层背景：蚀文知识稀缺，世家和修士需要解读道书或道诀。
- 阶段链：
  - 第1阶段：设摊解读与名声扩散
    - 起点发生：角色在千丈岩解读蚀文，以知识服务吸引求解者。
    - 消息扩散：解读能力通过求解者、旁观者和周边修士传播。
    - 各方反应：求解者拿出资源交换，相关人物开始关注解读结果。
    - 冲突升级：解读能力从个人本事变成可被争夺或利用的稀缺服务。
    - 地点转移：事件从千丈岩设摊处扩散到周边交易和议论场景。
    - 资源流转：蚀文知识转化为丹药、经诗、名声和人情。
    - 关系改变：解读者与求解者形成交易关系。
