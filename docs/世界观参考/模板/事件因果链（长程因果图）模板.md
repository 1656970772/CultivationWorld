# 事件因果链（长程因果图）模板

## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的跨事件、跨地点、跨势力、长时间发酵的长程因果链。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

本文只整理小说中出现过，或能由小说内容明确支撑的长程事件因果链，不写总览表，不写证据段，不写项目映射表，不把单场战斗、单次机缘、单段关系变化硬扩展成长程因果。

本模板关注的是“一件事如何滚成另一件事”。如果某个事件只在一个场景内完成，重点是起因、爆发、结算和直接后果，应放入 `冲突事件分析模板.md`；如果某个事件重点是有时间窗口、参与条件、准备过程和错过后果，应放入 `动态事件与机会点模板.md`；如果重点是两个人或多个势力之间关系如何改变，应放入 `人物关系与事件分析模板.md`。

只有当事件具备较长时间跨度、多阶段传播、多地点转移、多方参与、长期余波、后续事件触发等特征时，才放入本文。文档长度不是问题，因果链一定要写全；不要为了缩短篇幅省略中间环节。原文没有说明的时间、地点、传播范围、参与者动机、后续影响、资源流向、死亡结果、势力反应等字段，统一写“原文未说明”。

每部作品至少选择 10 条有代表性的长程因果链。优先选择能体现区域局势、势力连锁反应、主角与 NPC 长期命运变化、跨地图追杀、资源流转、通缉围剿、宗门战争、秘境余波、邪修暴露、身份变化、历史旧账复燃的链条。不要只选择主角相关链条；NPC、配角、反派、宗门、家族、商会、妖族、魔道、凡俗国家之间的长程因果同样重要。

## 必须写什么

- **因果链类型**：资源争夺链、宝物出世链、秘境余波链、宗门战争链、正魔冲突链、通缉追杀链、复仇链、师门背叛链、邪修暴露围剿链、拍卖截杀链、跨区域逃亡链、族群战争链、飞升或跨界链、历史封印复燃链、旧债牵连链。
- **起点事件**：宝物出现、秘境开启、功法泄露、强者陨落、弟子叛逃、亲友被杀、身份暴露、资源短缺、战争爆发、封印松动、传承出世、黑市消息泄露、宗门任务失败、误杀或误判。
- **深层背景**：资源稀缺、境界瓶颈、势力旧怨、功法路线冲突、地域贫瘠、正邪对立、族群仇怨、师承背叛、寿元压力、宗门衰落、强者布局、凡俗王朝变化。
- **阶段形态**：预兆、起点、消息扩散、试探、准备、第一次冲突、升级、转移、追杀、势力介入、公开化、暂时结算、余波、二次触发、长期沉淀。
- **传播方式**：目击、传闻、坊市消息、宗门公告、通缉令、黑市情报、商会预告、弟子回报、灵兽或傀儡侦查、法器感应、天象异变、幸存者泄露、敌人故意放风。
- **地点轨迹**：凡俗村镇、宗门山门、坊市、洞府、秘境、战场、边境、海域、草原、荒漠、古地、禁地、传送阵、跨界通道、异族区域、黑市、拍卖场。
- **资源流转**：法宝、丹药、功法、灵石、灵草、妖丹、尸体、魂魄、地图、令牌、传承、秘钥、情报、人情、职位、地盘、矿脉、商路、灵脉、俘虏。
- **人物与势力变化**：结怨、结盟、背叛、投靠、复仇、追杀、通缉、庇护、灭门、迁移、分裂、吞并、隐姓埋名、公开身份、转修功法、进入邪道。
- **长期后果**：区域局势变化、资源价格变化、宗门实力变化、NPC 修炼路线改变、关系网重组、后续秘境或战斗触发、角色性格变化、世界状态恶化或恢复。

### 写作方式

### 案例格式

每条因果链按下面结构写。不要只写字段名，要把“为什么下一步会发生”写清楚。能写出时间跨度、地点移动、消息传播、资源转手、关系变化和势力反应时，都要写出来。

#### 案例 N：因果链名称

**因果链类型：** 写清这条链属于什么类型，可以有多个类型，但要说明主因和次因。例如资源争夺链 / 通缉追杀链 / 宗门战争链 / 秘境余波链 / 师门背叛复仇链。

**起点事件：** 写清最开始的事件是什么，发生在哪里，谁参与，谁最早知道，涉及什么资源、身份、仇怨或机会。不要只写“某人得到机缘”。

**深层背景：** 写清这件事为什么会发生。可以是资源稀缺、势力旧怨、功法需求、寿元压力、战争背景、境界瓶颈、强者布局、族群冲突、历史封印等。没有明确背景时写“原文未说明”。

**第一阶段：起点如何发生：** 写起点事件的完整发生过程。包括行动者、被影响者、资源变化、伤亡、身份暴露、信息差、误判或选择。

**第二阶段：消息如何扩散：** 写谁知道了消息，消息如何从局部扩散到更大范围，是公开公告、暗中泄露、坊市传闻、黑市情报、宗门回报，还是只有少数人知晓。传播范围不明时写“原文未说明”。

**第三阶段：各方如何反应：** 写主角、NPC、宗门、家族、商会、邪修、妖兽、凡俗势力等各方如何准备、追踪、观望、封锁、买卖情报、派人调查或隐藏身份。

**第四阶段：冲突如何升级：** 写因果链如何从小冲突变成大冲突。包括杀人夺宝、围攻、逃亡、通缉、伏击、截杀、宗门介入、战争扩大、秘境再次开启、旧敌复仇等。

**第五阶段：地点如何转移：** 写事件从哪里转到哪里。要写清地图轨迹，例如“山门 - 坊市 - 边境 - 海域 - 秘境 - 传送阵”。如果原文没有明确路线，写“原文未说明”。

**第六阶段：资源如何流转：** 写宝物、灵石、功法、丹药、妖丹、尸体、地图、令牌、传承、情报、人情等如何转手，谁获得，谁失去，谁因此暴露或被追杀。

**第七阶段：关系如何改变：** 写哪些人物或势力因这条链结怨、结盟、背叛、投靠、分裂、和解、长期追杀或转为敌对。只要原文支撑，就把关系终态写清楚。

**第八阶段：阶段性结算：** 写这条链在当前阶段如何暂时结束。包括谁死亡、谁逃走、谁得利、谁背锅、谁被通缉、谁失去资源、谁改变修炼路线。

**长期余波：** 写这条链后续又引出了什么新事件。比如新的复仇、宗门战争、拍卖截杀、黑市交易、秘境争夺、势力洗牌、区域恐慌、主角迁移、NPC 性格变化。

**波及范围：** 写波及到个人、师徒、家族、宗门、坊市、区域、族群、跨界还是凡俗王朝。不要自行扩大，没有明确波及就写“原文未说明”。

**信息传播链：** 写目击者、隐瞒者、泄露者、误传者、买卖情报者、通缉发布者、后来才知道的人。可以和第二阶段有重叠，但这里要集中说明传播链条。

**资源流转链：** 集中列清资源从谁手里到谁手里，最后停在哪里。资源去向不明写“原文未说明”。

**关系变化链：** 集中列清关键关系变化。可以写“陌生 - 交易 - 互疑 - 背叛 - 追杀”这类链式变化。

**机会点与错过点：** 写谁抓住了机会，谁错过了窗口，谁因为情报慢、准备不足、境界不够、资源不够、距离太远、误判风险而失败。

**最终结果：** 写这条因果链目前在原文中的结果。如果仍在延伸，就写“阶段性结束，后续仍在延伸”；不明则写“原文未说明”。

**可作为参考的点：** 只写世界观参考价值，例如长程因果、跨区域追杀、资源暴露风险、通缉扩散、宗门介入、地图轨迹、势力连锁反应、NPC 离线演化、月度事件摘要。

## 案例

### 案例

#### 案例 1：韩立与墨大夫、余子童的早期夺舍因果链

**因果链类型：** 师徒控制链 / 夺舍因果链 / 凡人踏入修仙路链 / 性格形成链。

**起点事件：** 韩立进入七玄门后接触墨大夫，表面上是被培养和传授医术、修炼相关内容，实质上被卷入墨大夫自身寿元、身体和夺舍目的相关的布局。余子童相关残魂、夺舍信息和修仙线索也在这一阶段影响韩立的认知。

**深层背景：** 墨大夫有身体衰败、延续自身和夺取合适身体的需求；韩立年少、出身凡俗、缺乏修仙界常识，容易被强者以师徒关系和资源控制。余子童残魂涉及修仙者夺舍与残魂求存，使韩立第一次接触修仙界残酷的一面。

**第一阶段：起点如何发生：** 韩立从凡俗少年进入七玄门，被墨大夫看中并纳入控制范围。墨大夫以师徒、医术、修炼和资源为外壳，让韩立逐渐进入自己安排的路线。韩立获得早期修炼线索，但同时失去主动选择空间。

**第二阶段：消息如何扩散：** 这一链条主要是隐秘事件，不属于公开传播。七玄门内部是否有人完整知道墨大夫真实目的，按原文填写；不明处写“原文未说明”。

**第三阶段：各方如何反应：** 韩立一开始缺少信息，只能在墨大夫安排下学习和试探；墨大夫持续隐藏目的并推进控制；余子童残魂相关信息使韩立逐步理解夺舍、修仙者和身体控制的危险。

**第四阶段：冲突如何升级：** 师徒关系从表面培养变成生死冲突。墨大夫的真实目的暴露后，韩立不再只是受教者，而是被夺取身体、被控制命运的一方。余子童残魂相关风险进一步加深韩立对修仙者手段的警惕。

**第五阶段：地点如何转移：** 主要地点在七玄门及墨大夫相关活动范围内。是否涉及更细的洞府、密室、药园、山门路径，按原文填写；不明处写“原文未说明”。

**第六阶段：资源如何流转：** 韩立得到修炼入门线索、医术经验、部分功法或修仙界认知；墨大夫试图得到韩立身体或延续自身；余子童相关信息让韩立接触夺舍和修仙残酷规则。具体物品、功法和资源名按原文填写。

**第七阶段：关系如何改变：** 韩立与墨大夫从师徒表象转为敌对生死关系；韩立与余子童从信息接触、利用和防备关系中获得修仙界经验。韩立对强者、师承、交易和陌生修士的信任边界因此发生长期变化。

**第八阶段：阶段性结算：** 墨大夫夺舍目的失败，韩立摆脱早期控制，并带着修仙线索继续向外部修仙世界移动。余子童相关威胁也使韩立对残魂、夺舍和身体控制保持警惕。

**长期余波：** 这条链塑造了韩立后续谨慎、少信任、重视保命、重视信息差、不轻易暴露底牌的行事方式。它不是一次单纯师徒冲突，而是韩立从凡俗进入修仙界残酷规则的起点链条。

**波及范围：** 主要波及韩立、墨大夫、余子童、七玄门相关人物；是否扩大到外部修仙势力，按原文填写。

**信息传播链：** 主要为隐秘信息链。墨大夫隐瞒真实目的，韩立逐步察觉，余子童残魂带来另一套修仙界信息。公开传播和外部知晓范围原文未说明。

**资源流转链：** 修炼线索、医术经验、夺舍信息和修仙界认知从墨大夫、余子童相关事件流向韩立；墨大夫试图取得韩立身体但失败。具体法器、功法、药物按原文填写。

**关系变化链：** 韩立与墨大夫：受教和被控制 - 怀疑 - 生死冲突 - 敌对终止。韩立与修仙界认知：陌生 - 接触 - 警惕 - 形成长期生存原则。

**机会点与错过点：** 韩立抓住了摆脱控制和获取修仙线索的机会；墨大夫错失夺舍或延续自身的机会；余子童相关残魂是否另有机会点，按原文填写。

**最终结果：** 阶段性结束。韩立脱离早期凡俗门派控制，获得进入修仙世界的关键认知和谨慎性格底色。

**可作为参考的点：** 适合参考“弱者被强者培养并控制”“夺舍风险如何塑造角色性格”“凡人进入修仙世界的第一条因果链”“隐秘事件如何长期影响 AI 性格、执念和信任边界”。

#### 案例 2：虚天殿开启与虚天鼎争夺因果链

**因果链类型：** 秘境余波链 / 宝物争夺链 / 多方势力入局链 / 资源流转链。

**起点事件：** 虚天殿作为高价值秘境或古修遗留场所开启，引发乱星海多方修士、势力和强者关注。虚天鼎及相关宝物、灵药、古宝、传承成为各方进入和争夺的核心动机。

**深层背景：** 乱星海修士资源竞争激烈，高阶宝物和秘境传承价值极高；强者、散修和势力都可能借虚天殿获得突破资源、法宝或地位提升。虚天鼎本身具有特殊价值，需要特定条件、手段或灵兽配合才能牵动或取得。

**第一阶段：起点如何发生：** 虚天殿开启消息或进入条件出现后，各方开始围绕名额、令牌、地图、同行者、保命手段和宝物目标做准备。韩立也因资源和机缘进入这一链条。

**第二阶段：消息如何扩散：** 虚天殿不是普通偶遇事件，消息会在特定修士圈层和势力之间传播。具体通过令牌、传闻、势力情报、坊市消息还是熟人牵线，按原文填写。

**第三阶段：各方如何反应：** 各方修士准备丹药、法宝、灵兽、破禁手段和合作对象；强者关注核心宝物；弱一些的修士则可能寻找边缘收益或依附强者。韩立需要隐藏实力、判断风险、准备保命路线。

**第四阶段：冲突如何升级：** 进入虚天殿后，资源争夺从潜在竞争变成现实冲突。各方围绕宝物、灵药、通道、禁制和虚天鼎产生争夺、试探、合作、背叛或追杀。

**第五阶段：地点如何转移：** 因果链从乱星海相关坊市、洞府或集合地点，转入虚天殿内部不同区域，再转到离开秘境后的追索和余波场景。具体地点路径按原文填写。

**第六阶段：资源如何流转：** 虚天鼎、灵药、古宝、材料、情报、令牌等资源在事件中被发现、争夺、转移或失落。血玉蜘蛛等特殊灵兽可用于牵引虚天鼎；相关特殊用途要写清楚。资源最终归属不明时写“原文未说明”。

**第七阶段：关系如何改变：** 同行者可能从临时合作转为互疑或敌对；强者与低阶修士之间形成利用、控制和追索关系；韩立因获得或接触高价值资源，可能引发后续追杀、忌惮或隐秘牵连。

**第八阶段：阶段性结算：** 虚天殿关闭或主要争夺结束后，幸存者带着不同收益离开。有人获得宝物，有人死亡，有人失去机会，也有人因为知道太多或暴露资源而进入后续风险。
