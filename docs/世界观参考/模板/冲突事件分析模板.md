# 冲突事件分析模板

## 适用范围

本模板用于整理小说中由原文明确支撑的完整冲突事件链。冲突事件指双方或多方因资源、关系、权力、规则、误判、生存压力等形成目标冲突，并出现触发、升级、结算或后续影响的事件。

整理时将冲突事件视为“基准关系—背景矛盾—导火索—力量结构—认知与动员—接触试探—升级极端化—关键转折—降级退出—结算重组—恢复遗留—复发风险”的完整冲突系统。模板不要求每场冲突机械经历全部阶段，只记录作品实际发生、能够形成连续因果关系的内容。

本文不写总览、抽象规则表，也不把单场战斗、主角爽点、阵营标签或设定说明直接改写成通用世界规则。单场战斗只有具备明确起因、参与方、结算和后续影响时，才作为冲突事件收录。

样本应尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局。不要只写主角相关事件；NPC、配角、反派、宗门成员、散修、妖兽、异族、势力首领、家族成员、失败者、旁观者和被牵连者之间的事件流，只要原文能支撑完整因果链，都应纳入候选。

## 整理原则

1. 先做冲突准入判定
   事件必须具备至少两个目标不相容的相关方、明确的背景矛盾或导火索、实际对抗推进，以及阶段性结算或后续影响，才建立冲突事件卡。纯组织架构、修炼突破、资源实验、物品发现、单纯偶遇、日常互动和设定说明不收录。

2. 区分冲突系统与单场交手
   长期战争、宗门争斗和持续追杀可以作为上层冲突卡；其中具有独立导火索、目标、参与方和结算的具体行动才单独成卡。单场交手没有独立起因和后续结果时并入上层冲突，不把同一战争的每次战斗机械拆卡。

3. 一事一卡
   同一背景矛盾、核心参与方、连续对抗目标和结算体系归入同一张卡。后文新增阶段、视角、细节、转折或余波时补入原卡；只有目标、参与方或结算规则发生实质改变并形成新的独立事件时才另建卡。

4. 区分基准关系、背景矛盾和导火索
   “基准关系与背景矛盾”写冲突前各方的关系、长期利益冲突和结构性压力；“导火索与直接触发”写使潜在矛盾在当前时点转为实际对抗的事件。资源长期稀缺属于背景，某批资源被夺才可能是导火索。

5. 记录参与方目标和力量结构
   记录主动方、被动方、盟友、受害者、旁观者和被牵连者各自想得到、避免或保护什么，以及境界、人数、资源、权限、地位、情报和依赖关系造成的力量差异。不能只用“主角、反派”代替具体目标和约束。

6. 区分冲突中的认知与冲突后的传播
   “认知、误判与信息传播”写对抗运行期间各方知道、隐瞒、误判和利用的信息；“外部反应、消息扩散与追查”写结算后消息向更大范围传播所引发的通缉、悬赏、围剿、包庇或势力关注。

7. 先写主要冲突链，再展开阶段
   每张卡先用“背景矛盾 → 导火索 → 准备与动员 → 接触与试探 → 爆发与升级 → 转折或降级 → 结算与退出 → 余波或复发”概括主要冲突链。“冲突阶段与状态变化”再逐阶段记录实际状态、选择和直接结果，不重复抄写完整叙述。

8. 记录准备、动员和初始部署
   写各方如何集结人手、资源、盟友、情报、武器、阵法、封锁和撤退路线，以及准备不足、时间压力和初始位置如何影响后续对抗。没有准备阶段时写“不适用”。

9. 区分正常、异常和极端状态
   谈判、竞争、威慑和有限试探属于低强度状态；公开战斗、追杀、封锁和资源争夺属于升级状态；规则崩溃、大规模伤亡、灭门、屠城、区域毁坏或不可逆失控属于极端状态。作品没有展示某类状态时不推演。

10. 记录关键选择、升级阈值和降级机会
    记录合作、背叛、拒绝、误判、第三方介入、资源暴露和意外变化如何跨越升级阈值，也记录让步、交换、调停、撤退、停战和止损为何成功、失败或被错过。结果已确定时不补写不存在的替代路线。

11. 记录规则、场景与环境的双向作用
    记录制度、契约、身份规则、地形、建筑、天气、灵气、阵法、交通和旁观势力如何限制各方行动，也记录封锁、破坏、战斗、逃亡和资源争夺如何反向改变场所、环境和后续冲突条件。

12. 区分代价、结算和长期重组
    “代价、损失与承受差异”写各方和被牵连者付出了什么；“结算方式与关系/资源重组”写胜负、妥协、僵局、逃脱或停战如何确定，以及资源和关系最终怎样变化；“恢复、长期影响与复发风险”写损失是否恢复、矛盾是否真正解决。

13. 区分事实、传闻和后文揭示
    人物猜测、传闻、伪装结果和阶段性误导不能直接写成既定事实。后文推翻早期认知时，分别记录当时认知和后续揭示，并修正冲突链中受影响的判断、选择和结果。

14. 只保留冲突价值并控制样本数量
    保留能体现背景矛盾、导火索、力量结构、升级、转折、结算和长期影响的事件，不长篇复述无关心理、场景和打斗细节。覆盖不同身份、势力、地域、强度、胜负和结局，但不设置固定事件数量，也不为凑数收录低价值或不完整冲突。

15. 输出前自检
    检查事件是否符合准入、是否与上层或同级冲突重复、背景矛盾与导火索是否混写、参与方目标与力量结构是否明确、主要冲突链是否闭合、阶段与主链是否重复、正常与极端状态是否混写、代价与结算是否混写、外部传播与冲突中认知是否混写，以及未知和合理推断是否得到区分。

## 字段说明

- 冲突类型：写资源冲突、关系冲突、势力冲突、规则冲突、误判冲突、生存冲突、复仇冲突或其他类型；同一事件可并列主因和次因，但不堆砌无关标签。
- 准入理由：说明事件如何形成双方或多方目标不相容、实际对抗推进及阶段性结算或后续影响，而不是普通互动或孤立战斗。
- 基准关系与背景矛盾：写冲突前各方的合作、中立、依附、竞争或敌对关系，以及长期存在的资源、权力、身份、规则、生存或历史矛盾。
- 导火索与直接触发：写资源暴露、命令下达、规则违反、误判、背叛、袭击、拒绝或环境变化等使冲突实际开始的直接事件。
- 参与方、目标与力量结构：写主动方、被动方、盟友、受害者、旁观者和被牵连者的目标、利益、能力、人数、资源、权限、地位、依赖关系和力量差异。
- 规则、场景与环境条件：写制度、契约、身份规则、地点、地形、建筑、天气、灵气、阵法、交通、时间限制和旁观势力对冲突的约束。
- 认知、误判与信息传播：写冲突中各方明确知道、部分知道、隐瞒、误判或被误导的内容，以及信息如何影响试探、动员、升级和撤退。
- 准备、动员与初始部署：写各方集结的人手、资源、盟友、武器、情报、阵法、封锁和退路，以及准备时间和初始位置。
- 主要冲突链：按“背景矛盾 → 导火索 → 准备与动员 → 接触与试探 → 爆发与升级 → 转折或降级 → 结算与退出 → 余波或复发”用一句话概括主链。
- 冲突阶段与状态变化：按矛盾累积/预兆、接触与试探、动员与对抗、爆发与升级、转折与降级、结算与退出、余波与复发记录各阶段的状态、关键行动和直接结果。
- 关键选择、升级阈值与降级机会：写导致合作、背叛、升级、极端化、让步、调停、撤退、停战或错过止损机会的选择、条件和结果。
- 外在表现与环境反馈：写威慑、封锁、动员、追杀、战斗、破坏、逃亡、伤亡和聚落秩序等可感知表现，以及冲突对场所、生态、交通、资源和后续环境条件的反向影响。
- 代价、损失与承受差异：写各方及被牵连者在人员、伤势、资源、时间、身份、声望、领地、关系和机会上的损失，并说明承受差异。
- 结算方式与关系/资源重组：写胜负、妥协、僵局、逃脱、停战或暂时中断如何确定，结算是否得到执行，以及资源归属、身份、债务、联盟和仇怨如何变化。
- 外部反应、消息扩散与追查：写结算后消息如何传播，以及通缉、悬赏、追杀、围剿、包庇、调停、势力关注和其他第三方反应；无公开传播时写“无公开传播”。
- 恢复、长期影响与复发风险：写人员、关系、资源、场所和势力是否恢复，留下何种永久影响，背景矛盾是否解决，以及再次冲突的条件和风险。
- 信息边界与不确定项：写人物判断、传闻、伪装、合理推断、不同阶段说法之间的冲突，以及触发、力量、损失、结算、传播、恢复和复发等重要未知项。

### 韩明夺取风雷翅

- 冲突类型：资源冲突 / 个人冲突 / 控制与逃亡。主因是韩明夺取八阶妖兽伴生草，次因是风希控制并利用韩明炼制风雷翅。
- 准入理由：韩明与风希围绕伴生草、人身控制和风雷翅形成目标冲突，事件经历偷取暴露、抓捕控制、利用破绽、携宝逃走和资源关系重组。
- 基准关系与背景矛盾：韩明与风希一方此前没有明确合作关系；韩明需要八阶妖兽伴生草，风希一方控制伴生草及相关高阶资源，双方在资源取得和人身安全上存在力量不对称。
- 导火索与直接触发：韩明偷取风希子嗣的伴生草后行迹暴露，被风希发现并抓住；资源盗取使潜在风险转为直接控制冲突。
- 参与方、目标与力量结构：韩明的目标先是取得伴生草，受控后转为解除禁制并逃生；风希的目标是控制韩明并利用其打造风雷翅；风希子嗣是伴生草被偷的直接受害对象。风希掌握抓捕和下禁制的力量优势，韩明依赖隐瞒资源和寻找破绽反制。
- 规则、场景与环境条件：事件发生在八阶妖兽相关高风险资源场景中；风希以禁制约束韩明，并掌握人身和炼器过程的主动权。具体地形、时间限制和其他环境规则原文未说明。
- 认知、误判与信息传播：风希知道韩明偷取伴生草并可被用于炼制风雷翅，但对韩明灵液的实际作用缺乏完整认知；韩明知道自身受控并寻找脱身条件。事件是否向外传播原文未说明。
- 准备、动员与初始部署：韩明为取得伴生草接近风希子嗣相关资源；被捕后没有外部援军，主要依靠自身携带的灵液和临场判断寻找机会。风希通过抓捕、禁制和炼器安排建立控制。
- 主要冲突链：韩明需要伴生草 → 偷取资源后暴露 → 被风希抓住并下禁制 → 风希利用韩明炼制风雷翅 → 风希饮下灵液后身体发作 → 控制出现破绽 → 韩明携风雷翅逃走 → 双方留下资源损失与仇怨。
- 冲突阶段与状态变化：
  - 矛盾累积/预兆：韩明需要八阶妖兽伴生草，并接近风希子嗣控制的资源。
  - 接触与试探：韩明偷取伴生草后暴露，风希发现并抓住韩明。
  - 动员与对抗：风希没有立即杀死韩明，而是给韩明下禁制并要求其参与炼制风雷翅；韩明在受控状态下寻找脱身机会。
  - 爆发与升级：风希被韩明的灵液吸引并饮下，随后身体发作，原有控制关系出现破绽。
  - 转折与降级：韩明利用风希身体发作的时机摆脱控制，冲突由受控炼器转为逃亡。
  - 结算与退出：韩明成功逃走并带走风雷翅；风希失去对韩明和风雷翅的控制。
  - 余波与复发：风雷翅成为韩明后续移动、逃生和战斗资源；风希一方是否继续追索以及冲突是否复发原文未说明。
- 关键选择、升级阈值与降级机会：风希选择保留韩明并下禁制，而不是立即杀死，使冲突进入控制利用阶段；风希饮用灵液使控制链跨过转折点。双方没有形成谈判、交换或停战，韩明以逃走结束当前对抗。
- 外在表现与环境反馈：抓捕、禁制、受控炼器、灵液发作和携宝逃亡构成主要外在表现；事件是否造成场所破坏、妖兽反应、交通封锁或长期环境变化原文未说明。
- 代价、损失与承受差异：韩明承担偷取失败、被捕、禁制控制和逃亡风险；风希饮下灵液后身体发作并失去风雷翅及控制对象；风希子嗣失去伴生草。具体伤势、时间和其他资源损耗原文未说明。
- 结算方式与关系/资源重组：事件以韩明逃脱、风希控制失败告一段落。韩明获得风雷翅并摆脱禁制控制，风希失去相关成果，伴生草、灵液和风雷翅在事件中发生转移或暴露，双方关系转为仇怨。
- 外部反应、消息扩散与追查：无明确公开传播；是否形成通缉、悬赏、势力追杀或更广范围的消息扩散原文未说明。
- 恢复、长期影响与复发风险：风雷翅持续改变韩明的移动、逃生和战斗能力；风希身体是否恢复、是否继续追索韩明、禁制是否留下长期影响以及双方是否再次冲突原文未说明。
- 信息边界与不确定项：双方此前关系、事件具体地点和时间、灵液作用机制、风希伤势、禁制解除过程、公开传播、后续追索和冲突复发原文未说明。
