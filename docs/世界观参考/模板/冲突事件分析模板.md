# 冲突事件分析模板

## 适用范围

本模板用于整理小说中由原文明确支撑的完整冲突事件链。冲突事件指双方或多方因资源、关系、权力、规则、误判、生存压力等形成目标冲突，并出现触发、升级、结算或后续影响的事件。

本文不写总览、抽象规则表，也不把单场战斗、主角爽点、阵营标签或设定说明直接改写成通用世界规则。单场战斗只有具备明确起因、参与方、结算和后续影响时，才作为冲突事件收录。

样本应尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局。不要只写主角相关事件；NPC、配角、反派、宗门成员、散修、妖兽、异族、势力首领、家族成员、失败者、旁观者和被牵连者之间的事件流，只要原文能支撑完整因果链，都应纳入候选。

## 整理原则

1. 先做冲突准入判定  
   事件必须具备明确触发原因、至少两个利益或目标相关方、冲突推进、阶段结算或后续影响，才可建立冲突事件卡。  
   纯组织架构、修炼突破、资源实验、物品发现、单纯偶遇、日常互动、单纯设定说明，不作为冲突事件卡。

2. 一事一卡  
   同一触发原因、同一核心参与方、同一结算结果的事件必须合并到同一张卡。  
   禁止因视角变化、标题变化、局部细节、阶段推进另建“某事件（补充）”“某事件后续”等新卡。阶段性发展写入同卡的“因果阶段”或“整个流程”。

3. 字段完整  
   每张卡必须包含：冲突类型、触发原因、参与者与旁观者、因果阶段、关系与资源变化、消息传播与通缉后果、整个流程、后续影响。  
   无依据时写“原文未说明”；无公开传播时写“无公开传播”；禁止空字段。

4. 区分事实、传闻和后文揭示  
   人物猜测、传闻、伪装结果和阶段性误导，不能直接写成既定事实。  
   如果后文推翻早期认知，应写成“当时看似……，后文揭示……”，并据此修正事件链。

5. 只保留冲突价值  
   保留能体现起因、升级、结算、关系变化、资源转移、势力反应或后续影响的事件。  
   不长篇复述原文，不展开与冲突机制无关的心理描写、场景描写和打斗细节。

6. 限制低价值和不适宜内容  
   不收录纯情感暧昧、身体凝视、性化羞辱、滑稽桥段或单纯尴尬互动。  
   若这些内容确实引发后续外部冲突，只记录冲突触发、参与方选择和后果，不展开相关描写。

7. 保持样本覆盖  
   每部作品至少整理 20 个有代表性的完整事件链；若原文可支撑的完整事件不足 20 个，应明确写出“原文未说明更多完整事件链”。  
   样本应包含不同身份、不同势力、不同胜败结果和不同传播后果，避免只记录主角胜利或少数名场面。

## 字段说明

- 冲突类型：写清事件属于资源冲突、关系冲突、势力冲突、规则冲突、误判冲突、生存冲突、复仇冲突或其他类型；同一事件可有多个类型，但要说明主因和次因。
- 触发原因：写清具体压力、资源暴露、误判、命令、关系裂缝、规则限制或环境变化，说明冲突为什么开始。
- 参与者与旁观者：写明主动方、被动方、受害者、旁观势力、信息传递者和被牵连者；没有明确内容时写“原文未说明”。
- 因果阶段：按预兆、信息扩散、试探与控制、爆发与升级、结算与撤退、余波等阶段梳理事件推进；某阶段不存在或不明确时写“原文未说明”。
- 关系与资源变化：写清谁获得、失去、欠债、结盟、结仇、转投势力，或出现资源转移、身份变化、关系断裂。
- 消息传播与通缉后果：写传闻、追杀、悬赏、封锁、隐秘牵连、势力关注等后果；无公开传播写“无公开传播”，不明时写“原文未说明”。
- 整个流程：按原文顺序简洁写完整流程，重点说明每一步为什么引出下一步。
- 后续影响：写该事件对人物、势力、资源线、关系链和后续剧情选择的影响；没有明显影响写“原文未说明明显影响”。

```md
# 《作品名》冲突事件分析

## 冲突事件卡片

### 事件名称

- 冲突类型：
- 触发原因：
- 参与者与旁观者：
- 因果阶段：
  - 预兆：
  - 信息扩散：
  - 试探与控制：
  - 爆发与升级：
  - 结算与撤退：
  - 余波：
- 关系与资源变化：
- 消息传播与通缉后果：
- 整个流程：
- 后续影响：

### 韩明夺取风雷翅

- 冲突类型：资源冲突 / 个人冲突 / 逃亡追杀。主因是韩明为获取八阶妖兽伴生草进入风险场景，次因是风希想借韩明炼制风雷翅并控制韩明。
- 触发原因：韩明为获取八阶妖兽伴生草，偷取风希子嗣的伴生草，由此暴露并被风希抓住；风希发现韩明可用于打造风雷翅后，转为控制和利用韩明。
- 参与者与旁观者：韩明是被捕后寻找脱身机会的一方；风希是主动控制、利用并追索资源的一方；风希子嗣是伴生草被偷的直接受害对象；其他旁观者或信息传递者原文未说明。
- 因果阶段：
  - 预兆：韩明需要八阶妖兽伴生草，并因此接近风希子嗣相关资源。
  - 信息扩散：韩明偷取伴生草后行迹暴露，被风希发现并抓住。
  - 试探与控制：风希没有立即杀死韩明，而是想借韩明打造风雷翅，并给韩明下禁制。
  - 爆发与升级：风希被韩明的灵液吸引，喝下后身体发作，控制链出现破绽。
  - 结算与撤退：韩明趁机逃走，并带走风雷翅。
  - 余波：风雷翅成为韩明后续重要机缘与逃生资源；风希一方与韩明形成追索和仇怨关系。
- 关系与资源变化：韩明获得风雷翅并摆脱禁制控制；风希失去风雷翅相关成果并与韩明结怨；伴生草、灵液、风雷翅等资源在事件中发生转移或暴露。
- 消息传播与通缉后果：原文未说明是否形成公开通缉、悬赏、势力追杀或更广泛消息传播。
- 整个流程：韩明为获取八阶妖兽伴生草接近风希子嗣，偷取伴生草后暴露并被风希抓住；风希想借韩明打造风雷翅，于是下禁制控制韩明；风希饮下韩明灵液后身体发作，控制出现破绽；韩明趁机逃走，并带走风雷翅。
- 后续影响：风雷翅改变韩明后续移动、逃生和战斗能力；该事件形成“资源夺取 - 被强者控制 - 利用破绽反制 - 带宝逃亡”的完整冲突链。
```
