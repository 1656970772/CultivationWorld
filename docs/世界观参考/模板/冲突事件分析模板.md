# 冲突事件分析模板

# 规范

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的完整冲突事件链，不写总览，不写抽象规则表，也不把单场战斗、主角爽点或阵营标签直接改写成通用世界规则。

每部作品至少挑选 20 个有代表性的完整事件链。优先选择能体现“起因、升级、结算、后续影响”的事件，例如资源争夺、杀人夺宝、秘境冲突、宗门战争、正邪冲突、复仇、内部斗争、通缉追杀、误判引发的冲突、偶遇后长期牵连的关系事件等。

事件类型要尽量全面，不要全部选择主角相关事件。NPC、配角、反派、宗门成员、散修、妖兽、势力首领、家族成员之间的事件流也非常重要；只要原文能支撑完整因果链，都应纳入候选。

每个事件案例都按固定字段写清：冲突类型、触发原因、参与者与旁观者、因果阶段、关系与资源变化、消息传播与通缉后果、整个流程、后续影响。没有可靠原文依据的字段写“原文未说明”；不得为了补齐冲突类型、因果阶段、传播链或后续影响而自行虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。下列条目统一按“项目：参考内容的摘要”整理；原文未说明写“原文未说明”。

- 冲突类型：写清事件属于资源冲突、关系冲突、势力冲突、误判冲突或其他类型；同一事件可有多个类型，但要说明主因和次因。
- 触发原因：写清具体压力、资源暴露、误判、命令、关系裂缝或环境变化，说明冲突为什么开始。
- 参与者与旁观者：写明主动方、被动方、受害者、旁观势力、信息传递者和被牵连者；没有明确内容时写“原文未说明”。
- 因果阶段：按预兆、信息扩散、试探与控制、爆发与升级、结算与撤退、余波等阶段梳理事件推进。
- 关系与资源变化：写清谁获得、失去、欠债、结盟、结仇、转投势力，或出现资源转移和关系断裂。
- 消息传播与通缉后果：写传闻、追杀、悬赏、封锁、隐秘牵连等后果；不明时写“原文未说明”。
- 整个流程：按原文顺序写完整流程，不省略“为什么发生下一步”。
- 后续影响：写对人物、势力、资源线和后续剧情链的影响。

### 案例

```md
# 《作品名》冲突事件分析

## 冲突事件卡片

### 事件名称

- 冲突类型：
- 触发原因：
- 参与者与旁观者：
- 因果阶段：
  - 预兆：
  - 信息扩散：
  - 试探与控制：
  - 爆发与升级：
  - 结算与撤退：
  - 余波：
- 关系与资源变化：
- 消息传播与通缉后果：
- 整个流程：
- 后续影响：

### 韩立夺取风雷翅

- 冲突类型：资源冲突 / 个人冲突 / 逃亡追杀。主因是韩立为获取八阶妖兽伴生草而进入风险场景，次因是风希想借韩立炼制风雷翅并控制韩立。
- 触发原因：韩立为了获取八阶妖兽伴生草，偷取风希子嗣的伴生草，由此暴露并被风希抓住；风希发现韩立可用于打造风雷翅后，转为控制和利用韩立。
- 参与者与旁观者：韩立是被捕后寻找脱身机会的一方；风希是主动控制、利用并追索资源的一方；风希子嗣是伴生草被偷的直接受害对象；其他旁观者或信息传递者按原文填写，不明时写“原文未说明”。
- 因果阶段：
  - 预兆：韩立需要八阶妖兽伴生草，并因此接近风希子嗣相关资源。
  - 信息扩散：韩立偷取伴生草后行迹暴露，被风希发现并抓住。
  - 试探与控制：风希没有立即杀死韩立，而是想借韩立打造风雷翅，并给韩立下禁制。
  - 爆发与升级：风希被韩立的灵液吸引，喝下后身体发作，控制链出现破绽。
  - 结算与撤退：韩立趁机逃走，并带走风雷翅。
  - 余波：风雷翅成为韩立后续重要机缘与逃生资源；风希一方与韩立形成追索和仇怨关系。
- 关系与资源变化：韩立获得风雷翅并摆脱禁制控制；风希失去风雷翅相关成果并与韩立结怨；伴生草、灵液、风雷翅等资源在事件中发生转移或暴露。
- 消息传播与通缉后果：事件是否形成公开通缉、悬赏、势力追杀或更广泛消息传播，按原文填写；不明时写“原文未说明”。
- 整个流程：韩立为了获取八阶妖兽伴生草，偷取风希子嗣的伴生草，被风希抓住；风希想借韩立打造风雷翅，于是给韩立下禁制并控制韩立；风希被韩立的灵液吸引，喝下后身体发作；韩立趁机逃走，并带走风雷翅。
- 后续影响：风雷翅改变韩立后续移动、逃生和战斗能力；该事件形成“资源夺取 - 被强者控制 - 利用破绽反制 - 带宝逃亡”的典型冲突链，可作为杀人夺宝、怀璧其罪、强者控制弱者、反制逃亡类事件参考。

### 韩立遇到元瑶

- 冲突类型：按原文填写，如个人关系事件 / 秘境冲突 / 资源冲突 / 逃亡协作；同一链条可有多个类型，但要说明主因和次因。
- 触发原因：写清韩立与元瑶相遇的具体场景、机会窗口、资源压力、危险因素或误判原因；不能只写“偶遇”。
- 参与者与旁观者：写明韩立、元瑶、相关同伴、敌对方、旁观势力、信息传递者和后来被牵连的人；不明时写“原文未说明”。
- 因果阶段：
  - 预兆：写相遇前双方各自处境。
  - 信息扩散：写双方如何知道彼此、危险或机会；无公开传播则写“原文未说明”。
  - 试探与控制：写初见、合作、怀疑、交易或冲突。
  - 爆发与升级：写真正推动事件升级的危机、敌人、资源或选择。
  - 结算与撤退：写事件如何暂时结束，谁得到什么，谁失去什么。
  - 余波：写二人关系、后续再见、资源线索、情感牵连或长期影响。
- 关系与资源变化：写清关系变化、互信程度、救助或亏欠、资源获得/损失、敌对关系变化；没有可靠依据时写“原文未说明”。
- 消息传播与通缉后果：写该事件是否造成传闻、追杀、通缉、势力关注或隐秘牵连；不明时写“原文未说明”。
- 整个流程：按原文顺序写完整流程，不省略“为什么发生下一步”。
- 后续影响：写该事件如何影响韩立、元瑶及相关势力的后续选择、关系、资源和剧情链。

### 韩立与墨大夫

- 冲突类型：个人冲突 / 师徒控制 / 生存压力 / 夺舍或身体占有相关冲突；主因和次因按原文填写。
- 触发原因：写清墨大夫为何接近、培养或控制韩立，韩立为何进入该关系，以及双方目标如何逐渐冲突。
- 参与者与旁观者：写明韩立、墨大夫、七玄门相关人物、可能牵连者和信息传递者；不明时写“原文未说明”。
- 因果阶段：
  - 预兆：韩立进入七玄门或相关环境，接触墨大夫。
  - 信息扩散：韩立逐步发现风险，墨大夫隐藏真实目的。
  - 试探与控制：墨大夫以医术、修炼、师徒关系或利益安排影响韩立。
  - 爆发与升级：双方围绕身体、功法、控制权或生死产生正面冲突。
  - 结算与撤退：写明墨大夫结局、韩立获得或失去的资源、关系断裂方式。
  - 余波：写该事件如何塑造韩立的谨慎、信任边界、修炼资源和后续生存方式。
- 关系与资源变化：写清师徒关系如何转为敌对，韩立获得或失去哪些资源、功法、经验、身份保护或风险。
- 消息传播与通缉后果：写该事件是否被七玄门或外部势力知晓，是否引发追查、通缉或隐秘后果；不明时写“原文未说明”。
- 整个流程：按原文顺序写完整流程，不省略墨大夫布局、韩立察觉、双方冲突、最终结算和后续影响。
- 后续影响：该事件是韩立早期生存观、信任观和修炼道路的重要因果源，应写清它如何影响后续谨慎行事、资源使用和对强者控制的警惕。
```
