# 冲突事件分析模板

## 适用范围

用于整理小说中出现过，或能由资料来源明确支撑的完整冲突事件链。

本模板不写总览、证据段、抽象规则表，也不把单场战斗、主角爽点或阵营标签直接改写成通用世界规则。

## 前置声明

- 样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、名场面或成功案例。
- 案例只是最低写法示范，不是数量上限；原文有价值内容可以继续展开。
- 原文没有说明的境界、身份、地点、资源、关系、结果、传播方式或后续影响，写“原文未说明”。
- 信息不足但值得追踪的事件放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

每部作品至少挑选 20 个有代表性的完整事件链。优先选择能体现“起因、升级、结算、后续影响”的事件；不要只选主角相关事件。

| 类型 | 示例 | 重点 |
|------|------|------|
| 资源冲突 | 杀人夺宝、秘境争夺、矿脉争夺 | 写清资源如何暴露、转移和引发追索。 |
| 关系冲突 | 师徒控制、家族内斗、背叛复仇 | 写清信任如何建立、破裂和清算。 |
| 势力冲突 | 宗门战争、正邪冲突、通缉追杀 | 写清组织动员、消息传播和利益变化。 |
| 误判冲突 | 偶遇、误传、身份暴露、误入禁地 | 写清信息差如何推动下一步。 |

正式案例应优先覆盖以下核心字段；原文未说明写“原文未说明”，原文有其他相关内容可继续补充：

- **冲突类型**：可有多个类型，但要说明主因和次因。
- **触发原因**：写清具体压力、资源、误判、命令或关系裂缝。
- **参与者与旁观者**：写明主动方、被动方、受害者、旁观势力、情报来源和被牵连者。
- **因果阶段**：预兆、信息扩散、试探与控制、爆发与升级、结算与撤退、余波。
- **关系与资源变化**：写谁获得、失去、欠债、结盟、结仇或转投势力。
- **消息传播与通缉后果**：写传闻、追杀、悬赏、封锁、隐秘牵连；不明时写“原文未说明”。
- **整个流程**：按原文顺序写完整流程，不省略“为什么发生下一步”。
- **后续影响**：写对人物、势力、资源线和后续剧情链的影响。

## 案例

### 案例

#### 事件 1：韩立夺取风雷翅

**冲突类型：** 资源冲突 / 个人冲突 / 逃亡追杀。主因是韩立为获取八阶妖兽伴生草进入风险场景，次因是风希想借韩立炼制风雷翅并控制韩立。

**触发原因：** 韩立偷取风希子嗣的伴生草后暴露并被抓；风希发现韩立可用于打造风雷翅，转为控制和利用。

**参与者与旁观者：** 韩立、风希、风希子嗣；其他旁观者或传播者按原文填写，不明时写“原文未说明”。

**因果阶段：**

1. 预兆：韩立需要八阶妖兽伴生草。
2. 信息扩散：偷取伴生草后行迹暴露，被风希发现。
3. 试探与控制：风希想借韩立打造风雷翅，并下禁制。
4. 爆发与反制：风希喝下韩立灵液后身体发作，控制链出现破绽。
5. 结算与逃亡：韩立趁机逃走，并带走风雷翅。
6. 余波：风雷翅成为后续逃生资源，双方形成追索和仇怨。

**关系与资源变化：** 韩立获得风雷翅并摆脱控制；风希失去成果并与韩立结怨。

**消息传播与通缉后果：** 按原文填写；不明时写“原文未说明”。

**整个流程：** 按原文顺序写清偷取、暴露、被控、反制、带宝逃亡。

**后续影响：** 写风雷翅如何影响后续移动、逃生、战斗能力，以及该链条对“资源夺取 - 强者控制 - 反制逃亡”的参考价值。

#### 事件 2：韩立遇到元瑶

**冲突类型：** 个人关系事件 / 秘境冲突 / 资源冲突 / 逃亡协作，按原文确定主因和次因。

**因果阶段：**

1. 预兆：写相遇前双方各自处境。
2. 信息扩散：写双方如何知道彼此、危险或机会；无公开传播则写“原文未说明”。
3. 试探与接触：写初见、合作、怀疑、交易或冲突。
4. 爆发与升级：写真正推动事件升级的危机、敌人、资源或选择。
5. 结算与撤退：写事件如何暂时结束，谁得到什么，谁失去什么。
6. 余波：写关系、后续再见、资源线索、情感牵连或长期影响。

**补充字段：** 触发原因、参与者与旁观者、关系与资源变化、消息传播与通缉后果、整个流程、后续影响，按通用字段填写。

#### 事件 3：韩立与墨大夫

**冲突类型：** 个人冲突 / 师徒控制 / 生存压力 / 身体占有相关冲突，按原文确定主因和次因。

**因果阶段：**

1. 预兆：韩立进入七玄门或相关环境，接触墨大夫。
2. 控制与培养：墨大夫以医术、修炼、师徒关系或利益安排影响韩立。
3. 信息不对称：韩立逐步发现风险，墨大夫隐藏真实目的。
4. 爆发与反制：双方围绕身体、功法、控制权或生死产生正面冲突。
5. 结算：写明墨大夫结局，以及韩立获得或失去的资源。
6. 余波：写该事件如何塑造韩立的谨慎、信任边界和生存方式。

**补充字段：** 触发原因、参与者与旁观者、关系与资源变化、消息传播与通缉后果、整个流程、后续影响，按通用字段填写。
