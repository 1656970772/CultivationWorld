# 角色AI行为参考模板

## 适用范围

用于整理作品中角色行为模式、行为决策链，以及可供项目 AI 行为设计参考的决策依据。

## 前置声明

- 覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角或成功案例。
- 只写原文、资料来源或可靠依据能支撑的行为决策链。缺失字段写“原文未说明”，不得把主角策略套成所有 NPC 默认行为。
- 案例只是最低写法示范，不是数量上限；有价值的行为模式、决策节点和失败样本都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充来源，成熟后转为 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

本文只整理角色行为决策链。不写总览、证据段、抽象规则表，也不单独拆“行为原型、Utility、GOAP、Job/Toil、项目映射”等表格字段。

每个案例按原文先后顺序写清：角色当时知道什么、处于什么状态、想达成什么目标、有哪些正面因素、有哪些反面因素、最后选择什么行动、什么条件下打断或撤退、成功或失败后目标如何变化。

每个决策节点都要写“正面因素 / 反面因素”。因素内容要短，不硬补没有依据的动机。

| 类型 | 示例 | 重点 |
|------|------|------|
| 行为原型 | 谨慎求生、赌命夺宝、宗门忠诚、权力争夺、复仇追杀、护短报恩、避祸隐忍 | 只作为归纳标签，不替代原文决策链。 |
| 已知信息 | 目击、传闻、公告、情报买卖、敌人境界、宝物价值、事件窗口、退路 | 写角色当时确实知道什么。 |
| 自身状态 | 境界、伤势、法力/斗气、神识、保命物、丹药、法宝、队伍、身份暴露 | 写状态如何影响选择。 |
| 资源收益 | 宝物、丹药、功法、材料、灵石、贡献、传承、突破资源、情报、人情、职位、声望 | 写行动为什么值得冒险。 |
| 风险压力 | 强敌、围杀、追杀、时间不足、资源暴露、背叛、惩罚、寿元压力、伤势恶化 | 写行动为什么可能失败或需要撤退。 |
| 关系因素 | 师徒、同门、道侣、恩人、仇人、宗门命令、家族牵连、报恩、复仇、背叛 | 写关系如何改变收益和风险判断。 |
| 行动选择 | 打探、准备、购买、组队、赶路、隐藏、参与、观望、偷袭、战斗、撤退、求援、改目标 | 写最终选择和理由。 |
| 打断条件 | 濒死、强敌出现、保命物耗尽、资源已失、同伴遇险、窗口关闭、身份暴露、收益低于风险 | 写节点何时中止或转向。 |

## 案例

### 案例

#### 通用决策节点

**行为决策链：**

1. 写触发信息：角色听到、看到或收到什么消息，目标是什么。
2. 写正面因素：收益、信息、资源、队友、退路、宗门支持、关系驱动等。
3. 写反面因素：强敌、伤势、信息不明、资源不足、时间不够、身份暴露、关系牵连等。
4. 写行动选择：打探、准备、组队、参与、观望、偷袭、战斗、撤退、求援、放弃或改目标。
5. 写打断条件：濒死、保命物耗尽、关键资源已失、同伴遇险、事件窗口关闭、收益低于风险等。
6. 写结果变化：成功后如何消化收益，失败后如何疗伤、逃亡、记仇或换目标。

#### 分类型示例

| 类型 | 决策链重点 |
|------|------------|
| 谨慎求生型参与秘境 | 先打探，再准备，进入后避开核心风险，收益到手后撤离。 |
| 赌命夺宝型抢夺宝物 | 因瓶颈或资源压力冒险，强化短期战力，潜伏捡漏，得手后逃亡。 |
| 宗门忠诚型执行救援 | 因命令或同门关系响应，评估敌情，优先救援撤离，事后疗伤和补给。 |
