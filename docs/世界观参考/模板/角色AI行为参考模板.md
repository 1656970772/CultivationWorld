# 角色 AI 行为参考模板

## 适用范围

用于整理作品中角色行为模式、行为决策链，以及角色行为模式到项目 AI 架构的参考映射。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

本文只整理小说中出现过，或能由小说内容明确支撑的角色行为决策链，不写总览，不写证据段，不写抽象规则表，不单独拆“行为原型、Utility、GOAP、Job/Toil、项目映射”等表格字段。

每个案例只写行为决策链。行为决策链要按原文先后顺序写清角色每次为什么做某个选择：当时知道什么、处于什么状态、想达成什么目标、有哪些正面因素、有哪些反面因素、最后选择了什么行动、什么条件下会打断或撤退、成功或失败后目标如何变化。

每个决策节点都要写“正面因素 / 反面因素”。因素种类要写清楚，因素内容要简洁，不要写成长篇分析。没有明确依据的因素不要硬补；不要把主角的完美策略当成所有 NPC 的默认行为。

- **行为原型**：谨慎求生型、赌命夺宝型、宗门忠诚型、权力争夺型、复仇追杀型、传承护徒型、邪修掠夺型、商人套利型、散修游击型、护短报恩型、避祸隐忍型。
- **已知信息因素**：目击、传闻、宗门公告、情报买卖、同伴提醒、敌人境界、宝物价值、事件窗口、敌我位置、退路是否明确。
- **自身状态因素**：境界、伤势、法力/斗气余量、神识状态、保命物、丹药、法宝、队伍人数、身份是否暴露、是否被通缉。
- **资源收益因素**：宝物、丹药、功法、材料、灵石、贡献、传承、突破资源、情报、人情、职位、声望。
- **风险压力因素**：强敌、围杀、追杀、时间不足、事件过期、资源暴露、队友背叛、宗门惩罚、寿元压力、伤势恶化。
- **关系因素**：师徒、同门、道侣、恩人、仇人、宗门命令、家族牵连、护短、报恩、复仇、背叛。
- **正面因素类别**：收益高、风险可控、信息可靠、资源充足、有队友、有退路、有宗门支持、时机合适、关系驱动强。
- **反面因素类别**：境界不足、伤势重、信息不明、资源不足、敌人过强、时间不够、退路不稳、身份暴露、关系牵连大。
- **行动选择**：打探、准备、购买、组队、赶路、隐藏身份、参与、观望、偷袭、正面战斗、撤退、求援、放弃目标、改目标、闭关消化、记仇追杀。
- **打断条件**：濒死、强敌出现、保命物耗尽、关键资源已失、同伴遇险、事件窗口关闭、身份暴露、收益低于风险、宗门急召。

## 案例

### 案例

#### 案例 1：谨慎求生型参与秘境

**行为决策链：**

1. 角色听到秘境即将开启的消息，目标是获得突破资源。正面因素：收益高、时间窗口明确、已有部分情报。反面因素：自身境界偏低、敌人数量不明、死亡风险高。角色没有立刻出发，而是先打探消息。
2. 打探后确认秘境需要赶路和准备，角色决定购买丹药、符箓和逃生物。正面因素：资源尚可、准备能降低风险。反面因素：消耗灵石、准备时间有限。角色选择先补给再出发。
3. 进入秘境前，角色发现强者也会参与，决定寻找队友或跟随大队。正面因素：队友可分担风险、消息更充足。反面因素：分赃减少、队友可能背叛。角色选择临时结伴，但保留退路。
4. 秘境中发现核心宝物被强者争夺，角色判断风险过高，放弃核心宝物，转去采集边缘灵药。正面因素：边缘收益稳定、敌人少。反面因素：收益不如核心宝物。角色选择止损求稳。
5. 遭遇追杀时，角色消耗逃生符撤退。正面因素：保命优先、已获得部分资源。反面因素：损失符箓、错过后续争夺。角色撤离后闭关消化收益，短期不再参与高风险事件。

#### 案例 2：赌命夺宝型抢夺宝物

**行为决策链：**

1. 角色因突破资源不足，听到宝物出世消息后决定参与。正面因素：宝物价值高、可解决瓶颈。反面因素：敌人多、消息公开、争夺激烈。角色仍选择冒险。
2. 出发前，角色出售部分材料换取丹药和攻击法宝。正面因素：短期战力提升。反面因素：库存减少、失败后恢复困难。角色选择强化进攻能力。
3. 到达现场后，角色发现正面争夺有强者参与，改为潜伏等待。正面因素：可等战后捡漏。反面因素：等待期间可能错过机会。角色选择观望。
4. 强者混战后出现伤员和落单者，角色选择偷袭弱者夺宝。正面因素：目标虚弱、成功率上升。反面因素：暴露身份、引发追杀。角色选择快速出手。
5. 宝物到手后，角色立刻逃亡。正面因素：收益已达成。反面因素：追杀开始、身份暴露。角色放弃继续争夺，转入逃亡和隐藏身份。

#### 案例 3：宗门忠诚型执行救援任务

**行为决策链：**

1. 宗门急召，要求角色救援同门。正面因素：宗门命令、同门关系、完成后有奖励。反面因素：敌情不明、可能耽误自身修炼。角色选择响应。
2. 出发前，角色检查自身状态和补给。正面因素：丹药充足、法宝可用。反面因素：路途远、敌方可能设伏。角色选择带队或结伴出发。
3. 到达现场后，角色发现敌人强于预期。正面因素：救援对象仍存活、撤退路线可用。反面因素：正面战斗风险高。角色选择先掩护撤离，而不是强行击杀敌人。
4. 撤退途中同门受伤，角色消耗疗伤丹和防御符拖延敌人。正面因素：保住同门、维持宗门声望。反面因素：消耗大、自己受伤。角色继续执行救援。
5. 回宗后，角色获得宗门信任和奖励，但短期进入疗伤和补给状态。正面因素：关系提升、贡献增加。反面因素：伤势影响后续行动。角色目标从救援转为恢复。
