# 角色AI行为参考模板

# 规范

用于整理作品中角色行为模式、行为决策链，以及可供项目 AI 行为设计参考的决策依据。

- 覆盖多境界、多身份、多地域、多势力、多场景和多结局样本；不要只写主角或成功案例。
- 只写原文或可靠依据能支撑的行为决策链。缺失字段写“原文未说明”，不得把主角策略套成所有 NPC 默认行为。
- 案例只是最低写法示范，不是数量上限；有价值的行为模式、决策节点和失败样本都应继续展开。
- 信息不足但有保留价值的对象先放入 `### 待定案例`；后续补充信息，成熟后转为 `### 案例`。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

本文只整理角色行为决策链。不写总览、抽象规则表，也不单独拆“行为原型、Utility、GOAP、Job/Toil、项目映射”等表格字段。

每个决策节点都要写“正面因素 / 反面因素”。因素内容要短，不硬补没有依据的动机。

- 行为原型：写谨慎求生、赌命夺宝、宗门忠诚、权力争夺、复仇追杀、护短报恩、避祸隐忍等归纳标签，只作为辅助概括，不替代原文决策链。
- 触发信息：写角色听到、看到或收到什么消息，以及该消息如何引出当前行动。
- 已知信息：写角色当时确实知道的内容，如目击、传闻、公告、情报买卖、敌人境界、宝物价值、事件窗口和退路。
- 自身状态：写境界、伤势、法力/斗气、神识、保命物、丹药、法宝、队伍和身份暴露等状态如何影响选择。
- 目标：写角色当时想达成的直接目标，不把后续结果倒推成一开始的动机。
- 资源收益：写宝物、丹药、功法、材料、灵石、贡献、传承、突破资源、情报、人情、职位和声望等收益为什么值得行动。
- 风险压力：写强敌、围杀、追杀、时间不足、资源暴露、背叛、惩罚、寿元压力和伤势恶化等风险为什么可能导致失败或撤退。
- 关系因素：写师徒、同门、道侣、恩人、仇人、宗门命令、家族牵连、报恩、复仇和背叛等关系如何改变收益和风险判断。
- 正面因素：写推动角色继续行动的短句因素，如收益明确、退路存在、队友支援、宗门支持、关系驱动等。
- 反面因素：写阻碍角色继续行动的短句因素，如强敌在场、伤势未愈、信息不明、资源不足、时间不够、身份暴露等。
- 行动选择：写最终选择和理由，如打探、准备、购买、组队、赶路、隐藏、参与、观望、偷袭、战斗、撤退、求援、放弃或改目标。
- 打断条件：写濒死、强敌出现、保命物耗尽、关键资源已失、同伴遇险、事件窗口关闭、身份暴露和收益低于风险等中止或转向条件。
- 结果变化：写成功后如何消化收益，失败后如何疗伤、逃亡、记仇或更换目标。

### 案例

```md
## 角色AI行为卡片

### 角色或行为节点名称

- 结果变化：

### 谨慎求生型参与秘境

- 行为原型：谨慎求生
- 触发信息：角色得知秘境开启，内部可能存在可用资源。
- 已知信息：知道入口窗口、常见争夺风险和部分可撤离路线。
- 自身状态：战力不足以正面争夺核心宝物，但有基础保命手段。
- 目标：进入秘境获取可承受风险内的资源。
- 资源收益：普通灵药、材料、情报或历练机会足以支撑后续修炼。
- 风险压力：核心区域强敌多，信息不全时容易遭遇围杀或陷阱。
- 关系因素：若有同门或临时队友同行，需要兼顾协作和牵连风险。
- 正面因素：收益明确；退路存在；可先打探再行动。
- 反面因素：强敌可能进入；身份或收获暴露会引来追杀。
- 行动选择：先打探并准备补给，进入后避开核心风险，收益到手后撤离。
- 打断条件：强敌出现、保命物耗尽、关键路线失效或收益低于风险时撤退。
- 结果变化：成功后消化资源并隐藏收获，失败后疗伤、避祸或更换目标。

### 赌命夺宝型抢夺宝物

- 行为原型：赌命夺宝
- 触发信息：角色发现宝物现世，且短时间内仍有夺取机会。
- 已知信息：知道宝物价值、竞争者大致实力和可利用的混乱窗口。
- 自身状态：处于瓶颈、资源短缺或急需翻盘的压力中。
- 目标：在高风险窗口内夺取关键宝物。
- 资源收益：宝物可能带来突破、战力提升、传承资格或脱困机会。
- 风险压力：竞争者强、窗口短，得手后也可能被追杀。
- 关系因素：仇敌、同伴或宗门压力可能放大冒险理由，也可能限制撤退。
- 正面因素：收益足以改变处境；混乱中存在捡漏机会。
- 反面因素：敌强我弱；资源暴露后风险持续上升。
- 行动选择：短期强化战力，潜伏观察，趁混乱偷袭或捡漏，得手后立即逃亡。
- 打断条件：宝物已失、强敌锁定、伤势恶化或逃路被截断时放弃或改目标。
- 结果变化：成功后隐藏行踪并消化收益，失败后逃亡、疗伤或记仇。

### 宗门忠诚型执行救援

- 行为原型：宗门忠诚
- 触发信息：角色收到宗门命令，或得知同门陷入危险。
- 已知信息：知道求援地点、敌情大致强弱、同门处境和支援窗口。
- 自身状态：具备执行救援的基础战力或身份责任，但可能资源消耗较大。
- 目标：救出同门、完成命令，并尽量保全队伍。
- 资源收益：宗门贡献、声望、人情和同门信任。
- 风险压力：敌情可能不明，救援过程容易被伏击或拖入消耗战。
- 关系因素：宗门命令、同门情义和师承责任会提高行动优先级。
- 正面因素：命令明确；目标位置较清楚；同门关系推动行动。
- 反面因素：敌方可能设伏；伤亡扩大将造成关系和宗门压力。
- 行动选择：先评估敌情并联络支援，优先救人撤离，避免无必要追击。
- 打断条件：救援对象已脱险、敌方强援出现、队伍伤亡过大或撤离窗口关闭时转向撤退。
- 结果变化：成功后疗伤补给并交付任务，失败后承担惩罚、补救关系或继续追查。
```

### 待定案例

如果原文描述符合当前模板但信息较少，先在待定案例区保留关键摘要和括号来源；后续发现新信息时，在同一条后追加摘要和括号来源；信息相对完整后，将该条移入 `### 案例`，并从待定区删除该条，括号来源不迁移到正式案例。

待定案例格式统一为：`1. 对象名称（来源），关键摘要（来源），新增摘要（来源）。`
