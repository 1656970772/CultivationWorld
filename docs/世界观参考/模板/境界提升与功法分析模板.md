# 境界提升与功法分析模板

# 规范

- 本文只整理小说中出现过，或能由小说内容明确支撑的境界体系与境界突破方式。
- 本文不写总览，不写依据段，不写抽象规则表，不分析功法体系。功法、术法、神通、秘术、功法品级和功法效果放入专门的功法模板。
- 只整理原文出现过，或能由原文和可靠资料明确支撑的境界体系与突破方式。
- 样本应覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角、单一境界或成功案例。
- 案例只是写法示范，不是数量上限；原文有多少有价值内容就继续展开多少。
- 原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，写“原文未说明”，不要补设定。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 境界层级：写大境界、小境界、圆满、巅峰、半步、伪境、凡人武道阶位、妖兽阶位、神魂并行境界、肉身并行境界、特殊临时境界等。
- 提升阶段：写初入、稳固、积累、瓶颈、圆满、冲关、突破成功、突破失败、跌境、重修、恢复境界等阶段。
- 突破方式：写自然积累突破、丹药辅助突破、强行冲关、天劫突破、心境突破、神识突破、肉身突破、血脉觉醒、秘境机缘、外力灌顶、师长护法、夺舍重修、转世恢复、特殊体质路线、妖兽化形进阶等方式。
- 积累条件：写灵力、真气、法力、斗气、神识、肉身、心境、血脉、寿元、资源、洞府环境、天地灵气、师长护法等条件；不明时写“原文未说明”。
- 突破资源：写丹药、灵石、灵脉、洞府、天材地宝、妖兽材料、护法资源、秘境机缘、传承资源、特殊环境等。
- 环境要求：写洞府、灵脉、宗门修炼室、秘境、天劫场地、禁地、火脉、冰原、雷池、特殊界面、护法阵法等。
- 成功变化：写寿元增加、战力提升、神识增强、肉身增强、法力质量变化、根基稳固程度变化、后遗症有无、行动范围扩大、地图层级变化、身份地位变化、可参与事件变化等。
- 失败后果：写经脉受损、重伤、跌境、死亡、心魔、天劫失败、寿元损耗、资源耗尽、神魂受创、被敌人趁虚而入、突破中断等。
- 多方式记录：同一目标境界有多种突破方式时，分开写成“突破方式 1 / 突破方式 2 / 突破方式 N”，并分别记录根基、战力、寿元、后遗症、心魔风险、失败代价、后续瓶颈或身份变化。
- 通用性判断：不要把主角外挂、血脉特例、特殊丹药或剧情保送当成普通修士通用规则。

## 案例

### 案例

```md
# 《作品名》境界提升与突破分析

## 境界提升卡片

### 炼气期 → 筑基期

- 境界层级：炼气期 → 筑基期。
- 提升阶段：炼气初期 / 中期 / 后期 / 圆满 / 瓶颈 / 冲击筑基；按作品实际小阶段填写。
- 突破方式 1：丹药辅助筑基。
- 积累条件：炼气圆满或接近圆满；心境、神识、身体状态等按原文填写。
- 突破资源：筑基丹、灵石、护法资源、闭关资源；丹药数量和获得方式按原文填写。
- 环境要求：洞府、宗门闭关室、灵脉、安静场所或护法阵法；原文未说明则写“原文未说明”。
- 成功变化：进入筑基期；法力质量、寿元、神识、战力、身份地位、可参与事件变化按原文填写。
- 失败后果：丹药耗尽、经脉受损、重伤、短期不能再冲关、修为停滞等；原文未说明则写“原文未说明”。
- 突破方式 2：无丹药强行筑基。
- 积累条件：炼气圆满但缺少筑基丹，或因寿元、追杀、资源窗口等压力被迫冲关。
- 突破资源：原文未说明；若有替代资源则按原文填写。
- 环境要求：闭关场所、临时藏身处、护法阵法等；原文未说明则写“原文未说明”。
- 成功变化：如果成功后根基、战力、寿元、后遗症与丹药突破不同，要单独写清。
- 失败后果：风险通常更高；具体伤势、跌境、死亡或资源损失按原文填写。
- 突破方式 N：其他路线。
- 积累条件：如天劫突破、秘境机缘、外力灌顶、特殊体质路线等；按原文分别填写。
- 突破资源：按对应路线分别填写。
- 环境要求：按对应路线分别填写。
- 成功变化：按对应路线分别填写。
- 失败后果：按对应路线分别填写。

### 筑基期 → 结丹期 / 更高境界

- 境界层级：筑基期 → 结丹期，或作品中的其他中高阶突破。
- 提升阶段：初期 / 中期 / 后期 / 圆满 / 瓶颈 / 冲关；按作品实际设定填写。
- 突破方式 1：常规积累突破。
- 积累条件：修为圆满，神识、心境、肉身承受力等达到原文要求。
- 突破资源：日常丹药、灵石、护法资源等；按原文填写。
- 环境要求：修炼场所、闭关洞府、护法阵法等；按原文填写。
- 成功变化：寿元、战力、法力质量、法宝使用、身份地位等变化按原文填写。
- 失败后果：资源损耗、伤势、瓶颈加重、跌境或死亡等按原文填写。
- 突破方式 2：特殊资源突破。
- 积累条件：获得特殊丹药、天材地宝、秘境机缘、传承资源或外力灌顶。
- 突破资源：特殊丹药、天材地宝、传承资源或外力支持等。
- 环境要求：秘境、传承地、闭关地、灌顶场所等；按原文填写。
- 成功变化：是否比常规突破更快、更稳，是否带来额外能力、根基强化或后遗症。
- 失败后果：资源反噬、秘境危险、传承失败、外力中断、伤势或死亡等按原文填写。
- 突破方式 3：高风险突破。
- 积累条件：寿元压力、敌人逼迫、资源不足、战乱环境、强行冲关等。
- 突破资源：临时资源或不足资源；按原文填写。
- 环境要求：战乱环境、逃亡地点、临时闭关地等；按原文填写。
- 成功变化：根基不稳、伤势残留、后续瓶颈加重或身份变化等。
- 失败后果：跌境、死亡、寿元损耗、资源耗尽等。

### 妖兽阶位 → 更高阶位 / 化形

- 境界层级：妖兽某阶 → 更高阶 / 化形阶段。
- 提升阶段：成长期 / 临界期 / 进阶期 / 化形前后；按原文填写。
- 突破方式 1：血脉成长进阶。
- 积累条件：血脉成熟、吞食灵药、吸收天地灵气、族群护持等。
- 突破资源：灵药、妖丹、血脉资源、领地资源、吞噬对象。
- 环境要求：领地、灵药成熟地、妖族禁地、隐蔽进阶地点。
- 成功变化：阶位提升、灵智增强、化形、领地扩大、族群地位提升。
- 失败后果：血脉受损、妖丹破裂、重伤、跌阶、被修士猎杀。
- 突破方式 2：天劫或外部压力进阶。
- 积累条件：天劫、兽潮、强敌逼迫、资源争夺或环境异变。
- 突破资源：抗劫资源、族群护持、妖丹、特殊地形。
- 环境要求：天劫场地、边境、兽潮区域、禁地。
- 成功变化：阶位提升并可能引发区域威胁、材料价值上升或族群格局变化。
- 失败后果：死亡、重伤、被围猎、进阶中断或领地丢失。
```
