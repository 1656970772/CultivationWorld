# 境界提升分析模板


## 适用范围

- 本文只整理小说中出现过，或能由小说内容明确支撑的境界体系与境界突破方式。
- 本文不写总览，不写证据段，不写抽象规则表，不分析功法体系。功法、术法、神通、秘术、功法品级和功法效果放入专门的功法模板。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

如果原文中出现符合本模板主题、但信息暂时不足以形成相对完整案例的内容，先写入 `### 待定案例`，保留对象名称、关键摘要和来源位置。后续获得新信息时，在同一待定项追加摘要和来源；当信息已相对完整、足以支撑案例时，复核待定项中的全部来源，删除待定项，并整理为 `### 案例` 中的正式案例。不要求所有字段全部齐备后才转入正式案例。

## 必须写什么

- 境界体系要写清大境界、小阶段、半步、伪境、圆满、巅峰等特殊状态，以及每个阶段带来的能力边界变化。
- 按境界单独写，不写成长篇连续叙述。每个境界用固定字段列出：境界层级、提升阶段、突破方式、条件、资源、环境、成功变化、失败后果。
- 最关键的是写清**同一境界的不同突破方式**。如果同一目标境界存在多种突破方式，例如丹药突破、强行冲关、天劫突破、血脉觉醒、秘境机缘、夺舍重修、外力灌顶、特殊体质路线等，必须在同一境界条目下分开写。
- 不同突破方式如果会带来不同突破后效果，也必须分别写清。例如根基稳固程度、战力差异、寿元变化、后遗症、心魔风险、失败代价、后续瓶颈、身份地位变化等。
- 主角的境界突破样本要尽量完整，并按境界分段；配角、NPC、反派、宗门天才、散修、妖修等角色如果原文有清楚的突破样本，也应补充。
- 原文没有寿元数字、突破概率、战力跨度、小阶段名称或突破后差异时，不要硬补；可以写“原文未说明”。
- 不要把主角外挂、血脉特例、特殊丹药或剧情保送当成普通修士的通用规则。

参考范围不局限于以下类别：

- **境界层级**：大境界、小境界、圆满、巅峰、半步、伪境、凡人武道阶位、妖兽阶位、神魂并行境界、肉身并行境界、特殊临时境界。
- **提升阶段**：初入、稳固、积累、瓶颈、圆满、冲关、突破成功、突破失败、跌境、重修、恢复境界。
- **突破方式**：自然积累突破、丹药辅助突破、强行冲关、天劫突破、心境突破、神识突破、肉身突破、血脉觉醒、秘境机缘、外力灌顶、师长护法、夺舍重修、转世恢复、特殊体质路线、妖兽化形进阶。
- **积累条件**：灵力、真气、法力、斗气、神识、肉身、心境、血脉、寿元、资源、洞府环境、天地灵气、师长护法。
- **突破资源**：丹药、灵石、灵脉、洞府、天材地宝、妖兽材料、护法资源、秘境机缘、传承资源、特殊环境。
- **环境要求**：洞府、灵脉、宗门修炼室、秘境、天劫场地、禁地、火脉、冰原、雷池、特殊界面、护法阵法。
- **风险与失败后果**：经脉受损、重伤、跌境、死亡、心魔、天劫失败、寿元损耗、资源耗尽、神魂受创、被敌人趁虚而入、突破中断。
- **成功变化**：寿元增加、战力提升、神识增强、肉身增强、法力质量变化、根基稳固程度变化、后遗症有无、行动范围扩大、地图层级变化、身份地位变化、可参与事件变化。

## 案例

### 案例

#### 案例 1：炼气期 → 筑基期

境界层级：炼气期 → 筑基期。

提升阶段：炼气初期 / 中期 / 后期 / 圆满 / 瓶颈 / 冲击筑基；按作品实际小阶段填写。

突破方式一：丹药辅助筑基。

条件：炼气圆满或接近圆满；心境、神识、身体状态等按原文填写。

资源：筑基丹、灵石、护法资源、闭关资源；丹药数量和来源按原文填写。

环境：洞府、宗门闭关室、灵脉、安静场所或护法阵法；原文未说明则写“原文未说明”。

成功变化：进入筑基期；法力质量、寿元、神识、战力、身份地位、可参与事件变化按原文填写。

失败后果：丹药耗尽、经脉受损、重伤、短期不能再冲关、修为停滞等；原文未说明则写“原文未说明”。

突破方式二：无丹药强行筑基。

条件：炼气圆满但缺少筑基丹，或因寿元、追杀、资源窗口等压力被迫冲关。

资源：可能只有灵石、洞府、少量辅助丹药或自身积累；原文写多少就写多少。

环境：闭关地点、灵气条件、是否有人护法按原文填写。

成功变化：如果成功后根基、战力、寿元、后遗症与丹药突破不同，要单独写清。

失败后果：风险通常更高；具体伤势、跌境、死亡或资源损失按原文填写。

#### 案例 2：筑基期 → 结丹期

境界层级：筑基期 → 结丹期。

提升阶段：筑基初期 / 中期 / 后期 / 圆满 / 瓶颈 / 冲击结丹；按作品实际小阶段填写。

突破方式一：常规积累突破。

条件：筑基圆满；修为、神识、心境、肉身承受力等达到原文要求。

资源：日常丹药、灵石、修炼场所、护法等；具体名称和数量按原文填写。

环境：常规洞府、宗门修炼室、家族资源地等。

成功变化：进入结丹期；寿元、战力、法力质量、法宝使用能力、身份地位变化按原文填写。

失败后果：结丹失败、资源损耗、伤势、瓶颈加重、寿元压力等按原文填写。

突破方式二：特殊资源突破。

条件：获得特殊丹药、天材地宝、秘境机缘、传承资源或外力灌顶。

资源：具体资源名称、数量、来源、消耗。

环境：秘境、传承地、特殊灵地、禁地、阵法或师长护持。

成功变化：是否比常规突破更快、更稳，是否带来额外能力、根基强化或后遗症。

失败后果：资源反噬、秘境危险、传承失败、外力中断、伤势或死亡等按原文填写。

突破方式三：高风险突破。

条件：寿元压力、敌人逼迫、资源不足、战乱环境、强行冲关等。

资源：缺少关键资源或只具备最低资源。

环境：不稳定闭关地、战场、逃亡途中、无人护法等。

成功变化：若成功，是否根基不稳、伤势残留、后续瓶颈加重，要按原文写清。

失败后果：失败伤势、跌境、死亡、寿元损耗、资源耗尽等。

#### 案例 3：结丹期 → 元婴期

境界层级：结丹期 → 元婴期。

提升阶段：结丹初期 / 中期 / 后期 / 圆满 / 冲击元婴；按作品实际设定填写。

突破方式一：闭关冲击元婴。

条件：结丹圆满、神识积累、心境、肉身承受力等。

资源：高阶丹药、灵地、护法、法宝护持、闭关时间；具体按原文填写。

环境：高阶洞府、宗门禁地、灵脉、护法阵法等。

成功变化：元婴成形、寿元增长、战力层级提升、遁术或保命方式变化、宗门地位提升。

失败后果：神魂受损、重伤、跌境、寿元损耗、死亡、被迫夺舍等。

突破方式二：特殊机缘辅助元婴。

条件：获得秘境机缘、天地灵物、传承资源或外力帮助。

资源：具体机缘、丹药、灵物、护法资源。

环境：秘境、特殊灵地、天劫场地或传承空间。

成功变化：是否带来额外能力、根基强化、战力差异或后续瓶颈变化。

失败后果：原文写明则填写；未说明则写“原文未说明”。

#### 案例 4：妖兽阶位 → 更高阶位 / 化形

境界层级：妖兽某阶 → 更高阶 / 化形阶段。

提升阶段：成长期 / 临界期 / 进阶期 / 化形前后；按原文填写。

突破方式一：血脉成长进阶。

条件：血脉成熟、吞食灵药、吸收天地灵气、族群护持等。

资源：灵药、妖丹、血脉资源、领地资源、吞噬对象。

环境：领地、灵药成熟地、妖族禁地、隐蔽进阶地点。

成功变化：阶位提升、灵智增强、化形、领地扩大、族群地位提升。

失败后果：血脉受损、妖丹破裂、重伤、跌阶、被修士猎杀。

突破方式二：天劫或外部压力进阶。

条件：天劫、兽潮、强敌逼迫、资源争夺或环境异变。

资源：抗劫资源、族群护持、妖丹、特殊地形。

环境：天劫场地、边境、兽潮区域、禁地。

成功变化：阶位提升并可能引发区域威胁、材料价值上升或族群格局变化。

失败后果：死亡、重伤、被围猎、进阶中断或领地丢失。
