# 矿物与炼器材料分析模板

## 适用范围

本模板用于整理作品中明确出现的矿石、金属、玉石、晶体、宝砂、实体空间材料、星辰材料和其他能够作为原料继续加工的固体材料，并追踪其形成、分布、鉴定、开采、保存、加工、服役、劣化、回收和流通全过程。

本模板不分析法宝、武器、装备、饰品、容器、阵法等成品，也不收录灵植、生灵材料、灵能资源和天然灵液。对象即使被称为“天地奇物”，只要主要形态仍是可开采、提纯或加工的固体原料，就可进入本模板；已经具备完整主动能力、独立使用方式或成品结构时，转入天地奇物、法宝或其他对应模板。下游成品只在“用途/下游去向”中出现，完整内容放入对应专题模板。

## 整理原则

1. 先做准入判定
   对象应当以可继续加工的固体原料形态存在，能够被开采、提纯、熔炼、雕琢，或作为炼器、布阵投入。判断以当前形态和主要功能为准，不因“天地奇物”“空间之物”等名称自动排除或纳入；已经具备完整使用结构的人造器物不得建立本模板卡片。

2. 一物一卡
   同名、别名、同物异名、不同品阶、纯度、规格和加工阶段归入同一卡。先核对俗称、矿名、精炼态名称和地域叫法，避免重复建卡；若提纯或加工后形成有独立名称、性质和用途的新材料，可另建派生物卡，并通过形成机制、状态转化或替代关系连接原材料。

3. 字段完整
   每张卡必须包含：子类、别名/同物异名、准入理由、信息依据与确定性、形态/外观、组成/内部结构、基础物理性质、温度特性/寒热偏性、机械性能、五行/药性/本征相性、药力/效力强度（1~100）、毒性/危害性、温和度（1~100）、纯度/品阶/规格、形成机制/产状/分布、识别/鉴定方式、开采/取得条件、保存/运输/稳定与劣化、加工处理与状态转化、加工异常/损耗/废料/回收、相容/冲突/替代关系、功能特性/成品贡献、用途/下游去向、稀有度/价值/流通。
   禁止空字段。原文没有说明、检查范围内没有发现、材料尚未覆盖或该对象客观上不具有某一环节时，应分别写“原文未说明”“未检出”“未覆盖”或“不适用”。不得用同类小说常识、材料名称或使用者当前境界补齐设定。

4. 差异在卡内展开
   品阶、纯度、大小、重量、组成、属性、精炼状态和保存状态等差异写入同一张卡的相应字段。差异会改变物理性质、寒热偏性、机械性能、本征相性、效力、毒性、温和度、鉴定、用途、开采、加工、稳定性、损耗或价值时，在相关字段中分别描述。

5. 区分原矿、材料与成品
   原矿、精炼金属、晶体、粉末和宝砂等可继续加工的对象归本模板；被人为炼成并具备完整功效、认主结构或使用方式的对象，归入武器、法宝或其他成品模板。

6. 保留材料链条
   优先写清材料如何形成和分布，由什么组成，如何被识别、开采、保存和运输，经过何种处理发生哪些状态转化，怎样与其他材料相容或冲突，为成品贡献什么功能，以及如何劣化、产生废料、回收、流通或最终耗尽。下游武器、法宝、阵法和建筑只作为用途，不在本卡中展开完整效果。

7. 明确信息与推断分开
   材料名称、形成、组成、性质、鉴定、开采、加工、成品贡献、稀有度和价格应分别判断依据与确定性。应区分旁白直接说明、典籍记录、矿工或炼器师讲解、实际开采加工表现、交易记录、成品反推、人物评价和上下文直接推断；必要时附章节、段落或情节锚点，不得因名称带有“星辰”“空间”等词自行补写来源和性质。

8. 输出前自检
   检查对象是否符合固体加工材料准入条件、同名材料是否重复建卡、纯度和品阶差异是否归入同一卡、成品是否误收，是否遗漏组成、寒热偏性、机械性能、五行或本征相性、效力、毒性、温和度、鉴定、保存、状态转化、劣化、回收和流通，是否混淆硬度、韧性与脆性，是否把成品完整效果归因于单一材料，以及案例区是否只包含实际输出字段。

## 属性记录与量化规则

1. 属性分维记录
   五行或药性、寒热偏性、药力或效力强度、毒性、温和度和机械性能是不同维度，不得互相代替。冰寒材料不自动判为水属性，火属性材料不自动判为高温，坚硬材料也可能高脆、易碎。

2. 五行与药性
   原文明示可入药时记录金、木、水、火、土中的单一或复合药性；用于炼器、布阵或承载能量时记录五行及雷、冰、风、阴阳、空间、星辰等本征属性。没有明确证据时写“原文未说明”，不得根据名称、颜色或现实矿物常识推断。

3. 数值量表
   “药力/效力强度”和“温和度”使用 1~100；可入药材料记录药力，非药用材料记录其主要用途上的效力并标明评分对象。数值越高表示单位材料可提供或承载的已确认作用越强；温和度越高表示能量或药性越平稳、越容易处理、吸收或与其他材料协同。仅在原文给出数值，或同一作品内存在足够明确的等级、对比和实际表现时评分，并在字段中同时写明“数值 + 评分对象 + 依据 + 原文明示/相对折算”。证据不足时写“原文未说明（不评分）”。相对折算可使用 1~20 极弱、21~40 较弱、41~60 中等、61~80 较强、81~100 极强五档；不同作品的折算分数默认不可直接横向比较。

4. 毒性与危害
   毒性记录接触、吸入、吞服、炼化或加工时对肉身、神魂、经脉和环境造成的毒害，可在证据充分时使用 0~100 辅助量化；0 只用于原文明示或实际验证无毒，不得把“原文未提及中毒”写成 0。腐蚀、辐射、污染、灼伤、冻伤、空间侵蚀等非毒性危害也在本字段分别标注，不与毒性混为一谈。

5. 机械性能
   硬度表示抗压入或抗划伤能力，韧性表示吸收冲击而不断裂的能力，脆性表示受力后突然断裂或粉碎的倾向。原文只写“坚硬”时不得自动补写“坚韧”或“不易碎”；原文只写“易碎”时记录为高脆性，不反推其硬度。

## 字段说明

- 子类：填写矿石、金属、玉石、晶体、宝砂、空间材料、星辰材料或其他固体材料。
- 别名/同物异名：填写俗称、矿名、精炼态名称、地域叫法和不同语言称呼，并说明哪些只是加工阶段名、哪些已经成为独立派生材料。
- 准入理由：说明对象为何以可继续加工的固体原料形态进入本模板，以及为什么不是法宝、武器、阵法、灵液、生灵材料或其他成品。
- 信息依据与确定性：分别标注信息来自旁白直接说明、典籍记录、矿工或炼器师讲解、实际开采或加工表现、交易记录、成品反推、人物评价、上下文直接推断或尚未说明，必要时附章节、段落或情节锚点。
- 形态/外观：填写矿块、金属、玉料、晶体、粉末、砂粒等形态与颜色、光泽、纹理。
- 组成/内部结构：填写原文明确说明的主要成分、矿物相、杂质、伴生物、晶体结构、孔隙、纹理层次、内部灵纹、能量核心或空间结构，以及这些结构在不同纯度和加工阶段的变化；不得按现实矿物学自行补写。
- 基础物理性质：填写颜色与外观以外的密度、重量感、孔隙、导热、导电、导能、耐磨、耐压、耐腐蚀和静态稳定性等本体性质；寒热表现和受力表现分别写入后续专门字段。
- 温度特性/寒热偏性：填写材料本体呈冰寒、寒凉、常温、温热、炽热或随环境、注能、加工状态变化的表现，以及接触后造成的冻伤、灼伤、热胀冷缩和属性逸散。寒热偏性与水、火五行分别取证，不得互相推定。
- 机械性能：分别填写硬度、韧性、脆性、延展性、可塑性、弹性、抗冲击、断裂条件和粉碎难度；原文未区分的指标不得互相代填。
- 五行/药性/本征相性：填写材料自身的金、木、水、火、土药性或五行属性，以及雷、冰、风、空间、星辰、阴阳等其他属性，吸收、传导、储存或排斥何种能量，以及对环境灵气的本征响应；与具体其他材料的关系写入“相容/冲突/替代关系”。
- 药力/效力强度（1~100）：可入药材料填写单位材料的药效强度，非药用材料填写其在导能、储能、承载、淬炼或其他已确认核心功能上的强度并标明评分对象；写明评分依据和证据性质，不同功能强度差异明显时分项评分。证据不足时写“原文未说明（不评分）”。
- 毒性/危害性：填写毒性及接触、吸入、吞服、炼化、切割、加热或熔炼造成的腐蚀、污染、冻伤、灼伤、爆裂、空间侵蚀等危害，注明触发方式、受害对象、结果和证据；有充分依据时可附毒性 0~100。
- 温和度（1~100）：填写材料能量或药性在加工、配伍、接触、吸收时的平稳程度；数值越高越平稳、越容易控制和协同，越低越狂暴、排斥或易失控。机械上的易碎和化学上的稳定不得直接当作温和度，证据不足时写“原文未说明（不评分）”。
- 纯度/品阶/规格：填写原矿或精炼态、纯度、品阶、大小、重量和可用比例。
- 形成机制/产状/分布：分别写材料如何生成或积累，以矿脉、矿点、伴生矿、陨落物、晶簇或其他何种状态存在，以及地域、深度、环境、储量、已知矿区和伴生关系；原文只说明产地而未说明形成原因时不得补写机制。
- 识别/鉴定方式：写通过颜色、重量、硬度、纹理、气息、能量反应、切面、加热反应、专用工具或鉴定术识别材料、判断纯度和品阶的方法，以及赝品、易混材料、鉴定失败和鉴定者资格。
- 开采/取得条件：填写采矿工具、修为或职业能力、作业环境、危险、禁制、所有权、许可、开采成本，以及开采对矿区、地形、灵气或周边势力造成的影响；购买、交换、抢夺等非开采取得方式也在此说明。
- 保存/运输/稳定与劣化：写材料对温度、湿度、光照、灵气、空间、容器、震动、污染和相邻材料的要求，以及保存期限、运输方式、防护措施、风化、氧化、裂损、灵性流失、属性逸散和降品过程。
- 加工处理与状态转化：写清洗、破碎、选矿、去杂、熔炼、锻打、切割、研磨、阵法提纯、合金化和特殊处理，以及原矿、精矿、锭材、粉末或派生材料之间的熔化、凝固、粉化、灵性转移等变化；记录转化前后的名称、组成、性质、纯度、用途和明确加工门槛。
- 加工异常/损耗/废料/回收：分别写正常加工损耗、灵性或能量流失、污染、裂损、降品、处理失败、高温爆裂、属性冲突、空间失稳等异常或极端事故，以及废渣、边角料、失败产物的回收、重炼、降级利用和不可回收部分。
- 相容/冲突/替代关系：写可共熔、复合、镶嵌或共同承载结构的材料，发生排斥、腐蚀、能量冲突或结构破坏的组合，以及替代品能够替代的功能和替换后对成本、工艺、质量、稳定性及成品品阶的影响。
- 功能特性/成品贡献：写该材料凭借哪些已经确认的物理、能量或结构性质，为下游成品提供承力、导能、储能、隔绝、稳定空间、承载阵纹等具体贡献；不得把整个法宝的完整攻击、防御或特殊能力都归因于单一材料。
- 用途/下游去向：填写炼器、布阵、建筑、修复、货币和其他用途，以及进入何种成品、工艺阶段或最终处置路径；原文明确规定加工者、使用者或成品的境界、职业等级和品阶要求时在此说明，不得根据稀有度自行推断。
- 稀有度/价值/流通：按作品自身描述填写稀有程度、储量依据、价格、交换比例、计价单位、市场、拍卖、宗门配给、管制、垄断、走私和争夺，以及不同纯度、规格和加工状态的价值差异。
