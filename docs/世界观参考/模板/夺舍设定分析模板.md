# 夺舍设定分析模板

> 最后更新：2026-06-17
> 状态：模板
> 类型：夺舍、附身、转生、复活与身体接管调研
> 目标详细程度：L3

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

- 本文用于整理作品中的夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等身体或身份接管机制。
- 本文不写总览，不写证据段，不写表格，不写项目字段映射，不写游戏化抽象。
- 不把所有“复活”“转世”“重生”都称为夺舍，必须按原文机制区分。
- 不把主角特例直接当成普通 NPC 可用机制；如果只是主角开局设定，要写清特殊性。
- 不只写“某人夺舍成功”或“某人复活”，必须写清发起者、目标、发起原因、前置条件、媒介条件、接管方式、目标反抗、成功结果、失败后果、身份处理、记忆人格变化、关系后果、弱点和后续影响。
- “接管方式”是本模板重点，必须尽量详细写成流程：发起者如何接近目标、如何削弱目标、如何进入神魂或肉身、如何压制原主人、如何融合或替换身份、如何遮掩痕迹、失败或中断会怎样。
- 原文没有说明发起者、目标、媒介、条件、接管方式、反抗方式、身份处理、记忆人格变化、弱点或后续影响时，不要补，可以写“原文未说明”。

## 参考范围（不局限于以下类别）

- **机制类型**：夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂。
- **发起者**：高阶修士、残魂、邪修、师傅、器灵、魔头、古修、妖修、被封印存在、秘境意志、家族祖魂。
- **目标条件**：资质、境界差、肉身强度、灵根/血脉、神魂弱点、亲近关系、信任关系、是否被削弱、是否昏迷、是否死亡。
- **媒介条件**：法宝、阵法、丹药、禁术、魂牌、血契、寄魂物、尸体、傀儡、秘境环境、血脉仪式、祭坛、转生胎体。
- **行动链**：潜伏、伪装、诱骗、培养目标、削弱目标、进入识海、压制神魂、夺取身体、融合记忆、清理痕迹、逃避追查。
- **反抗/失败**：目标神魂反击、护身宝物、外力干预、镇魂法器、血脉排异、反噬、魂灭、疯癫、身体崩坏、记忆混乱。
- **后果**：身份变化、记忆继承、人格混合、关系背叛、师徒破裂、通缉追杀、复仇执念、寿元重置或不变、势力继承权变化。
- **弱点**：怕神魂攻击、镇魂法器、护体禁制、血脉排异、肉身不合、目标意志反抗、接管时机被打断、阵眼被破、真名或旧身份暴露。

## 完整夺舍案例

### 案例 1：高阶修士夺舍低阶修士

名字和类型：写具体人物或组织名称，以及机制类型；例如“某某（夺舍）”。如果原文没有明确称呼，按行为描述填写。

发起者：写清发起夺舍者是谁，原本身份、修为、神魂状态、是否濒死、是否残魂、是否被封印、是否有同伙或护法。

目标：写清被夺舍者是谁，资质、境界、肉身状态、神魂状态、与发起者关系，以及为什么会被选中。

发起原因：写清是为了延寿、复活、逃避死亡、重获肉身、夺取资质、继承身份、躲避追杀、突破瓶颈，还是复仇或完成执念。

前置条件：写清境界差、神魂强度、目标虚弱状态、目标信任关系、目标是否昏迷或被困、是否需要特定体质、血脉、灵根、时间或地点；原文未说明则写“原文未说明”。

媒介条件：写清法宝、阵法、丹药、禁术、魂牌、血契、寄魂物、祭坛、秘境环境或其他媒介；没有明确媒介就写“原文未说明”。

接管方式：非常详细写。写清发起者如何接触目标，如何进入目标识海或肉身，是否先伪装、诱骗、培养或削弱目标，如何压制目标神魂，如何抢夺肉身控制权，是否融合记忆，是否需要稳定期，是否会留下气息、伤痕、魂魄波动或性格变化，接管过程中被打断会怎样。

目标反抗：写清目标如何反击，例如神魂反扑、护身宝物触发、血脉排异、外力救援、意志抵抗、同归于尽、逃出部分神魂等；原文未说明则写“原文未说明”。

成功结果：写清发起者是否完全接管肉身，修为保留多少，寿元是否重置，能否使用目标资质、血脉、身份、法宝和关系网。

失败后果：写清反噬、魂灭、神魂受创、疯癫、身体崩坏、目标死亡、双方同损、身份暴露或被围剿。

身份处理：写清夺舍后如何处理原身份与新身份，是否伪装成目标继续生活，是否暴露给亲友、师门、家族或敌人，是否改名换身份。

记忆与人格变化：写清是否继承目标记忆，是否出现人格混合、记忆缺失、性情变化、执念残留或目标意识复苏。

关系后果：写清师徒背叛、亲友复仇、宗门清查、家族继承争议、仇怨延续、通缉追杀或势力重新站队。

弱点：写清这种夺舍方式怕什么，例如神魂攻击、镇魂法器、护体禁制、血脉排异、肉身不合、目标意志强、夺舍时机被打断、真名或旧身份暴露；原文未说明则写“原文未说明”。

结局或后续影响：写清夺舍者后来是否稳定身份、暴露、逃亡、被杀、被反夺舍、引发复仇、改变势力格局或成为长期隐患。

### 案例 2：残魂寄宿 / 器灵附体

名字和类型：写具体残魂、器灵、古修、魔头、法宝或宿主名称，以及残魂寄宿、器灵附体等类型。

发起者：写清寄宿者是谁，是否为残魂、器灵、被封印存在、古修意识、魔头分魂或秘境意志。

目标：写清宿主是谁，为什么能承载寄宿者，是否主动接受、被骗接受、被迫承载，还是无意触发。

发起原因：写清寄宿者是为了保命、等待复活、寻找传承者、操控宿主、借宿主行动、逃出封印、夺取机缘，还是完成旧执念。

前置条件：写清宿主神魂强度、体质、资质、血脉、法宝认主状态、封印松动条件、触发地点、触发行为或契约要求。

媒介条件：写清戒指、玉佩、剑器、魂牌、古宝、傀儡、封印石、秘境核心、血契、法宝认主仪式或其他寄魂物。

接管方式：非常详细写。写清寄宿者如何进入或依附媒介，如何与宿主沟通，是否隐藏真实身份，是否逐步影响宿主决策，是否能临时接管身体，接管时消耗什么，宿主是否会虚弱、失忆、人格变化或神魂受损，寄宿者是否能脱离媒介。

目标反抗：写清宿主能否拒绝、封印、驱逐、谈判、借助外力镇压，或通过毁掉媒介摆脱寄宿者。

成功结果：写清寄宿者获得行动能力、恢复神魂、培养宿主、控制宿主、借宿主复活，还是只保留旁观和指导能力。

失败后果：写清残魂消散、器灵沉睡、宿主神魂受创、媒介破碎、封印加强、双方记忆混乱或被外敌发现。

身份处理：写清外界是否知道宿主体内有残魂或器灵，宿主是否隐藏此事，寄宿者是否冒充宿主发言或行动。

记忆与人格变化：写清宿主是否继承残魂知识，是否被残魂影响性格，是否出现人格混合、执念污染、梦境干扰或记忆错乱。

关系后果：写清师徒、传承、利用、背叛、依赖、夺舍风险、亲友误解、宗门追查或敌人觊觎法宝。

弱点：写清是否怕媒介被毁、封印加强、镇魂法器、契约反制、宿主拒绝、神魂恢复不足、外界识破、法宝易主或宿主死亡；原文未说明则写“原文未说明”。

结局或后续影响：写清残魂是否复活、消散、成为宿主师长、反噬宿主、被驱逐、被炼化或引出更大传承/仇敌。

### 案例 3：转世 / 重生 / 复活

名字和类型：写具体人物或族群名称，以及转世、重生、复活、轮回归来等类型。

发起者：写清是谁转世或复活，是本人主动布局、外力复活、天道轮回、族群仪式、法宝保命，还是特殊血脉能力。

目标：写清新身体、新身份、胎体、尸体、傀儡身体、血脉后裔或复活容器是什么。

发起原因：写清是死亡后保命、重修、延续传承、躲避仇敌、等待时代变化、完成使命，还是被他人复活利用。

前置条件：写清死亡前准备、魂魄保存、轮回条件、复活材料、血脉要求、信仰祭祀、阵法、时间窗口、修为限制和外力帮助。

媒介条件：写清魂灯、命牌、转生法阵、复活丹、血池、肉身容器、尸体、族群祭坛、法宝空间、秘境环境或天生轮回规则。

接管方式：非常详细写。写清原神魂如何保存、如何进入新身体或旧身体，复活后是否需要重新修炼，记忆何时恢复，身体与神魂如何匹配，是否需要适应期，是否会被旧因果、旧敌人、旧契约或旧伤牵连。

目标反抗：如果新身体原本有意识，写清其是否反抗、被压制、融合或消失；如果没有目标意识，写“无独立目标意识”或“原文未说明”。

成功结果：写清是否恢复原身份、原记忆、原修为、原法宝、原关系网、原寿元，还是以新身份重新开始。

失败后果：写清复活失败、魂魄消散、记忆缺失、肉身崩坏、修为尽失、变成怪物、被召唤者控制或被旧敌发现。

身份处理：写清复活后是否公开旧身份，是否继续使用新身份，是否回归原势力，是否继承旧债、旧仇、旧职务和旧关系。

记忆与人格变化：写清记忆是否完整、是否分阶段苏醒、是否与新身体记忆冲突、人格是否变化、执念是否加重。

关系后果：写清亲友是否承认、旧敌是否追杀、宗门或家族是否接纳、继承权是否争议、旧恋旧怨是否延续。

弱点：写清是否怕记忆未醒、修为低谷、身体不适配、复活材料不足、旧敌追踪、魂魄不稳、轮回禁制、因果反噬或复活媒介被毁；原文未说明则写“原文未说明”。

结局或后续影响：写清转世者是否找回旧身份、复仇、重建势力、放弃前世、被旧因果拖累，或成为新剧情引线。

### 案例 4：身外化身 / 傀儡身体 / 替身身体

名字和类型：写具体人物、化身、傀儡、分身、替身身体或炼制路线名称。

发起者：写清创造或操控化身的人是谁，修为、目的、神魂分裂状态、是否本体存活。

目标：写清化身或身体来源，是炼制傀儡、尸体改造、分魂寄托、血肉重塑、法宝化身，还是他人身体改造。

发起原因：写清是为了保命、远程行动、试探危险、修炼分身、替死、隐匿身份、延寿、执行任务或保存传承。

前置条件：写清分魂能力、材料、肉身强度、傀儡术、炼器术、血脉材料、控制距离、修为限制、同步条件和维护消耗。

媒介条件：写清傀儡核心、分魂法器、替身符、尸体、血肉材料、阵法、灵石、法宝、控制印记或本命联系。

接管方式：非常详细写。写清神魂如何分出或转移，如何操控化身，化身是否有自我意识，能否远程共享感知，受伤是否反馈本体，死亡是否影响本体，化身如何维护、修复、升级或隐藏身份。

目标反抗：如果化身材料或傀儡身体原本有意识，写清其是否反抗、残留执念、反噬操控者或被他人夺控；没有则写“原文未说明”。

成功结果：写清化身能执行哪些行动，保留多少修为、记忆、法术、法宝使用能力，是否能替本体死亡或承担风险。

失败后果：写清分魂受创、本体反噬、化身失控、傀儡崩坏、身份暴露、材料浪费、被敌人追踪到本体。

身份处理：写清化身是否以独立身份活动，是否被他人当成真人，是否能继承本体关系，是否需要掩饰与本体的联系。

记忆与人格变化：写清化身是否共享记忆，是否形成独立人格，是否背叛本体，是否因长期分离出现认知差异。

关系后果：写清化身暴露后对本体声誉、宗门关系、敌对关系、师徒信任、同伴判断的影响。

弱点：写清是否怕控制核心被毁、分魂联系被切断、距离限制、材料缺陷、傀儡术克制、追踪本体、独立意识反叛或维护资源不足；原文未说明则写“原文未说明”。

结局或后续影响：写清化身是否被毁、独立、回归本体、替死、背叛、升级为新个体，或引发身份误会和追杀。

### 案例 5：血脉重塑 / 肉身改造 / 借尸还魂

名字和类型：写具体人物、仪式、族群、肉身改造法或借尸还魂案例名称。

发起者：写清是谁主导重塑或借尸，是本人、家族、邪修、医修、魔道组织、族群祭司，还是外部强者。

目标：写清被改造或借用的身体来源，是尸体、濒死者、血脉后裔、妖兽肉身、傀儡身体、人造身体或特殊容器。

发起原因：写清是为了修复肉身、换血脉、延寿、逃避死亡、突破瓶颈、伪装身份、改造族群，还是制造兵器。

前置条件：写清需要的血脉材料、尸体完整度、魂魄保存、肉身强度、药材、丹药、阵法、祭品、族群秘法、炼体基础或医术。

媒介条件：写清血池、药池、炼体阵、缝合术、丹药、法宝、祭坛、妖兽精血、家族血脉、尸体、傀儡核心或秘境环境。

接管方式：非常详细写。写清神魂如何进入新肉身，血脉如何重塑，旧肉身如何处理，新身体如何适配，是否需要药浴、阵法、祭祀、缝合、炼体、稳定期，是否有痛苦、排异、异化、失控或外貌变化。

目标反抗：如果身体原主残留神魂或执念，写清其是否反抗、污染、融合或影响新主人；没有则写“原文未说明”。

成功结果：写清是否获得新血脉、新资质、新寿元、新外貌、新战力、新身份，是否保留原修为和记忆。

失败后果：写清肉身崩坏、血脉污染、神魂排异、变成怪物、记忆丢失、寿元折损、被仪式反噬或被操控者控制。

身份处理：写清新肉身是否被认出，是否冒用他人身份，是否回归原势力，是否被家族或宗门承认。

记忆与人格变化：写清是否保持原人格，是否受血脉、身体原主、妖兽本能、尸气或改造材料影响。

关系后果：写清亲友是否接受，宗门是否追查，家族是否争夺，受害者关系网是否复仇，社会是否视为禁术或邪修。

弱点：写清是否怕血脉排异、身体腐坏、神魂不稳、丹药断供、阵法被破、肉身来源暴露、原主执念反噬、妖兽本能失控或医治失败；原文未说明则写“原文未说明”。

结局或后续影响：写清新身体是否稳定，是否留下后遗症，是否引发追杀、伦理争议、家族继承变化、身份混乱或新的修炼路线。
