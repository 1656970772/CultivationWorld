# 夺舍设定分析模板

# 规范

用于整理作品中的夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等身体或身份接管机制。

- 样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角特例或成功案例。
- 案例只是最低写法示范，不是数量上限；原文中有价值的夺舍、附身、复活、身体接管或身份接管机制应继续展开。
- 不把所有“复活”“转世”“重生”都称为夺舍，必须按原文机制区分。
- 不把主角开局、特殊体质或唯一传承直接当成普通 NPC 可用机制；若是特例，要写清特殊性。
- 原文没有说明的发起者、目标、媒介、条件、接管方式、反抗方式、身份处理、记忆人格变化、弱点或后续影响，写“原文未说明”。
- 信息不足但值得追踪的对象放入 `### 待定案例`；补充信息时按该区格式追加摘要，转正式案例前复核待定记录。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 名字和类型：写具体人物、组织、法宝、仪式或身体名称，以及机制类型；机制类型可包括夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等。
- 发起者：写身份、修为、神魂状态，是否濒死、残魂、被封印或有同伙。
- 目标：写目标身体或宿主的资质、境界、肉身、神魂、关系和被选中原因。
- 发起原因：写延寿、复活、逃避死亡、重获肉身、夺取资质、继承身份、突破、复仇或执念等动机。
- 前置条件：写境界差、神魂强度、虚弱状态、信任关系、体质、血脉、灵根、时间、地点等必要条件；不明时写“原文未说明”。
- 媒介条件：写法宝、阵法、丹药、禁术、魂牌、血契、尸体、傀儡、祭坛、转生胎体等承载或触发媒介；不明时写“原文未说明”。
- 接管方式：本模板重点，写清接近目标、伪装诱骗、培养或削弱、进入神魂或肉身、压制原主人、融合或替换身份、遮掩痕迹，以及失败或中断后果。
- 目标反抗：写神魂反击、护身宝物、外力干预、镇魂法器、血脉排异、意志抵抗、同归于尽等反制方式；没有反抗时写“原文未说明”。
- 结果与后果：写成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、结局或后续影响。

### 案例

```md
# 《作品名》夺舍设定分析

## 夺舍设定卡片

### 机制名称

- 名字和类型：
- 发起者：
- 目标：
- 发起原因：
- 前置条件：
- 媒介条件：
- 接管方式：
- 目标反抗：
- 结果与后果：

### 高阶修士夺舍低阶修士

- 名字和类型：写具体人物或组织名称；机制类型为夺舍、神魂接管或肉身接管，按原文称呼填写。
- 发起者：高阶修士、邪修、魔头或濒死残魂；写身份、境界、神魂状态和是否有同伙。
- 目标：低阶修士、弟子、仇敌后人或特定体质者；写资质、境界、肉身、神魂、关系和被选中原因。
- 发起原因：延寿、逃避死亡、夺取资质、继承身份、突破、复仇或执念。
- 前置条件：境界差、目标虚弱、信任关系、特殊体质、指定时间地点或护身手段失效。
- 媒介条件：禁术、魂牌、阵法、丹药、祭坛、封印空间或引魂法器等。
- 接管方式：接近目标、伪装诱骗、培养或削弱目标，进入识海或肉身，压制原主人，抢夺控制权，融合记忆，稳定身体并遮掩痕迹；写清失败或中断后果。
- 目标反抗：神魂反击、护身宝物、镇魂法器、外力干预、意志抵抗或同归于尽。
- 结果与后果：写成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、结局或后续影响。

### 残魂寄宿 / 器灵附体

- 名字和类型：写具体残魂、器灵、古修、魔头、法宝或宿主名称；机制类型为残魂寄宿、器灵附体或临时接管。
- 发起者：寄宿残魂、器灵、古修意识、魔头意识或秘境意志；写其神魂状态、封印状态和真实目的。
- 目标：宿主、法宝持有者、契约者或被迫承载者；写其为何能承载，是否主动接受、被骗接受、被迫承载或无意触发。
- 发起原因：保命、复苏、寻找传人、借宿恢复、影响宿主、临时行动或等待重获肉身。
- 前置条件：宿主神魂强度、契约关系、认主仪式、血契、封印松动、濒死状态或特定体质。
- 媒介条件：戒指、玉佩、剑器、魂牌、古宝、傀儡、封印石、秘境核心、血契或法宝认主仪式等。
- 接管方式：与宿主沟通，隐藏或公开身份，影响决策，必要时临时接管身体；写清接管消耗、持续时间、限制和解除方式。
- 目标反抗：宿主拒绝沟通、切断契约、镇压器灵、外力封印、神魂抵抗或借助法器压制。
- 结果与后果：写宿主是否虚弱、失忆、人格变化、神魂受损、关系改变，以及寄宿者是否恢复、沉睡、消散或反客为主。

### 转世 / 重生 / 复活

- 名字和类型：写具体人物或族群名称；机制类型为转世、重生、复活、轮回归来或血脉复生。
- 发起者：本人布局、同伴施法、族群仪式、外力干预、天道轮回或法宝保命；写参与者和主导者。
- 目标：新身体、新身份、胎体、尸体、傀儡身体、血脉后裔或复活容器；写肉身和神魂是否匹配。
- 发起原因：重获生命、延续传承、完成执念、躲避追杀、复仇、突破限制或承担族群使命。
- 前置条件：魂魄保存、轮回契机、血脉牵引、阵法完成、旧身死亡、时间窗口或特定地点。
- 媒介条件：法阵、法宝、魂灯、血脉秘术、转生胎体、复活容器、祭坛、丹药或外力灌注。
- 接管方式：魂魄保存并进入身体，复活后重新适应或重修，按阶段恢复记忆，处理身体与神魂的适配期。
- 目标反抗：新身体排异、旧意识残留、血脉冲突、记忆封锁、外力阻断或旧敌干扰。
- 结果与后果：写记忆恢复、修为变化、旧因果牵连、旧敌追索、旧契约延续、旧伤复发和身份处理。

### 身外化身 / 傀儡身体 / 替身身体

- 名字和类型：写具体人物、化身、傀儡、分身、替身身体或炼制路线名称；机制类型为身外化身、傀儡身体或替身身体。
- 发起者：创造或操控化身的人、组织、器灵或禁术使用者；写本体状态和操控目的。
- 目标：化身、分身、傀儡、替身身体、法宝化身或临时容器；写其材质、意识状态和可承载程度。
- 发起原因：保命、远程行动、试探危险、替死、隐匿身份、执行任务或保存传承。
- 前置条件：分魂能力、神识强度、炼制材料、控制距离、契约绑定、维护条件或本体存活。
- 媒介条件：傀儡核心、分魂秘术、法宝化身、替身符、魂印、控制令牌、机关结构或炼制阵法。
- 接管方式：分出或转移神魂，建立控制联系，远程操控化身，共享感知或命令行动；写清是否有自我意识和接管中断后果。
- 目标反抗：化身自我意识反噬、傀儡失控、控制被切断、魂印被破、外力夺控或本体受创。
- 结果与后果：写受伤或死亡是否反馈本体，化身如何维护、修复、升级、隐藏身份，以及损毁后的后续影响。

### 血脉重塑 / 肉身改造 / 借尸还魂

- 名字和类型：写具体人物、仪式、族群、肉身改造法或借尸还魂案例名称；机制类型为血脉重塑、肉身改造或借尸还魂。
- 发起者：主导重塑或借尸的人、组织、邪修、族群、医修或禁术使用者；写其目的和控制程度。
- 目标：尸体、濒死者、血脉后裔、妖兽肉身、傀儡身体、人造身体或特殊容器；写适配程度和身份关系。
- 发起原因：修复肉身、换血脉、延寿、逃避死亡、突破、伪装身份、改造族群或制造兵器。
- 前置条件：神魂适配、血脉相近、身体完整、目标虚弱、阵法准备、药材齐备、稳定期或祭祀条件。
- 媒介条件：药浴、阵法、祭坛、血脉秘术、缝合术、炼体法、尸体容器、妖兽材料或人造身体。
- 接管方式：神魂进入新肉身，重塑血脉，处理旧肉身，使新身体逐步适配；写清稳定期、痛苦、排异、异化、失控或外貌变化。
- 目标反抗：血脉排异、神魂不合、旧意识残留、身体崩溃、外力干预、祭祀失败或容器反噬。
- 结果与后果：写成功后的能力变化、身份处理、弱点、副作用、后续修炼限制、关系后果和最终结局。
```
