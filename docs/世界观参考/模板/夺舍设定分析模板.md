# 夺舍设定分析模板

## 适用范围

本模板用于整理小说中的夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等身体、神魂或身份接管机制。

不把所有“复活”“转世”“重生”都称为夺舍，必须按原文机制区分。不把普通控制、胁迫、监视、药物限制、修炼异常、心魔干扰或单纯法宝辅助直接写成夺舍卡片；这类内容只能作为前置条件、关联控制手段或待定线索。

主角开局、特殊体质、唯一传承或一次性奇遇不能默认视为普通 NPC 可复用机制。若是特例，要写清特殊性、限制和不可复制之处。

## 整理原则

1. 先判定是否属于本模板  
   只有涉及意识、神魂、人格或记忆进入、占据、共享、替换、融合或远程控制某个身体或载体的机制，才进入本模板。普通胁迫、药物控制、心魔干扰、假死、疗伤和无意识法器辅助不单独建卡。

2. 先确定主体关系  
   分清发起者、身体或载体、原意识、协助者，以及接管后是否形成新主体。进入身体不等于取得控制，取得控制也不等于原意识已经消失。

3. 区分机制规则和具体个案  
   机制规则写某类接管通常需要什么、怎样运行；具体个案写某次接管由谁发起、经过什么过程、最后怎样结束。单一个案不能自动视为通用规则。

4. 按过程整理，但不机械补齐  
   依次检查发起条件、媒介准备、进入、争夺或协商、稳定或中断、长期运行和终止。只填写原文实际出现的环节，没有的环节写“不适用”或直接省略。

5. 区分内部状态和外部表现  
   内部写身体控制、意识关系、记忆访问、人格变化和神魂损伤；外部写语言习惯、能力变化、身份异常、关系反应和可检测表现。外部表现不能单独决定内部机制。

6. 区分正常、异常和极端状态  
   正常状态写稳定独占、稳定共存、轮流控制或稳定连接；异常状态写记忆串扰、控制失灵、人格混合、身体排异和身份暴露；极端状态写反客为主、神魂崩坏、载体毁灭或不可逆融合。

7. 分开记录成本、限制和失败  
   成本是实施或维持时必然支付的消耗；限制是目标、距离、次数、时机和兼容条件；失败结果是反噬、接管中断、原意识反杀、身体死亡或无法再次转移。

8. 追踪身份与后续变化  
   接管完成后继续判断修为、技能、记忆、人格、契约、因果、血脉资格、社会身份和责任如何延续，并记录衰退、退出、逆转、再次转移和最终终止。

9. 保持信息边界并控制篇幅  
   将内容区分为原文明确、谨慎归纳、原文未说明和不适用。只保留能够判断机制性质、运行过程和结果的信息；同一内容不在多个字段重复填写，特殊个案不自动推广为普遍规则。

## 字段说明

- 卡片类型与机制归类：写机制规则总览或具体个案，并填写原文称谓、模板归类、收录结论，以及为什么属于夺舍、寄宿、共存、转世、复活、化身或其他相邻机制。
- 参与主体与载体：明确谁在接管什么，以及接管前各方的状态。
  - 发起者：
  - 身体或载体：
  - 原意识：
  - 协助者或干预者：
- 发起条件与目的：写发起原因、目标选择理由，以及境界、神魂、体质、生死状态、时间或环境等前置条件。
- 接管媒介与方式：写使用的术法、阵法、法宝、契约、分魂或其他媒介，以及进入、寄宿、替换、共享、融合或远程控制的方式。
- 接管过程：按实际出现的阶段简要整理。
  - 准备：
  - 进入：
  - 争夺或协商：
  - 稳定、中断或退出：
- 控制与意识状态：写接管实际达到的程度。
  - 身体控制：
  - 意识关系：
  - 原意识结局：
  - 控制切换与可逆性：
- 记忆、人格与能力变化：写记忆能否访问或继承、人格是否受影响，以及功法、技能、修为和特殊能力能否继续使用。
- 适配与维持：写神魂与身体的兼容程度、适配期、维持条件、持续消耗、失稳征兆和暴露风险。
- 反抗、排异与外部干预：写原意识反抗、身体或血脉排异、护身手段、外部人物或环境干预，以及这些因素怎样改变结果。
- 成本、限制与失败风险：分别写实施和维持成本、目标与时机限制、失败条件，以及反噬、损伤、失控或死亡等风险。
- 正常、异常与极端状态：只记录原文实际出现的状态。
  - 正常状态：
  - 异常状态：
  - 极端状态：
- 结果、身份与后续：汇总接管完成或失败后的直接结果和长期变化。
  - 各方结果：
  - 身份、关系与责任：
  - 后续成长或衰退：
  - 退出、逆转或终止：
  - 遗留影响：
- 信息边界：分别填写原文明确、谨慎归纳、原文未说明和不适用；角色认知与实际机制不一致时分开记录。

```md
### 寿尽修士夺舍受伤弟子

- 卡片类型与机制归类：具体个案；原文称为“夺舍”，属于外来神魂永久接管活人肉身。
- 参与主体与载体：
  - 发起者：寿元耗尽、原身已毁的高阶修士残魂。
  - 身体或载体：重伤昏迷的年轻弟子肉身。
  - 原意识：进入前仍然存活，但神魂虚弱。
  - 协助者或干预者：无。
- 发起条件与目的：残魂需要在消散前取得新身体；目标体质相近、神魂虚弱且处于孤立状态。
- 接管媒介与方式：残魂借寄魂玉保存神魂，进入目标识海后压制原意识并取得身体控制。
- 接管过程：
  - 准备：残魂伪装成传承，引导目标接触寄魂玉。
  - 进入：目标重伤后识海防御减弱，残魂趁机进入。
  - 争夺或协商：双方在识海中争夺控制权，原意识反抗失败。
  - 稳定、中断或退出：残魂封闭原意识核心，逐步适应肉身。
- 控制与意识状态：
  - 身体控制：发起者独占。
  - 意识关系：外来意识主导，原意识无法与外界沟通。
  - 原意识结局：被压制但尚未消散。
  - 控制切换与可逆性：不能主动切换；是否可以剥离原文未说明。
- 记忆、人格与能力变化：发起者取得部分宿主记忆，可模仿其日常习惯；原有修炼经验保留，但修为受新身体限制。
- 适配与维持：初期经脉不适配，需重新修炼；情绪反应和口癖差异可能暴露身份。
- 反抗、排异与外部干预：原意识持续抵抗，使发起者偶尔出现记忆错乱；肉身没有明显血脉排异。
- 成本、限制与失败风险：发起者损失部分神魂力量；若适配完成前神魂再次受创，原意识可能重新夺回控制。
- 正常、异常与极端状态：
  - 正常状态：发起者稳定控制身体并使用宿主身份。
  - 异常状态：旧记忆触发原意识反应，造成短时失神。
  - 极端状态：双方神魂同时受损，可能导致身体失控或死亡。
- 结果、身份与后续：
  - 各方结果：发起者暂时延续生命，原意识被压制，肉身继续存活。
  - 身份、关系与责任：外界仍将其视为原宿主，亲近者开始察觉性格变化。
  - 后续成长或衰退：发起者需按新身体重新恢复修为。
  - 退出、逆转或终止：解除方式原文未说明。
  - 遗留影响：宿主记忆与发起者人格持续发生串扰。
- 信息边界：
  - 原文明确：进入方式、控制结果和原意识仍然存在。
  - 谨慎归纳：性格异常可能来自记忆串扰。
  - 原文未说明：原意识能否最终恢复。
  - 不适用：主动共存和轮流控制。

### 残魂与宿主契约共存

- 卡片类型与机制归类：具体个案；属于残魂寄宿和有限身体接管，不属于原意识被替换的成功夺舍。
- 参与主体与载体：
  - 发起者：寄存在古戒中的残魂。
  - 身体或载体：古戒持有者的肉身。
  - 原意识：始终清醒并保有默认控制权。
  - 协助者或干预者：契约由双方自愿建立。
- 发起条件与目的：残魂需要借宿恢复，宿主需要残魂的战斗经验；双方以互利为目的。
- 接管媒介与方式：以古戒为寄魂载体，通过神魂契约在特定时段让渡身体控制权。
- 接管过程：
  - 准备：双方确认接管时限和宿主的收回权。
  - 进入：残魂通过契约连接宿主识海。
  - 争夺或协商：正常情况下不存在争夺，每次接管需双方同意。
  - 稳定、中断或退出：接管结束后残魂退回古戒，宿主恢复控制。
- 控制与意识状态：
  - 身体控制：双方轮流控制，同一时刻只有一方主导。
  - 意识关系：双方可以在识海中交流，非主控方保持感知。
  - 原意识结局：完整保留。
  - 控制切换与可逆性：可按契约切换，宿主具有优先收回权。
- 记忆、人格与能力变化：感知和战斗经验可以共享，私人记忆默认隔离；长期共存造成轻微口癖和情绪影响。
- 适配与维持：残魂只能使用宿主肉身能够承受的力量；维持寄宿需要宿主定期供养神魂。
- 反抗、排异与外部干预：宿主可通过封闭古戒阻止接管；外部封魂手段会同时削弱双方。
- 成本、限制与失败风险：每次接管有时间限制；宿主重伤或契约破损时可能发生控制权失灵。
- 正常、异常与极端状态：
  - 正常状态：双方依约轮换，意识边界清楚。
  - 异常状态：重伤时发生非主动切换和记忆串扰。
  - 极端状态：契约彻底破裂后可能出现夺权、融合或双魂受损。
- 结果、身份与后续：
  - 各方结果：宿主获得经验，残魂获得恢复机会。
  - 身份、关系与责任：对外身份仍属于宿主，残魂主控期间的责任归属未明。
  - 后续成长或衰退：残魂逐渐恢复，宿主的神魂负担随之增加。
  - 退出、逆转或终止：可解除契约并让残魂退回古戒。
  - 遗留影响：分离后仍可能保留部分共享记忆和行为习惯。
- 信息边界：
  - 原文明确：双方均保有意识、控制时限和宿主收回权。
  - 谨慎归纳：长期情绪影响尚未达到人格融合。
  - 原文未说明：契约破裂后的最终结果。
  - 不适用：原意识消散和永久身份替换。

```
