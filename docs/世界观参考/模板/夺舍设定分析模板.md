# 夺舍设定分析模板

## 适用范围

用于整理作品中的夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等身体或身份接管机制。

最终输出只按本模板的案例格式和字段写，不额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

- 样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角特例或成功案例。
- 案例只是最低写法示范，不是数量上限；原文中有价值的夺舍、附身、复活、身体接管或身份接管机制应继续展开。
- 不把所有“复活”“转世”“重生”都称为夺舍，必须按原文机制区分。
- 不把主角开局、特殊体质或唯一传承直接当成普通 NPC 可用机制；若是特例，要写清特殊性。
- 原文没有说明的发起者、目标、媒介、条件、接管方式、反抗方式、身份处理、记忆人格变化、弱点或后续影响，写“原文未说明”。
- 信息不足但值得追踪的对象放入 `### 待定案例`；补充信息时在同一项追加摘要和来源，转正式案例前复核全部来源。

## 必须写什么

本部分是“参考整理范围/字段提示”，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
|------|------|------|
| 夺舍 / 附身 | 高阶修士、邪修、魔头、残魂接管低阶修士 | 写清发起者如何削弱目标、进入识海或肉身、压制原主人。 |
| 残魂寄宿 / 器灵附体 | 戒指残魂、法宝器灵、古修意识、秘境意志 | 写清媒介、沟通方式、影响宿主和临时接管限制。 |
| 转世 / 重生 / 复活 | 轮回归来、法阵复活、血脉复生、外力复活 | 写清魂魄保存、身体来源、记忆恢复和旧因果牵连。 |
| 身外化身 / 傀儡身体 | 分身、替身、傀儡、法宝化身 | 写清分魂、控制距离、共享感知、损毁反馈和本体风险。 |
| 血脉重塑 / 借尸还魂 | 换血、肉身改造、尸体容器、人造身体 | 写清神魂适配、血脉排异、稳定期和身份处理。 |

正式案例建议字段：

- **名字和类型**：写具体人物、组织、法宝、仪式或身体名称，以及机制类型。
- **发起者**：身份、修为、神魂状态、是否濒死、残魂、被封印、是否有同伙。
- **目标**：目标身体或宿主的资质、境界、肉身、神魂、关系和被选中原因。
- **发起原因**：延寿、复活、逃避死亡、重获肉身、夺取资质、继承身份、突破、复仇或执念。
- **前置条件**：境界差、神魂强度、虚弱状态、信任关系、体质、血脉、灵根、时间、地点等。
- **媒介条件**：法宝、阵法、丹药、禁术、魂牌、血契、尸体、傀儡、祭坛、转生胎体等。
- **接管方式**：本模板重点。写清接近目标、伪装诱骗、培养或削弱、进入神魂或肉身、压制原主人、融合或替换身份、遮掩痕迹、失败或中断后果。
- **目标反抗**：神魂反击、护身宝物、外力干预、镇魂法器、血脉排异、意志抵抗、同归于尽等。
- **结果与后果**：成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、结局或后续影响。

## 案例

### 案例

#### 案例 1：高阶修士夺舍低阶修士

名字和类型：写具体人物或组织名称，以及机制类型；原文没有明确称呼时按行为描述填写。

写法重点：发起者、目标、发起原因、前置条件、媒介条件、接管方式、目标反抗、成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、结局或后续影响。

接管方式重点：写清如何接触目标、进入识海或肉身、压制神魂、抢夺控制权、融合记忆、稳定身体，以及被打断会怎样。

#### 案例 2：残魂寄宿 / 器灵附体

名字和类型：写具体残魂、器灵、古修、魔头、法宝或宿主名称，以及残魂寄宿、器灵附体等类型。

写法重点：寄宿者是谁，宿主为何能承载，是否主动接受、被骗接受、被迫承载或无意触发；媒介是戒指、玉佩、剑器、魂牌、古宝、傀儡、封印石、秘境核心、血契或法宝认主仪式等。

接管方式重点：写清寄宿者如何与宿主沟通，是否隐藏身份，如何影响决策，能否临时接管身体，接管消耗什么，宿主是否虚弱、失忆、人格变化或神魂受损。

#### 案例 3：转世 / 重生 / 复活

名字和类型：写具体人物或族群名称，以及转世、重生、复活、轮回归来等类型。

写法重点：是谁转世或复活，是本人布局、外力复活、天道轮回、族群仪式、法宝保命，还是特殊血脉能力；新身体、新身份、胎体、尸体、傀儡身体、血脉后裔或复活容器是什么。

接管方式重点：写清魂魄如何保存并进入身体，复活后是否重修，记忆何时恢复，身体与神魂如何匹配，是否有适应期，以及旧因果、旧敌、旧契约或旧伤如何牵连。

#### 案例 4：身外化身 / 傀儡身体 / 替身身体

名字和类型：写具体人物、化身、傀儡、分身、替身身体或炼制路线名称。

写法重点：创造或操控化身的人是谁，化身来源是什么，为何用于保命、远程行动、试探危险、替死、隐匿身份、执行任务或保存传承。

接管方式重点：写清神魂如何分出或转移，如何操控化身，是否有自我意识，能否远程共享感知，受伤或死亡是否反馈本体，化身如何维护、修复、升级或隐藏身份。

#### 案例 5：血脉重塑 / 肉身改造 / 借尸还魂

名字和类型：写具体人物、仪式、族群、肉身改造法或借尸还魂案例名称。

写法重点：谁主导重塑或借尸，身体来源是尸体、濒死者、血脉后裔、妖兽肉身、傀儡身体、人造身体还是特殊容器；目的是修复肉身、换血脉、延寿、逃避死亡、突破、伪装身份、改造族群或制造兵器。

接管方式重点：写清神魂如何进入新肉身，血脉如何重塑，旧肉身如何处理，新身体如何适配，是否需要药浴、阵法、祭祀、缝合、炼体、稳定期，以及是否有痛苦、排异、异化、失控或外貌变化。
