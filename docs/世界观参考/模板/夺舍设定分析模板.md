# 夺舍设定分析模板

## 适用范围

本模板用于整理小说中的夺舍、附身、残魂寄宿、器灵附体、转世、重生、复活、身外化身、傀儡身体、血脉重塑、借尸还魂等身体、神魂或身份接管机制。

不把所有“复活”“转世”“重生”都称为夺舍，必须按原文机制区分。不把普通控制、胁迫、监视、药物限制、修炼异常、心魔干扰或单纯法宝辅助直接写成夺舍卡片；这类内容只能作为前置条件、关联控制手段或待定线索。

主角开局、特殊体质、唯一传承或一次性奇遇不能默认视为普通 NPC 可复用机制。若是特例，要写清特殊性、限制和不可复制之处。

## 整理原则

1. 一机制一卡  
   同一人物、同一组织或同一机制链条中的观察、准备、施术、反抗、结果，必须合并到同一张机制卡。  
   禁止另建“某某（补充）”“某某前期”“某某后续”等重复卡；阶段变化写入同卡的“接管方式”或“结果与后果”。

2. 字段完整  
   每张卡必须包含：机制定位、原文称谓与模板归类、机制判定、是否真正接管、发起者、目标/宿主、原意识状态、发起原因、前置条件、媒介条件、接管方式、目标反抗、结果与后果、边界说明。  
   无依据时写“原文未说明”；没有明显反抗、变化或后果时写“原文未说明明显变化”。禁止空字段。

3. 候选先判定  
   直接涉及夺舍、附体、残魂、灵魂体、转世、重生、复活、分身、化身、傀儡、魂魄已失、寄宿、融合、占据等机制词或机制过程的内容，必须先进入候选梳理。  
   候选只分为“收录”“排除”“待定”三类：收录项写成正式机制卡；排除项和待定项只在候选梳理中简要说明原因。

4. 机制边界清楚  
   必须区分真正身体/神魂接管、临时影响、寄宿共存、替换原意识、身份继承、肉身改造、控制胁迫、监视跟踪、修炼副作用和疑似媒介。  
   关联控制手段可以写入卡片字段，但不能冒充机制本体。

5. 规则级设定单列  
   夺舍限制、灵魂体风险、转世条件、复活代价、化身反馈、傀儡失控、原意识融合等可复用世界观规则，必须单独写入“规则级设定”。  
   规则级设定优先写成通用规则，不要只停留在单个事件复述。

6. 粒度可控  
   样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局；不要只写主角特例或成功案例。  
   疑似线索不得压过正式机制；若疑似内容过多，应合并为“疑似线索”并优先说明为什么暂不收录为正式卡。

7. 输出简化  
   保留机制判断所需的关键过程、限制、反抗和后果，不展开无关剧情背景。  
   不为补齐字段虚构发起者、目标、媒介、条件、身份处理、记忆人格变化、弱点或后续影响。

## 字段说明

- 机制定位：写具体人物、组织、法宝、仪式、身体或族群名称，以及该机制在剧情中的功能，如复活、夺取资质、延寿、保命、远程行动、制造兵器等。
- 原文称谓与模板归类：写原文对该机制的称呼，以及模板中的归类；例如原文称“灵魂体”，模板可归类为“残魂寄宿”或“复活前置状态”。
- 机制判定：写“实锤机制”“高置信推断”或“疑似待定”。“关联但非接管”不写成正式卡，只在候选梳理中简要说明。
- 是否真正接管：写未接管、临时影响、寄宿共存、夺取控制权、替换原意识、融合共生、重塑身份等状态。
- 发起者：写身份、修为、神魂状态、肉身状态、是否濒死、残魂、被封印、受操控或有同伙。
- 目标/宿主：写目标身体、宿主、胎体、尸体、傀儡、化身、血脉后裔或复活容器的资质、境界、肉身、神魂、关系和被选中原因。
- 原意识状态：写存活反抗、被压制、融合、消散、已死、失忆、沉睡、残留或原文未说明。
- 发起原因：写延寿、复活、逃避死亡、重获肉身、夺取资质、继承身份、突破、复仇、完成执念、保存传承等动机。
- 前置条件：写境界差、神魂强度、目标虚弱、信任关系、体质、血脉、灵根、契约、死亡状态、特定时机、地点条件等必要条件；不明时写“原文未说明”。
- 媒介条件：写法宝、阵法、丹药、禁术、魂牌、血契、尸体、傀儡、祭坛、转生胎体、复活容器等承载或触发媒介；不明时写“原文未说明”。
- 接管方式：写接近目标、伪装诱骗、培养或削弱、进入神魂或肉身、压制原主人、融合或替换身份、稳定身体、遮掩痕迹，以及失败或中断后果。
- 目标反抗：只写被接管身体、宿主或原意识的反抗，如神魂反击、护身宝物、外力干预、镇魂法器、血脉排异、意志抵抗、同归于尽等；其他关联人物的行动不要误写成目标反抗。
- 结果与后果：写成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、副作用、修炼限制、结局或后续影响。
- 边界说明：写为什么纳入本模板，以及为什么不是普通控制、药物胁迫、监视、修炼异常或单纯法宝辅助。

## 夺舍设定卡片

### 高阶修士夺舍低阶修士

- 机制定位：写具体人物或组织名称；机制功能为延寿、夺取资质、逃避死亡、继承身份或复仇等。
- 原文称谓与模板归类：按原文称呼填写；模板归类可写夺舍、神魂接管、肉身接管或身份替换。
- 机制判定：写实锤机制、高置信推断或疑似待定。
- 是否真正接管：写未接管、夺取控制权、替换原意识、融合共生或原文未说明。
- 发起者：高阶修士、邪修、魔头或濒死残魂；写身份、境界、神魂状态和是否有同伙。
- 目标/宿主：低阶修士、弟子、仇敌后人或特定体质者；写资质、境界、肉身、神魂、关系和被选中原因。
- 原意识状态：写存活反抗、被压制、融合、消散、已死或原文未说明。
- 发起原因：延寿、逃避死亡、夺取资质、继承身份、突破、复仇或执念。
- 前置条件：境界差、目标虚弱、信任关系、特殊体质、指定时间地点或护身手段失效。
- 媒介条件：禁术、魂牌、阵法、丹药、祭坛、封印空间或引魂法器等。
- 接管方式：接近目标、伪装诱骗、培养或削弱目标，进入识海或肉身，压制原主人，抢夺控制权，融合记忆，稳定身体并遮掩痕迹；写清失败或中断后果。
- 目标反抗：神魂反击、护身宝物、镇魂法器、外力干预、意志抵抗或同归于尽。
- 结果与后果：写成功结果、失败后果、身份处理、记忆与人格变化、关系后果、弱点、结局或后续影响。
- 边界说明：说明该机制为什么属于夺舍或神魂接管；若只存在药物控制、监视、恐吓或修炼异常，不写成正式机制卡。

### 残魂寄宿 / 器灵附体

- 机制定位：写具体残魂、器灵、古修、魔头、法宝或宿主名称；机制功能为保命、复苏、寻找传人、临时行动或等待重获肉身等。
- 原文称谓与模板归类：区分原文称谓与模板归类；例如灵魂体、器灵、残念、古修意识、秘境意志等。
- 机制判定：写实锤机制、高置信推断或疑似待定。
- 是否真正接管：写寄宿共存、临时影响、临时接管、反客为主、未接管或原文未说明。
- 发起者：寄宿残魂、器灵、古修意识、魔头意识或秘境意志；写其神魂状态、封印状态和真实目的。
- 目标/宿主：宿主、法宝持有者、契约者或被迫承载者；写其为何能承载，是否主动接受、被骗接受、被迫承载或无意触发。
- 原意识状态：写清宿主意识是否清醒、是否能拒绝、是否被压制或是否与寄宿者共存。
- 发起原因：保命、复苏、寻找传人、借宿恢复、影响宿主、临时行动或等待重获肉身。
- 前置条件：宿主神魂强度、契约关系、认主仪式、血契、封印松动、濒死状态或特定体质。
- 媒介条件：戒指、玉佩、剑器、魂牌、古宝、傀儡、封印石、秘境核心、血契或法宝认主仪式等。
- 接管方式：与宿主沟通，隐藏或公开身份，影响决策，必要时临时接管身体；写清接管消耗、持续时间、限制和解除方式。
- 目标反抗：宿主拒绝沟通、切断契约、镇压器灵、外力封印、神魂抵抗或借助法器压制。
- 结果与后果：写宿主是否虚弱、失忆、人格变化、神魂受损、关系改变，以及寄宿者是否恢复、沉睡、消散或反客为主。
- 边界说明：说明该机制为什么不只是普通法宝辅助；若没有意识、沟通、寄宿或接管迹象，应写入待定项。

### 转世 / 重生 / 复活

- 机制定位：写具体人物、族群、仪式或复活路线名称；机制功能为重获生命、延续传承、躲避追杀、复仇或承担族群使命等。
- 原文称谓与模板归类：按原文称呼填写；模板归类可写转世、重生、复活、轮回归来、血脉复生或借体重生。
- 机制判定：写实锤机制、高置信推断或疑似待定。
- 是否真正接管：写新生身体、借体重生、原意识已死、融合共生、替换原意识或原文未说明。
- 发起者：本人布局、同伴施法、族群仪式、外力干预、天道轮回或法宝保命；写参与者和主导者。
- 目标/宿主：新身体、新身份、胎体、尸体、傀儡身体、血脉后裔或复活容器；写肉身和神魂是否匹配。
- 原意识状态：写旧身体意识、目标身体意识或新生意识的状态；不要把无关人物误写为宿主。
- 发起原因：重获生命、延续传承、完成执念、躲避追杀、复仇、突破限制或承担族群使命。
- 前置条件：魂魄保存、轮回契机、血脉牵引、阵法完成、旧身死亡、时间限制或特定地点。
- 媒介条件：法阵、法宝、魂灯、血脉秘术、转生胎体、复活容器、祭坛、丹药或外力灌注。
- 接管方式：魂魄保存并进入身体，复活后重新适应或重修，按阶段恢复记忆，处理身体与神魂的适配期。
- 目标反抗：新身体排异、旧意识残留、血脉冲突、记忆封锁、外力阻断或旧敌干扰。
- 结果与后果：写记忆恢复、修为变化、旧因果牵连、旧敌追索、旧契约延续、旧伤复发和身份处理。
- 边界说明：说明该机制为什么是转世、重生或复活；不要把普通疗伤、假死或身份伪装写成复活。

### 身外化身 / 傀儡身体 / 替身身体

- 机制定位：写具体人物、化身、傀儡、分身、替身身体或炼制路线名称；机制功能为保命、远程行动、试探危险、替死或执行任务等。
- 原文称谓与模板归类：按原文称呼填写；模板归类可写身外化身、分身、傀儡身体、替身身体、尸人或法宝化身。
- 机制判定：写实锤机制、高置信推断或疑似待定。
- 是否真正接管：写远程操控、共享感知、分魂接管、命令行动、自主行动或原文未说明。
- 发起者：创造或操控化身的人、组织、器灵或禁术使用者；写本体状态和操控目的。
- 目标/宿主：化身、分身、傀儡、替身身体、法宝化身或临时容器；写其材质、意识状态和可承载程度。
- 原意识状态：写无自主意识、自我意识初生、被魂印控制、保留旧意识或原文未说明。
- 发起原因：保命、远程行动、试探危险、替死、隐匿身份、执行任务或保存传承。
- 前置条件：分魂能力、神识强度、炼制材料、控制距离、契约绑定、维护条件或本体存活。
- 媒介条件：傀儡核心、分魂秘术、法宝化身、替身符、魂印、控制令牌、机关结构或炼制阵法。
- 接管方式：分出或转移神魂，建立控制联系，远程操控化身，共享感知或命令行动；写清是否有自我意识和接管中断后果。
- 目标反抗：化身自我意识反噬、傀儡失控、控制被切断、魂印被破、外力夺控或本体受创。
- 结果与后果：写受伤或死亡是否反馈本体，化身如何维护、修复、升级、隐藏身份，以及损毁后的后续影响。
- 边界说明：说明该机制为什么属于化身、分身或傀儡身体；普通法器、机关和远程传讯不单独成卡。

### 血脉重塑 / 肉身改造 / 借尸还魂

- 机制定位：写具体人物、仪式、族群、肉身改造法或借尸还魂案例名称；机制功能为修复肉身、换血脉、延寿、突破、伪装身份或制造兵器等。
- 原文称谓与模板归类：按原文称呼填写；模板归类可写血脉重塑、肉身改造、借尸还魂、人造身体或复活容器。
- 机制判定：写实锤机制、高置信推断或疑似待定。
- 是否真正接管：写神魂进入新肉身、旧意识残留、肉身重塑、身份重塑、失控异化或原文未说明。
- 发起者：主导重塑或借尸的人、组织、邪修、族群、医修或禁术使用者；写其目的和控制程度。
- 目标/宿主：尸体、濒死者、血脉后裔、妖兽肉身、傀儡身体、人造身体或特殊容器；写适配程度和身份关系。
- 原意识状态：写旧意识已死、残留、反抗、融合、被覆盖或原文未说明。
- 发起原因：修复肉身、换血脉、延寿、逃避死亡、突破、伪装身份、改造族群或制造兵器。
- 前置条件：神魂适配、血脉相近、身体完整、目标虚弱、阵法准备、药材齐备、稳定期或祭祀条件。
- 媒介条件：药浴、阵法、祭坛、血脉秘术、缝合术、炼体法、尸体容器、妖兽材料或人造身体。
- 接管方式：神魂进入新肉身，重塑血脉，处理旧肉身，使新身体逐步适配；写清稳定期、痛苦、排异、异化、失控或外貌变化。
- 目标反抗：血脉排异、神魂不合、旧意识残留、身体崩溃、外力干预、祭祀失败或容器反噬。
- 结果与后果：写成功后的能力变化、身份处理、弱点、副作用、后续修炼限制、关系后果和最终结局。
- 边界说明：说明该机制为什么属于肉身或血脉层面的接管/重塑；普通疗伤、炼体强化或换装伪装不单独成卡。
