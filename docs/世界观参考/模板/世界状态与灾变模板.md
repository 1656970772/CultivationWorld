# 世界状态与灾变模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的世界修正器、时代变局、灾害、大环境压力和持续性世界状态变化。

整理时将世界状态与灾变视为“基准状态—背景脆弱性—触发起始—传播增长—强度跨级—直接影响—群体与势力反馈—级联事件—干预拐点—恢复衰退—残余与新常态”的完整状态转换系统。模板不要求每个对象机械经历全部阶段，只记录作品实际涉及、能够形成前后因果关系的内容。

本模板只收录会持续影响区域、势力、资源、修炼环境、生态、贸易、战争节奏或群体行为的状态变化。不收录单纯的个人修炼异常、单件道具异象、单次试药、单人伤病、单场比武、单次机缘、单次对决、个人约定期限或地点介绍。

可收录的典型内容包括：灵气复苏、末法、灵脉枯竭、灵石矿脉稀少、魔气污染、魔劫、天灾、兽潮、妖兽迁徙、宗门大战、王朝乱世、资源枯竭、丹药短缺、商路封锁、群体迁徙、战争动员、门派备战等。

## 整理原则

1. 先做入选判定
   每个条目必须判断是否跨越单人或单物件，是否影响区域、势力、资源、生态、贸易、战争节奏或群体行为，是否持续超过单场事件。三项都成立才建立世界状态与灾变卡；不成立时不纳入本文。

2. 排除个人事件和单物件机制
   个人修炼突破或瓶颈、单件道具异象、单次试药、单人病情、单场比武、单次冲突和个人声望变化，不得因为能拆成阶段就写成本模板卡片。神秘瓶子异象、韩立试验小瓶、养精丹疗伤、萧炎斗之气消失等默认不收录，除非明确引发区域级、势力级或群体行为级持续变化。

3. 先确定基准状态
   每张卡先写变化发生前的环境、资源、生态、势力和群体常态，再说明当前状态偏离了什么。作品只展示灾变而没有说明此前常态时写“原文未说明”，不能根据结果倒推出完整基准。

4. 区分背景条件、触发因素和传播路径
   “背景条件与系统脆弱性”写长期积累的资源压力、生态失衡、战争结构或环境弱点；“触发因素与起始节点”写使潜在压力转为实际变化的直接因素和起始位置；“传播路径与反馈机制”写状态如何通过地理、生态、资源、贸易、人口或组织网络扩散并得到强化。三者不得混写成宽泛的“产生原因”。

5. 区分正常、异常和极端状态
   基准状态写正常运行；轻微偏离、局部异常和可控影响写入对应状态等级；跨越承载阈值、快速扩散、系统失效和灾害化写入严重或极端状态。作品没有明确等级和阈值时只写实际变化，不自行划级。

6. 兼顾整体影响与承受差异
   既写区域、势力、资源、生态和贸易等系统变化，也写不同地区、族群、职业、境界和生活方式承受影响的差异。单个角色经历只能用于说明群体或系统状态，不能直接代表全部区域。

7. 区分直接影响、系统反馈和次生事件
   “直接影响、损害与机会分布”写状态首先造成的人员、环境、设施和功能结果；“资源与经济变化”“群体行为与社会反馈”“势力应对与干预效果”写各系统随后发生的反应；“级联影响与次生事件”只写由前述变化继续引发的新状态或事件，不罗列同时发生但无因果关系的剧情。

8. 记录外在征兆与环境表现
   记录天气、光线、声音、气味、温度、灵气或魔气、地貌、水体、植被、妖兽、建筑、道路和聚落秩序等可感知变化。外在表现应与实际阶段和强度对应，不以通用灾难形象补全作品未写明的细节。

9. 记录干预、拐点和实际效果
   势力封锁、救援、清理、迁徙、镇压、开矿、调配资源或重建时，不只记录行动，还要记录干预针对什么环节、是否减缓传播、是否转移风险以及是否产生新的副作用。没有实际结果时写“原文未说明”。

10. 追踪恢复、衰退与新常态
    早期出现的战争、灾变、污染、资源枯竭或势力压力，若后续已有休战、封印、退潮、恢复、常态化或恶化结果，应写入“恢复条件、残余影响与新常态”。同时记录是否恢复原状、留下何种永久变化、是否具有周期性或复发风险。

11. 只写状态变化链
    卡片要写清状态如何出现、传播、增强、受阻、减弱或转化，以及如何影响资源、行为、势力应对和次生事件。不写剧情梗概，不把人物行动、战斗过程或单件道具机制铺满字段。

12. 明确信息与推断边界
    作品直接说明或能够由多处内容稳定归纳的信息按实际内容填写；必要的合理推断必须明确标注。未来预期、人物判断、可能结果和实际发生的状态分别记录，不得把备战预期写成灾变已经爆发，也不得从资源稀缺直接推定价格、伤亡或战争结局。

13. 区分未知与整理状态
    作品没有交代时写“原文未说明”，不同阶段或说法冲突时并列保留。当前材料未覆盖、报告未生成和待重新整理属于工作流程状态，不写入正式世界状态卡。

14. 覆盖多类世界状态
    整理时应覆盖灵气与天地环境、魔气与污染、自然灾害、生态变化、政治战争、资源经济、群体行为和时代变局等方向。长篇作品不要只抓开篇或主角亲历事件，应覆盖不同地域、势力、族群、阶段和结果。

15. 输出前自检
    检查条目是否跨越个人和单次事件，基准状态是否明确，背景条件、触发因素和传播路径是否混写，正常、异常和极端状态是否区分，对象与范围是否重复，直接影响与次生事件是否混淆，干预效果与恢复结果是否追踪，以及明确内容、合理推断和未知项是否得到区分。

## 字段说明

- 入选判定：写是否跨越单人或单物件、影响层级、是否持续超过单场事件；正式卡不记录整理进度或结局追踪进度。
- 类型：写灵气与天地环境、魔气与污染、自然灾害、生态变化、政治与战争状态、资源与经济波动、群体行为变化、时代变局等，可按作品实际情况使用多个类型。
- 基准状态与偏离特征：写变化发生前环境、资源、生态、势力和群体如何正常运行，以及当前状态在哪些方面偏离基准。
- 受影响对象与承受差异：写直接和间接受影响的区域、势力、族群、职业、资源、生态、商路、战线、修炼环境或群体，并说明不同对象承受程度、反应速度或获益机会的差异。
- 时间：写前兆、爆发、持续、拐点、恢复、周期、间隔或时代阶段；不明时写“原文未说明”。
- 范围：写影响涉及的区域、空间边界、传播方向、商路、禁地、城镇、山脉、海域、界面或战线；对象写“谁受影响”，范围写“影响到哪里”。
- 背景条件与系统脆弱性：写灵脉长期衰退、资源过采、生态失衡、战争积累、供应集中、交通依赖、防线薄弱及其他使状态容易发生或扩大的条件。
- 触发因素与起始节点：写魔气外溢、天象变化、封印失效、战争升级、妖兽迁徙、资源断供等直接触发因素，以及最初出现变化的地点、群体或系统环节。
- 传播路径与反馈机制：写状态如何沿灵脉、水体、气候、生态链、商路、人口迁徙、资源网络、战线或组织命令扩散，以及恐慌、争夺、污染累积和干预失误如何进一步强化或减弱状态。
- 强度、阈值与状态等级：写状态的强弱、密度、频率、速度、覆盖率和承载阈值，记录其如何从轻微偏离发展到局部异常、严重失衡或极端灾害，以及如何减弱、收缩、封印或常态化。
- 外在征兆与环境表现：写天气、光线、声音、气味、寒热、灵气或魔气、地貌、水体、植被、妖兽、建筑、道路、聚落秩序和其他可感知表现，并按不同阶段和强度记录变化。
- 直接影响、损害与机会分布：写人员伤亡、失地、设施受损、生态变化、修炼环境恶化、生产停顿等直接损害，以及资源潮、战功、任务、迁徙空缺等机会由哪些对象获得。
- 资源与经济变化：写灵石、矿脉、灵药、丹药、魔核、商路、洞府、任务报酬和战备物资等供给、需求、价格、流通、替代品及获取门槛变化。
- 群体行为与社会反馈：写迁徙、抢购、避难、防御加强、闭关、叛逃、投靠、巡逻、护送、佣兵活动、战争动员及其他群体适应、逃避或利用行为。
- 势力应对与干预效果：写宗门、家族、王朝、商会、联盟、魔道、妖族或其他组织如何封锁、围剿、迁徙、备战、救援、交易、开矿、调配资源和重建，并记录干预针对的环节、实际效果与副作用。
- 级联影响与次生事件：写由直接影响、资源变化、群体反馈或势力干预继续引出的附庸叛乱、资源争夺、商路中断、城镇失守、任务增加、防线重建、门派大比及其他次生状态或事件。
- 状态链：按起始节点、扩散/发展节点、拐点/干预节点、转化节点写清状态变化和因果关系；具体影响和应对分别写入对应字段。
- 恢复条件、残余影响与新常态：写停止扩散或开始恢复的条件、恢复速度和程度、封印清理、休战重建、永久地貌或生态变化、高危区域、资源新格局、势力洗牌、周期复发和后续趋势。
- 信息边界与不确定项：写本卡中需要说明的合理推断、人物预期与实际状态的差异、不同阶段或说法之间的冲突，以及持续时间、伤亡、资源数量、传播范围和最终结果等重要未知项。
