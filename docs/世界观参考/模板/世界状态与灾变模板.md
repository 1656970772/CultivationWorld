# 世界状态与灾变模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的世界修正器、时代变局、灾害、大环境压力和持续性世界状态变化。

本模板只收录会持续影响区域、势力、资源、修炼环境、生态、贸易、战争节奏或群体行为的状态变化。不收录单纯的个人修炼异常、单件道具异象、单次试药、单人伤病、单场比武、单次机缘、单次对决、个人约定期限或地点介绍。

可收录的典型内容包括：灵气复苏、末法、灵脉枯竭、灵石矿脉稀少、魔气污染、魔劫、天灾、兽潮、妖兽迁徙、宗门大战、王朝乱世、资源枯竭、丹药短缺、商路封锁、群体迁徙、战争动员、门派备战等。

## 整理原则

1. 先做入选判定
   每个条目必须判断是否跨越单人/单物件，是否影响区域、势力、资源、生态、贸易、战争节奏或群体行为，是否持续超过单场事件。
   三项都成立，才可建立世界状态与灾变卡；不成立时不纳入本文。

2. 覆盖多类世界状态
   整理时应覆盖灵气/灵脉/天地环境、魔气/污染/魔劫、自然灾害、生态变化、政治战争、资源经济、群体行为等方向。
   长篇作品不要只抓开篇主角亲历事件，应覆盖不同地域、势力、族群、阶段和结局。

3. 排除个人事件和单物件机制
   个人修炼突破或瓶颈、单件道具异象、单次试药、单人病情、单场比武、单次冲突、个人声望变化，不得因为能拆成“初始/发展/转化”就写成本模板卡片。
   例如神秘瓶子异象、韩立试验小瓶、养精丹疗伤、萧炎斗之气消失，默认不作为世界状态与灾变卡；除非明确引发区域级、势力级或群体行为级持续变化。

4. 只写状态变化链
   卡片要写清状态如何出现、增强或减弱，如何影响资源、行为、势力应对和二次事件，以及最终消退、常态化、恶化或转化。
   不写剧情梗概，不把人物行动、战斗过程或道具机制铺满字段。

5. 结局必须追踪
   早期出现的战争、灾变、污染、资源枯竭或势力压力，若后续已有休战、封印、退潮、恢复、常态化或恶化结果，应写入“消退或恶化结果”。
   例如七玄门与野狼帮冲突不能只写“仍在持续”；若原文后续已有双方休养、战事暂息或进一步恶化，应按实际状态填写。

6. 区分缺失状态
   原文明确没交代时写“原文未说明”。
   当前整理范围没有覆盖到时写“当前整理范围未覆盖到明确内容”。
   某书报告缺失时写“报告缺失/未生成/需重新生成”，不得凭零散线索补写正式卡片。

7. 保留有代表性的世界状态案例
   七玄门与野狼帮冲突、七玄门衰落与灭门危机、灵石矿脉日益稀少、血色禁地灵药逐年减少、乱星海天灾、炼药师稀缺导致各方拉拢、药材与魔核经济压力、帝国战争、中州血云灾难、千年魔劫、灵穴/魔穴格局、门派大比与丹药需求增加等，符合入选判定时应优先整理。

## 字段说明

- 入选判定：写是否跨越单人/单物件、影响对象、是否持续超过单场事件、结局追踪状态。
- 类型：写灵气与天地环境、魔气与污染、自然灾害、生态变化、政治与战争状态、资源与经济波动、群体行为变化、时代变局等。
- 对象：写受影响的区域、势力、族群、资源、生态、商路、战线、修炼环境或群体。
- 时间：写爆发、持续、恢复、周期或阶段；不明时写“原文未说明”。
- 范围：写影响到的区域、势力边界、商路、禁地、城镇、山脉、海域、界面或战线。
- 产生原因：写灵脉枯竭、魔气外溢、资源过采、战争扩张、妖兽迁徙、天象变化、势力冲突等；不明时写“原文未说明”。
- 强度变化：写状态如何增强、减弱、扩散、收缩、爆发、退潮、封印、常态化或恶化。
- 资源变化：写灵石、矿脉、灵药、丹药、魔核、商路、洞府、任务报酬、战备物资等供需变化。
- 群体行为变化：写迁徙、抢购、防御加强、闭关增多、叛逃、投靠、任务增加、巡逻、护送、佣兵活动、战争动员等。
- 势力应对：写宗门、家族、王朝、商会、联盟、魔道、妖族或其他组织如何封锁、围剿、迁徙、备战、救援、交易、开矿或调配资源。
- 二次事件：写由状态变化引出的附庸叛乱、资源争夺、商路中断、城镇失守、任务增加、防线重建、拍卖盛会、门派大比等。
- 状态链：按初始节点、发展节点、转化节点写清状态变化。每个节点只写状态变化和影响，不写长篇剧情。
- 灾害或收益：写伤亡、失地、资源价格波动、修炼环境恶化、战功机会、资源潮、任务奖励等。
- 消退或恶化结果：写退潮、恢复、封印、清理、休战、常态化、高危区域形成、战争扩大、资源枯竭、势力衰落等。
- 不确定项：写原文未说明、当前整理范围未覆盖到明确内容或报告缺失；不要自行补持续时间、伤亡数字、资源数量或最终结局。

### 七玄门与野狼帮势力冲突

- 入选判定：
  - 是否跨越单人/单物件：是，影响两个地方势力及其弟子群体。
  - 影响对象：门派地界、富裕城镇、内门弟子、门派扩招和历练节奏。
  - 是否持续超过单场事件：是。
  - 结局追踪状态：按原文填写休战、修养、恶化或持续敌对。
- 类型：政治与战争状态。
- 对象：地方门派冲突、城镇争夺、弟子伤亡和门派压力。
- 时间：原文未说明。
- 范围：七玄门地界、野狼帮势力范围、争夺城镇和受影响山门。
- 产生原因：富裕城镇争夺或地方势力扩张。
- 强度变化：从局部冲突升级为多次交战，后续转为休战、撤退、休养或长期敌对。
- 资源变化：城镇收益、门派人手、弟子伤亡、巡逻和历练成本变化。
- 群体行为变化：门派扩招、弟子历练、参战、防守、避让或休养。
- 势力应对：双方交战、防守、撤退、休整、调整弟子参战规则。
- 二次事件：门派扩招、弟子历练制度调整、地方传说、后续围攻或灭门危机。
- 状态链：
  - 初始节点：双方为地盘或城镇利益发生冲突。
  - 发展节点：内门弟子伤亡，门派扩招或历练节奏变化。
  - 转化节点：双方撤退休养、冲突暂息、常态化为地方压力，或恶化为围攻危机。
- 灾害或收益：人员伤亡、地盘压力、门派动员，也可能带来历练和扩招机会。
- 消退或恶化结果：按原文填写。
- 不确定项：具体伤亡数、持续时间或城镇损失若未说明，写“原文未说明”。

### 灵石矿脉日益稀少

- 入选判定：
  - 是否跨越单人/单物件：是。
  - 影响对象：修士群体、交易体系、矿脉争夺、宗门资源供给。
  - 是否持续超过单场事件：是。
  - 结局追踪状态：长期稀缺、新矿缓解、争夺加剧或原文未说明。
- 类型：资源与经济波动。
- 对象：灵石矿脉、灵石货币、修炼资源和交易市场。
- 时间：原文未说明。
- 范围：修仙界、坊市、宗门、矿脉区域或相关交易网络。
- 产生原因：巨量消耗、过度开采、矿脉减少或原文未说明。
- 强度变化：灵石由常用资源变得珍贵，或稀缺程度继续上升。
- 资源变化：灵石、矿脉、丹药、法器、符箓、交易门槛和任务报酬受到影响。
- 群体行为变化：修士节省灵石、争夺矿脉、提高交易门槛、寻找替代资源。
- 势力应对：开矿、封锁矿脉、争夺矿区、控制坊市货币流通。
- 二次事件：矿脉争夺、坊市价格变化、宗门资源紧缩、散修生存压力上升。
- 状态链：
  - 初始节点：灵石消耗或开采压力显现。
  - 发展节点：矿脉日益稀少，灵石价值提高，交易与修炼成本上升。
  - 转化节点：新矿脉缓解、长期稀缺常态化、宗门争夺升级或原文未说明。
- 灾害或收益：资源压力、交易成本上升、矿脉争夺机会。
- 消退或恶化结果：长期稀缺、新矿缓解、争夺加剧或原文未说明。
- 不确定项：没有明确价格或矿脉数量时，写“原文未说明”。

### 千年魔劫

- 入选判定：
  - 是否跨越单人/单物件：是。
  - 影响对象：道魔两方、门派资源、丹药需求、战争节奏和修行准备。
  - 是否持续超过单场事件：是。
  - 结局追踪状态：魔劫将至、爆发、缓解、常态化或原文未说明。
- 类型：魔气与污染 / 政治战争状态 / 时代变局。
- 对象：道魔格局、灵穴/魔穴、门派资源和修士群体。
- 时间：按原文填写。
- 范围：相关洲陆、门派、灵穴魔穴分布区和道魔战线。
- 产生原因：千年周期、道魔格局、灵穴/魔穴变化或原文说明原因。
- 强度变化：从将至的时代压力，发展为门派备战、资源需求增加或大规模杀伐。
- 资源变化：丹药、法器、弟子名额、门派大比奖励、战备物资需求变化。
- 群体行为变化：门派备战、大比增加、弟子修行加紧、资源调配、道魔对抗升级。
- 势力应对：组织大比、分配丹药、调动弟子、强化防线、准备战事。
- 二次事件：道魔杀伐、资源紧缺、门派内部竞争、战线变化。
- 状态链：
  - 初始节点：魔劫将至，成为门派和修士预期中的大环境压力。
  - 发展节点：资源需求、门派大比、丹药分配和战备行为增加。
  - 转化节点：魔劫爆发、被压制、常态化为长期道魔战争或原文未说明。
- 灾害或收益：战争伤亡、资源压力、修行机会、战功和门派洗牌。
- 消退或恶化结果：按原文填写。
- 不确定项：没有明确范围或结局时，写“原文未说明”。
