# 世界状态与灾变模板

## 适用范围

用于整理作品中出现过，或能由小说内容明确支撑的世界修正器、时代变局、灾害与大环境压力。

## 前置声明

- 样本要覆盖不同地域、境界、势力、族群、身份和结局；不要只写主角亲历的灾变或少数名场面。
- 只有对区域、势力、资源、修炼环境、生态、贸易、战争节奏或群体行为产生持续影响的内容，才放入本文。
- 只写原文、资料来源或可靠依据能支撑的内容；缺失信息写“原文未说明”，不要补设定。
- 案例只写状态变化链，不写总览、证据段、抽象规则表或项目映射。
- 信息不足但符合主题的内容，先写入 `### 待定案例`。后续获得新信息时，在同一待定项追加摘要和来源；信息足够后，复核来源并转为正式案例。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

| 类型 | 示例 | 重点 |
| --- | --- | --- |
| 灵气与天地环境 | 灵气复苏、末法、灵脉枯竭、天地元气变化、界面压制、天象异变 | 写清修炼环境如何改善或恶化。 |
| 魔气与污染 | 魔气上涨、邪气扩散、魔劫、堕魔潮、禁地污染、空间裂缝污染 | 写清污染范围、强度变化和扩散后果。 |
| 自然灾害 | 旱灾、瘟疫、饥荒、火灾、雷灾、寒潮、洪水、地裂、界面风暴 | 写清灾害持续时间、范围和群体反应。 |
| 生态变化 | 兽潮、妖兽活跃、妖王陨落、妖族迁徙、灵药成熟潮、领地扩张 | 写清资源、妖兽和修士活动如何改变。 |
| 政治与战争状态 | 王朝衰败、乱世、宗门大战、附庸叛乱、继任危机、商路封锁、边境战争 | 写清势力应对、秩序变化和长期压力。 |
| 资源与经济波动 | 矿脉发现或枯竭、秘境频出、拍卖盛会、资源枯竭、丹药短缺、灵石紧缺、坊市兴衰 | 写清价格、供给、贸易路线和争夺行为。 |
| 行为影响 | 闭关增多、迁徙、抢购、防御加强、叛逃、投靠、宗门任务增加、散修风险上升 | 写清群体行为如何随状态改变。 |

状态变化链建议逐节点写清：时间 / 范围 / 产生原因 / 强度变化 / 资源变化 / 角色或势力行为变化 / 灾害或收益 / 消退或恶化结果。原文写了持续时间、爆发时间、恢复时间、人员伤亡、价格变化、势力应对或妖兽迁徙时，都要写进对应节点。

状态链不只写起因和影响；若原文支持，应写清应对冲突、二次事件，以及状态最终退潮、封印、常态化、恶化为禁地/战争/资源潮等转化结果。

不要把单个事件误写成长期世界状态。单场战斗、单次机缘或单个冲突，应放到更合适的模板。

## 案例

### 案例

#### 案例 1：魔气上涨导致区域污染与修士迁徙

**状态变化链：**

1. 某区域开始出现魔气上涨或邪气扩散；写清时间、地点、范围和最初表现。
2. 魔气影响修炼环境，低阶修士出现修炼受阻、心神不稳、中毒、堕魔风险或被迫搬离。
3. 区域内灵药、矿脉、妖兽或凡人城镇受到影响；写清资源减少、资源变异、妖兽异化、人口死亡或迁徙。
4. 附近宗门、家族或坊市开始应对，例如调查、封锁、发布任务、抬高丹药价格或收容逃难者。
5. 魔气继续上升、稳定或被压制；写清持续时间、阶段变化和影响范围变化。
6. 二次冲突或后续事件：围剿邪修、清理污染妖兽、争夺净化资源、护送迁徙人群、宗门之间互相推责或封锁责任扩散。
7. 状态消退或恶化：大能出手、阵法封印、源头清理、扩散成禁地或迁徙潮持续。
8. 后续影响：资源价格、迁徙路线、宗门防御、任务数量和危险区分布如何变化。

#### 案例 2：灵脉枯竭引发宗门资源压力

**状态变化链：**

1. 某宗门、家族或区域的灵脉开始枯竭；写清发现时间、发现者、范围和征兆。
2. 修炼环境变差，闭关效率下降，弟子突破变慢，洞府或修炼室供给减少。
3. 宗门削减丹药、灵石、洞府、任务奖励或月俸；写清削减内容和持续时间。
4. 弟子、长老、附庸家族或散修产生反应，例如抢任务、外出寻矿、投靠他宗、内部争斗或离宗。
5. 宗门寻找新灵脉、开采旧矿、进入秘境、交易、压榨附庸、发动战争或裁撤供给。
6. 状态结局：找到新资源、灵脉彻底枯竭、宗门衰落、迁宗、被吞并或长期贫弱。
7. 后续影响：区域势力格局、修士成长速度、任务类型、资源价格和贸易路线如何变化。

#### 案例 3：兽潮爆发改变边境区域状态

**状态变化链：**

1. 某边境、山脉、森林、海域或荒原出现妖兽异常活跃；写清时间、地点、妖兽种类或规模。
2. 异常来源按原文填写，例如妖王陨落、妖兽迁徙、灵药成熟、魔气污染、繁殖潮、过度猎杀或秘境开启。
3. 妖兽活动影响采药、采矿、商路、凡人城镇、宗门边境和散修行动；写清死亡、损失、资源中断或价格变化。
4. 附近宗门、家族、坊市或王朝发布猎妖、巡逻、护送、清剿、筑防任务。
5. 修士参与防御或猎妖，产生消耗、奖励、材料收益或伤亡。
6. 兽潮升级、分散、被围剿、退潮、常态化为高风险边境或绕过防线；写清持续时间、推进路线、关键战斗和区域变化。
7. 后续影响：边境防御、猎妖任务、妖兽材料价格、势力损失、散修机会、死亡风险，以及区域状态最终恢复、恶化或长期化。
