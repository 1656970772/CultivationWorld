# 世界状态与灾变模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：世界修正器、时代变局、灾害与大环境压力调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的世界状态变化链，不写总览，不写证据段，不写抽象规则表，不单独拆“状态类型、产生原因、影响范围、项目映射”等表格字段。

每个案例只写状态变化链。状态变化链要按原文先后顺序逐步写清一个区域、势力、种族、时代或资源环境如何从正常状态变化为灾变、乱世、资源潮、灵气变化、魔气污染、兽潮、战争状态或其他长期压力，又如何消退、恶化或转化为后续事件。

状态变化链里的每个小节点都尽量写清“时间 / 范围 / 产生原因 / 强度变化 / 资源变化 / 角色或势力行为变化 / 灾害或收益 / 消退或恶化结果”。如果原文写了持续时间、爆发时间、恢复时间、影响区域、资源增减、人员伤亡、价格变化、势力应对或妖兽迁徙，要写进对应小节点。原文写了多少就写多少；没有写的不要补。

不要把单个事件误写成长期世界状态。只有当它对区域、势力、资源、修炼环境、生态、贸易、战争节奏或群体行为产生持续影响时，才放入本模板；否则应放到冲突事件、动态事件、秘境机缘或其他更合适的模板中。

## 参考范围（不局限于以下类别）

- **灵气与天地环境**：灵气复苏、末法、灵脉枯竭、天地元气变化、界面压制、修炼环境改善或恶化、天象异变。
- **魔气与污染**：魔气上涨、邪气扩散、魔劫、污染区域、堕魔潮、邪祟扩散、禁地污染、空间裂缝污染。
- **自然灾害**：旱灾、瘟疫、饥荒、火灾、雷灾、寒潮、洪水、地裂、空间裂缝、天灾、界面风暴。
- **生态变化**：兽潮、妖兽活跃、妖王陨落、妖族迁徙、灵药成熟潮、妖兽领地扩张、资源点被妖兽占据。
- **政治与战争状态**：王朝衰败、乱世、宗门大战、附庸叛乱、继任危机、势力扩张、防御收缩、商路封锁、边境战争。
- **资源与经济波动**：矿脉发现、矿脉枯竭、秘境频出、拍卖盛会、资源枯竭、商路断绝、丹药短缺、灵石贬值或紧缺、坊市繁荣或衰败。
- **行为影响**：修炼加速或减速、闭关增多、迁徙、抢购资源、猎妖增多、防御加强、扩张放缓、叛逃、投靠、宗门任务增加、散修风险上升。

## 完整世界状态变化链案例

### 案例 1：魔气上涨导致区域污染与修士迁徙

**状态变化链：**

1. 某区域开始出现魔气上涨或邪气扩散；写清开始时间、地点、范围和最初表现，原文未说明则不补。
2. 魔气影响修炼环境，低阶修士出现修炼受阻、心神不稳、中毒、堕魔风险或被迫搬离。
3. 区域内灵药、矿脉、妖兽或凡人城镇受到影响；写清资源减少、资源变异、妖兽异化、人口死亡或迁徙。
4. 附近宗门、家族或坊市开始应对，例如派人调查、封锁区域、发布任务、抬高丹药价格或收容逃难者。
5. 魔气强度继续上升、稳定或被压制；写清持续时间、阶段变化和影响范围变化。
6. 如果出现冲突，写清是围剿邪修、清理污染妖兽、争夺净化资源、护送迁徙人群还是宗门之间互相推责。
7. 状态消退或恶化：大能出手、阵法封印、源头被清理、魔气扩散到更大范围、区域变成禁地或迁徙潮持续。
8. 后续影响：区域资源价格变化、修士迁徙路线变化、宗门防御增强、任务增多、某地长期成为危险区或新机缘地。

### 案例 2：灵脉枯竭引发宗门资源压力

**状态变化链：**

1. 某宗门、家族或区域的灵脉开始枯竭；写清发现时间、发现者、范围和最初征兆。
2. 修炼环境变差，闭关效率下降，弟子突破变慢，洞府或修炼室供给减少。
3. 宗门减少丹药、灵石、洞府、任务奖励或月俸供给；写清削减内容和持续时间。
4. 弟子、长老、附庸家族或散修产生反应，例如抢夺任务、外出寻矿、投靠他宗、内部争斗或离宗。
5. 宗门采取应对：寻找新灵脉、开采旧矿、派人进入秘境、与商会交易、压榨附庸、发动战争或裁撤弟子供给。
6. 资源压力引发后续事件，例如叛逃、继任危机、宗门大战、坊市价格上涨、散修截杀增加。
7. 状态结局：找到新资源、灵脉彻底枯竭、宗门衰落、迁宗、被吞并或转为长期贫弱状态。
8. 后续影响：区域势力格局变化、修士成长速度变化、任务类型变化、资源价格和贸易路线变化。

### 案例 3：兽潮爆发改变边境区域状态

**状态变化链：**

1. 某边境、山脉、森林、海域或荒原出现妖兽异常活跃；写清时间、地点、妖兽种类或规模。
2. 异常来源按原文填写，例如妖王陨落、妖兽迁徙、灵药成熟、魔气污染、繁殖潮、修士过度猎杀或秘境开启。
3. 妖兽活动影响采药、采矿、商路、凡人城镇、宗门边境和散修行动；写清死亡、损失、资源中断或价格变化。
4. 附近宗门、家族、坊市或王朝发布猎妖、巡逻、护送、清剿、筑防任务。
5. 修士参与防御或猎妖，消耗丹药、符箓、法宝耐久和人手，获得妖兽材料、贡献、奖励或伤亡。
6. 兽潮升级、分散、被围剿或绕过防线；写清持续时间、推进路线、关键战斗和区域变化。
7. 状态结束或转化：妖兽退回领地、妖王被击杀、兽潮变成长期边境压力、某地变成高风险猎妖区。
8. 后续影响：边境防御增强、猎妖任务增多、妖兽材料价格变化、某些宗门或家族损失人手、散修机会与死亡风险同时上升。
