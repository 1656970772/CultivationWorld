# 世界状态与灾变模板

# 规范

用于整理作品中出现过，或能由小说内容明确支撑的世界修正器、时代变局、灾害与大环境压力。

## 参考和要求

- 参考范围：本部分是写作要求与参考整理范围；参考范围不是限定范围，仅用于提示检索方向，原文有其他相关内容也应继续补充。
- 整理范围：只收录对区域、势力、资源、修炼环境、生态、贸易、战争节奏或群体行为产生持续影响的世界修正器、时代变局、灾害与大环境压力。
- 覆盖要求：样本应覆盖不同地域、境界、势力、族群、身份和结局，不只整理主角亲历的灾变或少数名场面。
- 可靠性要求：只写小说内容能明确支撑的状态变化；缺失信息写“原文未说明”，不要补设定。
- 案例写法：案例只写状态变化链，不写总览、抽象规则表或项目映射。
- 待定处理：信息不足但符合主题的内容，先写入 `### 待定案例`；信息足够后转为正式案例，并删除待定项。
- 灵气与天地环境：整理灵气复苏、末法、灵脉枯竭、天地元气变化、界面压制、天象异变等内容，写清修炼环境如何改善或恶化。
- 魔气与污染：整理魔气上涨、邪气扩散、魔劫、堕魔潮、禁地污染、空间裂缝污染等内容，写清污染范围、强度变化和扩散后果。
- 自然灾害：整理旱灾、瘟疫、饥荒、火灾、雷灾、寒潮、洪水、地裂、界面风暴等内容，写清灾害持续时间、范围和群体反应。
- 生态变化：整理兽潮、妖兽活跃、妖王陨落、妖族迁徙、灵药成熟潮、领地扩张等内容，写清资源、妖兽和修士活动如何改变。
- 政治与战争状态：整理王朝衰败、乱世、宗门大战、附庸叛乱、继任危机、商路封锁、边境战争等内容，写清势力应对、秩序变化和长期压力。
- 资源与经济波动：整理矿脉发现或枯竭、秘境频出、拍卖盛会、资源枯竭、丹药短缺、灵石紧缺、坊市兴衰等内容，写清价格、供给、贸易路线和争夺行为。
- 行为影响：整理闭关增多、迁徙、抢购、防御加强、叛逃、投靠、宗门任务增加、散修风险上升等内容，写清群体行为如何随状态改变。
- 状态变化链：逐节点写清时间、范围、产生原因、强度变化、资源变化、角色或势力行为变化、灾害或收益、消退或恶化结果。
- 节点细节：原文写了持续时间、爆发时间、恢复时间、人员伤亡、价格变化、势力应对或妖兽迁徙时，都要写进对应节点。
- 转化结果：状态链不只写起因和影响；若原文支持，应写清应对冲突、二次事件，以及状态最终退潮、封印、常态化、恶化为禁地、战争或资源潮等转化结果。
- 排除内容：不要把单个事件误写成长期世界状态；单场战斗、单次机缘或单个冲突，应放到更合适的模板。

```md
### 魔气污染型

- 类型：魔气与污染
- 对象：某区域魔气上涨、邪气扩散或空间裂缝污染
- 时间：原文未说明
- 范围：受污染区域、相邻城镇、坊市、宗门边界或禁地周边
- 产生原因：魔气外溢、邪气扩散、空间裂缝污染或原文未说明
- 强度变化：污染出现后逐步加重，或在封印、净化后减弱
- 资源变化：灵药、矿脉、妖兽材料、任务报酬或安全商路受到影响
- 群体行为变化：低阶修士避让，凡人城镇迁徙，散修接取调查、护送或清剿任务
- 势力应对：宗门、家族或坊市调查、封锁、围剿、净化或组织迁徙
- 二次事件：污染引发妖兽异变、修士堕化、商路中断、禁地扩张或救援行动
- 状态链：
  - 初始节点：污染出现，修炼环境受阻
  - 发展节点：资源、妖兽、凡人城镇或低阶修士受影响，势力开始封锁或调查
  - 转化节点：围剿、净化、护送迁徙等行动发生，污染被封印、清理、扩散成禁地或迁徙潮长期化
- 灾害或收益：伤亡、失地、资源价格波动、任务增加，或净化后重新开放资源点
- 消退或恶化结果：封印、清理、退潮、常态化为高风险区域，或恶化为禁地

### 灵脉枯竭型

- 类型：灵气与天地环境
- 对象：宗门、家族或区域灵脉枯竭导致的长期资源压力
- 时间：发现时间按原文填写
- 范围：灵脉所在山门、家族驻地、洞府群、坊市或周边区域
- 产生原因：长期消耗、灵脉衰败、外力破坏、阵法抽取或原文未说明
- 强度变化：灵气浓度下降，洞府、丹药、灵石、月俸等供给逐步收缩
- 资源变化：修炼效率下降，丹药、灵石、洞府名额或任务报酬紧张
- 群体行为变化：弟子、长老、附庸或散修出现离散、争夺、投靠、闭关减少或外出增多
- 势力应对：寻找新资源、开矿、交易、压榨附庸、迁宗、结盟或开战
- 二次事件：附庸叛乱、资源争夺、商路调整、势力衰落、吞并或迁徙
- 状态链：
  - 初始节点：枯竭征兆出现，修炼效率下降
  - 发展节点：丹药、灵石、洞府或月俸削减，引发群体行为变化
  - 转化节点：势力寻找新资源、开矿、交易、压榨附庸或开战，最终迁宗、衰落、被吞并或长期贫弱
- 灾害或收益：资源压力、内部矛盾、外部觊觎，或新矿脉、新商路带来短期缓解
- 消退或恶化结果：灵脉恢复、迁宗成功、被其他势力吞并，或长期维持贫弱状态

### 兽潮边境型

- 类型：生态变化
- 对象：边境、山脉、森林、海域或荒原出现妖兽异常活跃
- 时间：爆发时间和持续时间按原文填写
- 范围：妖兽推进路线、边境城镇、采药区、矿区、商路和宗门防线
- 产生原因：妖王陨落、领地扩张、环境异变、资源成熟潮或原文未说明
- 强度变化：妖兽活动从零散袭击升级为兽潮，或在围剿、防御后退潮
- 资源变化：采药、采矿、商贸受阻，妖兽材料价格、护送报酬或防御物资需求变化
- 群体行为变化：散修冒险猎妖或避让，凡人城镇迁徙，宗门弟子巡逻、护送或参战
- 势力应对：猎妖、巡逻、护送、清剿、筑防、征召弟子或加固边境
- 二次事件：商路中断、城镇失守、材料价格上涨、防线重建或高风险边境常态化
- 状态链：
  - 初始节点：妖兽异常活跃，边境风险上升
  - 发展节点：采药、采矿、商路、凡人城镇和宗门边境受影响，巡逻和护送任务增加
  - 转化节点：兽潮升级、退潮、被围剿，或常态化为高风险边境
- 灾害或收益：伤亡损失、城镇破坏、商路停摆，或妖兽材料、任务奖励和战功机会增加
- 消退或恶化结果：兽潮退去、防线稳固、妖兽被清剿，或边境长期高危
```
