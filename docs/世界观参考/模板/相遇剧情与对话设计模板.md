# 相遇剧情与对话设计模板

## 适用范围

本模板主要用于提取和分析作品中具有独立语言价值的高品质对话弧，包括搞笑、荒诞、深度讨论、装腔、压迫、威胁、求饶、保命谈判、讽刺、暧昧、悲伤、热血、身份反转、试探交易、问罪决裂等类型。相遇剧情、旧识重逢、身份暴露和临时合作只作为对话发生的场景，不是收录目的本身。

正式案例必须存在至少两方直接语言交流，并由对白本身体现人物声音、目标冲突、信息变化、权力变化、情绪效果、思想价值或关系转折。没有对白推进的普通战斗、独角戏、日志、信息传播、公开测试、心理活动和纯旁观反应，不进入本模板；剧情重要但对白只是功能性交代时，也应转入 `信息传播与情报模板.md`、`有限视角与叙事日志模板.md`、`冲突事件分析模板.md` 或 `人物关系与事件分析模板.md`。

本模板不写 UI 对话树、游戏选项 DSL 和抽象数值表，也不要求对白必须导致外部行动。若一段对话没有明显行动结果，但具有不可替代的人物塑造、幽默、思想或情绪价值，仍可按高品质对话收录，并明确其核心价值。

## 整理原则

1. 以完整对话弧为卡片单位
   一张卡整理一段具有同一核心目标、连续语言交锋和明确收束的对话弧，不必覆盖整场相遇。同一场景中若先后出现试探、交易、身份暴露和决裂等独立目标，可以拆成不同对话弧；同一目标的连续推进则合并。

2. 先做高品质准入判定
   对话至少应体现人物声音、潜台词、目标冲突、信息变化、权力变化、情绪反转、语言笑点、价值讨论或关系转折中的一项，并由对白本身承担效果。仅因剧情重要、人物知名或结果重大，不能证明对话值得收录。

3. 排除流水账和功能性问答
   普通寒暄、报数字、交任务、重复确认、设定复述和可以任意更换说话人的通用台词，不建立正式卡。若删掉对白而剧情结果几乎不变，且没有人物、情绪、思想或语言价值，应转入其他事件模板。

4. 先划定对话弧边界
   明确从哪一次语言出招开始，到哪个决定、关系状态、笑点回收、思想落点或谈判结果结束。铺垫只保留理解对话所必需的部分，结束后的行动和长期关系另写结果与余波。

5. 还原关系、目标、筹码和信息
   对话发生前必须明确双方关系、地位差、表面目标、真实目标、底线、可交换筹码、隐藏筹码、已知信息和误判。没有这些条件，很难判断一句话为什么构成威胁、试探、装腔、求饶或反击。

6. 按语言行动拆分对话单元
   对话单元不是机械的一人一句，而是一组完成同一作用的语言交锋。每个单元记录说话者、对话内容、表面意思、真实意图、潜台词、使用策略、对方回应以及信息、情绪、权力和关系变化。

7. 保留有效对白，不复述整场剧情
   只保留承担开场、试探、误导、威胁、让步、反击、笑点、反转、高潮和收束作用的对话内容。无作用的寒暄、重复句和旁支解释可以省略；动作、停顿和环境只在实际改变台词效果时记录。

8. 区分明确内容和潜台词解读
   对话内容、可见动作和当场结果按明确内容填写；真实意图、潜台词和情绪解释可能属于谨慎归纳。不能因为后续发生战斗、结盟或背叛，就反推角色当时已经完整表达或预知这些结果。

9. 分析人物声音和语言辨识度
   记录用词、句式、称呼、语气、礼貌程度、隐喻、反问、停顿和口头习惯，并判断台词是否符合身份、关系和处境。换成其他人物仍完全成立的通用台词，人物塑造价值较低。

10. 分析效果怎样形成
    搞笑可能来自误会、错位、反差、重复和回扣；深度来自价值冲突、责任归属和两难；装腔或压迫来自框架控制、简短从容和兑现能力；求饶来自示弱、筹码、让步和责任转移。只标记“好笑”“有深度”“很霸气”不算完成分析。

11. 同时观察语言、动作和旁观环境
    公开或私密环境、旁观者、时间压力、空间距离、动作、沉默、打断和离场都会改变对白效果。只记录真正改变权力、情绪、节奏或理解的外部因素，不扩写无关场景描写。

12. 区分正常、紧张、失控和极端状态
    正常状态写仍可交换信息和协商；紧张状态写试探、讽刺、施压和防守增加；失控状态写辱骂、求饶崩溃、威胁升级或谈判框架破裂；极端状态写不可逆决裂、强制控制、死亡威胁或越界。还要记录是否能够降温和恢复谈判。

13. 追踪对话结果和后续回扣
    分别记录信息、资源、权力、关系、决定和行动结果，以及后续再次相遇时台词、行为或关系是否回扣本次对话。对白没有造成行动结果时，仍可因人物、思想或审美价值入选，但必须说明核心价值。

14. 宁缺毋滥并做自检
    样本数量由真正达到质量门槛的对话弧决定，不设机械数量要求。完成后检查：是否把整场剧情当作对话；是否只摘名句而缺少回应；目标、筹码和信息差是否清楚；每个单元是否写出语言行动和状态变化；人物声音是否可辨；效果形成机制是否具体；潜台词是否被当成事实；是否存在对话内容缺失却仍建卡的情况。

### 搞笑对话示例：看火

- 对话弧类型、质量判定与收录边界：师徒问责；搞笑、反差；两句回应完成责任追问和荒诞转移，不是普通工作汇报。
- 场景、关系与外部压力：炼器室冒烟，师父赶来；徒弟负责看守炉火，炉内传来异常撞击声。
- 精选对话单元：
  - 第1单元：师父问：“我不是让你看火吗？”徒弟答：“看了，一刻没眨眼。”表面是履职说明，实际暴露他把“看火”理解成只看不管。
  - 第2单元：师父问：“那炉子怎么炸了？”徒弟望向炉子：“它脾气比您大，我没敢劝。”徒弟用一本正经的拟人化推责，把问责变成第二个笑点。
- 对话结构与转折：职责质问 → 字面回应 → 结果追责 → 荒诞推责；第二次回应回扣第一次的“只看不管”。
- 人物声音与语言辨识度：师父短句急问，徒弟始终认真作答；笑点依赖两人身份差和徒弟避重就轻的习惯。
- 效果形成机制：字面理解、一本正经、责任与回答错位、递进回扣。
- 质量评价与可复用技法：关键不是套用俏皮话，而是让角色用一致的错误逻辑连续回应现实后果。

### 深度对话示例：开不开城门

- 对话弧类型、质量判定与收录边界：战时决策；深度、价值冲突；双方都提出真实且无法同时满足的责任。
- 参与者目标、底线与筹码：守将要避免敌军混入，医官要救城外难民；两人的底线分别是城防和眼前生命。
- 精选对话单元：
  - 第1单元：守将说：“门一开，百姓能进，敌人也能进。”他把风险集中到无法识别敌我的制度困境。
  - 第2单元：医官回答：“门不开，敌人明日才到；他们今夜就会死。”她不否认城防风险，而是改变时间尺度，让不作为也成为一种决定。
  - 第3单元：守将沉默后问：“你能认出多少人？”医官答：“认不全。但我能先认出伤者。”交锋从价值争论转入有限执行方案。
- 对话结构与转折：安全原则 → 生命反问 → 沉默降速 → 寻找可执行折中。
- 效果形成机制：双方立场均成立，第二轮通过时间反差重构责任，第三轮避免空泛说理。
- 结果、余波与再次回扣：决定只开侧门接收可核验伤者；双方都让步，也都没有完全获胜。
- 质量评价与可复用技法：深度来自同一决定承担两种代价，而不是让一方说出作者结论。

### 权力反转示例：关税还是军粮

- 对话弧类型、质量判定与收录边界：拦路勒索转交易；装腔、权力反转；弱势者通过隐藏资源重设谈话框架。
- 权力关系与信息格局：守关者掌握武力和道路，商人掌握对方急需的军粮信息；守关者误以为车队只是普通货商。
- 精选对话单元：
  - 第1单元：守关者说：“交钱，或者把车留下。”他用二选一封死普通谈判空间。
  - 第2单元：商人掀开车帘：“车里是你们三个月的军粮。你可以抢一次，也可以收三个月的税。”商人不请求宽免，而是把选择改成短期掠夺与长期收益。
  - 第3单元：守关者问：“你在教我做事？”商人答：“不，我在给将军留一件能向士兵解释的事。”他把私人威胁转成守关者必须面对的组织责任。
- 对话结构与转折：武力设框 → 资源揭示 → 框架反转 → 身份责任压回。
- 人物声音与语言辨识度：商人始终不用求饶语气，句子短而具体，底气来自可验证筹码。
- 效果形成机制：信息反转、长期与短期收益对照、从个人威胁转为公共责任。
- 结果、余波与再次回扣：车队按正常税率通过，双方建立带戒备的长期交易关系。

### 求饶谈判示例：三个不杀的理由

- 对话弧类型、质量判定与收录边界：俘虏求生；求饶、谈判拉扯；求饶者通过分阶段交付价值避免一次说尽后被杀。
- 参与者目标、底线与筹码：审问者要名单和联络方式，俘虏要活命；俘虏掌握名单、暗号和只能由本人完成的声音验证。
- 精选对话单元：
  - 第1单元：审问者说：“给我一个不杀你的理由。”俘虏答：“一个理由不值一条命。我给你三个。”他拒绝在对方框架里一次证明全部价值。
  - 第2单元：俘虏说：“名单、暗号，还有一个只认我声音的人。”他把筹码拆成信息、验证和持续用途三个层级。
  - 第3单元：审问者说：“先说名单。”俘虏答：“先松一只手。你要的是能开口的人，不是一具会点头的尸体。”他提出最小让步，并把请求包装成对审问目标有利。
- 对话结构与转折：死亡威胁 → 扩大自身价值 → 分层展示筹码 → 交换最小让步。
- 效果形成机制：权力极不对等但信息不可替代；俘虏不靠空泛哀求，而靠分期交付维持谈判。
- 正常、紧张、失控与极端状态：全程处于死亡威胁的极端状态，但双方仍有共同利益，因此谈判尚未崩溃。
- 结果、余波与再次回扣：俘虏获得暂缓处置和有限行动能力，生存仍取决于后续信息是否真实。

### 决裂对话示例：询问还是宣判

- 对话弧类型、质量判定与收录边界：师徒问罪；讽刺、悲伤、不可逆决裂；双方对谈话性质的定义本身成为冲突。
- 场景、关系与外部压力：私下会面，无旁观者；弟子已掌握部分事实，师父仍试图解释。
- 精选对话单元：
  - 第1单元：师父问：“你来问我真相，还是来要我同意你已经相信的真相？”他指出弟子表面求证、实际定罪。
  - 第2单元：弟子答：“我来给你最后一次说实话的机会。”弟子拒绝讨论自己的预设，把谈话压缩为服从或撒谎。
  - 第3单元：师父说：“那便不是问，是宣判。”他放弃解释，并重新命名整场对话。
- 对话结构与转折：表面求证 → 揭露预设 → 最后通牒 → 定义反转与结束。
- 正常、紧张、失控与极端状态：对话从紧张质询迅速进入框架破裂；双方不再承认同一套判断规则，已经无法继续谈判。
- 人物声音与语言辨识度：两人都使用克制短句，没有辱骂；决裂来自定义和信任崩溃，而不是音量升级。
- 结果、余波与再次回扣：弟子离开并终止师徒关系；未被讨论的真相成为后续冲突来源。
- 质量评价与可复用技法：极端决裂不必依赖吼叫，关键可以是双方失去共同解释框架。
