# 相遇剧情与对话设计模板

# 规范

本文只整理小说中出现过，或能由小说内容明确支撑的相遇剧情、对话推进、态度变化、信息差、选择后果和后续牵连，不写 UI 对话树，不写游戏选项 DSL，不写抽象数值表，也不把没有对话推进的普通战斗、普通日志或普通情报传播硬写成相遇剧情。

本模板关注“两个或多个人为什么会在此时此地相遇、双方如何开口、如何试探、如何交易或翻脸、对话结束后改变了什么”。如果重点是消息如何传播，放入 `信息传播与情报模板.md`；如果重点是玩家看见什么、日志如何呈现、信息如何被隐藏，放入 `有限视角与叙事日志模板.md`；如果重点是单场冲突的起因、升级和结算，放入 `冲突事件分析模板.md`；如果重点是长期关系变化，放入 `人物关系与事件分析模板.md`。

每部作品至少选择 20 个相遇剧情样本。样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局，不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本。

原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

## 参考和要求

本部分是写作要求与参考整理范围。参考范围不是限定范围，仅用于提示检索方向；原文有其他相关内容也应继续补充。

- 相遇名称和类型：写弱者遭遇强者试探、拍卖后截杀、秘境临时组队、旧识重逢、宗门招揽、通缉追杀、身份暴露、救援求助等类型，并简要点明这次相遇的核心冲突。
- 参与者：写双方姓名、境界、身份、势力、隐藏身份、已知关系和潜在敌意；境界或身份不明时写“原文未说明”。
- 相遇地点：写坊市、宗门、秘境、洞府、荒野、海域、战场、拍卖场、传送阵、凡俗城镇等；地点不明时写“原文未说明”。
- 相遇前状态：写双方为何在此、各自目标、压力、伤势、资源、任务、逃亡或情报差。
- 触发条件：写地点相遇、任务指派、资源暴露、气息感应、身份识破、旧怨、通缉、秘境入口、路线重叠等具体触发点。
- 开场态度：写警惕、友善、冷漠、试探、轻视、敌意、伪装、求助、求饶、审问、威胁、拉拢等。
- 对话推进：写谁先问、问什么、谁隐瞒、谁试探、谁提出交易、谁威胁、谁让步、谁拒绝，不要只写“双方交谈”。
- 信息差：写谁知道真相，谁只知道一部分，谁误判，谁隐藏境界、身份、实力、宝物价值或动机。
- 回应方式：写顺从、拒绝、隐瞒、反问、交易、拖延、求援、示弱、威胁、逃跑、反制、假装合作等，必须基于原文相似案例。
- 冲突升级点：写哪句话、动作、暴露点或条件变化导致战斗、合作、交易、求援或翻脸。
- 结果与变化：写开战、放行、结盟、交易、失去资源、获得情报、欠人情、关系变化、任务开启等结果。
- 后续牵连：写再次相遇、复仇、报恩、泄密、带路、埋伏、分赃纠纷、宗门介入、势力站队或长期敌对。
- 典型场景重点：强弱差相遇重点写境界压迫和保命话术；交易后风险重点写财富暴露和离开安全区后的升级点；秘境临时组队重点写分工、分配规则和合作破裂条件；旧识重逢重点写身份变化和旧关系重估；通缉追杀重点写确认方式、求饶或谈崩节点；宗门招揽重点写报酬、风险、门规和是否站队；身份暴露重点写识破方式、知情范围和补救代价；救援求助重点写求助代价、可信度判断和人情债。

```md
### 弱者遭遇强者试探或控制

- 相遇名称和类型：弱者遭遇强者试探 / 控制 / 交易；适合用于低阶角色因资源、灵兽、特殊能力或身份暴露，被高阶修士审问、交易、威胁或强制合作的相遇。
- 参与者：一方通常是境界较低、需要隐藏实力或保命的角色；另一方是高阶修士、宗门长老、妖修、魔道修士、强势散修或掌握场面主动权的人。具体姓名、境界和势力按原文填写。
- 相遇地点：可以发生在洞府、秘境、坊市、荒野、海域、宗门驻地、被抓后的临时据点等场景；地点不明写“原文未说明”。
- 相遇前状态：弱者可能正在赶路、采药、逃亡、交易、参加秘境或隐藏资源；强者可能因资源、功法、灵兽、丹药、法宝或情报而注意到对方。
- 触发条件：资源暴露、气息异常、身份可疑、被人举报、被强者搜查、同处秘境、被禁制困住、被强者抓住或被迫合作。
- 开场态度：强者多为审视、试探、命令、威胁、轻视或假意交易；弱者多为警惕、顺从、隐藏、拖延、装糊涂或寻找逃生机会。
- 对话推进：强者会询问身份、来历、资源获取、功法能力、是否愿意合作或交出物品；弱者会尽量少说实话，避免暴露底牌，必要时承诺配合、提出交换、拖延时间或转移话题。若强者明确下禁制、设条件、给任务或逼迫炼制、带路，要详细写清。
- 信息差：强者可能知道弱者有价值，但不知道全部底牌；弱者知道自己处于劣势，但可能掌握强者不知道的特殊物品、灵兽、毒、禁制破绽或逃生手段。
- 回应方式：顺从保命、隐瞒关键资源、提出交易、拖延时间、假装能力不足、寻找外部机会、趁强者疏忽逃跑、反问试探强者目的。
- 冲突升级点：强者索要核心资源、发现隐瞒、试图控制身体或行动、下禁制、逼迫执行危险任务、弱者反制或逃跑。
- 结果与变化：可能形成临时合作、强制控制、被迫交易、逃亡、反杀、结仇或后续追杀；弱者可能失去部分资源或暴露底牌，也可能借机获得情报或保命机会。
- 后续牵连：被控制者逃走后可能引出追杀、通缉、隐姓埋名、换地图、报复或长期警惕强者的性格变化。

### 坊市或拍卖后的交易、跟踪与截杀

- 相遇名称和类型：交易谈判 / 财富暴露 / 拍卖后截杀 / 黑吃黑试探；适合用于拍得宝物者离开安全区后被试探、跟踪、强买或截杀的相遇。
- 参与者：拍得宝物者、卖家、商会、跟踪者、劫修、邪修、护卫、同场竞价失败者、情报贩等；具体境界和势力按原文填写。
- 相遇地点：坊市、拍卖场、商会后堂、客栈、城外道路、传送阵附近、荒野、黑市出口。
- 相遇前状态：某人刚购买、出售或暴露高价值资源；另一方因竞价失败、贪图宝物、受雇跟踪、怀疑身份或想强买强卖而靠近。
- 触发条件：拍品价格过高、宝物价值暴露、灵石数量惊人、身份伪装失败、商会消息泄露、有人暗中标记、离开安全区。
- 开场态度：可能先礼后兵、假意交易、开价收购、试探来历、威胁交出宝物、装作偶遇、请到偏僻处谈话。
- 对话推进：跟踪者可能询问拍品是否愿意转让、试探对方后台、开价、威胁、暗示城外不安全；持宝者可能拒绝、抬价、隐瞒、拖延、假装有后台、寻找脱身机会。若商会或第三方参与调停，也要写清立场。
- 信息差：跟踪者可能不知道持宝者真实实力或逃生手段；持宝者可能不知道对方人数、后台、埋伏地点或是否有内应。
- 回应方式：立即拒绝、提高价格、假装背后有强者、转移地点、请求商会保护、分散出售、反跟踪、提前设伏、交出一部分资源保命。
- 冲突升级点：对方拒绝交易、离开安全区、身份被识破、跟踪暴露、威胁升级、第三方插手、持宝者反制。
- 结果与变化：可能交易成功、谈崩开战、被截杀、反杀、逃走、报官或报宗门，形成通缉和后续追杀；宝物、灵石、护卫费、情报费、法宝损耗、战利品和人情随之变化。
- 后续牵连：财富暴露可能引出连续追杀、换身份、换地图、黑市悬赏、宗门庇护或报复；商会信誉和安全边界也可能被重新评估。
```
