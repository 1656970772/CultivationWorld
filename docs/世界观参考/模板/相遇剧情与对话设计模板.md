# 相遇剧情与对话设计模板

## 适用范围

用于整理作品中出现过，或能由原文、资料来源和可靠依据支撑的相遇剧情、对话推进、态度变化、信息差、选择后果和后续牵连。

本模板关注“为什么此时此地相遇、双方如何开口、如何试探或交易、为何翻脸或合作、结束后改变了什么”。如果重点是消息传播，放入 `信息传播与情报模板.md`；如果重点是日志呈现，放入 `有限视角与叙事日志模板.md`；如果重点是单场冲突结算，放入 `冲突事件分析模板.md`；如果重点是长期关系变化，放入 `人物关系与事件分析模板.md`。

## 前置声明

- 样本尽量覆盖强弱差、同阶试探、旧识重逢、敌对遭遇、临时组队、交易谈判、招揽、追杀求饶、身份暴露、隐瞒身份、误判、救援、审问和合作破裂等。
- 不要只写主角；NPC、宗门成员、散修、妖兽、异族、旁观者和被牵连者，只要原文有支撑，都可纳入。
- 每部作品至少整理 20 个相遇样本；如果原文中可支撑样本不足 20 个，应列出已找到样本，并说明不足依据。案例数量不是上限。
- 原文没有说明境界、身份、地点、动机、台词、资源、关系或后续影响时，写“原文未说明”。
- 信息暂不完整但值得保留时，先放入 `### 待定案例`；后续补充来源，足以成例后再转入 `### 案例`。

## 必须写什么

本部分是参考整理范围/字段提示，不是封闭清单，也不是只能写这些；原文有相关内容可继续补充。

通用卡片字段：

| 字段 | 写法提示 |
|------|----------|
| 相遇名称和类型 | 写弱者遭遇强者试探、拍卖后截杀、秘境临时组队、旧识重逢、宗门招揽、通缉追杀等。 |
| 参与者 | 写双方姓名、境界、身份、势力、隐藏身份、已知关系和潜在敌意。 |
| 相遇地点 | 写坊市、宗门、秘境、洞府、荒野、海域、战场、拍卖场、传送阵、凡俗城镇等。 |
| 相遇前状态 | 写双方为何在此、各自目标、压力、伤势、资源、任务、逃亡或情报差。 |
| 触发条件 | 写资源暴露、气息感应、身份识破、旧怨、命令、通缉、秘境入口、路线重叠等。 |
| 开场态度 | 写警惕、友善、冷漠、试探、轻视、敌意、伪装、求助、求饶、威胁等。 |
| 对话推进 | 写谁先问、问什么、谁隐瞒、谁试探、谁提出交易、谁威胁、谁让步、谁拒绝。 |
| 信息差 | 写谁知道真相，谁只知道一部分，谁误判，谁隐藏境界、身份、实力或动机。 |
| 冲突升级点 | 写哪句话、动作、暴露点或条件变化导致战斗、合作、交易、求援或翻脸。 |
| 结果与变化 | 写开战、放行、结盟、交易、失去资源、获得情报、欠人情、关系变化、任务开启等。 |
| 后续牵连 | 写再次相遇、复仇、报恩、泄密、带路、埋伏、分赃纠纷、宗门介入或长期敌对。 |
| 来源依据 | 写原文位置、资料来源或可靠依据；可集中列出原文未说明的字段。 |

类型提示：

| 类型 | 示例 | 重点 |
|------|------|------|
| 强弱差相遇 | 强者审问、控制、交易、试探低阶角色。 | 境界压迫、保命话术、底牌隐藏、强制任务或逃生机会。 |
| 交易后风险 | 坊市、拍卖、黑市离场后的跟踪、强买强卖或截杀。 | 财富暴露、商会边界、跟踪者信息差、离开安全区后的升级点。 |
| 秘境临时组队 | 入口碰面、破禁合作、分赃谈判、背叛。 | 分工、信任、隐藏目标、分配规则、合作破裂条件。 |
| 旧识重逢 | 旧友、旧敌、同门、师徒、家族成员再见。 | 身份变化、旧印象失效、旧恩怨重估、关系再激活。 |
| 通缉追杀 | 身份确认、求饶、赔偿、反杀或逃亡。 | 通缉来源、确认方式、追杀者误判、求饶或谈崩节点。 |
| 宗门招揽 | 客卿、任务、担保、庇护、人情谈判。 | 报酬、风险、门规、保密、失败后果、是否站队。 |

## 案例

### 案例

| 案例方向 | 最小写法示例 | 不可漏写的重点 |
|----------|--------------|----------------|
| 弱者遭遇强者试探或控制 | 低阶角色因资源、灵兽、特殊能力或身份暴露，被高阶修士审问、交易、威胁或强制合作。 | 双方境界差、强者目的、弱者保命话术、信息差、控制条件、逃脱或后续追杀。 |
| 坊市或拍卖后的交易、跟踪与截杀 | 拍得宝物者离开安全区后，被竞价失败者、劫修、商会内应或情报贩试探、跟踪、强买或截杀。 | 财富暴露路径、商会保护范围、谈判转折、跟踪者误判、资源和关系变化。 |
| 秘境临时组队与分赃谈判 | 多方因禁制、地图、战力或时间限制临时同行，围绕分工、立誓、取宝和分赃谈判。 | 入队条件、隐藏目标、分配规则、背叛预兆、合作破裂或人情建立。 |
| 旧识重逢与身份变化 | 多年未见的旧友、旧敌、同门或亲族在新地点重逢，境界、势力和处境已变。 | 旧关系、身份重估、旧怨旧恩、旁观者是否知情、后续关系走向。 |
| 通缉、追杀与求饶遭遇 | 被通缉者被认出或追上，双方围绕身份、罪名、赔偿、资源和生死选择对话。 | 通缉传播、确认方式、求饶或反制、悬赏变化、逃亡路线和新仇怨。 |
| 宗门招揽、任务交涉与人情谈判 | 势力方因战力、技艺、情报或资源招揽散修、客卿或弟子，并谈条件。 | 任务风险、报酬、担保、门规束缚、保密要求、失败后果和站队影响。 |
