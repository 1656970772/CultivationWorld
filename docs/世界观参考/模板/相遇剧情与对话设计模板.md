# 相遇剧情与对话设计模板

> 最后更新：2026-06-19
> 状态：模板
> 类型：角色相遇、剧情触发、对话推进、选择后果与关系变化调研
> 目标详细程度：L3
> 输出限制：最终输出文档只按本模板中的案例格式和字段输出；不要额外添加模板未要求的章节、说明或扩展内容。

## 前置声明

本模板所有调研文档都必须尽量覆盖多境界、多身份、多地域、多势力、多场景和多结局样本。不要只写主角、单一境界、少数名场面或少数成功案例；低阶、中阶、高阶、凡人、散修、宗门弟子、长老、邪修、妖兽、异族、势力成员、失败者、旁观者和被牵连者，只要原文有支撑，都应纳入样本范围。

文档长度不作限制，样本范围必须足够大。模板中的案例只是最低写法示范，不是数量上限；实际整理作品时，原文中有多少有价值内容就继续展开多少。原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

本文只整理小说中出现过，或能由小说内容明确支撑的相遇剧情、对话推进、态度变化、信息差、选择后果和后续牵连，不写 UI 对话树，不写游戏选项 DSL，不写抽象数值表，也不把没有对话推进的普通战斗、普通日志或普通情报传播硬写成相遇剧情。

本模板关注的是“两个或多个人为什么会在此时此地相遇、双方如何开口、如何试探、如何交易或翻脸、对话结束后改变了什么”。如果重点是消息如何传播，放入 `信息传播与情报模板.md`；如果重点是玩家看见什么、日志如何呈现、信息如何被隐藏，放入 `有限视角与叙事日志模板.md`；如果重点是单场冲突的起因、升级和结算，放入 `冲突事件分析模板.md`；如果重点是长期关系变化，放入 `人物关系与事件分析模板.md`。

每部作品至少选择 20 个相遇剧情样本。样本要覆盖强弱境界差、同阶试探、旧识重逢、敌对遭遇、临时组队、交易谈判、宗门招揽、追杀求饶、身份暴露、隐瞒身份、误判、救援、审问、威胁、合作破裂等不同类型。不要只写主角被强者试探，也要写 NPC 之间、宗门成员之间、散修之间、妖兽或异族与修士之间的相遇。

## 参考范围（不局限于以下类别）

- **相遇类型**：偶遇、伏击、追杀、救援、审问、求助、交易、招揽、拜访、威胁、谈判、久别重逢、身份暴露、秘境同行、拍卖后截杀、宗门任务碰面、敌人狭路相逢、凡人与修士接触。
- **触发条件**：地点相遇、任务指派、资源暴露、气息感应、宝物认主、通缉名单、旧怨、情报泄露、身份识破、伤势暴露、境界压制、同门关系、势力命令、秘境入口、拍卖场外、逃亡路线重叠。
- **开场态度**：警惕、友善、冷漠、试探、轻视、敌意、伪装、求助、求饶、审问、威胁、拉拢、沉默观察、先礼后兵、虚与委蛇。
- **对话推进**：问路、查身份、探底牌、交换情报、提出交易、索要资源、许诺报酬、威胁杀人、请托任务、谈条件、逼迫站队、揭穿伪装、确认旧事、讨债、分赃、道别。
- **信息差**：隐藏境界、隐藏身份、假名、伪装散修、误判实力、误信传闻、不了解旧怨、不知道宝物价值、只知道部分真相、故意放假消息。
- **回应方式**：顺从、拒绝、隐瞒、反问、交易、拖延、求援、示弱、威胁、逃跑、反制、沉默、不承认、假装合作、转移话题。
- **结果类型**：开战、放行、结盟、交易成功、交易失败、加入队伍、获得情报、失去资源、欠下人情、关系变好、关系恶化、身份暴露、通缉升级、任务开启、后续追杀。
- **后续牵连**：再次相遇、复仇、报恩、泄密、带路、埋伏、分赃纠纷、宗门介入、势力站队、长期合作、长期敌对、进入下一条事件因果链。

## 写作方式

### 案例格式

每个案例都要写成完整的“相遇剧情链”，不要只写一句“双方交谈”。要写清相遇前状态、触发条件、开场态度、对话内容、信息差、冲突升级点、结果和后续牵连。原文没有说明的字段写“原文未说明”。

#### 案例 N：相遇剧情名称

**相遇名称和类型：** 写清这次相遇是什么类型，例如弱者遭遇强者试探、拍卖后截杀、秘境临时组队、旧识重逢、宗门招揽、通缉追杀、身份暴露谈判。

**参与者：** 写清谁遇到谁，各自境界、身份、所属势力、隐藏身份、已知关系和潜在敌意。境界或身份不明时写“原文未说明”。

**相遇地点：** 写具体地点，例如坊市、宗门山门、秘境入口、洞府、荒野、海域、战场、拍卖场、传送阵、凡俗城镇、妖兽领地。地点不明写“原文未说明”。

**相遇前状态：** 写双方为什么会出现在这里，各自目标是什么，是否有伤势、资源压力、追杀压力、任务压力、隐藏身份、赶路需求、情报差。

**触发条件：** 写具体是什么让剧情触发，例如发现宝物、感应气息、认出身份、听到名字、看到伤势、接到命令、怀疑伪装、抢同一资源、误入地盘。

**开场态度：** 写双方一开始的态度。可以是警惕、友善、试探、轻视、威胁、求助、求饶、沉默观察、假装不认识、假装合作。

**对话内容：** 详细写对话推进。不要只写“双方交谈”；要写谁先问、问什么、谁隐瞒、谁试探、谁提出交易、谁威胁、谁让步、谁拒绝、谁转移话题。

**可选回应：** 如果要作为剧情参考，可以写这类相遇通常有哪些回应方向，例如顺从、拒绝、隐瞒、交易、威胁、求援、逃跑、反问试探、假装合作。必须基于原文相似案例，不要自行发明。

**对话中的信息差：** 写谁知道真相，谁只知道一部分，谁被误导，谁隐藏身份，谁判断错误，谁故意套话。

**冲突升级点：** 写哪句话、哪个动作、哪个暴露点导致剧情从对话变成战斗、追杀、合作、交易、求援或翻脸。

**对话结果：** 写是否开战、是否交易成功、是否获得情报、是否结盟、是否放走对方、是否失去资源、是否启动任务、是否引出后续事件。

**关系变化：** 写陌生变合作、合作变背叛、敌对加深、暂时互利、欠人情、结仇、被盯上、秘密关系公开等变化。

**资源变化：** 写灵石、丹药、法宝、材料、情报、人情、任务、地图、令牌、身份安全、逃生机会有什么变化。

**后续剧情钩子：** 写这次相遇以后是否引出追杀、报恩、复仇、再次相遇、秘境同行、宗门任务、拍卖截杀、势力介入、事件因果链。

**原文未说明：** 集中列出原文没有交代但调研时需要留意的部分，例如停留时间、旁观者、真实动机、消息传播范围、后续是否再见。

**可作为参考的点：** 写这次相遇对世界观和剧情设计的参考价值，例如强弱境界差压迫、伪装身份、试探台词、交易谈判、信息差、关系转折、后续任务触发。

## 完整相遇剧情案例

### 案例 1：弱者遭遇强者试探或控制

**相遇名称和类型：** 弱者遭遇强者试探 / 控制 / 交易。适合用于高阶修士发现低阶修士有特殊资源、特殊能力、特殊灵兽或可利用价值时的相遇。

**参与者：** 一方通常是境界较低、需要隐藏实力或保命的角色；另一方是高阶修士、宗门长老、妖修、魔道修士、强势散修或掌握场面主动权的人。具体姓名、境界和势力按原文填写。

**相遇地点：** 可以发生在洞府、秘境、坊市、荒野、海域、宗门驻地、被抓后的临时据点等场景。地点不明写“原文未说明”。

**相遇前状态：** 弱者可能正在赶路、采药、逃亡、交易、参加秘境或隐藏资源；强者可能因资源、功法、灵兽、丹药、法宝或情报而注意到对方。

**触发条件：** 资源暴露、气息异常、身份可疑、被人举报、被强者搜查、同处秘境、被禁制困住、被强者抓住或被迫合作。

**开场态度：** 强者多为审视、试探、命令、威胁、轻视或假意交易；弱者多为警惕、顺从、隐藏、拖延、装糊涂或寻找逃生机会。

**对话内容：** 强者会询问身份、来历、资源来源、功法能力、是否愿意合作或交出物品；弱者会尽量少说实话，避免暴露底牌，必要时承诺配合、提出交换、拖延时间或转移话题。若强者明确下禁制、设条件、给任务或逼迫炼制/带路，要详细写清。

**可选回应：** 顺从保命、隐瞒关键资源、提出交易、拖延时间、假装能力不足、寻找外部机会、趁强者疏忽逃跑、反问试探强者目的。

**对话中的信息差：** 强者可能知道弱者有价值，但不知道全部底牌；弱者知道自己处于劣势，但可能掌握强者不知道的特殊物品、灵兽、毒、禁制破绽或逃生手段。

**冲突升级点：** 强者索要核心资源、发现隐瞒、试图控制身体或行动、下禁制、逼迫执行危险任务、弱者反制或逃跑。

**对话结果：** 可能形成临时合作、强制控制、被迫交易、逃亡、反杀、结仇或后续追杀。

**关系变化：** 陌生或临时接触变成控制与被控制、利用与反利用、追杀与逃亡、强者忌惮弱者潜力。

**资源变化：** 弱者可能失去部分资源或暴露底牌，也可能借机获得宝物、情报、保命机会；强者可能得到阶段性控制权，也可能因误判失去资源。

**后续剧情钩子：** 被控制者逃走后可能引出追杀、通缉、隐姓埋名、换地图、报复或长期警惕强者的性格变化。

**原文未说明：** 旁观者是否知晓、强者是否公开通缉、控制手段持续多久、外部势力是否介入，按原文填写；不明写“原文未说明”。

**可作为参考的点：** 适合参考强弱境界差下的对话压迫、保命话术、伪装底牌、强制任务、控制关系和逃生剧情触发。

### 案例 2：坊市或拍卖后的交易、跟踪与截杀对话

**相遇名称和类型：** 交易谈判 / 财富暴露 / 拍卖后截杀 / 黑吃黑试探。

**参与者：** 拍得宝物者、卖家、商会、跟踪者、劫修、邪修、护卫、同场竞价失败者、情报贩。具体境界和势力按原文填写。

**相遇地点：** 坊市、拍卖场、商会后堂、客栈、城外道路、传送阵附近、荒野、黑市出口。

**相遇前状态：** 某人刚购买、出售或暴露高价值资源；另一方因竞价失败、贪图宝物、受雇跟踪、怀疑身份或想强买强卖而靠近。

**触发条件：** 拍品价格过高、宝物价值暴露、灵石数量惊人、身份伪装失败、商会消息泄露、有人暗中标记、离开安全区。

**开场态度：** 可能先礼后兵、假意交易、开价收购、试探来历、威胁交出宝物、装作偶遇、请到偏僻处谈话。

**对话内容：** 跟踪者可能询问拍品是否愿意转让、试探对方后台、开价、威胁、暗示城外不安全；持宝者可能拒绝、抬价、隐瞒、拖延、假装有后台、寻找脱身机会。若商会或第三方参与调停，也要写清立场。

**可选回应：** 立即拒绝、提高价格、假装背后有强者、转移地点、请求商会保护、分散出售、反跟踪、提前设伏、交出一部分资源保命。

**对话中的信息差：** 跟踪者可能不知道持宝者真实实力或逃生手段；持宝者可能不知道对方人数、后台、埋伏地点或是否有内应。

**冲突升级点：** 对方拒绝交易、离开安全区、身份被识破、跟踪暴露、威胁升级、第三方插手、持宝者反制。

**对话结果：** 可能交易成功、谈崩开战、被截杀、反杀、逃走、报官或报宗门、形成通缉和后续追杀。

**关系变化：** 竞价对手变仇敌，商会信誉受影响，护卫与雇主关系变化，黑市势力盯上持宝者。

**资源变化：** 宝物、灵石、手续费、护卫费、情报费、伤药、法宝损耗、战利品和人情变化。

**后续剧情钩子：** 财富暴露可能引出连续追杀、换身份、换地图、黑市悬赏、宗门庇护或报复。

**原文未说明：** 拍卖场规则、商会保护范围、跟踪者来源、消息泄露路径、是否有后续通缉，不明处写“原文未说明”。

**可作为参考的点：** 适合参考拍卖后风险、财富暴露、交易谈判、黑吃黑、商会安全边界和离开安全区后的剧情触发。

### 案例 3：秘境临时组队与分赃谈判

**相遇名称和类型：** 秘境同行 / 临时组队 / 互相试探 / 分赃谈判。

**参与者：** 主角、散修、宗门弟子、临时队友、带路者、破禁者、炼丹炼器职业者、隐藏实力者。境界和身份按原文填写。

**相遇地点：** 秘境入口、洞府外、禁制前、灵药园附近、危险通道、战斗结束后的分赃现场。

**相遇前状态：** 各方都想获得秘境资源，但单独行动风险高，可能缺地图、缺破禁手段、缺战力、缺治疗或缺信任对象。

**触发条件：** 入口限制、禁制难破、妖兽太强、地图不全、人数不足、时间窗口有限、共同敌人出现、某人掌握关键线索。

**开场态度：** 表面合作，实则警惕。可能先互报身份、试探境界、问资源目标、谈分配方式、确认谁带路、谁破禁、谁负责战斗。

**对话内容：** 各方围绕是否组队、如何分工、谁先取物、如何分赃、遇险谁负责、是否立誓或设禁制展开谈判。隐藏实力者可能故意低调，强势者可能要求优先选择权。

**可选回应：** 加入队伍、拒绝同行、只交换地图、要求先分配、要求立誓、隐藏目标、假装不懂、提出退出条件。

**对话中的信息差：** 队友可能隐瞒真实目标、地图缺口、特殊法宝、伤势、仇怨、背叛计划或对某件宝物的真实了解。

**冲突升级点：** 宝物出现、分配不均、有人抢先动手、有人暴露隐藏实力、有人引来妖兽、有人触发禁制、有人背叛。

**对话结果：** 临时合作、队伍破裂、分赃成功、分赃失败、背叛开战、各自逃命、建立长期关系或结仇。

**关系变化：** 陌生人变临时同伴，临时同伴变仇敌，竞争者变互利合作，救命者与被救者产生人情。

**资源变化：** 地图、令牌、灵药、妖兽材料、法宝、丹药、破禁工具、战利品、疗伤资源和人情变化。

**后续剧情钩子：** 背叛者可能被追杀，幸存者可能再次合作，分赃不均可能引出复仇，秘境消息可能外泄。

**原文未说明：** 队伍契约、分赃规则、背叛者后续、旁观者是否知晓，不明处写“原文未说明”。

**可作为参考的点：** 适合参考临时组队、互相试探、分赃谈判、背叛预兆、秘境合作破裂和人情债建立。

### 案例 4：旧识重逢与身份变化

**相遇名称和类型：** 久别重逢 / 身份变化 / 信息差确认 / 关系重估。

**参与者：** 旧友、旧敌、同门、师徒、道侣、家族成员、曾经受恩者、曾经羞辱者、已经改换身份或境界大变的人。

**相遇地点：** 宗门、坊市、战场、拍卖会、秘境、外地大城、逃亡途中、凡俗故地。

**相遇前状态：** 双方曾有旧关系，但多年未见，境界、身份、势力、资源和处境已经变化。一方可能知道更多，一方可能仍停留在旧印象。

**触发条件：** 认出名字、认出功法、看到旧物、听到传闻、共同任务、被同一事件牵连、身份暴露、主动拜访。

**开场态度：** 惊讶、警惕、怀念、尴尬、敌意、试探、冷淡、热络、假装不认识。

**对话内容：** 双方确认身份、询问近况、试探境界和势力、提及旧事、回避伤痛、请求帮助、提出交易、确认是否仍可信。

**可选回应：** 承认身份、隐瞒身份、叙旧、切断旧关系、请求帮助、偿还人情、保持距离、转为交易关系。

**对话中的信息差：** 一方可能不知道另一方已经加入新势力、修为大涨、失去靠山、被通缉、背负旧怨或隐藏真实目标。

**冲突升级点：** 旧怨被揭开、身份被旁人发现、势力立场冲突、有人提出不可能接受的请求、过去恩情或仇恨重新结算。

**对话结果：** 恢复关系、关系疏远、短暂合作、互相放过、旧仇复燃、欠下人情、开启新任务或新的追杀。

**关系变化：** 旧友变盟友、旧友变陌路、旧敌暂时合作、同门变竞争者、恩人和受恩者关系重估。

**资源变化：** 情报、人情、庇护、推荐、任务线索、旧物、传承、债务、身份安全变化。

**后续剧情钩子：** 旧识可能成为后续联系人、告密者、盟友、敌人、牵线人、求援对象或复仇对象。

**原文未说明：** 多年空白经历、双方是否互相打听过、旁观者是否知道旧关系，不明处写“原文未说明”。

**可作为参考的点：** 适合参考长时间跨度后的身份重估、旧关系再激活、信息差确认、情感与利益冲突。

### 案例 5：通缉、追杀与求饶遭遇

**相遇名称和类型：** 通缉追杀 / 敌对遭遇 / 求饶谈判 / 生死选择。

**参与者：** 被通缉者、追杀者、悬赏修士、宗门执法者、受害者亲友、邪修、路人旁观者、临时帮手。

**相遇地点：** 荒野、城门、坊市外、传送阵附近、宗门边境、山谷、海域、秘境出口、客栈。

**相遇前状态：** 一方正在逃亡或隐藏身份，另一方根据通缉、悬赏、仇怨、情报或追踪手段寻找目标。

**触发条件：** 身份被认出、气息暴露、通缉画像匹配、法器追踪、受伤无法隐藏、同伴泄密、进入敌方地盘。

**开场态度：** 追杀者通常直接质问、包围、威胁或确认身份；被追杀者可能否认、求饶、拖延、交易、示弱或直接逃跑。

**对话内容：** 追杀者可能要求交出资源、说明罪名、确认身份、索命、索赔或逼问同伙；被追杀者可能辩解、交出部分资源、许诺报酬、威胁反扑、指出误会或寻找破绽。

**可选回应：** 否认身份、承认但求饶、交出资源、请求放行、威胁同归于尽、拖延援兵、假投降、突然逃跑、反杀。

**对话中的信息差：** 追杀者可能不知道目标还有底牌、同伙或伪装身份；被追杀者可能不知道追杀者人数、悬赏来源、是否有埋伏。

**冲突升级点：** 身份坐实、谈判失败、对方不接受赔偿、资源暴露、援兵到达、逃跑动作被发现。

**对话结果：** 被杀、逃走、反杀、被俘、交出资源保命、通缉升级、误会解除、临时交易。

**关系变化：** 仇怨加深、追杀者与被追杀者形成长期敌对、旁观者被牵连、帮忙者与逃亡者建立人情。

**资源变化：** 悬赏、赔偿、保命资源、逃生符箓、丹药、法宝损耗、战利品、情报变化。

**后续剧情钩子：** 逃亡路线变化、换身份、投靠势力、报复追杀者、悬赏升级、宗门介入。

**原文未说明：** 通缉令传播范围、追杀者如何确认身份、旁观者是否报信、后续悬赏是否变化，不明处写“原文未说明”。

**可作为参考的点：** 适合参考敌对开场、求饶话术、悬赏追杀、身份确认、谈判失败和逃亡后续。

### 案例 6：宗门招揽、任务交涉与人情谈判

**相遇名称和类型：** 宗门招揽 / 任务交涉 / 人情谈判 / 立场选择。

**参与者：** 宗门长老、执事、弟子、散修、客卿、任务发布者、被招揽者、推荐人、担保人。

**相遇地点：** 宗门大殿、坊市驻点、客栈、试炼场、战后营地、拍卖会后堂、洞府拜访。

**相遇前状态：** 一方需要人手、战力、技艺、情报或特殊资源；另一方需要靠山、任务奖励、修炼资源、身份保护、进入宗门或避祸机会。

**触发条件：** 展现实力、完成任务、救人、拥有特殊技艺、缺少靠山、被推荐、被势力关注、主动投靠。

**开场态度：** 宗门或势力方可能客气、审查、试探、许诺、压价或摆出上位姿态；被招揽者可能谨慎、讨价还价、隐瞒底牌或试探条件。

**对话内容：** 双方围绕任务目标、报酬、风险、身份、门规、期限、保密要求、失败后果、人情债、是否正式加入或临时合作进行交涉。

**可选回应：** 接受任务、拒绝任务、提高报酬、要求担保、要求保护、只做临时合作、隐瞒真实目的、请求宽限、提出交换条件。

**对话中的信息差：** 发布任务者可能隐瞒真实风险，被招揽者可能隐瞒实力、仇家、资源或真实身份。双方都可能试探对方底线。

**冲突升级点：** 条件谈崩、发现任务风险过高、身份被查出、报酬不符、被迫站队、拒绝后被威胁。

**对话结果：** 接任务、加入宗门、成为客卿、临时合作、拒绝并离开、关系恶化、被软禁、获得庇护或欠下人情。

**关系变化：** 陌生散修变客卿，弟子变核心培养对象，受助者欠人情，拒绝者被记恨，推荐人承担担保关系。

**资源变化：** 任务奖励、贡献、丹药、洞府、身份令牌、庇护、人情债、门规约束、失败处罚变化。

**后续剧情钩子：** 任务开启、宗门内部派系牵连、客卿身份带来保护或束缚、拒绝招揽引发敌意、任务失败造成通缉或赔偿。

**原文未说明：** 任务具体风险、担保关系、失败处罚、宗门后续态度，不明处写“原文未说明”。

**可作为参考的点：** 适合参考任务接取谈判、宗门招揽、客卿关系、人情债、加入势力前的条件博弈。
