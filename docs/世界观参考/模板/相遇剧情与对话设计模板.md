# 相遇剧情与对话设计模板

## 适用范围

本模板用于整理作品中由原文明确出现或明确支撑的相遇剧情、直接对话、试探交易、威胁控制、求助救援、身份暴露、旧识重逢、临时合作、谈崩翻脸、关系转折和后续牵连。

本模板只做相遇剧情与对话设计分析，不写 UI 对话树，不写游戏选项 DSL，不写抽象数值表。没有双方直接接触、没有对白推进、没有态度变化或行动结果的普通战斗、独角戏、日志、信息传播、公开测试、心理活动、纯旁观反应，不应作为相遇剧情卡；可按重点转入 `信息传播与情报模板.md`、`有限视角与叙事日志模板.md`、`冲突事件分析模板.md` 或 `人物关系与事件分析模板.md`。

## 整理原则

1. 先做入选判定  
   相遇卡必须同时具备：至少两方在同一时空发生直接接触；存在开场态度与回应；存在对白、试探、交易、威胁、让步、拒绝、隐瞒、翻脸中的至少一种推进；对关系、信息或行动造成变化。  
   若参与者只有一人，或只能写成“原文无对话”“纯动作”“独自实验”“独自研读”，不得进入本模板。

2. 区分相遇、信息传播和独角戏  
   `韩立山路意外受伤发现神秘瓶子`、`韩立夜间实验瓶子光丝吸收能力`、`韩立心魔入侵与平安符化解`、`韩立独自解读七绝堂藏书`属于独角戏或个人发现，不建相遇卡。  
   `韩立得知张铁失踪真相`、`金冬宝解释七玄门与野狼帮冲突及门规变化`偏信息传播，只有明确存在对话博弈时才可进入本模板。  
   `成人仪式复测展示八段斗之气震撼全场`偏公开测试和群体反应，不宜硬写成相遇对话卡。

3. 一场相遇一卡  
   同一时间、地点、参与者和目标连续一致的对话，应合并为一张卡，并在“对话阶段”中分段呈现。  
   例如 `墨大夫摊牌、长春功用途、尸虫丸、父母威胁、首度交锋失败`可合并为一场强制控制对话；`韩立配制止痛药与厉飞雨取药`和`韩立交付止痛药与厉飞雨取药`属于同一资源交付线，不要重复拆卡。只有目标、关系状态或场景断裂时才拆分。

4. 样本覆盖要均衡  
   每部作品至少选择 20 个有效相遇剧情样本；样本要覆盖多境界、多身份、多地域、多势力、多场景和多结局，不要只写主角、早期地图、单一势力、少数名场面或少数成功案例。  
   若有效样本不足，应说明“样本未达标”，并区分是原文不足、处理范围不足还是遗漏待补。

5. 优先提取有情绪价值的对话  
   相遇样本应优先选择能调动观看者情绪的对话，例如有压迫感、羞辱感、爽点、反转、误会、试探、幽默、尴尬、暧昧、讽刺、恐惧、悲伤、热血、谈判拉扯或关系破裂的场景。  
   普通寒暄、流水账问答、单纯交代任务、没有信息差和情绪波动的功能性对话，不宜成卡；除非它直接导致关系、资源、身份或行动发生重要变化。

6. 字段完整  
   每张卡必须包含：相遇名称和类型、入选理由、情绪钩子、参与者、相遇地点、相遇前状态、触发条件、开场态度、对话功能、对话阶段、信息差、回应方式、冲突升级点、结果与变化、后续牵连、事实状态。  
   原文没有说明的境界、身份、地点、资源、关系、结果或后续影响，统一写“原文未说明”，不要为了补齐结构而虚构。

7. 对话阶段按多轮写  
   对话阶段按第 1 轮、第 2 轮、第 3 轮等多轮推进来写，不需要拆成固定子流程。  
   每一轮都应尽量写出该轮推进相关的原文对白，再补一句说明这一轮完成了什么作用，如开场、试探、压迫、隐瞒、反击、交易、让步、拒绝、翻脸、收束等。不要只写“双方交谈”。

8. 原文对白要写进轮次  
   对话阶段里尽量保留本场对话中有推进作用的原文对白，不要把对白全部改写成摘要。  
   无信息差、无情绪价值、无推进作用的寒暄和重复句可以略去；关键的压迫句、反击句、误会句、笑点句、让步句和翻脸句应保留原文。

9. 对话推进要聚焦  
   不要把整章剧情、外貌描写、心理描写、完整战斗过程、台下反应或泛用写作说明塞进“对话阶段”。

10. 推测和复用要分开  
   后续牵连只写原文明确发生或可以直接归纳的变化；不要用“可能”“埋下伏笔”等泛化说法冒充原文事实。  
   正式卡片里不要写“适合用于……”这类模板说明句；如果需要沉淀写作方法，应另放“可复用设计模式”，并与原文事实区分。

11. 敏感场景降噪  
   涉及羞辱、性威胁、越界肢体接触等内容时，只分析对话功能、权力关系、边界越界、关系后果和后续影响，不复述刺激性细节。

12. 生成后自检  
   检查是否把独角戏、公开测试、纯战斗、信息传播、心理活动误当相遇卡；是否重复拆分同一场连续对话；是否只覆盖早期地图或少数主角场景；是否出现“原文无对话”却仍建卡；是否把没有情绪张力的流水账对话硬写成卡；是否把泛用设计说明写进正式卡片。

## 字段说明

- 相遇名称和类型：写这场相遇的名称和类型，如弱者遭遇强者试探、强制控制、交易谈判、求助救援、身份暴露、旧识重逢、临时合作、问罪对峙、谈崩翻脸等。
- 入选理由：说明这为什么是相遇剧情，而不是独角戏、信息传播、公开测试或纯战斗。
- 情绪钩子：写这场对话调动情绪的核心点，如压迫、羞辱、反杀爽点、误会、幽默、尴尬、讽刺、悲伤、热血、暧昧、谈判拉扯、关系破裂等。
- 参与者：写双方或多方姓名、境界、身份、势力、隐藏身份、已知关系和潜在敌意；不明写“原文未说明”。
- 相遇地点：写坊市、宗门、秘境、洞府、荒野、海域、战场、拍卖场、传送阵、凡俗城镇等；地点不明写“原文未说明”。
- 相遇前状态：写双方为何在此、各自目标、压力、伤势、资源、任务、逃亡状态、已知情报和误判。
- 触发条件：写地点重叠、任务指派、资源暴露、气息感应、身份识破、旧怨、通缉、秘境入口、路线重叠、求助上门等具体触发点。
- 开场态度：写警惕、友善、冷漠、试探、轻视、敌意、伪装、求助、求饶、审问、威胁、拉拢等。
- 对话功能：写开场、试探、隐瞒、交易、威胁、让步、拒绝、翻脸、收束等功能，至少标出核心功能。
- 对话阶段：按多轮写，每轮包含“原文对白”和“推进作用”；轮次数量按原文实际对话决定，不强行固定。
- 信息差：写谁知道真相，谁只知道一部分，谁误判，谁隐藏境界、身份、实力、宝物价值、动机、后手或真实目的。
- 回应方式：写顺从、拒绝、隐瞒、反问、交易、拖延、求援、示弱、威胁、逃跑、反制、假装合作等。
- 冲突升级点：写哪句话、动作、暴露点或条件变化导致战斗、合作、交易、求援、翻脸或关系转折。
- 结果与变化：写开战、放行、结盟、交易、失去资源、获得情报、欠人情、关系变化、任务开启等结果。
- 后续牵连：写再次相遇、复仇、报恩、泄密、带路、埋伏、分赃纠纷、宗门介入、势力站队或长期敌对；无明确后续写“原文未说明”。
- 事实状态：写原文明确、原文可归纳、原文未说明；用于标注该卡内容的确定程度。

### 韩立与厉飞雨毒誓对峙

- 相遇名称和类型：弱者识破秘密后的持刀威胁与保命谈判
- 入选理由：双方正面接触，有威胁、解释、交易和承诺，关系从潜在杀意转为暂时合作。
- 情绪钩子：死亡威胁下的保命谈判，弱者用“有价值”换取活路。
- 参与者：韩立；厉飞雨。
- 相遇地点：原文未说明。
- 相遇前状态：韩立识破抽髓丸代价；厉飞雨担心秘密暴露并掌握武力主动。
- 触发条件：韩立指出抽髓丸隐患，厉飞雨以武力逼问。
- 开场态度：厉飞雨威胁、审问；韩立警惕、求生、解释。
- 对话功能：威胁、试探、解释、让步、承诺、收束。
- 对话阶段：
  - 第 1 轮：
    - 原文对白：“给我一个不杀你的理由。”
    - 推进作用：厉飞雨直接把相遇推到生死威胁，逼韩立证明自己还有价值。
  - 第 2 轮：
    - 原文对白：“我能救你。”
    - 推进作用：韩立用救治价值反压对方需求，从被杀对象变成可交易对象。
- 信息差：厉飞雨知道自身服药风险但未掌握完整解决方式；韩立知道药物副作用并隐藏自己的后续筹码。
- 回应方式：韩立解释、承诺、发誓、以救治价值争取生机。
- 冲突升级点：厉飞雨认为韩立知道秘密后可能泄露，威胁升级。
- 结果与变化：双方形成不稳定合作，韩立获得活命空间，厉飞雨依赖韩立处理药物问题。
- 后续牵连：止痛药交付和后续互相利用关系延续。
- 事实状态：原文明确。

- 情绪钩子：公开羞辱后的尊严反击，低谷角色用狠话夺回主动权。
- 参与者：萧炎、纳兰嫣然、萧战、云岚宗相关人物、萧家旁观者。
- 相遇地点：萧家大厅。
- 相遇前状态：萧炎处于低谷并承受家族压力；纳兰嫣然带宗门背景提出退婚。
- 触发条件：纳兰嫣然上门解除婚约。
- 开场态度：纳兰嫣然强势、克制；萧战受辱愤怒；萧炎压抑后反击。
- 对话功能：试探、羞辱、拒绝、立约、翻脸、收束。
- 对话阶段：
  - 第 1 轮：
    - 原文对白：“三十年河东，三十年河西。”
    - 推进作用：萧炎从被动受辱转为当众反击，情绪从压抑转为爆发。
  - 第 2 轮：
    - 原文对白：“莫欺少年穷。”
    - 推进作用：萧炎用狠话完成尊严反击，把退婚羞辱转化为未来约战目标。
- 信息差：纳兰嫣然低估萧炎反弹；萧炎的未来潜力尚未被对方看见。
- 回应方式：萧炎拒绝被动羞辱，以公开宣言和约定夺回主动权。
- 冲突升级点：退婚要求触及家族尊严与个人尊严。
- 结果与变化：婚约破裂，三年之约开启，萧炎与云岚宗线形成长期冲突。
- 后续牵连：后续修炼目标、宗门对立和再次对决由此展开。
- 事实状态：原文明确。

### 张衍与闵楼初会

- 相遇名称和类型：陌生修士试探与学识证明
- 入选理由：双方初次直接接触，有质疑、试探、回应和身份确认，推动后续求解与资源馈赠。
- 情绪钩子：被质疑者不急着解释，而是用“你可一试”把压力还给对方。
- 参与者：张衍；闵楼。
- 相遇地点：原文未说明。
- 相遇前状态：张衍具备解读能力；闵楼对其能力存疑并带着求证目的接触。
- 触发条件：闵楼围绕蚀文解读能力发起试探。
- 开场态度：闵楼质疑、试探；张衍沉稳、应对。
- 对话功能：开场、试探、能力展示、身份确认、关系缓和。
- 对话阶段：
  - 第 1 轮：
    - 原文对白：“君可一试。”
    - 推进作用：张衍不急着解释，用一句回应把被审问变成现场验证。
- 信息差：闵楼不确定张衍真实水平；张衍知道自身能力但需控制展示尺度。
- 回应方式：张衍以接受测试和稳定回应建立可信度。
- 冲突升级点：能力真伪被当场验证。
- 结果与变化：闵楼认可张衍能力，为后续请托和馈赠建立基础。
- 后续牵连：闵楼后续携礼并形成请托关系。
- 事实状态：原文明确。

- 参与者：张衍；卞桥。
- 相遇地点：千丈岩 / 千人岩。
- 相遇前状态：双方围绕道诀、丹药或赌约形成压力与利益冲突。
- 触发条件：约定、问罪或资源结算触发当面对峙。
- 开场态度：一方强势追问或施压；另一方防守、反驳或据理争取。
- 对话功能：问罪、威胁、交易、让步、结算、收束。
- 对话阶段：
  - 第 1 轮：
    - 原文对白：原文未说明。
    - 推进作用：双方被推到公开对峙位置，资源归属成为焦点。
  - 第 2 轮：
    - 原文对白：原文未说明。
    - 推进作用：规则争执变成资源和颜面的双重较量。
  - 第 3 轮：
    - 原文对白：原文未说明。
    - 推进作用：资源归属落定，对峙暂时收束但关系留下后续压力。
- 信息差：双方对对方底牌、规则解释或后续处置存在不完全掌握。
- 回应方式：据理回应、守住关键资源、接受或反制条件。
- 冲突升级点：丹药、道诀、薄纸等关键资源归属引发压力。
- 结果与变化：资源归属发生变化，对峙关系暂时收束或转入后续矛盾。
- 后续牵连：原文未说明。
- 事实状态：原文明确。
