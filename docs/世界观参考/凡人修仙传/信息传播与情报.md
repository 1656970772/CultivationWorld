本文不写总览，不写独立证据段，不写表格，不写项目字段映射。证据锚点仅作为每张案例卡的一部分。

### 案例 1：七玄门夜遇奸细与功劳转移

信息类型：奸细情报 / 内部渗透 / 目击信息。

信息来源：原作事实：韩立夜间无意听到两名野狼帮奸细谈话，判断其中一人是七玄门厨房管事，另一人身份不明。

传播渠道：原作事实：韩立将经过告诉厉飞雨；后续门内流传的版本变成厉飞雨机警识破奸细并立功。

知晓范围：原作事实：韩立知道自己是最早目击者；厉飞雨知道韩立提供线索；七玄门普通弟子只知道厉飞雨立功。奸细并不知道韩立已经听到秘密。谁在门内改写功劳归属，原文未说明。

可信度与误差：原作事实：韩立亲耳听见，可信度高；门内公开版本存在失真，隐去了韩立的作用。我的判断：这是“真实情报私下流转，公开叙事重新包装”的早期样本。

角色反应：原作事实：韩立没有自己抓奸细，而是把线索交给厉飞雨；厉飞雨因此获得门内声望。

后续影响：原作事实：奸细事件强化了七玄门被野狼帮渗透的局势感，也让厉飞雨名声继续上升。韩立继续保持低存在感。

证据锚点：`凡人修仙传.txt:1303` 夜遇奸细章节；`凡人修仙传.txt:1327-1341` 韩立判断奸细身份和灭口风险；`凡人修仙传.txt:1425-1427` 韩立把经过告诉厉飞雨；`凡人修仙传.txt:1484` 门内版本归功于厉飞雨。

### 案例 2：野狼帮和谈是假，审讯俘虏补全战场情报

信息类型：假和谈 / 战报 / 俘虏口供 / 军事情报。

信息来源：原作事实：七玄门先收到野狼帮忽然要和谈的消息，门内多人怀疑有诈；后续逃回的供奉提供谈判队伍被伏击、吴门主和长老战死的消息；韩立和厉飞雨又抓住蓝衣执法审讯，得知野狼帮主力进攻落日峰，以及还有铁枪会、断水门等帮派参战。

传播渠道：原作事实：消息经逃回供奉、落日峰通报、俘虏审讯、王门主令牌传令等多渠道流动。部分命令由王门主亲信持令牌传达。

知晓范围：原作事实：七玄门高层、逃回供奉、韩立、厉飞雨、王门主亲信、马荣等分别掌握不同片段。马荣重视探查敌情，但被持令牌的王门主亲信阻止。贾天龙则通过暗插奸细提前得知七玄门底牌。

可信度与误差：原作事实：和谈消息本身带有诱敌性质；俘虏口供和逃回供奉叙述互相补足。王门主亲信依令牌压制侦查，导致局部信息封锁。我的判断：这是“敌方假消息 + 己方层级命令阻断侦查 + 俘虏口供补完”的复合案例。

角色反应：原作事实：韩立根据情报判断局势凶险，厉飞雨拷问俘虏，马荣想派人探查，王门主亲信阻止外出侦查。

后续影响：原作事实：七玄门被迫面对多帮派围攻，落日峰成为关键战场；七玄门高层误判和谈风险，被野狼帮掌握底牌。

证据锚点：`凡人修仙传.txt:2625` 和谈消息引发怀疑；`凡人修仙传.txt:2677-2678` 逃回供奉传回队伍全灭；`凡人修仙传.txt:2748-2758` 审讯蓝衣执法获得好坏两条消息；`凡人修仙传.txt:2776-2784` 令牌传令并压制探查；`凡人修仙传.txt:2968` 贾天龙通过暗插奸细掌握七玄门底牌。

### 案例 3：墨府明信、暗信与信物验证

信息类型：密信 / 身份验证 / 死讯传递。

信息来源：原作事实：韩立携墨大夫信物和书信见墨府严氏等人；墨大夫生前约定，明信无暗信代表平安，若标明暗信则多半有不妙消息。严氏等人用方法让暗信显形。

传播渠道：原作事实：龙形戒指作为信物，明信作为外层信息，暗信作为隐藏信息。韩立口述墨大夫之死经过，与暗信内容互相印证。

知晓范围：原作事实：墨府几位夫人知道暗信约定；韩立最初不知道暗信具体内容；墨府其他人知晓范围原文未说明。

可信度与误差：原作事实：信物真实，亲笔信和暗信提高可信度；韩立口述是否可信，需要与暗信和墨大夫性格印象对照。我的判断：这是“信物 + 预设密信协议 + 口供交叉验证”的凡人江湖情报机制。

角色反应：原作事实：严氏先验信物，再要求亲笔信，随后组织众人取出暗信；听完韩立叙述后，判断其说法大致可信。

后续影响：原作事实：墨府接受墨大夫已死的重大信息，并据此处理韩立与墨府之间的关系。后续具体消息外泄范围原文未说明。

证据锚点：`凡人修仙传.txt:3838-3858` 韩立投出龙形戒指并被验信物；`凡人修仙传.txt:3949-3965` 明信/暗信规则与暗信显形；`凡人修仙传.txt:4140` 韩立叙述与暗信信息相互吻合。

### 案例 4：孙二狗作为嘉元城地头蛇情报节点

信息类型：地方情报 / 黑帮网络 / 人物行踪。

信息来源：原作事实：孙二狗自称知道嘉元城大小消息；韩立因此留下他搜集墨府尤其吴剑鸣的消息。孙二狗能提供四平帮、墨府人物、墨玉珠回城等信息。

传播渠道：原作事实：孙二狗依靠本地帮派和地头蛇网络打探，再向韩立口头汇报。

知晓范围：原作事实：韩立通过孙二狗知道嘉元城与墨府局势；孙二狗知道的多为江湖与城内消息；他对修仙者层面的真实情况并不完整。

可信度与误差：原作事实：孙二狗提供的多是听闻和本地打探；韩立会继续观察验证。我的判断：孙二狗是“低阶本地信息中介”，价值在覆盖面，不在绝对准确。

角色反应：原作事实：韩立用威慑和利益控制孙二狗，让其悄悄搜集墨府情报；孙二狗因有赏而积极办事。

后续影响：原作事实：韩立借孙二狗缩短对嘉元城、墨府和吴剑鸣的摸底时间。

证据锚点：`凡人修仙传.txt:3608-3609` 孙二狗以消息能力求生；`凡人修仙传.txt:3633` “情报”章节；`凡人修仙传.txt:3650-3665` 韩立启用孙二狗并获四平帮情报；`凡人修仙传.txt:3691-3695` 韩立要求搜集墨府与吴公子消息；`凡人修仙传.txt:3753` 韩立据孙二狗情报判断墨玉珠归来。

### 案例 5：“神仙大会”小道消息与封口令

信息类型：修仙者聚会消息 / 意外目击 / 封口令。

信息来源：原作事实：四平帮小头目逃避追杀时偶然听见“神仙大会”相关消息，回去后告诉上司，上司上报帮主，帮主下封口令。孙二狗从醉酒高层处得知，再汇报韩立。

传播渠道：原作事实：意外偷听 -> 帮派上报 -> 帮主封口 -> 醉酒泄露 -> 孙二狗转报韩立。

知晓范围：原作事实：四平帮高层知道部分消息；普通帮众受封口令限制；韩立知道后追问消息可靠性。修仙者是否知道凡人偷听并传播，原文未说明。

可信度与误差：原作事实：孙二狗称消息可靠，但韩立发现信息并不确切，有遗漏。我的判断：该案例同时包含“偶然目击”“半封锁传播”和“低可信度但高价值机会点”。

角色反应：原作事实：韩立认真追问消息来源，判断可信度；随后将其视为接触修仙者的重要线索。

后续影响：原作事实：韩立因此进一步走向太南小会和升仙会线索。具体“四平帮高层”后续是否继续传播，原文未说明。

证据锚点：`凡人修仙传.txt:4204-4210` 孙二狗汇报神仙大会并说明知晓范围；`凡人修仙传.txt:4212-4218` 小头目偷听、上报、封口令链条；`凡人修仙传.txt:4226` 韩立判断孙二狗消息不确切。

### 案例 6：太南小会与升仙会的散修知识差

信息来源：原作事实：万小山向韩立说明太南小会是五年一次、面向岚州小辈的交易盛会；黑木等散修补充升仙会是越国十年一次、年轻修仙者拜入大派的重要机会；胡萍姑说明太南谷人数暴增，很多人借小会观察升仙会对手。

传播渠道：原作事实：散修之间口头介绍、聚会交流、队伍讨论。

知晓范围：原作事实：常在岚州活动的散修和修仙家族子弟知道太南小会与升仙会；韩立作为新入修仙界者起初不知道详情；部分散修对失踪风险、擂台惨烈程度知道更多。

可信度与误差：原作事实：各人说法来自散修经验和往届见闻，可信度中等；对死亡数字、高手潜伏等内容包含听闻成分。我的判断：这是“新手角色通过社群口耳相传补齐世界规则”的样本。

角色反应：原作事实：韩立一边听取信息，一边判断升仙会风险和入门机会；少女和吴九指听到部分情报后沉默，显示信息超出预期。

后续影响：原作事实：韩立对升仙会、筑基丹和入派路径形成认知，随后继续寻找更稳妥的入门办法。

证据锚点：`凡人修仙传.txt:4631-4633` 万小山说明太南小会；`凡人修仙传.txt:4894-4898` 散修讨论升仙会和失踪风险；`凡人修仙传.txt:4944-4952` 胡萍姑说明人群聚集、观察对手和擂台流程；`凡人修仙传.txt:4968` 情报大出部分人意外。

### 案例 7：升仙令的隐秘用途由书册补全

信息类型：秘传物品信息 / 家族流传 / 书册知识。

信息来源：原作事实：韩立从小册子末页看到“升仙令”图样与用途，才确认手中令牌是黄枫谷升仙令。书册说明此物只在修仙家族内部流传，普通修仙者无缘一见。

传播渠道：原作事实：升仙令原本通过修仙家族内部代代相传；韩立通过青溪上人书册间接获得公开度很低的知识；金光上人因提前得到风声，带升仙令逃走。

知晓范围：原作事实：秦家、叶家等相关家族知道升仙令价值；韩立在读册前不知道；太南小会讨论升仙会时无人提到升仙令。

可信度与误差：原作事实：书册图样和令牌实物匹配，后续黄枫谷接引人也认可升仙令，可信度高。我的判断：此处体现“物品价值被知识门槛锁住”，同一令牌在不知情者手里只是疑物，知道规则后变成入门资格。

角色反应：原作事实：韩立确认用途后兴奋并规划去黄枫谷；黄枫谷接引人见令牌后吃惊，将韩立带回门内等掌门处理。

后续影响：原作事实：韩立借升仙令进入黄枫谷，触发筑基丹分配争议。

证据锚点：`凡人修仙传.txt:5259-5265` 韩立从书册确认升仙令用途和黄枫谷归属；`凡人修仙传.txt:5269-5274` 秦家、叶家、金光上人与升仙令流转；`凡人修仙传.txt:5426-5429` 接引人认可令牌并带韩立回黄枫谷。

可信度与误差：原作事实：吴风和岳麓殿老者说法互相印证；宗门公告又改变韩立风险判断。我的判断：这是一条从“资源情报”变为“生死决策”的链路。

后续影响：原作事实：韩立报名并收到集合信符；黄枫谷本次派出精锐，试炼危险程度提高。

证据锚点：`凡人修仙传.txt:6071-6089` 吴风说明禁地、血禁试炼和重赏背景；`凡人修仙传.txt:6092-6103` 奖励与筑基丹分配机制；`凡人修仙传.txt:6114-6115` 韩立向岳麓殿老者确认后下决心；`凡人修仙传.txt:6618-6636` 七派宣布禁地五年后封闭六十年，韩立报名；`凡人修仙传.txt:6663` 王师叔发信符催集合。

### 案例 10：血色禁地中心区资料玉简交换

信息类型：秘境地图 / 资料交换 / 可信度博弈。

信息来源：原作事实：韩立与灵兽山钟吾把中心区资料输入玉简并交换，双方拿到后都用神识大致探查内容。

传播渠道：原作事实：临时合作、玉简复制、资料互换。
