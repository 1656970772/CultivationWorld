## 势力设定总览

### 案例一：七玄门

**势力类型**：正道宗门 / 综合型修仙宗门

**势力定位**：以弟子培养、功法传承、江湖争斗、势力扩张为主

七玄门是越国镜州两大霸主之一，曾是赫赫有名的大门派，由二百年前的"七绝上人"创立。门派拥有外门和内门之分，内门有百锻堂、七绝堂、供奉堂、血刃堂四个分堂，外门有飞鸟堂、聚宝堂、四海堂、外刃堂四个分堂。目前由王陆担任正门主，与野狼帮形成对峙局面。

**核心区域**：

- **彩霞山（总门所在地）**：
  - 位置：镜州境内第二大山，方圆十几里
  - 原名落凤山，相传五色彩凤落在此地化成此山
  - 因落日美景犹如彩霞笼罩而改名彩霞山
  - 全山被七玄门各分堂占据
  - 主峰落日峰设十三处哨卡，万无一失
  - 外人不能随意进入

- **落日峰（主峰）**：
  - 奇高陡峭
  - 从山底到峰顶只有一条路
  - 设十三处哨卡防守
  - 总堂所在地

- **百锻堂（内门）**：
  - 功能：两年基础训练
  - 特点：新入门弟子在此接受基础训练
  - 负责人：原文未说明

- **七绝堂（内门）**：
  - 功能：传授门内绝技
  - 特点：入门测试表现杰出者可不经训练直接进入
  - 藏书：包含眨眼剑法等绝学
  - 守卫：有专人检查

- **供奉堂（内门）**：
  - 功能：供奉特殊人才
  - 墨大夫属于此堂
  - 地位：与副门主并驾齐驱

- **神手谷（供奉墨大夫专属区域）**：
  - 位置：彩霞山内隐蔽山谷
  - 特点：四面环山，只有一个出入口
  - 设施：药园（种植各种珍稀药草）、书房（墨大夫藏书）、石室（韩立修炼用）
  - 守卫：有一名神秘高大男子守护

- **内门区域**：
  - 功能：内门弟子居住、修炼、领任务
  - 特点：需要一定身份才能进入

- **外门区域**：
  - 功能：外门弟子、杂役弟子活动
  - 负责打理门外生意
  - 飞鸟堂、聚宝堂、四海堂、外刃堂所在

**组织结构**：

- **门主/宗主**：
  - 王陆：正门主，拥有七绝上人嫡传后人身份
  - 马副门主：副门主之一
  - 其他副门主：原文未说明具体人数
  - 职责：统领全门、决策大事
  - 境界：原文未说明

- **长老会**：
  - 地位：只在正门主之下，和其他副门主并驾齐驱
  - 人数：原文未说明
  - 职责：护宗、决策

- **堂主**：
  - 岳堂主：负责入门测试
  - 顾副堂主：负责接收合格弟子
  - 职责：管理各堂事务

- **护法**：
  - 王护法：接引弟子的护法
  - 厉飞雨：后晋升为护法
  - 职责：护宗、处理事务

- **供奉**：
  - 墨大夫：供奉堂供奉
  - 职责：以医术服务宗门

- **内门弟子**：
  - 分为正式弟子和记名弟子
  - 正式弟子：通过入门测试
  - 记名弟子：表现突出但未完全过关

- **外门弟子**：
  - 为门派打理门外生意
  - 聚宝堂和飞鸟堂最多外门弟子
  - 外刃堂：表现优秀者可进入
  - 四海堂：只招收武林成名人物

- **真传弟子/核心弟子**：
  - 入门测试杰出者直接保送七绝堂
  - 舞岩：直接进入七绝堂
  - 特点：前途最好

**制度规则**：

- **入门测试**：
  - 每五年举行一次
  - 测试内容：竹林跑、攀岩、悬崖攀爬
  - 合格标准：正午前到达崖顶
  - 记名弟子：表现突出者可成为记名弟子
  - 外门弟子：未过关者成为外门弟子

- **正式弟子选拔**：
  - 半年后考核
  - 内容：长跑、组队格斗、抵挡师兄进攻
  - 合格者成为正式内门弟子

- **晋升制度**：
  - 两年基础训练后可拜师学习高深武功
  - 杰出者可被长老、堂主、供奉收为亲传弟子
  - 贡献积累可晋升职位

- **贡献/任务制度**：
  - 完成宗门任务获得贡献
  - 贡献可兑换资源
  - 抓奸细等大功可晋升护法

- **待遇制度**：
  - 内门弟子：免费习武吃喝不愁
  - 月俸：每月一两多散银
  - 外门弟子：外门弟子有月钱

**资源基础**：

- 灵脉：原文未说明具体等级
- 药园：神手谷内有药园
- 功法传承：七绝上人传承、多门绝学
- 丹堂：原文未说明
- 武器堂：原文未说明

**特色体系**：

- **入门测试**：炼骨崖测试（竹林、攀岩、悬崖）
- **七绝堂绝学**：眨眼剑法等
- **弟子培养**：基础训练后拜师
- **长老制度**：护宗、决策

**对外关系**：

- **野狼帮**：主要敌对势力，经常冲突
- **其他门派**：原文未说明具体关系
- **越国**：七玄门曾在越国声名赫赫

**宗门历史**：

- **创建**：二百年前由"七绝上人"创立
- **鼎盛时期**：曾雄霸镜州数十载，渗透数州
- **衰落**：七绝上人病故后势力大减，被其他门派联手挤出镜州首府
- **迁徙**：百年前被迫搬迁到镜州最偏僻的彩霞山
- **现状**：落为三流地方小势力，但仍是方圆数百里两大霸主之一
- **衰落原因**：七绝上人去世后无人能维持鼎盛

### 案例二：野狼帮

**势力类型**：邪道势力 / 马贼帮派

**势力定位**：以武力掠夺、地盘争夺、与七玄门对抗为主

野狼帮前身是镜州界内一股烧杀掳掠的马贼，后部分接受官府招安，另一部分成为野狼帮。马贼凶狠嗜血、敢杀敢拼的狠劲传承下来，导致七玄门在与野狼帮冲突时屡屡处于下风。目前由"金狼"贾天龙统领。

**核心区域**：

- **原文未说明具体山门位置**
- 控制乡镇数量比七玄门多
- 但不会经营，论富足程度远不及七玄门

**组织结构**：

- **帮主**：
  - 贾天龙（"金狼"）
  - 年龄：三十出头
  - 外貌：瘦弱俊秀（与传闻相反）
  - 性格：动不动就杀人
  - 境界：原文未说明
  - 职责：统领全帮、决策大事

- **帮众**：
  - 原为马贼出身
  - 凶狠嗜血、敢杀敢拼
  - 战斗力强但不懂经营

- **奸细/卧底**：
  - 派往七玄门的奸细
  - 厨房管事：被发展为七玄门奸细
  - 另一名年轻奸细：原文未说明具体身份

**制度规则**：

- **招募方式**：原文未说明
- **奖惩制度**：原文未说明
- **行动方式**：烧杀掳掠、偷袭、暗杀

**资源基础**：

- 地盘：控制乡镇较多
- 武力：战斗力强
- 缺点：不善经营

**特色体系**：

- **马贼传统**：凶狠嗜血、敢杀敢拼
- **招安残余**：部分接受官府招安
- **战斗力强**：七玄门屡屡处于下风

**对外关系**：

- **七玄门**：主要敌对势力，经常冲突
- **官府**：部分接受招安
- **其他势力**：原文未说明

**势力历史**：

- **起源**：镜州界内马贼
- **分化**：部分接受官府招安，部分成为野狼帮
- **现状**：与七玄门争夺地盘

### 案例三：神手谷

**势力类型**：特殊领地 / 供奉私人区域

**势力定位**：以墨大夫私人领地为主，用于医术研究和弟子培养

神手谷是墨大夫在七玄门的专属区域，四面环山，只有一个出入口，形成天然的隐蔽场所。墨大夫在此种植药草、研究医术、传授弟子，是韩立和张铁的主要活动场所。

**核心区域**：

- **位置**：彩霞山内隐蔽山谷
  - 从外面进入需要穿过树林
  - 四周被山峰环绕

- **药园**：
  - 位于山谷左侧
  - 种植各种珍稀药草
  - 散发浓郁药香
  - 韩立在此进行神秘瓶子试验

- **房屋区域**：
  - 位于山谷右侧
  - 十几间大大小小房屋连成一片
  - 墨大夫住所：比较气派
  - 韩立住所：较小
  - 张铁住所：原文未说明具体位置

- **石室（修炼室）**：
  - 用花岗岩山壁掏空制成
  - 屋门用整块大青石打制
  - 普通弟子无法享用
  - 韩立专用修炼场所
  - 防止修炼时被打扰走火入魔

- **书房**：
  - 墨大夫藏书之地
  - 各种医术书籍
  - 韩立可随意翻阅医术书籍
  - 《长生经》等书籍

- **大厨房**：
  - 位于山谷附近
  - 提供弟子饮食
  - 有管事负责

- **谷口**：
  - 与外界连接处
  - 厉飞雨来取药的地方
  - 墨大夫送药的地方

**组织结构**：

- **墨大夫（墨居仁）**：
  - 身份：供奉堂供奉
  - 职责：医术研究、弟子培养
  - 境界：原文未说明（原武林高手）

- **神秘高大男子**：
  - 身份：墨大夫手下/守护者
  - 特点：从不开口说话
  - 能力：站立一整天不知疲倦
  - 服从：绝对服从墨大夫命令
  - 来源：原文未说明

- **弟子**：
  - 韩立：墨大夫亲传弟子
  - 张铁：墨大夫弟子（后离开）

- **厨房管事**：
  - 负责伙食
  - 身份：野狼帮奸细
  - 特点：爱占小便宜、八字胡

**制度规则**：

- **进出限制**：原文未说明具体限制
- **墨大夫管理**：日常事务由墨大夫管理
- **修炼安排**：韩立和张铁的修炼由墨大夫安排

**资源基础**：

- 药园：各种珍稀药草
- 书籍：医术藏书
- 药材：墨大夫下山搜集
- 神秘瓶子：韩立秘密持有

**特色体系**：

- **隐秘性**：四面环山，只有一个出入口
- **医术研究**：墨大夫专精医术
- **药材种植**：珍稀药草园
- **弟子培养**：韩立和张铁

**对外关系**：

- **七玄门**：墨大夫作为供奉属于七玄门
- **墨大夫与韩立**：师徒关系复杂
- **与外界**：相对独立

**势力历史**：

- **建立**：墨大夫被王门主请入七玄门后建立
- **发展**：修建房屋、药园、石室
- **现状**：墨大夫离开后只剩韩立一人

## 势力发展影响因素

### 七玄门衰落原因

- **领导力缺失**：七绝上人去世后无人能维持鼎盛
- **资源争夺**：被其他门派联手挤出镜州首府
- **被迫迁徙**：搬迁到偏僻地区
- **外部压力**：野狼帮崛起，冲突加剧

### 野狼帮崛起原因

- **马贼传统**：凶狠敢拼
- **招安分化**：部分接受招安获得合法性
- **武力优势**：七玄门屡屡处于下风
- **地盘扩张**：控制乡镇增多

### 神手谷独特性

- **隐秘性**：四面环山，天然隐蔽
- **医术传承**：墨大夫专精医术
- **弟子培养**：韩立和张铁的成长地
- **秘密研究**：长春功修炼、神秘瓶子试验

---

## 结论

《凡人修仙传》前十五万字展现了多个势力的分布和特点。七玄门作为主角所在宗门，结构完整、体系复杂；野狼帮作为主要敌对势力，代表了江湖中凶残的一面；神手谷作为墨大夫的私人领地，展现了相对独立的势力形态。这些势力的互动构成了小说的主要矛盾冲突，推动了剧情发展。
