### 案例 1：外星海传送猎妖与妖丹回收（修士主动猎妖）

关系类型：猎杀 / 猎妖任务 / 材料回收 / 妖丹交易。

参与方：韩立、曲魂、外星海妖兽岛体系、天星城传送阵、外星海猎妖修士群体、天星城坊市与买家。

主动方：原作事实：修士主动交灵石经传送阵前往外星海妖兽岛，斩杀妖兽取妖丹并带回天星城出售或炼丹。

被动方：外星海五级、六级及更高阶海中妖兽；原文还说明外星海也有飞禽类妖兽和高空风险。

触发原因：原作事实：乱星海丹方大量以妖丹代替灵药，韩立修炼“三转重元功”需要大量妖兽内丹；天星城传送阵和妖丹价格共同驱动修士出海。

发生地点：天星城、外星海、凝翠岛、红瑚岛及周边珊瑚岛海域。

互动流程：原作事实：韩立先在坊市购买妖兽资料与妖兽岛资料，准备大容量储物袋，再传送至外星海；到达后观察本地猎妖修士结伴行动习惯，随后在岛礁布阵、以霓裳草诱妖、由曲魂和傀儡等配合击杀妖兽，收取妖丹和材料。

资源流向：原作事实：妖丹用于炼制丹药、支撑散功重修与后续修炼；妖兽材料一部分留下制符或炼器，一部分分批出售给小商家，后被妙音门追踪并提出整批收购。

关系变化：原作事实：普通猎妖从“人对妖兽”的资源猎杀，延伸出“猎妖者暴富后被商会/门派盯上”的人际风险。外星海深处猎妖还引出碧云门夺宝冲突和“虫魔”嫁祸事件。

风险与代价：原作事实：外星海妖兽难寻且危险，高空和海中都有妖兽；落单修士除妖兽外还要防备其他修士夺妖丹、夺材料。韩立储物袋容量也成为资源回收上限。

升级条件：我的判断：当猎妖地点深入、妖丹数量巨大、猎妖者暴露财富，关系容易从普通猎妖升级为修士截杀、门派追踪或地方势力争夺；该判断依据是韩立出售材料被妙音门注意，以及困住七级妖兽时遭碧云门队伍夺宝。

结束方式：原作事实：韩立完成数年猎妖后返回洞府，炼制大量丹药，出售剩余材料并闭关；但后续在外星海再次出现猎妖与争夺循环。

后续影响：原作事实：韩立获得数百颗五级、六七级妖丹和大量珍稀妖兽材料，炼丹术也因大量妖丹练手而提高；同时“虫魔”名声和碧云门仇怨影响其外海行动安全。

与妖兽分析的关联：涉及外星海五级妖兽、六级妖兽、琉璃兽、七级妖兽等；具体本体信息另查妖兽分析。

证据锚点：`凡人修仙传.txt:17312-17315`（乱星海以妖丹代替灵药的丹道）、`17936-17937`（传送至妖兽岛猎妖换灵石）、`18091-18109`（韩立准备资料和储物袋）、`18170-18179`（外星海结伴猎妖与风险）、`18271-18281`（连续诱妖取丹和材料堆积）、`18306-18307`（妖丹炼丹与材料出售）、`18437-18470`（妙音门因妖兽材料找上韩立）、`24899-24907`（七级妖兽引发碧云门夺宝与嫁祸）。

### 案例 2：六连殿围猎婴鲤兽妖丹（组织猎妖任务）

关系类型：猎杀 / 宗门或商会外援 / 妖丹争夺。

参与方：六连殿曹禄、古长老等六连殿修士、韩立等外援、婴鲤兽、争夺妖丹的枯瘦青年一方。

主动方：原作事实：六连殿发现一只六级妖兽，主动请外援协助除妖，目标明确是妖丹。

被动方：婴鲤兽及其尸身资源；妖兽反击细节在该片段中原文未完整展开。

触发原因：原作事实：六连殿想得到六级妖兽妖丹；后续争夺者也将婴鲤兽妖丹视作给家祖的贺礼。

发生地点：乱星海海域，六连殿组织的围猎区域；具体岛屿名原文片段未说明。

互动流程：原作事实：六连殿先掌握妖兽线索，再请外援；围猎完成后妖丹成为各方争夺核心，古长老强调其他东西可以让出，但妖丹必须留下。

资源流向：原作事实：六连殿目标是妖丹；其他尸材可让给争夺者，说明妖兽资源可以按价值拆分谈判。

关系变化：原作事实：猎妖成功后并未立刻结束，妖丹归属引发修士间对峙，说明妖兽资源会把“人妖冲突”转化为“人族内部资源冲突”。

风险与代价：原作事实：六级妖兽需要请外援；妖丹归属可能引起双方冲突甚至开战。

升级条件：我的判断：当妖丹被多个势力认定为必须资源时，猎妖任务会升级为势力颜面和交差压力；该判断依据是古长老“必须留下妖丹”的态度。

结束方式：原文片段未说明完整结果；待核验。

后续影响：原作事实：韩立由此接触乱星海妖丹丹方与外海猎妖逻辑；具体六连殿长期影响待核验。

与妖兽分析的关联：婴鲤兽的等级、能力和妖丹用途另查妖兽分析。

证据锚点：`凡人修仙传.txt:17286`（六连殿请外援除六级妖兽取妖丹）、`17315`（五级妖丹可替代筑基丹部分灵药）、`17539-17563`（婴鲤兽妖丹归属争夺）。

### 案例 3：血色禁地守药妖兽与采药弟子冲突（资源点守护）

关系名：血色禁地灵药点的守护妖兽循环。

关系类型：守药冲突 / 资源点争夺 / 低阶试炼。

参与方：七派炼气期试炼弟子、血色禁地一级妖兽、紫猴花、天灵果、寒烟草、碧水鳄、巨蜈蚣、墨蛟等。

主动方：原作事实：修士主动进入禁地采药；妖兽通常守在灵药或领地附近，被接近后反击。

被动方：被采走灵药的守护妖兽与禁地生态；也包括被妖兽或其他弟子袭击的采药修士。

触发原因：原作事实：筑基丹主药需要血色禁地灵药，七派弟子必须冒险采药；越接近中心区灵物越珍稀，守护妖兽越强。

发生地点：血色禁地中心区外围、乌龙潭、紫猴花山洞、碧水鳄水潭、墨蛟所在地下空间等。

互动流程：原作事实：弟子先依靠资料寻找灵药点，遇守护妖兽则偷袭、引开、合击或强杀；韩立在紫猴花山洞中先侦查巨蜈蚣，再诱其追出并以预设金刃剖腹，随后采走紫猴花。掩月宗队伍则以合击秘法对付碧水鳄，并计划继续扫荡顶阶妖兽巢穴。

资源流向：原作事实：灵药交给门派换筑基丹或奖励；妖兽尸身材料部分被韩立尝试回收，如蜈蚣外壳、墨蛟材料。

关系变化：原作事实：禁地形成“灵药刷新/妖兽再现”的长期循环；弟子每次进入都重复采药、击妖、互相争夺。

风险与代价：原作事实：守护妖兽会消耗修士法力体力，资料错误或妖兽增多会导致采药效率大降；低阶修士还会被其他修士利用妖兽陷害，如灵兽山弟子用驱兽粉控制寒冰蟾害人。

升级条件：我的判断：若守护妖兽等级超出试炼弟子预期，或修士借妖兽设局，普通守药冲突会升级为伤亡和门派试炼风险；依据是墨蛟进阶、寒冰蟾被利用杀人、韩立半日内连续击杀多头妖兽后吃不消。

结束方式：原作事实：妖兽被杀或修士撤离；灵药被采走后试炼继续。

后续影响：原作事实：韩立取得紫猴花等筑基丹主药；墨蛟材料随后被用于炼制神风舟、青火瘴等法器，延伸出炼器资源链。

与妖兽分析的关联：巨蜈蚣、碧水鳄、墨蛟、寒冰蟾等本体能力另查妖兽分析。

证据锚点：`凡人修仙传.txt:6991-7019`（乌龙潭寒烟草与寒冰蟾、驱兽粉设局）、`7109-7110`（灵药与妖兽循环再现）、`7823-7865`（巨蜈蚣守紫猴花与韩立回收尸材）、`7947-7965`（掩月宗合击碧水鳄并扫荡灵药点）、`8104`（连续击杀守护妖兽导致消耗）。

### 案例 4：墨蛟从守护兽变为材料链核心（守巢冲突与资源回收）

关系类型：守巢冲突 / 妖兽反杀 / 材料回收 / 炼器后续。

参与方：南宫婉、掩月宗弟子、韩立、墨蛟。

主动方：原作事实：掩月宗队伍进入灵药/资源区域，与墨蛟发生冲突；韩立原先旁观，后因出口变化与自身安危被卷入。

被动方：墨蛟先作为被围攻妖兽，进阶后反过来追杀掩月宗弟子和南宫婉。

触发原因：原作事实：试炼采药与资源探索触发遭遇；墨蛟本身进阶使风险突然提高。

发生地点：血色禁地地下空间。

互动流程：原作事实：南宫婉以朱雀环困住墨蛟，弟子合击；墨蛟蜕皮进阶到第二阶后杀伤力暴涨，掩月宗弟子撤退不及出现伤亡；韩立出手与南宫婉联手，以符宝和手段击杀墨蛟。

资源流向：原作事实：南宫婉取墨蛟元神，后文提到可能用于封印器灵；韩立取得墨蛟材料，后拿去交换或炼器，蛟鳍、尾部炼成神风舟，蛟目、残余丹液参与青火瘴等法器。

关系变化：原作事实：墨蛟由守护威胁转化为韩立后续飞行、防护、毒雾法器的材料来源；南宫婉与韩立关系也因该事件发生重大变化，但本文不展开人物关系。

风险与代价：原作事实：墨蛟进阶后实力堪比筑基中阶，造成弟子死亡；韩立和南宫婉被困后面临长时间追杀。

升级条件：原作事实：妖兽临场进阶、出口消失、修士法力耗尽，会使采药冲突升级为生死困局。

结束方式：原作事实：墨蛟被击杀，元神与材料被分取。

后续影响：原作事实：墨蛟材料进入韩立早期法器体系，神风舟改善赶路能力，青火瘴残余丹毒后来影响敌人。

与妖兽分析的关联：墨蛟的进阶、毒液、防御和材料用途另查妖兽分析。

证据锚点：`凡人修仙传.txt:8182-8238`（墨蛟识别、进阶与掩月宗撤退）、`8246-8294`（韩立和南宫婉联手困杀）、`8328-8375`（蛟丹/囊袋等材料细节）、`8586`（墨蛟材料归入战利品）、`9020-9380`（韩立处理墨蛟材料并炼成神风舟）、`9423`（青火瘴掺入残余丹液）、`20706-20707`（墨蛟元神或用于器灵）。

### 案例 5：霓裳草诱妖取丹（诱饵型猎妖闭环）

关系类型：猎杀 / 诱捕 / 妖兽本能驱动 / 材料回收。

参与方：韩立、曲魂、血玉蜘蛛、噬金虫、外星海五六级妖兽、霓裳草。

主动方：原作事实：韩立主动利用小瓶绿液催熟霓裳草，诱使妖兽靠近布阵地点。

被动方：被霓裳草气息吸引的海中妖兽；其中六级鸡冠蛟等更高阶妖兽曾被气息引来但未被韩立贸然猎杀。

触发原因：原作事实：霓裳草展叶时对大多数海中妖兽有强烈诱惑，年份越久影响范围和吸引高阶妖兽能力越强。

发生地点：红瑚岛、珊瑚礁、外星海岛礁。

互动流程：原作事实：韩立把霓裳草幼苗移栽到珊瑚礁，以绿液催熟展叶，自己和曲魂在附近养精蓄锐并布下阵法；妖兽被气息吸引后扑向霓裳草，韩立封住气息并启动阵法围杀，随后取丹取材。

资源流向：原作事实：妖丹进入炼丹闭环，材料进入储物袋、后续出售或制符炼器；霓裳草后来还被用于试验噬金虫、金丝蚕等灵虫培育。

关系变化：原作事实：妖兽被动受到诱惑，猎杀不再依赖漫长搜索；但诱饵年份控制不当会引来超出承受范围的妖兽。

风险与代价：原作事实：四百年份霓裳草曾引来六级鸡冠蛟，韩立急忙封住气息才让其离去；诱妖有误差，三百年霓裳草也可能错引六七级妖兽。

升级条件：原作事实：霓裳草年份提高、气味扩散范围扩大、猎妖点靠近高阶妖兽活动区时，普通猎妖会升级为高阶妖兽威胁。

结束方式：原作事实：妖兽被阵法击杀、韩立撤阵转移地点，或因妖兽过强而封气撤避。

后续影响：原作事实：韩立五年外星海猎妖获得大量妖丹材料；霓裳草还意外解决部分噬金虫繁殖进化问题。

与妖兽分析的关联：霓裳草不属于妖兽；被诱来的鸡冠蛟、琉璃兽等另查妖兽分析。

证据锚点：`凡人修仙传.txt:18206-18219`（霓裳草诱妖原理与限制）、`18221-18229`（韩立催熟布阵）、`18242`（封住气息）、`18271-18273`（连续灭杀五级妖兽和错引六级妖兽）、`24691-24709`（再次以四百年霓裳草诱六级妖兽）、`24831`（琉璃兽材料回收）。

### 案例 6：双瞳鼠租借寻灵眼（灵兽工具化服务）

关系类型：灵宠租借 / 寻宝辅助 / 宗门灵兽服务。

参与方：韩立、黄枫谷灵兽山或谷内灵兽管理处、双瞳鼠、管理女弟子。

主动方：原作事实：韩立主动租借双瞳鼠寻找灵眼之地。

被动方：双瞳鼠作为被租借灵兽，由宗门管理者交付给修士临时使用。

触发原因：原作事实：双瞳鼠略加训练后适合寻找灵眼之地，受谷内弟子喜爱。

发生地点：黄枫谷附近灵兽栖息地、韩立开辟洞府区域。

互动流程：原作事实：韩立以每日低阶灵石一块租下双瞳鼠，管理弟子附带其爱吃的土梨果并要求善待；韩立牵绳防止跟丢，喂食后跟随双瞳鼠寻找灵泉，最终发现灵眼之泉；用后把双瞳鼠放归，让其自行返回麒麟阁。

资源流向：原作事实：韩立支付灵石和食物，获得灵眼位置；双瞳鼠获得喂食并回到宗门。

关系变化：原作事实：关系是短期租用而非认主；宗门通过灵兽能力向弟子提供服务。

风险与代价：原作事实：原文未说明双瞳鼠反噬风险；实际风险主要是修士可能跟丢或不善待灵兽。

升级条件：原文未说明。

结束方式：原作事实：韩立发现灵泉并开辟洞府后，把双瞳鼠带远放掉，让其自行回归。

参与方：韩立、碧云门修士、妙鹤真人、极阴祖师、奇渊岛修士、假冒虫魔者、噬金虫群、被困七级妖兽。

主动方：原作事实：碧云门修士在韩立困住七级妖兽时起贪念，试图杀人夺宝；后来有人冒充“虫魔”四处杀人夺宝，搅浑水并逼韩立现身。

被动方：韩立、被夺宝目标妖兽及其妖丹材料、被假冒虫魔杀害的修士。

触发原因：原作事实：七级妖兽价值高，韩立独自猎妖暴露资源；碧云门因损失和虚天鼎线索等利益，想借虫魔恶名追查或逼迫韩立。

发生地点：外星海、奇渊岛附近海域。

互动流程：原作事实：韩立以霓裳草在外围引妖取丹，困住七级妖兽时遭碧云门结丹队伍夺宝，遂放出十万噬金虫灭敌；随后外海出现“虫魔”传言，说有人驱使金银飞虫杀人夺宝，许多修士误认韩立；韩立询问幸存修士后判断自己被嫁祸。

资源流向：原作事实：原七级妖兽资源归属在片段中未完整说明；碧云门队伍被灭，韩立保住自身；假冒者夺取的宝物原文未说明。

关系变化：原作事实：猎妖关系外溢为门派仇怨、名声污染和区域通缉风险；妖兽资源成为诱发修士间冲突的中介。

风险与代价：原作事实：韩立被误认为虫魔，可能遭亲友被害者组成灭魔会追杀；碧云门实力因一战大损，妙鹤真人数度出海搜寻韩立。

升级条件：原作事实：高价值妖兽、落单猎妖者、强大虫群战力暴露、门派损失与虚天鼎秘密叠加，会升级为长期追踪和嫁祸。

结束方式：原作事实：韩立选择闭关避风头；虫魔流言因兽潮等大变局暂缓，未彻底解决。

后续影响：原作事实：韩立在外海行动更谨慎；“虫魔”名声影响奇渊岛修士对他的判断。

与妖兽分析的关联：七级妖兽本体信息未在片段中明确，待查妖兽分析。

证据锚点：`凡人修仙传.txt:24804-24813`（修士误认虫魔及传言）、`24876-24887`（虫魔成名战和杀人夺宝传闻）、`24896-24909`（韩立判断碧云门嫁祸）、`24921-24934`（极阴与碧云门借虫魔身份追查）、`26367`（虫魔流言可能引发灭魔会）。

### 案例 20：高阶人妖互食逻辑（元婴/妖丹互为资源）

关系类型：互相猎杀 / 高阶资源需求 / 阵营边界。

参与方：高阶人类修士、高阶妖兽、九级妖兽、元婴修士、老道、毒蛟、韩立等旁观者。

主动方：视具体遭遇而定。原作事实：人类想灭妖取丹，妖兽也想吞噬修士元婴；实力悬殊时血战难免。

被动方：被实力强方盯上的另一方。

触发原因：原作事实：高阶妖兽妖丹和人类金丹、元婴都对对方有强烈吸引力；毒蛟等八级以上妖兽本身也具备与元婴修士对抗的实力。

发生地点：外星海、八级毒蛟/化形巨龟渡劫海域、风希洞府等高阶妖兽活动区域。

互动流程：原作事实：老道面对毒蛟提出联手猎杀，自己不要八级妖丹但要蛟龙精魂；毒蛟听懂人言后主动出手，以一敌多并为妖龟渡劫拖延。后文概括说明到了元婴期和八级妖兽水准，双方都不易杀死对方。

资源流向：原作事实：人族若胜可取妖丹、精魂、灵骨等；妖兽若胜可吞噬金丹、元婴或获取人族宝物。该具体战斗完整结果在片段中未全部展开。

关系变化：原作事实：高阶人妖关系不再只是野兽与猎人，而是两个有智慧高阶存在之间的互相衡量、谈判、偷袭和追逃。

风险与代价：原作事实：八级妖兽让韩立躲之不及；九级妖修风希则让韩立几乎断绝逃生念头。高阶猎妖失败代价可能是元婴被吞或被追杀。

升级条件：原作事实：化形雷劫、妖兽元气大损、修士联手、妖丹/精魂价值明确，会促使人族冒险出手。

结束方式：原文片段未完整说明毒蛟渡劫遭遇的最终结局；风希线则以韩立反制逃亡暂结。

后续影响：原作事实：韩立由这些遭遇认识到化形妖兽的灵智、速度与肉身优势，对高阶妖修更加忌惮。

与妖兽分析的关联：毒蛟、巨龟、裂风兽风希等另查妖兽分析。

证据锚点：`凡人修仙传.txt:23599`（八级妖兽智慧与实力）、`24537-24551`（化形雷劫和八级妖兽威胁）、`24593-24607`（老道联手猎毒蛟、毒蛟主动反击）、`24626`（人妖高阶互取妖丹/元婴）、`25631-25633`（风希九级妖修压迫）、`26129-26133`（化形期妖身与同阶人修对比）。
