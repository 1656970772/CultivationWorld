## 按境界填写案例

### 案例 1：炼气期 -> 筑基期

境界层级：炼气期 -> 筑基期。

提升阶段：炼气基础功法七层以上、十一/十二层、炼气顶峰、冲击筑基；小阶段名称除原文提到的“炼气期”“基础功法层数”“筑基期”外，其他细分原文未说明。

突破方式一：筑基丹辅助筑基。

条件：原作事实。炼气修士要进入筑基，通常需基础功法练到七层以上并服用筑基丹；升仙会报名也要求五行基础功法过第七层、年龄四十以下。证据：`凡人修仙传.txt:4910`、`凡人修仙传.txt:4942`。

资源：原作事实。筑基丹由大门派掌握，原料难觅，越国修仙门派合力也需十年才有望出炉少量丹药；门内三十岁以下弟子也需选拔争夺资格。证据：`凡人修仙传.txt:4912-4915`、`凡人修仙传.txt:5518`。

环境：原作事实。韩立实际在岳麓殿地火屋闭关筑基，理由是关闭后外界难以打扰。证据：`凡人修仙传.txt:8732-8734`、`凡人修仙传.txt:8810`。

成功变化：原作事实。筑基成功后进入门派高阶弟子序列，辈分按境界重排，待遇提升；寿元通常可至两百多岁。证据：`凡人修仙传.txt:4555`、`凡人修仙传.txt:8803-8806`、`凡人修仙传.txt:8814`。

失败后果：原作事实。服用筑基丹失败者通常仍停留炼气期，最多法力精进到顶峰；陈师妹成功，其兄第二枚筑基丹仍失败后对仙道失去信心。证据：`凡人修仙传.txt:5519-5522`、`凡人修仙传.txt:8600`。

证据锚点：筑基丹门派垄断与十年周期 `凡人修仙传.txt:4912-4915`；韩立八枚筑基丹叠服成功但药性危险 `凡人修仙传.txt:8748-8762`。

突破方式二：多枚筑基丹叠服冲关。

条件：原作事实。韩立伪灵根资质极差，单枚筑基丹成功率被门内判断为百分之一；他后来依靠自炼大量筑基丹，多次洗髓易筋，冲关成功。证据：`凡人修仙传.txt:5409`、`凡人修仙传.txt:8748-8760`。

资源：原作事实。多枚筑基丹；药力洗髓易筋是冲关关键。证据：`凡人修仙传.txt:8743-8748`。

环境：原作事实。封闭地火屋；无护法描述，主要依赖闭关环境。证据：`凡人修仙传.txt:8732-8734`。

成功变化：原作事实。韩立在昏迷中进入筑基期；随后被马师伯、钟灵道确认。证据：`凡人修仙传.txt:8760`、`凡人修仙传.txt:8802-8804`、`凡人修仙传.txt:8886-8890`。

失败后果：原作事实。韩立叠服后残余药性充斥全身，身体滚烫，存在危险；具体若失败是否经脉损毁，原文未说明。证据：`凡人修仙传.txt:8758-8762`。

我的判断：筑基可拆成“资格门槛 -> 丹药窗口 -> 闭关安全 -> 洗髓判定 -> 成功/失败阶层变化”的机制链；多枚丹药不是通用规则，应作为韩立资源特例，不可泛化为普通修士策略。

突破方式三：缺丹者以秘境/试炼争取筑基资源。

条件：原作事实。韩立在失去原筑基丹后，决定参加血色试炼，目标是寻灵药换取或炼制筑基机会；该路线本身不是直接突破，而是资源获取链。证据：`凡人修仙传.txt:6113-6116`、`凡人修仙传.txt:6614-6617`。

资源：原作事实。血色禁地灵药、筑基丹主药、门派奖励；具体每种灵药清单不在本文展开。证据：`凡人修仙传.txt:6047-6048`、`凡人修仙传.txt:6115`。

环境：原作事实。血色试炼/禁地，竞争惨烈，存在死亡风险。证据：`凡人修仙传.txt:6114-6116`。

成功变化：原作事实。若取得资源，可继续筑基；韩立后续确实获得筑基丹来源并成功。证据：`凡人修仙传.txt:8572-8573`、`凡人修仙传.txt:8598-8600`。

失败后果：原作事实。禁地争夺可能陨落；若放弃机会，则韩立认为可能永失仙道之机。证据：`凡人修仙传.txt:6113-6115`。

### 案例 2：筑基期 -> 结丹期

境界层级：筑基期 -> 结丹期/金丹期；特殊状态包括筑基顶峰、假丹、煞丹。

提升阶段：筑基初期/中期/后期、筑基顶峰、假丹、冲击结丹、金丹大成。部分小阶段名称在不同段落中出现，系统化小阶段原文未说明。

突破方式一：常规灵物辅助结丹。

条件：原作事实。结丹极难，百名筑基期也未必一人成功；除天灵根等奇才外，通常需要足够灵药和时间冲击瓶颈。证据：`凡人修仙传.txt:4576`、`凡人修仙传.txt:17692-17695`。

资源：原作事实。雪灵水、天火液是结丹时必须服用的两种灵物；降尘丹能增加结丹几率；其他辅助灵药种类越多，希望越大，但重复服用无效。证据：`凡人修仙传.txt:17252-17268`、`凡人修仙传.txt:17351-17356`、`凡人修仙传.txt:17689-17702`。

环境：原作事实。韩立选择有灵气且安全的地方闭关，服药前先调息到最佳状态。证据：`凡人修仙传.txt:17691`、`凡人修仙传.txt:17743-17746`。

成功变化：原作事实。结丹成功后寿元约四五百岁；韩立金丹大成后举手投足气势改变，天地灵气灌体，丹田凝出四色珠子。证据：`凡人修仙传.txt:4555`、`凡人修仙传.txt:18349-18386`。

失败后果：原作事实。结丹失败不一定死亡，但会消耗资源和寿元窗口；韩立第一次“一转”结丹惨败，后来以二转加多种灵药意外成功。证据：`凡人修仙传.txt:18376-18385`。

证据锚点：结丹比例与天灵根豁免瓶颈 `凡人修仙传.txt:4574-4577`；韩立五年多金丹大成 `凡人修仙传.txt:18383-18387`。

突破方式二：天灵根/异灵根资质路线。

条件：原作事实。天灵根修炼速度为普通灵根二至三倍，筑基期顶峰时不需面对结丹瓶颈；异灵根无豁免结丹瓶颈，但速度不弱于天灵根，配合属性功法可成高手。证据：`凡人修仙传.txt:4574-4582`。

资源：原作事实。原文强调资质和对应功法，未说明固定丹药需求。

环境：原文未说明。

成功变化：原作事实。门派会争抢天灵根和异灵根，视为预定结丹高手或强大战力。证据：`凡人修仙传.txt:4578-4583`、`凡人修仙传.txt:5401-5402`。

失败后果：待核验。异灵根仍可能遇到结丹瓶颈，但具体失败样本本文未核到。

突破方式三：煞丹/血凝五行丹等高风险捷径。

条件：原作事实。煞丹术可人为结成金丹，韩立曾因三分之一几率动心；曲魂借血凝五行丹炼化丹力结成煞丹。证据：`凡人修仙传.txt:14774-14778`、`凡人修仙传.txt:17747-17750`。

资源：原作事实。血凝五行丹；具体炼制资源不在本文展开。证据：`凡人修仙传.txt:17747-17750`。

环境：原作事实。闭关密室。证据：`凡人修仙传.txt:17743-17750`。

成功变化：原作事实。煞丹可达到金丹初期效果，但不是普通金丹路线。

失败后果：原作事实。煞丹缺陷是人造金丹不会再增大，终生修为不再长进，维持金丹初期。证据：`凡人修仙传.txt:14774-14776`。

我的判断：筑基到结丹是作品中“资质、功法、丹药、灵物、时间、心性”第一次全面叠加的关口，适合设计成多条件决策链，而不是单一经验条满级。

### 案例 3：结丹期 -> 元婴期

境界层级：结丹期 -> 元婴期；特殊状态包括结丹后期顶峰、假婴/准备凝婴、第二元婴。

提升阶段：结丹初期/中期/后期、结丹后期顶峰、准备凝结元婴、凝婴成功、元婴初成。完整阶段名原文未系统列出。

突破方式一：九曲灵参与补天丹辅助凝婴。

条件：原作事实。九曲灵参对凝结元婴大有用处；补天丹可洗炼结丹期修士先天灵根，更易进军元婴期。证据：`凡人修仙传.txt:20307-20313`、`凡人修仙传.txt:23033-23037`。

资源：原作事实。九曲灵参、补天丹、炼制九曲灵参丹药所需材料、丹方；韩立还需要等待结丹后期顶峰再用。证据：`凡人修仙传.txt:21057-21063`、`凡人修仙传.txt:23590`、`凡人修仙传.txt:28670-28675`。

环境：原作事实。韩立从虚天殿取得九曲灵参，在药园以禁制和金石化地面保护；后续闭关炼药和修炼。证据：`凡人修仙传.txt:21037-21057`、`凡人修仙传.txt:24435-24436`。

成功变化：原作事实。元婴成功后寿元可达千余年，能跻身一界顶尖修士之列，神识/保命能力层级变化明显；韩立后续被确认为凝结元婴不久并已有第二元婴机缘。证据：`凡人修仙传.txt:4555`、`凡人修仙传.txt:30347-30348`、`凡人修仙传.txt:144846-144847`。

失败后果：原作事实。慕沛灵寿元将尽，急于突破元婴瓶颈，闭关时心境破绽被心魔趁虚而入，法力反噬陨落；即使有九曲灵参丹药等辅助也未能凝婴。证据：`凡人修仙传.txt:63266-63268`。

证据锚点：九曲灵参捕捉与纯金之物、四象玄武阵相关 `凡人修仙传.txt:21053-21063`；慕沛灵失败样本 `凡人修仙传.txt:63266-63268`。

突破方式二：前人经验/修炼心得辅助。

条件：原作事实。韩立在阴冥之地读取无名元婴期修士从筑基到结丹再到凝结元婴的经验，认为可避免错误想法。证据：`凡人修仙传.txt:27740-27742`。

资源：原作事实。石碑心得，不是直接提升资源，但减少认知错误。

环境：原作事实。阴冥之地，祸福并存。证据：`凡人修仙传.txt:27741-27742`。

成功变化：我的判断。前人经验在机制上属于“突破知识/禁忌清单”，可降低错误决策，不应直接等同于提高概率的丹药。

失败后果：原作事实。若不知道凝婴忌讳，即使有九曲灵参也未必成功。证据：`凡人修仙传.txt:27741`。

突破方式三：特殊外力/双修/阴冥路线。

条件：原作事实。元瑶因金丹碎掉，借阴冥之气和人鬼合修功法，认为有机会重回结丹甚至凝结元婴。证据：`凡人修仙传.txt:28181-28183`。

资源：原作事实。阴冥之气、人鬼合修功法。具体通用性原文未说明。

环境：原作事实。阴冥之地。

成功变化：待核验。该段是角色判断与选择，不等于已证明的普适路线。

失败后果：原作事实。功法大成后可能受害，且丧失重进轮回资格。证据：`凡人修仙传.txt:28182`。

### 案例 4：元婴期 -> 化神期

境界层级：元婴期 -> 化神期；特殊状态包括元婴后期、元婴后期顶峰、半步化神、化神初期。

提升阶段：元婴初期/中期/后期、后期顶峰、寻找化神法门、冲击化神、化神成功/失败、稳固境界。

突破方式一：多资源闭关突破化神。

条件：原作事实。韩立经长期闭关修炼元磁神光，服用魔元丹等多种灵药，并借极品灵石和五种极寒之焰，突破化神初期。证据：`凡人修仙传.txt:63192-63194`、`凡人修仙传.txt:63255-63258`。

资源：原作事实。魔元丹、多种灵药、极品灵石、五种极寒之焰、元磁山/元磁神光相关秘术。证据：`凡人修仙传.txt:62061-62063`、`凡人修仙传.txt:62808`、`凡人修仙传.txt:63255-63258`。

环境：原作事实。特殊秘地/闭生死关，韩立离开宗门数百年。证据：`凡人修仙传.txt:63192-63194`。

成功变化：原作事实。化神后可初步调动天地元气，神通近似世俗传闻中的神仙；但人界天地元气稀薄，继续进阶中期几乎不可能。证据：`凡人修仙传.txt:63257-63258`、`凡人修仙传.txt:63282-63284`。

失败后果：原文未说明韩立此路线失败后果；但闭生死关意味着时间成本和宗门保护缺位。

证据锚点：韩立突破化神 `凡人修仙传.txt:63255-63258`；人界化神后续受天地元气限制 `凡人修仙传.txt:63282-63284`。

突破方式二：极寒之焰刺激/寒骊上人冲关。

条件：原作事实。寒骊上人元婴后期顶峰，研究突破化神，需集齐五名修炼不同寒焰的元婴修士，以极寒之焰刺激获取化神机遇。证据：`凡人修仙传.txt:52230-52234`。

资源：原作事实。五名不同寒焰元婴修士、玄玉洞等极寒环境、万年玄玉作为酬谢。证据：`凡人修仙传.txt:52234`、`凡人修仙传.txt:52750`。

环境：原作事实。小极宫玄玉洞/极寒之地，修士共同施法。证据：`凡人修仙传.txt:52234`、`凡人修仙传.txt:53285-53298`。

成功变化：原文未成功；观摩者认为若肉身檀化和元婴蜕变完成，则可能突破。

失败后果：原作事实。寒骊上人“功亏一篑”，神念稍差，未能突破化神瓶颈；体内玄玉寒气需拔除。证据：`凡人修仙传.txt:53318-53320`、`凡人修仙传.txt:53348-53360`。

我的判断：化神突破开始出现“多人协作突破仪式”和“观摩高阶突破”价值，适合设计为高风险公共事件，不只是个人闭关。

突破方式三：特殊体质/魔气灌体。

条件：原作事实。紫灵元婴后无法踏出化神一步，后因古魔祭坛联系六极圣祖，被真魔气灌体并改修魔道功法，一日千里进阶化神；原因还包含姹女素阴体。证据：`凡人修仙传.txt:122858-122860`。

资源：原作事实。古魔祭坛、六极圣祖神念、真魔气、魔道功法、特殊体质。

环境：原作事实。人界古魔遗留密地，后飞升魔界。证据：`凡人修仙传.txt:122858-122860`。

成功变化：原作事实。快速进阶化神并获得飞升魔界机会。
