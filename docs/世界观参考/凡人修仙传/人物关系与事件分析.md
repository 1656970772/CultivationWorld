## 完整人物关系变化链案例

### 案例 1：韩立、韩父母、三叔、七玄门

**关系变化链：**

（原作事实）韩立最初是山村贫寒家庭中的孩子，和父母、兄妹的关系以生计压力和亲情牵挂为底色；三叔作为较有身份的亲戚，先照顾韩家，又因七玄门招收弟子而想到适龄的韩立，使韩立和七玄门从无关系变成被举荐的候选者。韩父听到入门后有吃穿、月钱和外门出路后答应，韩立离家时仍以“挣钱后回家团聚”为目标。关系变化方向是血亲引荐扩展为宗门入口，公开、非对称，三叔掌握机会资源，韩立和父母承担分离后果。后续关系后果是韩立离家进入七玄门，原本的家庭供养目标逐步被修仙道路取代。（依据：`凡人修仙传.txt:27-50`、`凡人修仙传.txt:39-45`）

（我的判断）这条链说明早期“入门事件”不是单纯奇遇，而是由亲族资源、贫困压力和宗门招募机制共同推动；项目映射可作为“凡人家庭关系 -> 宗门入口 -> 长期离散”的关系初始化模板。

### 案例 2：七玄门、野狼帮、韩立等低阶弟子

**关系变化链：**

（原作事实）七玄门和野狼帮最初是地方势力竞争者，野狼帮觊觎七玄门控制的富裕城镇，经常挑起冲突；这类势力冲突推动七玄门扩招弟子，也使韩立等新入门者处在更高的门派压力中。后来双方冲突加剧，七玄门大量内门弟子被派下山参与拼杀，年长师兄出现伤亡。关系变化方向是地盘竞争升级为长期武装敌对，公开、势力对称但战斗风格不对称；后续关系后果是宗门扩招、历练制度变化和低阶弟子被卷入。（依据：`凡人修仙传.txt:79-83`、`凡人修仙传.txt:648-650`）

（我的判断）这是“势力仇怨牵连低阶成员”的样本：大势力的资源争夺会改变普通弟子的任务分配、生存风险和晋升路径。

### 案例 3：韩立、张铁、墨大夫

**关系变化链：**

（原作事实）韩立和张铁起初同为七玄门测试后留下的记名弟子，被墨大夫一并带走；张铁给韩立拿馒头，韩立称其“张哥”，二人因出身相近、脾气相投逐渐成为密友。墨大夫表面上把二人收为记名弟子并传授口诀、医药和象甲功，实际对韩立和张铁分别进行筛选与利用。张铁后来突然“外出闯江湖”而失踪，韩立虽难过但无力追查；再往后张铁肉身以曲魂/铁奴形式成为被控制的战斗工具，旧日好友关系被夺舍、炼尸和驱使关系覆盖。关系变化方向是同门互助 -> 密友 -> 被师长阴谋拆散 -> 好友肉身异化为工具；公开状态由公开同门转为隐秘操控，关系终态并非正常断裂，而是被夺舍/尸傀事件扭曲。（依据：`凡人修仙传.txt:165-183`、`凡人修仙传.txt:194-199`、`凡人修仙传.txt:289`、`凡人修仙传.txt:523`、`凡人修仙传.txt:15165-15192`）

（我的判断）这条链适合抽象为“同门友谊被上位者黑箱实验破坏”的案例。张铁不是普通退场角色，他的关系后果延伸到韩立对师徒、同门和夺舍的长期警惕。

### 案例 4：韩立、墨大夫、余子童

**关系变化链：**

（原作事实）韩立与墨大夫一开始是名义师徒，墨大夫对韩立提供药物、医术和修炼条件，但韩立逐渐察觉师徒间“不像普通师徒”的隔膜和危险。墨大夫返回后直接制住韩立，承认自己没真把韩立当徒弟，并以尸虫丸和韩立家人威胁其继续修炼长春功。墨大夫背后又有余子童元神提供夺舍之法，二人原先互害，后来因夺舍需求暂时合作，目标都是利用韩立肉身。最终墨大夫夺舍失败，韩立反过来吞噬/消灭相关元神，并清理余子童。关系变化方向是伪师徒 -> 控制与胁迫 -> 夺舍仇敌 -> 反杀终止；公开状态在七玄门中仍伪装为师徒，真实关系只有当事人知晓；关系后果是韩立形成极强的夺舍防范和不轻信导师的习惯。（依据：`凡人修仙传.txt:928-934`、`凡人修仙传.txt:1008-1066`、`凡人修仙传.txt:1917-1928`、`凡人修仙传.txt:1992-2057`、`凡人修仙传.txt:2090-2112`）

（我的判断）这是全书早期最典型的“师徒关系反转”链。师徒名分提供了资源和庇护表象，也提供了控制、投毒、威胁家属和夺舍的入口。

### 案例 5：韩立、厉飞雨

**关系变化链：**

（原作事实）韩立和厉飞雨最初并无深交，厉飞雨因服用抽髓丸发作被韩立发现，韩立救醒他并承诺保守秘密；厉飞雨因此欠韩立人情，韩立又给其配制缓解痛苦的药。二人关系从陌生同门/潜在冲突转为互相守秘、以人情维持的朋友关系；厉飞雨称韩立“韩师弟”，韩立也有意识地让厉飞雨每年取药，以保持人情不被遗忘。关系公开性偏低，秘密在于抽髓丸；关系不完全对称，厉飞雨武力强，韩立掌握药物和秘密；后续关系后果是韩立在七玄门内获得一个可调用的江湖武力盟友。（依据：`凡人修仙传.txt:695-715`、`凡人修仙传.txt:743-756`、`凡人修仙传.txt:764-770`、`凡人修仙传.txt:830-842`）

（我的判断）这条链不是单纯“友情”，而是救命、守秘、药物供给和人情债共同构成的低阶互助网络。

### 案例 6：韩立、马师伯、李化元

**关系变化链：**

（原作事实）韩立初入黄枫谷时与马师伯是药园管理任务中的上下级/长辈晚辈关系；马师伯性情古怪，但在韩立参加血色试炼前送出内外伤丹药，韩立判断其面冷心热。血色试炼后，韩立带出大量灵药并被李化元收为记名弟子，马师伯点破李化元收徒实际看中“谢师礼”灵药份额。韩立与李化元的关系从陌生高阶修士与低阶弟子，变成带有资源抽取性质的记名师徒，筑基后才得到较正式的重视。关系变化方向是任务合作 -> 长辈关照；另一路是被高阶修士因资源价值收徒 -> 筑基后关系升温。公开、非对称，后续后果是韩立获得师门名分与功法入口，同时更清楚宗门师徒关系中的利益计算。（依据：`凡人修仙传.txt:5689-5750`、`凡人修仙传.txt:6660-6662`、`凡人修仙传.txt:8553-8576`、`凡人修仙传.txt:9708-9709`、`凡人修仙传.txt:9840-9854`）

（我的判断）此例和墨大夫形成对照：同为师长关系，马师伯偏向有限善意，李化元偏向宗门利益和名分资源交换，可信度都不是无条件的。

### 案例 7：韩立、南宫婉、掩月宗

**关系变化链：**

### 案例 8：韩立、陈巧倩、陈家婚约

**关系变化链：**

（原作事实）陈巧倩早期在血色试炼等事件中与韩立有同门交集，后来在黑煞教相关行动中主动邀韩立同行谈话，指出韩立当年隐藏实力。她对韩立的评价从“普通同门/疑似好运者”转为识破其深藏不露；但陈巧倩另有家族安排，对方是秦家直系、天阙堡弟子，可能入赘陈家成为双修伴侣。关系变化方向是同门相识 -> 重新评价 -> 私人情感或好感空间被家族婚约覆盖；公开状态为同门公开，情感倾向未明说，关系终态转向家族安排。后续关系后果是韩立未将此线发展为道侣关系。（依据：`凡人修仙传.txt:13957-13973`、`凡人修仙传.txt:14880`）

（我的判断）这条链展示修仙家族婚约对个人关系的截断：即使有私人识别和好感，家族资源与双修安排仍可决定终态。

### 案例 9：辛如音、齐云霄、韩立、付家

**关系变化链：**

（原作事实）齐云霄与辛如音本是炼器/阵法圈中的互助关系，齐云霄多次救辛如音，辛如音认为恩情无以为报；韩立与二人有交易和传送阵修复关系。韩立救辛如音时杀死付家修士，齐云霄后来替辛如音外出寻材料，被付家追查牵连，逃回后重伤身亡；辛如音自愿过门守寡，并把齐云霄炼器心得和自己的阵法心血交给韩立，请求韩立日后为二人灭付家复仇。关系变化方向是救命恩义 -> 未成婚的情义 -> 死亡后守寡 -> 向第三方托付复仇；公开状态在小圈子内公开，关系不对称在于辛如音以传承和承诺交换韩立未来行动。后续关系后果是韩立承诺复仇，辛如音的阵法传承成为韩立后续破阵与传送能力的重要来源。（依据：`凡人修仙传.txt:15898-15909`、`凡人修仙传.txt:15917-15929`、`凡人修仙传.txt:15932-15945`、`凡人修仙传.txt:15953-15970`、`凡人修仙传.txt:30687`、`凡人修仙传.txt:47140`）

（我的判断）这是“恩义、死亡、传承、复仇承诺”高度压缩的一条链，适合用于设计遗愿任务和知识传承型关系后果。

### 案例 10：燕家、鬼灵门、王蝉、燕如嫣

**关系变化链：**

（原作事实）燕家和鬼灵门最初在燕家堡夺宝大会中表现为外来强客与主人关系，鬼灵门少主带人压制燕家弟子，引发燕家不安。鬼灵门随后提出归附条件：燕家加入鬼灵门，燕如嫣嫁给少门主王蝉并共修血灵大法，未来两家权力由二人后代承接；燕家内部讨论后基于魔道入侵、七派压制和家族延续选择归附，并要求生死咒作制约。王蝉和燕如嫣互下生死咒，关系从政治交易变成婚约与共同功法绑定；燕家和鬼灵门从无交情/试探转为附属同盟。后续关系后果是燕家迁离、七派修士被设计围杀，韩立与王蝉结下深仇。（依据：`凡人修仙传.txt:10387-10388`、`凡人修仙传.txt:10582`、`凡人修仙传.txt:10629-10640`、`凡人修仙传.txt:10675-10677`、`凡人修仙传.txt:10694-10714`、`凡人修仙传.txt:10728-10747`、`凡人修仙传.txt:10835-10875`）

（我的判断）这条链是势力婚姻的高价值样本：联姻不是情感终点，而是功法、继承权、宗门归附和战时站队的捆绑机制。

### 案例 11：韩立、王蝉、燕如嫣、鬼灵门

**关系变化链：**

（原作事实）燕家堡事件后，王蝉与韩立从无直接关系变成追杀/敌对关系；多年后韩立结婴，在南陇侯相关行动中再遇王蝉和燕如嫣，王蝉因韩立境界跃升而惊惧，王天古要求王蝉夫妇不要离自己太远以防韩立偷袭。燕如嫣尝试化解韩立与王蝉的仇怨，但韩立没有接受；后续冲突中，王蝉和燕如嫣联手用血灵大法牵制韩立。关系变化方向是旧仇 -> 境界反转后的忌惮 -> 配偶出面调停失败 -> 战斗对立延续；公开状态在鬼灵门高层和同行修士间半公开，关系不对称随韩立结婴而反转。后续关系后果是王蝉长期把韩立视为大敌，燕如嫣夹在夫妇/宗门关系与仇怨调停之间。（依据：`凡人修仙传.txt:32378-32397`、`凡人修仙传.txt:32455-32462`、`凡人修仙传.txt:32979-32987`、`凡人修仙传.txt:33083-33118`）

（我的判断）这是“仇敌境界反转”链：原先追杀者在对方成长后转为被威胁者，配偶调停只能降低即时冲突，不能消除旧仇。

### 案例 12：紫灵、妙音门、范夫人/卓如婷、乌丑、极阴岛

**关系变化链：**

（原作事实）妙音门原本是以女修和商贸为核心的中等势力，紫灵因门主被劫杀而组织复仇；她与范夫人、卓如婷等门内成员联手请外援，关系从门内竞争暂时转为共同追查仇敌。行动中发现赵长老等内应背叛，极阴岛乌丑承认劫货、嫁祸和收买叛徒，妙音门内部关系由同门协作反转为叛徒对峙。乌丑又以娶紫灵为条件挑衅，紫灵提出处死杀母修士作为条件但被拒。极阴祖师现身后，关系进一步升级为妙音门/外援被迫面对极阴岛压服。关系变化方向是门内合作 -> 内奸暴露 -> 三方对峙 -> 强者压迫下的生存危机；公开、非对称，后续关系后果是紫灵对极阴岛和乌丑形成深仇，并与韩立后续互助关系加深。（依据：`凡人修仙传.txt:18399-18457`、`凡人修仙传.txt:18555-18579`、`凡人修仙传.txt:18643-18670`、`凡人修仙传.txt:18706-18752`、`凡人修仙传.txt:18782-18822`）

（我的判断）这条链适合作为“门派商贸组织遭内鬼和外部强权双重侵蚀”的案例，关系后果不是单一复仇，而是势力信誉、继承权和外援网络重组。

### 案例 13：韩立、紫灵、虚天殿同行者

**关系变化链：**

### 案例 14：韩立、元瑶、啼魂兽

**关系变化链：**

（原作事实）韩立与元瑶早在乱星海有过照面，后来在虚天殿熔岩路/虫群危险中重逢；元瑶受困，韩立以庇护其离开为条件索要啼魂兽。元瑶几乎立刻答应，交出灵兽袋和控制啼魂的鸣魂珠；韩立看出其中可能有隐情，但仍收下。关系变化方向是旧识 -> 交易式救援 -> 灵兽所有权转移；公开状态只在当事人间，关系不对称，韩立掌握保护能力，元瑶掌握啼魂兽控制物。后续关系后果是啼魂兽成为韩立长期克制鬼物、尸焰等场景的关键伙伴，元瑶与韩立之间也形成带交易痕迹的人情关系。（依据：`凡人修仙传.txt:17204-17211`、`凡人修仙传.txt:21770-21772`、`凡人修仙传.txt:21807-21818`、`凡人修仙传.txt:21825-21828`、`凡人修仙传.txt:42248-42251`）

（我的判断）此例体现“灵宠关系的建边事件”可以是交易而非驯服。灵宠所有权、控制器物和救援条件共同构成关系转移链。

### 案例 15：韩立、噬金虫、铁火蚁群

**关系变化链：**

（原作事实）噬金虫不是人形角色，但与韩立构成长期主从/灵虫群关系；在虚天殿黑沙漠，韩立面对铁火蚁群时放出噬金虫，噬金虫吞食黑火并压制蚁群，帮助韩立通过危险区域。关系变化方向是储备灵虫/隐藏底牌 -> 战场主力 -> 资源消耗型伙伴；公开状态取决于场景，多数时候作为底牌隐藏；关系不对称，韩立指挥虫群，虫群以数量和吞噬能力提供生存保障。后续关系后果是韩立把噬金虫视为比一般宝物更有用的保命资源，不轻易为陌生人损耗。（依据：`凡人修仙传.txt:21707-21744`、`凡人修仙传.txt:21748-21764`、`凡人修仙传.txt:21891-21896`、`凡人修仙传.txt:22073-22092`）

（我的判断）这条链适合纳入“非人伙伴关系”：不是情感互动，而是高投入培育、战术损耗和关键场景不可替代性形成稳定绑定。

### 案例 16：韩立、银月、四瞳灵狐/玉如意

**关系变化链：**

（原作事实）银月最初是玉如意器灵，被韩立收取后随身；在落云宗雪云狐/四瞳灵狐事件中，银月说明自己有银月狼族残缺记忆，并借天赋灵魂吞噬夺得四瞳灵狐躯体。韩立担心银月泄露虚天鼎等秘密，银月则承认自身生死仍在韩立掌握，并提出可把主元神移入韩立飞剑充当器灵，以换取信任。关系变化方向是器物附属 -> 有自主意识的异族器灵 -> 互相试探 -> 主从契约强化；公开状态隐秘，关系不对称但带协商性质，银月既受制于寄身器物，也拥有情报和幻术价值。后续关系后果是银月成为韩立洞府事务、侦察、提醒和战术讨论的重要伙伴。（依据：`凡人修仙传.txt:29167-29196`、`凡人修仙传.txt:29201-29233`、`凡人修仙传.txt:29240-29285`、`凡人修仙传.txt:30605-30614`、`凡人修仙传.txt:31719-31731`）

（我的判断）这是“器灵主从关系从控制走向互利协商”的典型链，适合设计高智能器灵/AI 伙伴时参考：信任来自可验证制约，而非口头忠诚。

### 案例 17：韩立、落云宗、慕沛灵

**关系变化链：**

（原作事实）韩立以伪装低阶散修身份加入落云宗，最初只是新弟子与宗门的关系，慕沛灵作为筑基期师叔负责指点或管理相关事务。后续慕沛灵因家族婚事、杜东等牵连和韩立真实实力变化，被韩立收为侍妾作为一种惩戒与保护安排；韩立设置三十年之约，并施下禁神术、赠送筑基期丹药，慕沛灵则在子峰修炼。关系变化方向是师叔/师侄表面关系 -> 身份揭示后的依附 -> 名义侍妾与受控修炼者；公开状态在落云宗高层和相关人员中公开，关系不对称，韩立掌握禁制与资源，慕沛灵获得庇护和丹药。后续关系后果是慕沛灵随韩立参加交易会等场景，也暴露出“侍妾身份”可能被外部强者当作可交易对象的风险。（依据：`凡人修仙传.txt:28604-28655`、`凡人修仙传.txt:29411-29417`、`凡人修仙传.txt:30577-30614`、`凡人修仙传.txt:31832-31850`、`凡人修仙传.txt:31889-31899`）

（待核验）慕沛灵后续终局本轮未做全量检索，本文只确认到落云宗阶段的关系转变和交易会风险。

### 案例 18：韩立、落云宗二长老、令狐老怪/黄枫谷旧关系

**关系变化链：**

（原作事实）韩立早期在黄枫谷作为筑基修士参与魔道战争，后来黄枫谷溃败时被令狐老怪当作弃子处置，关系事实上断裂。多年后韩立以结丹后期/元婴身份在落云宗出现，落云宗二长老暗查其越国出身和黄枫谷旧史，确认其并非对落云宗另有目的；他们判断韩立一心苦修、对门派权力不热衷，因此只要笼络住他，落云宗可长期无忧。关系变化方向是旧宗门弃置 -> 新宗门收纳与调查 -> 高阶客卿/长老式依赖；公开状态在落云宗高层内部，关系不完全对称，韩立提供威慑，宗门提供灵地、身份和资源。后续关系后果是韩立成为落云宗稳定局面的关键节点，但仍保持个人修道优先。（依据：`凡人修仙传.txt:31806-31812`、`凡人修仙传.txt:31624-31626`、`凡人修仙传.txt:31737-31742`）

（我的判断）此例说明宗门关系可由“归属”转为“互利托底”：高阶个人不一定深度融入组织，也能成为组织安全结构的一部分。

### 案例 19：韩立、大衍神君、傀儡传承

**关系变化链：**

（原作事实）韩立最初通过千竹教林师兄事件获得大衍诀与傀儡真解，关系对象还不是大衍神君本人，而是功法/傀儡体系；后来大衍神君以残存意识长期指点韩立，传授五鬼锁神大法、解封秘术、假死法等，帮助韩立应对煞气、突兀追杀和大晋险局。二人关系从“得到传承文本”转为“残魂前辈与持有者”的合作/指点关系；公开状态隐秘，不对称但互有所求，大衍神君希望看到自身心血和材料目标，韩立需要见识与秘术。后续关系后果是韩立在多次危局中使用大衍神君提供的判断和法诀，大衍诀也成为韩立神识、傀儡和保命体系的重要支柱。（依据：`凡人修仙传.txt:9563-9582`、`凡人修仙传.txt:9798-9813`、`凡人修仙传.txt:11061-11121`、`凡人修仙传.txt:40934-40972`、`凡人修仙传.txt:41690-41708`、`凡人修仙传.txt:41976-41984`）

（我的判断）这不是传统师徒拜师链，而是“功法传承 -> 残魂顾问 -> 高阶风险共担”的关系链，可用于设计遗留意识型导师。

### 案例 20：灵兽山、御灵宗、越国七派

**关系变化链：**

（原作事实）灵兽山表面上是越国七派之一，和黄枫谷、掩月宗等同属越国修仙阵营；韩立后来从御灵宗修士处得知，灵兽山原本是御灵宗分支，是魔道预埋在越国的暗桩。魔道大战中，灵兽山趁警戒时打开大阵放入魔道，导致七派大败。关系变化方向是公开同盟 -> 隐秘渗透关系暴露 -> 背叛与阵营反转；公开状态从隐藏到战后暴露，关系不对称，灵兽山掌握联军内部部署，魔道利用其位置破阵。后续关系后果是七派修士对灵兽山大骂，越国战局急转直下，韩立也进一步确认宗门阵营并不天然可靠。（依据：`凡人修仙传.txt:11134-11136`、`凡人修仙传.txt:15292-15313`、`凡人修仙传.txt:15657-15658`）

（我的判断）这是势力关系中的“隐藏边”样本：公开关系和真实关系相反，事件触发后会从同盟瞬间转为背叛者，并造成战局级后果。

### 案例 21：韩立、妖修风希、毒蛟、玄龟

**关系变化链：**

（原作事实）韩立在乱星海遇到九级妖修风希，最初是误入巢穴的人类修士与高阶妖修的敌对/俘获关系；风希没有立即杀他，而是以碧焰酒提升其修为，并要求其木属性功法协助炼制法宝。风希又介绍两位化形妖修毒蛟和玄龟，三妖讨论妖修身体、法宝和对人类修士的战争，韩立在场但几乎无议价权。关系变化方向是猎物/俘虏 -> 被迫合作工具 -> 寻机逃脱对象；公开状态在三妖间公开，关系高度不对称。后续关系后果是韩立对高阶妖修的速度、族群护短和人妖冲突有直接认知，也为后续乱星海妖修战争背景提供关系动因。（依据：`凡人修仙传.txt:25617-25654`、`凡人修仙传.txt:25680-25703`、`凡人修仙传.txt:25768-25818`、`凡人修仙传.txt:25824-25825`）

（我的判断）这条链展示人妖关系不必只有捕杀，也可以是强迫合作；但合作建立在绝对实力差上，因此随时可反转为加害或逃亡。

### 案例 22：小极宫、人类修士、冰海妖兽/冰凤

**关系变化链：**

（原作事实）小极宫和冰海、万妖谷高阶妖兽长期围绕寒髓、化形雷劫和北冥冰岛资源形成敌对关系；大衍神君指出寒髓可提高妖兽渡化形雷劫成功率，所以妖兽会周期性攻打小极宫。后来小极宫外出现大量化形妖兽，冰凤、车老妖化身等参与，小极宫高层被迫讨论撤离和保全实力。关系变化方向是资源觊觎 -> 周期性攻防 -> 高阶妖修围宫 -> 人类宗门战略撤退；公开、势力对称但目的不同，妖兽要寒髓与渡劫机会，小极宫要保传承。后续关系后果是小极宫不能把战斗目标定为全歼妖兽，而要以保存宫内实力为优先。（依据：`凡人修仙传.txt:44115-44119`、`凡人修仙传.txt:52330-52331`、`凡人修仙传.txt:52545`、`凡人修仙传.txt:52846-52848`、`凡人修仙传.txt:52972-52997`、`凡人修仙传.txt:53233`）

（我的判断）这是“资源驱动的人妖势力关系”链：妖兽不是随机攻城，而是围绕渡劫资源、族群高层和宗门防御条件做周期性行动。

### 案例 23：韩立、曲魂、孙二狗

**关系变化链：**

（原作事实）曲魂原是墨大夫炼制/控制的铁奴式存在，韩立在离开七玄门后把曲魂作为战斗工具带在身边；在嘉元城，韩立用曲魂帮助孙二狗登上四平帮帮主之位，并把引魂钟交给孙二狗临时控制曲魂。孙二狗与韩立从被威胁的地头蛇/中介，转为受韩立扶持的帮主和代管者；曲魂则从韩立随身护卫转为寄放在凡人帮派中的威慑资源。多年后曲魂自行异变并逃离，孙二狗仍需向韩立交代下落。关系变化方向是主从控制 -> 外包代管 -> 凡人势力借用超常武力 -> 异变失控；公开状态在四平帮内部有限公开，关系不对称，韩立通过引魂钟和实力掌控全局。后续关系后果是孙二狗的地位建立在韩立背书和曲魂武力上，曲魂失控则把凡人帮派重新卷入修仙层面的风险。（依据：`凡人修仙传.txt:3573-3629`、`凡人修仙传.txt:4248-4258`、`凡人修仙传.txt:4487-4489`、`凡人修仙传.txt:14998-15012`、`凡人修仙传.txt:15165-15192`）

### 案例 24：墨府、韩立、严氏、墨彩环/墨凤舞
